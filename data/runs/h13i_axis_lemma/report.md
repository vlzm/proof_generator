# h13i_axis_lemma — однопараметрический разрез недостаточен для H13-I (сессия 9)

Цель: проверить, достаточно ли для H13-I (существование двойного разреза
`(a, b)` с `<= floor((n−1)^2/4)` инверсий) вращать только значения
(`b`), оставив позиции нетронутыми (`a = 0`, т. е. сама pi без сдвига). Если
бы `max_b concordant(pi, b) >= floor(n^2/4)` для всех pi, H13-I следовала бы
без выбора `a` вообще.

Команда: `python3 experiments/h13i_axis_lemma.py --nmax 8`. Версии: ядро не
задействовано (чистая комбинаторика на индексах, без `oracle/moves.py`),
скрипт h13i_axis_lemma-1.0. Покрытие: исчерпывающее, все pi при 2 <= n <= 8
(`n!` перестановок). Seed не требуется (полный перебор). Время: < 1 с при
n <= 8 (сумма 0.66 с), память — O(n!) не хранится, потоковый перебор.

Результат:

| n | floor(n^2/4) | min_pi max_b concordant | выполняется |
|---|---|---|---|
| 2 | 1 | 1 | да |
| 3 | 2 | 2 | да |
| 4 | 4 | 4 | да |
| 5 | 6 | 6 | да |
| 6 | 9 | 9 | да |
| 7 | 12 | 11 | **нет** |
| 8 | 16 | 15 | **нет** |

Наименьший контрпример: n = 7, `pi = (0,5,4,3,2,1,6)` (совпадает с примером
леммы C, `docs/notes/h13_line_model.md` §4, найденным там через условие на
префиксные суммы инверсий; здесь — независимая переформулировка через
максимум числа неинверсий при вращении одной оси). Прямая проверка полным
2D-перебором (`a`, `b` оба свободны) для этого же pi: максимум неинверсий
13 >= 12 достигается на 10 парах `(a,b)`, ни одна не имеет `a = 0`
(например `(1,2)`, `(2,1)`) — подтверждает, что именно вращение позиций
здесь необходимо, не только значений.

Вывод: однопараметрический (по значениям, с фиксированным разрезом позиций)
вариант H13-I ложен начиная с n = 7; совпадает по сути с уже известным
препятствием леммы C (сессия 8) в другой формулировке — не новый результат,
но независимое подтверждение и более простой (без условий на префиксные
суммы) контрпример. Не повторять: поиск доказательства H13-I через
фиксированный разрез позиций (только `b` свободен) в любой форме.

Следующий вопрос: сессия 9 не нашла доказательства полной (двухпараметрической)
H13-I за отведённый бюджет — см. `docs/notes/h13_line_model.md` §7 и
`PLAN.md` §8.
