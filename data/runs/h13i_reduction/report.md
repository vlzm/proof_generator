# h13i_reduction — contraction induction (k = 1, 2, 3) for H13-I

Дата: 14.09.2026 (сессия 9). Задача: доказать H13-I (`docs/notes/h13_line_model.md`
§6): у каждой pi в S_n есть двойной разрез с `I(pi) <= f(n) := floor((n-1)^2/4)`
инверсий. Направление сессии — индукция по n через удаление k элементов
(позиции + их значения, со схлопыванием обеих окружностей): нужен ли для
некоторого k явный шаг `I(pi) - I(contract(pi, K)) <= f(n) - f(n-k)` для
какого-то k-подмножества K.

Версии: `experiments/h13i_reduction.c` (h13i_reduction-1.0, исчерпывающий
перебор), `experiments/h13i_reduction_sample.py` (h13i_reduction_sample-1.0,
выборочная проверка при бОльших n). Ядро не используется (чистая
комбинаторика I(pi), без oracle/moves.py).

## Метод

`I(pi) = min_{q,c}` числа инверсий переразмеченной линии (как в
`experiments/line_profile.c`). Для k-подмножества позиций K: `contract(pi, K)`
удаляет позиции K и значения `pi[K]`, схлопывая обе окружности на оставшиеся
n-k точек с сохранением циклического порядка (естественное отображение на
классы тора при выбрасывании k точек). Точный бюджет шага индукции —
`f(n) - f(n-k)`, а не эвристический `n-k` (ошибка первой версии скрипта в
этой сессии, исправлена).

Исчерпуемый перебор (C, `I` для всех перестановок размера n-k предвычислена
и проиндексирована по рангу Лемера) — все pi в S_n, все C(n,k) подмножеств,
4 <= n <= 10. Выборочная проверка (Python) при 11 <= n <= 20: все n отражений
`pi_h(i) = h - i mod n`, все аффинные `pi(i) = a*i mod n` с `gcd(a,n) = 1`,
30 случайных перестановок (seed 12345) — семейства, ранее дававшие
контрпримеры к родственным гипотезам (H10, H11, индукция по одному элементу
в сессии 8).

## Результаты (исчерпывающе, 4 <= n <= 10)

| n | f(n) | k=1 бюджет / худший / контрпримеров | k=2 | k=3 |
|---|---|---|---|---|
| 4 | 2 | 1 / 1 / 0 | 2 / 2 / 0 | 2 / 2 / 0 |
| 5 | 4 | 2 / 2 / 0 | 3 / 3 / 0 | 4 / 4 / 0 |
| 6 | 6 | 2 / 2 / 0 | 4 / 4 / 0 | 5 / 5 / 0 |
| 7 | 9 | 3 / 3 / 0 | 5 / 5 / 0 | 7 / 7 / 0 |
| 8 | 12 | 3 / **5** / **16** | 6 / **7** / **8** | 8 / 8 / 0 |
| 9 | 16 | 4 / **5** / **18** | 7 / 7 / 0 | 10 / 10 / 0 |
| 10 | 20 | 4 / **7** / **40** | 8 / 8 / 0 | 11 / 11 / 0 |

(«худший» = `max_pi min_K [I(pi) - I(contract(pi,K))]`; жирным — превышение
бюджета.) Худшие входы при n = 8 (все k) и n = 9, k = 1 — вращения
мультипликативного `pi(i) = 5i mod 8` / `pi(i) = 4i mod 9`; при n = 9, k = 2
и n = 10, k = 1, 2 — вращения смешанного входа `(0,4,8,3,7,2,6,1,5)` (n=9) /
`(0,5,2,7,4,9,6,1,8,3)` (n=10); при n = 9, 10, k = 3 — почти полный разворот
`(0, n-1, n-2, ..., 1)`.

Команды: `gcc -O2 -o h13i_reduction experiments/h13i_reduction.c`;
`./h13i_reduction n k` для n = 4..10, k = 1, 2, 3 (n = 10, k = 1: 65 с;
k = 2: 76 с; k = 3: 98 с; остальные — секунды). Файлы
`result_n<n>_k<k>.json`.

## Результаты (выборочно, 11 <= n <= 20, только k = 3)

`sample_k3_n11_20.log`: k = 3 остаётся точным (без превышения) при n = 11, 12,
14 (среди проверенных семейств), но нарушается начиная с n = 13
(аффинный `pi(i) = 6i mod 13`: избыток 17 > бюджет 16) и снова при n = 15
(`7i mod 15`: 20 > 19), n = 16 (`7i mod 16`: 21 > 20), n = 18 (`7i mod 18`:
25 > 23), n = 20 (`9i mod 20`: 27 > 26).

## Вывод

Индукция «удалить k элементов» с точным бюджетом `f(n) - f(n-k)`:

- **k = 1**: нарушается с n = 8 (расширяет находку сессии 8, §1.7, теми же
  входами) и остаётся нарушенной при n = 9, 10 (число контрпримеров растёт:
  16, 18, 40).
- **k = 2**: нарушается ровно при n = 8 (8 контрпримеров, все — вращения
  одного мультипликативного входа), но точна (без запаса, без исключений)
  при n = 9, 10.
- **k = 3**: точна без единого исключения при всех 4 <= n <= 10 (исчерпывающе)
  и при n = 11, 12, 14 (выборочно, отражения + все взаимно простые аффинные
  входы + 30 случайных), но нарушается начиная с n = 13 на аффинном входе
  `6i mod 13` и далее на семействе `pi(i) = a*i mod n`.

Заключение: для любого фиксированного k индукция «удалить k элементов» рано
или поздно (при достаточно большом n) нарушается на мультипликативных
(аффинных) входах — тот же механизм, что закрыл H10/H11 и одноэлементную
индукцию в сессии 8 (`docs/notes/h13_line_model.md` §1.7): такие входы не
деградируют локально при удалении O(1) точек, поскольку их структура
арифметическая (по модулю n), а не позиционная. Это закрывает не только
одноэлементную, но всё семейство «удаление фиксированного числа элементов»
как путь к H13-I. Значение k = 3 интересно тем, что даёт точную (без запаса)
формулу на самом широком проверенном диапазоне (n <= 12) — возможный признак
точного тождества на этом интервале, но не общего закона.
