## Вопрос (PLAN §8, бюджет 2 сессии до письменного вердикта)

H10: для варианта N1 с маршрутом только по переносчикам
`min_c [2F_c − S_c + R_c] <= B_n + 1`, а после свободного сокращения `<= B_n`
при всех n >= 4 и pi из S_n. Шаг 1 — отражения, шаг 2 — общий случай.

## Вердикт

1. **На отражениях H10 верна и доказана** — `docs/proofs/C28_reflections.md`
   (C28). Следствия: `d(pi_h) <= B_n` для всех отражений, `d(sigma_n) <= B_n`
   при всех n >= 4 (C9 PROVED локально), слово для sigma_n имеет
   `N_X = floor((n−1)^2/4)`. Чекер `check_C28.py`: PASS, все h при 4<=n<=64,
   sigma_n при n <= 200 (`data/runs/check_C28/summary.md`).
2. **В общем случае H10 ложна (REFUTED), обе части.** Контрпримеры —
   аффинные входы `pi(i) = a·i + b (mod n)`, `gcd(a, n) = 1`, `a != 1`:
   - часть 2 («после сокращения `<= B_n`»): в аффинном семействе n = 17,
     (a, b) = (4, 10): `min_c red_R = B_n + 1`; среди всех перестановок —
     уже n = 10, `pi = (9,2,5,0,1,8,7,6,3,4)` (единственный такой вход при
     n = 10; см. «Исчерпывающая проверка при n = 10»);
   - часть 1 («`<= B_n + 1`»): n = 18, (5, 16): `min_c len_R = B_n + 3`
     (при c = 5: K = 5 циклов, F = 82, S = 23, R = 15; здесь после сокращения
     `B_n − 5`, но при (11, 2) того же n — `B_n + 1` после сокращения);
   - избыток растёт с n: n = 27, (8, 3): +4 / после сокращения +2; n = 28: +5 / +3;
     n = 36, (11, 27): +8 / +4; n = 50, (33, 3): +8 / +8; n = 54, (17, 5): +12 / +6.
   Файлы: `data/counterexamples/H10_affine_index.json` — все 441 (a, b) с
   нарушением (n <= 40 все, 41 <= n <= 60 худшие); полные таблицы по c со
   словами и сокращениями сохранены для n = 17 (4, 10), 18 (5, 16), (11, 2),
   27 (8, 3), 36 (11, 27), 54 (17, 5); остальные воспроизводит скрипт.
3. **Минимальность.** В аффинном семействе проверены все (a, b) при 4 <= n <= 40:
   наименьшее n с нарушением части 2 — 17, части 1 — 18. Среди всех
   перестановок: часть 2 нарушена при n = 10 (глобально наименьшее n:
   n <= 9 исчерпывающе в сессии 3, n = 10 исчерпывающе здесь), часть 1 при
   4 <= n <= 10 верна, так что её наименьший контрпример лежит в 11..18
   (в аффинном семействе — 18).
4. **Механизм.** Не слова, не маршрут и не выбор c, а сама схема. При n <= 10
   на аффинных входах локальные слова оптимальны: `local_len = sum_C d(q_C)`
   при всех c (q_C — состояние цикла в координатах переносчика; сумма d(q_C) —
   истинная нижняя оценка любой независимой обработки циклов при данных
   переносчиках), маршрут R_c мал, и тем не менее `len − d(pi)` велико:

   | n | (a, b) | d(pi) | B_n | min_c len_R | min_c red_R | потеря local | R_c при c* |
   |---|---|---|---|---|---|---|---|
   | 7 | (2, 1) | 14 | 21 | 19 | 17 | 0 при всех c | 3 |
   | 9 | (2, 0) | 26 | 36 | 33 | 32 | 0 при всех c | 3–4 |
   | 10 | (7, 2) | 34 | 45 | 46 | 44 | 0 при всех c | 7–8 |
   | 10 | (3, 4) | 34 | 45 | 46 | 40 | 0 при всех c | 8–9 |

   Уже `sum_C d(q_C)` (38 при n = 10, (7, 2), все c) превышает d(pi) = 34:
   кратчайшие слова для pi чередуют работу над разными циклами f_c, а схема
   сортирует циклы по одному. Это слагаемое «residual» карты потерь сессии 3
   (композиция циклов и само разложение на f_c; там до 10 при n = 9 на
   блочных вращениях). Аффинные входы с a != 1 — новое семейство, не
   входившее в выборки сессии 3. Аффинные входы далеки от диаметра (d = 34 против 45
   при n = 10), но избыток схемы над B_n на них растёт быстрее, чем запас
   `B_n − d`.

## Ход исследования

1. Данные отражений (`refl.py`-разведка, затем чекер): при нечётном n сдвиг
   c = 1 даёт ровно B_n при всех h; при n ≡ 0 (mod 4) — c ∈ {0, 1}; при
   n ≡ 2 (mod 4) и чётном h все c дают `>= B_n + 1`. Наблюдение, давшее
   доказательство: обход в длинную сторону из 0 в c = ±1 посещает все вершины,
   так что `R_{±1} <= n − 1` для любого pi, а F_c, S_c отражений явно считаются.
2. Безмаршрутная форма `min_c [2F_c − S_c] <= B_{n−1}` (эквивалент H10 при
   `R_c = n`): ложна — при n = 5 входы `pi = −2i + b` дают `B_{n−1} + 1`, при
   n = 7 `B_{n−1} + 2` при всех c. Максимум по всем pi: −1, 1, 0, 2, 1 при
   n = 4..8. Это указало на аффинные отображения.
3. Аффинное семейство: нарушения H10 с n = 17; таблица ниже.
4. Исчерпывающая проверка n = 10 (правило 10: замер 0.9 мс на перестановку
   для полного построения слов, 235 мкс для статистик; 4 процесса; чекпоинт
   по первому элементу перестановки).

## Исчерпывающая проверка при n = 10

`experiments/h10_scan.py --n 10 --workers 4`: 3 628 800 перестановок, статистики
для всех 36 288 000 сдвигов, 20 578 560 слов построены, исполнены и сокращены
(лучший сдвиг и все сдвиги с `len_R >= B_n`); 1 004 с на 4 процессах; отчёт
`data/runs/h10_scan/scan_n10.json`. Хвост гистограмм `min_c len_R − B_n`:
{−1: 909, 0: 90, +1: 6}; `min_c red_R − B_n`: {−1: 640, 0: 21, **+1: 1**}.

- Часть 1 при n = 10 держится: `min_c len_R <= B_n + 1`; входы с +1 — отражения
  h = 2, 4 (C28, случай 5), аффинные (7, 2) и (3, 4), а также (9,2,5,0,1,8,7,6,3,4)
  и (8,0,2,7,6,9,5,4,3,1).
- **Часть 2 нарушена уже при n = 10:** единственный вход
  `pi = (9,2,5,0,1,8,7,6,3,4)`, d(pi) = 36: при всех c длина `>= B_n + 1` и после
  сокращения `>= B_n + 1` (циклы f_c — (8, 2) или (4, 2, 2); при c = 6: F = 26,
  S = 12, R = 6). Это глобально наименьшее n для части 2 (n <= 9 исчерпывающе,
  C27v). Слова: `data/counterexamples/H10_part2_n10.json`. Минимум по c при
  сдвиге с `len_R >= B_n` вычислен точно: если бы какой-то сдвиг давал
  `len_R <= B_n − 1`, он же давал бы `red_R <= B_n − 1`.

Итого C27v в исправленной форме: часть 1 верна при 4 <= n <= 10 (все pi),
часть 2 — при 4 <= n <= 9 (все pi) и ложна при n = 10.

## Что это меняет

- H10 (C27) — REFUTED; C27v: часть 1 расширена до n = 10, часть 2 ограничена n <= 9 (при n = 10 один контрпример).
- Направление §4.2 «та же конструкция, минимум по c» закрыто: никакая оценка
  `2F_c − S_c + R_c` не даст `B_n + O(1)`, потому что сама величина
  (длина слова) превышает `B_n + 1` при n >= 18. Улучшение локальных слов
  и маршрута не поможет: на n <= 10 они уже оптимальны на этих входах.
- Положительный результат: C28 (все отражения, `d <= B_n`), C9 PROVED локально.
- Следующая задача — PLAN §8: выбор направления с совместной обработкой циклов
  (изучить геодезические аффинных входов при n <= 10) либо индукция H3;
  бюджет 1 сессия до письменного плана.
