# toric_inversions_fast — extending the exhaustive range of C33/H13-I

Дата: 17.09.2026 (сессия 9). Задача сессии (PLAN §8): доказать H13-I
(`I(pi) <= floor((n-1)^2/4)` при всех n >= 4). Код: `experiments/toric_inversions_fast.c`
(toric_inversions_fast-1.0), `experiments/toric_inversions_sample.py`
(toric_inversions_sample-1.0). Логи: `small_n.log`, `n11.log`, `n12.log`,
`large_n_samples.log` в этой директории.

## Метод

`I(pi) = min_{q,c} inv(w)` (см. `docs/notes/h13_line_model.md` §0) требует
наивно `O(n^2)` разрезов `x` `O(n^2)` на подсчёт инверсий = `O(n^4)` на
перестановку (`line_profile.c`, сессия 8). Здесь используется точная
рекуррентность (доказательство — «голова цикла переносится в конец»,
см. `docs/notes/h13_line_model.md` §7, новый §7 этой сессии):

```
inv(a+1, b) = inv(a, b) + (n-1) - 2*((pi[a] - b) mod n)
inv(0, b+1) = inv(0, b) + (n-1) - 2*((pinv[b] - 0) mod n)
```

Отсюда вся таблица `inv(a,b)`, `a,b = 0..n-1`, строится за `O(n^2)` после
одного базового подсчёта `inv(0,0)` — на два порядка быстрее наивного метода.

## Проверка корректности (правило 3 AGENTS.md)

- Значения `maxI` и `countMax` (число перестановок, достигающих максимума)
  при 4 <= n <= 10 совпали с `line_profile.c` (сессия 8, C33/C35/C36) и с
  независимой реализацией на Python (`I_full`, наивный `O(n^4)` перебор,
  проверено при 4 <= n <= 8 в ходе разработки, вне репозитория).
- `countMax = n` при каждом n = 4..12: экстремумы — ровно n отражений
  (согласуется с текстом C33).

Диапазон VERIFIED для C33/H13-I расширен с 4 <= n <= 10 до 4 <= n <= 12
(совпадает с глубиной основной таблицы расстояний C2v). n = 13 не запущен:
оценка по измеренному масштабированию (`x13`, размер сетки `x1.17`) — около
30 минут, не оправдано текущим вопросом (правило 10 AGENTS.md); при
необходимости воспроизводимо.

Выборочно (правило 9, `toric_inversions_sample.py`), n = 20, 50, 100, 101:
отражения (h = 0, 1) — точно на границе `floor((n-1)^2/4)`; антиподальная
транспозиция — I = 1; аффинные (в т.ч. `a = n-2`, `a = 99` при n = 101),
случайные (seed 1), identity, `rev_n` — все строго внутри границы, без единого
нарушения (38 проверок, 0 нарушений).
