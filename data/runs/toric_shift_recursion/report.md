# toric_shift_recursion — попытка доказательства H13-I (сессия 9)

Цель сессии (`docs/notes/h13_line_model.md` §6, бюджет 1 сессия): доказать
H13-I — `I(pi) <= floor((n-1)^2/4)` для всех pi. Результат: **не доказано**;
получены две новые структурные записи и одно опровержение (Claim A) для
следующей сессии. Код: `experiments/toric_shift_recursion.py`
(toric_shift_recursion-1.0). Полный вывод — ниже и в `output.txt`.

## 1. Claim A (закреплённый разрез позиций) — REFUTED

Гипотеза: разреза значений c одного достаточно при ФИКСИРОВАННОМ q (без
перебора q), т.е. `min_c inv <= floor((n-1)^2/4)` уже для w, построенной
прямо из pi (q = n-1). Исчерпывающая проверка всех pi:

| n | target | худший `min_c inv` | вход |
|---|---|---|---|
| 3 | 1 | 1 | OK |
| 4 | 2 | 2 | OK |
| 5 | 4 | 4 | OK |
| 6 | 6 | 6 | OK |
| 7 | 9 | **10** | (0,5,4,3,2,1,6) |
| 8 | 12 | **13** | (0,6,5,3,4,2,1,7) |

Опровергнуто при n = 7 (наименьшее n, ровно как в лемме C заметки: тот же
вход `(0,5,4,3,2,1,6)` — не совпадение, он уже был контрпримером к условиям
локальной оптимальности разреза). Вывод: фиксированный q не проще общей
задачи; нужен совместный перебор (q, c), что уже установлено численно при
4 <= n <= 10 (C33/C35), но доказательства не даёт.

## 2. Чистая рекурсия сдвига (новая лемма, PROVED + VERIFIED)

Перепараметризация разреза значений независимым якорем `c' = q+1-c`
(при фиксированном q даёт то же множество n разрезов, просто в другом
порядке) разрывает связь между двумя операциями:

- `Op_Q` (q -> q+1, c' фикс.): `inv` меняется на `(n-1) - 2*w_0`, где
  `w_0` — текущее значение на голове линии (голова переносится в конец,
  без переразметки).
- `Op_C` (c' -> c'+1, q фикс.): `inv` меняется на `(n-1) - 2*pos_0`, где
  `pos_0` — позиция элемента со значением 0 (переразметка всех значений на
  −1 mod n).

Доказательство прямым подсчётом инверсий элемента, покидающего/входящего в
экстремальную позицию (элемент со значением m на голове даёт m инверсий до
переноса и n−1−m после; симметрично для значения 0 при переразметке).
Проверено на 5000 случайных (n, q, c') при 3 <= n <= 14 — обе тождества
точны (`verify_recursions`). Следствие: `inv(q,c')` — функция высоты на
торе n x n с фиксированным (с точностью до перестановки) набором шагов
`{(n-1)-2k : k=0..n-1}` по каждой строке и по каждому столбцу.

Ограничение: покоординатный спуск по этой функции недостаточен — локальный
минимум по обеим координатам может превышать цель (тот же вход n = 7 из
леммы C заметки уже локально оптимален и даёт 10 > 9).

## 3. Двойственная форма (согласующиеся пары) — переформулировка, не решение

`inv(w) + noninv(w) = C(n,2)`, и `C(n,2) - floor((n-1)^2/4) = floor(n^2/4)`
точно при всех n >= 1 (проверено 1 <= n <= 200). Значит H13-I эквивалентна:
**на каком-то из n^2 разрезов число согласованных пар (сохраняющих
относительный порядок) не меньше `floor(n^2/4) = B_n`.**

Для пары `{i,j}` с `a=(j-i) mod n`, `b=(pi(j)-pi(i)) mod n` число разрезов
(из n^2), делающих пару согласованной: `g(a,b) = (n-a)(n-b) + ab`.

Усреднение по всем n^2 разрезам не годится именно там, где H13-I точна: на
отражениях (`I(pi_h) = floor((n-1)^2/4)` ровно, C33/C35) среднее `inv` по
всем разрезам близко к n²/3 — заметно выше цели — при всех проверенных
4 <= n <= 20 (см. таблицу в выводе). Значит `min <= среднее` не применимо
именно к экстремальным входам; нужен второй момент, неравномерное
распределение по разрезам или явная конструкция разреза по структуре pi.

## Вердикт

H13-I не доказана и не опровергнута за сессию (численно верна при
4 <= n <= 10, C33/C35). Новое отрицательное наблюдение: закреплённый q
(Claim A) не проще. Новое положительное наблюдение: чистая рекурсия сдвига
(п. 2) — годный инструмент для будущей сессии (например, для явной
конструкции: спуск по (Op_Q, Op_C) до тех пор, пока это уменьшает inv, затем
разбор оставшихся «локальных минимумов» по отдельной лемме, раз чистый
спуск не решает всё). Согласно плану (`docs/notes/h13_line_model.md` §6,
repo_state.md «Следующая задача»): бюджет сессии исчерпан без доказательства
— переход к индукции H3 (PLAN §4.3, п. 3) в следующей сессии; H13-I остаётся
CONJECTURED, кандидаты для возврата к ней — второй момент по согласованным
парам (п. 3) или явная конструкция разреза через рекурсию (п. 2).
