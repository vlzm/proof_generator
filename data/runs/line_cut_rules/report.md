# line_cut_rules — правила выбора разреза для H13-I

Версия line_cut_rules-1.0, seed 20260916, 33 с, память O(n^2).

Цель: по C38 (`docs/proofs/C37_toric_mean_bound.md`) усреднение по разрезам бесполезно — разрез нужно *выбирать*; проверяются простые канонические правила (минимум score по всем n^2 разрезам; ничьи разрешаются в худшую сторону — берётся наибольшее inv среди победивших разрезов).

Команда: `python3 experiments/line_cut_rules.py --nmax 8 --spearman_nmax 9 --families 40`. Покрытие: исчерпывающее по всем pi при 4 <= n <= 9 (все правила — до n = 8), далее выборочно (SAMPLED): все отражения, все аффинные, 60 случайных (seed 20260916), блочные входы. Ядро oracle-1.0 и таблицы не нужны: слова не строятся.

## Вывод и следующий вопрос

Правило «spearman» (разрез, минимизирующий `sum_j (w_j − j)^2`, то есть максимизирующий `sum_j j·w_j`) не нарушено ни разу; остальные правила нарушаются, «footrule» — уже при n = 4 на отражении `(0,3,2,1)` (inv 3 > 2) и при n = 8 на `(0,7,6,5,4,3,2,1)` (13 > 12). Отсюда гипотеза H13-S (CLAIMS C39). Конечная проверка не доказывает общий случай.

Следующий вопрос: доказать H13-S. Известная связь — неравенство Дэниелса `−1 <= 3τ − 2ρ <= 1`, из которого `D >= 0` следует при `sum_j (w_j − j)^2 <= n(n^2−1)/12`; среднее `sum d^2` по всем n^2 разрезам равно ровно `n(n^2−1)/6` (вдвое больше порога), а на отражении минимум примерно `n^3/12` — ровно на границе (`docs/notes/h13i_verdict.md` §4.1).
