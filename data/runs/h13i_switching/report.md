# h13i_switching — H13-I как задача о переключениях (сессия 9)

**Цель.** Проверить три вопроса о H13-I (`docs/notes/h13_line_model.md` §6):
(A) есть ли у каждой pi «устойчивый» разрез — такой, что каждый элемент линии
участвует не более чем в `floor((n−1)/2)` инверсиях (из него H13-I следовала бы
подсчётом степеней при чётном n); (B) верна ли счётная лемма «если все
`inv_v <= floor((n−1)/2)`, то `inv <= floor((n−1)^2/4)`»; (S) насколько
семейство n^2 разрезов отстаёт от максимума своего класса переключений
(2^(n−1) переключений), для которого граница `S >= floor(n/2)` доказана
(C37, теорема 4).

**Код и версии.** `experiments/h13i_balanced_cut.c` (h13i_balanced_cut-1.0,
C, без внешних зависимостей), `checks/check_C37.py` (check_C37-1.0, Python,
независимая реализация). Ядро oracle-1.0 и таблицы расстояний не используются:
утверждения — о перестановках и инверсиях, не о ходах окружности.

**Команды.**

```text
gcc -O2 -o h13i experiments/h13i_balanced_cut.c
./h13i A n      # n = 4..9  (претензия A и A')
./h13i S n      # n = 4..9  (разрезы против всех переключений)
./h13i B n      # n = 4..11 (счётная лемма B)
python3 checks/check_C37.py --hmax 8
```

**Параметры и покрытие.** Исчерпывающе по представителям торических классов
`pi(0) = 0` (класс замкнут относительно поворотов позиций и значений, поэтому
представителей ровно (n−1)!), по всем n^2 разрезам; в режиме S дополнительно по
всем 2^(n−1) переключениям; в режиме B — по всем n! словам. Seed не нужен
(полный перебор); в чекере случайные разметки — seed 4242, случайные pi —
seed 20260917.

**Ресурсы.** Однопоточно, память < 10 МБ. Время: A — 0.05 с (n = 8), 0.52 с
(n = 9); S — 0.08 с (n = 8), 1.4 с (n = 9); B — 0.5 с (n = 10), 7 с (n = 11);
`check_C37.py --hmax 8` — 22 с.

## Результаты

### A. «Устойчивый разрез» — REFUTED при n = 8 (строка C38)

| n | порог `floor((n−1)/2)` | представителей | без устойчивого разреза | `max_pi min_cut max_v inv_v` |
|---|---|---|---|---|
| 4 | 1 | 6 | 0 | 1 |
| 5 | 2 | 24 | 0 | 2 |
| 6 | 2 | 120 | 0 | 2 |
| 7 | 3 | 720 | 0 | 3 |
| 8 | 3 | 5040 | **2** | 4 |
| 9 | 4 | 40320 | **77** | 5 |

Контрпримеры при n = 8 (наименьшее n; минимальность — по n среди проверенных
4 <= n <= 9 и полным перебором всех представителей при этом n): ровно два
класса, `pi(i) = 3i mod 8` = (0,3,6,1,4,7,2,5) и `pi(i) = 5i mod 8` =
(0,5,2,7,4,1,6,3) — аффинные входы, те же, что и в §1.7 заметки (индукция
по одному элементу). У обоих по всем 64 разрезам минимум `max_v inv_v` равен 4
при пороге 3; при этом H13-I для них выполняется с запасом (`I = 9` у `3i` и `I = 11` у `5i` при границе 12).
То же число (`bad_Aprime`) получается, если смотреть только на разрез,
минимизирующий inv: при 4 <= n <= 7 он всегда устойчив, при n = 8, 9 — кроме
тех же 2 и 77 классов. Артефакт:
`data/counterexamples/C38_no_balanced_cut_n8.json`.

### S. Разрезы против всех переключений

| n | представителей | нарушений H13-I | max (max_switch S − max_cut S) | распределение разрыва |
|---|---|---|---|---|
| 4–7 | 6, 24, 120, 720 | 0 | 0 | все нули |
| 8 | 5040 | 0 | 6 | 0: 5014, 2: 25, 6: 1 |
| 9 | 40320 | 0 | 4 | 0: 40072, 4: 248 |

Разрыв 6 при n = 8 — у `pi(i) = 5i` (`max_cut S = 6`, `max_switch S = 12`).
Вывод: минимум по pi обеих величин равен `floor(n/2)` и достигается на
отражениях, но для отдельного pi семейство разрезов может не достигать
максимума своего класса переключений. Значит, теорема 4 (C37) даёт верную
константу, но не даёт H13-I.

### B. Счётная лемма (для C37 не нужна, но проверена)

Для всех слов длины n с `max_v inv_v <= floor((n−1)/2)` максимум inv равен
ровно `floor((n−1)^2/4)`: n = 4..11 → 2, 4, 6, 9, 12, 16, 20, 25. Нарушений
нет (исчерпывающе по всем n! словам, 4 <= n <= 11). При чётном n это
тривиальный подсчёт степеней; при нечётном n утверждение сильнее подсчёта
(`n(n−1)/4` против `(n−1)^2/4`) и остаётся открытым — см. C37 §6, замечание.
Экстремальные слова — `K_{m,m}` плюс изолированная вершина, например
(0,5,6,7,8,1,2,3,4) при n = 9.

### V. Семейство «средних по разрезам на самой pi» недостаточно

Для каждой pi и каждого (a, b) усредним S по n разрезам `(j + a, pi(j) + b)`
(это в точности семейство `mu * mu^-` из C37 §7в; при a = −1 — семейство
«первый элемент линии равен t» из §1.7 заметки). Максимум по (a, b) меньше
`floor(n/2)` уже при n = 5 (pi = (0,1,4,3,2): 8/5 < 2) и при n = 7
(pi = (0,2,1,6,5,4,3): 13/7 < 3). Положительно определённая релаксация
(замена pi на её автокорреляцию) для H13-I не проходит.

## Вывод и следующий вопрос

Доказано (C37): граница `floor((n−1)^2/4)` — это в точности граница класса
переключений, верная для любой ±1-разметки K_n (теорема 4), причём
экстремальный класс — класс отражений. H13-I равносильна тому, что **семейство
n^2 разрезов** достигает этой границы; локальные аргументы (переключение одной
вершины, пары вершин) внутри семейства недоступны — контрпримеры A при n = 8.

Следующий вопрос: описать, какие переключения вида `A_q Δ B_s` (северо-запад ∪
юго-восток для разбиения решётки позиций×значений) обязаны присутствовать в
классе. Конкретная проверяемая гипотеза для следующей сессии: для разреза,
минимизирующего inv, оценить суммарное нарушение `sum_v max(0, −d_v)` и число
неустойчивых вершин на тех 2 (n = 8) и 77 (n = 9) классах, где устойчивого
разреза нет, и выяснить, ограничено ли оно константой (тогда подсчёт степеней
даёт H13-I с поправкой).
