# toric_cuts — цель, параметры, результат (правило 7)

- **Цель.** Найти доказательство H13-I (`I(pi) <= floor((n−1)^2/4)`): проверить
  точные тождества о двойных разрезах и отсеять кандидатные семейства разрезов,
  по которым можно было бы усреднять.
- **Команда.** `python3 experiments/toric_cuts.py --nmax 8 --exhaustive-max 7`
  (по умолчанию `--sample 4000 --seed 20260915`).
- **Версии.** toric_cuts-1.0; ядро ходов не используется (чистая комбинаторика
  перестановок), таблицы расстояний не используются.
- **Параметры/seed.** `seed = 20260915` (выборка только при n = 8).
- **Покрытие.** Исчерпывающее при 4 <= n <= 7 (все n! перестановок);
  при n = 8 — выборка 4000 случайных плюс все аффинные входы и все отражения.
  Тождества проверяются на 6 перестановках каждого n (проверка O(n^4)).
- **Проверено состояний.** 24 + 120 + 720 + 5040 + 4040 перестановок,
  для каждой — все n^2 разрезов; рёбра графа ходов не задействованы.
- **Время.** ~2 с суммарно.
- **Результат.** Тождества подтверждены (счёт разрезов по паре, формула
  взвешенного покрытия, инвариант троек, `(n−2)I >= T`). Все семейства
  усреднения (равномерное, диагонали, антидиагонали, все наклоны, привязка
  к точкам) превышают порог `n·floor((n−1)^2/4)` начиная с n = 5 (привязка
  к точкам — при n = 5, 7, 8). Аффинный запрет подтверждён при 4 <= n <= 8.
- **Артефакты.** `report.md`, `report.json`.
- **Вывод.** Усреднения закрыты; доказательство H13-I должно выбирать разрез
  адаптивно. Подробности — `docs/notes/h13_line_model.md` §7,
  `docs/proofs/C37_toric_reflection.md`.

  покрытие с весами `k(n−k)`) построить правило выбора s при подходящем p,
  дающее `floor((n−1)^2/4)`?
