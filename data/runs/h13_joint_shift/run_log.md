# data/runs/h13_joint_shift — H13-I, сессия 9: алгебраические факты о совместном сдвиге

Цель: проверить новые структурные факты о сетке двойных разрезов (a, b),
найденные при попытке доказать H13-I (докупить набор фактов сверх
`docs/notes/h13_line_model.md` §1–4), и проверить ещё одно семейство из
n разрезов (без сдвига значений, b = 0), не тождественное уже отвергнутому
семейству «первый элемент линии = t».

Команда: `python3 experiments/h13_joint_shift.py --nmax 8`
(также `--nmax 6`, `--nmax 7` промежуточно — согласованы).

Параметры: nmax = 8 (полный перебор всех перестановок 4 <= n <= 8 для
фактов 1–3); факт 4 — только отражения pi_h, n из
{4,5,6,7,8,9,10,20,50,101,200}. Seed не требуется (перебор детерминирован).

Версии: код `experiments/h13_joint_shift.py` (h13_joint_shift-1.0); ядро
oracle-1.0 не используется (инверсии считаются напрямую, без ходов LRX);
коммит репозитория на момент запуска: 00f69c1d7f81d3840f8c5e9473bb9492e9327a1d.

Тип покрытия: исчерпывающий перебор всех перестановок при 4 <= n <= 8 для
фактов 1–3 (2 213 640 перестановок суммарно); отдельные значения n для
факта 4 (точные семейства, не выборка).

Проверено состояний: факт 1 — 1 246 944 пар (все pi, все пары позиций,
4<=n<=8); факт 2 — 362 878 шагов (все pi, все b, 2<=n<=8, суммарно с
меньшими n); факт 3 — все перестановки 4<=n<=8 (24+120+720+5040+40320);
факт 4 — 11 значений n (перечислены выше).

Время: ~10.6 с (nmax=8, факты 1–3); факт 4 — доли секунды. Память: не
измерялась отдельно, менее 200 МБ (перебор без хранения полного списка).

Результат:

1. Тождество «конкордантность минус дискордантность = (2da−n)(2db−n)» для
   каждой пары позиций, при прямом переборе по всем n^2 разрезам —
   **PASS, 0 нарушений** (1 246 944 пар).
2. Телескопическая рекурсия `inv(shift_{b+1}(s)) − inv(shift_b(s)) =
   n − 1 − 2·pos(b)` — **PASS, 0 нарушений** (362 878 шагов).
3. Семейство «b = 0» (только n поворотов позиций q, без сдвига значений c):
   недостаточно для H13-I. При n = 7 худший вход — `(0,5,4,3,2,1,6)`
   (тот же свидетель, что и в лемме C §4 заметки h13_line_model.md; полный
   I(pi) для него — 8, см. §4), `min_a J(a) = 10 > floor(36/4) = 9`; при
   n = 8 — `(0,6,5,3,4,2,1,7)`, `min_a J(a) = 13 > floor(49/4) = 12`.
   При n = 4, 5, 6 семейство достаточно (совпадает с целью на худшем входе).
4. Для отражений `pi_h`, семейство «b = 0» одно, без подбора c, уже
   достигает цели **точно**: `min_a J(a) = floor((n−1)^2/4)` при всех
   проверенных n (4..10, 20, 50, 101, 200), через элементарную формулу
   «два монотонных пробега» `J(a) = C(k,2) + C(n−k,2)`, минимум по
   `k = floor(n/2)` — сверено с прямым перебором на 4 <= n <= 10 и с
   замкнутой формулой на всех 11 n.

Контрпримеры: не к H13-I (она не проверялась этим скриптом заново — это
уже C33, здесь не повторяется); к достаточности семейства «b = 0» —
n = 7: `(0,5,4,3,2,1,6)`; n = 8: `(0,6,5,3,4,2,1,7)` (сохранены только как
вывод скрипта, отдельный файл не создавался — оба воспроизводимы командой
выше).

Артефакты: `experiments/h13_joint_shift.py`; полный вывод для nmax=8 —
`data/runs/h13_joint_shift/run_nmax8.log`.

Вывод: факты 1, 2, 4 — доказаны алгебраически (см.
`docs/notes/h13_line_model.md` §7) и подтверждены исчерпывающим перебором
на симметричных n. Факт 3 закрывает ещё одно семейство из n разрезов как
недостаточное для H13-I. Ни один из фактов не завершает доказательство
H13-I — общий случай требует совместного (не покоординатного) выбора a, b,
как и раньше.
