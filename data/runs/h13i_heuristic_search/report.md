# H13-I — эвристический поиск контрпримера (simulated annealing)

Дата: 17.09.2026 (сессия 9). Цель: проверить попыткой опровержения гипотезу
H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi) на n, где исчерпывающий
перебор недоступен, прежде чем пытаться доказательство. Это поиск ошибок
(AGENTS.md, правило 9), не доказательство и не замена исчерпывающей проверки.

## Метод

`experiments/h13i_heuristic_search.py` (h13i_heuristic_search-1.0):
simulated annealing по перестановкам, целевая функция `I(pi)` (максимизация).
`I(pi)` считается точно (не оценкой) по формуле двойного инкремента —
см. §0 ниже; сверена с полным перебором n^2 разрезов на n = 3..8 (точное
совпадение на 40 случайных pi на каждое n). На каждое n: 5 рестартов
(до 4 из них — старт с отражений `pi_h`, h = 0..min(n,4)-1; остальные —
случайные), 1500 итераций (800 при n >= 20), T: 3.0 -> 0.05 линейно,
предложение — случайная транспозиция двух позиций. Отдельно (не в
run1.jsonl, воспроизведено в сессии интерактивно): вариант без затравки
отражениями (все рестарты случайные) — см. §3.

## Команда и параметры

```
python3 experiments/h13i_heuristic_search.py 11 12 13 14 16 18 20 24 28 32 40 50
```
seed = 0 (фиксирован в коде, `anneal(..., seed=0)`); без core (эталонных
ходов) — I(pi) вычисляется прямой арифметикой по перестановке, BFS и
`oracle/moves.py` не используются.

## Результат

`data/runs/h13i_heuristic_search/run1.jsonl` — для каждого n: цель
`floor((n-1)^2/4)`, найденный максимум `I(pi)`, аргмакс, время. На всех
n в {11,12,13,14,16,18,20,24,28,32,40,50}: найденный максимум **равен**
цели (`H13_I_violated: false` везде), нарушений не найдено. Суммарное
время < 5 с.

## §3. Без затравки отражениями

Отдельный прогон (той же функцией `anneal`, `reflection_seeds=False`,
2500 итераций, 8 случайных рестартов, seed = 1) на n = 11, 14, 18, 22:
без стартовой точки-отражения поиск из чисто случайных перестановок
не всегда достигает цели за отведённое число итераций (n=11: 25/25;
n=14: 37/42; n=18: 63/72; n=22: 97/110) — таблица «отражения — локальный
и, по всем данным, глобальный максимум» не опровергнута, но точку
экстремума случайный старт не всегда находит за разумное число шагов
(ожидаемо: пространство перестановок велико, окрестность транспозиций
не гарантирует быстрый подъём к узкому максимуму). Важный факт для
вывода — ни в одном прогоне (со отражениями или без) `I(pi)` не превысил
`floor((n-1)^2/4)`.

## Вывод

Эвристика не находит контрпримера при 11 <= n <= 50 (не перебор — не
доказательство и не гарантия отсутствия контрпримера за пределами
исследованных перестановок, но локальный подъём с разных стартов,
включая случайные, ни разу не поднялся выше `floor((n-1)^2/4)`,
что согласуется с исчерпывающими данными при 4 <= n <= 12/13
(`data/runs/h13i_exhaustive/`)). Дополнительное свидетельство в пользу
H13-I; доказательства не даёт.
