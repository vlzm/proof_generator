# Прогон h13_i — H13-I: торическое тождество, конечные проверки, выборки

Дата: 17.09.2026 (сессия 9). Вердикт: `docs/notes/h13_i_verdict.md`.
Доказательство: `docs/proofs/C37_toric_identity.md`.

## Цель

Доказать H13-I (`I(pi) = min по n^2 двойным разрезам числа инверсий линии
<= floor((n − 1)^2/4)`) либо дать письменный вердикт с разбором причин.
Побочные цели: перепроверить конечный статус H13-I своим кодом; выяснить,
только ли отражения экстремальны; найти почти-экстремальные семейства
при больших n.

## Версии

- `experiments/toric_inversions.c` — toric_inversions-1.0
- `experiments/toric_sampling.py` — toric_sampling-1.0
- `checks/check_C37.py` — check_C37-1.0
- Ядро LRX (oracle-1.0) и таблицы расстояний **не используются**: величина
  `inv(w)` определяется через перестановки и не зависит от модели LRX.

## Результат

1. **H13-I VERIFIED при `4 <= n <= 10`** (независимый пересчёт): нарушений 0,
   `max_pi I(pi) = floor((n − 1)^2/4) = 2, 4, 6, 9, 12, 16, 20`, число
   аргмаксимумов равно `n` и все они — отражения.
2. **Доказано (C37)**: тождество `inv(a, s) = c(pi) + Q(a, s)/n`
   (`Q = sum_j (j − w_j)^2`); формула `c(pi) = (1/n^2) sum_{i<k}
   (T(k−i) − T(pi(k)−pi(i)))^2`; `c(pi) <= (n−1)(n−2)/6` с равенством
   ровно на отражениях; `min_r J(r) <= floor((n−1)^2/4)` для выровненной
   релаксации; `I(pi_h) = floor((n−1)^2/4)` для всех отражений и всех n.
3. **H13-I не доказана.** Разрыв — «плата за невыровненность»
   `M(a, r) >= 0`: `max_pi (I − min_r J)` равен `0, 0, 0, 0, 3, 2, 5`
   при `n = 4..10` и не меньше `8, 10, 24, 56` при `n = 12, 15, 20, 30`.
4. **Новая гипотеза C38** (`sum_a min_s inv(a, s) <= n · floor((n−1)^2/4)`)
   VERIFIED исчерпывающе при `4 <= n <= 10`, равенство ровно на отражениях;
   C38 => H13-I.
5. **Опровергнуты** (контрпримеры в `checks/check_C37.py`, части E, F):
   релаксация без слагаемого `c` (n = 8, `pi(i) = 5i`), усреднение по
   антидиагонали (n = 5, `(0,1,2,4,3)`), усреднение по сдвинутым разрезам
   в точках данных (n = 5, `(0,1,4,3,2)`), поякорная форма C38 (n = 4,
   `tau = (0,2,3,1)`), правило «r = argmin J» (n = 8, `(0,2,6,5,1,3,7,4)`).
6. **Структура экстремальных**: экстремальны ровно отражения (при n <= 10
   исчерпывающе; общая часть — лемма 3 и предложение 6). Почти-экстремальные —
   отражения с 1–2 транспозициями (`bound − 1`, `bound − 2`) и аффинные
   входы (до `bound − 3` при n = 20). Локальный поиск при n = 12..30
   границу не превысил.

## Контрпримеры (артефакты)

Все перечисленные контрпримеры воспроизводятся `checks/check_C37.py`

## Вывод и следующий вопрос

H13-I остаётся CONJECTURED (VERIFIED `4 <= n <= 10`). Следующая задача
по контингенции `docs/notes/h13_line_model.md` §6 — индукция H3
(PLAN §4.3, п. 3), бюджет 2 сессии. Если возвращаться к H13-I, цель —
C38 (усреднение по строкам), а не минимум по разрезам; поякорно она ложна,
нужна связь между строками.
