# check_C32 — прогон 13.09.2026 (сессия 5)

Цель: проверить лемму C32 (`R_c <= 2(n - g_max)`, `docs/proofs/carrier_route_gap.md`)
исчерпывающе на всех (pi, c) при 4 <= n <= 9, и измерить покрытие усиленного
достаточного условия H10 (SC') против прежнего (SC, C31).

Команда: `python3 checks/check_C32.py --exhaustive 9 --out data/runs/check_C32`

Версии: check_C32-1.0, ядро oracle-1.0, конструкция strict_upper-1.0.

Покрытие: исчерпывающе все pi из S_n и все c из Z_n при 4 <= n <= 9
(3 628 224 пары (pi,c) суммарно). Время: 337.7 с (n = 9 — 308.0 с из них).
Память: не измерялась отдельно, проход потоковый (без накопления перестановок).

Результат: лемма C32 не нарушена ни разу (0 нарушений на каждом n).
Покрытие (SC) / (SC'):

| n | SC, % | SC', % |
|---|---|---|
| 4 | 100.000 | 100.000 |
| 5 | 91.667  | 100.000 |
| 6 | 92.500  | 95.278  |
| 7 | 90.278  | 92.798  |
| 8 | 83.135  | 90.756  |
| 9 | 81.467  | 89.682  |

Вывод: (SC') строго покрывает больше входов, чем (SC), на каждом n, но доля
непокрытых не убывает к нулю (растёт с 0 % при n=4 до ~10-19 % при n=8,9 для
обоих условий) — ни C31, ни C32 отдельно не завершают доказательство общего
случая H10 (`docs/notes/H10_general_obstruction.md`).
