# h13i_torus_model — торическая переформулировка H13-I: проверка тождеств

Дата: 15.09.2026 (сессия 9). Цель: подтвердить (не доказать) переформулировку
H13-I как задачи о точках `(i, pi(i))` на торе `Z_n x Z_n` и четыре
структурных тождества, найденных при попытке доказательства, против
независимого brute-force `inv()` и против определения `w_{q,c}` из
`experiments/line_profile.c` / `experiments/line_model.py`.

Версия: `h13i_torus_model-1.0` (`experiments/h13i_torus_model.py`). Команда:
`python3 experiments/h13i_torus_model.py --nmin 4 --nmax 8`. Ядро oracle не
используется (чистая комбинаторика `pi`, без `oracle/moves.py`). Seed:
факт 3 — `seed=0`, факт 4 — `seed=1` (см. код); детерминированная
последовательность `random.Random(seed)`. Память — O(1) (без больших
массивов, только счётчики).

## Покрытие и результат

- Факт 5 (тождество `C(n,2) − floor(n^2/4) = floor((n−1)^2/4)`): n = 2..30 — PASS.
- Факт 1 (замена координат `(q,c) <-> (a,b)`, `a=q+1`, `b=q+1−c`, совпадение
  с `inv(w_{q,c})` из line_profile.c): все pi, все `(q,c)`, 4 <= n <= 8 — PASS.
- Факт 2 (квадрантное тождество: для пары точек с зазором позиций `l` и
  зазором значений `m` дискордантность на `l(n−m)+(n−l)m` из `n^2` разрезов,
  согласованность на `lm+(n−l)(n−m)`): все pi, все пары точек, 4 <= n <= 8 — PASS.
- Факт 3 (пошаговые тождества `F(a+1,b)−F(a,b) = (n−1)−2((pi(a)−b) mod n)` и
  симметричное по `b`): 200 случайных `(pi, a, b)` на n, `a, b` до `3n`
  (проверяет и обёртку через границу), 4 <= n <= 8 — PASS.
- Факт 4 (замкнутая форма
  `F(a,b) = F(a,0) + F(0,b) − F(0,0) + 2ab − 2nR(a,b)`,
  `R(a,b) = #{i < a : pi(i) < b}`): 300 случайных `(pi, a, b)`, `0 <= a,b <= n`,
  4 <= n <= 8 — PASS.

Время: n = 4..7 — 3 с; n = 8 (факты 1, 2 исчерпывающе) — 30 с. Полный лог —
`report.log`, машиночитаемый результат — `report.json` (последний запуск,
n = 4..8).

## Смысл и статус

Факты 1, 2, 5 — элементарная алгебра/переиндексация, PROVED и здесь же
VERIFIED компьютером против brute-force `inv()` и против `line_profile.c`.
Факт 3 — стандартный аргумент «перенос экстремального элемента с одного
конца линейного расположения на другой меняет число инверсий на явную
величину» (см. `docs/notes/h13_line_model.md`, раздел сессии 9), PROVED,
здесь VERIFIED случайными пробами с обёрткой через n. Факт 4 — телескопирование
факта 3 по прямоугольнику, PROVED из факта 3, здесь VERIFIED случайными
пробами.

Ни один из фактов 1–4 сам по себе не доказывает H13-I: факт 4 показывает, что
вдали от n точек графика pi функция `F(a,b)` (число инверсий разреза) имеет
ту же дискретную «кривизну», что и функция для тождественной перестановки
(классический тент `phi(c) = c(n−c)`, `c = (a−b) mod n`), с «отрицательными
всплесками кривизны» `−2(n−1)` ровно в n точках графика pi — но это не даёт
оценку `min_{a,b} F(a,b)` без дополнительного аргумента (не найденного в этой
сессии). Подробности и что было опробовано и не сработало —
`docs/notes/h13_line_model.md`, раздел «7. Сессия 9».

## Дальше (следующий вопрос)

Тождества 1–4 можно использовать в будущей сессии как готовый (проверенный)
набор инструментов для попытки завершить доказательство H13-I — не нужно
заново выводить пошаговые формулы или замкнутую форму. Открытый вопрос:
даёт ли совместный (двух-указательный) выбор `(a,b)`, использующий
монотонность `F(a+1,·) − F(a,·)` по b (факт 3), оценку `min_{a,b} F(a,b) <=
floor((n−1)^2/4)` в общем случае — см. `docs/notes/h13_line_model.md` §7.6.
