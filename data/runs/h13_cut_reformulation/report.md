# H13-I: две тождества и два отрицательных результата (сессия 9)

Дата: 17.09.2026. Ядро: не используется (комбинаторика двойных разрезов,
без ходов oracle). Таблицы: не требуются. Код: `experiments/h13_cut_reformulation.py`
(h13_cut_reformulation-1.0).

## Цель

Задача сессии (`docs/notes/h13_line_model.md` §6): доказать H13-I —
у каждой pi есть двойной разрез (a, b) с `inv(w) <= floor((n-1)^2/4)`.
Вопрос сессии: даёт ли точная формула числа разрезов-инверсий по паре
и/или телескопирование по b конструктивный путь к доказательству; работают
ли простые сужения перебора (диагональные разрезы, разрез a + средний b).

## Команда и параметры

```
python3 experiments/h13_cut_reformulation.py --nmax 7 --sample 8 9 --trials 500 --seed 1
```

`--nmax 7`: исчерпывающий перебор всех pi при 3 <= n <= 7 (6, 24, 120, 720,
5040 перестановок). `--sample 8 9 --trials 500 --seed 1`: 500 случайных pi
при n = 8, 9 плюс явная проверка на отражении (известный худший случай для
I(pi), C33/C35).

## Покрытие, время, память

Перебор n <= 7 — исчерпывающий по pi (все n^2 разрезов на каждой);
n = 8, 9 — 500 случайных pi плюс отражение (не исчерпывающе, для тождеств
это самопроверка, а не доказательство). Время 3.2 с, память <50 МБ
(чистый Python, in-memory).

## Результат

### 1. Тождество числа разрезов по паре (PROVED, проверено)

Для пары индексов i != i' с зазором позиций `d = (i'-i) mod n` и зазором
значений `e = (pi(i')-pi(i)) mod n` (оба в 1..n-1) число разрезов (a, b) из
n^2, на которых пара инвертирована, равно `n(d+e) - 2de`.

Доказательство: при разрезе a `x'_i=(i-a) mod n`; `x'_{i'}-x'_i ≡ d`
не зависит от a, а `x'_i` — биекция по a, поэтому ровно `n-d` значений a
дают `x'_i<x'_{i'}` и `d` значений — обратное; симметрично для b: `n-e`/`e`.
Так как a и b независимы, число несогласий = `(n-d)e + d(n-e) = n(d+e)-2de`. ∎

Проверено (`pair_count_formula` против брутфорса `pair_count_brute`):
совпадение на всех pi при 3 <= n <= 7 и на 500 случайных pi при n = 8, 9.

### 2. Телескопирование по b (PROVED, проверено)

При фиксированном a: `inv(a, b+1 mod n) = inv(a, b) + (n-1) - 2 p(a, b)`,
где `p(a, b) = (pi^{-1}(b) - a) mod n` — позиция (в a-развороте) точки со
значением, сравнимым с b.

Доказательство: последовательность для разреза (a, b+1) получается из
последовательности для (a, b) вычитанием 1 по модулю n из каждого элемента;
это переводит единственный элемент, равный 0 (на позиции p), в n-1
и уменьшает остальные элементы ровно на 1 — изоморфизм порядка на них.
Меняется порядок только у пары, где участвует позиция p: она теряла p
инверсий как минимум (с каждым более ранним элементом) и приобретает
n-1-p инверсий как новый максимум (с каждым более поздним). ∎

Проверено (`telescoping_ok`): совпадение на всех pi и всех a при
3 <= n <= 7, на 500 случайных pi при n = 8, 9 (все a).

### 3. Диагональные разрезы недостаточны (отрицательный результат)

Ограничение перебора до `a = b` (n разрезов вместо n^2) не достигает цели:
худшее (по всем pi) значение `min_a inv(a,a)` растёт быстрее `floor((n-1)^2/4)`:

| n | target `floor((n-1)^2/4)` | worst diagonal |
|---|---|---|
| 3 | 1 | 2 |
| 4 | 2 | 4 |
| 5 | 4 | 6 |
| 6 | 6 | 10 |
| 7 | 9 | 12 |

Худшие входы — отражения (те же, что для полного перебора).

### 4. «Лучшее a, затем среднее по b» недостаточно (отрицательный результат)

Для фиксированного a среднее по b от `inv(a,b)` равно `inv_usual(w_a) +
S(w_a)/n`, где `w_a(i) = pi((i+a) mod n)` (как обычная, не модулярная,
последовательность) и `S(w) = sum_i w(i)(2i-(n-1))`. Минимум этого среднего
по a также превышает цель на отражениях, с растущим разрывом:

| n | target | worst `min_a avg_b` |
|---|---|---|
| 3 | 1 | 5/3 |
| 4 | 2 | 7/2 |
| 5 | 4 | 6 |
| 6 | 6 | 55/6 |
| 7 | 9 | 13 |

Это уточняет и подтверждает наблюдение `docs/notes/h13_line_model.md` §6
(«усреднение по всем n^2 разрезам не работает») для более слабой (не
среднее по всем n^2, а среднее по b при оптимальном a) и потому более
опасной формы усреднения — тоже не работает, с количественным разрывом.

## Вывод

H13-I не доказана в этой сессии. Получены два новых точных тождества
(годны для будущей попытки: телескопирование даёт точную формулу изменения
`inv(a,b)` по b как «блуждание» с шагами `(n-1)-2p`, где p пробегает
перестановку 0..n-1 в порядке `pi^{-1}` со сдвигом -a mod n — минимум по b
при фиксированном a есть минимум частичной суммы этого блуждания; выбор a
переставляет шаги нетривиально из-за взятия по модулю n). Обе испробованные
простые редукции (диагональ, среднее по b при лучшем a) отвергнуты с
количественным разрывом, растущим с n на отражениях — сужают семейство
следующих кандидатов, но не дают самого доказательства.

## Следующий вопрос

По правилу принятой заранее развилки (`docs/notes/repo_state.md`,
`PLAN.md` §8): H13-I не закрыта за одну сессию — переход к индукции H3
(`PLAN.md` §4.3, пункт 3). Открытая зацепка для отдельной будущей попытки
H13-I: минимум по b при фиксированном a — это минимум частичной суммы
блуждания с фиксированным мультимножеством шагов `{n-1, n-3, ..., -(n-1)}`,
переставленных перестановкой `p(a, ·)`; связать выбор a (циклический сдвиг
значений p по модулю n, не перестановку их порядка) с получением
«отсортированного по возрастанию» порядка шагов на достаточно большом
префиксе — не проработано, бюджет для этого не выделялся.
