# H13-I, сессия 9 — совместная 2D локальная оптимальность разреза

## Цель

Проверить кандидатную лемму (усиление леммы C из `docs/notes/h13_line_model.md`
§4 в сторону «совместного сдвига», как предложено в задаче сессии 9): если
разрез `(q,c)` — локальный минимум сетки `inv(q,c)` при СОВМЕСТНЫХ сдвигах
обеих координат (не только по одной оси по отдельности, как в лемме C), то
`inv(q,c) <= floor((n-1)^2/4)`. Проверены две силы «локального минимума»:
4-соседи (по осям) и 8-соседей (по осям и диагоналям, т.е. учитывающие
одновременный сдвиг `(q,c) -> (q+-1, c+-1)`). Дополнительно измерено, на каком
торическом расстоянии от плохого локального минимума лежит настоящий
глобальный минимум `I(pi)` — чтобы понять, спасёт ли фиксированный радиус
поиска.

## Команда

```bash
gcc -O2 -o h13_local2d experiments/h13_local2d.c
for n in 4 5 6 7 8 9; do ./h13_local2d grid $n; done > data/runs/h13_local2d/grid_results.jsonl
for n in 4 5 6 7 8 9; do ./h13_local2d dist $n; done > data/runs/h13_local2d/dist_results.jsonl
```

## Параметры

- Диапазон: 4 <= n <= 9, исчерпывающе по всем n! перестановкам (без seed,
  полный перебор через `next_perm`).
- Версии: код `experiments/h13_local2d.c` (h13_local2d-1.0); ядро oracle-1.0
  не требуется (прямой подсчёт инверсий `w`, та же формула, что в
  `experiments/line_model.py` и `experiments/line_profile.c`).
- Тип покрытия: EXHAUSTIVE (все перестановки и все n^2 разрезов на
  перестановку) при 4 <= n <= 9.
- Проверенные состояния: все n! перестановок для каждого n; для каждой —
  вся сетка n^2 разрезов.

## Результат (grid: значения самого плохого локального минимума)

| n | bound=floor((n-1)^2/4) | 4-соседей: всего лок.мин / нарушений / худшее | 8-соседей: всего лок.мин / нарушений / худшее |
|---|---|---|---|
| 4 | 2  | 128 / 16 / 3      | 80 / 0 / 2        |
| 5 | 4  | 1200 / 225 / 6    | 775 / 0 / 4       |
| 6 | 6  | 7776 / 1692 / 10  | 3096 / 36 / 7     |
| 7 | 9  | 81144 / 16758 / 14 | 40278 / 1274 / 11 |
| 8 | 12 | 677376 / 147456 / 19 | 247296 / 7104 / 16 |
| 9 | 16 | 8330040 / 1765476 / 25 | 3765528 / 191646 / 22 |

4-соседняя локальная оптимальность нарушает границу уже при n = 4 (ожидаемо,
она слабее леммы C). 8-соседняя (учитывающая диагональные, т. е. совместные
сдвиги обеих координат на ±1) впервые нарушается при n = 6 и доля нарушений
растёт: 0, 0, 1.2%, 3.2%, 2.9%, 5.1% от числа локальных минимумов при n = 4..9,
а худшее значение растёт как минимум так же быстро, как сама граница
(избыток `worst - bound` = 0, 0, 1, 2, 4, 6 при n = 4..9).

Пример нарушения при n = 6: `pi = (0,2,1,3,5,4)`, разрез `(q,c)=(1,3)` —
8-соседний локальный минимум сетки со значением 7 > bound = 6; истинный
глобальный минимум `I(pi) = 3` достигается в `(q,c)=(0,0)` — торическое
расстояние 4 (см. ниже).

## Результат (dist: расстояние от плохого 8-соседнего локального минимума до истинного оптимума)

| n | нарушений | max L1-расстояние | среднее L1-расстояние |
|---|---|---|---|
| 4 | 0 | — | — |
| 5 | 0 | — | — |
| 6 | 36 | 4 | 4.000 |
| 7 | 1274 | 4 | 3.769 |
| 8 | 7104 | 7 | 4.802 |
| 9 | 191646 | 8 | 4.767 |

Максимальное расстояние растёт (4, 4, 7, 8 при n = 6..9), то есть плохой
2D-локальный минимум не находится в фиксированной окрестности истинного
глобального минимума: никакой фиксированный радиус поиска (для любой
константы r) не спасает аргумент «проверить локальный минимум радиуса r» —
уже при n = 9 нужен радиус >= 8 (растёт по крайней мере линейно по
имеющимся данным).

## Время и память

Меньше 6 секунд суммарно на всех n <= 9 (n = 9 — 3-5 c на каждый из двух
режимов), однопоточно, без существенной памяти (сетка n x n int).

## Вывод

Кандидатная лемма (совместная 2D локальная оптимальность разреза достаточна
для `inv <= floor((n-1)^2/4)`) — REFUTED уже 4-соседним вариантом (n=4) и,
что важнее, 8-соседним вариантом, учитывающим ОДНОВРЕМЕННЫЕ сдвиги обеих
координат (n=6, растущая доля нарушений). Это прямое расширение леммы C
(«вопрос -> кандидат -> оценка -> трудные входы» из AGENTS.md): лемма C
показывала недостаточность независимой (по одной оси) локальной
оптимальности; этот эксперимент показывает, что даже строго совместная
локальная оптимальность радиуса 1 (все 8 соседей сразу) недостаточна, и что
нужный «радиус исправления» растёт с n, а не ограничен константой. Значит,
искать доказательство H13-I через любой локальный (в смысле окрестности
фиксированного радиуса в решётке разрезов) аргумент бесперспективно; нужна
существенно нелокальная конструкция.
