# h13i_avgq — H13-I averaging reformulation (session 9, 14.09.2026)

## Цель

Доказать или опровергнуть H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi
из S_n, все n >= 4), задача сессии из `docs/notes/repo_state.md`
("следующая задача"). Проверить три кандидатных подхода из
`docs/notes/h13_line_model.md` §6.

## Команда, версии, параметры

```
gcc -O2 -Wall -o experiments/h13i_avgq experiments/h13i_avgq.c
./experiments/h13i_avgq exhaustive N     # N = 3..10
./experiments/h13i_avgq sample N 300     # N = 15,20,30,50,80,120,200,300
```

Ядро oracle-1.0 не используется (чисто комбинаторный подсчёт инверсий, без
симуляции ходов). Код: `experiments/h13i_avgq.c` (h13i_avgq-1.0). Seed для
случайных перестановок зашит в коде (20260913), детерминированно.
Покрытие: n = 3..10 — исчерпывающе (все n!); n = 15..300 — структурные
семейства (id, rev_n и его сдвиги по значению, `pi(i)=a*i+b mod n` для всех
взаимно простых с n значений a < 14 и нескольких b) плюс 300 случайных
перестановок на n. Время: n = 10 исчерпывающе — 6.4 с; каждый sample-прогон
— доли секунды. Память: O(n).

## Результат

Полный вывод — `output.txt`. Проверена гипотеза (avg):
`sum_{q=0}^{n-1} m(q) <= n * floor((n-1)^2/4)`, где
`m(q) = min_c inv(rotate(pi,q), c)`. Нарушений не найдено ни разу; во всех
исчерпывающих прогонах (n = 3..10) и на семействах (n = 15..300) точное
равенство достигается ровно на sigma_n и его сдвигах по значению
(экстремальные входы — те же, что и для C24/C28/C31/C32/C33). Отдельно
проверены и REFUTED два более простых подхода к H13-I:

- (а) минимум только по c при фиксированном q = 0 (натуральный порядок
  позиций): недостаточен уже при n = 7 (`pi = (0,5,4,3,2,1,6)`,
  `min_c inv = 10 > floor(36/4) = 9`) и n = 8
  (`pi = (0,6,5,3,4,2,1,7)`, `13 > 12`); на n = 4..6 совпадает с границей.
- (b) триангулярная свобода дискордантного графа в оптимальном (q,c):
  REFUTED при n = 5 на самой `rev_5 = (4,3,2,1,0)` — ни один из достигающих
  минимум (q,c) не даёт граф без треугольников (полный перебор всех (q,c)
  с этим минимумом).
- Явные (не минимизирующие) правила c(q) — `c(q)=pi(q)`, `c(q)=pi^{-1}(q)` —
  дают суммы, кратно превышающие `n*floor((n-1)^2/4)` уже при n = 4.

## Вывод и следующий вопрос

H13-I не доказана и не опровергнута. Найдена более узкая переформулировка
(avg, регистрационная строка C37), которая по всем конечным данным верна
и влечёт H13-I по принципу Дирихле, и для которой доступна точная рекурсия
`inv_q(c+1) - inv_q(c) = n-1-2 pos_q(c)` (см. `docs/notes/h13_line_model.md`
§6в) — более удобная отправная точка для доказательства, чем исходная
торическая формулировка. Следующий вопрос (бюджет 1 сессия): доказать
(avg) через эту рекурсию (кандидаты — п. 1–3 `h13_line_model.md` §7);
если не удастся — переход к индукции H3 (PLAN §4.3), как и планировалось
после сессии 8.
