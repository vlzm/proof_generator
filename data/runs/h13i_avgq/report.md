# h13i_avgq — averaged route to H13-I (сессия 9)

Цель: искать доказуемую редукцию H13-I (`I(pi) = min_{q,c} inv(w) <=
floor((n-1)^2/4)` для всех pi, см. `docs/notes/h13_line_model.md` §6) через
усреднение только по одному из двух параметров разреза, раз усреднение по
обоим (`(q, c)` вместе, n^2 клеток) уже отвергнуто (заметка §5, "среднее по
всем n^2 разрезам не работает").

Обозначения из §0 заметки: `v^{(q)}_j = pi[(q+1+j) mod n]` (поворот позиций),
`shift_c(v)_j = (v_j - c) mod n` (поворот значений), `M(q) = min_c
inv(shift_c(v^{(q)}))`, `I(pi) = min_q M(q)`.

## Ключевое тождество (используется в коде, не публиковалось ранее)

Для фиксированного `v` и `p = v^{-1}` (`p_c` — позиция значения `c` в `v`):
`inv(shift_{c+1}(v)) - inv(shift_c(v)) = (n - 1) - 2 p_c`. Причина: переход от
сдвига `c` к `c+1` уменьшает все значения на 1 по модулю n; относительный
порядок всех пар, не содержащих элемент со значением (после сдвига `c`)
равным 0, не меняется, а этот элемент (стоящий на позиции `p_c`) переходит
с ранга 0 (меньше всех) на ранг n-1 (больше всех), меняя число инверсий с ним
с `p_c` (был меньше всех правых от него) на `n - 1 - p_c` (стал больше всех).
Отсюда `M(q) = inv(v^{(q)}) + min_{0<=c<=n-1} S_c`, `S_0 = 0`, `S_c =
sum_{j<c} ((n-1) - 2 p_j)` — вычисление `M(q)` за O(n^2) вместо O(n^3)
(перебора c с пересчётом инверсий заново).

## Два эксперимента

1. **avgq** — гипотеза H13-I-avg: `avg_q M(q) <= floor((n-1)^2/4)` для всех
   pi. Влечёт H13-I напрямую: `min_q M(q) <= avg_q M(q) <=
   floor((n-1)^2/4)` (минимум конечного набора не больше среднего).
2. **singleq** — контроль: `M(0)` один (варьируется только c, разрез позиций
   фиксирован в q=0) — проверяет, не достаточно ли усреднять/выбирать один c
   без выбора q вовсе.

Версия: h13i_avgq-1.0 (`experiments/h13i_avgq.c`, C, O2). Ядро не используется
напрямую (комбинаторное утверждение о перестановках, не о ходах). Команда:
`gcc -O2 -o h13i_avgq experiments/h13i_avgq.c && ./h13i_avgq n avgq` (и
`singleq`). Покрытие: исчерпывающее по всем n! перестановкам и всем n
значениям q (avgq) или просто n значениям c (singleq), в порядке следующей
перестановки (lexicographic next_perm), без выборки. Время: avgq n=10 — 6.1 с,
n=11 — 85 с (39 916 800 перестановок); singleq — секунды при всех n <= 10.
Память: O(1) на перестановку (посчитано инкрементально), без хранения таблиц.

1. **H13-I-avg VERIFIED 3 <= n <= 11 (исчерпывающе, все n! перестановок,
   ноль нарушений)**: `avg_q M(q) = floor((n-1)^2/4)` ровно в максимуме,
   без запаса — граница тесна на каждом n. Максимум достигается (как минимум)
   на перестановке `rev_n(i) = n-1-i` (полное обращение) — она лексикографически
   последняя, отсюда `argmax_rank = n! - 1` на каждом n; торический класс
   этой pi (все повороты позиций/значений, включая `(0, n-1, n-2, ..., 1)`)
   даёт то же значение, так как `avg_q M(q)` — инвариант торического класса.
2. **singleq (контроль) REFUTED уже при n = 7**: `max_pi M(0) = 10 > 9`
   (7 перестановок-нарушителей), нарушения растут — 16, 162, 1250 при
   n = 8, 9, 10 (доля растёт: 0.14 %, 0.39 %, 1.4 %, 3.4 % от n! при
   n = 7..10). Значит одной оптимизации по c (без выбора q) недостаточно;
   доказательство H13-I-avg обязано использовать усреднение/минимум по обоим
   параметрам, а не сводиться к фиксированному разрезу позиций.

## Вывод и следующий шаг

H13-I-avg — новая, более сильная (усреднение только по q, минимум по c
остаётся) и чисто по данным ТОЧНАЯ переформулировка H13-I; если она доказана
в общем виде, H13-I следует немедленно неравенством "минимум <= среднее".
Доказательство не завершено в этой сессии: тождество для `M(q)` (раздел выше)
сводит задачу к оценке `sum_q [inv(v^{(q)}) + min_c S_c(q)] <= n *
floor((n-1)^2/4)`, где первое слагаемое имеет замкнутую форму через попарные
вклады: `sum_q inv(v^{(q)}) = sum_{i1<i2} ((n-d) если pi(i1)>pi(i2) иначе d)`,
`d = i2-i1` — VERIFIED исчерпывающе 2 <= n <= 8
(`experiments/h13i_avgq_pairwise_check.py`, `data/runs/h13i_avgq/pairwise_check.log`);
второе слагаемое — блуждание с шагами `(n-1)-2p_j`, возвращающееся в 0 за n
шагов (структура типа леммы о цикле Дворецкого—Мотцкина), и как оно ведёт
себя при суммировании по q — не выведено. H13-I осталась CONJECTURED (не
PROVED) в этой сессии, но сужена до H13-I-avg — предложена как следующая
задача (см. PLAN §8, заметку `docs/notes/h13_line_model.md` §6).
