# line_model — линейная модель с одним разрезом (H13, C33)

Цель: проверить, нужен ли обход по кругу для диаметра. Для pi, ребра разреза
{q, q+1} и сдвига c слово живёт на линии позиций q+1..q+n: голова не переходит
и не обменивает через разрез. `d_line(pi) = min_{q,c}` длины кратчайшего такого
слова; `I(pi) = min_{q,c}` числа инверсий переразмеченной линии (нижняя оценка
N_X в линейной модели). Всегда `d_line >= d`.

Версии: line_model-1.0, ядро oracle-1.0, таблицы C2v. Метод: BFS линейного
графа (состояния — расстановка на линии × положение головы 0..n−1; ходы
±1 внутри линии, обмен при голове < n−1) из (id, голова j1) для всех j1,
затем для каждой pi перебор всех (q, c) — исчерпывающе. Память < 100 МБ.
Команды: `python3 experiments/line_model.py --nmax 8`,
`python3 experiments/line_model.py --nmin 9 --nmax 9`. Журнал `report.log`,
json `report_n4_<n>.json`, `report_n9_9.json`.

Вывод (4 <= n <= 9, исчерпывающе): максимум `d_line` равен B_n и достигается
только на sigma_n; максимум минимума инверсий равен `floor((n − 1)^2/4)`
(достигается на rev_n = pi_{n−1}); обход по кругу не нужен для диаметра
в этом диапазоне (H13 подтверждена конечно, C33). Доля входов с `d_line = d`
падает: 100, 95, 97, 87, 89, 77 %; разрыв `d_line − d` растёт до 6 при n = 9 —
на таких входах обход через разрез экономит, но не на максимальном слое.
Это поиск ошибок, не доказательство. Следующий вопрос — PLAN §8 (H13):
доказуемая схема слова для линии с inv инверсиями.

## Версия 1.1 (сессия 8): модель «обход разреза»

`d_walk(pi; q, c)`: голова может переходить через разрез (ходы ±1 mod n), но
не обменивает через него; `d <= d_walk <= d_line`. Разрыв `d_line − d`
раскладывается на экономию от обхода головой (`d_line − d_walk`) и экономию от
обменов через разрез (`d_walk − d`). Команды: `python3 experiments/line_model.py
--nmax 8 --walk`, `--nmin 9 --nmax 9 --walk` (1174 с). Выход
`report_n4_<n>_walk.json`, `report_n8_8_walk.json`, `report_n9_9_walk.json`
(совместные гистограммы, в том числе по I(pi) и по d).

Вывод: при n <= 7 весь разрыв — обход головой (некоторая геодезическая никогда
не обменивает через некоторое ребро); при n = 8, 9 появляются входы, где любая
геодезическая при любом разрезе обменивает через все рёбра (аффинные и близкие
к ним, I от 9 до 14 при n = 9). На слое `d = B_n` и `B_n − 1` таких нет
(`d_line = d` при I >= 15, n = 9).
