# line_model — линейная модель с одним разрезом (H13, C33)

Цель: проверить, нужен ли обход по кругу для диаметра. Для pi, ребра разреза
{q, q+1} и сдвига c слово живёт на линии позиций q+1..q+n: голова не переходит
и не обменивает через разрез. `d_line(pi) = min_{q,c}` длины кратчайшего такого
слова; `I(pi) = min_{q,c}` числа инверсий переразмеченной линии (нижняя оценка
N_X в линейной модели). Всегда `d_line >= d`.

Версии: line_model-1.0, ядро oracle-1.0, таблицы C2v. Метод: BFS линейного
графа (состояния — расстановка на линии × положение головы 0..n−1; ходы
±1 внутри линии, обмен при голове < n−1) из (id, голова j1) для всех j1,
затем для каждой pi перебор всех (q, c) — исчерпывающе. Память < 100 МБ.
Команды: `python3 experiments/line_model.py --nmax 8`,
`python3 experiments/line_model.py --nmin 9 --nmax 9`. Журнал `report.log`,
json `report_n4_<n>.json`, `report_n9_9.json`.
