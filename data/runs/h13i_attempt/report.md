# H13-I attempt — session 9 (2026-09-17)

Задача: `docs/notes/repo_state.md` "Следующая задача" (13.09.2026, сессия 8) —
доказать H13-I: `I(pi) = min_{q,c} inv(w) <= floor((n-1)^2/4)` для всех pi
(торические классы), бюджет 1 сессия до письменного вердикта.

Код: `experiments/h13i_attempt.py` (h13i_attempt-1.0). Ядро не задействовано
напрямую (чисто комбинаторная задача о перестановках), формула `I(pi)`
взята из `docs/notes/h13_line_model.md` §0 (совпадает с C33).

Результат сессии: **H13-I не доказана и не опровергнута**. Найдена новая
точная переформулировка (XOR по парам точек) и два новых отрицательных
результата, сужающих пространство возможных доказательств; численная
проверка расширена до n = 50 (SAMPLED). Подробный разбор — `docs/notes/h13i_attempt.md`.

## 1. Переформулировка через XOR (verify-xor)

```
$ python3 experiments/h13i_attempt.py --verify-xor --nmax 6
verify_xor: nmax=6 checked=29366 all_match=True
elapsed: 0.2s
```

Лог: `verify_xor.log`. Проверено: для каждой pi при 2 <= n <= 6 и каждого из
n^2 разрезов (q, c) значение `inv(w)`, посчитанное напрямую по определению
(`inv_count` на явно построенной линии), совпадает с суммой по всем C(n,2)
парам точек `(i, pi(i))` одного бита `X_pair(q) XOR Y_pair(shift)`, где
`X_pair(q) = 1` iff позиционный разрез `q` лежит на дуге длины
`d = (i2-i1) mod n` (вперёд от i1 к i2), `Y_pair(shift)` — симметрично для
значений (дуга длины `e = (v2-v1) mod n`). Формула и её вывод —
`docs/notes/h13i_attempt.md` §1; это точная формализация «одноимённых
квадрантов» из `docs/notes/h13_line_model.md` §6.

Лог: `single_axis.log`. Вращение только значений при фиксированном (исходном)
порядке позиций (n разрезов, не n^2) не достигает цели уже при n = 7
(`pi = (0,5,4,3,2,1,6)`: минимум по n сдвигам значений равен 10 > 9). По
симметрии позиции/значения (замена ролей i <-> pi(i)) вращение только позиций
при фиксированных значениях так же недостаточно. Вывод: обе степени свободы
(q и c) необходимы одновременно; свести перебор n^2 к перебору n нельзя.

```
6 6 6 (0, 4, 3, 2, 1, 5) 154

```

Лог: `greedy.log`. Стратегия «выбрать q, минимизирующий `inv(x_q)`, затем
лучший c для этого q» расходится с истинным `I(pi)` уже на 3 входах при
n = 5 и даёт `worst = 10 > 9` при n = 7 — независимое (от леммы C
`h13_line_model.md` §4) подтверждение, что локально оптимальный выбор одной
координаты разреза не определяет глобально хороший разрез по обеим сразу.

Лог: `structured.log`. Для каждого n: все n отражений (исчерпывающе по h);
аффинные `pi(i) = a*i+b` для всех a, взаимно простых с n, и b с шагом

12345). `I(pi)` считается точно (все n^2 разрезов, `inv_count_fast` —
Fenwick-дерево, O(n log n) на разрез). Во всех случаях `I(pi) <=
floor((n-1)^2/4)`, с точным равенством на отражениях при каждом проверенном
n (согласуется с VERIFIED-диапазоном 4 <= n <= 10 из `line_profile.c`, C33).
Это SAMPLED, не VERIFIED: не исчерпывающе по всем pi при n >= 11, но
расширяет диапазон структурных семейств (отражения, аффинные, случайные) с
n <= 12 (`affine_family.py`, прежние сессии) до n = 50 без единого нарушения.
