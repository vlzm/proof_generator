# H13-I: попытка доказательства и расширенная проверка (сессия 9, 14.09.2026)

## Цель

Задача сессии (PLAN §8, `docs/notes/h13_line_model.md` §6): доказать
H13-I — `I(pi) = min_{a,b} f(a,b) <= floor((n-1)^2/4)` для всех pi из S_n
(`f(a,b)` — число инверсий линии после двойного разреза, см.
`docs/proofs/C37_cut_inversion_formula.md` §0), бюджет 1 сессия до
письменного вердикта.

## Что сделано

1. **Замкнутая форма (C37, PROVED)**: точные приращения `f(a+1,b)-f(a,b)`
   и `f(a,b+1)-f(a,b)` (леммы 1) и явная формула `f(a,b) = inv(pi) +
   (n-1)(a+b) + 2ab - 2P(a) - 2R(b) - 2n K(a,b)` (лемма 2) —
   `docs/proofs/C37_cut_inversion_formula.md`. Даёт алгоритм `O(n^2)` на pi
   вместо `O(n^4)` у `line_profile.c`. Независимая проверка —
   `checks/check_C37.py` (PASS): часть A/B — леммы против прямого перебора
   на случайных pi при 2 <= n <= 9 (7128 троек `(pi,a,b)`); часть C —
   `O(n^2)`-минимум против `O(n^4)`-минимума на всех pi при 4 <= n <= 9 и
   против ранее сертифицированных `max_pi I` из
   `data/runs/line_profile/profile_n{n}.json` — совпадение точное.
2. **Три эвристики выбора (a,b) проверены и отвергнуты** (не повторять):
   H1 «a = 0 фиксировано, минимум по b» — нарушает границу уже при n = 7
   (худший случай 10 > 9 = floor(6^2/4)); H2 «жадный двухшаговый» (сперва
   a*, минимизирующее f(a,0), затем минимум по b при этом a*) — тоже
   нарушает при n = 7 (10 > 9); H3 «канонический сдвиг b = pi(a)» (начало
   координат — в самой точке перестановочной матрицы) — не работает уже при
   n = 4 (3 > 2) и растёт как C(n,2) (эквивалентно отсутствию разреза).
   Данные и свидетели — `experiments/h13i_heuristics.py`,
   `data/runs/h13i_heuristics/report.md`.
3. **Попытка прямого доказательства** (замкнутая форма, «дискрепансия»
   `D(a,b) = K(a,b) - ab/n`, индукция удалением точки, связь с
   Grassmann-перестановками/аффинной группой Вейля) — см. §7 в
   `docs/notes/h13_line_model.md` (не завершена за бюджет сессии).
4. **Расширенная проверка** (`experiments/torus_cut.c`, режимы
   `exhaustive`/`family`/`search`):
   - Исчерпывающе 4 <= n <= 12 (НОВОЕ; было 4 <= n <= 10): максимум
     `I(pi)` по всем n! перестановкам равен ровно `floor((n-1)^2/4)` —
     `exhaustive_log.txt`.
   - n = 13: исчерпывающая проверка запущена (6 227 020 800 перестановок,
     алгоритм Хипа, тот же алгоритм O(n^2), что и в `torus_cut.c`,
     перепроверенный на n <= 9 против `torus_cut.c` побайтово одинаковыми
     результатами) — см. «Статус» ниже.
   - Структурные семейства при n = 20, 50, 100, 101, 200, 500, 1000:
     отражения (максимум точно `floor((n-1)^2/4)` при всех n),
     аффинное семейство `pi(i) = a i + b mod n` (перебор всех обратимых a,
     сетка b) — максимум всегда достигается на `a = n-1`, то есть на самой
     же отражательной подсемье, и не превосходит границу; случайные выборки
     (200–2000 перестановок) — `family_log.txt`.
   - Симуляция отжига (максимизация `I(pi)`, транспозиции и развороты
     отрезков, цель — опровергнуть гипотезу) при n = 13..300 — нарушений не
     найдено (лучшие найденные значения — 85–95% от границы на больших n,
     ограничение метода поиска, а не свидетельство о более низком истинном
     максимуме: на n <= 20 отжиг находит именно отражения) —
     `search_log.txt`.

успел завершиться до конца сессии).

## Вывод

H13-I не доказана и не опровергнута за бюджет сессии. Новое: замкнутая
форма (инструмент для дальнейших попыток и практический ускоритель
проверок в 4-6 раз выше по n при тех же ресурсах — n <= 12 вместо n <= 10
исчерпывающе, до n = 1000 структурно), три конкретно проверенные и
отвергнутые эвристики, расширенное вычислительное подтверждение без единого
контрпримера. Решение по плану (`docs/notes/h13_line_model.md` §6, PLAN §8):
без доказательства H13-I за сессию — переход к индукции H3 (PLAN §4.3).

```
gcc -O3 -o experiments/torus_cut experiments/torus_cut.c -lm
./experiments/torus_cut exhaustive 12          # ~140 с, память O(n)
./experiments/torus_cut family 1000            # ~секунды
./experiments/torus_cut search 100 30000 4 1   # ~1-2 с
python3 checks/check_C37.py --trials 300 --nmax 9
python3 experiments/h13i_heuristics.py --nmax 8
```

Ядро: не задействовано (чистая комбинаторика перестановок, без oracle/moves).
Версии: `torus_cut-1.0`, `check_C37-1.0`, `h13i_heuristics-1.0`.
Оборудование: без GPU, один процесс на ядро (за исключением фоновых
запусков n = 12/13, которые не пересекались по времени с интерактивной
работой).
