## Результат 1 (PROVED, элементарно): независимость разрезов по позициям и по значениям

Двойной разрез (q, c) в определении N1/line_model эквивалентен паре
(q, v0), где `v0 = (q − c) mod n` — разрез по значениям (номер разреза
линии значений). Так как при фиксированном q сдвиг c пробегает весь Z_n,
v0 тоже пробегает весь Z_n, и соответствие (q, c) <-> (q, v0) биективно;
значит (q, v0) пробегает все n^2 пар независимо. Для пары точек
P = (i, pi(i)), P' = (j, pi(j)), i < j, с d1 = j − i, d2 = (pi(j) − pi(i))
mod n (оба в {1, ..., n−1}), число разрезов (q, v0), на которых пара
инвертирована, равно `n(d1+d2) − 2 d1 d2`, и не зависит от других пар.
Формула сверена с прямым подсчётом (перебор всех pi, всех пар, всех n^2
разрезов) при 4 <= n <= 7 — совпадение без исключений. Эта независимость
уже неявно используется в line_profile.c (двойной цикл по q и c), но явно
как лемма не была зафиксирована; сама по себе она недостаточна для H13-I
(см. ниже) — усреднение по всем n^2 разрезам не даёт нужной оценки
(подтверждено ранее в h13_line_model.md §6 и здесь заново: максимум
среднего числа инверсий по всем n^2 разрезам равен 3.5, 6.0, 9.17, 13.0 при
n = 4..7 против границы 2, 4, 6, 9 — среднее хуже границы, а не лучше).

## Результат 2 (REFUTED): две урезанные до n кандидатов схемы разреза

Гипотеза: не нужен полный перебор n^2 разрезов — n кандидатов достаточно.
Проверены две естественные схемы.

(a) «Старт со значения 0»: для каждого q взять v0 = pi(q+1) (голова линии
видит первым значение 0). Максимум минимума по кандидатам над всеми pi:
2+1, 4+2, 6+4, 9+6, 12+9 (n = 4..8) — избыток растёт быстрее n (похоже на
floor(n(n-1)/2 − 2 floor(n/2)floor((n+1)/2)+...) — не оценивалось отдельно,
достаточно, что избыток растёт). Худшие входы — обращения (rev_n со
сдвигом): (0,3,2,1), (0,4,3,2,1), (0,5,4,3,2,1), ... Схема отвергнута.

(b) «Только разрез значений» (фиксируем q = 0, то есть читаем pi в
исходном порядке индексов, перебираем только n сдвигов v0): максимум
минимума над всеми pi (`experiments/h13i_value_rotation_only.c`):

| n | bound = floor((n-1)^2/4) | max по всем pi | избыток | худший вход |
|---|---|---|---|---|
| 4 | 2 | 2 | 0 | (0,2,3,1) |
| 5 | 4 | 4 | 0 | (0,2,4,3,1) |
| 6 | 6 | 6 | 0 | (0,2,4,5,3,1) |
| 7 | 9 | 10 | 1 | (0,5,4,3,2,1,6) |
| 8 | 12 | 13 | 1 | (0,6,5,3,4,2,1,7) |
| 9 | 16 | 17 | 1 | (0,2,7,6,5,4,3,8,1) |
| 10 | 20 | 23 | 3 | (0,8,6,5,4,3,2,1,9,7) |

Избыток не убывает и не стабилизируется на +1 (скачок к +3 при n = 10):
схема тоже отвергнута как путь к H13-I. Гипотеза «одной свободы по
значениям хватает с точностью O(1), а разрез по позициям лишь гасит
остаток +1» не подтвердилась — по крайней мере не в этой простой форме.

## Вердикт

H13-I за сессию не доказана и не опровергнута (полный перебор `I(pi) <=
floor((n-1)^2/4)` остаётся VERIFIED только при 4 <= n <= 10, как и раньше,
C33/C35, `experiments/line_profile.c` — здесь не повторялся, запрет
repo_state.md на BFS линейной модели при n >= 10 не затронут: обе новые
программы — не BFS, а прямой перебор pi без построения графа состояний).
Независимость разрезов (результат 1) — единственный новый факт, PROVED
для всех n; полезен как стартовая точка, но сам по себе не закрывает
задачу: обе естественные урезанные схемы (результат 2) отвергнуты
конкретными контрпримерами, а полное усреднение по n^2 разрезам отвергнуто
раньше (h13_line_model.md §6). Бюджет 1 сессии (repo_state.md) исчерпан.
Следующий шаг по документированному плану (h13_line_model.md §6, PLAN
§4.3, п. 3) — индукция H3, бюджет 2 сессии; не начата в этой сессии.
