# h13i_attempt — попытка доказать H13-I (сессия 9)

Дата: 17.09.2026. Ядро `oracle-1.0`. Код: `experiments/h13i_attempt.py`
(h13i_attempt-1.0). Полный лог: `report.log`; каждый вызов скрипта
перезаписывает `report.json` (см. агрегированные числа ниже — они собраны
вручную из `report.log`, отдельные `report.json` не сохраняют историю
запусков).

Цель: до попытки доказательства H13-I (`I(pi) <= floor((n-1)^2/4)` для всех
pi, PLAN §8, `docs/notes/h13_line_model.md` §6) проверить кандидатные подходы
из задания сессии — (a) совместный сдвиг обоих разрезов, (b) устойчивость
экстремальности отражений (компрессия/локальные ходы), (c) сверка с
найденной литературой — вычислительно на малых n, прежде чем формулировать
доказательство.

Команды и покрытие:

```text
python3 experiments/h13i_attempt.py --nmin 4 --nmax 7 --affine-nmax 16
python3 experiments/h13i_attempt.py --nmin 8 --nmax 8 --only diagonal
python3 experiments/h13i_attempt.py --nmin 8 --nmax 8 --only circtransp
python3 experiments/h13i_attempt.py --nmin 9 --nmax 9 --only diagonal
python3 experiments/h13i_attempt.py --nmin 9 --nmax 9 --only circtransp
```

Покрытие: пп. 1–2 (тождество, рекурренты) и п. 3 (компрессия) —
исчерпывающе 4 <= n <= 7 (дорогая часть, по правилу 9 начата с 4..7);
п. 4 (диагональ) и п. 6 (circtransp) — исчерпывающе 4 <= n <= 9; п. 5
(аффинное семейство) — структурированное семейство (n-1 значений a на
каждое n, не полный перебор), 4 <= n <= 16, разрешено правилом 9 сверх
лестницы n <= 10. Время: суммарно около 152 c (основной вклад — BFS
`circtransp` при n = 9, 127 c).

## Результаты

1. **Тождество «квадрантов»** (`--pairsum`): для пары {i,k} с циклическими
   разрывами `d = (k-i) mod n`, `e = (pi[k]-pi[i]) mod n`, число разрезов
   (r0,c0) из n^2, на которых пара дискордантна, равно `n*d + n*e - 2*d*e`;
   просуммировано по всем парам — совпадает с прямой суммой `inv(r0,c0)` по
   всей сетке n^2 разрезов, на id/sigma_n/rev_n/случайных pi, 4 <= n <= 7.
   Подтверждает переформулировку через «одноимённые квадранты» (задание,
   пункт (b)), но само по себе не даёт минимума (только сумму/среднее по
   n^2 разрезам — а среднее уже отвергнуто в `h13_line_model.md` §6).
2. **Рекурренты по одной координате** (`--recurrence`, кандидат (a)):
   `inv(r0+1,c0) - inv(r0,c0) = n-1-2x`, `x=(pi[r0]-c0) mod n`;
   `inv(r0,c0+1) - inv(r0,c0) = n-1-2p`, `p=(pi^{-1}(c0)-r0) mod n`.
   Проверено на случайных pi для всех (r0,c0), 4 <= n <= 7, 0 расхождений.
   Формулы корректны, но попытка построить прямое доказательство через
   телескопирование обеих рекуррент вместе не довела до оценки: смешанный
   шаг (r0,c0) -> (r0+1,c0+1) даёт `delta = 2(n-1) - 2*w_0 - 2*((z-1) mod n)`
   (w_0 — значение в начале строки, z — позиция значения 0), что зависит от
   двух независимых характеристик разреза и не сворачивается в замкнутую
   форму без дополнительной идеи.
3. **Компрессия / локальные максимумы** (`--compress`, кандидат (b)
   в форме «отражения — единственный локальный максимум»): под соседними
   транспозициями позиций (`pos-swap`) и значений (`val-swap`)
   отражения — не единственные локальные максимумы I(pi): 10, 120, 224
   не-отражения являются локальными максимумами при n = 5, 6, 7
   соответственно (все с I < bound). Значит простая компрессия/поднятие по
   соседним транспозициям не может служить доказательством того, что
   максимум достигается только на отражениях — ландшафт I(pi) имеет много
   локальных максимумов. VERIFIED 4 <= n <= 7 (исчерпывающе).
4. **n «диагональных» разрезов недостаточно** (`--diagonal`): ограничение
   на n разрезов вида `c0 = pi(r0)` (голова стартует прямо в точке данных)
   уже не достигает границы `floor((n-1)^2/4)` на 4/24, 5/120, 6/720,
   56/5040, 552/40320, 2025/362880 перестановках (n = 4..9); худший случай —
   `rev_n` с одной неподвижной точкой (`(0, n-1, n-2, ..., 1)`). Значит
   полная свобода по обеим координатам (n^2, а не n разрезов) существенна
   уже при n = 4. VERIFIED 4 <= n <= 9 (исчерпывающе).
5. **Аффинное семейство** `pi(i) = a*i mod n`, gcd(a,n)=1 (`--affine`,
   структурированное семейство, не полный перебор): `max_a I(pi_a) =
   floor((n-1)^2/4)`, достигается ровно при `a = n-1` (отражение
   `pi(i) = -i`, уже доказано C32/C33) — при всех остальных a строго
   меньше. VERIFIED (структурированно, не исчерпывающе по всем pi)
   4 <= n <= 16. Не продвигает общее доказательство (аффинные — лишь n-1
   из n! перестановок), но подтверждает: среди аффинных экстремум только
   у отражения, без исключений, при n значительно больше 10.
6. **Сверка с найденной литературой** (`--circtransp`, пункт (c) задания):
   поиск нашёл (аннотации, не полный текст — см. ниже) van Zuylen,
   Bieron, Schalekamp, Yu, «A tight upper bound on the number of cyclically
   adjacent transpositions to sort a permutation», IPL 2016 / arXiv:1402.4867
   (диаметр графа Кэли с образующими — n соседних транспозиций окружности —
   равен ровно `floor(n^2/4)`) и Even-Zohar, «The Writhe of Permutations and
   Random Framed Knots», RSA 2017 / arXiv:1511.09469 (writhe перестановки,
   инвариантный к вращению круга; по аннотации — граница `(N-1)^2/4` для
   `pi(x) = N-x`). Прямой доступ к первоисточникам заблокирован песочницей
   (egress policy блокирует arxiv.org и onlinelibrary.wiley.com), поэтому
   точные определения проверить не удалось. Проверено то, что можно
   проверить вычислительно: диаметр графа «n соседних транспозиций
   окружности, включая транспозицию (n-1,0)» (BFS от id) равен ровно
   `floor(n^2/4)` при 4 <= n <= 9 (совпадает с формулой из аннотации первой
   статьи) — но эта величина НЕ равна ни I(pi) (двойной разрез), ни
   I_single(pi) (разрез только по позициям, без сдвига значений) почти
   нигде: расхождений 17/24 .. 281255/362880 (n = 4..9). Значит это другая
   величина (другая метрика на S_n, с иным набором образующих), она не
   совпадает с нашим I(pi), и её граница (`floor(n^2/4)`, не
   `floor((n-1)^2/4)`) относится к другой задаче — эта нить литературы НЕ
   даёт готового доказательства H13-I и не зарегистрирована как источник
   утверждения (правило 11: только проверенные формулировки).

## Итог

Ни один из трёх кандидатов сессии (совместный сдвиг, компрессия/
устойчивость экстремума отражений, литература) не довёл до доказательства
H13-I за бюджет сессии. Пункты 1–2 дают проверенные тождества, полезные для
будущей попытки; пп. 3–4 — отрицательные результаты (не работает);
п. 5 — подтверждающие (но не продвигающие) данные; п. 6 — literature lead
проверен и признан нерелевантным (другая метрика). Вердикт —
`docs/notes/h13_line_model.md` §7.
