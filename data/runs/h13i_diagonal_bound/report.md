# Отчёт: H13-I-diag (попытка доказать H13-I, сессия 9)

Цель. Доказать H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi, n >= 4;
`docs/notes/h13_line_model.md` §6) или дать честный вердикт за 1 сессию.
Найдена редукция к более узкой числовой гипотезе H13-I-diag (см. ниже) —
цель прогона: проверить её на максимально доступном покрытии, а также
проверить (и, где нужно, опровергнуть) две более слабые версии рассуждения.

Команда и параметры:

```text
python3 experiments/h13i_diagonal_bound.py --identity  --nmin 4 --nmax 7
python3 experiments/h13i_diagonal_bound.py --heuristic --nmin 4 --nmax 8
python3 experiments/h13i_diagonal_bound.py --raw       --sizes 7,8,20
python3 experiments/h13i_diagonal_bound.py --exhaustive --nmin 4 --nmax 8
python3 experiments/h13i_diagonal_bound.py --exhaustive --nmin 9 --nmax 10
python3 experiments/h13i_diagonal_bound.py --sample    --sizes 20,50,100,101,200
```

Seed: `--sample` использует `random.Random(42)` (фиксирован в коде). Версии:
код `experiments/h13i_diagonal_bound.py` (h13i_diagonal_bound-1.0), ядро
oracle-1.0 не требуется (эксперимент — чистая комбинаторика над
перестановками, без ходов графа).

Тип покрытия:

- `--exhaustive`, 4 <= n <= 10: ПОЛНЫЙ перебор всех n! перестановок; для
  4 <= n <= 7 каждое значение `min_k R(u^(k))` дополнительно сверено ассертом
  с прямым перебором всех n^2 разрезов (`I_pi_bruteforce`) — 0 расхождений.
- `--identity`, 4 <= n <= 7: полный перебор, проверка тождества леммы D на
  каждой перестановке и каждом t = 0..n.
- `--heuristic`, 4 <= n <= 8: полный перебор, явное (не минимизирующее)
  правило разреза вместо истинного минимума.
- `--raw`, n = 7, 8, 20: одна перестановка на n (sigma_n), не перебор.
- `--sample`, n = 20, 50, 100, 101, 200: 8 перестановок на каждое n
  (sigma_n, отражение h=0, rev_n, id_n, один аффинный вход, три случайных)
  — структурная/случайная выборка, не перебор (AGENTS.md правило 9).

Число проверенных состояний: сумма n! по n = 4..10 = 24 + 120 + 720 + 5040 +
40320 + 362880 + 3628800 = 4 038 904 перестановки в `--exhaustive`; на каждой
— n «диагональных» минимумов (каждый — O(n) после начального O(n^2)), итого
порядка `sum n! * n^2` элементарных операций. `--identity` — 5904
перестановки (n = 4..7) x (n+1) момента t x n значений k. `--heuristic` —
46 104 перестановки (n = 4..8). `--sample` — 40 перестановок.

Время: n = 9 — 16.6 с, n = 10 — 207.2 с (см. `exhaustive_9_10.json`). n <= 8 —
секунды. Всего прогона — около 5-6 минут суммарно. Память: не измерялась
отдельно, порядок КБ (нет таблиц расстояний, только текущая перестановка и
её n диагоналей).

## Результат

1. **Лемма D (доказана, не только проверена):** для любого фиксированного t
   и любой pi, `sum_{k=0}^{n-1} S_t^{(k)} = 0`, где `S_t^{(k)}` — накопленное
   изменение inv при повороте `u^{(k)}` на t шагов. Проверено на переборе
   (`--identity`), 0 нарушений на 5904 перестановках (4 <= n <= 7).
2. **Точность редукции:** `I(pi) = min_k R(u^{(k)})` — проверено ассертом
   против прямого определения `I(pi)` (все n^2 разреза) на всех перестановках
   4 <= n <= 7 (5904 шт.), 0 расхождений.
3. **Гипотеза H13-I-diag** (`sum_k R(u^{(k)}) <= n * floor((n-1)^2/4)`):
   0 контрпримеров на **полном** переборе 4 <= n <= 10 (4 038 904
   перестановки) и на структурной/случайной выборке n = 20, 50, 100, 101, 200
   (40 перестановок). Равенство — ровно на n входах при каждом n = ровно
   поворотах (сдвигах L) одного отражения `pi_h`; на всех остальных входах —
   строго меньше.
4. **Негативный результат (важен для следующей сессии):** переход от
   истинного минимума `min_t` к среднему `avg_t` (через лемму D) даёт слишком
   слабую оценку — сырая (без вращения) сумма `sum_k inv(u^{(k)})` на
   sigma_n уже превышает цель `n * floor((n-1)^2/4)`: 91 vs 63 (n=7), 140 vs
   96 (n=8), 2470 vs 1800 (n=20). Явное правило «разрез сразу после позиции
   максимума» вместо истинного минимума тоже не годится: 4 контрпримера из
   24 уже при n = 4, до 7656 из 40320 при n = 8.

Контрпримеров к самой H13-I-diag не найдено ни на одном из проверенных
уровней — но ни один из опробованных путей к доказательству не замкнулся.

## Вывод и следующий вопрос

H13-I остаётся VERIFIED 4 <= n <= 10, CONJECTURED в общем случае (без
изменений статуса). H13-I-diag — новая, более узкая и достаточная для H13-I
гипотеза, тоже VERIFIED в указанном объёме и CONJECTURED в общем случае;
доказательство не найдено за бюджет сессии. Следующий вопрос — прямая
комбинаторная характеризация `R(u)` (минимума инверсий одной перестановки по
вращениям), которая позволила бы просуммировать по k без потери на переходе
`min_t <= avg_t` (см. `docs/notes/h13_line_model.md` §7.5); если и это не
даст результата за следующую сессию — переходить к индукции H3 (PLAN §4.3).
