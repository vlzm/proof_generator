# h13i_search — попытка дешёвого сертификата для H13-I (сессия 9)

Цель: `experiments/line_model.py`/`docs/notes/h13_line_model.md` §6, найти
доказуемую схему выбора разреза `(q, c)` для H13-I
(`I(pi) <= floor((n-1)^2/4)` для всех pi), не требующую перебора всех `n^2`
разрезов. Проверены шесть дешёвых кандидатов на всех pi при `4 <= n <= 10`
(исчерпывающе, эталонная функция инверсий перебором пар,
`experiments/h13i_search.c`, h13i_search-1.0):

- `local4`, `local8` — худшее значение среди 2D-локальных минимумов
  `inv(q, c)` по 4- и 8-окрестности тора `(q, c)` (не требует знания
  глобального минимума, только локальный спуск).
- `antipod4pt` — минимум по 4 фиксированным разрезам `(0,0), (n/2,0), (0,n/2),
  (n/2,n/2)` (n чётно).
- `qsweep_c0` — минимум по `q` при фиксированном `c = 0`.
- `L1_center_c`, `L2_center_c`, `Linf_center_c` — `c*` минимизирует
  `sum|t_i|`, `sum t_i^2`, `max|t_i|` по `t_i = centered((pi(i) - i + c) mod n)`
  (диагональное центрирование), затем минимум по всем `q` при этом `c*`.

## Вывод

- `local4`/`local8` (2D-локальный спуск по решётке `(q,c)`, радиус 1 или с
  диагоналями) — плохой сертификат: доля нарушений растёт с n (почти все
  перестановки при n = 8..10). Значит одношаговая локальная оптимальность
  по обеим осям недостаточна даже совместно (расширяет вывод §4 заметки —
  раньше было показано только для отдельных осей).
- Фиксированные малые наборы разрезов, не зависящие от pi (`antipod4pt`,
  `qsweep_c0`), нарушают границу на заметной доле входов — ожидаемо, но
  явно исключает эту простую идею.
- `L1_center_c`/`L2_center_c` (выбор c по минимизации диагонального
  разброса, затем перебор q) — ближе всего: 0 нарушений при `4 <= n <= 7`,
  но 14/40320 (n=8), 261/362880 и 1566/362880 (n=9), 1112/5040 и 5040
  (из 3628800) (n=10) нарушений — растёт с n, не годится как точный
  сертификат без поправки. Нарушения немногочисленны (<0.2%), может быть
  полезно как эвристика/стартовая точка для точного аргумента, но не как
  самостоятельное доказательство.

Ни один из шести кандидатов не даёт доказуемого сведения к O(n) или O(1)
разрезам. Список отвергнутых подходов в `docs/notes/h13_line_model.md` §1.7
и §4 расширен этим отчётом (см. §6 заметки). H13-I остаётся открытой;
бюджет сессии (1 сессия до письменного вердикта, `docs/notes/repo_state.md`)
исчерпан без доказательства — по плану переход к индукции H3 (PLAN §4.3).

Воспроизведение: `gcc -O2 -o experiments/h13i_search experiments/h13i_search.c
&& ./experiments/h13i_search <n>` для `n = 4..10` (n=9: ~4 с, n=10: ~57 с на
1 ядре). Вывод — JSON в `data/runs/h13i_search/n{n}.json`.
