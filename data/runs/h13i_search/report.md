# H13-I search — session 9 (15.09.2026)

Цель: доказать H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi, всех n >= 4),
бюджет 1 сессия до письменного вердикта (`docs/notes/h13_line_model.md` §6).
Итог сессии — вердикт `docs/notes/h13i_verdict.md`: доказательство не
найдено, дополнительные отрицательные и подтверждающие результаты ниже.

Команда: `experiments/h13i_search.py` (h13i_search-1.0). Ядро oracle-1.0 не
используется напрямую (H13-I — чистая комбинаторика торических классов, без
ходов L/R/X); корректность `fast_I` проверяется отдельно против brute force.

## 1. Самопроверка `fast_I` (O(n^2 log n) вместо O(n^4))

`python3 experiments/h13i_search.py --selftest`

Исчерпывающе 3 <= n <= 8 (6..40320 перестановок), выборочно (200 случайных)
n = 9, 10, 12, 15 — `fast_I == brute_I` на каждом входе. Лог
`data/runs/h13i_search/selftest.log`. Время < 5 с.

## 2. Отклонённые ограниченные семейства разрезов (исчерпывающе, 4 <= n <= 8)

`python3 experiments/h13i_search.py --restricted-families --nmax 8`

| n | bound | diagonal (n вместо n^2 разрезов, начало в точке перестановки) — нарушений | single-shift (один q, только s) — нарушений | всего pi |
|---|---|---|---|---|
| 4 | 2 | 4 | 0 | 24 |
| 5 | 4 | 5 | 0 | 120 |
| 6 | 6 | 6 | 0 | 720 |
| 7 | 9 | 56 | 7 | 5040 |
| 8 | 12 | 552 | 16 | 40320 |

Обе семьи недостаточны и доля нарушений растёт с n. `single-shift` при n = 7
воспроизводит именно контрпример леммы C (`(0,5,4,3,2,1,6)`, вход из
`docs/notes/h13_line_model.md` §4) как один из 7 нарушителей — независимое
подтверждение, что оптимизация по одному s без выбора q не работает уже на
известном примере, а не только на нём одном. Лог
`data/runs/h13i_search/restricted_families.log`.

## 3. Поиск контрпримера при n > 10 (структурированные + случайные + SA)

`python3 experiments/h13i_search.py --search` (seed = 0, ветки `--nlist`,
`--sa-nlist` по умолчанию). Покрытие: не исчерпывающее (n! слишком велико) —
поиск ошибок (правило 9), не доказательство.

Отражения (исчерпывающе по h, n^2 разрезов на каждое) + аффинные `a*i+b`
(исчерпывающе по обратимым a, всем b) + случайные перестановки
(200–3000 на n, uniform shuffle) для n = 11, 12, 15, 20, 25, 30, 40, 50, 70,
100:

| n | bound | max найдено | источник максимума |
|---|---|---|---|
| 11..100 (10 точек) | см. лог | ровно = bound на каждом n | отражение h=0 |

Максимум во всех 10 точках достигается ровно на отражении и равен
`floor((n-1)^2/4)` — ни разу не превышен случайными (800–3000 выборок) или
аффинными входами. Время до 28.6 с (n = 100). Лог
`data/runs/h13i_search/search.log`.

Симулированный отжиг (максимизация `I(pi)` случайными транспозициями,
6 рестартов x 8000–15000 итераций, геометрическое охлаждение T: 3.0 -> 0.02)
для n = 11..16, 18, 20, 24 — достигает bound точно при n <= 18, не достигает
(но и не превышает) его при n = 20 (83/90), n = 24 (118/132) в отведённом
бюджете итераций; ни разу не найдено `I(pi) > bound`.

## Вывод

За сессию: ни доказательства, ни контрпримера. Дополнительное отрицательное
свидетельство (диагональные и single-shift разрезы недостаточны) и
дополнительное подтверждающее (SA/random/affine до n = 100 не находят
нарушения) — не меняют статус H13-I (CONJECTURED). Вердикт и следующий шаг —
`docs/notes/h13i_verdict.md`.
