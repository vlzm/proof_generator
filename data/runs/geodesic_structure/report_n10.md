# Геодезические на трудных входах, n = 10

Версии: geodesic_structure-1.0, strict_upper-1.0, oracle-1.0; таблица `data/tables/dist_n10.bin` (C2v). Команда: `python3 experiments/geodesic_structure.py --n 10 --samples 300 --inputs affine --seed 1`.

Обозначения: c — сдвиг слова (конечное положение головы); F — сумма кратчайших дуг при этом c; LBX — оценка спаривания `sum_v max(p_v, m_v)`; double/single/bad — обмены, полезные для двух / одного / нуля элементов; cross — двойные обмены между элементами разных циклов f_c (конструкция N1 их не делает). `N_X = F/2 + single + 2·bad` — тождество.
