# Прогон checks/check_C28.py -- независимая проверка C28 (H10 на отражениях)

- Дата: 12.09.2026, сессия 4. Цель: проверить закрытый вид доказательства
  docs/proofs/C28_reflections.md (леммы R2-R5, явное правило выбора
  сдвига) против фактически исполненной конструкции, не только внутреннюю
  согласованность формул.
- Команда: python3 checks/check_C28.py 40. Отчёт: report.json.
- Версии: ядро oracle-1.0, constructions/strict_upper.py (strict_upper-1.0).
- Тип покрытия: исчерпывающее по h для каждого n, диапазон 4 <= n <= 40
  (первая попытка была запущена с n_max=80 в фоне; после нескольких минут
  реального времени без сохранённого отчёта -- скрипт пишет report.json
  только по завершении всего диапазона -- прогон был остановлен и
  перезапущен с n_max=40, который завершился за 70 с; заявляется только
  фактически выполненный и сохранённый диапазон, не запрошенный 80 из
  первой попытки).
- Время: 70.1 с, память -- незначительна (без таблиц расстояний).
- Результат: PASS. Для каждого n в 4..40 и каждого h из Z_n:
  1. закрытые формулы F_h', S_h' (леммы R2-R3) и H(c) (лемма R4) на
     предсказанном теоремой сдвиге c совпали с F_c, S_c, H реально
     построенного и исполненного слова (strict_upper.shift_word);
  2. предсказанное теоремой значение 2F_c-S_c+H(c) совпало с фактическим;
  3. истинный минимум по всем c (оба маршрута, слова построены и проверены
     apply_word внутри shift_word) не превышает предсказанное теоремой
     значение и не превышает B_n+1;
  4. R_c <= H(c) (лемма R5) проверена поточечно на предсказанном сдвиге.
- Итог по данным: истинный избыток min_c[...] - B_n равен ровно 1 при
  n = 2 (mod 4) (n = 6, 10, 14, ..., 38) и ровно 0 иначе -- для ОБОИХ
  маршрутов (H и по переносчикам) на каждом проверенном n. Теорема C28
  не просто верна на этом диапазоне, а точна: маршрут по переносчикам не
  улучшает истинный минимум относительно маршрута H(c) ни при одном n
  в этом диапазоне (расхождение между маршрутами существует у отдельных
  h внутри семейства -- см. docs/proofs/C28_reflections.md параграф 7 --
  но не меняет максимум по h).
- Следующий вопрос: тот же приём (R_c<=H(c)) не работает для общей pi
  (см. CLAIMS C27, LOGS сессия 4) -- доказательство C28 не переносится
  дальше отражений без новой леммы о структуре переносчиков.
