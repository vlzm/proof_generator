# H13-I — single-shot cut-selection rules (negative result)

Дата: 16.09.2026 (сессия 9). Задача: PLAN §8 / `docs/notes/h13_line_model.md`
§6 — доказать H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi через выбор
двойного разреза). Код: `experiments/h13i_cut_rules.py`
(h13i_cut_rules-1.0). Ядро не задействовано напрямую (чистая комбинаторика
разрезов, сверено с `experiments/line_profile.c`'s определением w_j).

## Идея и результат

Цель — найти явное **конструктивное** правило выбора разреза (q, c), не
требующее перебора всех n^2 вариантов, которое само по себе доказывало бы
H13-I. Проверены два однопроходных правила: сначала выбрать q независимо от
c, затем взять лучший c для этого q.

1. `min_inv0`: q минимизирует `inv` при фиксированном c = 0.
2. `min_S`: q минимизирует `S(q) = sum_c inv(q, c)` (то есть среднее по c).

Оба правила совпадают с целью при 4 <= n <= 6 (исчерпывающе), но
**нарушаются на n = 7 и n = 8** (исчерпывающий перебор всех перестановок,
`data/runs/h13i_cut_rules/output_n4_8.txt`):

| n | target `floor((n-1)^2/4)` | `min_inv0` худший результат | `min_S` худший результат |
|---|---|---|---|
| 4 | 2 | 2 (=target) | 2 (=target) |
| 5 | 4 | 4 (=target) | 4 (=target) |
| 6 | 6 | 6 (=target) | 6 (=target) |
| 7 | 9 | **10** (pi = (0,5,6,4,3,2,1)) | **10** (pi = (0,1,6,5,4,3,2)) |
| 8 | 12 | **13** (pi = (0,6,7,5,4,2,3,1)) | **13** (pi = (0,1,7,6,4,5,3,2)) |

Оба правила промахиваются ровно на 1. Важно: истинный `I(pi)` для этих
входов заметно ниже цели (проверено отдельно: n = 7 вход даёт I = 8 < 9,
n = 8 вход даёт I = 10 < 12) — то есть провал правила не связан с
близостью к экстремали (отражениям), а с тем, что «локально лучший при
фиксированном c» или «лучший в среднем по c» разрез не обязан быть
глобально лучшим. Это согласуется с уже отвергнутыми в сессии 8 подходами
(усреднение по разрезам, локальные условия — лемма C в
`docs/notes/h13_line_model.md`).

## Побочное наблюдение: рекуррента по c (не даёт результата, но фиксируется)

Для фиксированного q, при сдвиге c -> c+1 (mod n) значение `inv(q, c)`
меняется по точной формуле `inv(q, c+1) = inv(q, c) + (n - 1 - 2*pos_q(c))`,
где `pos_q(c)` — индекс j (в порядке, начинающемся с q+1), на котором стоит
значение c. Мультимножество шагов `{n-1-2j : j = 0..n-1}` (т. е.
`{-(n-1), -(n-3), ..., n-3, n-1}`) не зависит от pi и q — это всегда одно и
то же мультимножество (n чисел одной чётности с n-1, сумма 0); меняется
только порядок шагов (определяется pi и q совместно через `pos_q`). Отсюда
`min_c inv(q, c) = inv(q, 0) + min_k W_k(q)`, где `W` — циклическая частичная
сумма шагов от нуля. Идея «оценить худший случай по всем перестановкам
порядка шагов, игнорируя `inv(q,0)`» не редуцирует задачу: `inv(q, 0)` сам
существенно зависит от pi и не ограничен независимо от порядка шагов, так
что чистого комбинаторного (не зависящего от pi) следствия не получено.
Оставлено как возможный инструмент для будущей сессии, не как результат.

## Вывод

Ни одно простое однопроходное правило выбора q (без совместного перебора c)
не доказывает H13-I — это расширяет список отвергнутых подходов сессии 8
двумя конкретными контрпримерами. Прямого пути к конструктивному
доказательству за это исследование не найдено; бюджет сессии на H13-I
исчерпан без вердикта "доказано/опровергнуто". Per PLAN §8 fallback,
следующая задача — индукция H3 (PLAN §4.3, п. 3).
