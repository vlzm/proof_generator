# h13i_cut_rules — попытки доказательства H13-I, сессия 9

Цель: найти доказуемую конструкцию разреза (q, c) с `inv(w) <= floor((n-1)^2/4)`
для любой pi (H13-I, `docs/notes/h13_line_model.md` §6), либо исчерпать
дешёвые кандидаты и задокументировать причину отказа. Версия кода
`h13i_cut_rules-1.0`, ядро не требуется (самодостаточный подсчёт инверсий,
условности разреза идентичны `experiments/line_profile.c`). Метод:
исчерпывающий перебор всех pi (n! перестановок) при 4 <= n <= 10, для
каждой pi — либо ограниченное семейство разрезов (ruleA: n кандидатов,
rule1d: n кандидатов), либо полный перебор n^2 разрезов (ihist). Покрытие:
все pi при данном n, без выборки. Время: каждый режим 4 <= n <= 10 — до 9 с
(n = 10 rule1d/ruleA), ihist полный (n^2 разрезов на pi) уже требуется для
самого I(pi) и совпадает по стоимости с `experiments/line_profile.c`.
Память: O(n) на перестановку. Команды:
`gcc -O2 -o experiments/h13i_cut_rules experiments/h13i_cut_rules.c`,
`./experiments/h13i_cut_rules n {ruleA|rule1d|ihist}` для n = 4..10.
Полный вывод — `report.log`.

## Режим ruleA — «самоссылающийся» разрез

Для каждого q (n кандидатов) сдвиг c выбирается так, чтобы первый элемент
линии получил метку 0 (`w_0 = 0`); берётся минимум по q. Результат:
провал уже при n = 4 (4 из 24) и растёт: доля провалов и худший избыток
растут с n (худшее `inv` = 3, 6, 10, 15, 21, 28, 36 при n = 4..10, на
rev_n = pi_{n-1} — последняя перестановка в лексикографическом порядке).
Вывод: ограничение свободы c одним «естественным» условием на голову
недостаточно уже для малых n; кандидат отклонён.

## Режим rule1d — только сдвиг значений, без сдвига позиций

Позиция разреза зафиксирована (q = n − 1, естественный порядок), перебирается
только c (n кандидатов вместо n^2). Результат:

| n | provалов | из них — точные отражения pi_h | худший избыток над порогом |
|---|---|---|---|
| 4–6 | 0 | 0 | — |
| 7 | 7 | 0 | 1 (10 vs 9) |
| 8 | 16 | 0 | 1 (13 vs 12) |
| 9 | 162 | 0 | 1 (17 vs 16) |
| 10 | 1250 | 0 | 3 (23 vs 20) |

Ключевое наблюдение: **ни один провал не является точным отражением**
`pi_h(i) = h − i mod n` — все n отражений проходят правило rule1d (для
какого-то c при естественном q). Провалившиеся входы — другая, растущая
по числу семья (например при n = 7: `(0,5,4,3,2,1,6)` и его повороты —
тождество на двух точках, разворот середины; полный перебор по q даёт
минимум 8 < 9 уже при q = 0). Ни разу избыток над порогом не превышает
малого числа (1 при n <= 9, 3 при n = 10), но провалов становится много
(1250 при n = 10) и структура их не сводится к отражениям или их
малым возмущениям видимым образом за отведённое время. Вывод: свобода
только по c недостаточна в общем случае; нужна свобода по q. Явного
доказуемого правила выбора q (в замкнутой форме от pi) не найдено.

## Режим ihist — распределение I(pi) (полный перебор n^2 разрезов)

Подтверждает данные сессии 8 и продолжает диапазон: максимум `I(pi) =
floor((n-1)^2/4)` достигается **ровно на n перестановках** (точные
отражения) при каждом 4 <= n <= 10; следующий уровень (`I = max − 1`)
уже заметно многочисленнее (72 при n = 8, 423 при n = 9) и отличается
от максимума всего на 1. Значит зазор между экстремумом и «вторым по
величине» уровнем не растёт с n — простой аргумент устойчивости
(«не-отражения имеют заметный запас») неприменим: вблизи максимума нужен
почти столь же точный аргумент, что и для самого максимума.

## Аналитическая лемма (не вычислительная, включена как часть сессии)

Для пары точек P, Q перестановки с `d_x = (x_Q − x_P) mod n`,
`d_y = (y_Q − y_P) mod n` (∈ {1,…,n−1}), число разрезов (a,b) из всех n^2,
на которых пара инвертирована, равно `term(d_x,d_y) = n(d_x+d_y) − 2 d_x d_y
= n^2/2 − 2uv`, где `u = d_x − n/2`, `v = d_y − n/2`. Суммируя по всем C(n,2)
парам и деля на n^2, получаем среднее `inv(a,b)` по всем разрезам:
`avg = C(n,2)/2 − (2/n^2) * sum_pairs(uv)`. Поскольку `term <= n^2/2`
поточечно (при любых целых d_x, d_y в диапазоне), `avg <= C(n,2)/2 =
n(n-1)/4` для ЛЮБОЙ pi — но `n(n-1)/4 − floor((n-1)^2/4) = (n-1)/4 + O(1) > 0`
при n > 1. Значит равномерное усреднение по всем n^2 разрезам (pigeonhole)
принципиально не может доказать порог `floor((n-1)^2/4)` ни при какой pi —
разрыв растёт линейно по n. Это делает строгим наблюдение сессии 8
(«усреднение не работает») и объясняет, почему требуется pi-зависимый
структурный аргумент, а не общая оценка среднего.

## Итог

H13-I не доказана за сессию. Два дешёвых явных правила (ruleA, rule1d)
отклонены с явными контрпримерами и/или растущим числом исключений;
усреднение по всем разрезам строго недостаточно (аналитическая лемма
выше); ландшафт I(pi) вблизи максимума плотный (соседние уровни
отличаются на 1), что исключает грубые аргументы устойчивости. Экстремум
подтверждён точно как «ровно n отражений» при 4 <= n <= 10. Решение —
переход к индукции H3 (PLAN §4.3 п. 3), как предписано критерием PLAN §8.
