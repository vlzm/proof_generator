# toric_I_recurrence_check — вывод рекуррентностей для inv(s,t) (сессия 9)

Цель: проверить брутфорсом две точные рекуррентные формулы и точную формулу
пары `f(a,b)`, на которых основан `experiments/toric_I_fast.c` (O(n^2) вместо
O(n^4) на перестановку), прежде чем использовать их для расширения диапазона
H13-I. Формулы и вывод — `docs/notes/h13_line_model.md` §7.

Версии: `experiments/toric_I_recurrence_check.py` (toric_I_recurrence_check-1.0).
Команда: `python3 experiments/toric_I_recurrence_check.py --nmin 2 --nmax 7`.
Покрытие: исчерпывающе все pi, все n^2 клеток сетки (s,t), 2 <= n <= 7
(5912 перестановок). Время: < 1 с. Память: O(n^2) на перестановку (полная
сетка брутфорсом).

Результат: все проверки прошли (0 нарушений) — обе рекуррентности
(`inv(s+1,t)-inv(s,t) = (n-1)-2*w0`, `inv(s,t+1)-inv(s,t) = (n-1)-2*k`) и
формула суммы по парам `sum_{s,t} inv(s,t) = sum_{pairs} f(a,b)`,
`f(a,b) = n(a+b) - 2ab`, верны точно на каждой перестановке и каждой клетке
сетки. Вывод: формулы — доказанные тождества (не эвристики), можно
использовать в `toric_I_fast.c` для быстрого перебора при n = 11, 12, 13.

Артефакт: `output.txt` (лог прогона).
