# check_C37 — независимая проверка C37 и конечных данных C38 (сессия 9)

Цель: независимо (по определениям, без рекуррент и без C-кода) проверить
тождество двойного разреза, его следствия и само H13-I.

Код: `checks/check_C37.py` (check_C37-1.0). Все линии строятся переразметкой
`w_j = (pi(a + j) − b) mod n`, инверсии считаются двойным циклом; арифметика
целочисленная (удвоенные ранги `s(u) = 2(u mod n) − (n − 1)`), допусков нет.
Ядро LRX и таблицы расстояний не используются.

Команда: `python3 checks/check_C37.py --nmax 8 --seed 20260916`.
Время 6.3 с, память < 50 МБ. Лог: `check_C37.log`.

Покрытие:

- части A–E (теорема 3, леммы 4 и 6, следствия 7 и 9): все `n!` перестановки
  при 3 <= n <= 7; при 8 <= n <= 11 — 30 случайных (seed 20260916) плюс
  отражения `h = 0, 1, n/2` и аффинные `m = 2, 3, n − 2` (где gcd(m, n) = 1);
- часть D (следствие 8) считает `E(pi)` прямым перебором всех C(n, 3) троек;
- часть F: H13-I исчерпывающе по всем торическим классам при 4 <= n <= 8
  (независимо от `experiments/toric_inv.c`), максимум `I` равен
  `floor((n − 1)^2/4)` и достигается на отражении;
- часть F′: семейства (все отражения, все аффинные с gcd(m, n) = 1,
  5 случайных) при 12 <= n <= 24 и n = 30, 40, 50, 60 — `I <= M` всюду,
  максимум на отражениях; при n <= 16 значение `I`, посчитанное через
  тождество, сверено с прямым перебором разрезов;
- часть G: покрытие критериев следствий 7 и 9 по всем классам при 4 <= n <= 8
  (совпало с `experiments/toric_spearman.py`).

Результат: PASS, расхождений нет, контрпримеров нет.

Вывод: тождество и следствия C37 подтверждены независимо; конечные данные
H13-I (C38) воспроизведены до n = 8 исчерпывающе и до n = 60 на семействах.
