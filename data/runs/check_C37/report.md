# check_C37 — независимая проверка C37 (сессия 9)

Цель: независимо проверить все вычислимые части доказательства
`docs/proofs/C37_toric_average.md` (леммы 1–5 и теорема
`I(pi) <= Ibar(pi) <= (n−1)(2n−1)/6`), сверить определение двойного разреза
с формой `(q, c)` из `docs/notes/h13_line_model.md` и заодно зафиксировать
конечные данные по H13-I и по строчной форме RA собственным кодом (Python,
независимо от `experiments/toric_inv.c`).

Версия: check_C37-1.0. Команда:

```text
python3 checks/check_C37.py --nmax 8 --sample_nmax 40
```

Время 2.5 с, память — единицы МБ. Арифметика целочисленная: `phi`
используется только через `psi(x) = 2*(x mod n) − (n−1)`, тождество леммы 2
проверяется в форме `n*(2n*inv(u,v) + T2(u,v)) = 2*sum_{u,v} inv(u,v)`.
Ядро oracle-1.0 не привлекается: слова не исполняются.

## Покрытие и результат

| часть | что проверено | покрытие |
|---|---|---|
| 1 | множества значений `inv` по разрезам `(q, c)` и `(u, v)` совпадают | все pi, 4 <= n <= 6 |
| 1b | следствие 3 (`T = n^2 * D~`, дважды центрированная угловая дискрепанция) и следствие 4 (смешанная разность `= 2 − 2n*[pi(u)=v]`) | все pi, 4 <= n <= 6 |
| 2 | лемма 1 (шаговые формулы против прямого счёта), лемма 2 (тождество на всех `n^2` разрезах), лемма 3 (целость `k_a`, пары, все тройки), лемма 4 (формула Ibar), лемма 5, теорема | все классы (`pi(0) = 0`), 4 <= n <= 8 |
| 2 | H13-I (`max I = floor((n−1)^2/4)`), RA (`max RA = n*floor((n−1)^2/4)`), `max n^2*Ibar` равен значению на отражениях | все классы, 4 <= n <= 8 |
| 3 | леммы 1–5 и теорема, H13-I и RA на выборке (отражения, тождественная, все аффинные с `gcd(a,n)=1`, 12 случайных, seed 1) | 9 <= n <= 40, SAMPLED |

Числа части 2: классов 6, 24, 120, 720, 5040 при n = 4..8; `max I` = 2, 4, 6,
9, 12 (= границе, ровно один класс — отражения); `max RA` = 8, 20, 36, 63, 96
(= n*границе, ровно один класс); `max n^2*Ibar` = 56, 150, 330, 637, 1120
(= `n^2 (n−1)(2n−1)/6`).

Результат: **PASS** (`run.log`).

Негативный контроль: при искусственной порче счётчика инверсий
(`inv_line` + 1 при n = 8) проверка падает на лемме 4 — assert'ы не
вырождены.

Границы применимости: перебор конечен и подтверждает только формулы;
общая часть доказательства C37 — разделы 1–6 документа, они на перебор
не опираются. H13-I и RA этим прогоном НЕ доказаны, статус их строк —
VERIFIED в указанных диапазонах (шире — `data/runs/toric_inv/report.md`).
