# check_C37 — цель, параметры, результат (правило 7)

- **Цель.** Независимо проверить утверждения C37 (`docs/proofs/C37_toric_reflection.md`).
- **Команда.** `python3 checks/check_C37.py` (значения по умолчанию:
  `--amax-a 20 --amax-t 7 --amax-eq 8 --amax-d 12 --seed 20260915`).
- **Версии.** check_C37-1.0; независимая реализация (линия строится явно,
  инверсии считаются перебором пар), инкрементная таблица из
  `experiments/toric_cuts.py` не используется; ядро ходов и таблицы расстояний
  не нужны.
- **Покрытие.** A: все отражения и все n^2 разрезов при 4 <= n <= 20;
  B: исчерпывающе все pi при 4 <= n <= 7 (тройки) и 4 <= n <= 8 (множество
  равенства); C: исчерпывающе при 4 <= n <= 6, выборка 200 + отражения при
  n = 7, 8, точная арифметика при 4 <= n <= 200; D: все аффинные входы при
  4 <= n <= 12 плюс три контрпримера.
- **Проверено состояний.** ~46 000 перестановок; для каждой — до n^2 разрезов.
- **Время.** 3.3 с.
- **Результат.** PASS.
- **Артефакты.** `report.md`, `report.json`.
- **Следующий вопрос.** Доказать единственность максимизатора (равенство
  в H13-I только на отражениях) — пока конечное наблюдение 4 <= n <= 10.
