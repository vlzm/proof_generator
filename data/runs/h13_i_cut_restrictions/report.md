до письменного вердикта (PLAN §8, `docs/notes/h13_line_model.md` §6).

Команда: `python3 experiments/h13_i_cut_restrictions.py 8` (см. код —

исчерпывающе при 3 <= n <= 8. Seed не требуется (полный перебор). Ядро:
oracle-1.0 не задействовано (чистая комбинаторика на торе, не ходы LRX).
Время и память: n = 8 — 16.7 с, единственный процесс, память
незначительна (`data/runs/h13_i_cut_restrictions/output.txt`).

## Результат

1. Подтверждено без нового покрытия (уже VERIFIED в C33/C35 при
   4 <= n <= 10 через `line_profile.c`): `max_pi I(pi) = floor((n-1)^2/4)`
   при 3 <= n <= 8, счётчик контрпримеров — 0.
2. **Диагональные разрезы недостаточны**: ограничение поиска до n
   разрезов вида c = q (вместо n^2) не находит нужный минимум почти на
   половине входов уже при малых n (9/24 при n = 4, 4543/40320 при n = 8,
   доля растёт с n). Отклонено как направление.
3. **Разрез только по позициям недостаточен**: фиксация сдвига значений
   (c = 0) и перебор только q (классическая величина "минимум инверсий по
   циклическим вращениям") не достигает бюджета `floor((n-1)^2/4)` уже при
   n = 7 (7 входов из 5040) и n = 8 (16 из 40320); доля мала, но не равна
   нулю и не убывает. Совместное варьирование обоих разрезов необходимо
   в самой формулировке, а не только для удобства — оба параметра
   существенны.

## Аналитическая часть (не проверялась независимым кодом)

Переформулировка через согласованные (конкордантные) пары: для пары
позиций {i, i'} с разностью позиций `a = (i'-i) mod n` и разностью
значений `b = (pi(i')-pi(i)) mod n` (оба в 1..n-1), число разрезов (q, c)
из n^2, на которых пара дискордантна, равно `n(a+b) - 2ab`; отсюда сумма
дискордантности по всем n^2 разрезам равна `n^3(n-1)/2 - S_ab`, где
`S_ab = sum_{i != i'} a*b` (по всем упорядоченным парам). Средняя по всем
n^2 разрезам дискордантность для sigma_n (pi(i) = -i mod n) равна
`(n-1)(2n-1)/6 ~ n^2/3`, что больше цели `floor((n-1)^2/4) ~ n^2/4` — это
формализует уже известный вывод ("усреднение не работает", §1.7):
усреднение даёт верную, но слишком грубую оценку на экстремальном классе,
поэтому доказательство требует существования конкретного хорошего разреза,
а не среднего аргумента. Формула не проверена дополнительным кодом сверх
согласия с эмпирическим средним для id и sigma_n (сверено вручную для
малых n).

## Вердикт

H13-I не доказана и не опровергнута за сессию. Проверенные и отклонённые
направления за сессию 9: диагональные разрезы, чистое вращение позиций.
Ранее отклонённые (сессия 8): усреднение по всем n^2 разрезам, индукция
удалением одного элемента, семейство "первый элемент = t", локальные
условия оптимальности (лемма C). Новое (не проверенное дальше): точная
формула суммы дискордантности по всем разрезам через `S_ab`; она даёт
количественное объяснение, почему усреднение проваливается именно на
отражениях, но не даёт конструктивного доказательства существования
хорошего разреза.

Решение по контрактному правилу PLAN §8 ("если нет за сессию — переход
к индукции H3"): следующая задача — H3 (PLAN §4.3 п. 3), отдельным
бюджетом 2 сессии до вердикта. H13-I остаётся открытой гипотезой
(CONJECTURED, VERIFIED 4 <= n <= 10 по C33/C35 и данной сессии для
n <= 8), не входит в подтверждённую цепочку к C15.
