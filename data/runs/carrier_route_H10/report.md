# H10 / C27: вариант N1 с маршрутом по переносчикам — вердикт (сессия 4, 13.09.2026)

Цель (PLAN §8, вторая и последняя сессия бюджета H10): доказать или опровергнуть

```text
(а)  min_c [2F_c − S_c + R_c] <= B_n + 1   при всех n >= 4 и pi из S_n,
(б)  после свободного сокращения собранного слова  <= B_n,
```

прямой оценкой минимума по c, без усреднения (N1, 3.4) и без цепочки s §§5–9.

**Результат: REFUTED.** Часть (б) неверна при n = 10 (наименьшее n; контрпример
единствен среди всех перестановок S_10), часть (а) — при n = 18; превышение
растёт с n. Отдельно доказана Теорема A для отражений (все n >= 4).
Доказательства и разбор — `docs/proofs/N1_carrier_route.md`.

## Версии и окружение

Ядро oracle-1.0 (`oracle/moves.py`), конструкция strict_upper-1.0
(`constructions/strict_upper.py`), чекер check_C27-1.0 (`checks/check_C27.py`),
C-ядро `checks/carrier_core.h` + `checks/check_C27_fast.c` (независимая
реализация по спецификации PROBLEM §5.2 и N1 §§1–3),
`experiments/affine_C27.py` (affine_C27-1.0), `experiments/search_C27.c`.
Python 3.11, gcc -O2, один поток, целочисленная арифметика (float в этих
прогонах не используется).

## Результаты

### Исчерпывающие прогоны: максимум `min_c [2F_c − S_c + R_c] − B_n`

| n | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11 |
|---|---|---|---|---|---|---|---|---|
| максимум | 0 | 0 | **+1** | 0 | 0 | 0 | **+1** | 0 |
| число pi с `>= B_n` | 1 | 2 | 7 | 3 | 11 | 10 | 96 | 21 |

Число pi с превышением +1: 1 при n = 6, 6 при n = 10. Полные гистограммы —
`exhaustive.log`, списки самих перестановок — `excess_n<k>.txt`
(формат: превышение, затем pi).

Максимум по pi среднего по c: `mean_c [2F_c − S_c + R_c] − B_n` =
1/2, 0, 1, 5/7, 3/2, 14/9, 12/5, 25/11 при n = 4..11 — растёт, то есть
усреднение по c для этого варианта тоже не удерживает B_n.

### Контрпример к части (б): n = 10 (минимальный)

```text
pi = (9, 2, 5, 0, 1, 8, 7, 6, 3, 4),  B_10 = 45,
min_c [2F_c − S_c + R_c] = 46 = B_10 + 1,   min_c |свободно сокращённое слово| = 46.
```

Таблица правила 15 по всем сдвигам — `docs/proofs/N1_carrier_route.md` §3.1 и
`check_C27.json` (`B_C_counterexamples.C27b_minimal.rows`). Минимальность:
при 4 <= n <= 9 часть (б) верна для всех pi (C27v, сессия 3); при n = 10
кандидатами могут быть только 6 перестановок с превышением +1 (свободное
сокращение не удлиняет слово), и ровно у одной из них сокращение не опускает
длину до B_n. При n = 11 максимум превышения равен 0, поэтому часть (б) там
снова верна для всех pi — по n утверждение не монотонно. При n = 12 и выше
исчерпывающий прогон не выполнялся (оценка ~40 мин, правило 10).

### Контрпримеры к части (а): аффинное семейство

```text
n = 18,  pi(i) = 5i + 16 mod 18:  min_c = 156 = B_18 + 3   (после сокращения 148)
n = 26,  pi(i) = 5i + 6:          min_c = 328 = B_26 + 3   (после сокращения 324)
n = 27,  pi(i) = 8i + 3:          min_c = 355 = B_27 + 4   (после сокращения 353 = B + 2)
n = 28,  pi(i) = 11i + 20:        min_c = 383 = B_28 + 5   (после сокращения 379 = B + 1)
```

Максимум превышения по аффинному семейству (`affine.json`, столбец len_R):
+1 при n = 6, 10, 14, 17, 22, 25, 30; +3 при n = 18 и 26; +4 при n = 27;
+5 при n = 28; дальше (только величина, `search_C27`): +2 (n = 31), +4 (34),
+8 (36), +5 (37), +3 (39, 41, 42), +4 (43), +9 (45), +8 (50), +6 (53),
**+12 (n = 54)**, +9 (56). После сокращения (столбец red_R) превышение впервые
положительно при n = 17 (+1) и достигает +3 при n = 28.

Минимальность части (а) (правило 6): исчерпывающе нет превышения >= 2 при
4 <= n <= 11; при 12 <= n <= 17 проверено исчерпывающе аффинное семейство
(максимум +1) и выборочно общие pi (hill-climbing, 20 000 рестартов на n:
максимумы +0, +1, +0, +1, +1 при n = 13..17); наименьшее n среди проверенных
с превышением >= 2 равно 18.

### Проверки Теоремы A и вспомогательных лемм (`check_C27.py`, PASS, 9.3 с)

* A: C-ядро совпадает с strict_upper-1.0 (F_c, S_c, R_c и длина слова) на всех
  5 904 перестановках при 4 <= n <= 7 и на 400 случайных при n = 8, 9.
* B, C: таблицы контрпримеров n = 10 и n = 18, 26, 27, 28; все слова исполнены
  эталонными ходами и сортируют pi (в том числе после сокращения).
* D: замкнутые формы Лемм A1–A3 и граница Теоремы A — все отражения,
  4 <= n <= 30; фактический минимум равен B_n + 1 ровно при n = 2 (mod 4)
  и чётном h из 2..n/2, иначе не больше B_n.
* E: зигзаг-цикл (0, 1, n−2, n−1, …) при чётном n >= 8 имеет
  (M, t, E, F, S) = (3, n/2, 0, 2n, 5), то есть S(C) − |C| = 5 − n:
  цикловая оценка `S(C) >= |C| + 1` неверна.
* F: полный перебор всех ориентированных нетривиальных циклов при 4 <= n <= 9
  (144 606 циклов): минимум S(C) − |C| равен 1, 1, −1, −1, −3, −3.
* G: для каждого сдвига каждого контрпримера R_c совпадает с длиной кратчайшей
  прогулки по независимому BFS на состояниях (позиция, посещённые переносчики),
  то есть опровержение не является артефактом эвристики `carrier_route`.

## Вывод и следующий вопрос

Маршрут по переносчикам не спасает конструкцию N1: минимум по c её оценки
превышает B_n на растущую величину. Вместе с C26 (REFUTED для маршрута H(c))
это закрывает направление «улучшать только внешний маршрут при тех же
локальных словах»: при 4 <= n <= 11 обе версии почти достигают B_n, но на
структурированных pi (аффинные отображения с несколькими длинными циклами при
каждом c) разрыв растёт.

Следующий вопрос — не маршрут, а локальные слова: у контрпримеров при каждом c
получается 4–5 циклов с F_c около P и малым S_c, так что `2F_c − S_c` само по
себе уже около B_n. Естественные кандидаты (PLAN §4.2–4.3): доказательство
H8/C25 (даёт локальное C9), H6/C22 (`D_n <= B_n + n`), аудит S1 (C8).
Бюджет H10 (2 сессии) исчерпан, вердикт письменный — правило 12.
