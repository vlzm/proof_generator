# H10 (PLAN §8, C27) на отражениях: расширенный прогон

Сессия 4 (13.09.2026). Модуль `experiments/reflection_route.py`
(reflection_route-1.0); ядро oracle-1.0; конструкция strict_upper-1.0.

## Цель

Шаг (1) PLAN §8: доказать/проверить `min_c [2F_c - S_c + R_c] <= B_n + 1`
на отражениях явно, расширив семейный прогон C27v (4<=n<=12,
`experiments/loss_map.py`) на большие n. R_c (маршрут по переносчикам,
вариант N1, правило 16) и F_c, S_c не требуют таблицы расстояний и не
требуют явной сборки слова, поэтому расширение возможно далеко за пределы
BFS.

## Метод

Для отражения `pi(i) = h - i mod n` и сдвига c, `f_c(i) = (k-i) mod n` c
`k = (h+c) mod n` — тоже отражение. Замкнутая форма (вывод — докстринг
модуля; **перекрёстно сверена** с общей аудированной `strict_upper.py`
(`shift_word(..., route="carrier")`) на всех (n, h, c), 4<=n<=15, 1226
троек — `self_test()` в модуле, PASS):

- неподвижные точки f_c: 1 при нечётном n; 2 при чётном n и чётном k;
  0 при чётном n и нечётном k;
- каждая нетривиальная пара {i, j=k-i mod n} — транспозиция с
  F-вкладом 2L (L — длина короткой дуги) и S(C) = 3 (обе разновидности,
  PROBLEM §5.3), поэтому S_c = 3 * (число нетривиальных пар);
- переносчик пары — начало короткой дуги в положительном направлении:
  i, если m = (j-i) mod n (при i<j как целые 0..n-1) <= n//2, иначе j.

R_c = `carrier_route` (`constructions/strict_upper.py`, не изменена).

## Команда

```bash
python3 experiments/reflection_route.py --nmin 4 --nmax 160
```

Один поток, точная целочисленная арифметика, без float. Время: 83.7 с
суммарно по всем n (растёт с n; при n = 160 — 2.0 с на одно n: n сдвигов
на n отражений на carrier_route O(m log m), m ~ n/2).

## Покрытие

Все n отражений (h = 0..n-1) и все n сдвигов c — исчерпывающе,
4 <= n <= 160 (157 значений n). B_n — точная целочисленная формула
(`bounds/known.py`), не требует таблицы расстояний.

## Результат

`max_h min_c [2F_c - S_c + R_c] - B_n` равен **ровно** `1`, если `n ≡ 2
(mod 4)` (максимум достигается только при h = 2, c = 0), и **ровно** `0`
иначе (максимум при h = 1), без единого исключения на всех 157 проверенных
n. Совпадает с прежними данными `loss_map.py` для 4<=n<=12 (тот же h = 2,
n = 6, 10 — единственные превышения B_n среди C27v при переборе всех
перестановок 4<=n<=9) и с сокращённым отчётом report.md сессии 3
("Q_R − B_n по h при n = 6: ...; при n = 10: ...").

Таким образом H10 на отражениях подтверждена явной проверкой формулы
`min_c [2F_c - S_c + R_c] = B_n + [n ≡ 2 (mod 4)]` на 4<=n<=160 (VERIFIED,
диапазон явный); общее доказательство этой формулы для всех n не получено
в этой сессии — числовая картина исключительно регулярна (единственный
худший h = 2, единственный худший c = 0), что делает конечную алгебраическую
лемму вероятной целью следующей сессии, но не заменяет её.

## Вывод и следующий шаг

Направление (1) PLAN §8 закрыто с большим запасом уверенности: явная
формула на отражениях, а не только конечный перебор. Направление (2)
(перенос на произвольную pi) остаётся открытым — тождество
`F_c = sum_i delta_n(i - pi(i), c)` даёт медиану для F, но для R_c
(в отличие от H(c)) нет ещё общей верхней оценки через F_c, S_c одной
и той же pi: R_c зависит от расположения переносчиков на окружности,
не только от их числа, и это расположение для общего pi не изучено.
Бюджет H10 (PLAN §8): использована 1 из 2 сессий; следующая сессия —
либо связать R_c с F_c/S_c для общего pi (первый кандидат: R_c <= 2K_c,
K_c = число нетривиальных циклов f_c, недостаточно — дать нижнюю оценку
`2F_c - S_c` через K_c, чтобы компенсировать 2K_c), либо письменный
вердикт с найденным преп­ятствием, как предписано PLAN §8 при неудаче.
