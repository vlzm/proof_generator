# Проверка леммы приращения (сессия 9, попытка H13-I)

Цель: проверить тождество `inv_{c+1}(sigma) - inv_c(sigma) = n - 1 - 2*k_c`
(k_c — позиция значения c в sigma), используемое в попытке доказать H13-I
(`docs/notes/h13_line_model.md`, §7). Тождество проверяется напрямую
перебором инверсий линейной перестановки, независимо от ядра oracle-1.0
(это утверждение о перестановках и инверсиях, не о ходах LRX).

Команда: `python3 experiments/delta_lemma_check.py`.
Версия скрипта: delta_lemma_check-1.0. Seed: 1 (для n = 10, 20, 50, 100, 101).

Покрытие (правило 9 AGENTS.md):
- n = 4..9 — исчерпывающе (все перестановки: 24, 120, 720, 5040, 40320, 362880).
- n = 10, 20 — 20000 случайных перестановок; n = 50, 100, 101 — 2000 случайных
  перестановок.

Проверяется на каждой перестановке: для всех c = 0..n-1 совпадение
фактической разности `inv_{c+1} - inv_c` (брутфорс подсчёт инверсий) с
формулой `n - 1 - 2*k_c`, и замкнутость цикла (`inv_n = inv_0`).

Результат: PASS на всех перестановках во всех проверенных диапазонах, без
исключений. Время: ~99 с (весь диапазон, один процесс).

Вывод: лемма верна (совпадает с аналитическим выводом в
`docs/notes/h13_line_model.md` §7.1); используется как инструмент, не
как полное доказательство H13-I (см. §7.3 — почему одной этой леммы
недостаточно).

Следующий вопрос: нет — сессия 9 закрыта письменным вердиктом по H13-I
(лемма зарегистрирована, доказательство не завершено), следующая задача —
индукция H3 (PLAN §4.3, п. 3).
