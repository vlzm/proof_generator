# I(pi) exhaustive extension and large-n sampling (H13-I / C33)

Дата: 16.09.2026 (сессия 9). Задача из PLAN §8: доказать H13-I за 1 сессию
до письменного вердикта; если нет — переход к индукции H3 (§4.3).

## Цель

`H13-I`: `I(pi) = min_{a,b} inv(w_{a,b}) <= floor((n-1)^2/4)` для каждой pi
(торический класс перестановки; определения — `docs/notes/h13_line_model.md`
§0). Ранее VERIFIED исчерпывающе 4 <= n <= 10 (C33). Задача сессии: либо
доказать H13-I, либо расширить проверку и зафиксировать вердикт.

## Что сделано

1. Выведена и независимо проверена точная формула градиента сетки
   `g(a,b) = inv(w_{a,b})` (C37, `checks/check_C37.py`, доказательство —
   `docs/notes/h13_line_model.md` §7.1). Формула сводит вычисление всей
   сетки n x n значений `g` к O(n^2) операциям на одну pi (вместо
   наивных O(n^4)).
2. `experiments/toric_inversions_scan.c` — точный перебор `I(pi)` по всем
   n! перестановкам с использованием C37. Расширяет исчерпывающую проверку
   C33 с 4 <= n <= 10 до 4 <= n <= 12.
3. `experiments/toric_inversions_sample.c` — структурная и случайная выборка
   для n = 13..200 (отражения — все h; аффинные `a*i+b` для взаимно простых
   a; 3000 случайных перестановок; 500 возмущённых отражений), ищет
   контрпример за пределами исчерпуемого диапазона.
4. Попытки доказательства H13-I (не завершены) — см. §7.2
   `docs/notes/h13_line_model.md`: переформулировка через две замкнутые
   "прогулки" сетки со сдвигом на n-1-2k, локальный спуск (Лемма C уже
   показывала недостаточность — переформулировка это подтверждает другим
   языком, не даёт нового аргумента); проверено и отвергнуто отождествление
   `I(pi)` с длиной Кокстера аффинной перестановки (не совпадает уже при
   n = 4); проверено, что "чистый сдвиг только по значению" (без вращения
   позиций) не достаточен сам по себе — терпит неудачу на том же входе,
   что и Лемма C (`(0,5,4,3,2,1,6)`, n = 7).

## Команды и параметры

```
gcc -O2 -o toric_scan   experiments/toric_inversions_scan.c
gcc -O2 -o toric_sample experiments/toric_inversions_sample.c
python3 checks/check_C37.py
for n in 4 5 6 7 8 9 10 11 12; do ./toric_scan $n; done
./toric_sample     # встроенный список n = 13..200, 3000 случайных на n
```

Ядро/таблицы не используются (чисто комбинаторная величина на S_n,
не связана с oracle-ходами).

## Результаты

`checks/check_C37.py`: 46232 перестановки (все n! при 2 <= n <= 8),
0 расхождений, 9 с — PASS. Идентичность C37 подтверждена независимо от
кода `toric_inversions_*.c`.

Исчерпывающий перебор (`scan_n4_11.log`, `scan_n12.log`):

| n | bound = floor((n-1)^2/4) | max I(pi) | время |
|---|---|---|---|
| 4..10 | 2,4,6,9,12,16,20 | равно bound | < 2 с (было VERIFIED ранее) |
| 11 | 25 | 25 | 15.4 с |
| 12 | 30 | 30 | 3м42с |

Максимум во всех случаях достигается ровно на n отражениях (представитель
`(0, n-1, n-2, ..., 1)` и его повороты) — согласуется с прежним наблюдением
"равенство — ровно n отражений".

Выборка n = 13..200 (`sample_n13_200.log`): на всех 17 значениях n худший
найденный `I(pi)` по всем четырём семействам (отражения, аффинные, 3000
случайных, 500 возмущённых отражений) в точности равен `floor((n-1)^2/4)`
и достигается на отражении (kind=0); ни аффинные, ни случайные, ни
возмущённые отражения его не превышают. Полный перебор — 1.6 с (быстрый
алгоритм на C37).

## Вывод

H13-I: **не доказана**, но подтверждена исчерпывающе на 4 <= n <= 12
(расширение с n <= 10) и подтверждена выборочно на n = 13..200 без единого
контрпримера, включая структурные семейства (отражения, аффинные) и
возмущения. Экстремум — по-прежнему только отражения; ни одна из проверенных
структурных семей их не обгоняет даже при больших n. Новый инструмент
(C37 + быстрые сканеры) пригоден для дальнейшего расширения проверки, если
понадобится.

Попытка доказательства через переформулировку "сетка как замкнутая прогулка
со сдвигами n-1-2k" не дала прорыва: она точно воспроизводит Лемму C в
других терминах (локальный спуск недостаточен на входе `(0,5,4,3,2,1,6)`,
n = 7), не даёт глобального аргумента. Отдельно исключено отождествление с
длиной Кокстера аффинной перестановки (не совпадает уже при n = 4) и
доказано, что для H13-I необходимы ОБА параметра сдвига совместно (чистый
сдвиг только по значению или только по позиции недостаточен, тот же
контрпример n = 7).

Решение по протоколу PLAN §8: доказательство не найдено за сессию — переход
к индукции H3 (§4.3, п. 3). H13-I остаётся CONJECTURED, VERIFIED
4 <= n <= 12 (было 4 <= n <= 10), SAMPLED (без контрпримера) n = 13..200.
Формула C37 и связанные сканеры сохраняются как задел для следующей попытки
H13-I, если к ней вернутся.
