  явного сдвига `docs/proofs/H10_reflections.md` (H10 на отражениях, C28)
  против независимой реализации N1 §§1-2 (`constructions/strict_upper.py`)
  и против самого варианта конструкции (`carrier_route`).
- Команда: `python3 checks/check_H10_reflections.py --exhaustive-max 80
  --lemma-bc-max 150` (значение `--sample-ns` по умолчанию:
  `150,200,201,202,203,500,501,502,503,998,999,1000,1001`). Seed не нужен —
  проверка полностью детерминирована (нет случайной выборки).

  (`constructions/strict_upper.py`), код репозитория ветки
  `claude/peaceful-hopper-q3x945`.
- Оценка скорости перед запуском (правило 10): измерено отдельно на
  n = 20 (0.1 с), n = 30/50/70 (0.38/2.6/10.1 с для теоремы, экстраполяция
  ~O(n^4) из-за `carrier_route` O(K^2) внутри O(n) сдвигов; лемма B/C —
  измерено n = 40/60/80, экстраполяция ~O(n^3.4), 9.2 с на 4<=n<=150 —
  подтвердилось на практике). По этой оценке `--exhaustive-max` ограничен
  80 (не 120, как в первой неудачной попытке — тот прогон был неверно
  оценён и остановлен вручную после подтверждения, что он не соответствует
  бюджету разумного времени сессии; уточнённая оценка после измерения дала
  безопасные параметры этого прогона).
- Тип покрытия:
  - Лемма B/C (замкнутые формулы `F(w)`, `S(w)`, `K(w)`): исчерпывающе по
    всем `w`, `4 <= n <= 150` (11 319 пар); структурная выборка `w` в
    `{0,1,2,n-1,n/2,n/2+1}` при `n` в `{150,200,201,202,203,500,501,502,503,
    998,999,1000,1001}` (78 пар) — покрывает все 4 класса `n mod 4` на
    масштабах ~200, ~500, ~1000.
  - Теорема (явный `c*`, длина слова, `R_c<=H(c)`, избыток над `B_n` не выше

    выборка `h` на тех же больших `n`.
  - Каждое слово (оба маршрута) исполнено эталонными ходами
    (`oracle/moves.py: apply_word`) и проверено, что оно сортирует вход —
    не только сравнение чисел.
- Состояний/рёбер проверено: 11 319 + 78 = 11 397 пар `(n,w)` для леммы B/C;
  сумма `h` по `4<=n<=80` (3 240) плюс 65 структурных пар `(n,h)` для
  теоремы = 3 305 перестановок, для каждой — 2 построенных и исполненных
  слова (маршрут N1 и маршрут по переносчикам) = 6 610 слов.
- Время: 307.0 с всего (9.2 с — лемма B/C исчерпывающе, 1.6 с — лемма B/C
