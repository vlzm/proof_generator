# h13i_averaging_probes — три кандидата на доказательство H13-I отвергнуты

Дата: 15.09.2026 (сессия 9). Цель: доказать H13-I (`I(pi) <= floor((n-1)^2/4)`
для всех pi, торические классы, см. `docs/notes/h13_line_model.md` §6) за
1 сессию, либо дать письменный вердикт и перейти к H3.

Команда: `python3 experiments/h13i_averaging_probes.py --nmax 9 --json-out
data/runs/h13i_averaging_probes/results_n9.json`. Версии: ядро oracle-1.0
(не используется напрямую — только модель разреза из `line_model`/C33),
h13i_averaging_probes-1.0. Детерминированный перебор, seed не требуется.

Покрытие: исчерпывающе все перестановки при 4 <= n <= 9 (24 .. 362880 входов);
для каждой — все n^2 origins (s, v0) переборa. Формула для суммы по всем n^2
origins сверена с прямым двойным циклом (брутфорс) на выборках 4 <= n <= 7
(`check_formula_matches_bruteforce`, 30 перестановок на n).

Три проверенных кандидата (см. код и `docs/notes/h13_line_model.md` §7 для
точных определений):

- A: `I(pi) <= (1/n^2) sum_{s,v0} inv(s,v0)` (совместное усреднение).
- B: `I(pi) <= min_s Avg(s)`, `Avg(s) = (1/n) sum_v0 inv(s,v0)` (точный
  минимум по v0 заменён средним; минимум только по s).
- C: `I(pi) <= min_{i0} inv(i0, pi[i0])` (origins только в самих точках
  перестановки, n штук вместо n^2).

Результат (см. `run_n8.log`, `run_n9.log`, `results_n9.json`):

| n | bound=floor((n-1)^2/4) | perms | A ok | B ok | C ok | время |
|---|---|---|---|---|---|---|
| 4 | 2  | 24     | нет (avg 3.500) | нет (avg 3.500) | нет (max 3)  | 0.0 с |
| 5 | 4  | 120    | нет (avg 6.000) | нет (avg 6.000) | нет (max 6)  | 0.0 с |
| 6 | 6  | 720    | нет (avg 9.167) | нет (avg 9.167) | нет (max 10) | 0.0 с |
| 7 | 9  | 5040   | нет (avg 13.000)| нет (avg 13.000)| нет (max 15) | 0.2 с |
| 8 | 12 | 40320  | нет (avg 17.500)| нет (avg 17.500)| нет (max 21) | 2.3 с |
| 9 | 16 | 362880 | нет (avg 22.667)| нет (avg 22.667)| нет (max 28) | 26.4 с |

Худший вход во всех трёх пробах при каждом n — ровно отражение
`pi_0 = (0, n-1, n-2, ..., 1)` (h = 0), не новое семейство (уже известно
как один из n максимизаторов `I(pi)` — §1 п. 1 заметки). У отражений
`Avg(s)` не зависит от s, поэтому кандидат B численно совпадает с A на
худшем входе.

Дополнительно (`h13i_probe5.py`, не сохранён как отдельный модуль,
воспроизводится тем же `probe_A_num` с порогом): доля перестановок, где
кандидат A превышает границу, растёт с n — 24/24, 115/120, 714/720,
4984/5040, 39832/40320 при n = 4..8 (>98% входов при n = 8). Совместное
усреднение неверно почти всегда, не только на редких экстремальных входах.

Вывод: все три кандидата отвергнуты исчерпывающе (4 <= n <= 9). Причина
неудачи одна и та же — усреднение (в любой из трёх форм) не может отличить
входы, где `I(pi)` уже равен границе (запас нулевой — отражения), от входов
с запасом, и теряет ровно там, где терять нельзя.

Следующий вопрос: по протоколу `docs/notes/h13_line_model.md` §6 — переход
к индукции H3 (PLAN §4.3), поскольку доказательство H13-I за отведённую
сессию не найдено. H13-I остаётся открытой (VERIFIED 4 <= n <= 10 по C33,
CONJECTURED в общем случае); при возврате к ней — не повторять усреднение
ни в одной из трёх форм выше (совместное по n^2, точный-минимум-по-v0 плюс
среднее-по-s, ограничение origins точками перестановки).
