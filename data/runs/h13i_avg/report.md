# h13i_avg — новый кандидат для H13-I: адаптивное усреднение по одной координате

Дата: 15.09.2026 (сессия 9). Задача: доказать H13-I (`I(pi) <= floor((n-1)^2/4)`
для всех pi, PLAN §8, `docs/notes/h13_line_model.md` §6), бюджет 1 сессия до
письменного вердикта. Итог этого прогона: **не доказано**; найден и проверен
новый нетривиальный кандидат-путь к доказательству (не пробовавшийся раньше),
подтверждённый исчерпывающе до n = 12 и эвристически до n = 100 без единого
контрпримера, но общее доказательство не найдено. Ядро/таблицы не нужны — это
чистая комбинаторика перестановок (инверсии), независимая от oracle/BFS.

## Цель и кандидат

Известно (`docs/notes/h13_line_model.md` §5): усреднение inv по всем n^2
разрезам (p0, v0) не даёт floor((n-1)^2/4) (среднее слишком велико на
sigma_n-подобных входах). В задании этой сессии предложено (и явно указано
проверить, а не считать данностью) усреднение только по ОДНОЙ координате
с адаптивным выбором другой:

```
g(p0) = min_{v0 in Z_n} inv(p0, v0)              (лучший сдвиг значений при фиксированном разрезе позиций p0)
phi(pi) = sum_{p0=0}^{n-1} g(p0)
```

**Кандидат-лемма:** `phi(pi) <= n * floor((n-1)^2/4)` для всех pi при всех
n >= 4. Если верна — H13-I следует немедленно по принципу Дирихле: у какого-то
p0 обязательно `g(p0) <= phi(pi)/n <= floor((n-1)^2/4)`, а `I(pi) <= g(p0)`.

`g(p0)` вычисляется точно за O(n log n) через телескопическую рекурренту
`inv(p0, v+1) - inv(p0, v) = n - 1 - 2*pos(v)`, где `pos(v)` — позиция значения
v в p0-развёрнутой строке (перенос значения v с ранга «наименьшее» на ранг
«наибольшее», остальной относительный порядок не меняется). Вывод и проверка
рекурренты — вручную на n = 3, 5 и по совпадению с прямым подсчётом инверсий
на всех входах ниже (расхождений не было).

Проверены также: (a) формула `f(k,m) = n(k+m) - 2km` (число разрезов (p0,v0)
из n^2, на которых пара с позиционным разрывом k и значенческим разрывом m
инвертирована) — дана в задании как факт из внешнего источника, здесь
подтверждена, а не принята как данность; (b) что более простые формы
усреднения — усреднение только по позициям без сдвига значений (только p0,
v0 = 0) и усреднение по одной антидиагонали (v0 = s − p0 при фиксированном s,
любом или лучшем s) — не работают в общем случае (см. ниже), т.е. именно
АДАПТИВНОСТЬ выбора v0 для каждого p0 отдельно даёт эффект, а не просто другая
схема усреднения.

## Код и версии

- `experiments/h13i_avg.c` (h13i_avg-1.0): исчерпывающий перебор всех
  перестановок (лексикографический порядок), для каждой — `phi(pi)` через
  рекурренту; печатает JSON с максимумом и аргмаксимумом.
- `experiments/h13i_avg.py` (h13i_avg-1.0): (1) `--verify-f` — проверка
  формулы f(k,m) случайными парами; (2) `--search` — имитация отжига
  (simulated annealing) по транспозициям, ищущая перестановку с `phi > `
  границы, для n за пределами исчерпуемого перебора; (3) `--families` —
  проверка на известных «трудных» входах из прошлых сессий (аффинные
  контрпримеры H10, единственный контрпример H10 при n = 10, отражения и их
  одиночные транспозиции).
- Ядро: не используется (чистая арифметика перестановок).

## Команды и покрытие

```
gcc -O2 -o h13i_avg experiments/h13i_avg.c
for n in 4 5 6 7 8 9 10 11 12; do ./h13i_avg $n; done   > exhaustive_n4_12.jsonl
python3 experiments/h13i_avg.py --verify-f --nmax 9 --trials 400 --seed 1 \
    --search --n 15 20 30 50 100 --iters 3000 --restarts 6 --seed 0 --families
```

Покрытие: `verify_f` — 200–330 случайных пар (i,j,vi,vj) на n = 4..9 (все n^2
разрезов проверены для каждой пары), без расхождений. Исчерпывающий перебор
`phi(pi)`: **все** перестановки при 4 <= n <= 12 (полный S_n, включая n = 11,
12 — шире прежнего покрытия I(pi) в репозитории, которое было VERIFIED только
до n = 10). Эвристика (`--search`): не исчерпывающая, явно помечена SAMPLED —
имитация отжига, 6 рестартов x 3000 шагов при n = 15, 20, 30, 50, 100 (правило 9
AGENTS.md: это поиск ошибок, не доказательство). `--families`: явный
целенаправленный набор — единственный известный в репозитории аффинный
контрпример H10 при n = 10, три ранее найденных «плохих» аффинных пары,
полный перебор аффинных (a,b) (a обратим по mod n, b in {0,1,n/2}) при
n = 10, 18, 30, и все n(n-1)/2 одиночных транспозиций отражения при
n = 20, 30, 50.

Время: n = 12 — 1203 с (20 мин) на одном ядре, 479 001 600 перестановок;
n = 11 — 88 с; n <= 10 — секунды. Поиск (search): 364 с суммарно на пять n.
Память: O(n) на перестановку, без таблиц расстояний.

## Результаты

### Исчерпуемый диапазон (4 <= n <= 12)

| n | n*floor((n-1)^2/4) | max phi(pi) (перебор) | где достигается |
|---|---|---|---|
| 4 | 8 | 8 | (0,3,2,1) |
| 5 | 20 | 20 | (0,4,3,2,1) |
| 6 | 36 | 36 | (0,5,4,3,2,1) |
| 7 | 63 | 63 | (0,6,5,4,3,2,1) |
| 8 | 96 | 96 | (0,7,6,5,4,3,2,1) |
| 9 | 144 | 144 | (0,8,7,6,5,4,3,2,1) |
| 10 | 200 | 200 | (0,9,8,7,6,5,4,3,2,1) |
| 11 | 275 | 275 | (0,10,9,...,1) |
| 12 | 360 | 360 | (0,11,10,...,1) |

Во всех случаях максимум **в точности равен** границе `n*floor((n-1)^2/4)`,
т.е. кандидат-лемма тесна (не с запасом), и достигается **ровно** на
перестановке `pi(i) = -i mod n` (фиксирует 0, обращает остальное) — это одна
из n известных экстремальных перестановок для самого I(pi) (отражения,
`docs/notes/h13_line_model.md` п. 1.1: там максимум I(pi) достигается ровно на
n отражениях). Совпадение экстремального входа с уже известным экстремальным
семейством I(pi) — сильный довод в пользу того, что кандидат-лемма
действительно является «правильной» формой факта, а не случайным совпадением
на малых n.

Отдельно проверено (см. `report.json`, `reflection_perturbations`): все
C(n,2) перестановок, отличающихся от отражения одной транспозицией, также
дают `phi <= n*floor((n-1)^2/4)` (с равенством) при n = 20, 30, 50 — граница
не нарушается и рядом с экстремумом.

### Эвристический поиск (не исчерпывающий, n = 15..100)

| n | n*floor((n-1)^2/4) | phi(отражение) | max phi (отжиг, 6x3000 шагов) |
|---|---|---|---|
| 15 | 735 | 735 | 735 |
| 20 | 1800 | 1800 | 1800 |
| 30 | 6300 | 6300 | 6300 |
| 50 | 30000 | 30000 | 30000 |
| 100 | 245000 | 245000 | 245000 |

Отжиг из случайного старта ни разу не превысил границу и не поднялся выше
значения на отражении (обычно застревает существенно ниже — отражение
оказывается изолированным глобальным максимумом, трудным для случайного
поиска, но никогда не превышаемым).

### Известные трудные входы прошлых сессий

Единственный известный в репозитории контрпример к H10 при n = 10
`(9,2,5,0,1,8,7,6,3,4)`: `phi = 152 <= 200`. Аффинные контрпримеры H10/H12
(`pi(i) = a*i+b`, n = 17,18,54 — из `docs/notes/h10_verdict.md`): все
`phi <= n*floor((n-1)^2/4)` с большим запасом (например n = 54: 29700 <= 37908).
Полный перебор обратимых (a,b mod n) при n = 10, 18, 30: **0 нарушений**.

### Проверенные более слабые (и отвергнутые) формы усреднения

Для контроля, что именно адаптивность даёт эффект (не просто «другая формула
усреднения»), проверены и **отвергнуты** исчерпывающе при 4 <= n <= 7:

- одна координата без адаптации (v0 = 0 фиксирован, только p0 варьируется):
  нарушается уже при n = 7 (`(0,5,4,3,2,1,6)`, best-over-p0 = 10 > 9);
- усреднение по одной антидиагонали (v0 = s − p0, s фиксирован или выбран
  лучшим из n значений): нарушается уже при n = 5 (`(0,2,4,1,3)`, best-over-s
  average = 5 > 4), т.е. даже выбор ЛУЧШЕЙ ОДНОЙ антидиагонали недостаточен —
  нужен по-настоящему адаптивный выбор v0 отдельно для каждого p0.

Интересное наблюдение: на самой экстремальной перестановке (отражение) её
собственный оптимум `v0(p0)` **является** одной антидиагональю
(`v0 = c − p0 mod n` с постоянным c, что следует из симметрии `pi(i) = -i`),
но для общего pi единой антидиагонали уже недостаточно — отсюда и провал
предыдущего кандидата.

## Вывод и незакрытый вопрос

Кандидат-лемма `sum_p0 min_v0 inv(p0,v0) <= n*floor((n-1)^2/4)` — новая,
нетривиальная, точная (equality ровно на n отражениях) и прошла все
проверки этой сессии (исчерпывающе 4 <= n <= 12, эвристически до n = 100,
все известные трудные семейства). **Доказательства не найдено** за отведённое
время: испробованные и не приведшие к результату направления —

1. явная формула v0*(p0) для общего pi (работает только для отражений, где
   `pi(i) = -i` даёт постоянную анти-диагональ v0 = c − p0; для общих
   перестановок оптимум v0(p0) не описывается простой формулой — проверено
   прямым выводом argmin на нескольких общих pi);
2. exchange/монотонный аргумент по соседним транспозициям (путь id ->
   reversal через n(n-1)/2 соседних транспозиций, каждая добавляющая одну
   инверсию): phi НЕ монотонна вдоль такого пути (проверено n = 4..7), хотя
   максимум вдоль пути достигается на последнем шаге (полное обращение) —
   монотонность в этой простой форме не работает, нужен другой порядок обхода
   или другой потенциал;
3. закрытая формула для суммы через рекуррентную структуру (телескопирование
   по p0 и по v0 одновременно) не выведена — минимум циклической частичной
   суммы в общем случае не имеет простого выражения через саму перестановку
   без вычисления по существу того же перебора.

Это остаётся ОТКРЫТЫМ направлением для будущей сессии (не отвергнутым, в
отличие от прежних попыток H13-I в §1.7 заметки): в отличие от чистого
усреднения по n^2 разрезам (доказанно недостаточного) и индукции по одному
элементу (не работает, контрпример n = 8), этот кандидат ни разу не нарушен
и структурно завязан на то же экстремальное семейство, что и сам I(pi).

## Следующий вопрос

Доказать (или опровергнуть на большем n) кандидат-лемму `phi(pi) <=
n*floor((n-1)^2/4)`. Перспективные направления, не испробованные в этой
сессии: (а) индукция по n через удаление одного элемента перестановки (строки
и столбца матрицы перестановки) с явной оценкой изменения phi; (б) ЛП-двойственность
или выпуклая релаксация для min_v0 inv(p0,v0) как функции от pos-перестановки;
(в) связь с известными результатами о «минимальном числе инверсий по всем
вращениям» циклической последовательности (возможно, есть в литературе по
permutation patterns / toroidal permutations — не проверялось, отдельная
задача поиска источников).
