# h13i_cut_families — проверка двух маршрутов к доказательству H13-I (сессия 9)

Цель (`docs/notes/h13_line_model.md` §6): прежде чем искать новую конструкцию
для H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi, `I(pi) = min_{q,c} inv`
по всем n^2 двойным разрезам), проверить два простых маршрута к доказательству:

1. **Усреднение по всем n^2 разрезам.** Если бы `avg_{q,c} inv(pi_{q,c}) <=
   floor((n-1)^2/4)` для всех pi, принцип Дирихле сразу давал бы H13-I без
   дальнейшей конструкции. Заметка §6 уже отмечает качественно, что это не
   работает на sigma_n и на id; здесь — точный худший случай и число
   нарушений при 4 <= n <= 9.
2. **Одномерные семейства разрезов** (n разрезов вместо n^2): (2a) только
   сдвиг значений (`q = n − 1` фиксировано, разрез позиций не используется),
   (2b) диагональ `q = c`. Обе сводят перебор к линейному числу вариантов;
   проверяется, достигают ли они `floor((n-1)^2/4)` на всех pi.

Версии: `h13i_cut_families-1.0` (`experiments/h13i_cut_families.py`), ядро
oracle-1.0. Команда: `python3 experiments/h13i_cut_families.py --nmin 4
--nmax 9`. Покрытие: исчерпывающе все pi, все n^2 разрезов, при
4 <= n <= 9 (правило 9 AGENTS.md — дёшево, сразу до 8, и 9 отдельно).
Время: n = 8 — 9.6 с, n = 9 — 123.5 с (однопоточно, чистый Python).
Память: O(1) на перестановку (перебор без хранения). Отчёты
`report_n4_8.json`, `report_n9_9.json`; полный лог `report.log`.
Сверка: `max I(pi)` совпадает с известным значением `floor((n-1)^2/4)`
(C33/line_profile) на каждом n — независимое подтверждение корректности
перебора этим скриптом.

Худшие входы обоих маршрутов при каждом n — отражение `pi_0 = (0, n−1, n−2,
…, 1)` (та же перестановка, что и худшее среднее, и один из n максимумов
I(pi); ожидаемо, т.к. отражения — известный экстремальный класс C33/C35).
Худшие входы, нарушающие семейства 2a/2b при n = 7, 8, 9 — не только
отражения (например при n = 9: `(0, 2, 7, 6, 5, 4, 3, 8, 1)` для 2a,
`(0, 1, 8, 3, 7, 6, 5, 4, 2)` для 2b).

## Вывод

1. **Маршрут 1 (усреднение) отвергнут.** Не просто на отдельных pi (sigma_n,
   id, как отмечено ранее качественно) — среднее превышает границу почти на
   всех pi: 24/24, 115/120, 714/720, 4984/5040, 39832/40320, 356364/362880
   (доля растёт к ~98%). Худшее среднее растёт как `~7n^2/12` (наблюдаемо:
   3.5, 6.0, 9.17, 13.0, 17.5, 22.67 при n=4..9), тогда как граница —
   `~n^2/4`; разрыв не убывает. Усреднение не годится ни в каком варианте
   с равномерным распределением по всем n^2 разрезам сразу.
2. **Маршруты 2a/2b (одномерные семейства из n разрезов) отвергнуты с n = 7.**
   При 4 <= n <= 6 оба совпадают с истинным I(pi) на всех входах (0
   нарушений) — задача выглядит одномерной, но это артефакт малых n.
   Начиная с n = 7 оба семейства строго слабее полного перебора (7, 16, 162
   нарушений при n = 7, 8, 9, растущая доля), и нарушители — не только
   отражения. Значит нужная свобода выбора разреза существенно двумерна;
   никакая редукция к одному параметру (в двух проверенных естественных
   формах) не работает, что согласуется с уже отвергнутыми в
   `docs/notes/h13_line_model.md` §1.7 семейством «первый элемент = t» и
   §4 (лемма C — локальные условия недостаточны).
3. Оба маршрута исключены как самостоятельное доказательство H13-I;
   необходим аргумент, использующий совместный выбор (q, c), а не только
   счётное сокращение пространства разрезов или равномерную оценку среднего.
   Следующие кандидаты — `docs/notes/h13i_verdict.md`.
