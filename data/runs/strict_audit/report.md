Худшие входы конструкции (первые): n=5 (0,2,4,1,3); n=6 (0,1,4,5,2,3);
n=7 (0,3,6,2,5,1,4); n=8 (0,2,5,7,3,1,6,4). Это худшие входы алгоритма, не

не дублируются; пример n=8: c=0: F=16, S=12, sum M=8, E=0, theta=0, H=8,
маршрут 8, локальные 20, len 28 (N_X 12, N_rot 16); c=1: F=16, S=9, sum M=5,
E=2, theta=1, H=7, len 30 (после сокращения 28); min_c bound 28, среднее
119/4, s = 21/2.

Отражения pi(i)=h-i, 4<=n<=20, min_c len - B_n: 0 при нечётном n и при
нечётном h; -1 при n=0 (mod 4), h чётном; +1 при n=2 (mod 4), h чётном.

## Вывод и следующий вопрос

Реализация N1 по тексту работает на всех проверенных диапазонах; общий
аргумент §§1–9 подтверждён аудитом (C16–C21 PROVED локально). Новое:
C9 доказано явным словом конструкции N1 (`docs/proofs/C9_sigma_upper.md`).

Следующий вопрос: карта потерь показывает, что при min по c потеря против
d(pi) в среднем растёт примерно на 1 с ростом n, а свободные сокращения
на стыках снимают около половины. Какое из направлений PLAN §4.2 — минимум
вместо среднего по c в доказательстве, учёт сокращений на стыках или
маршрут только по переносчикам — даёт оценку вида B_n + o(n)? Начать с
анализа min_c [2F_c - S_c + H(c)] против среднего на худших входах n=7, 8.
