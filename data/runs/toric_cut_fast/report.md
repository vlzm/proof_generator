# toric_cut_fast — O(n^2) вычисление I(pi), расширение C33 до n = 12

Сессия 9 (16.09.2026). Задача: продолжить H13-I (`docs/notes/h13_line_model.md`
§6) — либо доказать `I(pi) <= floor((n-1)^2/4)` для всех pi, либо дать вердикт
за 1 сессию. Полное доказательство не найдено (вердикт —
`docs/notes/h13_line_model.md` §7.4); ниже — воспроизводимые прогоны.

## Версии

Ядро не требуется (задача про `I(pi)` — чистая комбинаторика над Z_n, не
использует `oracle/moves.py`). Код: `experiments/toric_cut_fast.c`
(toric_cut_fast-1.0), `experiments/toric_cut_diag_test.c`
(toric_cut_diag_test-1.0), `experiments/toric_cut_localmax.c`
(toric_cut_localmax-1.0). Доказательство рекурсии —
`docs/proofs/D1_toric_cut_recursion.md`.

## Прогон 1 — проверка реализации (check)

Цель: подтвердить, что рекурсия D1 даёт тот же `I(pi)`, что прямой перебор
всех n^2 разрезов с прямым подсчётом инверсий (определение §0 D1).

Команда: `gcc -O2 -o toric_cut_fast experiments/toric_cut_fast.c && ./toric_cut_fast check n`
для n = 4..9. Покрытие: исчерпывающее, все перестановки. Seed: нет
(детерминированный перебор в порядке `next_perm`). Память: O(n), тривиально.

| n | perms | mismatches | время |
|---|---|---|---|
| 4 | 24 | 0 | < 0.01 с |
| 5 | 120 | 0 | < 0.01 с |
| 6 | 720 | 0 | < 0.01 с |
| 7 | 5040 | 0 | < 0.01 с |
| 8 | 40320 | 0 | < 0.01 с |
| 9 | 362880 | 0 | ~0.1 с |

Результат: 0 расхождений во всех случаях — реализация рекурсии верна.

## Прогон 2 — профиль I(pi), расширение диапазона (profile)

Цель: `max_pi I(pi)` исчерпывающе при n, недостижимых для O(n^4)-перебора
(`experiments/line_profile.c`) в разумное время.

Команда: `./toric_cut_fast profile n` для n = 9..12. Покрытие: исчерпывающее,
все n! перестановок (порядок Лемера через `next_perm`, тот же порядок, что
у `line_profile.c`/таблиц C2v). Seed: нет. Память: O(n^2) для гистограммы,
тривиально. Машина: 1 ядро (однопоточная реализация), `gcc -O2`.

| n | n! | max I | floor((n-1)^2/4) | время | argmax (rank, 0-индекс, порядок Лемера) |
|---|---|---|---|---|---|
| 9 | 362 880 | 16 | 16 | 0.104 с | 40319 |
| 10 | 3 628 800 | 20 | 20 | 1.245 с | 362879 |
| 11 | 39 916 800 | 25 | 25 | 14.5 с | 3628799 |
| 12 | 479 001 600 | 30 | 30 | 3 мин 23 с | 39916799 |

Каждый argmax — последняя перестановка в порядке Лемера при данном n
(известный отражённый вход из line_profile-семейства). Полные гистограммы
`by_I` — в выводе команды (не сохранены отдельным файлом, воспроизводимы за
секунды-минуты).

Результат: **`max_pi I(pi) = floor((n-1)^2/4)` подтверждено исчерпывающе при
4 <= n <= 12** (было 4 <= n <= 10, `data/runs/line_profile/`). Обновлена C33
(CLAIMS.md).

n = 13 (6 227 020 800 перестановок) не запускался: экстраполяция по времени
n = 9..12 (~x11–13 на переход n -> n+1 c учётом роста n^2) даёт порядка
40–60 минут; правило 10 AGENTS.md требует конкретного вопроса, который этот
прогон должен решить, — такого вопроса нет (H13-I не станет ближе к
доказательству от ещё одного подтверждённого n).

## Прогон 3 — отвергнутые сокращения перебора (diag / diag2 / fixed_a)

Цель: проверить, достаточно ли o(n^2) «дешёвых» кандидатов разреза вместо
полного перебора (a, b), для получения `inv <= floor((n-1)^2/4)` (не
обязательно оптимума, только границы).

Команда: `gcc -O2 -o diag_test experiments/toric_cut_diag_test.c && ./diag_test MODE n`
для MODE в {diag, diag2, fixed_a}, n = 4..9. Покрытие: исчерпывающее.

| n | diag (нарушений) | diag2 (нарушений) | fixed_a (нарушений) |
|---|---|---|---|
| 4 | 4 | 0 | 0 |
| 5 | 5 | 0 | 0 |
| 6 | 6 | 6 | 0 |
| 7 | 56 | 7 | 7 |
| 8 | 552 | 8 | 16 |
| 9 | 2025 | 99 | 162 |

Результат: все три REFUTED (первое нарушение при n = 4, 6, 7 соответственно;
число нарушений растёт с n). Подробности и примеры контрпримеров —
`docs/notes/h13_line_model.md` §7.2.

## Прогон 4 — попытка компрессии к отражению (localmax)

Цель: проверить лемму «pi не отражение => есть сосед по обмену соседних
значений или позиций со строго не меньшим I» — если верна, вместе с
`I(отражение) = floor((n-1)^2/4)` (точно) даёт H13-I через конечность
перебора (глобальный максимум I не может быть не-отражением).

Команда: `gcc -O2 -o localmax experiments/toric_cut_localmax.c && ./localmax n both`,
n = 4..7. Покрытие: исчерпывающее (для каждой pi с `I(pi) < bound` — все
2(n−1) соседей).

| n | нарушений (неглобальный локальный максимум) | bound |
|---|---|---|
| 4 | 1 | 2 |
| 5 | 11 | 4 |
| 6 | 123 | 6 |
| 7 | 230 | 9 |

Результат: REFUTED — контрпример уже при n = 4 (`pi = (0,2,1,3)`, I = 1,
все 6 соседей I <= 1). Не запускалось при n = 8, 9 (число нарушений уже
растёт быстро, вопрос закрыт содержательно, а не по недостатку данных).
Подробности — `docs/notes/h13_line_model.md` §7.3.

## Вывод и следующий вопрос

H13-I не доказана. Позитивный итог сессии — быстрый точный алгоритм (D1,
O(n^2)) и расширенный диапазон VERIFIED (C33, n <= 12 вместо n <= 10).
Три конкретные схемы доказательства закрыты (не повторять без изменения
предпосылок, см. `docs/notes/h13_line_model.md` §7.4): дешёвые (o(n^2))
правила выбора разреза; компрессия к отражению соседними транспозициями без
дополнительных условий на I(pi). Следующий вопрос — по PLAN §8: индукция H3,
либо компрессия §7.3 с леммой, ограниченной на pi с `I(pi)` близким к
максимуму, либо с более широким набором ходов (произвольные транспозиции).
