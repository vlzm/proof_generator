# h13_averaging_probe — одномерное усреднение для H13-I (сессия 9)

Цель: проверить кандидат «выбрать лучший разрез позиций `a`, затем взять
любой `b` не хуже среднего по `b`» как способ доказать
`I(pi) <= floor((n-1)^2/4)` без явного выбора `b` (принцип Дирихле в одной
координате). Не проверялось в сессии 8 (там — усреднение сразу по всем `n^2`
разрезам). Определения — `docs/notes/h13_line_model.md` §0, §7.1.

Команда: `python3 experiments/h13_averaging_probe.py 3 8`
(exhaustive по всем pi, всем n при 3 <= n <= 8; ядро не используется —
инверсии считаются напрямую). Версия: h13_averaging_probe-1.0.
Время: 1.2 с. Память: тривиальна. Контроль: для каждого худшего найденного
pi отдельно посчитан истинный `I(pi)` полным перебором `(a,b)` — совпадает
с C33 (`<= floor((n-1)^2/4)`), т. е. расхождение только в оценке через
среднее, не в самой величине I.

| n | `floor((n-1)^2/4)` | `max_pi min_a A(a)` | экстремальный pi | истинный `I(pi)` (контроль) |
|---|---|---|---|---|
| 3 | 1 | 1.667 | (0,2,1) | 1 |
| 4 | 2 | 3.5 | (0,3,2,1) | 2 |
| 5 | 4 | 6.0 | (0,4,3,2,1) | 4 |
| 6 | 6 | 9.167 | (0,5,4,3,2,1) | 6 |
| 7 | 9 | 13.0 | (0,6,5,4,3,2,1) | 9 |
| 8 | 12 | 17.5 | (0,7,6,5,4,3,2,1) | 12 |

Вывод: `max_pi min_a A(a)` растёт быстрее границы (уже `> 2x` избыток при
n = 8: 17.5 против 12) и не является допустимой оценкой сверху для
`min_{a,b} inv(a,b)`. Экстремальные входы — тот же класс отражений
`pi(i) = (n-1) - i`, что и в C33/C34-B. Одномерное усреднение по `b` при
оптимальном `a` не работает; вместе с полным усреднением по `n^2` разрезам
(сессия 8) и локальными условиями (лемма C, `docs/notes/h13_line_model.md`
§4) закрывает все варианты принципа Дирихле, опробованные к сессии 9. Для
экстремальных pi минимизирующий `b` должен лежать заметно ниже среднего по
`b` при любом `a` — граница держится за счёт конкретного выбора `b`, а не
за счёт "типичности" мажority сдвигов.

Следующий шаг зафиксирован в `docs/notes/h13_line_model.md` §7.4 и
`docs/notes/repo_state.md`: переход к индукции H3 (PLAN §4.3, п. 3).
