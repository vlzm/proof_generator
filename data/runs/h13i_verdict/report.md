# h13i_verdict — сессия 9 (15.09.2026)

**Цель.** Доказать, опровергнуть или закрыть письменным вердиктом H13-I:
у каждой перестановки pi ∈ S_n есть двойной разрез (поворот позиций и
значений) с не более `M = floor((n − 1)^2 / 4)` инверсиями (`I(pi) <= M`).
Бюджет — 1 сессия (PLAN §8).

**Вердикт.** Не доказана и не опровергнута. Письменный вердикт —
`docs/notes/h13i_verdict.md`. Получены: точное описание сетки разрезов
(6 доказанных лемм, из них одна отрицательная — никакое не зависящее от pi
взвешивание разрезов не может дать H13-I), одно выжившее усиление (C38),
восемь отвергнутых кандидатов с наименьшими контрпримерами и разделение
H13-I с найденной в литературе теоремой о циклической сортировке (C39).

## Результат

1. **H13-I верна при 4 <= n <= 12** (`fail_H13I = 0` во всех строках
   `scan.json`); `max_pi I(pi) = M` достигается ровно на одном торическом
   классе — классе отражений (`count_maxI = 1`). Это расширяет конечную часть
   строки C33 с n <= 10 до n <= 12.
2. **C38** (`sum_b min_a F(a,b) <= n·M`): нарушений нет при 4 <= n <= 12;
   равенство ровно на классе отражений (`count_maxS = 1`).
3. **Леммы 0–6** (`docs/notes/h13i_verdict.md` §2–3) доказаны и проверены.
   Лемма 6 — отрицательный результат: доказательство H13-I обязано выбирать
   разрез в зависимости от pi; любое семейство фиксированных взвешиваний
   должно содержать не менее n/2 элементов (не менее n при чётном n).
4. **Восемь кандидатов отвергнуты** с наименьшими контрпримерами (§4
   вердикта); все воспроизведены чекером (часть E).
5. **C39:** `cs(pi) <= I(pi)` всегда, но `cs < I` уже при n = 8
   (16 перестановок; наименьшее n равно 8). Лексикографически первая —
   `(0,3,6,1,4,7,2,5)`, `cs = 8 < 9 = I`; наибольший разрыв —
   `(0,5,2,7,4,1,6,3)`, `cs = 8 < 11 = I`. При 4 <= n <= 8
   `max_pi cs(pi) = max_pi I(pi) = M`.

## Вывод и следующий вопрос

Прямые пути «усреднение по разрезам» закрыты доказательно (лемма 6), а
найденная теорема о циклической сортировке относится к другой величине (C39),
поэтому H13-I остаётся открытой. Следующий вопрос: доказать C38, разобрав
дихотомию `mu(pi) <= M` (тривиально по лемме 3) и `mu(pi) > M`; в последнем
случае нужна нижняя оценка на `sum_b (mu − min_a F(a,b))` через структуру pi
(лемма 4 переводит её в максимум циклической корреляции перестановки с
«пилой» `r(t) = t mod n`). По PLAN §8 бюджет H13-I исчерпан; направление
сессии 10 — индукция H3 (PLAN §4.3).
