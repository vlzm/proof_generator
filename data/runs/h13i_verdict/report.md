# h13i_verdict — алгебра двойного разреза и граница свободного разреза (сессия 9)

**Цель.** Доказать или опровергнуть H13-I (`I(pi) <= floor((n−1)^2/4)`,
`docs/notes/h13_line_model.md` §6) за одну сессию; при неудаче — письменный
вердикт с конкретным следующим шагом.

**Команды.**

```text
python3 experiments/toric_cut_algebra.py --nmax 8 --free-nmax 8    # 82 с
python3 checks/check_C37.py --amax 8 --free-amax 8                 # 28 с
```

**Параметры и seed.** `--nmax 8` — исчерпывающий перебор перестановок до n = 8;
`--free-nmax 8` — исчерпывающий перебор всех `2^{n−1}` подмножеств точек до
n = 8. Случайные выборки: seed 20260916 (части 2 и 5), seed 11 (часть 7),
seed 370037 и 5150 в чекере. Структурированные наборы (`families`): все
отражения, аффинные `a i + b` с `b ∈ {0, 1, n/2}`, тождественная,
антиподальный поворот, произведение соседних транспозиций, «двойные» блоки.

**Версии.** toric_cut-1.0, check_C37-1.0, ядро oracle-1.0. Доказательство —
`docs/proofs/C37_double_cut_algebra.md`. Таблицы расстояний не используются:
утверждение чисто комбинаторное (про `I(pi)`, не про `d`).

## Результат

**1. Тождество разреза (доказано, лемма 2 C37).** Для `S(m, k) = A_m xor B_k`
(префикс позиций xor префикс значений; геометрически — две «разноимённые»
четверти сетки)

```text
inv(линии разреза (m, k)) = |Inv(pi) xor delta(S)| = inv(pi) + s(n − s) − 2 e_inv(S),
```

и в знаках `inv = B_n/2 − Q(x)/2`, `Q(x) = sum_{i<j} eps_{ij} x_i x_j`. Отсюда
H13-I равносильна: среди n^2 знаковых векторов `x(m, k)` есть один с
`Q(x) >= floor(n/2)`.

**2. Свободный разрез (доказано, теорема 5 C37).** Для произвольной знаковой
функции на парах `max_x Q(x) >= floor(n/2)`, точно (равенство при `eps ≡ −1`,
то есть на `rev_n`/`sigma_n`). Следствие: у каждой pi есть **произвольное**
подмножество S с `|Inv xor delta(S)| <= floor((n−1)^2/4)`. Константа H13-I —
это порог Эдвардса для K_n, она не улучшаема; открытая часть H13-I — только
принадлежность нужного S торическому семейству.

Конечные данные части 5 (исчерпывающе, все pi и все подмножества):

| n | `floor((n−1)^2/4)` | `max_pi min_free` | `max_pi I(pi)` | гистограмма `I − min_free` | из них аффинных |
|---|---|---|---|---|---|
| 4 | 2 | 2 | 2 | {0: 24} | — |
| 5 | 4 | 4 | 4 | {0: 120} | — |
| 6 | 6 | 6 | 6 | {0: 720} | — |
| 7 | 9 | 9 | 9 | {0: 5040} | — |
| 8 | 12 | 12 | 12 | {0: 40112, 1: 200, 3: 8} | 16 из 208 |

Восемь входов с дефектом 3 — это ровно аффинное семейство `pi(i) = 5i + b mod 8`
(`I = 11`, свободный минимум 8); семейство `pi(i) = 3i + b` даёт дефект 1
(`I = 9`, свободный минимум 8).

Чекер дополнительно: `min_pi max_x Q(x) = floor(n/2)` ровно при 4 <= n <= 8
(теорема 5 точна и в классе перестановочных знаков), и то же на 300 случайных
знаковых функциях на K_n при 4 <= n <= 10.

**3. Усреднение (доказано, лемма 4 C37; отрицательный результат).** Пара с
круговыми расстояниями `(d_p, d_v)` согласована ровно при
`(n − d_p)(n − d_v) + d_p d_v` разрезах. Среднее число согласованных пар:
`(n−1)(2n−1)/6` для `id_n` и `(n^2 − 1)/6` для `sigma_n` и `rev_n`. Порог —
`floor(n^2/4)`. Значит усреднение закрывает `id_n` при n >= 5 и **никогда** не
закрывает `sigma_n`; это уточняет запись в `h13_line_model.md` §6 (провал
усреднения — на экстремальном входе, а не на тривиальном). Доля закрытых pi:
0/24, 5/120, 6/720, 56/5040, 488/40320 при n = 4..8.

**4. Критерий H14 (следствие 5.2 C37) — REFUTED при n = 8.** Достаточное
условие: есть разрез, в линии которого каждый элемент инвертирован не более
чем с `floor((n−1)/2)` другими (при нечётном n плюс условие на множество
максимумов). При 4 <= n <= 7 такой разрез есть у всех pi; при n = 8 — ни у
одной из 16 аффинных перестановок `pi(i) = 3i + b` и `pi(i) = 5i + b mod 8`
(например `(0,3,6,1,4,7,2,5)`: `I = 9`, но `max_p inv_p >= 4` при всех 64
разрезах; `(0,5,2,7,4,1,6,3)`: `I = 11`). Наименьшее n среди проверенных 4..8.

**5. H13-I перепроверена независимым кодом**: `max_pi I(pi) = floor((n−1)^2/4)`
при 4 <= n <= 8, достигается ровно на n отражениях (4, 5, 6, 7, 8 входов при
n = 4..8); на структурированных и случайных входах при n = 20, 50, 100, 101
нарушений нет. Это согласуется с C33/C35 и не заменяет их.

## Вывод и следующий вопрос

H13-I не доказана и не опровергнута; задача сведена к вопросу о том, насколько
торическое семейство из n^2 разрезов приближает свободный оптимум. Дефект
равен нулю при 4 <= n <= 7 и не превосходит 3 при n = 8 (208 входов из 40320).
Следующий вопрос: **чем характеризуются свободные оптимумы и когда среди них
есть «двухчетвертной» (то есть торический)?** Отдельно — аффинное семейство
`pi(i) = a i + b`, замкнутое относительно торических сдвигов: там H13-I
превращается в одномерную задачу `min_b inv((a j + b) mod n) <=
floor((n−1)^2/4)` (суммы Дедекинда), и именно там живут все известные
контрпримеры к достаточным критериям. Запасной путь — индукция H3
(PLAN §4.3, п. 3), первый шаг расписан в `docs/notes/h13i_verdict.md` §5.
