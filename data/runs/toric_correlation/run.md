# Прогон toric_correlation (сессия 9, 13.09.2026)

Цель: проверить торическое тождество для `inv(q, c)` (C37, теорема A), оценку
энергии (теорема B) и следствие C, а затем исчерпывающе проверить пять
достаточных условий для H13-I, которые из тождества вытекают.

Команда: `python3 experiments/toric_correlation.py --nmax 8 --idmax 6
--random-n 12 20 30 50 80 --trials 30` (seed 20260913).
Версии: `toric_corr-1.0`; ядро ходов не используется (утверждение чисто
комбинаторное, о перестановках и разрезах, а не о словах).

Покрытие:

- теорема A — все pi и все n^2 разрезов при 2 <= n <= 6 (перебор линий и
  подсчёт инверсий парами, сверка с формулой в целых числах);
- теорема B и следствие C — все pi при 2 <= n <= 8;
- достаточные условия — все pi при 4 <= n <= 8;
- «пик отражения» на случайных pi — n = 12, 20, 30, 50, 80, по 30 выборок.

Время: 13.4 с (поле `seconds` в `report.json`), чистый Python.

Результат (`report.md`):

- теорема A: 0 расхождений на 8 + 54 + 384 + 3000 + 25920 разрезах;
- теорема B: `min E` равен границе при 2 <= n <= 8, множество равенства —
  ровно n отражений;
- следствие C: `max_pi I` = 2, 4, 6, 9, 12 при n = 4..8 против доказанной
  границы 3, 6, 9, 13, 17 (и цели H13-I 2, 4, 6, 9, 12) — нарушений нет;
- точный критерий `2n max S + E >= 2n thr` нарушений не имеет (это и есть
  H13-I, уже VERIFIED при 4 <= n <= 10);
- достаточные условия: P нарушается при n = 8 (16 pi, первая `(0,3,6,1,4,7,2,5)`),
  M — при n = 4..8, T — при n = 4, 6, 8, L — при n = 5..8, W — при n = 5, 7, 8;
- «пик отражения» на случайных pi ниже пика при n = 20, 30, 50, 80.

Артефакты: `report.json`, `report.md`, контрпримеры
`data/counterexamples/C38_peak_bound.json`.

Вывод: тождество и оценка среднего доказаны и подтверждены; ни одно из
естественных достаточных условий не годится — теорема B и любая универсальная
нижняя оценка `max S` тесны в непересекающихся режимах.

Следующий вопрос: количественная устойчивость теоремы B (если E близко к
границе, насколько pi близка к отражению) — единственная схема, согласованная
со всеми найденными контрпримерами; см. `docs/notes/h13i_verdict.md` §4.
