# h13i_axis_restricted — можно ли обойтись одной осью двойного разреза

Цель: проверить, достаточно ли для H13-I (`I(pi) <= floor((n-1)^2/4)` для всех
pi) зафиксировать одну из двух степеней свободы двойного разреза (вращение
позиций a или сдвиг значений b) и оптимизировать только вторую — что сделало
бы доказательство H13-I тривиальным (одномерная задача о циклической
последовательности). Заодно — независимая пересверка самого I(pi) <= bound
(полный перебор по (a, b)) на исчерпывающем диапазоне.

Версия: h13i_axis_restricted-1.0 (`experiments/h13i_axis_restricted.c`), не
зависит от ядра oracle (чистая комбинаторика инверсий целочисленных
последовательностей). Команда: `gcc -O2 -o h13i_axis_restricted
experiments/h13i_axis_restricted.c && ./h13i_axis_restricted n`. Исчерпывающе
по всем pi (перебор по возрастанию в лексикографическом порядке), n = 4..10;
n = 10 — 85 с (остальные — секунды).

## Результат

| n | bound = floor((n-1)^2/4) | total = n! | b_only_fail | a_only_fail | full_fail |
|---|---|---|---|---|---|
| 4 | 2 | 24 | 0 | 0 | 0 |
| 5 | 4 | 120 | 0 | 0 | 0 |
| 6 | 6 | 720 | 0 | 0 | 0 |
| 7 | 9 | 5 040 | 7 | 7 | 0 |
| 8 | 12 | 40 320 | 16 | 16 | 0 |
| 9 | 16 | 362 880 | 162 | 162 | 0 |
| 10 | 20 | 3 628 800 | 1 250 | 1 250 | 0 |

`full_fail = 0` при всех n = 4..10: подтверждает (независимой реализацией)
уже сертифицированное `I(pi) <= floor((n-1)^2/4)` (C33/C35).

`b_only_fail` и `a_only_fail` совпадают при каждом n (ожидаемо: пара
"a-only для pi" и "b-only для pi^{-1}" — один и тот же перебор с точностью до
обращения перестановки). Оба положительны начиная с n = 7 и растут:
0, 0, 0, 7, 16, 162, 1250 (доля растёт: 0.14%, 0.04%, 0.045%, 0.034% при
n = 7..10 — не убывает к нулю в этом диапазоне). Наименьший провал —
n = 7, пример `(0,5,4,3,2,1,6)` (это и есть пример леммы C заметки
`docs/notes/h13_line_model.md` §4: `min_b inv = 10 > 9` при a = 0).

## Вывод

Ни одна из двух осей двойного разреза не может быть зафиксирована заранее:
одномерное сведение H13-I к «циклической последовательности + один сдвиг»
не работает уже при n = 7, и число исключений растёт с n, а не является
конечным списком «малых n». Доказательство H13-I обязано использовать
совместный выбор (a, b) — направление «локальные условия по одной оси»
(лемма C заметки) закрыто исчерпывающе, а не одним примером.
