## Вопрос сессии (PLAN §8)

Разложить потерю доказанной оценки N1 по пунктам 1–5 §4.1 на отражениях и на
всех pi при 4<=n<=7 (расширено до n = 8, 9), выбрать направление §4.2.

## Определения

Для входа pi и каждого c из Z_n строятся слово N1 (§§2–3) и слово того же
состава с другим внешним маршрутом (вариант, правило 16 AGENTS.md):

- `H(c)` — маршрут N1 §3 (обход всех вершин), `R_c` — кратчайшая прогулка по
  Z_n из 0 в c через все переносчики нетривиальных циклов f_c (функция
  `carrier_route`, сверена с BFS по состояниям (позиция, посещённые) на всех
  3 584 случаях 2<=n<=8). Локальные слова применяются при первом посещении
  переносчика, как в N1.
- `local_len = sum |W_C| = 2F_c − S_c` (точно, N1 (2.6)); `local_d = sum d(q_C)`,
  где q_C — состояние в координатах переносчика, которое сортирует W_C
  (q_C[v_j] = v_{j+1}). Любое слово, сортирующее q_C, оставляет переносчик в
  слоте 0, поэтому `local_d` — истинная нижняя оценка локальной работы.
- `len = 2F_c − S_c + H(c) = |слово|`, `red` — длина после свободного
  сокращения; `len_R = 2F_c − S_c + R_c`, `red_R` — то же для варианта.

Цепочка величин (минимумы по всем c из Z_n):

```text
Q_avg = mean_c len = правая часть N1 (3.4) с точным s     (проверено тождество)
Q_min = min_c len  = min_c [2F_c − S_c + H(c)]             (в N1 длина = оценке)
Q_J   = min_c red;   Q_R = min_c len_R;   Q_RJ = min_c red_R
```

Потери §4.1 (c* — сдвиг с минимальной длиной, при ничьих — наименьший c):

```text
1 local     = local_len − local_d при c*      (и min_c, mean_c)
2 route     = H(c*) − R_{c*};   в цепочке: Q_min − Q_R
3 shift     = Q_avg − Q_min                     (среднее против минимума)
4 s-chain   = зазоры s → (7.3) → max((8.1),(8.2)) → (8.3) → U_n
5 junction  = len − red при c*;  в цепочке: Q_R − Q_RJ
residual    = Q_RJ − d(pi)      (композиция циклов, выбор слов, не покрытое выше)
shift + route + junction + residual = Q_avg − d(pi)     (тождество, assert)
```

Три величины п. 3 §4.1 — минимум фактической длины, минимум оценки
`2F_c − S_c + H(c)` и её среднее: в N1 первые две совпадают тождественно
(длина слова равна оценке при каждом c, C18v), поэтому «выбор сдвига» — это
ровно `Q_avg − Q_min`.

В среднем по всем перестановкам потеря выбора сдвига сидит в слагаемом F:
лучший сдвиг имеет F_c заметно ниже среднего P, а S_c и H(c) при нём в среднем
не лучше средних. Здесь полезно тождество (проверено на всех (pi, c) при
4<=n<=7): `F_c = sum_i delta_n(i − pi(i), c)`, то есть F_c — сумма круговых
расстояний от c до мультимножества {i − pi(i)}, а min_c F_c — его 1-медиана;
mean_c F_c = P (N1 §3). Это та же форма, что T_h = sum_i delta_n(pi(i) + i, h)
в N1 §5, но с разностью вместо суммы.

На отражениях картина другая. У sigma_n (все 4<=n<=12) разложение потери
сдвига `(2F, −S, H)` равно `(0, 0, P/n − 1 + 2/n)` при нечётном n,
`(0, 3/2, P/n − 2 + 2/n)` при n ≡ 0 (mod 4) и `(2, −3/2, P/n − 3/2 + 2/n)`
при n ≡ 2 (mod 4): F_c = P при всех c для нечётного n и n ≡ 0 (mod 4)
(F_c чередует P ± 1 при n ≡ 2 mod 4), S_c принимает два значения по чётности c,
и весь остаток C24 `(3.4) − B_n = n/4 + O(1)` — это усреднение стоимости
позиционирования `H̄ = n − 2 + (P+2)/n` против `H(c*) = n` (c* = 0) или
`n − 1` (c* = 1). На случайных входах F-часть даёт порядка 0.3·n^{3/2}, но эти
входы имеют малое d и для C15 не критичны; на экстремальных входах
(отражениях) критично именно усреднение H.

## Ответы по пунктам §4.1

1. **Локальные слова.** Длина W_C равна 2F − S тождественно (2.6). Против
   точного расстояния своего состояния локальное слово при лучшем сдвиге
   теряет в среднем <= 0.08 (максимум 4 при n = 8, 2 при n = 7), а минимум
   по c потери равен 0 у всех входов при n = 4, 6, 8 и <= 1 при n = 5, 7.
   Потеря локальных слов велика только на длинных циклах с большим F
   (до 8–10 на одном цикле при n = 8), которые лучший сдвиг не выбирает.
   Локальные слова — не источник зазора.
2. **Позиционирование.** H(c) против кратчайшего маршрута по переносчикам:
   при c* в среднем 1.4–2.5 (максимум n) при n <= 8; на выборках 6–24

## Вывод и выбранное направление §4.2

Зазор между доказанной оценкой U_n и лучшим словом конструкции состоит из двух
линейных частей, обе в доказательстве, не в словах: проводка §§5–9
(≈ 0.92n на sigma_n, ≈ 0.75n на случайных входах) и переход к среднему по c
в (3.4) (n/4 + O(1) на отражениях за счёт усреднения H(c); до ≈ 0.6n на худших
входах при n = 8 за счёт F). Слова при лучшем c не длиннее B_n + 2 на всех входах
4<=n<=8 и не длиннее B_n + 1 на выборках n = 20 (B_n при 50, 100). Потери самой
конструкции против d(pi) (маршрут 2.5, композиция 1.35, стыки 0.7 при n = 8)
сосредоточены на входах с малым d и не мешают C15.

Выбранное направление — **улучшать доказательство той же конструкции:
оценивать минимум по c напрямую, минуя и усреднение (3.4), и цепочку s §§5–9**
(§4.2, первый пункт: выигрыш от выбора c). Ни одна оценка s не закрывает C15
(C24), а цепочка s на отражениях теряет ещё 0.92n; прямая оценка минимума
обходит обе потери. Конкретно: поскольку `F_c = sum_i delta_n(i − pi(i), c)`,
минимум по c даёт 1-медиану мультимножества разностей вместо среднего P, а
H(c) при c около 0 равно n вместо среднего ≈ 5n/4; нужно неравенство вида

```text
H9:  min_c [2F_c − S_c + H(c)] <= B_n + 2      при всех n >= 4, pi из S_n
     (VERIFIED 4<=n<=8; SAMPLED n = 20: <= B_n + 1; n = 50, 100: <= B_n)
```

с явной оценкой снизу для S_c и H(c) при медианном c (на отражениях всё
уравнивается точно: C24 + C25). Так как +2 не даёт C15, рабочий вариант —
тот же минимум с маршрутом по переносчикам:

```text
H10: min_c [2F_c − S_c + R_c] <= B_n + 1,  после свободного сокращения <= B_n
     (VERIFIED 4<=n<=8: +1 только на отражении n = 6, h = 2; семейства до n = 12;
      SAMPLED n = 20, 50, 100)
```

R_c <= H(c) тривиально, поэтому H10 сильнее H9 на единицу, но лемма C18 о
маршруте (обход всех вершин) для R_c переписывается без изменений: локальные
слова применяются при посещении переносчика, порядок посещения не важен (3.1).
Первый шаг направления: доказать H9/H10 на отражениях (уже данные C24, C25),
затем на двухцикловых f_c; бюджет по §4.2 — 2 сессии до письменного вердикта.
Не выбрано: улучшение слов (потери слов O(1) и на лёгких входах) и H6/C22
(даёт лишь `B_n + n`).
