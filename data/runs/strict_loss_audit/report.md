# Карта потерь конструкции N1 — PLAN §4.1 (сессия 3, 2026-09-12)

Ядро oracle-1.0; конструкция strict_upper-1.0; эксперимент
`experiments/loss_map.py` (loss_map-1.0). Python 3.11, один поток, точная
арифметика (Fraction). Расстояния d(pi) — сертифицированные таблицы
`data/tables/dist_n{4..10}` (C2v).

## Вопрос

Какое слагаемое доминирует в `min_c[2F_c - S_c + H(c)] - d(pi)` при n = 7, 8
и как оно ведёт себя на выборках n = 20, 50, 100 (PLAN §8)?

## Определения (все величины точные)

Для входа pi и каждого сдвига c из Z_n строится слово N1 (§§2–3) и слово
того же состава с другим внешним маршрутом:

- `H(c)` — маршрут N1 §3 (обход всех вершин; H(0) = n, иначе n + delta(0,c) - 2).
- `R_c` — кратчайшая прогулка по окружности Z_n из позиции 0 в c через все
  переносчики нетривиальных циклов f_c (дуга, дополнительная к одному
  промежутку между требуемыми точками, или полный круг). Функция
  `carrier_route` сверена с перебором BFS на 3 584 случаях 2 <= n <= 8.
  Локальные слова применяются при первом посещении переносчика, как в N1.

Цепочка величин (минимумы — по всем c из Z_n):

```text
Q_avg = mean_c [2F_c - S_c + H(c)]      правая часть N1 (3.4) до §§5–8
Q_min = min_c  [2F_c - S_c + H(c)]      = min_c длины сырого слова N1
Q_R   = min_c  [2F_c - S_c + R_c]       маршрут только по переносчикам
Q_RJ  = min_c  reduced_len(слово с маршрутом R_c)   плюс свободное сокращение
Q_J   = min_c  reduced_len(слово N1)                только сокращение
```

Потери в порядке PLAN §4.1: `shift = Q_avg - Q_min`, `route = Q_min - Q_R`,
`junction = Q_R - Q_RJ`, `residual = Q_RJ - d(pi)`. Сумма четырёх равна
`Q_avg - d(pi)`. Порядок разложения влияет на слагаемые route/junction
(сокращения на разных маршрутах различны), поэтому `Q_J` записан отдельно.
Дополнительно: `slack_U = U_n - Q_avg` (запас переходов §§5–9 N1 вместе
с округлением), `slack_73 = s - rhs(7.3)`.

Маршрут R_c и сокращённые слова — варианты конструкции (AGENTS.md правило 16):
леммы N1 на них не переносятся, здесь они только измерены. Все построенные
слова исполнены эталонными ходами и сортируют вход (assert), при n = 50, 100
тоже.

## Ответ на вопрос §8

1. **Доминирует слагаемое «минимум против среднего по c».** При n = 7, 8 оно
   даёт 6.2 и 8.1 из 4.1 + 6.2 = 10.3 и 5.4 + 8.1 = 13.5 средней потери
   `Q_avg − d`; на выборках растёт как `~2.7n` (28, 97, 265 при n = 20, 50, 100),
   максимум — как `~7n`. Оно — единственное линейно растущее слагаемое.
   Иначе: усреднённое выражение (3.4) даже с точным s лежит на `Theta(n)`
   выше лучшего слова той же конструкции.
2. **Маршрут** — второе слагаемое: 2.9 и 3.4 при n = 7, 8; на выборках 7, 21,
   34 (сублинейно, растёт медленнее n: в случайных f_c переносчиков мало, но
   они разбросаны, и прогулка экономит лишь самый большой промежуток).
   Максимум по выборке достигает 0.8n при n = 100.
3. **Стыки** — O(1): среднее 0.5–0.9 при всех n, максимум 6.
4. **Остаток** после трёх слагаемых при n = 8 — 1.35 в среднем, максимум 8;
   он — потеря самих локальных слов и выбора циклов против d(pi), не
   объясняемая ни одним из трёх слагаемых.

Разница `slack_U` (переходы §§5–9 плюс округление) растёт как `~0.78n`
(U_n − B_n = (kappa−1)n + O(1) ≈ 0.17n добавляется к линейному слагаемому 1).
Итого при больших n: `U_n − d` ≈ (потеря выбора сдвига ~2.7n среднее)
+ (§§5–9 ~0.8n) − (запас против B_n); конструкция при min по c не хуже
`B_n − 4` на выборках n = 50, 100 (максимум по 40 входам; это не оценка).

## Наблюдение (данные, не утверждение)

С маршрутом только по переносчикам минимум по c величины
`2F_c − S_c + R_c` не превосходит B_n **на всех** перестановках при
n = 4, 5, 7, 8, 9 и не превосходит B_n + 1 при n = 6. Единственный вход с B_n + 1
при n = 6 — отражение `pi = (2,1,0,5,4,3)` (h = 2): все шесть
сдвигов дают ровно 16 (F, S, R по сдвигам: c чётные — 8, 6, 6; c нечётные —
10, 9, 5); d(pi) = 14. Тот же избыток +1 у отражений при n = 10, h = 2, 4
(n = 2 mod 4, h чётно, как в `data/runs/strict_audit/report.md`); свободное
сокращение снимает у них 2, и `Q_RJ <= B_n` на всех проверенных входах
(все перестановки n <= 8, семейства n <= 10, выборки n = 20, 50, 100).

Входы с `Q_R = B_n` при n = 7 — три отражения (h = 1, 2, 3; d = 21, 20, 19);
при n = 8 — два отражения (h = 1, 3) и восемь неотражений с d = 18 или 20
(например `(0,1,5,7,2,6,4,3)`, `(2,6,0,3,7,5,4,1)`): на них конструкция
теряет 8–10 ходов против d, но остаётся в B_n.

Среднее по c того же выражения `mean_c[2F_c − S_c + R_c]` превышает B_n
(максимум избытка 1/2, 0, 1, 6/7, 2 при n = 4..8): усреднение по c не
удерживает B_n даже с маршрутом по переносчикам, минимум — удерживает.

## Вывод и выбранное направление §4.2

Слагаемое «минимум против среднего по c» — единственное линейное; оно же
включает известный остаток n/4 на отражениях (C24). Переход к минимуму в
доказательстве — направление «улучшать доказательство той же конструкции»
из §4.2, но данные показывают, что даже у минимума маршрут H(c) стоит ещё
заметную величину (в среднем 3.4 при n = 8, до 0.8n на выборке n = 100), а с маршрутом по
переносчикам минимум по c уже не превышает B_n (+1 на одном семействе)
на всём проверенном диапазоне.

Выбранное направление: **вариант конструкции с маршрутом только по
переносчикам и оценка минимума по c**, то есть гипотеза

```text
H8:  min_c [2F_c - S_c + R_c] <= B_n + 1   при всех n >= 4, pi из S_n
     (равенство B_n + 1 только на отражениях n = 2 mod 4, чётное h, по данным n <= 10),
```

а с последующим свободным сокращением `<= B_n`. Первый шаг — доказательство
`R_c <= H(c)` тривиально; содержательная часть — почему минимум по c
выражения `2F_c − S_c + R_c` укладывается в B_n, тогда как среднее по c —
нет (избыток до 2 при n = 8). Кандидат-механизм: при сдвигах с большим F_c
переносчиков мало и R_c мал; при сдвигах с малым F_c маршрут длинный, но
2F_c − S_c мал. Гипотеза проверена на всех перестановках n = 9 (режим `--h8`, 322 с):
исключений нет. Записана как H8 (PLAN §0) и C25 (CLAIMS.md), CONJECTURED.
