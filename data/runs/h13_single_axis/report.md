# h13_single_axis — одноосное вращение недостаточно для H13-I (сессия 9)

Цель: проверить, сводится ли H13-I (`I(pi) <= floor((n-1)^2/4)` для двойного
разреза `(q, c)`, C33/C35) к оптимизации только ОДНОГО параметра разреза —
что дало бы гораздо более простую (одномерную, n вариантов вместо n^2)
задачу и путь к доказательству через классическую комбинаторику циклических
последовательностей.

Версия: h13_single_axis-1.0 (`experiments/h13_single_axis.c`, C), ядро
не требуется (инверсии считаются напрямую/через Фенвика, без oracle/moves.py,
т.к. вопрос чисто комбинаторный — про I(pi), не про d(pi)). Команда:
`gcc -O2 -o h13_single_axis experiments/h13_single_axis.c &&
./h13_single_axis n [rotate|shift|both]`. Исчерпывающе по всем pi
(лексикографический порядок), обе поставленные ниже величины.

Два однопараметрических семейства (частные случаи общего разреза `w_j =
pi(q+1+j) - (q+1-c) mod n` из `experiments/line_model.py`):

- `rotate`: `c = q+1` (без вычитания/mod по значениям) — n вращений сырой
  последовательности pi как есть.
- `shift`: `q = n-1` (без вращения позиций) — n сдвигов значений с mod n
  (`w_j = (pi(j)+c) mod n`).

Гипотеза перед экспериментом: если max_pi min по одному из этих n-выборов
уже равен `floor((n-1)^2/4)` (совпадает с C33 для полного разреза n^2), то
H13-I сводится к одномерной задаче.

## Результат: REFUTED для обоих семейств, начиная с n = 7

| n | B_n | floor((n-1)^2/4) | max_pi min (rotate) | max_pi min (shift) |
|---|---|---|---|---|
| 4 | 6 | 2 | 2 | 2 |
| 5 | 10 | 4 | 4 | 4 |
| 6 | 15 | 6 | 6 | 6 |
| 7 | 21 | 9 | **10** | **10** |
| 8 | 28 | 12 | **13** | **13** |
| 9 | 36 | 16 | **17** | **17** |
| 10 | 45 | 20 | **23** | **23** |
| 11 | 55 | 25 | **28** | **28** |
| 12 | 66 | 30 | **33** | — (не считалось, O(n^2) на разрез слишком дорого) |

Полный вывод в `output.txt` (все n, оба режима, худшие примеры).
Время: rotate экспоненты (O(n) на pi через инкремент Фенвика) — n = 11: 2.9 с,
n = 12: 36 с; shift (O(n^2) на pi, прямой подсчёт инверсий на каждый из n
сдвигов) — n = 11: 87 с, n = 12 не считался (оценка > 15 мин).

Оба семейства дают буквально одинаковый максимум при каждом n (не только
похожий порядок роста — совпадают числа), и на n = 7, 8 — даже один и тот же
худший вход `(0,5,4,3,2,1,6)` / `(0,6,5,3,4,2,1,7)`. Похоже на пару,
связанную инволюцией (обратная перестановка/транспонирование ролей позиция
<-> значение), но это отдельный вопрос, не требуется для вывода ниже.

Контрольная сверка: для тех же худших входов совместная оптимизация по
`(q, c)` (полный разрез, n^2 вариантов, `experiments/line_profile.c` /
прямой перебор) даёт `I(pi) <= floor((n-1)^2/4)`, т.е. запас, потерянный при
фиксации одного параметра, восстанавливается только совместным выбором
обоих. Пример n = 7, `pi = (0,5,4,3,2,1,6)`: `rotate`/`shift`-минимум = 10,
но `I(pi) = 8` (прямой перебор всех 49 разрезов, проверено отдельно),
то есть совместный выбор даёт запас 2, а не только закрывает разрыв в 1.

## Вывод

Ни `rotate`, ни `shift` по отдельности не воспроизводят C33 уже при n >= 7:
разрыв (`{1,1,1,3,3,3}` при n = 7..12) не исчезает и не выглядит ограниченным
константой малого размера — растёт (хотя и медленно). Значит H13-I
существенно требует СОВМЕСТНОГО выбора обоих параметров разреза; ни одна
чисто одномерная редукция (вращение только по позициям с натуральным
порядком значений, ни вращение только по значениям с фиксированным
порядком позиций) недостаточна. Это исключает путь «сведение к классической
теореме о циклических перестановках и инверсиях при одном вращении» —
такой теоремы для нужной константы `floor((n-1)^2/4)` при одном вращении
попросту нет (сам факт неверен). Согласуется с уже известными в
`docs/notes/h13_line_model.md` §1.7 и §4 отрицательными результатами
(усреднение по n^2 разрезам, индукция по одному элементу, локальные условия
лемма C) — все они тоже указывают на то, что H13-I не распадается на
независимые под-задачи по q и по c.

Следующий вопрос: доказательство H13-I (если оно есть) должно явно
использовать совместность выбора (q, c) — например, выбирать c как функцию
уже выбранного q (или наоборот) по структуре pi, а не независимо/по
симметрии. См. `docs/notes/h13_line_model.md` §7 (сессия 9) для леммы D
(точное тождество вращения, использованное в этом эксперименте) и
итогового вердикта сессии.
