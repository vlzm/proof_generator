# torus_avg-1.0 — mean of M(a), H13-I route (session 9)

Command:
```
python3 experiments/torus_avg.py --nmin 2 --nmax 9
python3 experiments/torus_avg.py --sample 10,12,15,20,30,50 --trials 500 --seed 12345
python3 experiments/torus_avg.py --sample 80,100 --trials 300 --seed 777
```
Ядро: не используется (чистая комбинаторика перестановок, без oracle/BFS).
Версия скрипта: torus_avg-1.0. Формула `M_fast` сверена с прямым перебором
(`M_brute`, все b) и с полным перебором двух разрезов (`I` через все n^2 пар
(a,b)) на 3000+200 случайных входах при 2<=n<=11 (`self_check`, PASS при
каждом запуске).

## Что проверяется

`M(a) = min_b inv(вращение pi на a, вращение значений на b)` — минимум
инверсий при фиксированном вращении позиций a. Тривиально
`I(pi) = min_a M(a) <= mean_a M(a)`, поэтому оценки `mean_a M(a) <=
floor((n-1)^2/4)` достаточно для H13-I. Замкнутая форма `M(a)` (вывод —
докстринг `experiments/torus_avg.py`): телескопическая рекурсия
`inv(x, b+1) = inv(x, b) + (n-1-2p_b)`, `p_b` — позиция значения b в x;
отсюда `M(a) = min_{0<=k<=n} [inv(x,0) + k(n-1) - 2 P(k)]`, `P(k)` — сумма
позиций k наименьших значений.

## Результаты

Исчерпывающе 2 <= n <= 9 (все перестановки, `itertools.permutations`):

| n | target = floor((n-1)^2/4) | max mean_a M(a) | достигается на (перестановках) |
|---|---|---|---|
| 2 | 0 | 0.0 | 2 (все) |
| 3 | 1 | 1.0 | 3 (все) |
| 4 | 2 | 2.0 | 4 |
| 5 | 4 | 4.0 | 5 |
| 6 | 6 | 6.0 | 6 |
| 7 | 9 | 9.0 | 7 |
| 8 | 12 | 12.0 | 8 |
| 9 | 16 | 16.0 | 9 |

Максимум всегда равен target ровно (не строго меньше), и число перестановок,
на которых он достигается, равно ровно n при каждом n — совпадает со счётом
отражений (n отражений `pi(i) = h - i mod n`, h = 0..n-1; C33: `max_pi I(pi) =
floor((n-1)^2/4)` достигается ровно на n отражениях). Аргмакс при каждом n —
отражение `pi(i) = -i mod n` (h = 0), не проверено, что это единственный тип
аргмакса (не нужно для верхней оценки).

Выборочно (все n отражений + до 20 соседних транспозиций на отражение +
300-3000 случайных): n = 10, 12, 15, 20, 30, 50, 80, 100 — максимум найденного
`mean_a M(a)` равен target ровно на каждом n (достигается отражениями),
ни одного превышения не найдено.

## Два отвергнутых упрощения (воспроизводимо)

`python3 experiments/torus_avg.py --mode single_b --nmin 2 --nmax 8` —
`M(x)` без вращения позиций (a=0, для ЛЮБОЙ строки x, не только вращений pi)
превышает target уже при n=7 (10 > 9, `x=(0,5,4,3,2,1,6)`) и n=8
(13 > 12, `x=(0,6,5,3,4,2,1,7)`) — REFUTED.

`python3 experiments/torus_avg.py --mode diagonal --nmin 2 --nmax 8` —
семейство `n` разрезов `(a, pi(a))` вместо `n^2` превышает target уже при
n=4 (3 > 2) и растёт как `~n^2/2` на разворотах с неподвижной точкой
(21 > 12 при n=8) — REFUTED резко.

Оба разбираются подробнее в `docs/notes/h13_line_model.md` §7.2–7.3.

## Вывод

Гипотеза H13-I'' (`mean_a M(a) <= floor((n-1)^2/4)` для всех pi, равенство
только на отражениях) не опровергнута; данные точно совпадают с известным
максимумом `I(pi)` (C33) на отражениях, что естественно: при `I(pi)` = max
все n `M(a)` уже должны быть >= target по H13-I, и `mean = target` означает
все n значений `M(a)` равны target одновременно (не только их минимум) —
самое жёсткое возможное совпадение среднего и минимума, отдельно
подтверждено (см. `docs/notes/h13_line_model.md`, раздел H13-I'',
`sanity2`-проверка в докстринге). Гипотеза H13-I'' влечёт H13-I (`min <=
mean`), но сама не доказана: нужна оценка суммы n значений `M(a)`,
имеющих явную замкнутую форму — кандидат для следующей сессии.
