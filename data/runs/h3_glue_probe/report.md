# h3_glue_probe — сессия 9 (15.09.2026), проба по H3

**Цель.** Первое измерение для индукции H3 (PLAN §4.3, п. 3): годится ли
«склейка соседней пары» как вложение задачи n − 1 в задачу n при нулевом
запасе рекурренты `T_n <= T_{n−1} + (n − 1)`. Это проба, а не вердикт:
бюджет сессии 9 был отдан H13-I.

**Код и версии.** `experiments/h3_glue_probe.py` (h3_glue_probe-1.0), ядро
oracle-1.0 (`apply_move`); расстояния считаются собственным BFS по
генераторам L, R, X, а не читаются из таблиц (самопроверка: полученные `D_n`
равны 6, 10, 15, 21, 28 при n = 4..8, что совпадает с `B_n` и со строкой C2v).

**Команда.** `python3 experiments/h3_glue_probe.py --nmax 8` (0.4 с).
Параметры: `--nmax 8`. Seed не используется (детерминированный полный обход).

**Покрытие.** Исчерпывающе, 4 <= n <= 8: все `n!` состояний (24, 120, 720,
5040, 40320), все 3 ребра на состояние (BFS от тождественной, многоисточниковый
BFS от множеств склеенных состояний, ковшовая Дейкстра с начальными
потенциалами). Проверено состояний 46 234, рёбер ≈ 139 тыс. на каждый из
четырёх обходов.

**Время и память.** 0.4 с суммарно; при n = 8 — 40 320 состояний в словарях
Python (≈ 60 МБ пик).

**Результат.**

| n | бюджет n−1 | A: S, E, R | B: S, R | обход до `G_B` на кратчайшем слове |
| --- | --- | --- | --- | --- |
| 4 | 3 | 3, 2, 5 | 1, 4 | 0 |
| 5 | 4 | 4, 4, 6 | 3, 4 | 0 |
| 6 | 5 | 5, 6, 8 | 3, 5 | 0 |
| 7 | 6 | 6, 7, 10 | 5, 6 | 0 |
| 8 | 7 | 8, 9, 13 | 5, 8 | 0 |

1. Схема A (склейка именно `(n−1, 0)`, контракция — удаление значения `n−1`)
   **опровергнута**: `R(n) > n − 1` начиная с n = 4, перерасход растёт
   (+2, +2, +3, +4, +6).
2. Схема B (склейка любой пары `(v, v+1)`) даёт `R − (n−1)` =
   +1, 0, 0, 0, +1; свидетель при n = 8 — `(0,3,5,7,2,6,4,1)`.
3. У каждого состояния при 4 <= n <= 8 есть кратчайшее слово, проходящее
   через склеенное состояние схемы B (обход ровно 0 для всех pi).

**Артефакты.** `data/runs/h3_glue_probe/probe.json`,
заметка `docs/notes/h3_induction_start.md`.

**Вывод и следующий вопрос.** Фиксированная выделенная пара как вложение не
годится (то же, что с одноэлементной редукцией для `I(pi)`); склейка
произвольной соседней пары промахивается ровно на 1 при n = 4 и n = 8, причём
только из-за грубой оценки `d_{n−1}(c_B) <= B_{n−1}` для всех склеенных
состояний. Следующий вопрос: измерить `max E(sigma)` по слоям
`d_{n−1}(c_B(sigma))` и построить явную имитацию слова задачи n − 1 с учётом
пересечений суперъячейки головой.
