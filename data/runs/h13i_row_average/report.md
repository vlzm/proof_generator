# H13-I, сессия 9: проверка гипотезы «среднее по строкам»

Дата: 14.09.2026. Коммит на момент запуска: 00f69c1 (родитель этой сессии).
Ядро: не задействовано (задача — чистая комбинаторика над двойными
разрезами, та же модель `inv(q,s)`, что в `experiments/line_model.py` /
`experiments/line_profile.c`; таблицы расстояний не используются).

## Цель

Проверить новую гипотезу, найденную в этой сессии при попытке доказать
H13-I совместными сдвигами (см. `docs/notes/h13_line_model.md` §7):

> `sum_{q=0}^{n-1} I(q) <= n * floor((n-1)^2/4)`, где `I(q) = min_s inv(q,s)`
> — минимум инверсий по разрезу значений при фиксированном разрезе позиций q.

Эта гипотеза сильнее H13-I: по принципу Дирихле `min_q I(q) <= (1/n) sum_q
I(q)`, так что при её выполнении `I(pi) = min_{q,s} inv(q,s) <=
floor((n-1)^2/4)` для той же pi — H13-I следует напрямую. Гипотеза НЕ
доказана (см. заметку, §7.4); эта проверка — только численное
подтверждение до диапазона, недостижимого прежними прогонами H13
(`experiments/line_model.py`/`line_profile.c` останавливались на n = 9/10).

## Команда и параметры

```
gcc -O2 -o h13i_row_average experiments/h13i_row_average.c
./h13i_row_average n        # для n = 4..11, лексикографический перебор всех n! перестановок
python3 experiments/h13i_probe.py --nmax 9   # части 1-4 (тождества, sanity closed-form, python-версия части 3, отвергнутые семейства)
```

Без seed — оба скрипта детерминированы для частей exhaustive; часть 1 при
n = 8, 9, 12 использует 300 случайных перестановок с `random.seed(1)`,
часть 2 при n = 8, 9 — 200 случайных с `random.seed(2)` (см. заголовки
функций в `h13i_probe.py`).

## Покрытие и результат

`experiments/h13i_row_average.c` (h13i_row_average-1.0), исчерпывающий
перебор всех перестановок, замер стенных часов на 4 ядрах (однопоточная
программа), память — O(n) на перестановку (не измерялась отдельно,
заведомо мала: только массивы размера n):

| n | floor((n-1)^2/4) | n*bound | перестановок | нарушений | max избыток | время |
|---|---|---|---|---|---|---|
| 4 | 2 | 8 | 24 | 0 | 0 | 0.003 с |
| 5 | 4 | 20 | 120 | 0 | 0 | 0.004 с |
| 6 | 6 | 36 | 720 | 0 | 0 | 0.004 с |
| 7 | 9 | 63 | 5 040 | 0 | 0 | 0.005 с |
| 8 | 12 | 96 | 40 320 | 0 | 0 | 0.034 с |
| 9 | 16 | 144 | 362 880 | 0 | 0 | 0.344 с |
| 10 | 20 | 200 | 3 628 800 | 0 | 0 | 4.38 с |
| 11 | 25 | 275 | 39 916 800 | 0 | 0 | 60.4 с |

Сырой вывод — `output.txt` в этой директории. Во всех восьми диапазонах
максимум `sum_q I(q)` достигается ровно на равенстве (`worst_excess = 0`,
т. е. `sum_q I(q) = n*floor((n-1)^2/4)` точно) и ровно на входе
`pi(i) = -i mod n` (одно из n вращений sigma_n/отражений); при этом (см.
раздел ниже) `I(q) = floor((n-1)^2/4)` для КАЖДОГО q на этом входе, не
только в среднем.

`experiments/h13i_probe.py --nmax 9` (без C, часть 3 дублирует то же
утверждение в Python при 4 <= n <= 8 — согласуется с таблицей выше построчно):
полный вывод — `probe_output.txt` в этой директории.

Дополнительно в `h13i_probe.py`:

- Часть 1 (новые тождества градиента, см. заметку §7.2): подтверждены без
  единого расхождения — исчерпывающе 4 <= n <= 7 (все перестановки, все
  (q,s)), выборочно (300 случайных перестановок) при n = 8, 9, 12.
- Часть 2 (замкнутая форма `I(q) = inv(a) - max_s M(s)` против прямого
  перебора по s): совпадает без расхождений — исчерпывающе 4 <= n <= 7,
  выборочно (200 случайных) при n = 8, 9. Эта форма и есть то, что
  реализует `h13i_row_average.c`, отсюда её нужно было проверить отдельно
  перед доверием к C-версии.
- Часть 4 (три явных неадаптивных семейства из ~n разрезов вместо
  истинного минимума по s): все три ОПРОВЕРГНУТЫ уже при n = 4 —
  диагональ `s = q + t` ни при каком общем для всех pi значении t не
  укладывается в `n*bound` (при n = 4 уже 4 из 24 pi не имеют ни одного
  подходящего t); семейство «старт = 0» нарушает границу на всех четырёх
  отражениях n = 4 (сумма 12 против границы 8); минимум по одному
  фиксированному столбцу нарушает границу почти всегда (24 из 24 при
  n = 4). Точные числа по всем n = 4..8 — в выводе и в самой заметке.

## Вывод

Численно, исчерпывающе при 4 <= n <= 11 (существенно шире диапазона
n <= 10, в котором и так уже была проверена сама H13-I в сессии 8):
гипотеза `sum_q I(q) <= n*floor((n-1)^2/4)` верна и точна на отражениях.
Доказательства нет (см. `docs/notes/h13_line_model.md` §7.4 — почему три
естественных способа сделать это конструктивным не работают, и почему
доказательство не может быть «по строке», раз Лемма C уже даёт строку с
`I(q) = 10 > floor(36/4) = 9` при n = 7). Численная проверка САМОЙ H13-I
(не только этой более сильной гипотезы) для 4 <= n <= 11 не выполнялась
отдельно в этой сессии — она следует из данного результата как частный
случай (принцип Дирихле), и для 4 <= n <= 10 уже была VERIFIED в сессии 8
(`experiments/line_profile.c`, C33/C35).

## Следующий вопрос

Доказать (или опровергнуть на большем n) `sum_q I(q) <= n*floor((n-1)^2/4)`
напрямую — вероятно, через амортизационный/телескопирующий аргумент по
рекуррентам `Delta_q` и `Delta_s`, а не через явное неадаптивное семейство
разрезов (все проверенные варианты последнего опровергнуты). Расширять
перебор дальше n = 11 неоправданно без такой идеи (n = 12 — по грубой
экстраполяции времени, x12 от 60 с ~ 12 минут; не запущено в этой
сессии, правило 10 AGENTS.md).
