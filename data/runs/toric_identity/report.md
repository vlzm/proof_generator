# toric_identity — тождество Кендалл–Спирмен, максимум среднего, усреднённые формы H13-I (сессия 9)

Цель: найти структуру величины `I(pi) = min_{a,b} inv(w^{a,b})` (H13-I), пригодную
для общего доказательства: (1) проверить точное тождество между числом инверсий
и суммой квадратов смещений на торическом классе; (2) найти максимум среднего
`A(pi)` по всем n^2 разрезам и семейство, на котором он достигается;
(3) проверить усреднённые формы H13-I (по одной координате и по «прямым»
разрезов), которые могли бы заменить максимум.

Версии: `toric_identity-1.0` (`experiments/toric_identity.py`), Python 3.11,
без ядра ходов и без таблиц (задача чисто комбинаторная: перестановки, инверсии).
Seed не используется (полный перебор). Память — O(n^2).

Команды:

```text
python3 experiments/toric_identity.py --nmax 8                              (3.4 с)
python3 experiments/toric_identity.py --nmin 9  --nmax 9  --skip_lines      (7.2 с)
python3 experiments/toric_identity.py --nmin 10 --nmax 10 --skip_lines
                                      --identity_sample 20                  (83 с)
```

Покрытие: исчерпывающее по всем pi при 4 <= n <= 10 (24 … 3 628 800 входов),
для каждой pi — все n^2 разрезов. Тождество (пункт 1) проверяется прямым
подсчётом `D2` на выборке pi каждого n (24 … 3616 входов, все n^2 разрезов);
независимая полная проверка тождества и лемм — `checks/check_C37.py`.
Пункт «семейства-прямые» считался при 4 <= n <= 8 (при n >= 9 отключён флагом
`--skip_lines` как дорогой и уже опровергнутый).

Выход: `raw.md`, `raw_n9.md`, `raw_n10.md` (печать скрипта), `report*.json`.

## Результаты

1. **Тождество (C37).** `inv(a, b) − D2(a, b)/n` одинаково для всех n^2 разрезов
   и равно `(n^2 − 1)/12 − W/n^2`, `W = sum_{i,j} f(j − i) f(pi(j) − pi(i))`,
   `f(t) = (t mod n) − (n − 1)/2`. Нарушений нет ни у одной проверенной pi.
   Доказано для всех n: `docs/proofs/C37_toric_identity.md`.

2. **Максимум среднего (C38).** Для 4 <= n <= 10

   | n | max n^2 A(pi) | n^2 (n−1)(2n−1)/6 | число argmax | все отражения |
   |---|---|---|---|---|
   | 4 | 56 | 56 | 4 | да |
   | 5 | 150 | 150 | 5 | да |
   | 6 | 330 | 330 | 6 | да |
   | 7 | 637 | 637 | 7 | да |
   | 8 | 1120 | 1120 | 8 | да |
   | 9 | 1836 | 1836 | 9 | да |
   | 10 | 2850 | 2850 | 10 | да |

   Совпадает с доказанным `A(pi) <= (n−1)(2n−1)/6`, равенство — ровно отражения.
   Следствие `I(pi) <= floor((n−1)(2n−1)/6)` = 3, 6, 9, 13, 17, 22, 28 при
   n = 4..10 (для сравнения `M_n` = 2, 4, 6, 9, 12, 16, 20).

3. **Усреднение по одной координате (C39, конечные данные).**
   `(1/n) sum_a min_b inv(a, b) <= M_n` при 4 <= n <= 10; равенство достигается
   ровно на n отражениях (4, 5, 6, 7, 8, 9, 10 входов). Это усиление H13-I;
   общего доказательства нет.

4. **Семейства-прямые — опровергнуты.** Минимум по всем наклонам mu и смещениям c
   от `avg_a inv(a, mu a + c)` (и по столбцам) превышает `M_n`:
   у 0, 25, 72, 343, 1152 перестановок при n = 4..8; худшие входы —
   n = 5 `(0,2,1,4,3)` 22/5; n = 6 `(0,2,5,1,4,3)` 19/3; n = 7 `(0,2,4,1,6,5,3)` 68/7;
   n = 8 `(0,3,6,2,1,7,5,4)` 13.

5. **Уточнение вторым моментом** `A − 6 Var/(n^2 − 1)` на отражениях:
   2.6, 4.8, 7.6, 11, 15, 19.6, 24.8, 30.6, 37 при n = 4..12 против
   `M_n` = 2, 4, 6, 9, 12, 16, 20, 25, 30 — строго лучше среднего (`n^2/3`),
   но не доходит до `n^2/4` (асимптотика ≈ `0.30 n^2`).

Контрпримеры: только к отвергнутым формам (пункт 4 и одномерная форма
`max_a min_b inv`: 10 > 9 при n = 7, вход `(0,1,6,5,4,3,2)`; 13 > 12 при n = 8,
вход `(0,1,7,6,4,5,3,2)`). Контрпримеров к H13-I, C37, C38, C39 нет.

Вывод и следующий вопрос: равномерное усреднение исчерпано и даёт ровно `n^2/3`
(C38, точно); цель `n^2/4` требует оценки колебания `inv` по разрезам. Ближайший
объект — C39 (усреднение по одной координате: тесное, с тем же случаем равенства).
Разбор — `docs/notes/h13_line_model.md` §7.
