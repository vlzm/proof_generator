# h13i_diagonal — три сведения H13-I к одному параметру, отвергнуты

Цель: проверить, достаточно ли для доказательства H13-I (`I(pi) <=
floor((n-1)^2/4) =: M` для всех pi) одного свободного параметра из двойного
разреза `(q, c)`, вместо совместного перебора по обоим — три конкретных
кандидата, подсказанных структурой Леммы D (docs/notes/h13_line_model.md §7):

1. `I_shift0(pi)` — разрез фиксирован на диагонали `s = q + 1 - c = 0`
   (значения не переразмечаются, меняется только точка начала чтения `q`);
2. `I_fixedc(pi)` — позиция разреза фиксирована (`q = n - 1`, естественный
   порядок), меняется только переразметка значений `c` (двойственно (1) под
   `pi -> pi^{-1}`, уже отвергнуто как Лемма C §4, но проверено заново для
   протокола и как независимая проверка симметрии);
3. `minqA(pi) = min_q (среднее по c от inv(w))` — для каждого q берём точное
   среднее по всем n значениям c (Лемма D даёт для него замкнутую формулу),
   затем минимизируем по q; если бы `minqA(pi) <= M` для всех pi, это уже
   доказывало бы H13-I, так как `minqA(pi) >= I(pi)` всегда.

Дополнительно (только n <= 7, дорогая проверка): для каждой pi с
`I_full(pi) < M` — есть ли транспозиция (обмен двух значений `pi(i), pi(j)`,
любые i, j) строго увеличивающая `I_full`? Если бы такой всегда находился,
это давало бы стратегию "локальный подъём до отражения" для доказательства
верхней оценки через связность S_n транспозициями.

## Команда, параметры, версии

- `gcc -O2 -o experiments/h13i_diagonal experiments/h13i_diagonal.c`
  (h13i_diagonal-1.0), затем `./experiments/h13i_diagonal N [--local]`
  для N = 4..10 (N <= 7 с `--local`).
- Ядро не используется напрямую (чистая комбинаторика torus-класса), только
  сама формула `I(pi)` из line_profile.c (переиспользована без изменений).
- Seed: не требуется (полный перебор, не выборка).
- Покрытие: **исчерпывающее** по всем `n!` перестановкам при 4 <= n <= 10 для
  тестов (1)-(3); исчерпывающее при 4 <= n <= 7 для теста (4) (дороже:
  O(n^2) транспозиций x O(n^2) разрезов x O(n^2) инверсий на каждую
  перестановку с `I_full < M`).
- Время: n=4..7 c `--local` < 0.14 с; n=8 без `--local` 0.37 с; n=9 — 4.3 с;
  n=10 — 73 с. Память — O(1) сверх перестановки (без хранения таблиц).
- Артефакты: `data/runs/h13i_diagonal/out_n{4..10}.json` (out_n{4..7}_local
  для теста (4)), исходник `experiments/h13i_diagonal.c`.

## Результат

| n | M | max I_shift0 | max I_fixedc | max minqA | stuck (I_full<M, no improving transposition) |
|---|---|---|---|---|---|
| 4 | 2 | 2 | 2 | 3.5 | 0 / 24 |
| 5 | 4 | 4 | 4 | 6.0 | 10 / 120 |
| 6 | 6 | 6 | 6 | 9.17 | 120 / 720 |
| 7 | 9 | 10 | 10 | 13.0 | 224 / 5040 |
| 8 | 12 | 13 | 13 | 17.5 | — |
| 9 | 16 | 17 | 17 | 22.67 | — |
| 10 | 20 | 23 | 23 | 28.5 | — |

Все три сведения к одному параметру **отвергнуты** при 4 <= n <= 10
(исчерпывающе): начиная с n = 7 `max I_shift0` и `max I_fixedc` превышают M
и разрыв растёт (M - max: 0,0,0,-1,-1,-1,-3 при n=4..10 — не стабилизируется);
`minqA` хуже с самого начала (n = 4) и разрыв растёт быстрее (превышение
1.5, 2.0, 3.17, 4.0, 5.5, 6.67, 8.5 при n = 4..10) — усреднение по значениям
при лучшем `q` не приближается к нужной границе даже асимптотически.
Худший вход для (1)-(3) при каждом n — обращение `(0, n-1, n-2, ..., 1)`
(отражение sigma_n при n >= 6; при n <= 5 другой представитель того же
класса), т.е. ровно экстремальное семейство C33/C35.

Тест (4): при n >= 5 существуют перестановки с `I_full < M`, не допускающие
НИ ОДНОЙ увеличивающей `I_full` транспозиции (10, 120, 224 штук при n = 5,
6, 7) — `I(pi)` не унимодальна относительно хода "обмен двух значений",
значит простая стратегия "поднимайся транспозицией к отражению" не может
служить доказательством верхней оценки без дополнительного аргумента,
почему застревание в таких локальных максимумах невозможно (сами они
< M, так что застревание не противоречит H13-I, но и не доказывает его).

## Вывод

Ни один из трёх кандидатов "один параметр вместо двух" не работает и ни один
не приближается к границе с ростом n (в отличие, например, от возможной
надежды, что разрыв — эффект малых n). Локальный подъём транспозициями тоже
не работает по структурной причине (немонотонность). Подробности и связь
с Леммой D — `docs/notes/h13_line_model.md` §7.

## Следующий вопрос

Не повторять эти три конкретных сведения при больших n — они опровергнуты
исчерпывающе с растущим разрывом, дальнейший рост n не изменит вывода.
Нужен верно двумерный (не редуцируемый к одному параметру) аргумент;
кандидаты и вердикт сессии — `docs/notes/h13_line_model.md` §7-8.
