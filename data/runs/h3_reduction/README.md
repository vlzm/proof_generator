# h3_reduction — цель, параметры, результат (правило 7)

- **Цель.** Проверить арифметические предпосылки индукции H3
  (`D_n <= D_{n−1} + (n − 1)`, PLAN §4.3) для одноэлементной редукции.
- **Команда.** `python3 experiments/h3_reduction.py --nmax 8 --sample-from 9
  --sample 100000 --prep-max 8` (`--seed 20260915`).
- **Версии.** h3_reduction-1.0, ядро oracle-1.0, таблицы C2v
  (`data/tables/dist_n{4..9}.bin`, сертифицированы).
- **Покрытие.** Исчерпывающее при 5 <= n <= 8 (все n! состояний);
  при n = 9 — случайная выборка 100 000 состояний (seed 20260915).
  Проверка подготовки (все слова длины <= n − 1 над {L, R, X}) —
  исчерпывающе при n <= 8 для состояний с отрицательным запасом.
- **Проверено состояний.** 120 + 720 + 5040 + 40320 + 100000; на каждое —
  n одноэлементных редукций и обращения к таблицам; для состояний
  с отрицательным запасом — до 3^(n−1) слов подготовки.
- **Время.** ~5 с (n = 9: 3.6 с).
- **Результат.** `max excess > n − 1` при всех проверенных n (никакое
  фиксированное правило удаления не подходит); необходимое условие
  `slack >= 0` без подготовки выполняется при n = 5, 6 с нулевым запасом
  и нарушается при n = 7 (1 состояние), n = 8 (62), n = 9 (19 из 100 000);
  все нарушения при n = 7, 8 снимаются подготовкой длины <= n − 1.
- **Артефакты.** `report.md`, `report.json`.
- **Вывод.** H3 не опровергнута, но в строгой форме (имитация 1:1) требует
  линейной модели H13 — `docs/notes/h3_induction.md`.
- **Следующий вопрос.** Задача о подготовке: достижимо ли за <= n − 1 ходов
  состояние, в котором разрез линейной модели стоит рядом с головой?
