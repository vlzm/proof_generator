# line_imax — исчерпывающая проверка H13-I при 4 <= n <= 14

Дата: 14.09.2026 (сессия 9). Версия кода: `line_imax-1.0`
(`experiments/line_imax.c`). Ядро oracle не используется: величина `I(pi)`
чисто комбинаторная (число инверсий линии), таблицы расстояний не нужны.

## Цель

H13-I: `I(pi) = min_{a,b} inv(w)` (все `n^2` двойных разреза;
`w_j = (pi(a+j) - b) mod n`) удовлетворяет `I(pi) <= floor((n-1)^2/4)`
для каждой торической перестановки `pi` из Z_n. До этой сессии проверено
исчерпывающе при 4 <= n <= 10 (`experiments/line_profile.c`, сессия 8).

## Команды

```sh
gcc -O2 -o line_imax experiments/line_imax.c
for n in 4 5 6 7 8 9 10 11 12; do ./line_imax $n; done > data/runs/line_imax/n04_12.out
./line_imax 13 > data/runs/line_imax/n13.out
./line_imax 14 500000000 > data/runs/line_imax/n14.out     # checkpoint 5*10^8
```

Параметров и seed нет: перебор детерминированный и полный.

## Покрытие

Перебираются все `(n-1)!` перестановок с `pi(0) = 0`. `I(pi)` инвариантна
относительно `pi(i) -> pi(i+s) - t`; для каждого s сдвиг значений `t = pi(s)`
переводит pi в представителя с `pi(0) = 0`, поэтому каждый торический класс
имеет `n / |стабилизатор|` различных представителей в этом срезе (не меньше
одного), и покрытие — **все торические классы**. Для каждого представителя строится вся таблица `inv(a,b)`
размера `n x n` за `O(n^2)` по двум приращениям:

```text
inv(a+1,b) - inv(a,b) = (n-1) - 2 * ((pi(a) - b) mod n)
inv(a,b+1) - inv(a,b) = (n-1) - 2 * ((posval(b) - a) mod n)
```

`inv(0,0)` считается двойным циклом. Корректность приращений и самой величины
`I(pi)` независимо перепроверена наивным подсчётом инверсий в
`checks/check_C37.py` (часть F): совпадение при 4 <= n <= 8, и там же
`line_imax` запускается заново при 4 <= n <= 10.

## Бюджет (правило 10)

Измерено до длинных прогонов: n = 10 — 0.06 с, n = 11 — 0.71 с,
n = 12 — 7.8 с, n = 13 — 111 с. Рост множителя ≈ n * (n/(n-1))^2, отсюда
оценка n = 14 ≈ 25–30 мин (факт: 2264.81 с = 37.7 мин, одноядерный прогон без
оптимизации компилятора под целевую машину — дольше линейной экстраполяции,
но в пределах порядка), n = 15 ≈ 8–9 ч — не запускался.
Критерий остановки: любое нарушение печатается сразу (первые 5) и меняет
статус H13-I с CONJECTURED на REFUTED; при отсутствии нарушений прогон
доводится до конца. Checkpoint для n = 14 — каждые 5*10^8 представителей.

стабилизатор порядка n, поэтому представитель ровно один).

## Вывод и следующий вопрос

H13-I VERIFIED при 4 <= n <= 14 (все торические классы), равенство — ровно
на отражениях. Общего доказательства нет; сведение к нижней оценке
`max_{a,b} V(a,b)` — `docs/proofs/C37_inversion_spearman.md` (C37.7), (C37.8),
вердикт и отвергнутые подходы — `docs/notes/h13i_verdict.md`.

проверено для всех pi при 4 <= n <= 8 и на семействах до n = 101.
