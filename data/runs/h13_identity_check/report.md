# H13-I, сессия 9 — независимая проверка тождества суммы по всем n^2 разрезам

## Цель

До использования тождества, сообщённого предыдущим ходом этой же сессии
(см. задание), — проверить его самостоятельно (AGENTS.md: доверие к
непроверенному численному результату другого хода недопустимо). Тождество:
для перестановки `pi` и неупорядоченной пары `{i,i'}` с `d=(i'-i) mod n`,
`e=(pi(i')-pi(i)) mod n`,

```
sum_{q,c} inv(w) = sum_{pairs {i,i'}} [ n(d+e) - 2*d*e ]
```

где сумма слева — по всем n^2 разрезам `(q,c)`, `inv(w)` — число инверсий
линии разреза (та же формула, что в `experiments/line_model.py`).

## Команда

```bash
python3 experiments/h13_identity_check.py --nmax 7 --nmax-sampled 30 --samples 100 --seed 1
```

## Параметры

- Диапазон: 4 <= n <= 7 — исчерпывающе (все перестановки); 8 <= n <= 30 —
  SAMPLED, 100 случайных перестановок на n, seed = 1.
- Версия кода: `experiments/h13_identity_check.py` (h13_identity_check-1.0).
- Тип покрытия: EXHAUSTIVE при 4 <= n <= 7 (5904 перестановки суммарно),
  SAMPLED при 8 <= n <= 30 (2300 случайных перестановок).
- Обе части тождества считаются точной целочисленной арифметикой (Python int).

## Результат

Тождество выполняется точно (`assert a == b`) без единого исключения на всех
проверенных входах — 5904 перестановки исчерпывающе (n=4..7) и 2300 случайных
перестановок (n=8..30, по 100 на каждое n). Полный лог — `log.txt`.

## Время и память

Несколько секунд, однопоточно, память — незначительная (только сами
перестановки).

## Вывод

Тождество подтверждено независимо. Оно, однако, не даёт пути к доказательству
H13-I напрямую: как уже зафиксировано в `docs/notes/h13_line_model.md` §6,
усреднение (даже точное, через это тождество) по всем n^2 разрезам не может
дать границу `floor((n-1)^2/4)` в общем случае — среднее превышает эту
границу уже на простых входах (id-подобные перестановки дают среднее порядка
n^2/3, см. §6 старой заметки; при этом истинный минимум для identity равен 0).
Тождество даёт точную формулу среднего, но между "среднее большое" и
"минимум маленький" нужен содержательный аргумент отбора конкретного
разреза, которого тождество само по себе не предоставляет. Сохранено как
проверенный факт для будущих сессий; не является частью доказательства.

## Следующий вопрос

Не продолжать без новой идеи, как использовать точную форму (не только
среднее) — например, через второй момент (дисперсию `T(s,t)` по (s,t)) или
структуру самого тождества по парам (d,e). Не пытались в этой сессии из-за
бюджета; см. вердикт `docs/notes/h13_line_model.md` §7.
