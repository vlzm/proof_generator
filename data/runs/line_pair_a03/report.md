# line_pair_a03 — фиксированная пара разрезов {0, 3} (H13-I, сессия 9)

Цель: проверить кандидатную идею «фиксированное (не зависящее от pi) малое
семейство позиционных разрезов a достаточно для H13-I» — для каждой pi
проверяется `min(min_b inv(a1, b), min_b inv(a2, b)) <= floor((n-1)^2/4)`,
перебор исчерпывающий по всем pi при заданном n (для каждого a перебор всех
b и полный подсчёт инверсий).

Версия: line_pair_a03-1.0, ядро oracle-1.0 (для формулы разреза; таблицы
расстояний не нужны — I(pi) от d(pi) не зависит). Команда:
`gcc -O2 -o line_pair_a03 experiments/line_pair_a03.c && ./line_pair_a03 n a1 a2`.

| n | (a1, a2) | порог floor((n-1)^2/4) | худший случай | избыток | провалов | время |
|---|---|---|---|---|---|---|
| 4 | (0, 3) | 2 | 2 | 0 | 0 | <1 с |
| 5 | (0, 3) | 4 | 4 | 0 | 0 | <1 с |
| 6 | (0, 3) | 6 | 6 | 0 | 0 | <1 с |
| 7 | (0, 3) | 9 | 9 | 0 | 0 | <1 с |
| 8 | (0, 3) | 12 | 12 | 0 | 0 | <1 с |
| 9 | (0, 3) | 16 | 16 | 0 | 0 | ~1 с |
| 10 | (0, 3) | 20 | 20 | 0 | 0 | ~7 с |
| 11 | (0, 3) | 25 | 25 | 0 | 0 | 269 с |
| 11 | (0, 4) | 25 | 26 | 1 | 22 | 269 с |
| 11 | (0, 5) | 25 | 27 | 2 | 363 | 266 с |

Пара {0, 3} при 4 <= n <= 11 не даёт ни одного провала (перебор всех
n! перестановок для каждого n); для сравнения пары {0, 4} и {0, 5} уже
проваливаются при n = 11 — устойчивость {0, 3} не структурная, а числовая
случайность малых n.

**Это не доказательство и не общая конструкция.** Локальный поиск
(hill climbing, `experiments/h13_averaging_bound.py` часть 3) находит при
n = 20 перестановку, на которой пара {0, 3} даёт избыток 2 над порогом —
значит при n = 20 в этом семействе уже есть провал, которого поиск при
n <= 11 не видит просто потому, что провалов там нет вовсе. Вывод: никакое
фиксированное (не растущее с n и не зависящее от pi) семейство разрезов
размера O(1) не решает H13-I в общем случае.

Файлы: `experiments/line_pair_a03.c` (line_pair_a03-1.0),
raw JSON строк — вывод программы, приведён построчно выше.
