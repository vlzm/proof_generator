# sweep_eval — кандидат «развёртка» против таблиц и B_n

Цель: измерить кандидата sweep-1.1 (`constructions/candidate_sweep.py`) и портфель
`min(N1_R, развёртка)` (N1_R — `strict_upper.py`, маршрут по переносчикам, минимум по c)
на всех перестановках 4 <= n <= 9 и на семействах до n = 40. Версии: sweep_eval-1.0,
sweep-1.1, strict_upper-1.0, oracle-1.0; таблицы C2v для d(pi). Seed 1 (случайные выборки).

Команды: `python3 experiments/sweep_eval.py --perms 9 --workers 4` (1 245 с при n = 9 на
4 процессах; `report_perms9_fam0.json`, `perms9.out`) и
`python3 experiments/sweep_eval.py --perms 3 --families 40 --samples 30`
(1 955 с; `report_perms3_fam40.json`, `fam40.out`). `report.log` — сводный журнал.
Покрытие: исчерпывающе по pi при 4 <= n <= 9 (все n·2·2·2 слов на вход построены и
исполнены эталоном); семейства — отражения (все h), sigma_n, rev_n, повороты sigma_n,
аффинные `a·i + b` без a = n − 1 (все (a, b) при n <= 20, b из {0, 1, n/2, n − 1} при
21 <= n <= 40), 30 случайных перестановок на каждое n. Память — незначительна.

## Вывод

Развёртка сама по себе — `<= B_n` при 4 <= n <= 8 и `<= B_n + 2` при n = 9 (только
отражения); её потеря на отражениях линейна (≈ 0.8n) и целиком во вращениях (N_X равен
N_X геодезических). Портфель с N1_R — `<= B_n` на всём проверенном. На аффинных
контрпримерах к H10 развёртка короче B_n с растущим запасом. Следующий вопрос —
PLAN §8 (H12): единая политика головы, дающая колебания N1 на отражениях и проходы
развёртки на аффинных входах; см. `docs/notes/geodesic_structure.md` §5.
