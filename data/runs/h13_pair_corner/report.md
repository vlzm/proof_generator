# Отчёт: h13_pair_corner — сессия 9 (17.09.2026)

## Цель

Продолжить работу над H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi;
`docs/notes/h13_line_model.md` §6), бюджет 1 сессия до письменного
вердикта (`docs/notes/repo_state.md`).

## Команды

```
python3 checks/check_C37.py
python3 experiments/h13_pair_corner.py --verify-formula --scan --sizes 15,20,30,50 --seed 42
python3 experiments/h13_pair_corner.py --hillclimb --sizes 11,12,13,14 --iters 1500 --restarts 5 --seed 0
```

Версии: h13_pair_corner-1.0, check_C37 (без версии ядра — чистая
комбинаторика, ядро oracle-1.0 не используется). Seed: 1 (verify-formula),
42 (scan), 0 (hillclimb, к которому прибавляется n).

## Результаты

1. **Новая лемма (C37, PROVED)**: число углов `(a,b)`, в которых
   фиксированная пара точек `(i1,pi(i1))`, `(i2,pi(i2))` несогласна, равно
   `f(d,e) = n(d+e) - 2de`, где `d = i2-i1`, `e = (pi(i2)-pi(i1)) mod n`.
   Элементарное доказательство — `docs/proofs/C37_pair_corner_formula.md`.
   Проверка: `checks/check_C37.py` — **PASS**, исчерпывающе все пары всех
   перестановок при 4 <= n <= 7 (117 984 пары, 5904 перестановки,
   0 расхождений, 1.2 с). Независимая (не через experiments/) реализация.

2. **Покрытие H13-I расширено (SAMPLED, не VERIFIED)**: для n = 15, 20, 30,
   50 проверены отражение sigma_n, reverse, несколько аффинных семейств
   (при n = 50 в т.ч.) и по 5 случайных перестановок на n — во всех случаях
   `I(pi) <= floor((n-1)^2/4)`, с равенством только на отражении и reverse
   (совпадают по построению — `reverse = pi(i) = n-1-i`, отражение sigma_n
   = `pi(i) = -i mod n`; оба — крайние случаи одного семейства отражений).
   Ни одного нарушения. Это не исчерпывающая проверка (rule 9): охват —
   явно перечисленные семейства + 5 случайных на n, а не все перестановки.

3. **Поиск контрпримера (hillclimb, не нашёл нарушений)**: локальный поиск
   (случайные рестарты, 5 стартов × 1500 итераций обмена двух элементов,
   принятие немонотонного `I`, отклонение ухудшающих ходов) при
   n = 11, 12, 13, 14 не нашёл ни одной перестановки с `I(pi) >
   floor((n-1)^2/4)`; при n = 12 достигнут точный максимум (граница
   floor((n-1)^2/4) = 30, найдено 30 — почти-отражение
   `[1,0,11,10,...,3,2]`, т.е. reverse с переставленными первыми двумя
   элементами). При n = 11, 13, 14 найденный максимум ниже границы (не
   значит, что граница не точна — hillclimb не гарантирует глобальный
   максимум; интерпретация: ещё один инструмент отсутствия контрпримера,
   не доказательство точности). Время: 51.7 с (одно ядро).

## Вывод

H13-I **не доказана и не опровергнута** в сессии 9: новых контрпримеров
не найдено (расширяет уверенность до n = 50 точечно и n = 11..14 —
локальным поиском), но общего доказательства нет. Получена новая точная
комбинаторная лемма (C37) — не завершает доказательство: её билинейность
по (d,e) позволяет "чинить" одну пару выбором угла, но `inv(a,b)` —
сумма по `C(n,2)` парам одновременно, и попытка построить из C37 общий
аргумент (см. §7 заметки) за сессию не завершена: наивное усреднение
по-прежнему не работает, а способ выбрать угол, одновременно хороший для
большинства пар, не найден.

## Следующий вопрос

Решение, зафиксированное заранее (`docs/notes/repo_state.md`,
`docs/notes/h13_line_model.md` §6): бюджет сессии на H13-I исчерпан без
доказательства -> переход к альтернативному направлению C15 — индуктивная
редукция H3 (PLAN §4.3, п. 3), бюджет 2 сессии до вердикта. C37 сохраняется
в реестре как самостоятельная (доказанная) лемма на будущее — она точна и
может пригодиться, если в H3 или другой попытке снова понадобится точный
учёт углов для отдельных пар точек.
