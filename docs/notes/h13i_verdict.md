# H13-I: состояние после сессии 9 — маршруты усреднения и одномерных семейств закрыты

Дата: 16.09.2026 (сессия 9). Бюджет `docs/notes/h13_line_model.md` §6: 1
сессия до письменного вердикта; израсходована. **Вердикт: H13-I остаётся
CONJECTURED (не доказана и не опровергнута)**; два простых маршрута к
доказательству исключены с точными данными, ни один встречный пример не
найден при 4 <= n <= 9 (H13-I по-прежнему VERIFIED в этом диапазоне из
сессии 8, `experiments/line_profile.c`).

## 1. Что проверено в этой сессии

`experiments/h13i_cut_families.py` (h13i_cut_families-1.0), исчерпывающе
4 <= n <= 9 (`data/runs/h13i_cut_families/report.md`):

1. **Усреднение по всем n^2 разрезам не доказывает H13-I ни для одного
   практически значимого класса входов.** Заметка §6 (сессия 8) отмечала
   качественно, что среднее для sigma_n и для id больше границы; здесь
   показано, что превышение массовое: 24/24, 115/120, 714/720, 4984/5040,
   39832/40320, 356364/362880 перестановок (4 <= n <= 9) имеют
   `avg_{q,c} inv > floor((n−1)^2/4)` — доля растёт к ≈98%. Худшее среднее
   растёт как `~7n^2/12` против границы `~n^2/4`; разрыв не убывает с n.
   Значит никакая ссылка на равномерное усреднение (по всем n^2 разрезам
   сразу) не может дать доказательство — нужен аргумент, зависящий от
   структуры pi, а не только от объёма пространства разрезов.
2. **Ни одно из двух естественных одномерных семейств разрезов (n вместо
   n^2) не совпадает с истинным I(pi), начиная с n = 7.** Проверены:
   (а) только сдвиг значений (разрез позиций не используется, n вариантов
   по c); (б) диагональ q = c (n вариантов). При 4 <= n <= 6 оба совпадают
   с I(pi) на всех входах; при n = 7, 8, 9 нарушается на 7, 16, 162 входах
   соответственно (растущая доля), и нарушители — не только отражения.
   Значит понадобиться именно двумерная свобода (q, c) существенна для
   H13-I уже при небольших n; сведение к счётному линейному семейству
   разрезов невозможно в этих двух естественных формах — присоединяется к
   уже отвергнутому в сессии 8 семейству «первый элемент линии = t»
   (`h13_line_model.md` §1.7).
3. По ходу проверки: попытка получить чистую комбинаторную характеризацию
   «инверсия пары {a,b} при разрезе (q,c) ⟺ q лежит в дуге позиций XOR c
   лежит в дуге значений» была написана и **проверена прямым
   пересчётом на случайных pi (4 <= n <= 8, 1000 пар (pi,q,c)) — не совпала
   с `inv_count` на большинстве случаев** (ошибка в знаке/направлении дуги
   значений, не переисследовано дальше в рамках бюджета сессии). Не
   регистрируется как лемма; направление остаётся кандидатом для
   переисследования (см. §3 п. 3), но текущая формулировка неверна и не
   должна использоваться без нового вывода и проверки.

## 2. Что не изменилось

- H13-I: VERIFIED 4 <= n <= 10 (сессия 8, `experiments/line_profile.c`,
  `data/runs/line_profile/`), CONJECTURED при всех n >= 4 — без изменений;
  эта сессия не расширила диапазон проверки (это было бы просто повтором
  line_profile, запрещённым правилом «не повторять» сессии 8) и не нашла
  контрпример.
- H13-R (C36), H13′ (C35) — без изменений, не затрагивались.
- Отвергнутые ранее подходы (усреднение в исходной качественной форме,
  индукция по одному элементу, семейство «первый элемент = t», локальные
  условия — лемма C) остаются отвергнутыми; эта сессия делает негативный
  результат по усреднению и по двум конкретным одномерным семействам
  количественным и исчерпывающим вместо качественного.

## 3. Следующий шаг

Кандидаты, ещё не проверенные:

1. **Неравномерное распределение по разрезам.** Усреднение проваливается
   равномерно; возможно, взвешенное среднее (вес разреза (q,c), зависящий
   от структуры pi — например от локальной плотности инверсий вблизи (q,c))
   даёт нужную границу. Не проверено численно в этой сессии из-за бюджета.
2. **Второй момент / дисперсия.** Если `Var_{q,c}(inv) `велика на входах,
   где среднее превышает границу, минимум может быть далеко от среднего;
   проверить, коррелирует ли высокая дисперсия именно с превышением
   среднего над границей (что оправдало бы аргумент типа
   «среднее минус k·стандартное отклонение»).
3. **Повторный вывод характеризации «инверсия = XOR дуг»** (п. 1.3) с
   аккуратной проверкой знаков и направления обеих дуг перед использованием;
   если верна, она сводит F(q,c) к сумме `A(q) + B(c) − 2·C(q,c)`, где
   `A(q)` имеет чистую замкнутую форму (не зависящую от pi — доля пар
   {a,b}, разделённых позицией q), а `B(c)` — это в точности инверсии
   разреза с q = n−1 (уже считается семейством 2a выше и, как показано в
   п. 2, само по себе недостаточно); интерес — в перекрёстном члене C(q,c),
   который пока не имеет закрытой формы.
4. Если ни один из п. 1–3 не даст прогресса за следующую сессию — перейти
   к индукции H3 (PLAN §4.3, п. 3, бюджет 2 сессии до вердикта), как
   предусмотрено `h13_line_model.md` §6.

Бюджет на H13-I: заложенная 1 сессия израсходована без доказательства и без
опровержения; п. 1–3 выше — не повтор отвергнутых подходов, но и не
гарантированный путь. Решение об открытии новой сессии на H13-I (кандидаты
выше) или о переходе на H3 — за следующей сессией, с учётом PLAN §12
(бюджет — число сессий, по исчерпании — отчёт и остановка).
