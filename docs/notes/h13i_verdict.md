# H13-I — вердикт сессии 9: тождество доказано, гипотеза не доказана

Дата: 13.09.2026 (сессия 9). Бюджет: 1 сессия до письменного вердикта
(PLAN §8, `docs/notes/repo_state.md`). Итог: **H13-I не доказана**; доказана
точная переформулировка (C37, `docs/proofs/C37_toric_correlation.md`) и первая
общая при всех n оценка `I(pi) <= floor((n-1)(2n-1)/6)`; пять естественных
достаточных условий, вытекающих из переформулировки, опровергнуты явными
контрпримерами. Код: `experiments/toric_correlation.py` (toric_corr-1.0),
`checks/check_C37.py`. Отчёты: `data/runs/toric_correlation/`,
`data/runs/check_C37/`.

## 1. Что доказано (C37)

Обозначения: разрез `(q, c)`, `s = (q - c) mod n`,
`sig(t) = n - 1 - 2 (t mod n)`,

```text
S(q, s) = sum_i sig(q - i) sig(s - pi(i)),
E(pi)   = sum_{i,j} sig(j - i) sig(pi(j) - pi(i)).
```

- **Теорема A.** `4 n^2 inv(q, c) = n^2(n^2 - 1) - E(pi) - 2 n S(q, s)`.
  Зависимость `inv` от разреза — ровно двумерная циклическая корреляция
  перестановочной матрицы с ядром `sig ⊗ sig`; `I(pi)` отвечает `max S`.
  Доказательство элементарно: `sig(q - i) = 2 x_i - (n-1)` (позиция i в линии),
  откуда `S = 4 sum_j j w_j - n(n-1)^2`, а величина `inv + (2/n) sum_j j w_j`
  не меняется ни при одном из двух элементарных сдвигов разреза.
- **Теорема B.** `E(pi) >= 2n^2(n-1) - n^2(n^2-1)/3`, равенство ровно на
  n отражениях (неравенство о перестановках, применённое отдельно при каждом i).
- **Следствие C.** `avg_{q,c} inv = (n^2-1)/4 - E/(4n^2) <= (n-1)(2n-1)/6`,
  равенство ровно на отражениях; значит `I(pi) <= floor((n-1)(2n-1)/6)`
  при всех n >= 2. Это первая доказанная при всех n нетривиальная оценка для `I(pi)`
  (тривиальная — `n(n-1)/2`);
  она слабее цели в отношении, стремящемся к 4/3
  (`(n-1)(2n-1)/6 ~ n^2/3` против `floor((n-1)^2/4) ~ n^2/4`).

Следствие C делает строгим прежнее наблюдение «усреднение не работает»
(`h13_line_model.md` §6): максимум среднего достигается ровно на отражениях,
и разрыв со целью равен `(n^2 - 1)/12`.

Эквивалентная форма цели (замечание 3 доказательства): при
`thr(n) = n floor(n/2) + n(n-1)/2`

```text
H13-I  <=>  2 n max_{q,s} S(q, s) + E(pi) >= 2 n thr(n).
```

Обе части тесны на отражениях: там `max S = -n(n^2-1)/3 + 2n floor(n^2/4)`
(«пик отражения») и `E` равно границе теоремы B.

## 2. Что опробовано и опровергнуто

Все проверки — исчерпывающие при 4 <= n <= 8 (`experiments/toric_correlation.py`,
часть «candidates»), плюс случайные при больших n. Ни одно из условий ниже
не выполняется для всех pi, поэтому ни одно не может заменить H13-I.

1. **Пик отражения (P):** `max S >= -n(n^2-1)/3 + 2n floor(n^2/4)`.
   Вместе с теоремой B это дало бы H13-I *точно* (обе оценки тесны на
   отражениях одновременно). Верно при 4 <= n <= 7 и **ложно при n = 8**:
   16 перестановок, наименьшая в лексикографическом порядке —
   `(0,3,6,1,4,7,2,5)` (аффинная, `pi(i) = 3i mod 8`). При больших n нарушение
   типично: у случайной pi `max S` порядка `n^{2.5}`, а пик отражения — порядка
   `n^3/6` (проверено: n = 20, 30, 50, 80 — минимум по 30 случайным
   перестановкам ниже пика). Вывод: **теорема B и любая универсальная нижняя
   оценка пика несовместимы** — они тесны в непересекающихся режимах
   (отражения против «типичных» pi), поэтому разбивать
   `2n max S + E >= 2n thr` на два независимых слагаемых нельзя.
2. **Пара max/min (M):** `2 max S + min S >= 2 thr` (получается из
   `E >= n min S`). Ложно уже при n = 4 (20 из 24 перестановок); оценка
   `E >= n min S` теряет множитель порядка 3.
3. **Три точки (T):** `sum_j [S(j,pi(j)) + S(j+n/2,pi(j)) + S(j,pi(j)+n/2)]
   >= 2 n thr` (чётные n). В непрерывном пределе соответствующее неравенство
   `int F dρ >= 0`, `F = 3 psi⊗psi - phi⊗psi - psi⊗phi`, обращается в равенство
   и на антидиагонали (отражение), и на диагонали (тождественная) — признак
   того, что промежуточные меры его нарушают. Так и есть: ложно при n = 4, 6, 8
   (n = 8: 40296 из 40320).
4. **Семейство прямых (L):** `max S >= (1/n) max_{lam, s} sum_a S(a, lam a + s)`
   — усреднение S по прямой любого наклона lam (для lam = -1 это
   антидиагональ, точная для отражений; для lam = 1 — диагональ, точная для
   тождественной). Недостаточно: ложно при n = 5, 6, 7, 8 (n = 8: 1152 pi).
5. **Сдвиги графика (W):** `max S >= max_{s,t} (1/n) sum_j S(j+s, pi(j)+t)`
   — сведение к автокорреляционной мере ρ (симметричная мера с равномерными
   маргиналами и атомом n в нуле). Ложно при n = 5, 7, 8 (n = 8: 1088 pi).

Дополнительно опробовано и отвергнуто аналитически:

6. **Третий момент.** `max S >= sum S^3 / sum S^2` (верно, так как
   `sum S^3 <= max S * sum S^2`), но для отражения интеграл `int c^3` профиля
   `c(x) = -1/3 + 2x(1-x)` отрицателен, так что оценка даёт отрицательное
   число. Работают лишь моменты высокого порядка — не конечный аргумент.
7. **Двойственный сертификат.** Оценка E через транспортную задачу с
   зафиксированными «диагональными» массами (`z_i = i + pi(i)`): ищем
   `alpha(u) + beta(v) + gamma(u+v) <= sig(u) sig(v)` и используем
   положительную определённость `h(r) = gamma(r) + (2/n) C(r + c)`. Сертификат,
   тесный на отражениях, в непрерывном пределе даёт
   `E[F] + max_c E[G_c] >= 1/2` с `F = min(rho,1-rho)^2`, `G_c = 2{rho+c}(1-{rho+c})`;
   на равномерном распределении разностей левая часть равна `1/12 + 1/3 = 5/12
   < 1/2`. Переход к положительно определённой части теряет множитель 2.

## 3. Где именно ломается задача

Точная форма `2 n max S + E >= 2 n thr` — это утверждение вида «максимум
корреляционной функции не меньше половины её собственной энергии со знаком
минус». В непрерывном пределе (мера mu на торе с равномерными маргиналами,
`R = Psi * mu`, `Psi = psi ⊗ psi`, psi — пила):

```text
tau(a,b) = tau_0 + 2 R(a,b),   tau_0 = int R dmu,
H13-I  <=>  2 max R + int R dmu >= 0   (с точностью до членов порядка 1/n).
```

Равенство — ровно на антидиагональной мере (отражение): там `max R = 1/6`,
`int R dmu = min R = -1/3`. Трудность в том, что `int R dmu` — квадратичная
форма с *знакопеременным* множителем (`-1/(pi^2 j k)`: отрицательный при
`jk > 0`, положительный при `jk < 0`), так что помодовые оценки невозможны, а
любое усреднение по фиксированному семейству разрезов (пункты 3–5) не находит
максимум у мер, «промежуточных» между диагональю и антидиагональю.

## 4. Рекомендация

Прямой путь к H13-I через одно неравенство исчерпан в рамках сессии.
Варианты по убыванию привлекательности:

1. **Устойчивость около отражений (stability).** Доказать: если
   `E <= 2n^2(n-1) - n^2(n^2-1)/3 + eps n^4`, то pi «близка» к отражению
   (например, распределение `z_i = i + pi(i)` сосредоточено), и тогда
   `max S` оценивается снизу через антидиагональное семейство (пункт 4 выше
   с lam = -1); при `E` далеко от границы нужна независимая оценка
   `max S >= thr` (для случайных pi выполняется с большим запасом; при
   4 <= n <= 8 нарушается только на отражениях при n = 4). Это разбиение на
   два режима — единственная схема, согласованная со всеми найденными
   контрпримерами. Цена: количественная теорема устойчивости для
   неравенства о перестановках.
2. **Отказ от H13-I как обязательного шага**: перейти к индукции H3
   (PLAN §4.3) — запасной путь из `repo_state.md`.

Не повторять: усреднение по всем n^2 разрезам (следствие C показывает, что
максимум среднего равен `(n-1)(2n-1)/6` и это окончательно), индукцию по
одному элементу (`h13_line_model.md` §1.7), пункты 1–7 §2 этой заметки.
