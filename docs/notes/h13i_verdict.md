## 1. Постановка

`pi` — биекция Z_n -> Z_n. Двойной разрез `(a, b) ∈ Z_n^2` даёт линию
`w` с `s_i = (i - a) mod n` (индекс в линии) и `t_i = (pi(i) - b) mod n`
(ранг значения); `inv(a,b)` — число инверсий, `I(pi) = min_{a,b} inv(a,b)`.
H13-I: `I(pi) <= floor((n-1)^2/4)` для всех n и всех pi.
Соответствие с `(q, c)` из `line_model.py`: `a = q+1`, `b = q+1-c`.

Равносильно: `floor((n-1)^2/4) = min_k [C(k,2) + C(n-k,2)] = B_n -
floor(n^2/4)`, то есть у каждой pi есть разрез с **не менее `floor(n^2/4)`
согласованных пар**. Экстремум — ровно класс отражений, у которых при лучшем
разрезе линия распадается на два убывающих блока длин `ceil(n/2)`, `floor(n/2)`.

## 2. Что доказано в этой сессии (C37)

Пусть `psi(t) = (t mod n) - (n-1)/2` (центрированная пила, `sum_t psi = 0`) и

```text
V(a,b) = sum_i psi(i - a) * psi(pi(i) - b)      — ковариация Спирмена линии
Q(pi)  = sum_i V(i, pi(i))                      — сумма V по n «разрезам в точках»
```

**Теорема C37.** `inv(a,b) = inv_avg(pi) - (2/n) * V(a,b)` для всех разрезов;
то есть на семействе n^2 разрезов одной торической перестановки число инверсий
(Кендалл) — **аффинная функция ковариации Спирмена**. Доказательство
элементарно: знак `sgn(s_j - s_i)` равен `E_ij + (2/n)(s_j - s_i)` с
`E_ij = 1 - 2((j-i) mod n)/n`, перекрёстные члены в `sum_{i<j}` исчезают,
потому что `sum_{j != i} E_ij = 0` (позиции и значения пробегают **все**
вычеты — единственное место, где используется торичность).

Следствия (все в `docs/proofs/C37_inversion_spearman.md`):

```text
(C37.3)  sum_i (s_i - t_i)^2 = n(n^2-1)/6 - 2 V(a,b)
(C37.4)  inv(a,b) = const(pi) + (1/n) sum_i (s_i - t_i)^2
(C37.5)  inv_avg(pi) = (n^2-1)/4 - Q(pi)/n^2
(C37.7)  H13-I для pi  <=>  2 V*(pi) + Q(pi)/n >= n * c_n,  V* = max_{a,b} V
         c_n = (n^2-1)/4 - floor((n-1)^2/4) = (2n-1)/4 (чёт.), (n-1)/2 (нечёт.)
(C37.8)  3 V*(pi) >= n * c_n   =>   H13-I для pi
```

(C37.4) — самая наглядная форма: **минимизация инверсий по двойному разрезу
тождественно равна минимизации суммы квадратов смещений** `sum_i (s_i-t_i)^2`
(выбор начала координат на торе, при котором картинка максимально «диагональна»).

На отражениях (C37.7) выполняется **с равенством** при всех n (проверено
в замкнутой форме, `check_C37.py` часть E, 4 <= n <= 60), что объясняет их
экстремальность: `V(a,b)` там зависит только от `a+b`, `V(m) = -C(m) -
n*psi(-m)` с автокорреляцией пилы `C(m) = n(n^2-1)/12 - (n/2) m (n-m)`.

## 3. Конечная проверка H13-I: 4 <= n <= 14

`experiments/line_imax.c` (line_imax-1.0). Перебор ведётся по `(n-1)!`
представителям с `pi(0) = 0` (для каждого s сдвиг значений `t = pi(s)` даёт
такого представителя, так что каждый торический класс покрыт); вся таблица `inv(a,b)` строится за `O(n^2)` по двум
приращениям
`inv(a+1,b) - inv(a,b) = (n-1) - 2((pi(a)-b) mod n)` и
`inv(a,b+1) - inv(a,b) = (n-1) - 2((posval(b)-a) mod n)`.

Измерение перед длинным прогоном (правило 10): n = 10 — 0.06 с,
n = 11 — 0.76 с, n = 12 — 9.0 с, n = 13 — 111 с; экстраполяция на
n = 14 — ~28 мин, checkpoint каждые 5·10^8 представителей.

| n | представителей | `floor((n-1)^2/4)` | max I | классов с максимумом | нарушений |
|---|---|---|---|---|---|
| 11 | 3 628 800 | 25 | 25 | 1 | 0 |
| 12 | 39 916 800 | 30 | 30 | 1 | 0 |
| 13 | 479 001 600 | 36 | 36 | 1 | 0 |
| 14 | 6 227 020 800 | 42 | 42 | 1 | 0 |

«Классов с максимумом = 1» означает: единственный представитель с `pi(0)=0`,
достигающий максимума, — `pi(i) = -i`, то есть **экстремален ровно класс
отражений** (при 4 <= n <= 14). Семейства при n = 20, 50, 64, 100, 101
(тождественная, отражения, все аффинные, блочные, случайные) — запас
`floor((n-1)^2/4) - I` равен 0 только на отражениях.

## 4. Отвергнутые подходы (с контрпримерами)

Воспроизводится `python3 experiments/h13i_leads.py --nmax 8`; отчёт
`data/runs/h13i_leads/report.md`. Число pi (представителей с `pi(0)=0`),
на которых подход даёт больше `floor((n-1)^2/4)`:

| n | диаг. `(a,a+s)` | антидиаг. `(a,s-a)` | точки `(i,pi(i)+r)` | `(i+q,pi(i)+r)` | нет 321-разреза | нет блочного разреза |
|---|---|---|---|---|---|---|
| 5 | 8 | 12 | 5 | 5 | 1 | 2 |
| 6 | 45 | 20 | 0 | 0 | 19 | 34 |
| 7 | 243 | 256 | 77 | 63 | 248 | 242 |
| 8 | 1414 | 857 | 272 | 136 | 2795 | 3058 |

1. **Усреднение по всем n^2 разрезам** — отвергнуто в сессии 8; в терминах C37
   это утверждение `V* >= 0`, тривиальное и слишком слабое (`inv_avg` для
   отражений ≈ `n^2/3`).

2. **Усреднение по однопараметрическим семействам** (диагонали `b = a+s`,
   антидиагонали `b = s-a`) — отвергнуто. Антидиагональ точна на отражениях
   (там `inv` постоянна вдоль `a+b = const`), но ломается уже при n = 5
   (`pi = (0,1,2,4,3)`); диагональ точна на тождественной и ломается при n = 4.
   Общий довод: у отражений оптимальны ровно `n` разрезов из `n^2` при чётном n и `2n` при нечётном (проверено при 4 <= n <= 14), поэтому
   **никакое не зависящее от pi семейство разрезов не годится** — усреднение
   должно зависеть от pi.

3. **Усреднение по «разрезам в точках»** `{(i, pi(i)+r)}` и по сдвинутым
   `{(i+q, pi(i)+r)}` — зависит от pi и точно на отражениях и на аффинных
   входах (там `inv` постоянна вдоль семейства), но недостаточно: n = 5,
   `pi = (0,1,4,3,2)` даёт среднее 21/5 > 4; n = 7, `(0,1,4,6,5,3,2)` — 66/7 > 9;
   n = 8, `(0,1,4,7,6,5,3,2)` — 49/4 > 12. Запас мал (0.2–0.4), но подход
   в такой форме закрыт.

4. **Мантеловский путь (a): триангуляционная свобода.**
   `floor((n-1)^2/4) = ex(n-1, K_3)`, но правильное соответствие другое:
   при оптимальном разрезе отражения **граф согласованных пар** есть в точности
   граф Турана `K_{ceil(n/2), floor(n/2)}` на n вершинах с `floor(n^2/4) =
   ex(n, K_3)` рёбрами, а граф инверсий — `K_k ⊔ K_{n-k}`. Мантель даёт
   **верхние** оценки для графов без треугольника, а нам нужна **нижняя**
   оценка числа рёбер графа согласованности, поэтому теорема Мантеля
   неприменима напрямую. Единственное честное применение: если линия
   321-избегающая (граф инверсий без треугольника), то `inv <= floor(n^2/4)` —
   это слабее нужного ровно на `floor(n/2)`. Кроме того, разреза с
   321-избегающей линией может не быть: первый контрпример — `sigma_5`
   (n = 5), далее 2795 из 5040 классов при n = 8.

5. **Мантеловский путь (b): блочный разрез.** Если у разреза первые
   `k ∈ {floor(n/2), ceil(n/2)}` элементов линии — ровно k наименьших значений,
   то `inv <= C(k,2)+C(n-k,2) = floor((n-1)^2/4)` (точная цель). Такой разрез
   существует тогда и только тогда, когда pi переводит циклический интервал
   длины k в циклический интервал длины k. Контрпример — n = 5,
   `pi = (0,2,4,1,3)`; при n = 8 разреза нет у 3058 из 5040 классов.

6. Из сессии 8 (не повторялось): индукция по одному элементу (n = 8,
   `(0,5,2,7,4,1,6,3)`), семейство «первый элемент линии равен t»,
   локальные условия оптимальности (лемма C, линия `(0,5,4,3,2,1,6)` при n = 7).

## 5. Что осталось: нижняя оценка `V*`

По (C37.8) достаточно доказать

```text
V*(pi) = max_{a,b} sum_i psi(i-a) psi(pi(i)-b)  >=  n * c_n / 3  (≈ n^2/6).
```

Данные: условие выполнено для **всех** pi при 4 <= n <= 8 (столбец L5 в
`h13i_leads`, 0 отказов) и на всех проверенных семействах при n до 101
с большим запасом. Минимум `V*` по pi достигается на аффинных входах:
n = 5: 5 (нужно 10/3), n = 6: 19/2 (5.5), n = 7: 14 (7), n = 8: 14 (10).
Для аффинной `pi(i) = g i` величина `V(a,b)` зависит только от `b - g a`,
и `sum_i psi(i) psi(g i - b)` — это (с точностью до нормировки) сумма
Дедекинда `s(g, n)`; измеренный минимум `V*` по g растёт как `≈ n^2/2 - O(n)`,
то есть втрое выше порога `n^2/6`.

Две явные нижние оценки `V*`, выводимые из C37, по отдельности и вместе
недостаточны (столбец L6: 35 отказов при n = 7):

```text
L6a («след по сдвинутым диагоналям»)  V* >= (1/n) max_r sum_i C(pi(i) - i - r)
L6b («разрезы в точках»)              V* >= (1/n) max_r sum_i V(i, pi(i) + r)
```

L6a бесполезна на отражениях (даёт 0), L6b — на «почти отражениях».
Второй момент тоже не годится: `sum_{a,b} V = 0`,
`sum_{a,b} V^2 = sum_{i,j} C(j-i) C(pi(j)-pi(i))`, и стандартная оценка
`max V >= sqrt(sum V^2 / (N(N-1)))` при `N = n^2` даёт лишь `n^{1.5}`.

Третья равносильная форма (следствие C37.3b, проверена чекером при
4 <= n <= 8) — через **расхождение** точечного множества `{(i, pi(i))}`:
с `N(a,b) = #{x < a : pi(x) < b}` и `D(a,b) = N(a,b) - ab/n`

```text
V(a,b) = n * [ n D(a,b) - sum_{b'} D(a,b') - sum_{a'} D(a',b) ] + gamma(pi),
```

так что нужна нижняя оценка максимума «локального минус маргинальные»
расхождения по боксам с углом в начале координат. Это связывает H13-I
с классической теорией расхождения перестановок.

Формулировка для следующей сессии (матричный вид): `V = Psi P Psi^T`, где
`Psi` — циркулянт пилы (`Psi[a][i] = psi(i-a)`), `P` — матрица перестановки.
Требуется: **максимальный элемент матрицы `Psi P Psi^T` не меньше `n^2/6`**
для любой матрицы перестановки P. Эквивалентно (через (C37.4)): у любой
торической перестановки есть начало координат, при котором
`sum_i (s_i - t_i)^2 <= n(n^2-1)/6 - n^2/3`.

## 6. Связь с C15 и следующий шаг

`H13-I + H13-R => C15` по C12 (`docs/notes/h13_line_model.md` §5.2):
`d(pi) <= I(pi) + floor(n^2/4) <= floor((n-1)^2/4) + floor(n^2/4) = B_n`.
H13-R (C36, бюджет вращений `floor(n^2/4)` при `N_X = I`) остаётся
CONJECTURED (VERIFIED 4 <= n <= 9) и в этой сессии не трогался — это
отдельная задача о маршрутах, к ней имеет смысл переходить только после
закрытия H13-I.

Развилка по PLAN §8:

1. Ещё одна сессия на H13-I в форме (C37.8) — задача стала чисто
   «аналитической» (нижняя оценка максимума корреляции пилы с перестановкой),
   отвязанной от инверсий и от LRX; кандидаты: третий момент `sum V^3`
   (вычислим через тройные корреляции пилы), разложение Фурье
   `V(a,b) = n^{-2} sum_{k,l != 0} hat_psi(k) hat_psi(l) S(k,l) w^{-ka-lb}`
   с `S(k,l) = sum_x w^{kx + l pi(x)}` и `hat_psi(k) = n/(w^{-k}-1)`
   (нужна нижняя оценка максимума при известной L2-норме и нулевом среднем),
   выпуклость по «таблице разностей» `N(d,v) = #{i : pi(i+d)-pi(i) = v}`
   (матрица `N/n` дважды стохастическая, `Q` в ней линейна, `V*` выпукла).
2. Индукция H3 (PLAN §4.3, п. 3) как независимый путь — назначенный запасной
   вариант.

Не повторять: усреднение по любому семейству разрезов, не зависящему от pi
(п. 4.2); усреднение по «разрезам в точках» в чистом виде (п. 4.3);
мантеловские схемы (п. 4.4, 4.5); BFS линейной модели при n >= 10.
