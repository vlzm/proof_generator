# H13-I — вердикт сессии 9

Дата: 15.09.2026 (сессия 9). Задача из `docs/notes/h13_line_model.md` §6 /
PLAN §8: доказать H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi из S_n,
всех n >= 4), бюджет 1 сессия до письменного вердикта. Код и данные:
`experiments/h13i_search.py` (h13i_search-1.0), `data/runs/h13i_search/`.

## 1. Что сделано

1. Реализован и проверен `fast_I(pi)` — O(n^2 log n) вычисление `I(pi)`
   (вместо прежнего O(n^4): n^2 разрезов x O(n^2) подсчёт инверсий каждый)
   через рекуррентное обновление Фенвик-деревом: при фиксированном разрезе
   позиций q сдвиг значений s -> s+1 меняет inv на `n - 1 - 2m`, где m —
   индекс в линии элемента со значением s (он «оборачивается» из минимума
   в максимум, остальные пары порядок не меняют). Даёт O(n) на шаг s вместо
   пересчёта, O(n^2 log n) на всю перестановку. Проверено против brute force:
   исчерпывающе 3 <= n <= 8, выборочно n = 9, 10, 12, 15 (200 случайных
   каждое) — совпадает всегда.
2. Проверены (и отклонены) два кандидата на «достаточное подмножество
   разрезов» вместо полного перебора n^2: разрезы «по данным» (n штук,
   начало в одной из точек перестановки) и «один q, только s» (n штук).
   Оба дают нарушение bound на растущей доле pi при 4 <= n <= 8 (таблица —
   `data/runs/h13i_search/report.md` §2). Второе воспроизводит именно
   контрпример леммы C (`(0,5,4,3,2,1,6)`, n = 7) — независимое
   подтверждение вывода прошлой сессии, что совместный выбор (q, s) нужен
   по существу, не сводится к оптимизации одной координаты.
3. С `fast_I` найден способ проверять `I(pi) <= bound` для отдельных
   перестановок при n на порядок больше прежнего (n = 10 — предел
   исчерпывающего перебора C33; здесь — n до 100 для отдельных входов).
   Поиск контрпримера: отражения (исчерпывающе по h), аффинные `a*i+b`
   (исчерпывающе по обратимым a и всем b), случайная выборка (200–3000 на
   n) для n = 11..100; отдельно симулированный отжиг, максимизирующий
   `I(pi)` (6 рестартов, 8000–15000 итераций) для n = 11..24. Максимум во
   всех случаях — ровно `floor((n-1)^2/4)`, достигается на отражениях;
   ни разу не превышен. Это не доказательство (перебор конечен и
   неисчерпывающий при n > 10), но убирает по крайней мере лёгкие
   контрпримеры до n = 100 и подтверждает, что отражения остаются
   единственным наблюдаемым экстремумом на этом диапазоне.

## 2. Что не сделано — доказательство H13-I

Испробованные направления (из списка кандидатов §6 прошлой сессии и
собственные) не дали доказательства за сессию:

- Совместный («одновременный») сдвиг обоих разрезов вместе (`(q, s) ->
  (q+t, s+t)`) не был доведён до содержательной леммы: не нашлось чистого
  выражения для того, как `I` меняется при таком сдвиге, которое сводило бы
  задачу к более простому одномерному перебору.
- Ограниченные семейства разрезов (п. 1.2 выше) — отклонены с доказательными
  контрпримерами.
- Экстремальность отражений через C32 (баланс дуг) не была развита в
  доказательство того, что отражения — глобальный максимум `I` (это
  наблюдение, не теорема): не построено ни одного локального «сжимающего»
  преобразования pi (обмен соседних значений или похожее), про которое
  доказано, что оно не увеличивает `I`, и что оно ведёт от произвольной pi
  к отражению — это оставалось бы естественным следующим шагом, если
  задача будет возобновлена, но не начато по существу.
- Литература о торических классах перестановок не изучалась (нет доступа к
  внешним источникам в рамках сессии; это по-прежнему открытый пункт).

## 3. Решение

За сессию бюджет исчерпан (правило 12 AGENTS.md), доказательства нет.
Статус H13-I — CONJECTURED, без изменений; новые числа (§1) добавлены как
подтверждающие и отклоняющие данные, не как доказательство и не как
опровержение.

Согласно условию задачи (`docs/notes/h13_line_model.md` §6 и PLAN §8:
«если нет за сессию — переход к индукции H3 (PLAN §4.3)») — следующая
задача смещается на индуктивную редукцию H3 (PLAN §4.3, п. 3): переход от
sigma_(n-1) к sigma_n (или от произвольной задачи размера n-1 к размеру n)
с оценкой стоимости имитации ходов меньшей задачи под вращениями L/R,
которые двигают весь массив (нельзя молча исключать фиксированный
элемент), и восстановлением ориентации. Бюджет по PLAN §4.3 — 2 сессии до
вердикта; эта сессия его не начинает (только пересдвигает очередь) —
оставлено на следующую сессию как отдельная задача с чистым бюджетом.

H13-I остаётся открытой; при возврате к ней — начинать с локального
сжимающего преобразования (см. п. 2 выше) или с обзора известных
результатов о минимальном числе инверсий по торическому классу
перестановки, если источники станут доступны.
