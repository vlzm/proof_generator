Дата: 16.09.2026 (сессия 9). Бюджет — 1 сессия до письменного вердикта
(PLAN §8). Код: `experiments/line_toric_scan.c` (line_toric_scan-1.0),
`checks/check_C37.py` (check_C37-1.0). Доказательство:
`docs/proofs/C37_toric_mean_bound.md`. Отчёты: `data/runs/line_toric_scan/`,
`data/runs/check_C37/`. Предыдущая заметка по H13 — `docs/notes/h13_line_model.md`

## 0. Вердикт

**H13-I (`I(pi) <= floor((n−1)^2/4)` при всех n и всех pi) не доказана
и не опровергнута.** Контрпримеров не найдено: утверждение проверено
исчерпывающе при 4 <= n <= 13 (все торические классы) и на всех
структурированных семействах до n = 120, включая полное аффинное семейство.
За сессию получено:

1. **Переформулировка** (доказана): H13-I равносильна «существует разрез
   с не менее чем `floor(n^2/4)` согласованными парами», то есть
   `max_{a,b} D(a, b) >= floor(n/2)`, где `D = (согласованные) − (инверсии)` —
   числитель тау Кендалла. Требуемый перевес — всего `Θ(n)` при `Θ(n^2)` парах.
2. **C37 PROVED**: `I(pi) <= floor((n−1)(2n−1)/6)` при всех n >= 2 — первая
   общая (при всех n) верхняя оценка I. Это `≈ n^2/3` против цели `≈ n^2/4`.
3. **C38 PROVED**: оценка C37 — ровно предел метода усреднения; на отражениях
   доля разрезов, дающих `inv = I`, равна 1/n (чётное n) или 2/n (нечётное).
   Доказательство H13-I обязано указывать разрез почти точно.
4. **Точность H13-I доказана при всех n** (раньше — конечные данные до n = 10):
   отражения дают `I = floor((n−1)^2/4)` (лемма 6 доказательства).
5. Исчерпывающая проверка H13-I расширена с `4 <= n <= 10` до `4 <= n <= 13`:
   `max_pi I = floor((n−1)^2/4)`, максимум достигается ровно на одном
   торическом классе — классе отражений.
6. **Правило выбора разреза (новая гипотеза H13-S, строка C39)**: разрез,
   минимизирующий `sum_j (w_j − j)^2`, даёт `inv <= floor((n−1)^2/4)` и даже
   ровно `I(pi)` — все торические классы при 4 <= n <= 13 и семейства до
   n = 40; прочие простые правила опровергнуты.
   Это первый кандидат на доказательство, согласованный с требованием C38.
7. Аффинное семейство: среднее по торическому классу `pi(i) = a·i + b` равно
   `n(n−1)/4 − n·s(a, n)`, где `s(a, n)` — сумма Дедекинда; `max_a min_t inv`
   равен `floor((n−1)^2/4)` и достигается только при `a = n − 1` (проверено
   для всех a при n <= 120).

Следующая задача по плану — не H13-R (она осмысленна только после H13-I),
а индукция H3 (PLAN §4.3, п. 3); H13-I остаётся открытой с конкретными
кандидатами §4 ниже.

## 2. Почему усреднение закрыто (а не «не сработало»)

Точное среднее числа инверсий по всем n^2 разрезам равно
`mean(pi) = C(n,2)/2 − A(pi)/(4n^2)`, где
`A(pi) = sum_{i≠i'} h(i'−i)·h(pi(i')−pi(i))`, `h(x) = n − 2(x mod n)`
(лемма 3). Отсюда:

- `mean(pi) <= floor((n−1)^2/4)` ⟺ `A(pi) >= 2n^2·C(n,2) − 4n^2·floor((n−1)^2/4)`,
  то есть `A >= n^3` при чётном n и `A >= n^2(n−1)` при нечётном. Доля
  перестановок, проходящих этот тест: 0/24, 5/120, 6/720, 56/5040, 488/40320
  при n = 4, ..., 8 — то есть усреднение доказывает H13-I примерно для 1 %
  входов, а не «почти для всех, кроме отражений».
- `max_pi mean(pi) = (n−1)(2n−1)/6` ровно на отражениях (леммы 4, 5), откуда
  C37 и теорема C38(a): любое фиксированное (не зависящее от pi)
  распределение весов на разрезах даёт оценку не лучше `(n−1)(2n−1)/6`.
- На отражении `inv >= floor((n−1)^2/4)` во всех n^2 разрезах, а равенство —
  ровно в n (или 2n) из них. Значит и адаптивное усреднение обязано быть
  сосредоточено на этих n разрезах (C38(b)).

Вывод: любой будущий аргумент должен *выбирать* разрез, а не усреднять; и
выбор должен быть точным с точностью до множества плотности 1/n.

## 3. Разобранные подходы

1. **Усреднение по всем n^2 разрезам** — закрыто (§2). Ранее было известно
   лишь как наблюдение о конкретных входах (`h13_line_model.md` §1.7, §6);
   теперь есть точная граница метода и доказательство её оптимальности.
2. **Индукция по одному элементу** — опровергнута раньше (n = 8, аффинный
   вход `(0,5,2,7,4,1,6,3)`: I = 11, все восемь редукций дают 6).
3. **Семейство «первый элемент линии равен t»** — опровергнуто раньше для
   каждого фиксированного t. Замечание: по C38(b) семейство из n разрезов —
   правильного порядка, так что подход не безнадёжен по размеру; неверен
   именно способ выбора.
4. **Локальная оптимальность (лемма C прежней заметки)** — необходима, но
   недостаточна. Новое наблюдение: полное двумерное условие локальной
   оптимальности — это уже глобальная оптимальность. Точная формула изменения
   при совместном сдвиге разрезов на (k, l) (проверена для всех (k, l) и всех
   разрезов при 4 <= n <= 7):

   ```text
   Delta(k, l) = (k + l)(n − 1) + 2kl − 2 S(k) − 2 T(l) − 2n·c(k, l),
   S(k) = sum_{j<k} w_j,  T(l) = sum_{x<l} pos_w(x),  c(k, l) = #{j < k : w_j < l}.
   ```

   При l = 0 и k = 0 получаются оба условия леммы C. Так как `Delta(k, l) >= 0`
   для всех (k, l) равносильно «w — минимум своего класса», усиливать лемму C
   до всех пар (k, l) бессмысленно: это и есть исходная задача. Полезным может
   быть только частичный набор пар (например, l ∈ {0, 1} и все k) — не пробован.
5. **Блочный критерий** (лемма 7 доказательства): если при каком-то разрезе
   линия распадается в прямую сумму блоков с `sum C(b_t, 2) <= floor((n−1)^2/4)`,
   H13-I для этой pi верна; в частности достаточно одной дуги из `floor(n/2)`
   подряд идущих позиций, переходящей в дугу подряд идущих значений. Покрытие
   падает: 24/24, 110/120, 612/720, 3346/5040, 21616/40320 при n = 4, ..., 8;
   у `pi(i) = 2i mod 5` блочные разложения бывают только вида (1, 4) и (4, 1),
   лучшая блочная оценка 6 > 4 при `I = 3`.
6. **Моментные методы.** На отражениях распределение inv по классу известно
   точно: значения `C(k,2) + C(n−k,2)`, k = 1, ..., n, каждое ровно n раз.
   Тогда `mu ≈ n^2/3`, `min = n^2/4`, `max = C(n,2)`, дисперсия `≈ n^4/180`,
   и оценка `mu − min >= sigma^2/(max − mu)` даёт лишь `≈ n^2/30 < n^2/12` —
   требуемого зазора не хватает. Любой аргумент, использующий только моменты
   распределения inv по классу, обязан быть точным на отражениях, где
   `max_{a,b} D` равно ровно `floor(n/2)`.
7. **Литература (не проверена).** Найдены (только по названиям и аннотациям,
   тексты недоступны: доступ к arxiv.org из сессии заблокирован прокси)
   работы о «circular sorting»: R. M. Adin, N. Alon, Y. Roichman, «Circular
   sorting», arXiv:2502.14398 (2025) — заявлено: точная максимальная длина
   сортировки n помеченных точек на окружности соседними обменами;
   продолжения — arXiv:2510.18529, arXiv:2608.06338. Статус аудита:
   **не прочитано**, в доказательствах не используется. Это прямой сосед нашей
   величины `N_X` (обмены на окружности) и первый кандидат к чтению в сессии
   с доступом к сети.

## 4. Кандидаты для следующего захода по H13-I

1. **Правило Спирмена — главный кандидат.** Разрез, минимизирующий
   `sum_j (w_j − j)^2` (равносильно: максимизирующий `sum_j j·w_j`), даёт
   `inv <= floor((n−1)^2/4)`, и даже, в **сильной форме**, ровно `I(pi)`:
   любой разрез с минимальным расстоянием Спирмена минимизирует и число
   инверсий. Ничьи разрешаются пессимистично (берётся наибольшее inv среди
   победивших разрезов). Нарушений нет: исчерпывающе по всем торическим
   классам при 4 <= n <= 13 (обе величины постоянны на классе;
   `experiments/line_toric_scan.c` 1.1, счётчики `H13S_weak_failures`,
   `H13S_strong_failures`), независимо вторым кодом по всем pi при
   4 <= n <= 9 и на семействах (все отражения, все аффинные, 60 случайных,
   блочные) при n = 16, 20, 25, 30, 40 (`experiments/line_cut_rules.py`,
   отчёт `data/runs/line_cut_rules/`), плюс 4000 случайных при n = 10, 11, 12
   и 1500 при n = 13, 15, 18. Гипотеза H13-S, строка C39. Это именно «выбор
   разреза», которого требует C38, причём выбор задаётся минимумом явного
   квадратичного функционала. Другие простые правила не годятся: минимум
   footrule нарушается уже при n = 4 на отражении `(0,3,2,1)` и при n = 8 на
   `(0,7,6,5,4,3,2,1)`, а максимум числа неподвижных точек, круговое смещение
   и запас леммы C нарушаются массово (`data/runs/line_cut_rules/report.md`).
   К доказательству: по известному неравенству Дэниелса `−1 <= 3τ − 2ρ <= 1`
   (τ = `D/C(n,2)`, ρ = `1 − 6·sum d^2/(n(n^2−1))`; численно проверено при
   3 <= n <= 7, доказательство не воспроизводилось) условие `D >= 0` следует
   из `sum_j (w_j − j)^2 <= n(n^2−1)/12`. Среднее `sum d^2` по всем n^2
   разрезам равно ровно `n(n^2−1)/6` (так как среднее `sum_j j·w_j` равно
   `n(n−1)^2/4`) — ровно вдвое больше порога, а на отражении минимум
   `sum d^2` равен примерно `n^3/12`, то есть снова ровно на границе. Значит
   «Спирмен + Дэниелс» в лоб не закрывает даже более слабую веху `D >= 0`;
   нужен либо более точный минимум `sum d^2` по разрезам, либо неравенство
   между τ и ρ, учитывающее структуру торического класса.
2. **Устойчивость в лемме 5.** Тест «среднее <= цели» (§2) покрывает лишь ~1 %
   входов, но для pi, близких к отражению, есть и вторая структура: у
   отражения оптимальный разрез — «сбалансированный блок» (лемма 6 + лемма 7).
   Возможная схема: разбить вход на «почти отражения» (малое `A + max`) —
   для них строить блочный разрез возмущением, и «все остальные» — для них
   найти усиление усреднения, использующее не только первый момент. Слабое
   место: для случайной pi `A ≈ 0`, а нужен запас порядка `n^3`.
3. **Аффинное подсемейство как отдельная теорема.** Для `pi(i) = a·i + b` все
   линии имеют вид `(a·j + t) mod n`, и H13-I превращается в утверждение
   `min_t inv((a j + t) mod n) <= floor((n−1)^2/4)` для всех a, взаимно простых
   с n. Среднее по t равно `n(n−1)/4 − n·s(a, n)` (сумма Дедекинда), значит для
   `a = n − 1`, `a = n − 2` и многих других усреднение не годится и нужен выбор
   t — естественный аппарат — цепные дроби и взаимность Дедекинда. Данные:
   максимум по a достигается только при `a = n − 1`. Это самая конкретная
   подзадача, и именно аффинные входы были источником контрпримеров в сессиях
   4–5.
4. **Более слабая веха H13-I′: `max_{a,b} D >= 0`**, то есть
   `I(pi) <= C(n,2)/2 ≈ n^2/4 − n/4`. Слабее цели всего на `n/4`, но уже не
   следует из усреднения (на отражениях среднее `D` отрицательно). Доказать
   H13-I′ — самостоятельный результат и, вероятно, шаг к H13-I.
5. **Двойственная форма.** Замена позиций `i -> −i` даёт `D -> −D`, поэтому
   H13-I равносильна утверждению «у каждой pi есть разрез с не менее чем
   `floor(n^2/4)` инверсиями». Максимум иногда удобнее минимума (например,
   жадные аргументы «взять разрез с наибольшим первым элементом»).
6. **Индукция не по элементу, а по паре / по сжатию.** Удаление одного
   элемента опровергнуто; сжатие двух соседних значений (или двух соседних
   позиций) в один элемент — не пробовано; шаг бюджета
   `floor((n−1)^2/4) − floor((n−3)^2/4) = n − 2` заметно больше, чем у
   одноэлементного шага.

## 5. Куда это ведёт в проекте

`H13-I + H13-R => C15` (по C12). Поскольку H13-I не доказана, C15 этим путём
не получен; H13-R (бюджет вращений `floor(n^2/4)`) остаётся VERIFIED при
4 <= n <= 9 и осмысленна только вместе с H13-I. Следующая задача по PLAN §8 —
индукция H3 (PLAN §4.3, п. 3) как независимый путь к C15; H13-I возвращается
в план с кандидатами §4, когда появится новый инструмент (или доступ
к литературе §3.7).
