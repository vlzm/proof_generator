# H13-I — попытка сессии 9: вердикт

Дата: 14.09.2026 (сессия 9). Задача из PLAN §8 / `docs/notes/h13_line_model.md`
§6: доказать H13-I (`I(pi) <= floor((n-1)^2/4)` для всех pi, при всех n >= 4),
бюджет 1 сессия до письменного вердикта. Ядро не используется (задача —
чистая комбинаторика перестановок); опорные данные — C33/C35
(`experiments/line_profile.c`, VERIFIED 4 <= n <= 10).

## Что сделано

1. Найдено и доказано точное (не приближённое) тождество для инверсий при
   сдвиге значений одной перестановки на константу по модулю n, через
   телескопирование по шагам сдвига (C37, `docs/proofs/C37_shift_recursion.md`,
   `checks/check_C37.py`, PASS). Тождество даёт **точную** формулу
   `I(pi)` при использовании только одной степени свободы (`c` при `q = 0`,
   или, по симметрии `pi <-> pi^{-1}`, `q` при `c = 0`).
2. Тождество аналитически (без перебора) объясняет точность C33/C35 на
   отражениях: `min_c inv(sigma_c(rev_n)) = floor((n-1)^2/4)` следует прямо
   из тождества и тождества C12, без обращения к таблицам (§2 доказательства
   C37).
3. Проверена (исчерпывающе, `checks/check_C37.py`, 4 <= n <= 9) гипотеза о
   том, что **одной** координаты (или независимого применения тождества к
   `pi` и к `pi^{-1}` с выбором лучшего) достаточно для H13-I. **Опровергнуто**:
   начиная с `n = 7`, максимум по pi обеих стратегий превышает
   `floor((n-1)^2/4)` ровно на 1 (10 против 9 при n=7; 13 против 12 при n=8;
   17 против 16 при n=9). Минимальный свидетель:
   `pi = (0,5,4,3,2,1,6)` при n = 7 — истинный минимум `I(pi) = 8` достигается
   на 10 парах `(q,c)` из 49, ни одна не имеет `q = 0` или `c = 0`.

## Вывод

H13-I доказательству этой сессии не поддалась: она существенно двумерна —
информация об одном сдвиге (даже точная, не оценка) не определяет и не
ограничивает снизу вклад второго, как показывает предъявленный минимальный
контрпример. Это независимо (другим методом — точной рекуррентой, а не
локальными неравенствами лемм C сессии 8) подтверждает вывод
`docs/notes/h13_line_model.md` §4 (лемма C): доказательство должно
анализировать совместный сдвиг обеих координат.

Попытки продолжить в сторону совместного анализа в рамках бюджета сессии
(комбинация двух формул `inv(0,c)` и `inv(q,0)` через общий кросс-член,
разложение по XOR арок на торе Z_n x Z_n намеченное в
`docs/notes/h13_line_model.md` §6) не завершены содержательным результатом:
запись `inv(q,c)` как объединения двух «прямоугольников» на торе (по каждой
паре точек) получена, но не привела к явной оценке максимума по покрытию за
отведённое время.

**H13-I остаётся OPEN.** Статус C33/C35 не меняется (данные, не доказательство,
VERIFIED 4 <= n <= 10). Новый инструмент (C37) сохраняется для следующей
попытки: он даёт точную (не только верхнюю) формулу зависимости `inv` от
одной координаты, что может пригодиться для совместного аргумента (например,
фиксируя `q` не в 0, а в оптимуме одной задачи, и повторно применяя тождество
уже к `rotate_q(pi)` — эта комбинация тоже проверена здесь как «combo» и уже
включена в таблицу; более общая идея — не двух-шаговая оптимизация, а прямая
оценка `max_{q,c}` через тождество для ОБЕИХ координат одновременно — не
испробована).
