# H13-I — вердикт сессии 9: не доказана и не опровергнута

Дата: 14.09.2026. Бюджет: 1 сессия до письменного вердикта (PLAN §8) —
израсходован. Предмет:

> **H13-I.** При всех n >= 4 и всех pi из S_n: `I(pi) <= M_n = floor((n−1)^2/4)`,
> где `I(pi)` — минимум числа инверсий переразмеченной линии по всем n^2
> двойным разрезам (по торическому классу pi).

Итог: **open**. Гипотеза не опровергнута (контрпримера нет, поиск при
11 <= n <= 36 ничего не дал) и не доказана. Доказаны четыре вспомогательных
утверждения (C37–C40, `docs/proofs/C37_toric_inversions.md`, чекер
`checks/check_C37.py` PASS), включая первую безусловную общую оценку `I(pi)`.
Данные — `data/runs/h13i_toric/report.md`.

## 1. Что доказано (новое)

1. **Словарь (C37).** Разрез `(q, c)` ⟷ пара «начало позиций alpha = q+1,
   начало значений beta = q+1−c». Пара точек согласована при разрезе o ровно
   когда o лежит в одном из двух «одноимённых» ящиков, натянутых на эту пару
   (точная форма §6 старой заметки). Далее

       inv(alpha, beta) = | E Δ cut(S_alpha Δ T_beta) |,

   где E — граф инверсий pi при базовом разрезе, `S_alpha` (`T_beta`) — точки с
   позицией (значением) меньше alpha (beta), `cut(U)` — полный двудольный граф
   разбиения. Эквивалентно: **разрез = квадрантная раскраска** точек знаком
   `sgn(x − alpha)·sgn(y − beta)`, и H13-I ⟺ «найдётся разрез с
   `conc − inv >= floor(n/2)`». Есть замкнутая формула `inv(alpha, beta)` и
   тождество прямоугольника (смешанная вторая разность равна `2 − 2n·[pi(a)=b]`),
   из которого получается точная формула сдвига разреза на (k, l).
2. **Релаксация (C38).** Для *любого* графа на n вершинах найдётся разбиение с
   `|E Δ cut(U)| <= M_n`; доказательство — жадное добавление вершин по одной с
   чётностным выигрышем (`M_n = sum_{m<n} floor(m/2)`). Константа M_n точна уже
   на релаксации (граф K_n = обращённая перестановка). **Следствие для метода:**
   никакой аргумент, который не использует ограничение «раскраска квадрантная»,
   не может дать в H13-I ничего лучше M_n, а вся трудность H13-I — именно в этом
   ограничении (n^2 раскрасок из 2^(n−1)).
3. **Безусловная оценка (C39).** `sum_{все n^2 разрезов} conc = T(pi) =
   sum_{a≠b} p_ab·v_ab`, и по неравенству о перестановках
   `T(pi) >= n^2(n^2−1)/6` с равенством ровно на отражениях. Отсюда для всех
   n >= 2 и всех pi

       I(pi) <= floor( C(n,2) − T(pi)/n^2 ) <= floor( (n−1)(2n−1)/6 ) ≈ n^2/3.

   Это первая доказанная общая оценка `I(pi)` (раньше были только конечные
   данные при 4 <= n <= 10).
4. **Тождество двух разрезов (C40).** Для любых разрезов o, o' с четырьмя
   ящиками размеров A, B (одноимённые) и C, D (разноимённые):

       inv(o) + inv(o') = 2·sum_ящики inv(ящик) + 2CD + (A+B)(C+D).

   Следствие: если у pi есть два разреза с `C = D = 0` и `|A − B| <= 1`, то
   H13-I для неё верна. Это покрывает все отражения (новое короткое
   доказательство верхней оценки `I(pi_h) <= M_n` без слов и без C32),
   тождественную перестановку и все «двублочные» по кругу перестановки.

## 2. Что перепробовано и почему не сработало

| Подход | Где ломается |
|---|---|
| Усреднение по всем n^2 разрезам | Даёт только `n^2/3` (C39). Разрыв Θ(n) остаётся *и для случайной* pi: `E[T] = n^3(n−1)/4`, средняя оценка `n(n−1)/4` ровно на n/4 больше цели. Значит нужен разброс inv по разрезам или отбор разреза, среднего не хватает принципиально |
| Индукция по одному элементу | Известный контрпример n = 8 (`(0,5,2,7,4,1,6,3)`): I = 11, все восемь редукций дают 6. Объяснение в новых терминах: после удаления точки её сторона в квадрантной раскраске *вынуждена* (свобода есть только когда разрез стоит ровно в позиции или ровно в значении удалённой точки) |
| Усиление «для всякого alpha найдётся beta» (дало бы индукцию с выбором стороны) | Ложно: `max_alpha min_beta inv` = 10 при n = 7 (`(0,1,6,5,4,3,2)`), 13 при n = 8 |
| Семейства n разрезов `(t+h, pi(t)+k)` (сдвиг относительно точки данных на фиксированный вектор) | Ложно при любом (h, k): лучшее семейство даёт 5, 7, 11, 16 при n = 5..8 против 4, 6, 9, 12. Идея была в том, что для тождественной перестановки хороши разрезы «на диагонали данных», а для отражений — «на n/2 дальше»; вектор (n/4, n/4) удовлетворяет обоим, но не остальным pi |
| Конечная система локальных условий оптимальности разреза | Условия глубины 0 (лемма C старой заметки) ложны уже при n = 7; глубины 1 — при n = 10 (линия `(0,1,8,7,6,5,4,3,2,9)`, inv = 21 > 20); глубины 2 достаточно при n <= 10. Нужная глубина, видимо, растёт с n, так что «конечная система неравенств» — не путь |
| Жадный алгоритм теоремы 2.1 внутри семейства разрезов | Жадному нужно n свободных знаков, у разреза их 2. Локальный максимум `conc − inv` по четырём одношаговым соседям даёт только 4 «счастливые» точки из n (при чётном n каждая даёт +1 по чётности), а нужно n |
| Тождество двух разрезов как индукция/рекурсия | При `C + D = t > 0` тривиальная оценка `inv(ящик) <= C(|ящик|,2)` теряет ровно `t^2/4`; у аффинных pi с наклоном ≠ ±1 любые два разреза дают `t = Θ(n)`. Нужна рекурсия внутрь ящиков, но там разрез уже зафиксирован |
| Второй момент («min <= среднее − Var/размах») | На отражениях `Var ≈ n^4/180`, размах `≈ n^2/4`, значит выигрыш `≈ n^2/45`, а нужен `n^2/12`. Не хватает множителя ~4; для случайных pi, наоборот, с большим запасом |

## 3. Численный статус H13-I

- VERIFIED исчерпывающе при 4 <= n <= 10 (сессия 8, `line_profile`; сессия 9
  независимо пересчитала 4 <= n <= 9 другим кодом: `max I = M_n`, аргмаксимумы —
  ровно n отражений).
- SAMPLED при 11 <= n <= 36: подъём по транспозициям (400 рестартов, n <= 26;
  при n <= 16 максимум найден равным ровно M_n), все аффинные при n <= 36,
  все отражения с одной и двумя транспозициями при n <= 20. Превышений нет.

## 4. Что я считаю самым перспективным дальше (если к H13-I вернутся)

1. «Лестничный» жадный алгоритм: при движении (alpha, beta) по монотонной
   лестнице от (0,0) до (n,n) каждая точка меняет цвет ровно дважды (при
   переходе alpha через её позицию и beta через её значение). Задача:
   выбрать лестницу и момент остановки с `conc − inv >= floor(n/2)`. Это
   точная переформулировка H13-I, в которой видна степень свободы (выбор
   слияния двух порядков), отсутствующая в жадном алгоритме теоремы 2.1.
2. Количественная форма C39 (замечание 3.5): `T = n^2(n^2−1)/6 + sum_a D_a`,
   где `D_a >= 0` измеряет отклонение pi от отражения. Нужна вторая оценка
   вида «если `sum D_a` мало, то pi близка к отражению и работает
   тождество двух разрезов (C40)». Обе половины сейчас пограничны по
   порядку n^4/12 — требуется аккуратная константа.
3. Литература: задача = «покрывающий радиус разрезного кода K_n на графе
   инверсий, при ограничении на квадрантные разбиения». Релаксация (C38)
   решается полностью; ограниченная версия, насколько я знаю, не описана.
