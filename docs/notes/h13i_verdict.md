## 0. Постановка и обозначения

pi — перестановка Z_n. Для разреза (q, c) линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1 (`h13_line_model.md` §0).
Замена `a = q + 1`, `b = q + 1 − c` — биекция Z_n^2 → Z_n^2, поэтому всюду ниже

    w^{a,b}_j = (pi(a + j) − b) mod n,   F(a, b) = inv(w^{a,b}),
    I(pi) = min_{a,b} F(a, b),           M = M_n = floor((n − 1)^2 / 4).

**H13-I:** `I(pi) <= M` при всех pi и всех n >= 4.
Эквивалентно (дополнение до всех пар): у некоторого разреза не менее
`floor(n^2/4) = C(n,2) − M` неинверсий.

Точки `(i, pi(i))` образуют перестановочную матрицу на торе Z_n × Z_n;
разрез (a, b) — угол, по которому тор разворачивается в квадрат.
Обозначения: `inv(pi)` — число инверсий самой pi; `A(a) = sum_{i<a} pi(i)`;
`B(b) = sum_{j<b} pi^{-1}(j)`; `N(a, b) = #{i < a : pi(i) < b}`
(представители 0..n−1); `C(n,2) = n(n−1)/2`.

## 1. Итог одной фразой

Сетка разрезов `F` описана точно (§2: пять лемм, все доказаны и проверены
машинно), и из этого описания следует **почему провалились все прежние
попытки усреднения и почему провалятся любые будущие того же вида**
(§3, лемма 6: никакое не зависящее от pi взвешивание разрезов не даёт H13-I,
и любое семейство таких взвешиваний должно содержать не менее n/2 штук).
Найдено одно усиление, пережившее исчерпывающую проверку при 4 <= n <= 12
(§5), и восемь кандидатов отвергнуты с наименьшими контрпримерами (§4).
В литературе найдена близкая теорема (§6), но она о другой величине:
расстояние циклической сортировки `cs(pi)` строго меньше `I(pi)` уже при
n = 8, поэтому H13-I из неё не следует.

## 2. Точная структура сетки разрезов (доказано)

**Лемма 0 (дуговое описание пары).** Пусть 0 <= i < j <= n−1 — позиции,
`dx = j − i`, `dy = (pi(j) − pi(i)) mod n`. Пара {i, j} — инверсия линии
`w^{a,b}` тогда и только тогда, когда выполнено ровно одно из двух условий:
`a ∈ (i, j] := {i+1, ..., j}` (дуга длины dx) и
`b ∈ (pi(i), pi(j)]` (циклическая дуга длины dy).

*Доказательство.* Индекс позиции x в линии равен `(x − a) mod n`, поэтому i
стоит раньше j тогда и только тогда, когда `(i−a) mod n < (j−a) mod n`.
Положив `u = (i−a) mod n`, получаем `(j−a) mod n = u + dx − n·[u + dx >= n]`,
так что условие равносильно `u + dx < n`, то есть
`(i−a) mod n ∉ {n−dx, ..., n−1}`, то есть `a ∉ {i+1, ..., i+dx} = (i, j]`.
Точно так же значение позиции i меньше значения позиции j тогда и только
тогда, когда `b ∉ (pi(i), pi(j)]`. Инверсия — несовпадение двух порядков. ∎

**Лемма 1 (приращения).** Для всех a, b:

    F(a+1, b) = F(a, b) + n − 1 − 2·((pi(a) − b) mod n),
    F(a, b+1) = F(a, b) + n − 1 − 2·((pi^{-1}(b) − a) mod n).

*Доказательство.* Линия `w^{a+1,b}` получается из `w^{a,b}` переносом первого
элемента `w_0 = (pi(a) − b) mod n` в конец. Стоя первым, он инвертирован ровно
с меньшими элементами (их `w_0`, так как линия — перестановка 0..n−1); стоя
последним — ровно с большими (их `n − 1 − w_0`); остальные пары не меняются.
Для второй формулы: `w^{a,b+1}_j = (w^{a,b}_j − 1) mod n`, то есть элемент со
значением 0 становится наибольшим, а все прочие сохраняют взаимный порядок.
Этот элемент стоит в линии на месте `p = (pi^{-1}(b) − a) mod n`; как минимум
он инвертирован с p элементами перед ним, как максимум — с `n − 1 − p`
элементами после. ∎

**Лемма 2 (замкнутая форма).** Для всех a, b ∈ {0, ..., n−1}

    F(a, b) = inv(pi) + (n−1)(a + b) + 2ab − 2A(a) − 2B(b) − 2n·N(a, b).

*Доказательство.* По лемме 1 `F(a,0) = inv(pi) + (n−1)a − 2A(a)` и
`F(0,b) = inv(pi) + (n−1)b − 2B(b)` (при b = 0 имеем `(pi(i) − 0) mod n = pi(i)`,
при a = 0 — `(pi^{-1}(j) − 0) mod n = pi^{-1}(j)`). Смешанная вторая разность:

    F(a+1,b+1) − F(a+1,b) − F(a,b+1) + F(a,b)
      = 2[((pi^{-1}(b) − a) mod n) − ((pi^{-1}(b) − a − 1) mod n)],

а `(t mod n) − ((t−1) mod n)` равно 1 при `t ≢ 0` и `−(n−1)` при `t ≡ 0`.
Значит смешанная разность равна 2 при `pi(a) ≠ b` и `2 − 2n` при `pi(a) = b`.
Суммируя её по прямоугольнику `[0,a) × [0,b)` и прибавляя краевые значения,
получаем `F(a,b) = F(a,0) + F(0,b) − F(0,0) + 2ab − 2n·N(a,b)`, так как число
пар `(a',b')` с `a' < a`, `b' < b`, `pi(a') = b'` равно `N(a,b)`. ∎

**Лемма 3 (постоянные суммы строк и столбцов).** Положим

    T(pi) = sum_{i ≠ j} ((j − i) mod n)·((pi(j) − pi(i)) mod n),
    mu(pi) = C(n,2) − T(pi)/n^2.

Тогда `sum_a F(a,b) = n·mu` при каждом b и `sum_b F(a,b) = n·mu` при каждом a.
В частности `I(pi) <= mu(pi)`.

*Доказательство.* По лемме 1 `sum_a [F(a,b+1) − F(a,b)] =
sum_a (n − 1 − 2((pi^{-1}(b) − a) mod n)) = n(n−1) − 2·n(n−1)/2 = 0`, значит
`sum_a F(a,b)` не зависит от b; симметрично `sum_b F(a,b)` не зависит от a;
обе величины равны `(1/n)·sum_{a,b} F(a,b)`. По лемме 0 пара i < j инвертирована
ровно при `dx(n − dy) + (n − dx)dy = n·dx + n·dy − 2·dx·dy` разрезах; выражение
инвариантно относительно `(dx,dy) -> (n−dx, n−dy)`, то есть относительно выбора
ориентации пары, поэтому

    sum_{a,b} F(a,b) = (1/2) sum_{i≠j} [n·dx + n·dy − 2·dx·dy]
                     = (1/2)[ 2·n·n·(n(n−1)/2) − 2T ] = n^3(n−1)/2 − T,

откуда `sum_a F(a,b) = n^2(n−1)/2 − T/n = n·mu`. ∎

**Лемма 4 (корреляционная форма).** Пусть
`Psi(a,b) = sum_{j∈Z_n} ((j − a) mod n)·((pi(j) − b) mod n)`. Тогда

    F(a, b) = mu(pi) + (n−1)^2/2 − (2/n)·Psi(a, b).

*Доказательство.* Зафиксируем b, положим `v_j = (pi(j) − b) mod n`,
`t_j = (j − a) mod n`. По лемме 1 для любого a'
`F(a',b) − F(a,b) = sum_{j ∈ [a,a')} (n − 1 − 2 v_j)`, где `[a,a')` — циклический
промежуток длины `(a'−a) mod n`. Суммируя по a' и пользуясь леммой 3,

    n·mu − n·F(a,b) = sum_j (n − 1 − 2 v_j)·#{a' : j ∈ [a,a')}
                    = sum_j (n − 1 − 2 v_j)(n − 1 − t_j).

Так как `sum_j (n − 1 − 2 v_j) = 0`, правая часть равна
`sum_j (2 v_j − (n−1)) t_j = 2·Psi(a,b) − (n−1)·n(n−1)/2`. ∎

Следствие. `I(pi) <= M` равносильно `max_{a,b} Psi(a,b) >= (n/2)(mu + (n−1)^2/2 − M)`:
задача — о максимуме циклической взаимной корреляции перестановки с «пилой»
`r(t) = t mod n`. Максимум `Psi` достигает `sum_t t^2` ровно на сдвигах
(`pi(j) = j + const`), то есть `Psi_max` измеряет близость pi к повороту.

**Лемма 5 (двойственность «минимум ↔ максимум»).** Пусть `pi^r(i) = pi(−i mod n)`.
Тогда `F_{pi^r}(a, b) = C(n,2) − F_{pi}((1 − a) mod n, b)`. Следовательно

    H13-I для всех pi   ⟺   max_{a,b} F_{pi}(a,b) >= floor(n^2/4) для всех pi.

*Доказательство.* Линия `pi^r` при (a,b) читает позиции `−a, −a−1, ..., −a−n+1`,
то есть является обращением линии pi при разрезе `(−a − n + 1) mod n = (1−a) mod n`
с тем же b. Обращение линии переводит инверсии в неинверсии. Вторая часть —
применение первой к `pi^r` и равенство `M = C(n,2) − floor(n^2/4)`. ∎

**Проверка.** Леммы 0–5 проверены машинно (`checks/check_C37.py`, часть A):
все pi при 4 <= n <= 7, выборки при 8 <= n <= 11; сетка F строится там строго
по определению (все n^2 линий, подсчёт инверсий), а формулы лемм 1–5
сверяются с ней поэлементно.

## 3. Отрицательный результат: усреднение не может работать (доказано)

**Лемма 6.** Пусть n >= 3. (i) Не существует распределения вероятностей
`lambda` на множестве разрезов Z_n^2, не зависящего от pi, для которого
`sum_{a,b} lambda(a,b)·F_{pi}(a,b) <= M` при всех pi ∈ S_n.
(ii) Более того, если Λ — семейство таких распределений и для каждой pi
найдётся `lambda ∈ Λ` с `sum lambda·F_pi <= M`, то `|Λ| >= n/2`
(и `|Λ| >= n` при чётном n).

*Доказательство.* Для отражений `pi_h(i) = (h − i) mod n` линия разреза (a,b)
равна `w_j = (u − j) mod n` с `u = (h − a − b) mod n`, то есть
`u, u−1, ..., 0, n−1, ..., u+1` — два убывающих блока длин `s = u + 1` и `n − s`,
все перекрёстные пары которых — неинверсии. Значит

    F_{pi_h}(a, b) = C(s,2) + C(n−s,2) = C(n,2) − s(n − s),  s = 1 + ((h−a−b) mod n).

Минимум по (a,b) равен `C(n,2) − floor(n^2/4) = M` и достигается ровно при
`s ∈ {floor(n/2), ceil(n/2)}`, то есть ровно на одной (чётное n) или двух
(нечётное n) «антидиагоналях» `D_t = {(a,b) : a + b ≡ t mod n}`. Так как
`F_{pi_h} >= M` всюду, условие `sum lambda F_{pi_h} <= M` вынуждает lambda быть
сосредоточенным на этих антидиагоналях:

- чётное n: `lambda(D_{h−c}) = 1` для подходящей константы c и всех h — при
  n >= 2 это невозможно (две разные h дают две разные антидиагонали массы 1);
- нечётное n: `lambda(D_{h−c}) + lambda(D_{h−c−1}) = 1` для всех h; суммируя
  по h ∈ Z_n и пользуясь `sum_t lambda(D_t) = 1`, получаем `2 = n`.

Это доказывает (i). Для (ii): при чётном n множества допустимых носителей для
разных h не пересекаются, так что каждой h нужна своя lambda. При нечётном n
одно lambda может обслуживать h и h+1 лишь будучи сосредоточенным целиком на
`D_{h−c}` (из `x + y = 1`, `x + z = 1`, `x + y + z <= 1` следует `y = z = 0`),
и тогда h+2 оно уже не обслуживает; значит каждое lambda обслуживает не более
двух значений h. ∎

Лемма 6 объясняет и закрывает целый класс подходов: равномерное усреднение по
всем `n^2` разрезам (`h13_line_model.md` §1), усреднение по диагонали, по
антидиагонали, по любому фиксированному семейству разрезов и любые их
взвешенные варианты. Доказательство H13-I обязано выбирать разрез
*в зависимости от pi*, причём не менее чем n/2 разными способами.

## 5. Выжившее усиление (C38)

**C38 (гипотеза).** Для всех pi и всех n >= 4

    sum_{b ∈ Z_n} min_{a ∈ Z_n} F(a, b)  <=  n · M.

То есть: *в среднем по сдвигу значений* лучший сдвиг позиций уже даёт не более
M инверсий. Это строго сильнее H13-I (минимум не превосходит среднего) и
строго слабее отвергнутого `rowmax`.

Проверено исчерпывающе по всем торическим классам при **4 <= n <= 12**
(`experiments/toric_cut_scan.c`; `(n−1)!` представителей, 39 916 800 при n = 12,
77 с). Нарушений нет. Максимум `n·M` достигается **ровно на одном торическом
классе — классе отражений** при каждом n от 4 до 12 (`count_maxS = 1`);
столько же (`count_maxI = 1`) классов достигает `I(pi) = M`. Побочно это
расширяет проверку самой H13-I и строки C33 (`max_pi I(pi) = M`) с n <= 10
до n <= 12.

Почему C38 выглядит правильной целью:

- у него нет «лёгкой» части: неравенство точно на отражениях при каждом b
  (`min_a F(a,b) = M` для всех b), поэтому запас нулевой всюду, а не только
  в одной точке;
- оно сводит двумерную задачу к одномерной с усреднением: по лемме 3
  `min_a F(a,b) <= mu` при каждом b, так что **достаточно разобрать случай
  `mu > M`**, то есть `T(pi) < n^2·floor(n^2/4)` (при `mu <= M` C38 и H13-I
  тривиальны). Это точная дихотомия, пригодная для начала доказательства;
- в терминах леммы 4 нужно `sum_b max_a Psi(a,b) >= (n^2/2)((n−1)^2/2 + mu − M)`.

## 6. Литература: «Circular sorting» (Adin, Alon, Roichman)

Поиск (WebSearch, 15.09.2026) нашёл статью R. M. Adin, N. Alon, Y. Roichman,
**«Circular sorting», arXiv:2502.14398**, и продолжения
(arXiv:2608.06338 «Circular sorting in the alternating group»,
arXiv:2510.18529). По сводке поисковой выдачи: для сортировки n помеченных
точек на окружности *соседними обменами* максимальное число обменов равно
ровно `floor((n−1)^2/4)`, доказательство разбито на четыре случая по `n mod 4`.

**Статус аудита: НЕ ПРОЧИТАНА.** Полный текст недоступен: `arxiv.org`,
`web.math.princeton.edu`, зеркала и обзоры заблокированы политикой egress
этой сессии (403 от прокси). Всё, что есть, — сводка поисковой выдачи;
точные формулировки не сверены. В реестре это отражено как CLAIMED
внешнее происхождение без локального аудита.

**Важно: это не H13-I.** Определим `cs(pi)` — наименьшее число обменов
циклически соседних позиций, переводящих pi в поворот тождественной
перестановки. Тогда:

- `cs(pi) <= I(pi)` всегда (выбрать лучший разрез и отсортировать линию
  пузырьком; ни один обмен не пересекает разрез);
- **но равенства нет.** При n = 8 найдено 16 перестановок с `cs < I`;
  лексикографически первая — `(0,3,6,1,4,7,2,5)` (`pi(i) = 3i mod 8`),
  `cs = 8 < 9 = I`; наибольший разрыв — `(0,5,2,7,4,1,6,3)` (`pi(i) = 5i mod 8`),
  `cs = 8 < 11 = I`. Наименьшее n с `cs ≠ I` равно 8 (при 4 <= n <= 7
  проверены все pi, расхождений нет). Пример проверен независимо: `I = 11`
  пересчитан прямым перебором всех 64 разрезов по определению, `cs = 8`
  подтверждён явной последовательностью обменов рёбер `[7,5,6,3,4,1,2,0]`,
  переводящей `(0,5,2,7,4,1,6,3)` в `(2,3,4,5,6,7,0,1)`.
- при 4 <= n <= 8 совпадают максимумы: `max_pi cs(pi) = max_pi I(pi) = M`,
  и оба достигаются на отражениях.

Итого: теорема AAR (если формулировка из сводки верна) даёт `cs(pi) <= M`, а
H13-I требует `I(pi) <= M` — более сильного утверждения. Для C15 нужна именно
H13-I: слово конструкции не должно пересекать разрез, иначе линейная модель
(C33) неприменима.

**Побочное следствие для нижних оценок.** Для любого слова LRX, сортирующего
pi, обмены в неподвижной системе позиций — это обмены циклически соседних
позиций, а вращения дают лишь итоговый поворот; поэтому
`N_X >= cs(pi)`, и `max_pi cs(pi) = floor((n−1)^2/4)` при 4 <= n <= 8
согласуется с C13. Это самостоятельный инструмент нижней оценки для N_X.

## 7. Что осталось нетронутым

- Доказательства H13-I нет; контрпримера нет (и при n <= 12 его не существует).
- Подходы «индукция по одному элементу», «первый элемент = t», «лемма C»
  из `h13_line_model.md` не повторялись и остаются отвергнутыми.
- Не пробовано: доказательство C38 из дихотомии `mu <= M` / `mu > M`;
  экстремальная (обменная) характеризация максимума `sum_b min_a F`;
  чтение AAR после снятия блокировки egress.

## 8. Следующий шаг

Задача H13-I закрыта письменным вердиктом; по правилу PLAN §8 переход к
запасному направлению — индукция H3 (PLAN §4.3, п. 3). Отдельной дешёвой
задачей остаётся аудит arXiv:2502.14398, когда текст станет доступен: если
там доказано `cs <= M`, то для H13-I нужна ещё «лемма о неиспользуемом
ребре», которая при n = 8 ложна для оптимальных слов, но может быть верна
в ослабленной форме `I(pi) <= M`.
