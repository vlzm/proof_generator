# H13-I — сессия 9: попытка доказательства, отрицательные результаты, расширение VERIFIED

Дата: 17.09.2026 (сессия 9). Задача из PLAN §8 (по состоянию на конец сессии 8):
доказать H13-I — `I(pi) <= floor((n-1)^2/4)` при всех pi, всех n >= 4, где
`I(pi) = min_{q,c} inv(w)` по всем n^2 двойным разрезам (`docs/notes/h13_line_model.md`
§0), бюджет 1 сессия до письменного вердикта. Код: `experiments/line_profile_fast.c`
(line_profile_fast-1.0), `experiments/h13i_cut_freedom.py` (h13i_cut_freedom-1.0).
Отчёты: `data/runs/h13i_verdict/`.

## Вердикт

**H13-I не доказана за сессию.** Общего доказательства нет; найдены две новые
количественные причины, почему естественные короткие пути к доказательству
не работают (п. 1–2 ниже), одна структурная переформулировка, полезная для
следующей попытки (п. 3), и расширение исчерпывающей проверки с 4<=n<=10
до 4<=n<=11 новым более быстрым алгоритмом (п. 4). Решение по разветвлению
плана: переход к индукции H3 (PLAN §4.3, п. 3) как следующая задача.

## 1. Усреднение по всем n^2 разрезам не работает (количественно)

Для пары позиций `i<j` (разрыв `g=j-i`) и соответствующего разрыва значений
`g'` (направленного: `g'=pi(j)-pi(i) mod n`) число разрезов `(q,c)` из n^2,
на которых пара `(i,j)` согласована (не даёт инверсии), равно точно
`f(g,g') = (n-g)(n-g') + g*g' = n^2 - n(g+g') + 2*g*g'`. Суммируя по всем
C(n,2) парам и деля на n^2, получаем среднее число согласованных пар по всем
разрезам. Если бы это среднее было `>= floor(n^2/4)` для каждой pi, H13-I
следовала бы немедленно (какой-то разрез не хуже среднего).

Это не так: минимум по pi среднего числа согласованных пар (при
4 <= n <= 8, точный перебор `experiments/h13i_cut_freedom.py`) равен
2.5, 4, 5.833, 8, 10.5 при n = 4..8 — заметно **ниже** порога
`floor(n^2/4)` = 4, 6, 9, 12, 16, причём минимум достигается именно на
экстремальных для I(pi) входах (перестановки вида `(0, n-1, n-2, ..., 1)`,
близкие к отражениям). Смысл: среди n^2 разрезов только меньшинство —
хорошие, и находить их нужно не усреднением, а конструктивно/адресно.
Количественно уточняет и подтверждает качественное замечание
`docs/notes/h13_line_model.md` §6.

## 2. Свобода одного разреза недостаточна — нужны оба

Если зафиксировать порядок позиций (не вращать, `q = n-1`) и искать лучший
только среди n вращений значений c, максимум по pi от этого более слабого
минимума **превышает** `floor((n-1)^2/4)` начиная с n = 7: значения 2, 4, 6,
10, 13 при n = 4..8 против порога 2, 4, 6, 9, 12 (равенство при n <= 6,
избыток +1 при n = 7, 8; `experiments/h13i_cut_freedom.py`). Значит одна из
двух степеней свободы (вращение позиций ИЛИ вращение значений) не избыточна:
доказательство обязано использовать обе одновременно, а не сводиться к
однопараметрическому семейству разрезов (в духе отвергнутого в сессии 8
семейства «первый элемент = t», см. `h13_line_model.md` §1.7).

## 3. Переформулировка через дуги (структурная, для следующей попытки)

Для фиксированного разреза `(q,c)` (эквивалентно паре: `q` — какая позиция
идёт первой, `s = c-1 mod n`, т.е. значения переразмечены так, что `s` — новый
максимум/точка разреза) и пары позиций `i<j` (разрыв `g`), пара согласована на
этом разрезе, кроме случаев, когда РОВНО ОДНА из двух точек `q`, `s` попадает
в «свою» дугу: `q` — в дугу позиций длины `g` (от i до j), `s` — в дугу
значений длины `g'` (направленную так же). Формально число рассогласованных
разрезов для пары `(i,j)` равно `g*(n-g') + (n-g)*g'` — это в точности счётчик
«ровно одна дуга накрывает точку разреза», т. е. симметрическая разность
индикаторов дуг на двух независимых копиях Z_n. `I(pi)` — минимум по точке
`(q,s)` тора суммы таких XOR-индикаторов по всем C(n,2) парам. Форма похожа на
задачу дискрепанса по дугам на торе; сведение к известным результатам
(тэта-функции, VC-размерность дуговых семейств) не найдено за сессию.

Побочно получена явная **лемма о пересчёте** (использована в
`line_profile_fast.c` для ускорения): при фиксированном сдвиге значений `s`
и продвижении разреза позиций `q` на 1 (первый элемент линии со значением x
переносится в конец) число инверсий меняется ровно на `(n-1-2x)`. Отсюда
`inv` при разрезе `q=k` (считая от `q=n-1`) равно `inv_0 + k(n-1) - 2*S_k`,
где `S_k` — сумма первых k значений линии при разрезе q=n-1, сдвиг s
фиксирован. Это даёт исчерпывающий обход всех n позиционных разрезов за O(n)
после одного O(n^2) подсчёта инверсий (вместо n пересчётов по O(n^2)), т.е.
`I(pi)` за O(n^3) вместо O(n^4). Попытка найти явную формулу
`min_k [k(n-1)-2 S_k]` через свойства перестановки (аналог «поиска глобального
минимума кольцевой суммы», ср. классическую задачу о заправках) не завершена;
трудность та же, что и в п. 2 — нужен совместный (не покоординатный) выбор
`s` и `k`.
