## 0. Утверждение

**H13-I**: для любой pi перестановки Z_n существует двойной разрез (q, c)
(ребро позиций {q, q+1}, сдвиг значений c) такой, что переразмеченная линия
`w_j = pi[(q+1+j) mod n] − (q+1−c) mod n` имеет не более `floor((n−1)^2/4)`
инверсий. Эквивалентно: `I(pi) = min_{q,c} inv(w) <= floor((n−1)^2/4)`.
VERIFIED 4 <= n <= 10 (сессия 8, `experiments/line_profile.c`; здесь
подтверждено повторно в режиме `ihist`). Цель сессии — доказательство при
всех n, а не расширение перебора.

## 1. Лемма D (PROVED): равномерное усреднение по всем n^2 разрезам
недостаточно ни при какой pi

Точки перестановки — `P_i = (i, pi(i))`, i in Z_n. Для пары точек P, Q
положим `d_x = (x_Q − x_P) mod n`, `d_y = (y_Q − y_P) mod n`, оба в
`{1, …, n−1}` (значение не зависит от того, какая из точек названа P, а
какая Q, см. ниже). Для разреза (a, b) in Z_n x Z_n (a — сдвиг позиций,
b — сдвиг значений) пара инвертирована тогда и только тогда, когда ровно
одно из событий `x'_P < x'_Q` (по a), `y'_P < y'_Q` (по b) происходит,
где `x'_P(a) = (x_P − a − 1) mod n` и аналогично для y. Поскольку
`x'_Q(a) − x'_P(a) mod n = d_x` не зависит от a, событие `x'_P(a) < x'_Q(a)`
выполнено для `n − d_x` значений a и нарушено для `d_x` значений (аналогично
для b и d_y). Число разрезов (a,b), на которых пара инвертирована:

```
term(d_x, d_y) = d_x*(n − d_y) + (n − d_x)*d_y = n(d_x + d_y) − 2 d_x d_y.
```

При замене P <-> Q оба d_x, d_y заменяются на n − d_x, n − d_y, и `term`
не меняется — значит `term` корректно определена на неупорядоченной паре.
Подстановкой `u = d_x − n/2`, `v = d_y − n/2` (полуцелые при чётном/нечётном
n одинаково): `term = n^2/2 − 2uv`. Поскольку `d_x, d_y in [1, n−1]`, имеем
`|u|, |v| <= n/2 − 1` (или `n/2` при чётном n на одной стороне), так что
`term <= n^2/2` поточечно для любой пары, с равенством только при
`d_x = d_y = n/2` (возможно лишь при чётном n).

Суммируя по всем `C(n,2)` парам и деля на `n^2` (число разрезов):

```
avg_{a,b} inv(a,b) = (1/n^2) * sum_pairs term <= (1/n^2) * C(n,2) * (n^2/2) = n(n-1)/4.
```

Это верно для ЛЮБОЙ pi — оценка не использует структуру pi, только то, что
`term <= n^2/2` поточечно. Пигеонхол даёт `min_{a,b} inv(a,b) <= avg <=
n(n-1)/4`. Но `n(n-1)/4 − floor((n-1)^2/4) = (n-1)/4 + O(1) > 0` при n > 1
(например n = 10: 22.5 vs 20 — разрыв 2.5; n = 20: 95 vs 90 — разрыв 5) —
разрыв растёт линейно по n. Значит равномерное усреднение по всем n^2
разрезам принципиально не может дать порог `floor((n-1)^2/4)` ни при какой
pi, включая случаи, где `avg` близко к максимуму `n(n-1)/4` (это, видимо,
и есть отражения — оценка выше точна на них с точностью O(n), но сам
пигеонхол теряет ровно линейную добавку). Это делает строгим наблюдение
сессии 8 («среднее не работает даже для отдельных pi») и показывает, что
никакая доработка ЧИСТО пигеонхольного аргумента (без использования
структуры pi за пределами поточечной оценки term) не годится — нужен
argument, различающий pi.

## 2. Два явных дешёвых правила разреза отклонены (эксперимент)

**ruleA** (самоссылающийся разрез: для каждого q сдвиг c подбирается так,
чтобы первый элемент линии получил значение 0): провал уже при n = 4 (4 из
24 pi), худший избыток растёт как ~floor(n^2/4) (на rev_n): 3, 6, 10, 15,
21, 28, 36 при n = 4..10. Отклонено сразу.

**rule1d** (только сдвиг значений c при фиксированном естественном порядке
позиций, n кандидатов вместо n^2): выполняется точно при n <= 6, но
проваливается на растущем числе входов при n >= 7 (7, 16, 162, 1250 при
n = 7..10) с малым, но не нулевым избытком (1 при n <= 9, до 3 при n = 10).
**Ни один из проваленных входов не является точным отражением** —
все n отражений `pi_h(i) = h − i mod n` проходят это правило (проверено
исчерпывающе при каждом n <= 10, `fail_reflections = 0` во всех случаях).
Провалившиеся входы — другое семейство (у найденных представителей —
перестановки, тождественные в одной-двух точках и обращающие остаток;
не отражения в смысле `pi_h`), для которых достаточно перейти на другой q
(в примерах — q = 0), но замкнутой формулы выбора q не найдено. Значит
свобода по обоим параметрам (q и c) действительно нужна в общем случае —
и это не сводится к «отражения особые, остальное легко»: контрпримеры
rule1d — НЕ отражения, то есть трудность появляется и вне экстремальной
точки.

## 3. Ландшафт I(pi) вблизи максимума плотный — стабильность не поможет

Полный перебор (`ihist`) подтверждает: максимум `I(pi) = floor((n-1)^2/4)`
достигается ровно на n перестановках (точные отражения) при каждом
4 <= n <= 10 — согласуется с сессией 8. Но следующий уровень `I = max − 1`
уже многочислен: 72 (n=8), 423 (n=9), 81... — таблицы см. отчёт. Отличие от
максимума — ровно 1, а не растущий с n запас. Значит **любой корректный
аргумент должен быть почти столь же точным вблизи максимума, сколь и в
самой точке максимума** — грубая «стабильность» (не-экстремальные pi имеют
большой запас) неприменима: запас у «почти экстремальных» pi минимален.

## 4. Вердикт

H13-I не доказана за сессию (бюджет 1 сессия исчерпан). Установлено
строго: (а) равномерный пигеонхол по n^2 разрезам не может доказать порог
ни при какой pi — лемма D, зазор `(n−1)/4`, растёт линейно; (б) два
проверенных дешёвых явных правила отклонены с контрпримерами; (в) провалы
одного из правил — не отражения, то есть трудность не локализована в
экстремальной точке; (г) ландшафт I(pi) вблизи максимума плотный (шаг 1),
что исключает грубые аргументы устойчивости. Экстремальная характеризация
(«ровно n отражений») переподтверждена при 4 <= n <= 10.

(PLAN §4.3 п. 3), бюджет 2 сессии до вердикта. Не повторять: усреднение по
всем n^2 (или n) разрезам без дополнительной структуры (лемма D закрывает
это направление на любых pi, не только на найденных контрпримерах); поиск

исключений видна уже при n = 7).
