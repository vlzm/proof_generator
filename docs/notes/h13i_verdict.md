# H13-I — вердикт сессии 9: алгебра двойного разреза, свободный разрез, что осталось

(PLAN §8, сессия 8). Ядро oracle-1.0. Код: `experiments/toric_cut_algebra.py`

`docs/proofs/C37_double_cut_algebra.md`; отчёты `data/runs/h13i_verdict/`,

**Итог: H13-I не доказана и не опровергнута.** Доказано: (а) точный перевод
H13-I в задачу о знаках на K_n; (б) её «свободная» версия — при произвольном
выборе подмножества S граница `floor((n−1)^2/4)` всегда достижима и точна
(теорема 5 C37). Опровергнут естественный достаточный критерий (H14). Остаток
задачи локализован: нужно показать, что подходящее S есть среди n^2 торических.

## 1. Переформулировка (доказана, C37)

Точки `(i, pi(i))`; `A_m` — префикс позиций, `B_k` — префикс значений,
`S(m, k) = A_m xor B_k` (две «разноимённые» четверти сетки), `delta(S)` — пары,
разделённые S. Тогда для любого разреза

```text
inv(линии) = |Inv(pi) xor delta(S(m, k))| = inv(pi) + s(n − s) − 2 e_inv(S).
```

В знаках: `x_i = ±1` по принадлежности S, `eps_{ij} = ±1` по согласованности
пары в pi, `Q(x) = sum_{i<j} eps_{ij} x_i x_j`; тогда
`inv(линии) = B_n/2 − Q(x)/2`, и

```text
H13-I  <=>  у каждой pi среди n^2 векторов x(m, k) есть вектор с Q(x) >= floor(n/2).
```

Это в точности max-2-XOR (max-cut со знаками) на полном графе K_n
с ограничением «разрез берётся из торического семейства».

## 2. Что доказано полностью (теорема 5 C37)

Для произвольной знаковой функции eps на парах `max_x Q(x) >= floor(n/2)`;
равенство при `eps ≡ −1` (то есть на `rev_n` и `sigma_n`). Следствие: у каждой
pi есть **произвольное** подмножество S с
`|Inv(pi) xor delta(S)| <= floor((n−1)^2/4)`.

Доказательство — локальный спуск: в максимуме все «полевые» суммы
`r_p = n − 1 − 2 inv_p` неотрицательны; при чётном n они нечётны, значит
`>= 1`, и `2Q = sum r_p >= n`; при нечётном n они чётны, а множество нулей
`Z` парно инвертировано (парные смены знака), откуда `|Z| <= (n+1)/2`
и `2Q >= n − 1`.

Смысл для проекта: **константа `floor((n−1)^2/4)` в H13-I — это порог
Эдвардса для K_n**, она не улучшаема и не «случайна»; отражения экстремальны
уже на уровне знаков, без всякой торической структуры. Вся трудность H13-I —
в том, что торическое семейство содержит всего n^2 разрезов из 2^{n−1}.

## 3. Отвергнутые подходы (с указанием, где именно ломается)

1. **Усреднение по всем n^2 разрезам** (лемма 4 C37). Пара с круговыми
   расстояниями `(d_p, d_v)` согласована ровно при
   `(n − d_p)(n − d_v) + d_p d_v` разрезах; среднее число согласованных пар
   равно `Sigma(pi)/n^2`. Точно: `Sigma(id_n)/n^2 = (n−1)(2n−1)/6`,
   `Sigma(sigma_n)/n^2 = (n^2 − 1)/6`. Для `id_n` усреднение проходит при
   n >= 5, для `sigma_n` — **никогда** (`(n^2−1)/6 < n^2/4`). То есть
   усреднение проваливается ровно на экстремальном входе, а не на
   тривиальном; уточнение записи в `h13_line_model.md` §6. Доля pi, которые
   усреднение закрывает: 0/24, 5/120, 6/720, 56/5040, 488/40320 при n = 4..8.
   Любая «мягкая» оценка бессильна: на `sigma_n` величина `Q` принимает по
   разрезам широкий спектр значений, а нужен ровно максимум.

2. **Взвешенное усреднение по `s = |S|`** невозможно единым весом: оптимум
   `sigma_n` — сбалансированные S (`s = n/2`), оптимум `id_n` — `S = пусто`.
   Вес, зависящий только от s, не может обслужить оба.

3. **Критерий H14** (следствие 5.2 C37): достаточно найти разрез, в линии
   которого каждый элемент инвертирован не более чем с `floor((n−1)/2)`
   другими (плюс при нечётном n условие на множество максимумов). Это в
   точности «торический разрез, который является локальным минимумом при
   свободных сменах знака». **Опровергнуто при n = 8**: у 16 аффинных
   перестановок (`pi(i) = 3i + b` и `5i + b mod 8`; наименьшее n среди
   проверенных 4..8) ни один из 64 разрезов не годится, хотя `I(pi)` равно 9
   и 11 при пороге 12. Те же аффинные входы уже ломали индукцию по одному
   элементу (`h13_line_model.md` §1.7) и H10 (C27).

4. **«Свободный оптимум всегда торический»** — тоже неверно, но почти верно:
   при 4 <= n <= 7 `I(pi) = min_S |Inv xor delta(S)|` для **всех** pi; при
   n = 8 расхождение у 208 из 40320 pi (200 с дефектом 1, 8 с дефектом 3,
   16 из 208 аффинные). Максимум `I` при этом остаётся равен `floor((n−1)^2/4)`
   и достигается ровно на n отражениях.

## 4. Конечные данные сессии (`data/runs/h13i_verdict/report.md`)

- Тождество разреза: исчерпывающе все pi и все n^2 разрезов при 4 <= n <= 7,
  случайные при n = 8, 12, 20, 33, 50.
- Формула пары и `Sigma(pi)`: исчерпывающе при 4 <= n <= 6; замкнутые формулы
  для `id_n`, `sigma_n`, `rev_n` точной арифметикой при 4 <= n <= 60.
- Свободный разрез: исчерпывающе по всем `2^{n−1}` подмножествам и всем pi при
  4 <= n <= 8; локальный спуск на структурированных и случайных входах при
  n = 12, 20, 33, 50, 100, 101 — везде `<= floor((n−1)^2/4)` с равенством на
  отражениях.
- H13-I (независимая перепроверка C33/C35): `max_pi I(pi) = floor((n−1)^2/4)`
  при 4 <= n <= 8, достигается ровно на n отражениях; структурированные и
  случайные входы при n = 20, 50, 100, 101 — без нарушений.

## 5. Следующий шаг

Приоритет 1 (прямое продолжение, бюджет 1 сессия): **оценить дефект
торического семейства**. Задача: доказать `I(pi) <= min_S |Inv xor delta(S)| +
g(n)` или, что практичнее, сразу `I(pi) <= floor((n−1)^2/4)` в двух режимах —
(а) если свободный оптимум достигается на множестве вида «две четверти», он
торический по построению (лемма 2), значит нужно характеризовать свободные
оптимумы; (б) если у pi есть разрез с `max_p inv_p <= floor((n−1)/2)`, работает
следствие 5.2. Конкретный эксперимент: при 4 <= n <= 8 для каждой pi найти все
свободные оптимумы S и проверить, как далеко ближайший из них от торического
семейства (в метрике Хэмминга на подмножествах); отдельно разобрать аффинные
входы `pi(i) = a i + b`, где дефект и появляется. Аффинное семейство закрыто
относительно торических сдвигов, поэтому для него задача одномерна: нужно
`min_b inv(a j + b mod n) <= floor((n−1)^2/4)` — это конечная задача о суммах
Дедекинда, её стоит решить отдельно и полностью.

Приоритет 2 (запасной путь из PLAN §4.3, п. 3): **индукция H3**. H13-I по
одному элементу не индуктируется (`h13_line_model.md` §1.7), но индуктировать
нужно не `I`, а саму `d`. Первый шаг, который предлагается следующей сессии:

1. Формализовать вложение: выбрать элемент e и «припарковать» его в позиции p
   окружности; остальные n − 1 элементов образуют перестановку pi' на
   окружности длины n − 1.
2. Выписать точную стоимость имитации: каждый ход L/R малого слова — один ход
   большого; лишний ход возникает только когда голова перешагивает через
   припаркованный элемент, то есть число лишних ходов равно числу проходов
   головы через позицию p, а это `<= ceil(N_rot(малое слово)/(n−1))`;
   плюс стоимость вставки e на место в конце.
3. Бюджет рекурренты нулевой: `B_n − B_{n−1} = n − 1`, значит нужно
   `число проходов + вставка <= n − 1`. При `N_rot <= floor((n−1)^2/4)` первое
   слагаемое `<= (n−1)/4 + 1`, так что на вставку остаётся `~3(n−1)/4` —
   запас есть, но выбор (e, p) существенен.
4. Измерить: при 5 <= n <= 8 для каждой pi посчитать
   `min_{e, p} [d_{n−1}(pi') + стоимость имитации]` и сравнить с `d(pi)` и
   `B_n` по сертифицированным таблицам (C2v). Это отвечает на вопрос, есть ли
   вообще выбор (e, p) с нулевой потерей, до всякого доказательства.

Не повторять: усреднение по разрезам (п. 3.1–3.2), критерий H14 (п. 3.3),
индукцию по одному элементу для `I` (`h13_line_model.md` §1.7), поиск схемы
слова с `N_rot <= inv + f(n)` (C34-A, C36).
