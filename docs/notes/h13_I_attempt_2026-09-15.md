## 0. Постановка (без изменений)

`I(pi) = min_{q,c} inv(w)`, `w_j = pi(q+1+j) - (q+1-c) mod n`, разрез —
ребро позиций `{q,q+1}` и сдвиг значений `c`, `n^2` вариантов. Цель:
`I(pi) <= floor((n-1)^2/4)` при всех n >= 4 и всех pi.

## 1. Новый инструмент: `O(n^2)`-формула для `I(pi)`

Переобозначим `s = q+1 mod n` (начало чтения позиций) и `t = (q+1-c) mod n`
(порог значений; при фиксированном `s` пробегает все `0..n-1` независимо,
пока `c` пробегает `0..n-1`). Тогда `F(s,t) := inv(w)`, `w_j = (pi((s+j) mod
n) - t) mod n`.

**Наблюдение (телескопирование).** Пусть `rho = pi^{-1}`.

- `F(0,0) = inv(pi)` (обычные инверсии массива).
- `P(0) = F(0,0)`, `P(s+1) = P(s) + (n-1-2*pi[s])` — вращение массива
  позиций на 1 (перенос переднего элемента `pi[s]` в конец) меняет число
  инверсий по стандартной формуле для перестановки `0..n-1`: элемент,
  бывший первым (вносил инверсию с каждым меньшим него, т.е. `pi[s]` штук),
  становится последним (вносит инверсию с каждым большим, `n-1-pi[s]`
  штук); дельта `= (n-1-pi[s]) - pi[s] = n-1-2 pi[s]`.
- При фиксированном `s`: `F(s,0) = P(s)`,
  `F(s,t+1) = F(s,t) + (n-1-2*sigma)`, `sigma = (rho(t)-s) mod n` — та же
  формула, применённая к значениям: увеличение `t` на 1 циклически уменьшает
  все `w_j` на 1 mod n, элемент со значением 0 (позиция `sigma` в строке)
  становится максимальным.
- `I(pi) = min_{s,t} F(s,t)`.

Это даёт `O(n)` на построение `rho`, `O(n^2)` (n мало) на `inv(pi)`, `O(n)`
на все `P(s)`, и `O(n)` на строку (проход по `t`) для каждого из `n` `s` —
итого `O(n^2)` на pi вместо `O(n^4)` у `experiments/line_profile.c`
(`n^2` разрезов, `O(n^2)` инверсий на разрез).

**Проверка формулы** (`checks/check_C37.py`, часть A): совпадает с прямым
`O(n^4)` перебором исчерпывающе при `2 <= n <= 7`, на 2000 случайных pi при
n = 8, 9, 10. Реализация: `experiments/toric_I_fast.c` (C, `toric_I_fast-1.0`).

**Эффект**: n = 10 — 0.4 с (было 93 с у `line_profile.c`), n = 11 — 5 с,
n = 12 — 74 с, n = 13 — см. §2 (фоновый прогон). Это НЕ повтор запрещённого
правилом «BFS линейной модели при n >= 10» (`docs/notes/repo_state.md`,
«Следующая задача»): там речь о дорогом BFS графа обхода/линейного графа
(`experiments/line_model.py --walk`, 1174 с уже на n = 9 для d_walk); здесь
— простой перебор минимума `inv` по `n^2` разрезам, без BFS состояний.

## 4. Что было испробовано для доказательства (и почему не закрылось)

### 4.1 Парная переформулировка через XOR

Для пары позиций `{p,p'}` определим `A(s) = 1`, если при чтении с `s` `p`
идёт раньше `p'` (это индикатор дуги длины `g = (p-p') mod n` по `s`), и
`B(t)` аналогично для пары значений `{pi(p),pi(p')}` (дуга длины
`h = (pi(p)-pi(p')) mod n` по `t`). Прямым разбором знаков показано:

> пара `{p,p'}` даёт инверсию в `w(s,t)` тогда и только тогда, когда
> `A(s) != B(t)`.

Следствие — точное тождество `C(n,2) = floor(n^2/4) + floor((n-1)^2/4)`
(проверяется по чётности n) переписывает H13-I как: **существует разрез
`(s,t)`, при котором число НЕинвертированных пар не меньше `floor(n^2/4)`**
— именно формулировка «одноимённые квадранты», уже отмеченная в §6 заметки
`h13_line_model.md`. Совпадение `floor(n^2/4)` с числом Мантеля (максимум
рёбер в графе без треугольников на n вершинах / максимум в полном
двудольном графе) наводит на мысль о редукции к теореме Мантеля, но
предъявить нужный граф (рёбра = совпадения на оптимальном разрезе,
вершины = ?) не удалось: естественные кандидаты («граф совпадений» как
граф на позициях, как граф на значениях, как граф на парах) либо не дают
нужного числа рёбер по построению, либо не очевидно двудольны/ациклич\
ны на треугольниках. Не закрыто — направление помечено как перспективное
для следующей сессии.

### 4.2 Суммирование по всем `(s,t)` (усреднение) — не работает (подтверждено)

`sum_{s,t} A(s) B(t)`-разложение сводится к прежней «усреднённой» величине
`sum_pairs (2g-n)(2h-n)`, уже отвергнутой в сессии 8 (среднее может
превышать цель). Новый результат сессии 9: сама операция XOR даёт точную
константу `floor(n/2) = floor(n^2/4) - floor((n-1)^2/4)` как целевой порог
для «max корреляции» `max_{s,t} sum_pairs a_pair(s) b_pair(t)` (где
`a,b in {-1,+1}`), но доказать существование разреза с такой корреляцией
без полного перебора не удалось.

### 4.3 Линейные семейства размера `2n` — недостаточны (проверено исчерпывающе)

Пять кандидатных семейств из `n` или `2n` разрезов протестированы
исчерпывающе при `4 <= n <= 8` (`experiments/large_n_scan.py`-черновик,
функция `test_family`, интерактивно в сессии; не сохранён отдельным файлом,
т.к. результат отрицательный и воспроизводится тривиально):

| семейство | размер | первый провал |
|---|---|---|
| фиксированный `c = 0` (т.е. `t = s`) | n | n = 4: I=4 > bound=2 |
| фиксированный `c = floor(n/2)` | n | n = 4: I=4 > bound=2 |
| объединение двух фиксированных c (`0`, `floor(n/2)`) | 2n | n = 7: I=10 > bound=9 |
| для каждого s пара `(s,s)` и `(s,s+floor(n/2))` | 2n | n = 7: I=10 > bound=9 |
| диагональ `t=s` плюс антидиагональ `t=-s` | 2n | n = 5: I=5 > bound=4 |

Ни одно семейство линейного размера (в `n`) не достаточно уже при малых n;
это независимо подтверждает вывод сессии 8 (§1.7 заметки) для семейства
«первый элемент линии = t» (которое эквивалентно кандидатам вида
«диагональ со сдвигом `t = pi(s) - t0`», уже отвергнутым там) и расширяет
его на семейства, параметризованные по `c` (а не по значению первого
элемента), и на объединения двух-трёх таких семейств. Похоже, что
необходим действительно двумерный (порядка `n^2`, не `O(n)` и не `O(n
log n)`) аргумент или явная неконструктивная (комбинаторная) оценка.

### 4.4 Индукция по совместному сдвигу (s,s+1) и (t,t+1) — не опробована до результата

Идея из §6 заметки («сдвиги обоих разрезов вместе»): рассмотреть
диагональную рекурсию `F(s+1,t+1) - F(s,t)`, комбинируя формулы §1. Дельта
раскладывается в сумму двух знакомых слагаемых
(`(n-1-2*w(s,t)_0) + (n-1-2*sigma')`), не давая новой структуры сама по
себе — не более информативна, чем последовательное применение двух
однопараметрических рекурсий. Направление не дало результата за отведённое
время; возможно, нужен не единичный, а согласованный шаг `(s -> s+k(s))`.

## 5. Возможная зацепка в литературе (НЕ подтверждена — доступ заблокирован)

Поиском найдена работа **R. M. Adin, N. Alon, Y. Roichman, "Circular
Sorting", arXiv:2502.14398** (первая версия — февраль 2025, вторая —
август 2025). По аннотации и сторонним обзорным ссылкам (сам arXiv и
зеркала — например `web.math.princeton.edu` — заблокированы политикой
egress этой сессии, `EGRESS_BLOCKED`; текст статьи НЕ прочитан): работа
определяет максимальное число шагов для сортировки `n` меток на круге
соседними транспозициями (циклический граф `C_n` вместо линейного пути) и
доказывает, что этот максимум равен **ровно `floor((n-1)^2/4)`, на
перестановке-развороте** — то же число и тот же экстремальный вход, что и
у `I(pi)`.

Это совпадение веса и экстремали примечательно, но метрика другая:
«circular sorting distance» — это точное расстояние в графе Кэли (S_n,
соседние транспозиции цикла `C_n`), не наша величина `I(pi)` (минимум
инверсий по `n^2` линейным разрезам с независимым сдвигом значений). Можно
показать элементарно, что `circular-distance(pi) <= I(pi)` (любой разрез,
не использующий одно ребро, даёт корректную, но не обязательно кратчайшую,
сортировку соседними транспозициями по кругу длины `F(s,t)`; минимизация по
`(s,t)` — верхняя оценка на `circular-distance`). Но обратного неравенства
или точного равенства **не установлено** (не удалось прочитать доказательство
статьи, а из одного совпадения максимумов равенство поточечно не следует).
**Рекомендация для следующей сессии**: получить текст статьи (через
доступ без блокировки egress, или запросить у пользователя) и проверить:
(a) совпадает ли их определение с `I(pi)` дословно или только по
экстремуму; (b) содержит ли доказательство верхней оценки явную
конструкцию разреза, переносимую на H13-I впрямую.
