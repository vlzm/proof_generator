# H13-I — попытка доказательства (сессия 9, 17.09.2026)

Задача (`docs/notes/repo_state.md`, `docs/notes/h13_line_model.md` §6):
доказать **H13-I**: для каждой перестановки `pi` порядка n
`I(pi) = min_{q,c} inv(w(pi; q, c)) <= floor((n-1)^2/4)`,
где `w` — линия, полученная поворотом позиций на q и значений на c (точное
определение — `h13_line_model.md` §0). Бюджет — 1 сессия до письменного
вердикта (PLAN §8, повтор в `docs/notes/repo_state.md`).

**Итог: не доказано и не опровергнуто за сессию.** Ниже — новая
переформулировка, доведённый до конца, но недостаточный по силе анализ
через неё, и два самостоятельных отрицательных результата (§4, §5), закрывающих
конкретные более простые направления. Код и численные данные —
`experiments/h13i_attempt.py`, `data/runs/h13i_attempt/report.md`.

## 1. Переформулировка через XOR пар точек (проверено n <= 6, все pi и разрезы)

Смотрим на `pi` как на n точек `(i, pi(i))` на торе `Z_n x Z_n`. Разрез
`(q, c)`: позиционный разрез — ребро `{q, q+1}` (позиция q+1 становится
первой в линии); значный разрез задаётся сдвигом `shift = (q+1-c) mod n`
напрямую (`w_j = (pi(position_j) - shift) mod n`, значение `shift` становится
нулём).

Для неупорядоченной пары точек `P1 = (i1, v1)`, `P2 = (i2, v2)` (v1=pi(i1),
v2=pi(i2)) определим:

- `d = (i2 - i1) mod n` — длина дуги окружности позиций от i1 вперёд до i2;
- `e = (v2 - v1) mod n` — длина дуги окружности значений от v1 вперёд до v2;
- `X(q) = 1`, если позиционный разрез `q` лежит на d-дуге (`(q - i1) mod n < d`), иначе 0;
- `Y(shift) = 1`, если значный разрез лежит на e-дуге (`((shift-1) - v1) mod n < e`), иначе 0.

**Утверждение (проверено, `--verify-xor`, все pi и все n^2 разрезов, 2 <= n <= 6,
29366 проверок):**

```
inv(w(pi; q, c)) = sum_{pairs {P1,P2}} [X_pair(q) XOR Y_pair(shift)]
```

Это точная формализация фразы из `h13_line_model.md` §6 «точка (q, s) тора,
лежащая в "одноимённых" квадрантах не менее floor(n^2/4) пар»: `XOR = 0`
(«одноимённый квадрант», пара не даёт инверсию) ровно когда разрез либо не
задевает ни одну из двух дуг пары, либо задевает обе.

Вывод формулы (без проверки кодом — прямой комбинаторный подсчёт, см. также
`h13_line_model.md` §0 для того же определения w): при фиксированной паре и
переборе всех n позиционных разрезов ровно `n-d` дают «i1 раньше i2» в
линии и `d` дают «i2 раньше i1» (разрез, не задевающий дугу от i1 до i2,
сохраняет естественный порядок; разрез внутри этой дуги его переворачивает).
Аналогично для значений. Разбор четырёх комбинаций (i1-раньше/i2-раньше) x
(v1-меньше/v1-больше) даёт: инверсия в w тогда и только тогда, когда ровно
одно из двух «разрез на своей дуге» верно — это и есть XOR.

### 1.1. Что даёт переформулировка

`I(pi)` — это минимум по n^2 точкам решётки `Z_n x Z_n` суммы `C(n,2)`
слагаемых вида `X_pair(q) XOR Y_pair(c)`, где для каждой пары `X_pair`
зависит только от q через индикатор дуги длины d на окружности позиций, а
`Y_pair` — только от c (через shift) через индикатор дуги длины e на
окружности значений. Это ближе к задаче о минимальном разрезе / дискрепансии
семейства дуг, чем к задаче про перестановки как таковые, но система дуг
`{(d_pair, e_pair)}_{pairs}` не произвольна: она порождена n точками на
торе, а значит удовлетворяет согласованиям троек (для трёх точек i1,i2,i3
на окружности позиций ровно одна из трёх дуг между парами содержит две
другие — обычное свойство циклического порядка; то же для значений). Эти
согласования — не использованы; вероятный следующий шаг (не сделан).

### 1.2. Простая парная оценка недостаточна по порядку

Естественная идея: найти инволюцию `(q,c) -> (q',c')` на n^2 разрезах такую,
что для каждой пары `X XOR Y` переворачивается, тогда
`inv(q,c) + inv(q',c') = C(n,2)` и `min <= C(n,2)/2`. Такая инволюция
существует (например `c' = c + z` для z, переворачивающего каждую e-дугу
относительно её середины — при чётных n сдвиг на n/2 не подходит
универсально, но сам факт существования верхней оценки `<= ceil(C(n,2)/2)`
через какую-то парность правдоподобен и не проверялся отдельно). Проблема —
не в существовании, а в силе: `floor((n-1)^2/4) < C(n,2)/2 = n(n-1)/4`
уже при n >= 3 (разница растёт как `(n-1)/4`), так что даже идеальная
парная инволюция на 2 недостаточна — нужна конструкция с разрезом не на 2,
а минимум на 4 симметричных класса (или прямой комбинаторный аргумент),
чтобы снять лишние ~n/4, ровно как в зазоре N1 (правило 17 AGENTS.md,
`docs/notes/h10_verdict.md`). Числовая проверка (n=7..10, из C33): target
9,12,16,20 против C(n,2)/2 = 10.5,14,18,22.5 — разрыв растёт линейно, не
исчезает.

## 2. Формула «блуждания» при фиксированном q (одна ось, для справки)

Для ФИКСИРОВАННОГО q (линия x_0..x_{n-1} = pi на этой линии) и переменного
значного сдвига `s`, пусть `f(s) = inv(ротация значений x на s)`. Стандартный
приём («элемент с текущим максимумом переходит в минимум при сдвиге на 1»)
даёт рекуррентную формулу (не закодирована, прямой вывод):

```
f(s) = inv(x) + s(n-s) - 2*cross(s)
```

где `cross(s)` — число пар (h, l), h среди s элементов с наибольшим
значением, l среди n-s остальных, с `pos(h) < pos(l)` (h раньше l). Порог
`s(n-s)` берёт максимум при `s = floor(n/2)`, что на вырожденном случае
(x строго убывает, т.е. reversed) даёт ТОЧНО `floor((n-1)^2/4)` при
оптимальном s (проверено аналитически: `C(a,2)+C(b,2)` при
`a+b=n, a~b~n/2` равно `floor((n-1)^2/4)`; см. §2.1 ниже) — это единственная
ось (без вращения позиций), на которой достигается точное равенство ровно
на инвертированной линии.

Проблема: §2 из experiments (`--single-axis`) показывает, что для
ПРОИЗВОЛЬНОЙ линии x (не только исходного порядка pi) минимум `f(s)` по
одной оси не всегда `<= floor((n-1)^2/4)` (n=7, `pi=(0,5,4,3,2,1,6)`,
минимум по 7 сдвигам значений = 10 > 9) — своими силами (без выбора q)
формула §2 недостаточна; нужен ОДНОВРЕМЕННЫЙ выбор q, для которого пока нет
формулы, связывающей `cross(s)` c q компактно.

### 2.1. Проверка для инвертированной линии

`x_j = n-1-j`. Порог s разбивает на два блока длины `s` и `n-s`, каждый
полностью развёрнут (наследует обращённость), между блоками все пары
согласны (не инверсия) — значит `f(s) = C(s,2) + C(n-s,2)`, минимум при
сбалансированном разбиении: n=2m даёт `m^2-m = floor((n-1)^2/4)`, n=2m+1
даёт `m^2 = floor((n-1)^2/4)` — точное совпадение с целью в обоих случаях.
Это объясняет (независимо от прежнего численного наблюдения C33), почему
именно отражения (аффинный эквивалент разворота) экстремальны: у них
блочное разбиение по значному порогу уже оптимально сбалансировано и
"бесплатно" достигает цели одной осью; у произвольной pi нужного баланса
может не быть ни по одной оси — тогда нужна совместная (q,c) степень
свободы, но явной формулы для неё в терминах, допускающих оценку, не
найдено.

## 3. Численная проверка (SAMPLED, n <= 50)

`experiments/h13i_attempt.py --structured`: отражения (исчерпывающе по h),
аффинные (все a взаимно простые с n, b с шагом n/5), 30 случайных входов —
при n = 11, 12, 13, 14, 15, 16, 18, 20, 25, 30, 40, 50 везде
`I(pi) <= floor((n-1)^2/4)`, отражения достигают равенства при каждом n.
Данные согласуются с VERIFIED 4 <= n <= 10 (`line_profile.c`, C33) и
расширяют структурные семейства заметно за прежний предел SAMPLED n <= 12
(`affine_family.py`, H10). Полный отчёт — `data/runs/h13i_attempt/report.md`.

## 4. Одной оси разреза недостаточно (закрытое направление)

Вращение только значений с фиксированным (нерот.) порядком позиций не
достигает цели уже при n = 7 (`I` для этой одной оси = 10 > 9,
`experiments/h13i_attempt.py --single-axis`). По симметрии позиции/значения
(замена ролей через `pi <-> pi^{-1}`) вращение только позиций при
фиксированном порядке значений так же недостаточно. Отсюда: полный перебор
n^2 разрезов принципиально нельзя свести к перебору n по одной оси — любое
доказательство должно работать с обеими координатами разреза одновременно
(или явно описывать, как выбор одной зависит от другой).

## 5. Жадная двухшаговая эвристика недостаточна (закрытое направление)

«Сначала выбрать q, минимизирующий `inv(x_q)` (n вариантов), затем лучший c
для этого q» расходится с истинным `I(pi)` уже на 3 входах при n = 5, и даёт
`worst = 10 > 9` при n = 7 (`experiments/h13i_attempt.py --greedy`).
Независимо (в другой форме) от леммы C `h13_line_model.md` §4: локальная
оптимальность по q не определяет глобально хорошую пару (q, c).

## 6. Что не сделано и куда двигаться дальше

- Использовать согласования троек точек (§1.1) в оценке XOR-суммы —
  не начато; вероятно, ключевой недостающий шаг (система дуг из перестановки
  устроена жёстче произвольной системы дуг).
- Явная инволюция на 4 (не 2) класса разрезов, снимающая полный зазор
  `C(n,2)/2 - floor((n-1)^2/4) ~ (n-1)/4` (§1.2) — не построена.
- Совместная формула `f(q,s)` (обобщение §2 на оба индекса сразу) — не
  выведена; частичная рекуррента при изменении q на 1 (аналог §2 с ролями
  элемент/значение поменяны местами) выписывается тем же приёмом, но
  совместное поведение (как cross(s) меняется при изменении q) не
  прослежено.
- Индукция по одному элементу и по паре элементов (антиподальной или
  соседней) для I(pi) впрямую — по одному элементу уже отвергнута
  (`h13_line_model.md` §1.7); по паре не пробовалась в этой сессии.

## Вердикт и следующий шаг

Согласно критерию сессии 8 (`docs/notes/repo_state.md`, PLAN §8): H13-I не
доказана за отведённую 1 сессию. Найденные новые факты (XOR-переформулировка,
её недостаточность в простой (парной) форме, недостаточность одной оси и
жадной эвристики) регистрируются (CLAIMS.md C37), диапазон SAMPLED расширен
до n = 50. По плану — следующая задача: индукция H3 (PLAN §4.3, п. 3,
бюджет 2 сессии до вердикта), как отдельное направление к C15, не связанное
напрямую с линейной моделью. Возврат к H13-I возможен отдельной сессией с
использованием §1.1/§6 этой заметки как отправной точки, если направление
H3 не даст прогресса за отведённый бюджет.
