# H13-I — попытка доказательства (сессия 9), вердикт: не доказано

Дата: 13.09.2026. Задача из `docs/notes/h13_line_model.md` §6 и PLAN §8/§0
(H13): доказать H13-I: `I(pi) <= floor((n-1)^2/4)` для всех pi (торические
классы: у каждой pi есть двойной разрез с не более `floor((n-1)^2/4)`
инверсиями). Бюджет — 1 сессия до письменного вердикта. Итог: **не доказано
и не опровергнуто**; ниже — переформулировка, проверенные и закрытые
направления, и один незавершённый.

## 1. Переформулировка через групповое действие

Двойной разрез (q, c) (`docs/notes/h13_line_model.md` §0) эквивалентен паре
(a, b) в Z_n x Z_n: `a = (q+1) mod n` (начало линии по позициям), `b = (q+1-c)
mod n` (сдвиг значений), и `w_j = (pi((j+a) mod n) - b) mod n`. Отображение
(q,c) -> (a,b) — биекция Z_n x Z_n -> Z_n x Z_n, так что "все n^2 разрезов"
это ровно все пары (a,b).

Формула `pi_{a,b}(j) = (pi(j+a) - b) mod n` — действие группы `(Z_n x Z_n, +)`
на перестановках Z_n: `(a2,b2)*(a1,b1)*pi = (a1+a2, b1+b2)*pi` (проверяется
прямой подстановкой). Значит **I(pi) — инвариант орбиты**: I одинаково на
всех pi_{a,b} для фиксированной pi и всех (a,b). H13-I утверждает, что на
каждой из orbit(pi) (их не более n!/n^2 * (что-то) — точнее, по
орбита-стабилизатору, n!/|orbit|) минимум инверсий по орбите не превышает
floor((n-1)^2/4). Это не упрощает задачу (никакой новой информации о pi не
даёт), но объясняет одну уже известную числовую находку:

**Замечание (доказано элементарно).** Отражения `pi_h(i) = h - i mod n`
образуют ровно одну орбиту при действии выше, и это в точности орбита
`pi_0(i) = -i mod n`. Стабилизатор `pi_0`: `(a,b)` с `pi_0(j+a)-b = pi_0(j)`
для всех j, т.е. `-(j+a)-b = -j (mod n)`, т.е. `b = -a mod n` — n решений (по
одному на каждое a). По теореме об орбите-стабилизаторе `|orbit(pi_0)| =
n^2 / n = n`, и явно orbit = `{ j -> -j-s mod n : s = 0,...,n-1 } = { pi_h :
h = 0,...,n-1 }`. Это ровно и объясняет находку сессии 8 ("равенство —
ровно n отражений", C33/C35): единственная (по данным при 4 <= n <= 10)
экстремальная орбита имеет размер ровно n именно из-за стабилизатора
порядка n у отражения, а не по совпадению. Утверждение "орбита отражения —
единственный максимизатор I" остаётся эмпирическим (проверено исчерпывающе
только при 4 <= n <= 10, C33); из него выводится "ровно n" автоматически,
но само оно не доказано для общего n.

## 2. Закрытое направление: ни одна ось разреза не фиксируется заранее

Гипотеза (не сформулированная явно раньше, но естественная): может быть,
для *любой* pi достаточно варьировать только b (сдвиг значений), оставив
a = 0 (порядок позиций как есть), то есть I(pi) сводится к одномерной задаче
"циклическая последовательность значений, найти лучший сдвиг". Тогда H13-I
превратилась бы в чисто одномерное утверждение о вращениях одной
циклической последовательности.

Проверено исчерпывающе (`experiments/h13i_axis_restricted.c`,
`data/runs/h13i_axis_restricted/report.md`), 4 <= n <= 10 (все pi):
неверно начиная с n = 7. Число pi, для которых `min_b inv(pi shifted by b) >
floor((n-1)^2/4)` (a = 0 фиксировано): 0, 0, 0, **7, 16, 162, 1250** при
n = 4..10 — доля не убывает к нулю. Симметрично для "a-only" (b = 0,
варьировать только вращение позиций) — те же числа (ожидаемо: a-only для pi
= b-only для pi^{-1}). Наименьший провал — n = 7, `(0,5,4,3,2,1,6)`: это
ровно пример леммы C из `docs/notes/h13_line_model.md` §4 (там показано, что
локальные условия по одной оси недостаточны на ОДНОМ примере; здесь —
исчерпывающая пересверка, что исключений много и они растут, а не единичный
казус). **Вывод: доказательство H13-I обязано совместно выбирать (a,b);
редукция к одномерной задаче закрыта.**

## 3. Незавершённое направление: подсчёт по разностным векторам

Задача переформулирована как утверждение про пары точек. Для упорядоченной
пары (i,k), i != k, пусть `δ_{ik} = (k-i) mod n` (сдвиг позиций, 1..n-1),
`e_{ik} = (pi(k)-pi(i)) mod n` (сдвиг значений, 1..n-1). Пара {i,k}
НЕ инвертирована при разрезе (a,b) тогда и только тогда, когда:
`a` лежит в дуге `{k+1,...,i}` (длины n - δ_{ik}) одновременно с `b` в дуге
`{pi(k)+1,...,pi(i)}` (длины n - e_{ik}), **или** симметрично обе дуги —
дополнения (длины δ_{ik} и e_{ik}). Число неинверсий:
`N(a,b) = sum_{i<k} [это условие]`; нужно `max_{a,b} N(a,b) >= floor(n^2/4)`.

Среднее `N(a,b)` по всем n^2 парам (a,b) уже проверено недостаточным
(`docs/notes/h13_line_model.md` §6: на sigma_n среднее ~ n^2/6 < n^2/4).
Разбиение по фиксированному δ (n пар на каждый δ = 1..n-1, дуги длины n-δ
"синхронно вращаются" при варьировании i) выглядит многообещающим — сумма
по δ сводится к n одномерным задачам с известной длиной дуги, только позиция
дуги зависит от значений pi через `e_i^{(δ)} = pi(i+δ)-pi(i) mod n` — но
довести до неравенства `max_{a,b} N(a,b) >= floor(n^2/4)` в рамках бюджета
сессии не удалось: усреднение по δ снова даёт средний, а не максимальный
случай, а объединение по всем δ одновременно (совместный выбор (a,b) должен
одновременно работать для всех n-1 значений δ) не редуцировано до
одномерной оценки. Не регистрируется как отдельная лемма — не доведено до
проверяемого утверждения.

## 4. Что не годится (подтверждено и/или унаследовано)

- Усреднение по всем n^2 разрезам сразу — REFUTED (сессия 8).
- Усреднение только по одной из осей (b-only или a-only) при фиксированной
  другой — REFUTED здесь (§2), исчерпывающе.
- Индукция по одному элементу (удаление с сжатием позиций и значений) —
  REFUTED (сессия 8, `docs/notes/h13_line_model.md` §1.7): контрпример
  n = 8, `(0,5,2,7,4,1,6,3)`, I = 11, все 8 редукций дают I = 6, тогда как
  разница бюджетов `floor(49/4) - floor(36/4) = 3`.
- Локальные условия оптимальности разреза по одной координате (лемма C) —
  недостаточны (сессия 8, один пример; здесь — исчерпывающая пересверка §2).
- Семейство разрезов «первый элемент линии = t» — REFUTED (сессия 8).

## 5. Вердикт и следующий шаг

H13-I остаётся CONJECTURED: PROVED ни разу не получено за сессию; REFUTED
тоже нет (все 4 <= n <= 10 подтверждают гипотезу исчерпывающе, включая
независимую пересверку `full_fail = 0` здесь). Бюджет сессии (PLAN §8, п.
«Следующий шаг») исчерпан без письменного доказательства.

Новое (регистрируется как C37, см. CLAIMS.md): ни одна из двух осей разреза
не сводит H13-I к одномерной задаче — исчерпывающе 4 <= n <= 10.

Per PLAN §8: если H13-I не доказана за сессию — переход к индукции H3
(PLAN §4.3, `PLAN.md`) как основному следующему шагу. Отдельно, как
конкретная зацепка для будущей попытки H13-I (не обязательство): довести
разностно-векторный счёт §3 до неравенства, используя то, что орбита-
экстремум — единственная орбита отражения (§1); рассмотреть аргумент
"экстремальность через перестановочный обмен" (adjacent transposition в pi)
с контролем изменения I, опираясь на структуру C32 (баланс дуг), как
предполагала заметка `h13_line_model.md` §6 — не начато в этой сессии.
