## 0. Соглашения

Двойной разрез `(a, b)`: линия задаётся позицией `x_i = (i − a) mod n`
и значением `y_i = (pi(i) − b) mod n`; `inv(a, b)` — число инверсий линии,
`I(pi) = min_{a,b} inv(a, b)`. Связь с обозначениями `line_profile.c`
и `line_model.py`: `a = q + 1`, `b = q + 1 − c`; множество разрезов то же.

**H13-I:** `I(pi) <= floor((n − 1)^2/4)` при всех n >= 4 и всех pi.

## 1. Эквивалентные формы (доказано)

**Лемма 1.1 (арифметика границы).** При всех n >= 1

```
C(n,2) − floor((n−1)^2/4)   = floor(n^2/4),
C(n,2) − 2·floor((n−1)^2/4) = floor(n/2).
```

Доказательство: при `n = 2m` левые части равны `2m^2 − m − (m^2 − m) = m^2`
и `2m^2 − m − 2m^2 + 2m = m`; при `n = 2m + 1` — `2m^2 + m − m^2 = m^2 + m`
и `2m^2 + m − 2m^2 = m`. ∎ (Проверено при 4 <= n <= 500,
`check_H13I.py` часть 1.)

**Следствие 1.2 (три эквивалентные формулировки H13-I).** Обозначим
`noninv(a, b) = C(n,2) − inv(a, b)` и `K(a, b) = noninv − inv` (статистика
Кендалла линии). Тогда H13-I равносильна каждому из:

- `max_{a,b} noninv(a, b) >= floor(n^2/4)`;
- `max_{a,b} K(a, b) >= floor(n/2)`.

Вторая форма полезна тем, что показывает масштаб задачи: искомый порог
`floor(n/2)` мал по сравнению с самой величиной `K ∈ [−C(n,2), C(n,2)]`,
а среднее `K` по всем `n^2` разрезам на отражениях равно
`−(n−1)(n−2)/6 ≈ −n^2/6`. Нужен разрез, где `K` лишь чуть-чуть
положительна, при сильно отрицательном среднем — поэтому любые усреднения
проваливаются не «немного», а на порядок (см. §3).

**Лемма 1.3 (геометрия пары).** Пара `{p, q}` согласована (не инвертирована)
при разрезе `(a, b)` тогда и только тогда, когда
`[a ∈ (q, p]] = [b ∈ (pi(q), pi(p)]]`. Множество согласующих её разрезов —
объединение двух противоположных прямоугольников тора `Z_n × Z_n`
общей площади `(n − dx)(n − dy) + dx·dy`, где `dx = (q − p) mod n`,
`dy = (pi(q) − pi(p)) mod n`; несогласующих — двух других, площади
`(n − dx)·dy + dx·(n − dy)`. Таким образом `inv(a, b)` — кратность
накрытия точки `(a, b)` системой из `C(n,2)` пар «несогласных»
прямоугольников, и H13-I = «есть точка кратности не выше
`floor((n−1)^2/4)`». ∎

**Лемма 1.4 (торическая инвариантность и редукция классов).** Для
`pi'(i) = pi(i − alpha) + beta` выполнено `inv_{pi'}(a, b) = inv_pi(a − alpha,
b − beta)`, значит `I(pi') = I(pi)`. Каждый торический класс содержит
представителя с `pi(0) = 0` (взять `alpha = −i_0`, `beta = −pi(i_0)`),
поэтому `max_pi I(pi)` достигается уже на `(n − 1)!` представителях
с `pi(0) = 0`. ∎ (Проверено при 4 <= n <= 7, `check_H13I.py` часть 2.)

**Лемма 1.5 (сдвиговые тождества, включая совместный сдвиг).** Пусть `w` —
линия разреза `(a, b)`, `w_0` — её первое значение, `beta` — позиция
значения 0. Тогда

```
inv(a+1, b)   − inv(a, b) = (n − 1) − 2·w_0,      w_0   = (pi(a) − b) mod n;
inv(a, b+1)   − inv(a, b) = (n − 1) − 2·beta,     beta  = (pi^{-1}(b) − a) mod n;
inv(a+1, b+1) − inv(a, b) = 2·(n − w_0 − beta)    при w_0 != 0,
                          = 0                     при w_0 = 0.
```

Диагональный сдвиг — это операция `w ↦ w'`, `w'_j = (w_{j+1} − 1) mod n`
(циклический сдвиг влево плюс вычитание 1 из всех значений), т. е.
параллельный перенос точки разреза по диагонали тора. Это и есть
«совместный сдвиг обоих разрезов», которого не хватало в
`h13_line_model.md` §4; его явный вид получен здесь. ∎
(Проверено при 4 <= n <= 6 на всех pi и всех разрезах,
`check_H13I.py` часть 3.)

## 3. Закрытые направления (каждое — с явным контрпримером)

**3.1. Усреднение по любой прямой тора разрезов — REFUTED при n = 5.**
Прямая тора — это `n` разрезов вида `(a, g·a + t)`, `a ∈ Z_n` (направления
`(1, g)`, `g = 0..n−1`), плюс «вертикали» `(t, b)`, `b ∈ Z_n`. Минимум по
всем `n + 1` направлениям и всем сдвигам среднего значения `inv` вдоль
прямой уже при n = 5 равен `22/5 > 4 = floor(16/4)` (худшая
`pi = (0,2,1,4,3)`, исчерпывающе по всем классам при n = 5); при n = 6
худшее значение `38/6 > 6`. Это строго сильнее известного факта
«усреднение по всем `n^2` разрезам не работает»: не работает усреднение и
по любому одномерному подмножеству разрезов, в том числе по диагоналям
и антидиагоналям, хотя на отражениях `inv` постоянна вдоль антидиагоналей
и минимальная антидиагональ даёт ровно границу.

**3.2. Усреднение по `b` при фиксированном `a` бесполезно на отражениях
при каждом `a` (доказано).** Из `Σ_b noninv(a, b) = Σ_{p ≺_a q} (n − d_pq)`,
`d_pq = (pi(q) − pi(p)) mod n`, следует
`max_b noninv(a, b) >= C(n,2) − Q(a)/n`, `Q(a) = Σ_{p ≺_a q} d_pq`.
Для отражения `pi(i) = h − i` имеем `d_pq = n − (x_q − x_p)`, поэтому

```
Q(a) = n·C(n,2) − Σ_{i<j} (j − i) = n·C(n,2) − n(n^2−1)/6
```

не зависит от `a`, и оценка даёт `noninv >= (n^2 − 1)/6`, что строго
меньше требуемого `floor(n^2/4)` при всех n >= 2. То есть эта оценка
недостаточна не «в среднем по a», а при каждом a и на всём классе
экстремальных входов. ∎ (Проверено при 4 <= n <= 12 и всех h,
`check_H13I.py` часть 11.)

**3.3. Жёсткие семейства из n разрезов — REFUTED при 4 <= n <= 8.**
Семейство `F(m, t)`: для каждого `a` берётся тот `b`, при котором элемент
линии на позиции `m` имеет значение `t` (т. е. `b = (pi(a + m) − t) mod n`).
Ни одно из `n^2` семейств `F(m, t)` не даёт `max_pi min_a inv <=
floor((n−1)^2/4)` при 4 <= n <= 8 (исчерпывающе, `h13i_probes.py`;
минимум по семействам максимума `min_a inv` равен 3, 5, 7, 11, 16 при n = 4..8
против границ 2, 4, 6, 9, 12). Это обобщает §1.7
заметки `h13_line_model.md`, где отвергалось только `m = 0`. В частности
отвергается и естественный кандидат `F(floor((n−1)/2), 0)` («ноль в
середине линии»), который на всех отражениях даёт в точности оптимальный
разрез, но на других входах — нет.

**3.4. Маршрут Диакониса–Грэма — REFUTED при n = 8.**
Неравенство Диакониса–Грэма `inv(w) + T(w) <= D(w)` (D — футрул
`Σ_j |j − w_j|`, T — расстояние Кэли `n − #циклов`) даёт
`I(pi) <= min_{a,b} (D − T)`. На отражениях это точно: в оптимальном
разрезе `D = floor(n^2/4)`, `T ≈ n/2`, `D − T` = граница. Но при n = 8
для `pi(i) = 3i mod 8` минимум `D − T` по всем 64 разрезам равен 13 > 12.
Наименьшее n среди проверенных 4 <= n <= 8. Чистый футрул тем более не
годится: `max_pi min_{a,b} D` = 4, 6, 8, 12, 16 при n = 4..8 против
границы 2, 4, 6, 9, 12.

**3.5. Локальная оптимальность по четырём направлениям — REFUTED при n = 11.**
Это прямое закрытие пробела, отмеченного в `h13_line_model.md` §4/§6
(«доказательство должно использовать совместные сдвиги обоих разрезов»).
Назовём разрез `(a, b)` 4-локально минимальным, если
`inv(a + k·dx, b + k·dy) >= inv(a, b)` при всех `k` для четырёх направлений
`(1,0), (0,1), (1,1), (1,−1)` (последние два — совместные сдвиги из
леммы 1.5). Глобальный минимум 4-локально минимален, поэтому достаточность
этого условия доказала бы H13-I. Максимум `inv` по всем 4-локально
минимальным разрезам всех pi:

| n | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11 |
|---|---|---|---|---|---|---|---|---|
| граница | 2 | 4 | 6 | 9 | 12 | 16 | 20 | 25 |
| только (1,0), (0,1) | 2 | 4 | 6 | **10** | 12 | **17** | **22** | **27** |
| все четыре | 2 | 4 | 6 | 9 | 12 | 16 | 20 | **26** |

Контрпример (наименьшее n среди проверенных 4 <= n <= 11):
`n = 11`, `pi = (0,2,10,6,5,1,9,8,7,4,3)`, разрез `(a, b) = (4, 1)`,
линия `(4,0,8,7,6,3,2,10,1,9,5)`, `inv = 26 > 25`, при этом сам разрез
локально минимален по всем четырём направлениям, а `I(pi) = 18`.
Вывод: никакой фиксированный конечный набор направлений «локальности»
не заменяет глобального минимума — при росте n появляются посторонние
локальные минимумы выше границы.

## 4. Положительный результат: дуговой критерий (доказано)

**Лемма 4.1 (критерий (S)).** Пусть `k = floor(n/2)`. Если существуют дуга
позиций `A = [a, a + k)` и дуга значений `B = [b, b + k)` с `pi(A) = B`,
то `I(pi) <= floor((n − 1)^2/4)`.

Доказательство. Возьмём разрез `(a, b)`. Первые `k` элементов линии — это
образы `A`, а их значения — это `B`, сдвинутая на `−b`, т. е. в точности
`{0, …, k − 1}`. Значит все `k(n − k)` пар «первая половина — вторая
половина» не инвертированы, откуда
`noninv(a, b) >= k(n − k) = floor(n/2)·ceil(n/2) = floor(n^2/4)`,
и по лемме 1.1 `inv(a, b) <= floor((n − 1)^2/4)`. ∎

Отражения переводят дуги в дуги, поэтому (S) выполняется для всего
экстремального класса; тождественная перестановка и все повороты — тоже.
Данные (исчерпывающе, представители с `pi(0) = 0`):

| n | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|
| представителей | 6 | 24 | 120 | 720 | 5040 | 40320 |
| с (S) | 6 | 22 | 86 | 478 | 1982 | 14840 |
| max I без (S) | — | 3 | 4 | 7 | 11 | 14 |
| граница | 2 | 4 | 6 | 9 | 12 | 16 |

То есть (S) покрывает все экстремальные входы, но у оставшихся входов
запас всего 1–2 и не растёт: разбор «(S) или нет» не даёт лёгкого второго
случая. Худшие входы без (S) — аффинные (`(0,5,2,7,4,1,6,3) = 5i mod 8`,
`(0,4,8,3,7,2,6,1,5) = 4i mod 9`).

**Точное разложение.** Для любого разреза и любого `k`

```
noninv(a, b) = k(n − k) − M + N_1 + N_2,
```

где `M = Σ_{r=1..k} (y^{(r)} − (r − 1))` — «несоответствие» множества
значений первой половины линии начальному отрезку (`y^{(1)} < … < y^{(k)}` —
её значения по возрастанию), а `N_1`, `N_2` — числа неинверсий внутри
половин. При `k = floor(n/2)` H13-I равносильна существованию разреза
с `N_1 + N_2 >= M`: «разболтанность» образа дуги должна окупаться
неинверсиями внутри половин.

## 5. Аффинное семейство — вторая по трудности серия

Для `pi(i) = c·i + d` линия разреза `(a, b)` равна `w_x = (c·x + e) mod n`
с `e = c·a + d − b`, пробегающим всю `Z_n`; значит `I` зависит только от `c`
и равно `min_e inv(x ↦ c·x + e)`. Максимум по `c` даёт `c = −1`
(отражение) — равенство границе. При `c ∉ {±1}` запас мал и достигается
при `c`, близких к `n − 1`:

| n | 16 | 17 | 18 | 20 | 24 | 30 | 31 | 32 | 40 | 50 | 60 | 64 | 101 | 128 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| запас при c != ±1 | 7 | 3 | 7 | 3 | 4 | 10 | 8 | 5 | 16 | 8 | 30 | 12 | 17 | 21 |

Это объясняет, почему аффинные входы систематически ломают упрощения
(§3.3, §3.4 здесь; §1.7 в `h13_line_model.md`): у них `inv` при почти
любом разрезе близка к `C(n,2)/2 = floor((n−1)^2/4) + (n−1)/4`, то есть
нужную экономию порядка `n` даёт только тонкий выбор разреза.

## 6. Вердикт

H13-I остаётся **CONJECTURED**; конечная проверка расширена до
**исчерпывающей при 4 <= n <= 14**. За сессию закрыты (с контрпримерами)
все оставшиеся «дешёвые» схемы: усреднение по прямым тора, жёсткие
семейства из n разрезов, маршрут `D − T`, локальная оптимальность по
четырём направлениям. Доказаны эквивалентные формы (леммы 1.1–1.5) и
достаточный дуговой критерий (лемма 4.1), покрывающий экстремальный класс.

Препятствие формулируется точно: величина `K(a, b)` в среднем сильно
отрицательна (порядка `−n^2/6` на отражениях), а требуется разрез с
`K >= floor(n/2)`; такие разрезы образуют долю порядка `1/n` от всех и не
выделяются ни локальными условиями фиксированного порядка, ни
одномерными усреднениями. Нужен глобальный аргумент, различающий
«дуговую» структуру (§4) и аффинную (§5).

Кандидаты на следующий заход, если к H13-I возвращаться:
1. количественное усиление леммы 4.1 — оценка `noninv >= k(n−k) − M + N_1
   + N_2` с доказательством `N_1 + N_2 >= M` для некоторого разреза;
2. отдельное доказательство для аффинного семейства (теоретико-числовая
   задача о `min_e inv(c·x + e)`), как проверка реалистичности любой схемы;
3. поиск в литературе именно по «минимальному числу инверсий торического
   класса перестановки»; известные неравенства Диакониса–Грэма и Дэниелса
   (Кендалл против Спирмена) проверены и в нужной силе не работают (§3.4).

Согласно `docs/notes/repo_state.md`, при отсутствии доказательства за
сессию план — переход к индукции H3 (PLAN §4.3, п. 3), бюджет 2 сессии.
