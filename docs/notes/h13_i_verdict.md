# H13-I — вердикт сессии 9: не доказана; найдено торическое тождество

Дата: 17.09.2026 (сессия 9). Бюджет: 1 сессия до письменного вердикта
(PLAN §8). **Итог: H13-I не доказана.** Доказаны три общих утверждения
о торических классах (C37), которые переводят H13-I в другую форму
и закрывают часть задачи; оставшийся разрыв назван и измерен.

Код: `experiments/toric_inversions.c` (toric_inversions-1.0),
`experiments/toric_sampling.py` (toric_sampling-1.0), `checks/check_C37.py`.
Доказательство: `docs/proofs/C37_toric_identity.md`. Отчёт:
`data/runs/h13_i/report.md`.

## 0. Постановка (напоминание)

`pi` — биекция Z_n -> Z_n; двойной разрез `(a, s)` даёт линию
`w_j = (pi(a + j) − s) mod n`; `I(pi) = min_{a,s} inv(w)`.

**H13-I:** `I(pi) <= floor((n − 1)^2/4)` при всех n >= 4.

Конечный статус: VERIFIED при `4 <= n <= 10` (исчерпывающе, все
`n!` перестановок и все `n^2` разрезов; независимо пересчитано в этой сессии
`experiments/toric_inversions.c`, `data/runs/h13_i/toric_inversions_4_10.json`).
Максимум достигается ровно на `n` отражениях при каждом `4 <= n <= 10`.

## 1. Что доказано (C37)

Пусть `Q(a, s) = sum_j (j − w_j)^2` — квадратичное смещение линии,
`T(u) = u mod n`, `D(u) = min(T(u), n − T(u))`.

1. **Тождество (лемма 1).** На торическом классе
   `inv(a, s) = c(pi) + Q(a, s)/n`, где `c(pi)` от разреза не зависит.
   Следствие: *разрез с минимумом инверсий — это в точности разрез
   с минимумом квадратичного смещения линии.*
2. **Формула (лемма 2).**
   `c(pi) = (1/n^2) sum_{i<k} ( T(k − i) − T(pi(k) − pi(i)) )^2
          = (1/(2 n^2)) sum_k Q(k, pi(k))`;
   `c >= 0`, `c = 0` ровно на поворотах.
3. **Максимум c (лемма 3).** `c(pi) <= (n − 1)(n − 2)/6`, равенство
   **тогда и только тогда, когда pi — отражение.** Доказательство:
   для каждого «якоря» `k` величина `Q(k, pi(k)) = sum_i (p_i − q_i)^2`
   максимальна ровно при обратном спаривании `q = n − p` (неравенство
   о перестановках), а это равносильно тому, что pi — отражение.
4. **Теорема 5.** Пусть `d_i = T(i − pi(i))`, `r = T(a − s)` и
   `J(r) = c(pi) + (1/n) sum_i D(d_i − r)^2`. Тогда `J(r)` — целое,
   `J(r) <= inv(a, s)` для каждого разреза с `T(a − s) = r`, и
   **`min_r J(r) <= floor((n − 1)^2/4)` при всех n >= 2.**
   Доказательство: усреднение `J` по `r` даёт ровно `c + Delta_n`
   (`Delta_n = (1/n) sum_v D(v)^2` — константа, не зависящая от pi),
   а `c + Delta_n` равно границе при нечётном n и границе + 1/2 при чётном,
   где спасает целочисленность `J`.
5. **Предложение 6.** `I(pi_h) = floor((n − 1)^2/4)` для каждого отражения
   и каждого n >= 2 (элементарно: линия отражения — два убывающих блока,
   `inv = C(v+1,2) + C(n−1−v,2)`, минимум при равном делении). Раньше
   равенство было известно только как конечная проверка при `n <= 10`.

Итого: H13-I доказана **для выровненной релаксации** (п. 4) и **для самих
экстремальных входов** (п. 5), но не в общем случае.

## 2. Где именно остался разрыв

Точка `i` называется *выровненной* при разрезе `(a, s)`, если
`|alpha_i − beta_i| = D(delta_i)`, то есть её смещение в линии — «короткая
сторона» циклического смещения. Разложение точное:

```text
inv(a, s) = J(r) + M(a, r),
M(a, r)   = sum over non-aligned i of ( n − 2 D(d_i − r) ) >= 0,
I(pi)     = min_r [ J(r) + min_a M(a, r) ].
```

Геометрически: точка `i` не выровнена ровно тогда, когда `a` лежит
в полуинтервале между `pi(i) + r` и `i`, пройденном в короткую сторону
(длина `D(d_i − r)`); её вес — `n − 2 D(d_i − r)`. То есть H13-I — это задача
«на окружности Z_n даны n хорд, по одной с концом в каждой точке; найти точку,
покрытую хордами малого суммарного веса».

Теорема 5 говорит `min_r J(r) <= bound`, но не про `M`. Измерения:

| n | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 12 | 15 | 20 | 30 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `max (I − min_r J)` | 0 | 0 | 0 | 0 | 3 | 2 | 5 | >=8 | >=10 | >=24 | >=56 |
| `floor((n−1)^2/4)` | 2 | 4 | 6 | 9 | 12 | 16 | 20 | 30 | 49 | 90 | 210 |

(`n <= 10` — исчерпывающе, `n >= 12` — по выборкам из
`data/runs/h13_i/sampling_seed1.jsonl`.) Разрыв растёт примерно как `n^2/16`,
то есть релаксация не «почти точна» — она точна только там, где выровненный
разрез существует при оптимальном `r` (следствие 5.1). Измерено точно:
при `4 <= n <= 7` равенство `I(pi) = min_r J(r)` верно для **всех** pi
(значит, выровненный разрез при оптимальном `r` есть всегда); при `n = 8`
у 40 перестановок даже правило «взять `r` = argmin J, затем лучшее `a`»
даёт больше границы (п. 3.5), хотя сама H13-I для них выполняется
при другом `r`.

## 3. Отвергнутые в этой сессии подходы (с контрпримерами)

Все контрпримеры воспроизводит `checks/check_C37.py` (части E, F).

1. **Отбросить `c`** («выровненная релаксация без якорного члена»):
   `min_{a,s} Q <= sum_v D(v)^2 − (n/2 при чётном n)` — **ложно**.
   Наименьшее найденное n: 8, `pi(i) = 5 i mod 8 = (0,5,2,7,4,1,6,3)`:
   `min Q = 56`, порог `40`. (Минимальность: при `4 <= n <= 7` нарушений
   нет — исчерпывающий перебор; при n = 8 нарушителей 16 штук.)
   Смысл: слагаемое `c` обязано участвовать — экономия на
   квадратичном смещении покупается ровно «непохожестью на отражение».
2. **Усреднение по антидиагонали** `min_t (1/n) sum_a inv(a, t − a) <= bound`
   — **ложно**; наименьшее n = 5, первый в лексикографическом порядке
   контрпример `(0,1,2,4,3)` (значение 21 при пороге 20); максимум
   отношения растёт (n = 10: 240 против 200). Причина: «правильное»
   направление диагонали зависит от pi (для отражений это `a + s`,
   для поворотов `a − s`).
3. **Усреднение по сдвинутым «разрезам в точках данных»**
   `min_g (1/n) sum_a inv(a, pi(a) + g) <= bound` — **ложно**;
   наименьшее n = 5, первый контрпример `(0,1,4,3,2)` (21 против 20);
   при n = 6 нарушений нет, при n = 7 первый — `(0,1,2,6,5,4,3)`
   (66 против 63). Это семейство «подстраивается под pi» (для отражений
   совпадает с антидиагональю, для поворотов — с диагональю) и всё равно
   недостаточно.
4. **Поякорная форма усреднения по строкам** (для каждого якоря `k`:
   `min_sigma W_k(sigma) + V_k/2 <= n·bound`, где
   `W_k(sigma) = sum_i (p_i − T(q_i − sigma))^2`, `V_k = W_k(0)`) —
   **ложно уже при n = 4**: `tau = (0,2,3,1)` даёт `9 > 8`. Избыток растёт:
   `1, 1, 3, 5, 11, 15` при `n = 4..9` (перебор всех `tau` с `tau(0) = 0`).
   То есть «плохие якоря» существуют; их компенсируют остальные.
5. **Правило «взять `r` = argmin J(r), затем лучшее `a`»** — **ложно**:
   при n = 8 у 40 перестановок оно даёт больше границы, например
   `pi = (0,2,6,5,1,3,7,4)`: `r* = 1`, `J(r*) = 8`, но `min_a inv(a, a − r*) = 14 > 12`
   (H13-I для этой pi выполняется при другом `r`).
6. Ранее отвергнутое (сессия 8, не повторялось): усреднение по всем `n^2`
   разрезам, индукция по одному элементу, семейство «первый элемент
   линии равен t», локальные условия оптимальности (лемма C).
   Локальные условия — это в точности условия локального минимума `Q`;
   тождество леммы 1 объясняет, почему их мало: `Q` — не выпуклая функция
   на торе, у неё бывают локальные минимумы выше границы.

## 4. Что выжило: единственная не опровергнутая усиленная форма (C38)

**C38 (гипотеза).** Для всех n >= 4 и всех pi

```text
sum_a min_s inv(a, s) <= n · floor((n − 1)^2 / 4),
```

то есть *среднее по разрезам позиций от наилучшего сдвига значений
не превосходит границы*. Равенство — ровно на отражениях.

- C38 => H13-I (минимум не больше среднего).
- VERIFIED исчерпывающе при `4 <= n <= 10` (все `n!` перестановок,
  `experiments/toric_inversions.c`), максимум равен `n·bound` ровно
  на отражениях; транспонированная форма `sum_s min_a inv(a, s)` даёт
  те же числа. На выборках при `n = 12, 15, 20, 30` нарушений нет.
- C38 **нельзя** доказать поякорно (п. 3.4) — нужно использовать связь
  между строками.
- В терминах C37: C38 равносильна
  `sum_a min_s Q(a, s) + (1/2) sum_a Q(a, pi(a)) <= n^2 · floor((n−1)^2/4)`.

Это естественный следующий объект атаки: утверждение об *усреднении*,
а не о минимуме, и в нём уже нет свободы выбора `r`.

## 5. Структура экстремальных и почти-экстремальных входов

- **Экстремальные — только отражения.** Исчерпывающе при `4 <= n <= 10`:
  `max_pi I(pi) = floor((n−1)^2/4)`, число аргмаксимумов равно `n`, и все
  они — отражения. Теперь это подкреплено и общим утверждением: равенство
  в лемме 3 (`c = (n−1)(n−2)/6`) достигается ровно на отражениях, а
  предложение 6 даёт `I(pi_h) = floor((n−1)^2/4)` при всех n.
- **Почти-экстремальные — возмущения отражений.** Выборки при
  `n = 12, 15, 20, 30` (`data/runs/h13_i/sampling_seed1.jsonl`, seed 1):
  отражение плюс одна транспозиция значений даёт `bound − 1`, плюс две —
  `bound − 2`, плюс три — от `bound − 5` до `bound − 11`.
- **Аффинные входы** `pi(i) = a i + b` (не отражения): максимум
  `bound − 4` (n = 12), `bound − 4` (n = 15), `bound − 3` (n = 20),
  `bound − 10` (n = 30) — близко, но строго ниже; именно на них ломается
  выровненная релаксация (п. 3.1, `pi(i) = 5i` при n = 8).
- **Случайные** заметно ниже: максимум по 400 выборкам равен
  `bound − 7` (n = 12), `bound − 10` (n = 15), `bound − 21` (n = 20),
  `bound − 42` (n = 30).
- **Локальный поиск** (подъём транспозициями, 8 рестартов) ни разу
  не превысил границу и ни разу не нашёл не-отражение с `I = bound`.
