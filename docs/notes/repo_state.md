## Следующая задача

H13-I закрыта вердиктом сессии 9 (не доказано, не опровергнуто; см. выше и
`docs/notes/h13_line_model.md` §7). Следующий шаг — **индукция H3** (PLAN §4.3,
п. 3), бюджет 2 сессии до письменного вердикта: определить вложение задачи
размера n−1 в задачу размера n для исходной цели `D_n <= B_n` (не для I(pi)
отдельно — редукция по одному элементу для самого H13-I уже отвергнута,
`docs/notes/h13_line_model.md` §1.7). Конкретно: построить, как слово для
`sigma_{n-1}` (или произвольной pi размера n−1) вкладывается в слово для
перестановки размера n, полученной естественным расширением (например,
добавлением элемента n−1 на новую позицию с последующей корректировкой),
посчитать точную стоимость вставки (число дополнительных обменов и вращений
головы) и подтвердить или опровергнуть рекуррентность `T_n <= T_{n-1} + (n-1)`
(H3), которая при `T_4 <= 6` в точности даёт `B_n` с нулевым запасом. Ключевая
трудность (PLAN §4.3 п. 3): L и R вращают весь массив, поэтому «зафиксировать»
один элемент при вложении меньшей задачи нельзя молча — нужно явно учесть, что
база (n−1)-конструкции читается на окружности размера n, и посчитать
стоимость восстановления ориентации/головы после вставки.

Не повторять: полный перебор n >= 13 для I(pi) без инкрементального алгоритма
(`experiments/line_toric_max_i.c` даёт O(n^3), но n=13 всё равно оценивается
часами по измеренной скорости); гибридное усреднение и «диагональное»
ограничение для H13-I (оба отвергнуты сессией 9, §7.2 заметки); BFS линейной
модели при n >= 10; поиск схемы с `N_rot <= inv + f(n)` (её нет: C34-A, C36).

Параллельно доступны (не изменились): аудит S1 (§3.2, C8); аудит прежнего
комплекта (C1, gap); доказательство H8/C25 (формула длины на sigma_n).
