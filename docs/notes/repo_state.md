## Следующая задача

PLAN §8: H10, вторая (последняя) из 2 сессий бюджета. Шаг 1 (отражения)
выполнен: C28 даёт точные F(k), S(k) и правило переносчика, но не формулу

{3,4,5,10,11}); без неё C28 остаётся VERIFIED (числ. без исключений до
n=150), не PROVED. Два варианта следующего шага:

1. Вывести R(k,c) на отражениях (наиболее прямой путь к PROVED на этом
   семействе; может дать модель аргумента для произвольной pi).
2. Начать шаг 2 плана напрямую: связать `argmin_c F_c` (медианный сдвиг,
   тождество `F_c = sum_i delta_n(i − pi(i), c)`) с S_c и R_c для
   произвольной pi; собственный маршрут H(c) для этого не годится (H9
   REFUTED).

вердикт с найденным препятствием, как и планировалось изначально (правило
12 AGENTS.md).
