Сессия 8 (13.09.2026) — вердикт H13:

- Пункт (2) (доказуемая общая схема слова для линии, `N_rot <= inv + f(n)`,

  «I(pi) + геометрический обход k точек рёбер обмена из фиксированного
  старта» — прямая объектная BFS-проверка (n = 8, k = 3) дала точное
  `d_line = 13` против предсказанных 8: конечная позиция головы c в линейной
  модели переразмечивает содержимое линии, а не выбирается независимо, так
  что простой геометрический обход рёбер обмена не описывает длину слова
  целиком. Ошибка и её причина зафиксированы как предупреждение —
  `docs/notes/h13_verdict.md` §2. Точные данные (`experiments/h13_blocks.py`,
  n = 9..12, k = 2, 3, 4; таблицы n = 11, 12 воспроизведены `exact/bfs_fast.c`)

  для вывода о `Theta(n)` против `O(1)` в доступном диапазоне (BFS при n >= 13
  недоступен). Статус H13(2): CONJECTURED/OPEN.

  блоках). H13(1) (`max_pi d_line = B_n` только на sigma_n, C33) не

## Следующая задача

H3 — индуктивная редукция (PLAN §4.3 п.3), бюджет 2 сессии до письменного
вердикта: определить вложение задачи размера n-1 (или меньше) в задачу
размера n, оценить стоимость имитации её ходов при фиксированном элементе
(L и R вращают весь массив — исключить его молча нельзя) и восстановление
ориентации после подзадачи. Критерий: либо рекуррента вида
`D_n <= D_{n-1} + c` с доказанным шагом и запасом, либо вердикт и следующий
кандидат из PLAN §4.2/§4.3. Параллельно доступны (не обязательны): аудит S1
(§3.2, C8), аудит прежнего комплекта (C1, gap-файл), доказательство H8/C25
(формула длины N1 на sigma_n).

Не повторять: попытки геометрической формулы длины для линейной модели без
объектной BFS-проверки на малом n (см. `docs/notes/h13_verdict.md` §2, ошибка
сессии 8); перебор c политики «горизонт» на больших n; BFS точных таблиц
при n >= 13 (факториал не позволяет точную таблицу за разумное время
и место).
