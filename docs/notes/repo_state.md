Сессия 4 (13.09.2026) — H10 шаг 1 (отражения), 1-я из 2 бюджетных сессий:

- Доказано алгебраически (не только численно): на отражениях
  `pi_h(i)=h-i mod n`, для любой нетривиальной транспозиции цикла f_c,
  `F(C)=2*delta_n(i,j)`, `S(C)=3` без исключений (антиподальный случай
  даёт то же S через другую комбинацию M,E). Отсюда `F_c=P` при n нечётном
  или n=0 mod4; при n=2 mod4: `F_c=P∓1` по чётности `h+c` (C28). Это
  уточняет (опровергает при n=2 mod4) фразу сессии 3 «F_c постоянна по c
  на отражениях» — проверено на sigma_n (n=6,10).
- R_c (маршрут по переносчикам) явной формулы не получил за бюджет сессии:
  переносчики отражения — два кластера ~n/4 на окружности, расположение
  зависит от n mod 4 негладко. Вместо формулы —
  `experiments/h10_reflections_check.py`: исчерпывающий перебор всех h, c
  при 4<=n<=71 без контрпримеров к `<= B_n+1` (равенство ровно при
  n=2 mod4). Отчёт `data/runs/strict_loss_audit/h10_reflections_check.json`
  (C27v-refl); расширяет диапазон C27v для этой семьи с n<=12 до n<=71.
- Полный разбор: `docs/proofs/h10_reflections.md`. Шаг 2 (произвольная pi)
  не продвинут: то же препятствие (нет оценки R_c) видно уже на
  транспозициях, общий случай не проще.
