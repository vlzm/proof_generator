Сессия 4 (13.09.2026) — вердикт по H10 (C27), бюджет 2 сессии исчерпан:

- `docs/proofs/H10_reflections.md`: H10 доказан на подсемействе отражений
  `pi(i)=h-i mod n` для **всех** n>=4 (замкнутая форма, не конечный
  диапазон) — новая строка реестра C27r, PROVED. Механизм: у отражений
  каждый нетривиальный цикл f_c — 2-цикл, и для любого 2-цикла (в том числе
  антиподального) `S(C)=3` тождественно, независимо от длины шага; вместе
  с `F_c` (тоже функцией не более чем чётности c) это сводит минимум по
  всему `Z_n` к минимуму по `c из {0,1}`. Доказательство сильнее, чем
  требовало H10: используется собственный маршрут `H(c)` конструкции N1,
  маршрут по переносчикам `R_c` не понадобился (`R_c<=H(c)` тривиально
  переносит результат). Итог: `min_c[2F_c-S_c+H(c)] <= B_n+1` при всех
  n>=4 и всех h, с равенством `B_n+1` ровно при `n≡2 (mod4)` и `h` чётном
  (проверено точностью границы прогоном слов до n=80), иначе `<=B_n`.
  Побочно доказана H8/C25 (длина слова N1 на sigma_n равна ровно B_n) для
  всех n>=4, не только 4<=n<=12 (частный случай h=1); формула N_X/N_rot —
  вторая, отдельная часть H8/C25 — не выведена, остаётся VERIFIED
  4<=n<=12.
- `checks/check_C27_reflections.py` (PASS, ~45 c): точные формулы F_c,S_c,
  H(c) сверены с конструкцией на 4<=n<=60 (нечётное n — все h все c, 35 980
  троек; чётное n — все h, c=0,1, 1856 пар); реальные слова обоих
  маршрутов исполнены и проверены на сортировку 4<=n<=40 (2×22 126 слов).
  Отчёт `data/runs/check_C27_reflections/`.
- Общий случай (произвольная pi) остаётся CONJECTURED, VERIFIED в прежнем
  объёме (4<=n<=9 все pi, семейства n<=12, SAMPLED n=20,50,100 — новых
  прогонов не потребовалось, вопрос качественный, не числовой). Точное
  препятствие к переносу аргумента отражений — `docs/notes/H10_general_obstruction.md`:
  на контрпримере H9/C26 (n=9, pi=(0,2,8,7,5,1,6,4,3)) показано, что
  `S(C)` длинного цикла не определяется его длиной (в отличие от 2-циклов
  отражений), и минимумы `2F_c-S_c` и `R_c` достигаются на разных c —
  нужна оценка суммы, а не отдельные оценки слагаемых. Три отклонённых
  подхода и три кандидата для продолжения перечислены там же.
- Бюджет задачи (2 сессии, поставлен в сессии 3) исчерпан этой сессией.
