## Готово (сессия 1, 12.09.2026)

  независимый сертификатор `verify_distances.py`.
- BFS: эталонный `exact/bfs.py` и ускоренный `exact/bfs_fast.c`
  (побайтово совпадают на 4<=n<=11).
- Таблицы расстояний сертифицированы для 4 <= n <= 12; n=11, 12 (.bin)
  не в git из-за размера — sha256 в `data/tables/dist_n1{1,2}.json`,
  воспроизведение: `gcc -O2 -o exact/bfs_fast exact/bfs_fast.c &&
  ./exact/bfs_fast 11 data/tables/dist_n11.bin && ./exact/bfs_fast 12
  data/tables/dist_n12.bin` (~4 мин на n=12), сверить sha256.
- VERIFIED при 4 <= n <= 12: D_n = B_n; единственность sigma_n; слой
  D-1 = 3 соседа sigma_n; d(rev_n) = D_n - 2; расщепление всех геодезических
  (floor((n-1)^2/4), floor(n^2/4)). Реестр: CLAIMS.md, строки C2v–C14v.
- `bounds/known.py`: все заявленные формулы в точной арифметике.
- Отчёт: `data/runs/session1_report.md`; журнал: LOGS.md.
