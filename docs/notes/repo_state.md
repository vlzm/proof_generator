## Следующая задача

PLAN §8, шаг 2 (шаг 1 — H10 на отражениях, PROVED, C28): H10 для
произвольной pi — связать медианный сдвиг `argmin_c F_c` (тождество
`F_c = sum_i delta_n(i − pi(i), c)`) с S_c и R_c; нужна либо нижняя оценка
S_c у минимизирующего c, либо аргумент «нельзя одновременно иметь F_c = P,
малое S_c и большое R_c при всех c»; собственный маршрут H(c) для C15
не годится (H9 REFUTED). Отражения не дают готового шаблона для этого шага:
там `2F_c−S_c` зависит только от чётности h+c, что и позволило обойтись
c in {0,1} (`docs/proofs/H10_reflections.md`); для произвольной pi такой
структуры может не быть. Бюджет — остаток из исходных 2 сессий на весь H10
(сессия 4 частично ушла на шаг 1). Худшие входы для проверки идей —
`data/runs/strict_loss_audit/perms*.json`.
