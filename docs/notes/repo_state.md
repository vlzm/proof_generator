## Следующая задача

PLAN §8: H10, шаг 2 (общая pi) — вторая и последняя сессия бюджета
(первая, сессия 4, закрыла шаг 1 на отражениях: C28, PROVED). Приём шага 1
(`R_c<=H(c)` тривиально) не спасает общий случай: барьер — на контрпримерах
C26 к H9 (n=9) `Q_R-B_n=-4` при `Q_min(H)-B_n=+3`, то есть маршрут по

работает; нужна прямая лемма о числе/разбросе переносчиков цикловой

`F_c = sum_i delta_n(i − pi(i), c)`, PROBLEM §5.2), а не оценка через H(c).

pi(i)=a*i mod n n<=29 — аналог плоского профиля F_c контрпримеров C26)
ничего не нашёл. При неудаче — письменный вердикт (PLAN §8 шаг 3); барьер
уже сформулирован явно (LOGS.md, сессия 4, п. 3) как минимальный найденный
пример препятствия. Худшие входы для проверки идей —
