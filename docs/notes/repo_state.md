Сессия 9 (15.09.2026) — вердикт по H13-I: не доказана за бюджет:

- Переформулировка H13-I (`docs/notes/h13_line_model.md` §7.1): I(pi) — задача
  о двух НЕЗАВИСИМЫХ циклических порядках на n точках (разрез позиций `q` и
  разрез значений `e = (q+1-c) mod n` пробегают Z_n независимо). Точная
  формула вклада пары `{a,b}` в сумму по всем n^2 разрезам:
  `(n-delta)(n-gamma) + delta*gamma`, `delta=(b-a) mod n`,
  `gamma=(pi(b)-pi(a)) mod n` (проверена численно, случайные pi, 3<=n<=7). У
  отражений `gamma = n - delta` для каждой пары — структурное (не доказанное)
  объяснение, почему они численно единственный максимизатор I.
- Два новых однопараметрических семейства разрезов отвергнуты с растущим
  разрывом (`experiments/h13i_rotation_only.c`,
  `experiments/h13i_diagonal_cut.c`, `data/runs/h13i_single_param/run_notes.md`):
  (1) только поворот позиций (значение зафиксировано) — разрыв против
  `floor((n-1)^2/4)` равен 0,0,0,1,1,1,3,3 при n = 4..11 (исчерпывающе,
  O(n) на перестановку через инкрементальную формулу инверсий); (2) диагональ
  `c = const` (оба разреза синхронно) — разрыв 2,2,4,3,5,6,8 при n = 4..10.
  Оба растут, не O(1): независимая двумерная сетка `(q,c)` нужна по существу.
- Компрессионный (обменный) аргумент «отражения — глобальный максимум I(pi)»
  намечен, но не доведён до доказательства: обмен двух соседних по значению
  элементов меняет согласованность до `2(n-2)` пар одновременно, и как это
  двигает MAX (а не сумму) по сетке `(q,c)` — не сведено к управляемому
  случаю за сессию.
- Реестр: C37 (новые отрицательные результаты; H13-I остаётся CONJECTURED,
  VERIFIED 4 <= n <= 10 без изменений — C33/C35 не тронуты).
- Вердикт: H13-I не доказана и не опровергнута; направление меняется на

## Следующая задача

H13-I закрыта вердиктом сессии 9 (не доказана, не опровергнута; см.
`docs/notes/h13_line_model.md` §7 и CLAIMS C37) — не возвращаться к ней в
рамках следующего бюджета. Следующая задача — **индукция H3** (PLAN §4.3,
п. 3; PLAN §0), бюджет 2 сессии до письменного вердикта:

1. Определить явное вложение задачи размера n-1 в задачу размера n (какой
   элемент/позиция — «лишний», как читается состояние размера n-1 внутри
   состояния размера n).
2. Стоимость имитации ходов L, R, X меньшей задачи в терминах ходов на n
   элементах: L и R вращают ВЕСЬ массив длины n, включая лишний/фиксированный
   элемент — его нельзя молча исключить из подсчёта; нужна явная формула
   доп. стоимости на каждый шаг меньшей задачи (или на переход между шагами).
3. Восстановление ориентации/положения лишнего элемента в конце (запас
   рекурренты по H3 — ровно ноль, значит доп. стоимость должна быть учтена
   точно, без округления в свою пользу).
4. Проверить кандидатную рекурренту `T_n <= T_(n-1) + (n-1)`, `T_4 <= 6`
   (даёт ровно B_n, H3) на сертифицированных таблицах C2v при 4 <= n <= 12,
   ДО попытки доказать её в общем случае: если это уже подсчитано некорректно
   (T_4..T_12 не совпадают с B_n тем же способом сведения) — переформулировать
   до общего доказательства.

Не повторять: усреднение по всем n^2 разрезам, индукция H13-I по одному
элементу, семейство «первый элемент = t», локальные условия оптимальности
разреза, однопараметрические редукции H13-I (поворот только позиций;
диагональ `c = const`) — все отвергнуты (`docs/notes/h13_line_model.md` §1.7,
§4, §7; CLAIMS C34-C37). BFS линейной модели или полного графа при n >= 11
без нового обоснованного вопроса и измерения по правилу 10.
