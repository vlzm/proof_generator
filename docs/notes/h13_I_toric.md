# H13-I — торические классы: вердикт сессии 9

Дата: 14.09.2026 (сессия 9). Задача из PLAN §8: доказать
**H13-I: `I(pi) <= floor((n − 1)^2/4)` при всех n >= 4 и всех pi**
(`I(pi)` — минимум числа инверсий линии по всем `n^2` двойным разрезам,
`docs/notes/h13_line_model.md` §0). Бюджет — 1 сессия до письменного вердикта.

**Вердикт: H13-I не доказана и не опровергнута.** Доказана более слабая общая
оценка `I(pi) <= (n − 1)(2n − 1)/6` (≈ `n^2/3` вместо `n^2/4`) — первая
доказанная общая оценка для `I`: `docs/proofs/C37_toric_average.md` (C37,
PROVED). Конечная проверка H13-I расширена с n <= 10 до **4 <= n <= 13
исчерпывающе**. Найдена точная переформулировка задачи и отвергнуты ещё три
класса подходов. Ниже — что именно установлено и куда идти дальше.

Код: `experiments/toric_inv.c` (toric_inv-1.0), `checks/check_C37.py`.
Отчёты: `data/runs/toric_inv/report.md`, `data/runs/check_C37/report.md`.

## 1. Точное тождество (основной инструмент)

Разрез `(u, v)` (связь с `(q, c)`: `u = q + 1`, `v = q + 1 − c`), линия
`w_j = (pi(u + j) − v) mod n`, `phi(x) = (x mod n) − (n−1)/2` и

```text
T(u, v) = sum_i phi(i − u) * phi(pi(i) − v)     («спирменова» корреляция разреза).
```

Тогда (C37, лемма 2) **`inv(u, v) + (2/n) T(u, v) = Ibar(pi)`** при всех
`(u, v)`, где `Ibar` — среднее `inv` по всем `n^2` разрезам. Следствия:

1. `I(pi) = Ibar(pi) − (2/n) * max_{u,v} T(u, v)`; минимум инверсий и максимум
   корреляции достигаются на одних и тех же разрезах.
2. Среднее `inv` по любой полной строке и по любому полному столбцу тора
   разрезов равно `Ibar`. Любое усреднение по строке/столбцу бесполезно —
   это объясняет разом все «усредняющие» неудачи сессии 8.
3. `T(u, v) = n^2 * D~(u, v)`, где `D~` — дважды центрированная (вычтены
   средние по строке и столбцу) угловая дискрепанция
   `D(u, v) = #{i < u : pi(i) < v} − uv/n`. То есть H13-I — утверждение
   о максимуме дискрепанции точечного множества `{(i, pi(i))}` на торе.
4. Смешанная разность `inv(u+1,v+1) + inv(u,v) − inv(u+1,v) − inv(u,v+1) =
   2 − 2n*[pi(u) = v]`: `inv` супермодулярна всюду, кроме n точек самой pi.

Эквивалентные формы H13-I (все проверены как эквивалентные машинно при
4 <= n <= 7):

```text
H13-I  <=>  max_{u,v} T(u, v) >= Delta/(2n),   Delta = n^2*floor(n^2/4) − E,
            E = sum_{i != j} ((j−i) mod n)*((pi(j)−pi(i)) mod n) = n*sum_a a*k_a
       <=>  max_{u,v} [конкордантных пар] >= floor(n^2/4)
       <=>  max_{u,v} [Кендалл tau] >= floor(n/2)   (tau = C(n,2) − 2*inv).
```

## 2. Что доказано (C37)

```text
I(pi) <= Ibar(pi) <= (n − 1)(2n − 1)/6   для всех n >= 3 и всех pi,
max_pi Ibar(pi) = (n − 1)(2n − 1)/6      (достигается ровно на отражениях).
```

Схема: `Ibar = n(n−1)/2 − (1/n) sum_a a*k_a`, где
`k_a = (1/n) sum_i ((pi(i+a) − pi(i)) mod n)`; ключ — «тройное неравенство»
`k_a + k_b + k_c <= 2n` при `a + b + c ≡ 0 (mod n)` (три сдвига по кругу дают
сумму n или 2n) и `k_a + k_{n−a} = n`. Суммирование тройных неравенств по всем
упорядоченным тройкам с суммой n даёт `sum_a a*k_a >= n(n^2−1)/6`. Подробности
и машинная сверка — `docs/proofs/C37_toric_average.md`.

Запас до H13-I: `(n−1)(2n−1)/6 − floor((n−1)^2/4) ≈ n^2/12`, то есть по
следствию 1 нужно ещё доказать `max_{u,v} T >= Delta/(2n)`, а на отражениях
`Delta/(2n) = n^3/24 + O(n)` — при значениях T порядка `n^3`.

## 3. Конечные данные (новое)

Исчерпывающе по одному представителю каждого торического класса
(все pi с `pi(0) = 0`; `I` — торический инвариант), `experiments/toric_inv.c`:

| n | классов | max I | floor((n−1)^2/4) | классов с равенством | max RA | n*floor((n−1)^2/4) | время |
|---|---|---|---|---|---|---|---|
| 4..10 | 6 … 362 880 | = границе | 2 … 20 | 1 (отражения) | = n*границе | | < 1 с |
| 11 | 3 628 800 | 25 | 25 | 1 | 275 | 275 | 1.2 с |
| 12 | 39 916 800 | 30 | 30 | 1 | 360 | 360 | 15 с |
| 13 | 479 001 600 | 36 | 36 | 1 | 468 | 468 | 207 с |

Во всех n = 4..13 максимум `Ibar` по pi тоже достигается на отражениях и равен
`(n−1)(2n−1)/6` — ровно оценка C37 (равенство в теореме).

`RA(pi) = sum_u min_v inv(u, v)`. Сверх того:

- аффинные `pi(i) = a*i + b`, все `(a, b)` при 4 <= n <= 120: `max I` равен
  границе и достигается только при `a = −1` (отражения); нарушений нет;
- восхождение по транспозициям (300 стартов, seed `7919*n`) при
  n = 13..40: максимум ровно на границе при n <= 24, ниже — при n = 30, 40;
  нарушений нет.

Итого **H13-I VERIFIED при 4 <= n <= 13** (исчерпывающе), равенство — ровно
на n отражениях.

## 4. Более сильная гипотеза (строчная форма, C38)

```text
RA:  sum_u min_v inv(u, v) <= n * floor((n − 1)^2/4)      («в среднем по строке»)
```

VERIFIED при 4 <= n <= 13 исчерпывающе; равенство — ровно на отражениях.
`RA => H13-I` (минимум не больше среднего). Эквивалентно
`sum_u max_v H_u(v) >= Delta/(2n)`, где `H_u(v) = n*(D(u,v) − D_col(v))` —
«ходьба» по частичным суммам центрированных позиций. Дополнительно:
минимальное (по pi) число «хороших» строк (`min_v inv(u,v) <=
floor((n−1)^2/4)`) равно 4, 5, 6, 6, 6, 7, 8, 9, 9, 10 при n = 4..13,
то есть «плохих» строк не больше трёх во всём проверенном диапазоне.
Эти формы сильнее H13-I и могут оказаться доступнее: в них разрешено
усреднять по u.

## 5. Отвергнутые подходы (к прежнему списку)

Прежние (сессия 8, `h13_line_model.md` §1.7, §4): равномерное усреднение по
разрезам, индукция по одному элементу, семейство «первый элемент линии = t»,
локальные условия оптимальности. Новые:

1. **Усреднение по строке/столбцу** бесполезно тождественно (следствие 2
   выше) — не нужно и проверять.
2. **Усреднение по «точечным» семействам** `B(s, t) = sum_j T(j+s, pi(j)+t)`
   (среднее T по n разрезам, сдвинутым вдоль самой pi; это в точности
   усреднённая форма семейства «первый элемент = t»): требуется
   `max_{s,t} B >= Delta/2`, нарушается при n = 5 на `(0,1,4,3,2)`
   (`max B = 15 < 17.5`) и при n = 7 на `(0,2,1,6,5,4,3)` (`56 < 70`);
   всего 5 из 24 и 63 из 720 классов.
3. **Усреднение по любой прямой тора разрезов** (все направления `g` с
   `gcd(g_1, g_2, n) = 1`, все сдвиги): минимум среднего по прямой превышает
   `floor((n−1)^2/4)` при n = 5 на `(0,2,1,4,3)` (22/5 против 4), при n = 6 на
   `(0,2,5,1,4,3)` (19/3 против 6), при n = 7 на `(0,2,4,1,6,5,3)`
   (68/7 против 9).
4. **Моментные (мягкие) оценки** `max T` не дают нужной константы: на
   отражениях `max T / RMS(T) = 1.096, 1.110, 1.116` при n = 12, 20, 40
   (предел ≈ 1.118), а оценка `max T >= sum (T^+)^2 / sum T^+` даёт лишь
   0.79–0.80 от `max T`, тогда как требуется 100 % с точностью `O(1/n)`.
   Неравенство точное: на отражениях `max T = n^3/24 + n/12` и
   `Delta/(2n)` — то же число.

Вывод: доказательство обязано *выбирать* разрез (или хотя бы по одному
разрезу на строку, как в C38), а не усреднять по фиксированному семейству.

## 6. Следующий шаг

Рекомендация: атаковать строчную форму C38 (`RA`), а не H13-I напрямую —
там разрешено усреднение по u, и статистика `max_v H_u(v)` допускает выбор
«сечения» `v(u)`; достаточно предъявить *любое* правило `u -> v(u)` с
`sum_u inv(u, v(u)) <= n*floor((n−1)^2/4)`. Известно, что правила
«`v = pi(u) − t` при фиксированном t» не годятся (п. 5.2), а вот правила,
зависящие от локальной структуры строки (например, выбор пика ходьбы
`H_u`), не исследованы.

Второй путь — усилить C37: неравенство `sum_a a*k_a >= n(n^2−1)/6`
использует только первые моменты `k_a`. Ограничение `I <= Ibar` теряет ровно
`(2/n) max T`; нужна нижняя оценка `max T` через те же разностные статистики
(например, через распределение `m(a, b) = #{i : pi(i+a) − pi(i) = b}`,
которое даёт и `Delta`, и `T` линейно).

Если ни то, ни другое не пойдёт — переход к индукции H3 (PLAN §4.3), как и
предусмотрено в `h13_line_model.md` §6.
