# H10 / C27 на отражениях: точные формулы F(k), S(k) и структура переносчиков

Сессия 4 (13.09.2026). Бюджет H10 по PLAN §8 — 2 сессии до письменного
вердикта; это первая из них. Шаг (1) плана: явный разбор на отражениях.

## 0. Параметризация

Для отражения `pi(i) = h - i mod n` и сдвига `c`, `f_c(i) = pi(i)+c = k-i mod n`
с `k = h+c mod n`. Так как `c` пробегает `Z_n`, `k` тоже пробегает весь `Z_n`
(биекция при фиксированном h). Величины `F_c` и `S_c` (в отличие от `R_c`)
зависят только от `k`, а не от `h` и `c` по отдельности — обозначаем их
`F(k)`, `S(k)`. Маршрут `R_c` зависит от конкретного `c = k-h` (позиция
конца маршрута), поэтому от него так просто не избавиться.

## 1. F(k) — точная формула (PROVED)

`F(k) = sum_x dist(x, k-x mod n)`, где `dist(a,b) = min(g, n-g)`,
`g = (b-a) mod n` — обычное циркулярное расстояние (это переформулировка
`F_c` как суммы по всем позициям, а не по парам: каждая транспозиция даёт
свой `F(пара)` дважды при суммировании по обеим точкам, неподвижные точки —
0).

**n нечётно.** `2` обратимо по модулю `n`, поэтому `x -> (k-2x) mod n` —
биекция `Z_n -> Z_n`. Значит мультимножество `{dist(x,k-x) : x}` совпадает
с `{dist(0,u) : u in Z_n}` при любом `k`. Отсюда `F(k) = P` для всех `k`
(P = floor(n^2/4)), не только в среднем — точно. Подтверждено на всех
проверенных нечётных `n` (7, 9, 11, ..., см. `checks/check_C27.py`).

**n чётно.** `2x mod n` пробегает только чётные вычеты, каждый — дважды
(x и x+n/2 дают одно и то же). Значит `(k-2x) mod n` пробегает вычеты
чётности `k` (все чётные, если k чётно; все нечётные, если k нечётно),
каждый дважды. Отсюда

```text
F(k) = 2 * Feven   если k чётно
F(k) = 2 * Fodd    если k нечётно

Feven = sum_{v четно, 0<=v<n} min(v, n-v)
Fodd  = sum_{v нечётно, 0<=v<n} min(v, n-v)
Feven + Fodd = P
```

Прямым вычислением по чётности `n`:

- `n = 0 mod 4`: `Feven = Fodd = P/2` (симметрия чётных и нечётных вычетов
  относительно `n/2`) => `F(k) = P` для всех `k` — тоже константа, как
  и при нечётном `n`, но по другой причине. Подтверждено n=8,12,...,148.
- `n = 2 mod 4`: `Fodd = Feven + 1` (проверено n=6,10,...,150, разница
  всегда ровно 1) => `Feven=(P-1)/2`, `Fodd=(P+1)/2` (P нечётно при
  n=2 mod4), `F(k) = P-1` при чётном k, `F(k) = P+1` при нечётном k.

## 2. S(k) — точная формула (PROVED)

`S(пара) = 3` всегда (PROBLEM §5.3: и для неантиподальной, и для
антиподальной транспозиции). Значит `S(k) = 3 * t(k)`, `t(k)` — число
транспозиций `f_c` = `(n - f(k))/2`, `f(k)` — число неподвижных точек
(решений `2x = k mod n`).

- `n` нечётно: `2` обратимо, ровно одно решение всегда => `f(k)=1`,
  `t(k)=(n-1)/2`, `S(k) = 3(n-1)/2` для всех `k` — константа (согласуется
  с C24: среднее число неподвижных точек = 1, здесь оно точно 1 при каждом
  k, не только в среднем).
- `n` чётно: решение существует (`gcd(2,n)=2` делит k) <=> `k` чётно;
  тогда 2 решения (`f(k)=2`), иначе 0 (`f(k)=0`). Значит
  `S(k) = 3(n/2 - 1)` при чётном k, `S(k) = 3n/2` при нечётном k.

## 3. 2F(k) - S(k): вывод

Подставляя формулы §1-2:

```text
n нечётно:        2F-S = 2P - 3(n-1)/2                          (константа по k)
n = 0 mod 4:       2F-S = 2P - 3(n/2-1)   k чётно
                    2F-S = 2P - 3n/2       k нечётно             (k нечётно на 3/2 меньше... нет: 3n/2 > 3(n/2-1), т.е. k нечётно ДАЁТ МЕНЬШЕЕ 2F-S на 3)
n = 2 mod 4:        2F-S = 2P+1-3n/2       k чётно
                    2F-S = 2P+2-3n/2       k нечётно             (k чётно меньше на 1)
```

(Выведено арифметически из §1-2, проверено численно на всех отражениях
для 4<=n<=150 — см. `checks/check_C27.py --reflections 150`, файл
`data/runs/check_C27/reflections.json`.)

Что это даёт для `min_c [2F_c-S_c+R_c]`: без учёта `R_c` минимум по `k`
почти не зависит от чётности при `n` нечётном (нет выбора) и даёт
преимущество нечётному k при `n=0 mod4` (на 3 хода) или чётному k при
`n=2 mod4` (на 1 ход). Разница между чётностями `k` всюду O(1) — весь
порядок `n` в `2F-S` от `k` не зависит. Значит выбор `c` работает почти
целиком через `R_c` (маршрут), а не через `2F_c-S_c`, — важное отличие от
общего `pi`, где по H9-контрпримеру (C26) само `2F_c-S_c` может сильно
меняться с `c`.

## 4. Переносчики (carrier): точное правило (PROVED, из кода конструкции)

Для транспозиции `{a,b}` (`a<b` — так её видит `cycles_of`, поскольку
цикл инволюции всегда начинается с меньшего индекса), `choose_carrier`
(section 2.1 N1) даёт:

```text
carrier(a,b) = a   если b-a <= n/2
             = b   если b-a >  n/2
```

(Проверено разбором `local_word`/`choose_carrier`: направление шага
`a->b` положительно ровно при `b-a<=n/2` — совпадает с определением
`signed_step`, rule 16; тогда цикл "однонаправлен" или начало смены знака
приходится на `a`/`b` соответственно — включая антиподальный случай
`b-a=n/2`, где перенос всегда `a`.) Эквивалентно на языке пары `{x,y=k-x
mod n}`: перенос — это `x`, если `(k-2x) mod n < n/2` (или `=n/2` и
`x=min(x,y)`), иначе `y`.

## 5. Что ещё не сделано

`R_c` (маршрут только по переносчикам от 0 до c) зависит от `c=k-h`, а не
только от `k`: множество переносчиков зависит от `k` (правило §4), а
начало/конец маршрута — от `h` и `c` отдельно. Множество переносчиков НЕ
является дугой (проверено: например n=12,k=0 даёт переносчики {3,4,5,10,11}
— два кластера, не одна дуга), поэтому формула длины маршрута сложнее, чем
"длина дуги". Замкнутой формулы `R(k,c)` не выведено; это отдельная задача.
