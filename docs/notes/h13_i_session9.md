## 0. Задача

**H13-I**: для каждой pi из S_n существует пара (a, b) из Z_n x Z_n такая, что
линия `w_j = (pi((a+j) mod n) − b) mod n`, j = 0..n−1, имеет не более
`floor((n−1)^2/4)` инверсий. (Обозначения a = q+1, b = q+1−c согласованы
с `docs/notes/h13_line_model.md` §0; I(pi) = min по (a,b).) Верно при
4 <= n <= 10 (C33, исчерпывающе, независимым C-кодом `line_profile.c`).
Общего доказательства не было; предыдущая сессия дала три направления-кандидата

## 2. Переформулировка «квадрантов на торе» (PROVED, лемма)

Для pi из S_n и пары различных позиций i, i' обозначим `g = (i' − i) mod n`
(g из [1, n−1]) и `h = (pi(i') − pi(i)) mod n` (h из [1, n−1]).

**Лемма (счёт по дугам).** Число пар (a, b) из Z_n x Z_n, для которых цикличный
порядок позиций i, i', считанный от a, совпадает с цикличным порядком значений
pi(i), pi(i'), считанным от b («согласованная», она же «одноимённые квадранты»,
пара), равно

```text
K(g, h) = (n − g)(n − h) + g h.
```

Доказательство. Для фиксированной упорядоченной пары (i, i') ровно `n − g`
значений a дают «i раньше i'» при чтении окружности с точки a (дуга длины
n − g, заканчивающаяся в i), и ровно g значений a дают «i' раньше i» (дуга
(i, i'] длины g) — стандартный факт о циклическом порядке с точкой отсчёта.
Аналогично для value-дуг длины n − h и h с точкой отсчёта b. Пара согласована,
если оба порядка (позиционный от a, значенческий от b) совпадают: либо оба
«длинные» (n − g)(n − h) исходов, либо оба «короткие» g h исходов. ∎

Тогда `concordant(a, b) := C(n,2) − inv(w(a,b))` (число согласованных пар при
данном (a, b)) удовлетворяет `sum_{a,b} concordant(a,b) = sum_{i<i'} K(g,h)`;
через тождество `floor(n^2/4) + floor((n−1)^2/4) = n(n−1)/2 = C(n,2)` (C12)
H13-I эквивалентна **max_{a,b} concordant(a,b) >= floor(n^2/4)** — это и есть
формулировка «точка тора в одноимённых квадрантах хотя бы floor(n^2/4) пар» из
задания. Тождество проверено `check_reformulation()` перебором всех pi при
4 <= n <= 8 (`data/runs/h13_i_session9/report.md`, часть 1).

Усреднение `(1/n^2) sum_{a,b} concordant(a,b) = (1/n^2) sum K(g,h)` — это
ровно отвергнутое в сессии 8 усреднение по n^2 разрезам (h13_line_model.md
§6): недостаточно ни для sigma_n (среднее ниже floor(n^2/4)), ни для
контроля через дополнение у id. Переформулировка не отменяет этот факт,
только даёт ему чистую комбинаторную форму.

## 3. Три новых направления — все отклонены

### 3.1 Второй момент (неравенство Коши-Буняковского)

Идея: `max_{a,b} concordant(a,b) >= S2/S`, где `S = sum concordant(a,b)`,
`S2 = sum concordant(a,b)^2` по n^2 точкам (поскольку `max * S >= S2`). Эта
оценка использует дисперсию, а не только среднее, и в принципе может
превзойти чистое усреднение.

**Отклонено.** Уже на точных случаях равенства оценка не достигает цели: при
n = 4, pi = (0,3,2,1) (отражение) `max = 4 = floor(16/4)` (точно), но
`S2/S = 17/5 = 3.4 < 4`. То же для рефлексий n = 5..8: `S2/S` = 5.2, 7.4, 10.0,
13.0 против целей 6, 9, 12, 16 — отставание растёт с n. Второй момент даже
слабее чистого среднего на этом семействе. (`check_second_moment()`,
`data/runs/h13_i_session9/report.md` часть 2, все pi при 4 <= n <= 8.)

### 3.2 Совместная (не по одной оси) локальная оптимальность

Идея сессии 8 (лемма C, h13_line_model.md §4) проверяла только сдвиг разреза
позиций (a, b) -> (a+k, b+k) и сдвиг разреза значений (a,b) -> (a, b−k)
отдельно — это ровно две из бесконечно многих прямых на решётке (a,b), и их
композиция не даёт условия в промежуточных направлениях (отсюда и был
контрпример n=7). Задание прямо предлагает «совместные сдвиги обоих
разрезов»: проверена усиленная версия — назовём (a, b) *совместной
неподвижной точкой*, если b — глобальный минимум по всей строке a (перебор
по всем n значениям b, не только соседним), и одновременно a — глобальный
минимум по всему столбцу b. Это строго сильнее леммы C (учитывает вообще все
направления через две координатные развёртки, не только k-шаги по двум
диагоналям).

**Отклонено.** Глобальный минимум — всегда такая точка (тривиально), так что
существование неинтересно; вопрос — являются ли ВСЕ совместные неподвижные
точки хорошими. Нет: тот же n=7 контрпример h13_line_model.md §4,
pi = (0,5,4,3,2,1,6), имеет неподвижную точку (a,b) = (0,0) с inv = 10 >
floor(36/4) = 9, сосуществующую с хорошими неподвижными точками, например
(1,2) с inv = 8. Перебор 4 <= n <= 8 (`check_joint_fixed_points()`): плохие
неподвижные точки есть у 49 из 5040 перестановок при n = 7, но у 0 из 24, 120,
720, 40320 при n = 4, 5, 6, 8 — эффект не монотонен по n (та же чётностная
прихотливость, что и у C28/C31 по n mod 4, но здесь без объяснения).
Итог: даже сильная совместная локальная оптимальность не подразумевает
глобальный порог; нужна информация, различающая «плохую» неподвижную точку
от «хорошей», то есть фактически решение исходной задачи.

### 3.3 Избегание паттерна 321 / оценка Мантеля

`floor((n−1)^2/4)` — это в точности число Турана (Мантеля) — максимум рёбер
в графе без треугольников на n−1 вершинах. Гипотеза: граф инверсий
оптимальной линии (вершины — n позиций, рёбра — инвертированные пары)
всегда свободен от треугольников, то есть оптимальная линия избегает
паттерна 321 (треугольник графа инверсий <=> три позиции j<k<l с
w_j > w_k > w_l, то есть вхождение 321); тогда по Мантелю
`inv <= floor(n^2/4)` — уже само по себе слабее нужного на floor(n/2), но,
возможно, точная структура (объединение <= 2 возрастающих подпоследовательностей
без «полного» перекрёстка) даёт нужное floor((n−1)^2/4).

**Отклонено на первом же нетривиальном n.** При n = 5, pi = (0,1,4,3,2):
`I(pi) = 3`, но обе оптимальные линии, дающие этот минимум, содержат паттерн
321 (например разрез (0,0) даёт линию (0,1,4,3,2), тройка позиций 2,3,4 —
убывающая 4>3>2). При n = 6..8 доля перестановок, у которых НИ ОДИН
оптимальный разрез не свободен от 321, растёт: 150/720, 1785/5040,
24152/40320 (`check_321_avoidance()`, часть 4 отчёта). Оптимальные линии,
как правило, треугольники в графе инверсий содержат; идея неверна в общем
виде.

## 5. Литература

Поиск (WebSearch, сентябрь 2026) по «toric equivalence classes of
permutations», «necklace alignment maximize concordant pairs cyclic
permutation», «minimum inversions cyclic rotation domain codomain» не дал
прямого источника с этим утверждением или похожей техникой доказательства;
нашлось общее определение «toric equivalence» перестановок (её и используем)
и несвязанные результаты про cyclic sieving / cyclic descents. По-видимому,
конкретно эта форма (одновременный поворот и позиций, и значений, минимум
инверсий) не задокументирована в стандартной литературе под искомыми
терминами, либо использует другую терминологию, не найденную за отведённое
время.
