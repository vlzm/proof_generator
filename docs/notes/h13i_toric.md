# H13-I — торические классы: доказанные леммы, данные, вердикт

Дата: 15.09.2026 (сессия 9). Код: `experiments/toric_inv.c` (toric_inv-1.0),
`experiments/h13i_attempts.py` (h13i_attempts-1.0), `checks/check_H13I.py`
(check_H13I-1.0). Отчёты: `data/runs/h13i_toric/`, `data/runs/check_H13I/`.
Предыстория и определения — `docs/notes/h13_line_model.md`.

**Вердикт: H13-I не доказана.** Доказаны: случай равенства (отражения),
две эквивалентные переформулировки, инвариант «число витков» и три следствия
из него; проверка расширена с 4 <= n <= 10 до **4 <= n <= 13** исчерпывающе.
Отвергнуты четыре схемы доказательства (три — явными контрпримерами, одна —
прямым подсчётом). Рекомендация по следующему шагу — §5.

## 0. Утверждение и обозначения

Разрез `(a, b)` (в обозначениях `(q, c)` заметки h13_line_model:
`a = q + 1`, `b = q + 1 − c`) даёт линию

    w_j = pi(a + j) − b  (mod n),   j = 0..n−1,

и `I(pi) = min_{(a,b) in Z_n^2} inv(w)`. **H13-I:** `I(pi) <= floor((n−1)^2/4)`.

Точки тора: `p_i = (i, pi(i))`, i in Z_n. Пара точек *конкордантна* при
разрезе, если порядки по позициям и по значениям совпадают (не инверсия).
Число пар `C(n,2)`, поэтому H13-I равносильна «есть разрез с не менее
`floor(n^2/4)` конкордантными парами» (тождество
`floor(n^2/4) + floor((n−1)^2/4) = C(n,2)`).

## 1. Доказанные леммы

### Лемма 1 (рекуррентности сдвига)

    inv(a+1, b) = inv(a, b) + n − 1 − 2·((pi(a) − b) mod n),
    inv(a, b+1) = inv(a, b) + n − 1 − 2·((pi^{-1}(b) − a) mod n).

*Доказательство.* Сдвиг `a -> a+1` переносит первый элемент линии в конец.
Если его значение `v = (pi(a) − b) mod n`, то как первый он давал ровно `v`
инверсий (с элементами меньшего значения), а как последний даёт `n−1−v`
(с элементами большего значения); остальные пары не затронуты. Сдвиг
`b -> b+1` делает элемент со значением 0 наибольшим: стоя на позиции
`u = (pi^{-1}(b) − a) mod n`, как наименьший он давал `u` инверсий (с тем, что
левее), как наибольший даёт `n−1−u` (с тем, что правее). ∎

Следствие (вычислительное): все `n^2` разрезов считаются за `O(n^2)` после
одного `O(n log n)`; вместе с нормализацией `pi(0) = 0` (по одному
представителю на поворот значений) это и дало перебор до n = 13 (§3).

Следствие (лемма C заметки h13_line_model — частный случай при k = 1):
в точке минимума `v <= (n−1)/2` и `u <= (n−1)/2`.

### Лемма 2 (площади пар и среднее по всем разрезам)

Для пары точек `p = (x, y)`, `p' = (x', y')` положим `dx = (x − x') mod n`,
`dy = (y − y') mod n`. Тогда пара конкордантна ровно при
`dx·dy + (n−dx)(n−dy)` разрезах и инвертирована ровно при
`dx(n−dy) + (n−dx)dy` разрезах.

*Доказательство.* `p` стоит в линии раньше `p'` тогда и только тогда, когда
`a` не лежит в дуге `(x', x]` длины `dx`; аналогично для значений и `b`.
Условия на `a` и на `b` независимы, откуда обе площади. ∎

Следствие. Сумма конкордантных пар по всем `n^2` разрезам равна
`n · Σ_{δ=1}^{n−1} δ·W_δ`, где `W_δ = #{i : pi(i+δ) < pi(i)}` (сравнение целых
в `[0, n)`); при этом `Σ_δ W_δ = C(n,2)` для любой pi. Среднее число
конкордантных пар по разрезу равно `(1/n)Σ_δ δ·W_δ`; для отражений
`W_δ = n − δ` и среднее равно `(n^2 − 1)/6 < n^2/4`. Значит **усреднение
по всем разрезам не может доказать H13-I** — это точная форма препятствия,
отмеченного в §6 заметки h13_line_model.

### Лемма 3 (двойственность отражением позиций)

Пусть `pi^r(i) = pi(−i)`. Отображение разрезов `(a, b) -> ((1 − a) mod n, b)`
переводит линию pi в её обращение, поэтому
`inv_{pi^r}((1−a) mod n, b) = C(n,2) − inv_{pi}(a, b)` и

    I(pi) + M(pi^r) = C(n,2),   где M = max по всем n^2 разрезам.

Так как `pi -> pi^r` — биекция `S_n`, сохраняющая торические классы, а
`floor(n^2/4) + floor((n−1)^2/4) = C(n,2)`, получаем эквивалентную форму:

**H13-I′: у каждой перестановки есть разрез с не менее `floor(n^2/4)`
инверсиями.**

Случаи равенства меняются местами: в H13-I равенство на отражениях, в H13-I′ —
на поворотах (`pi(i) = i + s`: все линии — повороты тождественной с
`inv = k(n−k)`, максимум `floor(n^2/4)`). Форма H13-I′ удобнее тем, что её
экстремальный класс — повороты, устройство которых тривиально.

### Лемма 4 (число витков omega)

    omega(pi) = (1/n) Σ_{i in Z_n} ((pi(i+1) − pi(i)) mod n).

Тогда: (а) `omega` — целое, `1 <= omega <= n−1`, и оно инвариантно
относительно обоих поворотов, то есть является инвариантом торического класса;
(б) при **любом** значении разреза `b` число циклических спусков
(`(pi(i+1)−b) mod n < (pi(i)−b) mod n`) равно `omega`; поэтому линия при любом
разрезе имеет ровно `omega − 1` или `omega` спусков; (в) `omega = 1`
равносильно тому, что pi — поворот; `omega = n − 1` равносильно тому, что
pi — отражение.

*Доказательство.* Пусть `d_i = (pi(i+1) − pi(i)) mod n in [1, n−1]`. Сумма
`Σ d_i ≡ Σ (pi(i+1) − pi(i)) = 0 (mod n)`, значит omega целое; из
`1 <= d_i <= n−1` следует `1 <= omega <= n−1`. Поворот значений не меняет
разности, поворот позиций переставляет их циклически. Дуги `(pi(i), pi(i+1)]`
длины `d_i` склеиваются в замкнутый обход окружности `Z_n` суммарной длины
`n·omega`, поэтому каждая точка `b` покрыта ровно `omega` дугами; а `b`
покрыта дугой i тогда и только тогда, когда i — спуск относительно b. Наконец
`omega = 1` равносильно `d_i ≡ 1` (поворот), `omega = n−1` — `d_i ≡ n−1`
(отражение). ∎

### Лемма 5 (отражения: случай равенства H13-I доказан)

Для отражения `pi_h(i) = (h − i) mod n` и любого разреза линия равна
`w_j = (c − j) mod n`, где `c = (h − a − b) mod n`: два убывающих блока длин
`c+1` и `n−1−c`, причём все значения первого блока меньше всех значений
второго. Поэтому `inv = C(c+1, 2) + C(n−1−c, 2)` и

    I(pi_h) = min_{1 <= k <= n} [C(k,2) + C(n−k,2)] = floor((n−1)^2/4)

при всех n >= 4 и всех h. ∎

То есть H13-I верна с равенством на всех отражениях; вместе с §3 это
объясняет, почему любая схема доказательства обязана быть **точной** на
отражениях, — в частности, почему проваливаются все усреднения по семействам
разрезов, покрывающим значения `a + b` равномерно (на отражениях `inv`
зависит только от `a + b`, и среднее равно `C(n,2) − (n^2−1)/6 ≈ n^2/3`).

### Лемма 6 (разложение на возрастающие пробеги)

Если разрез `a` поставлен на циклическом спуске относительно b, то линия —
конкатенация ровно `omega` возрастающих пробегов длин `n_1, ..., n_omega`
(лемма 4б), а пары внутри пробега не инверсии, поэтому

    inv <= Σ_{L < L'} n_L·n_{L'} = (n^2 − Σ_L n_L^2)/2.

Следствия: `omega = 1 => I = 0`; `omega = 2 => I <= floor(n^2/4)`. Для больших
omega оценка бесполезна: на отражениях она даёт `C(n,2) − 1`.

### Лемма 7 (подъём: «перекрытые пары»)

Поднимем значения: `ỹ_{i+1} = ỹ_i + d_i`, так что `ỹ` строго возрастает и
`ỹ_{i+n} = ỹ_i + n·omega`. Для разреза `(a, b)` и пары `i < j` из окна
`[a, a+n)` инверсия равносильна тому, что полуинтервал `(ỹ_i, ỹ_j]` содержит
`⌈(ỹ_j − ỹ_i)/n⌉` точек решётки `b + nZ`, то есть строго больше, чем
`(ỹ_j − ỹ_i)/n`. Задача принимает вид: выбрать окно из n последовательных
точек и сдвиг решётки шага n так, чтобы «перекрытых» пар было мало. При
`omega = 2` это просто: `inv` — число пар, пересекающих границу блока, с
`ỹ_j − ỹ_i < n`.

## 2. Что отвергнуто в этой сессии (с контрпримерами)

Воспроизведение: `python3 experiments/h13i_attempts.py --nmax 8`
(`data/runs/h13i_toric/attempts.json`).

1. **Индукция удалением k элементов.** Схеме нужно: у каждой pi есть
   k-элементная редукция торического класса (удалить k точек, стянуть позиции
   и значения) с `I(pi) <= I(pi'') + (target(n) − target(n−k))`. Бюджет равен
   `floor((n−1)/2)` при k = 1 и ровно `n − 2` при k = 2. При n <= 7 обе формы
   верны; при n = 8 обе ложны: k = 1 — 16 перестановок (первая
   `(0,3,6,1,4,7,2,5)`: I = 9, лучшая редукция 5 при нужных 6), k = 2 — 8
   перестановок (один торический класс; `(0,5,2,7,4,1,6,3)`: I = 11, лучшая
   двухэлементная редукция 4 при нужных 5). Аффинные входы «хрупки»: удаление
   любых точек разрушает торическую структуру и обрушивает I. Направление
   «индукция по n удалением» закрыто (k = 1 было известно из сессии 8).
2. **Усреднение по привязанным семействам.** `F_{α,β} = {(i+α, pi(i)+β) : i}` —
   семейство из n разрезов, привязанных к точкам самой pi; оно **постоянно**
   на обоих экстремальных классах (на отражениях `a + b` постоянна вдоль
   семейства, на поворотах — `a − b`), то есть остаётся точным там, где
   утверждение тесно. Тем не менее `max_pi min_{α,β} (среднее по семейству)`
   равно `21/5 > 4` при n = 5 (`pi = (0,1,4,3,2)`) и `67/7 > 9` при n = 7
   (`pi = (0,2,1,6,5,4,3)`); при n = 4, 6 равно ровно target. Обобщение
   `F_{α,β,γ} = {(i+α, pi(i+γ)+β)}` (n^3 семейств, тоже постоянных на
   экстремальных классах) даёт те же значения. Частный случай γ = 0, α = 0 —
   отвергнутое в сессии 8 семейство «первый элемент линии равен t».
3. **Моментный метод.** В форме H13-I′ неравенство `max F >= ΣF^2/ΣF` для
   тождественной перестановки (`F(a,b) = k(n−k)`, `k = (a − b) mod n`) даёт
   `n^2/5 + O(n) < n^2/4` (численно 0.2020·n^2, 0.2001·n^2, 0.2000·n^2 при
   n = 10, 50, 200); третий момент — `3n^2/14 ≈ 0.2143·n^2`; m-й момент даёт
   `(n^2/4)·2(m+1)/(2m+3) + O(n)`, то есть для точной константы нужно
   `m ~ n^2`.
   Никакой фиксированный момент (и, тем более, дисперсионная оценка) константу
   `1/4` не даёт: ландшафт `F` гладкий, максимум достигается на ~n разрезах
   из n^2.
4. **Компрессия по omega.** Идея: ход, повышающий omega и не понижающий I,
   дал бы индукцию по omega с базой `omega = n−1` (отражения, лемма 5).
   Для ходов «обмен значений в циклически соседних позициях» и «обмен позиций
   циклически соседних значений» это ложно: при n = 5, 6, 7 таких ходов нет
   у 35, 138, 1008 перестановок (первая при n = 5 — `(0,2,1,4,3)`:
   `omega = 3`, `I = 2`).

## 5. Вердикт и следующий шаг

H13-I остаётся CONJECTURED: VERIFIED при 4 <= n <= 13 (было 10), доказана в
случае равенства (отражения, лемма 5) и при `omega in {1, 2}` (лемма 6, причём
при omega = 2 — с более слабой константой `floor(n^2/4)`).

Почему это трудно: утверждение точно (равенство ровно на n отражениях из n!
перестановок), а ландшафт `inv(a, b)` на торе разрезов гладкий — минимум
достигается примерно на n разрезах из n^2. Поэтому проваливаются все схемы
«усреднить по семейству» (§2.2, §2.3) — линейный функционал по разрезам обязан
быть сосредоточен ровно на оптимальном множестве отражений, а такие
естественные семейства (привязанные) уже перебраны. Индукция по n удалением
точек (§2.1) ломается на аффинных входах, индукция по omega (§2.4) — на ходах,
меняющих I скачком.

Наиболее перспективная точка входа, если к H13-I возвращаться, —
**двойственная форма H13-I′** (лемма 3): «у каждой pi есть разрез с не менее
`floor(n^2/4)` инверсиями». Её экстремальный класс — повороты, а не отражения,
и конструкция разреза там очевидна (`a − b = floor(n/2)`), так что искать надо
явное правило выбора разреза, обобщающее «антиподальный сдвиг» поворота;
леммы 1 и 7 дают для этого точный аппарат (градиент `inv` на торе разрезов
выписан явно; условие инверсии — «перекрытая пара» относительно решётки шага
n). Отдельный ориентир: экстремальная конфигурация для H13-I′ — единственная
с `omega = 1`, а лемма 6 закрывает `omega <= 2`; значит содержательная часть —
средние omega.

Пре-регистрированный запасной путь проекта (PLAN §4.3, п. 3) — индукция H3;
на неё и переходим (бюджет 2 сессии до вердикта). H13-I при этом не
закрывается: она остаётся необходимой половиной H13′ (вместе с H13-R даёт C15
по C12), и возврат к ней разумен только с новой идеей уровня §5.

## 6. Литература (статус аудита: НЕ проверено)

Поиск дал близкую по числам тему — «circular sorting» / сортировка
циклически соседними транспозициями: диаметр, по аннотациям, равен
`floor(n^2/4)` (Adin, Alon, Roichman, «Circular Sorting», arXiv:2502.14398;
и «A tight upper bound on the number of cyclically adjacent transpositions to
sort a permutation», Inform. Process. Lett., 2016, по гипотезе Feng и др. при
постановке Jerrum). **Тексты из этой среды недоступны** (egress-политика
блокирует arxiv.org и web.math.princeton.edu), поэтому формулировки известны
только по сниппетам поисковой выдачи, аудит не выполнен и **ни одно
утверждение выше на них не опирается**. Связь с нашей задачей не установлена
и не очевидна: у нас повороты позиций и значений бесплатны, но обмены через
разрез запрещены, а там — наоборот. Если к H13-I возвращаться, эти тексты
стоит получить и проаудировать: совпадение констант `floor(n^2/4)`
(H13-I′ и H13-R) может оказаться содержательным.
