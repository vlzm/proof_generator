# H12 — вердикт по единой политике головы (сессия 6)

Дата: 13-14.09.2026. Задача PLAN.md, строка H12 / §3 (после `docs/notes/geodesic_structure.md`
§5), бюджет 2 сессии до письменного вердикта (сессия 5 — построение направления
и кандидата «развёртка»; эта сессия — вторая и последняя в бюджете).

## 1. Вопрос

Сессия 5 показала, что портфель `min(N1_R, sweep-1.1)` даёт `<= B_n` на всех
проверенных входах, но это ДВЕ отдельные конструкции с правилом выбора между
ними. Шаг 1 H12 — найти ОДНУ политику движения головы (без портфеля), которая
воспроизводит короткие колебания N1 на отражениях/sigma_n и длинные проходы
sweep на аффинных входах.

## 2. Что было испробовано

`constructions/candidate_frontier.py` (frontier-1.1), два кандидата из
PLAN.md §3(a)(«лукахед» по стоимости дороги + выигрыш):

1. **`frontier_word` / mode "farthest"**: направление — по тому, с какой
   стороны БЛИЖЕ дальний конец текущего диапазона продуктивных рёбер (правило,
   оптимальное для статической задачи, которую решает `carrier_route` N1).
   Результат: эмпирически совпадает буквально (слово в слово) с `sweep-1.1`
   nearest на всех проверенных случаях (> 3000 случайных перестановок n = 6..14,
   все sigma_n/отражения/аффинные контрпримеры к H10 до n = 54). Множество
   продуктивных рёбер по одну сторону головы почти всегда — один непрерывный
   отрезок, так что его ближний и дальний конец совпадают по стороне; лукахед
   не добавляет информации. Не используется дальше (сохранён для отчёта, как
   и предупреждала PLAN.md: «не повторять... плато как у nearest»).

2. **`weighted_word` / mode "weighted"** (рабочий вариант): вместо сравнения
   расстояний сравнивается `score = gain - tw*distance` в ближайшем продуктивном
   ребре с каждой стороны (tw = 1.0), голова идёт в сторону большего score;
   ничья — по `tie_pref`, первый шаг — по `init_dir` (оба входят в перебор
   `best_weighted` вместе со сдвигом c и порогом thr наравне, а не фиксированы).
   Один дополнительный бит информации — двойной обмен (gain 2) стоит одного
   лишнего шага мимо одинарного (gain 1) — воспроизводит короткие колебания N1
   на отражениях (ближний одинарный обмен перестаёт быть автоматически
   предпочтительным, когда на шаг дальше виден двойной) и сохраняет длинные
   проходы на аффинных входах (там рядом обычно только одинарный обмен, а
   двойной — дальше в том же направлении, и score продолжает толкать голову
   вперёд, а не разворачивает).

## 3. Результат (`experiments/frontier_eval.py`, отчёт `data/runs/frontier_eval/report.md`)

`best_weighted(pi) - B_n <= 0` без единого исключения:

- исчерпывающе по ВСЕМ перестановкам при 4 <= n <= 9 (362 880 входов при n = 9);
  максимум `len - B_n` равен 0 (единственный вход на каждое n; сверено с
  таблицами `dist_n{4..12}.bin`, `len - d` растёт до +7 — конструкция не
  геодезическая, что и не требуется);
- на отражениях (все h при n <= 40, представительная выборка h при n = 41..60)
  и sigma_n — ровно B_n (как у N1/C28/C9), не больше;
- на rev_n — `B_n - 2` при всех n = 4..60;
- на аффинных `pi(i) = a*i+b` (полное покрытие a, b при n <= 20; частичное при
  n > 20, см. `report.md`) — строго меньше B_n с растущим запасом (n = 60:
  `B_n - 182` в худшем случае);
- на поворотах sigma_n и случайных выборках (30 на n) — с запасом.

**Критерий H12(1) выполнен на всём проверенном диапазоне: единая политика без
портфеля, `<= B_n` на всех pi при 4 <= n <= 9 и на отражениях/аффинных при
n <= 60.** Статус — CONJECTURED (H12(а)), не PROVED: конечная проверка не
доказывает общий случай (правило 5 AGENTS.md); CLAIMS.md — новая строка.

Это сильнее результата сессии 5: `sweep-1.1` одна (без портфеля) давала
превышение +1/+2 на sigma_9 и двух отражениях при n = 9; `weighted` этого
превышения не имеет нигде в проверенном диапазоне.

## 4. Что осталось (H12, шаг 2 — задача следующей сессии)

Формула длины для доказательства, а не только конечная проверка:

1. Точный подсчёт `N_X = F_c/2 + single + 2*bad` (тождество из
   `docs/notes/geodesic_structure.md` §2) для `weighted` на отражениях —
   почему `single` и `bad` дают в сумме то же, что у N1 (там доказано в C28), и
   на аффинных входах — почему `single + 2*bad` не хуже, чем при
   независимой обработке циклов (тут N1 теряет, H11).
2. Подсчёт числа разворотов головы (`reversals` уже считается в
   `weighted_word`, не используется пока в оценке) как функции n (h для
   отражений; a, b для аффинных) — нужна явная формула, не только измерение.
3. При успехе (1)-(2) — это даёт доказательство `d(pi) <= B_n` для отражений
   и для семейства аффинных входов отдельно (не то же самое, что общее pi;
   нужно решить, доказывается ли общий случай через ту же схему или остаётся
   гипотезой, подтверждённой на структурированных семействах, аналогично C29).
4. Не повторять: mode "farthest"/лукахед по дальнему концу диапазона — не
   даёт новой информации (§2 выше).
