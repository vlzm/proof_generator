## 1. Политика

Тот же язык, что у развёртки (`docs/notes/geodesic_structure.md` §2): сдвиг c,
цели `e + c`, знаковый остаток `rem` по кратчайшей дуге, `gain` обмена,
порог thr. Отличие — выбор направления головы. В каждой точке решения
(на непродуктивном ребре или после обмена) строится дерево глубины H:
ветвь — «идти в направлении dd до ближайшего ребра с `gain >= thr`
(в том числе текущего, k = 0), обменять, продолжить»; лист после H обменов
или при `Phi = 0` оценивается как

```text
f = (вращения + обмены на ветви) + w · Phi_листа,
```

исполняется первый шаг лучшей ветви; при равенстве сохраняется направление.
`Phi/2` — нижняя оценка оставшихся обменов, поэтому w = 0.5 — «допустимая»
эвристика; w = 1 дополнительно платит по вращению за оставшийся обмен.
H = 1, w = 0 — режим nearest сессии 5. Итоговое слово — минимум по c, dir,
thr в {1, 2} (4n слов на вход, каждое исполнено эталоном).

**Тупик и фолбэк (sweep-1.3).** При фиксированном c цикл, все элементы
которого идут по кратчайшим дугам в одну сторону (n = 7,
`pi = (0,1,3,6,4,5,2)`, c = 0, цикл (2 3 6) с шагами +1, +3, +3), не имеет
ребра с `gain >= 1`: политика останавливается (`ConstructionError`), и
`best_sweep` спасается другим сдвигом. Таких пар (pi, c) больше половины:
2508 / 4320 при n = 6, 18 368 / 35 280 при n = 7, 197 608 / 322 560 при n = 8
(при n = 8 у каждой pi есть тупиковый c). Обмен с `gain = 0` как выход не
годится — политика зацикливается (XX на одном ребре или уходит в состояние
«все на +1»). Работает аналог переносчика N1: при тупике элемент с наибольшим
|rem| получает постоянный флаг «идти по длинной дуге» (направление
фиксируется, дополнительная дистанция `n − 2|rem|`), и поиск продолжается
с изменённым rem. С фолбэком тупиков нет (0 / 35 280 при n = 7), минимум по c
не меняется на проверенных n (см. §3), но фиксированный «плохой» c даёт
до B_n + 19 при n = 6, 7: выбор c остаётся существенной частью конструкции.

## 2. Отражения: расщепление геодезических при всех h

Для всех отражений `pi_h(i) = h − i` при 6 <= n <= 20 и H = 3, w = 0.5:

- `N_X = floor((n − 1)^2 / 4)` при **всех** h — ровно расщепление
  геодезических sigma_n (C14v); у развёртки sweep-1.1 тот же N_X, у N1_R —
  тот же на sigma_n (C28);
- длина = `B_n − delta_n(h, 1) + eps(n, h)`, где eps = 0 при
  `delta(h, 1) <= ~n/4` и eps = 2, 4, 6, 8 ступенями к антиподу h ≈ n/2 + 1
  (n = 20: eps = 0…8 при h = 9…15, всюду длина `<= B_n − 2`);
  на sigma_n (h = 1) длина ровно B_n, `N_rot = floor(n^2/4)`;
- при 6 <= n <= 10 по таблицам `d(pi_h) = B_n − delta_n(h, 1)` для всех h
  (наблюдение; в реестре не было), политика даёт d ровно, кроме
  h с eps = 2 (n = 10: только h = 6).

Развёртка nearest на sigma_n теряла ≈ 0.8n вращений (+2, +4, +12, +32 при
n = 9, 10, 20, 40); горизонт H >= 2 с w = 1 убирает потерю целиком при
n <= 20; w = 1 оставляет +1 на отдельных отражениях при n = 2 mod 4
(n = 10: h = 6; n = 14: h = 8), w = 0.5 — нет.

## 5. Вывод

1. **Шаг (1) H12 выполнен**: единая политика головы существует — выбор
   направления по дереву глубины 3 с оценкой «дорога + обмены + Phi/2».
   Она воспроизводит колебания N1 на отражениях (N_X = floor((n − 1)^2/4),
   на sigma_n ровно B_n) и два прохода на аффинных входах (n = 10: ровно d),
   и даёт `<= B_n` всюду, где проверено (C30). Портфель с N1_R больше не нужен.
2. Что политика **не** делает: не решает тупики фиксированного c без
   фолбэка-переносчика; при плохом c длина далеко за B_n. Значит, любое
   доказательство `<= B_n` для неё — это (а) выбор c (как в N1: c с минимальным
   F_c или из {0, 1} на отражениях) и (б) формула длины при этом c.
3. Следующая задача (вторая сессия бюджета H12): шаг (2) — формула длины на
   отражениях при c из {0, 1}: доказать `N_X = floor((n − 1)^2/4)` (тождество
   `N_X = F_c/2 + single`, число одинарных обменов) и `N_rot <= floor(n^2/4)`,
   т. е. прямое доказательство `<= B_n` на отражениях политикой без N1;
   затем — аффинные входы (`N_X = F_c/2 + 2` при двух проходах) и общий
   случай через выбор c. Если формула на отражениях не получается за
   сессию — вердикт: H12(б) подтверждена численно, доказательство длины
   политики с горизонтом — не путь к C15, переход к H3 (§4.3).
4. Побочное наблюдение для реестра: `d(pi_h) = B_n − delta_n(h, 1)` для всех
   отражений при 6 <= n <= 10 (по таблицам); при n <= 5 не проверялось.
   Формула объясняет «+1» C28 (маршрут по переносчикам не точен около
   антипода) и даёт цель для нижней оценки.
5. Не повторять: полный перебор c при n >= 24 на семействах с 30 случайными
   входами (часы); сравнение с N1_R на всех pi (не нужно — политика одна).
