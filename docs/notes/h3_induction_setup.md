# H3 — постановка индукции: что именно надо определить (заготовка)

Дата: 14.09.2026 (сессия 9). Это **не результат**, а точная постановка
запасного направления из PLAN §4.3 п. 3 и §8, записанная на будущее, чтобы
следующая сессия не начинала с нуля. Ничего не проверено численно.

## 1. Что утверждает H3

PLAN §0, строка H3: переход от `sigma_{n−1}` к `sigma_n` стоит
`floor((n−1)/2)` обменов и `floor(n/2)` шагов головы, рекуррента
`T_n <= T_{n−1} + (n−1)` при `T_4 <= 6` даёт ровно `B_n`; **запас нулевой**
(`n − 1 = floor(n/2) + floor((n−1)/2)`, согласуется с H1). Цель индукции —
не sigma_n, а C15 (`d(pi) <= B_n` для всех pi), поэтому индукционное
предположение должно быть по всем pi, а не только по sigma.

## 2. Препятствие, которое нельзя обойти молча

Ходы L и R вращают **всю** окружность относительно головы (PROBLEM §2:
положение головы — часть состояния, массив читается от головы). Поэтому
нельзя «заморозить» один элемент и работать с остальными n−1 как с меньшей
задачей: любой шаг головы меняет положение замороженного элемента в массиве.
Индукция обязана определить:

1. **Вложение** `iota: S_{n−1} x (позиции головы) -> S_n x (позиции головы)`
   — какое состояние меньшей задачи какому состоянию большей соответствует.
2. **Имитацию ходов**: слово `u` для меньшей задачи -> слово `Phi(u)` для
   большей, с `apply_word(iota(p), Phi(u)) = iota(apply_word(p, u))`.
3. **Стоимость имитации**: `|Phi(u)| − |u|` как функция от `u` (а не только
   от длины), и отдельно `N_X` и `N_rot` (правило 8).
4. **Восстановление ориентации**: где голова обязана оказаться в конце
   `Phi(u)` и сколько стоит привести её туда (у `d` это часть определения,
   PROBLEM §2).

## 3. Три кандидата вложения (ни один не проверен)

(A) **«Элемент n−1 у головы».** `iota(p)` — та же окружность с вставленным
новым элементом в фиксированную позицию рядом с головой. Имитация: каждый ход
меньшей задачи копируется, но всякий раз, когда голова проходит вставленную
позицию, нужен лишний шаг. Стоимость — число проходов головы через одну
фиксированную точку окружности, то есть `~N_rot(u)/n`. Это даёт
`|Phi(u)| <= |u| + N_rot(u)/n + O(1)` — слишком дорого при `N_rot ~ n^2/4`
(добавка `~n/4`, а запас рекурренты нулевой). Вариант годится только если
удастся выбрать позицию вставки так, чтобы голова проходила через неё
`O(1)` раз (у оптимальных слов для sigma_n голова обходит окружность
`~n/2` раз — см. C13v, `N_rot = floor(n^2/4)`).

(B) **«Дуга вместо элемента».** Меньшая задача живёт не на n−1 позициях,
а на дуге; вложение — склейка двух соседних позиций окружности в одну.
Тогда ходы L/R переносятся без потерь, а X на склеенной паре имитируется
словом длины 3 (`XLX`-подобным). Нужно: описать, какие перестановки Z_n
являются образами, и стоимость приведения произвольной pi к образу.
Это ближе к структуре C32 (две линейные инверсии дуг), где окружность уже
разбита на две дуги.

(C) **«Снятие пары антиподов».** Убирать не один элемент, а пару
`i, i + floor(n/2)`, переходя от n к n−2, с рекуррентой
`T_n <= T_{n−2} + (2n−3)`; `B_n − B_{n−2} = 2n−3`, запас снова нулевой, но
шаг согласован с симметрией `sigma_n` и с автоморфизмом
`p -> sigma_n o p o sigma_n` (PROBLEM §4.3).

## 4. Что считать успехом и что — провалом

Запас рекурренты ноль, поэтому **любая** потеря в имитации убивает индукцию:
нужна не оценка `|Phi(u)| <= |u| + (n−1) + O(1)`, а точное `<= |u| + (n−1)`
при `T_4 = 6`. Реалистичная промежуточная цель — доказать индукцию для
какого-то класса pi (например, для образов вложения) и измерить потерю
на остальных. Первый эксперимент: по таблицам `4 <= n <= 10` для каждого
кандидата вложения посчитать `d(iota(p)) − d(p)` по всем p из `S_{n−1}`
и проверить, не превышает ли максимум `n − 1`. Это дёшево (таблицы уже есть,
C2v) и сразу отсекает негодные вложения.

## 5. Связь с линейной моделью

C37 (`docs/proofs/C37_inversion_spearman.md`) даёт для любой pi и любого
разреза точное `N_X`-содержание линии; лемма A (C34) — маршрут с
`N_rot = B_n − 1`. Если индукция H3 будет строиться на словах линейной
модели, инвариантом естественно брать не `d(pi)`, а пару
`(I(pi), бюджет вращений)`, и тогда шаг индукции должен добавлять ровно
`floor((n−1)/2)` к `I` и `floor(n/2)` к `N_rot` — это и есть разбиение
`n − 1 = floor(n/2) + floor((n−1)/2)` из строки H3.
