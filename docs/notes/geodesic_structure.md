Ядро oracle-1.0, конструкция strict_upper-1.0 (вариант с маршрутом по
переносчикам, ниже «N1_R»), таблицы C2v при n <= 10. Скрипты:

## 1. Вопрос

На аффинных входах `pi(i) = a·i + b` слова N1_R длиннее B_n даже после
сокращения (C27, H11), причём локальные слова там оптимальны и маршрут
короток: потеря — в независимой обработке циклов. Что делают вместо этого
кратчайшие слова?

## 2. Язык: сдвиг слова, полезность обмена, оценка спаривания

Для слова w, сортирующего pi (голова стартует в позиции 0 окружности),
сдвиг `c(w) = (#L − #R) mod n` — конечное положение головы; элемент e
заканчивает в позиции `e + c`. Так каждая геодезическая получает свой c и
свои циклы f_c. Обмен X на ребре {h, h+1} двигает элемент из h на +1, из h+1
на −1; ход полезен элементу, если уменьшает его расстояние до цели.
Обмен двойной / одинарный / вредный по числу полезных ходов; потенциал
`Phi = sum |rem|` меняется на −2 / 0 / +2, откуда тождество

```text
N_X = F_c/2 + single + 2·bad          (F_c = Phi в начале).
```

Двойной обмен «cross», если его элементы стартуют в разных циклах f_c.
Оценка спаривания: p_v, m_v — число кратчайших дуг через ребро v в + и −
направлении; `LBX(c) = sum_v max(p_v, m_v)` — нижняя оценка N_X для слов со
сдвигом c, элементы которых идут по кратчайшим дугам.

## 3. Что делают геодезические (n = 8, 9, 10; `report_n{8,9,10}.md`)

Аффинные входы n = 10, (a, b) = (7, 2) и (3, 4): d = 34, B_n = 45, N1_R при
лучшем c — 46. По ДАГу — 14 геодезических каждая, все со сдвигом c = 0 (сдвиг с
K = 2 циклами и минимальным F = 24; сдвиги с K = 3 имеют F = 26 и не
используются). Их строение:

| величина | геодезические (все 14) | N1_R при том же c = 0 | N1_R при лучшем c = 2 |
|---|---|---|---|
| N_X | 14 = F/2 + 2 | 18 = F/2 + 6 | 18 |
| двойных обменов, из них cross | 12, из них 6 | 12, из них 6 | 12, из них 6 |
| одинарных | 2 | 6 | 6 |
| LBX | 12 | 12 | 12 |
| N_rot | 20 = 2(n − 1) + 2 | 30 | 28 |
| длина | 34 | 48 | 46 |

Трасса геодезической `XLLXLXLLXLLXLXLXRRXRXRRXLXRRRXRXRX`: голова делает
**один проход вперёд** (позиции 0 → 9) и **один проход назад** (9 → 0), на
каждом шаге меняя элемент, идущий вперёд, с элементом, идущим назад,
независимо от их циклов; фиксированные точки временно сдвигаются на 1 и
возвращаются двойным обменом. N1_R делает по два прохода на каждый цикл
(`XLLXLXLXLXRXRRXRXRXRRRRR…`) и платит маршрут между переносчиками: та же
пара (F/2 + 6 одинарных обменов) и +8–10 вращений.

Вход-контрпример ко второй части H10 `(9,2,5,0,1,8,7,6,3,4)` (d = 36): 20
геодезических, сдвиги 5 и 7 (K = 3, F = 24), N_X = 15 = F/2 + 3, N_rot = 21;
N1_R — 46 при N_X = 17–19.

Отражения (sigma_n, h = 2): геодезические имеют N_X = F/2 + floor(n/2) − 1
(n = 9: 16 = 10 + 6 при LBX = 10) — оценка спаривания на отражениях **не
точна**, одинарные обмены неизбежны; N1_R здесь совпадает с геодезическими
(sigma_9: 36, sigma_10: 45), и его слова — короткие колебания головы
(`XRXRRXRRXR…`), а не два длинных прохода.

Вывод: у N1 на аффинных входах теряются (а) 4 обмена — cross-спаривание
там уже есть случайно, но одинарных обменов вдвое больше, и (б) 8–10
вращений маршрута между циклами. Кратчайшие слова обрабатывают все циклы
за два прохода головы.

## 4. Кандидат «развёртка» (`constructions/candidate_sweep.py`, sweep-1.1)

Для pi, сдвига c, направления dir и порога thr:

- **проход** (mode `pass`): голова идёт в направлении dir; на ребре под
  головой с элементами x (сзади), y (спереди) обмен делается, если
  `gain = [rem x > 0] + [rem y < 0] − [rem x < 0] − [rem y > 0] >= thr`
  (thr = 1 разрешает одинарные обмены с «безразличным» соседом, thr = 2 —
  только двойные); проход заканчивается, когда впереди в пределах n − 1
  шагов нет смещённых элементов; проходы чередуют направление до `Phi = 0`,
  затем голова идёт к c по короткой дуге;
- **ближайший продуктивный** (mode `nearest`): после каждого обмена (или на
  непродуктивном ребре) голова идёт к ближайшему ребру, где обмен с
  `gain >= thr` возможен в текущей конфигурации; при равенстве сохраняет
  направление.

`best_sweep(pi)` — минимум длины по c, dir, thr, mode (4n·2·2 слов). Каждое
слово исполнено эталонными ходами. Таблиц кандидат не читает.

## 5. Вывод и выбранное направление

1. Совместная обработка циклов — это **проходы головы через все циклы
   сразу**; в терминах обменов геодезические аффинных входов почти достигают
   оценки спаривания (N_X = LBX + 2), а N1 теряет вдвое больше одинарных
   обменов и маршрут. Кандидат «развёртка» воспроизводит это: на всех
   аффинных контрпримерах к H10 он короче B_n с запасом, растущим с n
   (n = 54: B_n − 168).
2. Развёртка проигрывает N1 там, где N1 точен, — на отражениях; проигрыш
   целиком во вращениях (N_X оптимален), т. е. в политике движения головы,
   а не в выборе обменов. Портфель `min(N1_R, развёртка)` — `<= B_n` на всех pi при 4 <= n <= 9 и на всех семействах до n = 40 (H12(а), C29).
3. Направление §4.2 на следующие сессии — **H12** (PLAN §3): единая
   политика головы, которая на отражениях даёт короткие колебания N1, а на
   аффинных входах — два длинных прохода; кандидаты: (а) выбор ребра для
   следующего обмена по «стоимости дороги + выигрыш» с горизонтом больше
   одного ребра; (б) DP по траектории головы при фиксированном мультимножестве
   обменов развёртки; (в) гибрид: N1-обработка транспозиций и развёртка для
   остального. Критерий: `<= B_n` на всех pi при 4 <= n <= 9, на sigma_n и
   отражениях при n <= 60, на аффинных при n <= 60; затем — формула длины
   для доказательства (тождество `N_X = F_c/2 + single + 2·bad` и оценка
   числа одинарных обменов — первая цель).
4. Не повторять: полные проходы на отражениях (квадратичная потеря,
   `report.log` первого прогона sweep-1.0: +137 при n = 26).
