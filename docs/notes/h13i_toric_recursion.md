# H13-I, сессия 9 — декаплированный разрез (s, t): инструмент и вердикт

Дата: 14.09.2026. Ядро oracle-1.0, таблицы C2v (4 <= n <= 12). Код:
`experiments/h13i_toric.py` (h13i_toric-1.0, независимая от `line_profile.c`
реализация). Отчёт: `data/runs/h13i_toric/`.

Задача (PLAN §8, `docs/notes/h13_line_model.md` §6): доказать H13-I —
`I(pi) = min_{q,c} inv(w) <= floor((n-1)^2/4)` для всех pi, всех n >= 4,
где `(q,c)` — двойной разрез PROBLEM §5.6.

## 0. Перепараметризация (q, c) -> (s, t)

Тот же набор из n^2 разрезов удобнее в виде пары независимых сдвигов:

```text
W(pi, n, s, t)[j] = (pi[(s + j) mod n] - t) mod n,   j = 0..n-1
s = q + 1,  t = q + 1 - c                              (биекция на Z_n x Z_n)
```

`s` — чисто доменный сдвиг (какой элемент читается первым, значения не
трогает); `t` — чисто значенческий сдвиг (какая метка становится нулём,
порядок чтения не трогает). В исходной паре (q, c) оба действия смешаны
(смена q при фиксированном c одновременно меняет и то, и другое).

## 1. Точная рекуррента по одному шагу (PROVED, проверено 500 случайных
   троек (pi, s, t) при 4 <= n <= 9, `check_recursion` в коде)

```text
inv(W_{s+1,t}) - inv(W_{s,t}) = (n-1) - 2*v0(s,t),   v0(s,t) = W(pi,n,s,t)[0] = (pi[s]-t) mod n
inv(W_{s,t+1}) - inv(W_{s,t}) = (n-1) - 2*p0(s,t),   p0(s,t) = (pi^{-1}[t]-s) mod n
```

Доказательство. `s -> s+1` при фиксированном t — это ровно перенос переднего
элемента (значение `v0`, без изменения) в конец списка, без изменения
остальных значений (проверяется прямой подстановкой в определение W).
Элемент `v0` меняет роль в паре с каждым из n-1 остальных: раньше он был
первым и давал инверсию с `v0` элементами меньше себя (их ровно `v0`, так
как значения — в точности {0,...,n-1} без него); теперь он последний и даёт
инверсию с `n-1-v0` элементами больше себя. Остальные C(n-1,2) пар не
меняются. `Delta = (n-1-v0) - v0`. Симметрично для `t -> t+1`: это декремент
всех значений по модулю n; единственный элемент со значением 0 (позиция
`p0`) заворачивается в n-1, остальные просто уменьшаются на 1 (относительный
порядок между ними не меняется). ∎

Это уточнение «леммы C» из `h13_line_model.md` §4: там прежняя рекуррента
была получена в смешанных (q, c)-координатах и давала только необходимое
условие для суммы по префиксу k шагов; здесь та же формула в разделённых
координатах — точное равенство на каждом единичном шаге, с прямой (не
рекурсивной) формулой для `v0` и `p0` через pi и pi^{-1}.

## 2. C37 (PROVED): `I(pi) = I(pi^{-1})` для всех pi, всех n

Как перестановка (последовательность) длины n, W(pi,n,s,t) как функция
`j -> W[j]` имеет функциональную обратную `v -> (pi^{-1}(t+v) - s) mod n =
W(pi^{-1}, n, t, s)[v]` (прямая подстановка). Число инверсий перестановки
равно числу инверсий обратной к ней (классический факт: обе считают одно и
то же множество пар {a,b} с "неправильным" относительным порядком).
Следовательно `inv_pi(s,t) = inv_{pi^{-1}}(t,s)` для всех (s,t), и минимум
по всем n^2 парам совпадает: `I(pi) = I(pi^{-1})`. Проверено исчерпывающе
4 <= n <= 8 (`experiments/h13i_toric.py`).

Практическое следствие: чекеры и поиск контрпримеров могут проверять только
один представитель из пары {pi, pi^{-1}} (сокращение перебора вдвое для
не-инволюций); для крайнего случая (отражения) pi = pi^{-1}, так что это не
уменьшает сложность самого трудного случая.

## 3. Одной степени свободы недостаточно (проверено исчерпывающе 4<=n<=9)

Если зафиксировать доменный порядок (s = 0, читать pi как дано) и искать
минимум только по значенческому сдвигу t, то максимум по pi этого
ограниченного минимума ПРЕВОСХОДИТ floor((n-1)^2/4) уже при n = 7:

| n | floor((n-1)^2/4) | max по pi min_t inv (s=0 фикс.) | превышение |
|---|---|---|---|
| 4 | 2 | 2 | нет |
| 5 | 4 | 4 | нет |
| 6 | 6 | 6 | нет |
| 7 | 9 | 10 | да, на (0,5,4,3,2,1,6) |
| 8 | 12 | 13 | да, на (0,6,5,3,4,2,1,7) |
| 9 | 16 | 17 | да, на (0,2,7,6,5,4,3,8,1) |

(Пример n=7 — тот же вход, что и контрпример «леммы C» в
`h13_line_model.md` §4; там указано, что его I(pi) = 8 при «несоседнем
разрезе» — здесь подтверждено полным перебором: истинный `I = 8 < 9`,
достигается только при доменном сдвиге s != 0.)

Вывод: обе степени свободы (s и t) необходимы в общем случае; направление
«достаточно вращать только значения» закрыто отдельно от прежних отвергнутых
направлений (усреднение, индукция по элементу, семейство «первый элемент
= t», локальные условия — `h13_line_model.md` §1.7, §4).

## 4. Почему усреднение по всем n^2 разрезам не работает даже на отражениях
   (точная формула, проверено 4<=n<=12)

Для `sigma'_n(i) = (1-i) mod n` (любое отражение — тот же результат, так как
среднее инвариантно относительно доменных/значенческих сдвигов pi):

```text
sum_{s,t} inv(W(sigma'_n,n,s,t)) = n^2 (n-1)(2n-1) / 6
avg = (n-1)(2n-1)/6  ~ n^2/3
```

При этом истинный минимум `I(sigma'_n) = floor((n-1)^2/4) ~ n^2/4` —
СТРОГО МЕНЬШЕ среднего, и разрыв растёт линейно с n (при n=9: среднее
22.67 против минимума 16). Значит, на самом трудном классе входов
распределение `inv` по n^2 разрезам сильно скошено: подавляющее
большинство разрезов существенно хуже искомой оценки, и лишь небольшое
структурное подмножество (в духе C32 — разрезы, согласованные с осью
отражения) её достигает. Любой аргумент на основе среднего или считающего
веса подмножества разрезов (не привязанного к структуре pi) не может дать
floor((n-1)^2/4) как верхнюю оценку минимума — тот же диагноз, что и
в `h13_line_model.md` §6, здесь дан точной формулой вместо наблюдения.

## 5. Вердикт

H13-I не доказана и не опровергнута за эту сессию. Новое (инструмент,
пригодный для дальнейших попыток): точная разделённая рекуррента (§1),
двойственность C37 (§2). Новое отрицательное: одной степени свободы мало
(§3, ранее не проверялось явно в общем виде — только для конкретного
семейства "первый элемент = t"), точная формула среднего на отражениях (§4)
закрывает усреднение более убедительно, чем прежняя оценочная запись.

Рекуррента §1 сама по себе не даёт конструктивного доказательства: попытка
телескопировать по s при фиксированном t сводит задачу к тому же вопросу
для pi^{-1} (симметрично тому, что телескопирование по t сводит к тому же
вопросу для pi) — самоподобие, не редукция. Совместный (диагональный) шаг
по обеим координатам сразу не даёт более простой формулы, чем два
последовательных шага (проверено прямой подстановкой).

Следующий шаг по PLAN §8: поскольку H13-I не доказана за отведённую
1 сессию, переходить к индукции H3 (PLAN §4.3, п. 3) как заявлено в плане.
H13-I остаётся CONJECTURED, VERIFIED 4 <= n <= 10 (C33/C35, теперь
дополнительно перепроверено независимой реализацией 4 <= n <= 9 —
`data/runs/h13i_toric/report.md`); её можно вернуть в очередь позже с
конкретным новым кандидатом (например: индукция не по одному элементу, а
по антиподальной паре, используя точную рекурренту §1 для контроля
изменения inv при удалении пары; или прямое построение хорошего (s,t) по
структуре циклов pi, а не по перебору/усреднению).
