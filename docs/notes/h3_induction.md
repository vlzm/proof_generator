# H3 — индуктивная редукция S_{n-1} -> S_n: постановка и первая попытка

Дата: 16.09.2026 (сессия 9). Бюджет по плану — 2 сессии до вердикта
(PLAN §4.3, п. 3); это первая из них. Статус H3 остаётся «идея» /
CONJECTURED — доказательства нет; ниже точная формулировка, работающая
редукция объекта задачи (лемма о вложении) и один явно проверенный
отрицательный результат (конкретная конструкция не укладывается в бюджет).

## 1. Цель

`D_n <= D_{n-1} + (n - 1)` при всех n >= 5, с `D_4 = B_4 = 6` (VERIFIED,
C2v) как базой. Поскольку `B_n - B_{n-1} = n - 1` точно, индукция без
запаса даёт `D_n <= B_n` при всех n >= 4 — то есть C15. Нулевой запас
(AGENTS.md формулировка задачи) означает, что ЛЮБАЯ конструкция шага
индукции обязана быть точной: экономия и потери должны в сумме давать
ровно `n - 1`, не больше.

## 2. Вложение (лемма о срезе значения n-1) — точное, не приближённое

Для `pi` из `S_n` пусть `k = pi^{-1}(n-1)` (позиция значения n-1 в массиве).
Определим `rot_cost = delta_n(k, n-1) <= floor(n/2)` и слово `rot_word`
(степень `L` или `R`, короче направление), переносящее содержимое позиции k
на позицию n-1. Пусть `p2 = apply_word(pi, rot_word)`; тогда `p2[n-1] = n-1`
и `q := p2[0:n-1]` — перестановка значений `{0, ..., n-2}`, то есть элемент
`S_{n-1}`.

Это точное утверждение (не оценка): `q` — это n-1 оставшихся элементов
окружности pi, прочитанные начиная сразу после места значения n-1, в их
исходном циклическом порядке. Слово `rot_word` длины `rot_cost` — ребро
пути от `pi` до `p2` в графе Кэли (по определению `p2 = apply_word(pi,
rot_word)`), поэтому `|d(pi) - d(p2)| <= rot_cost`; отсюда
`d(pi) <= rot_cost + d(p2)`, и задача сводится к оценке `d(p2)` через
`d(q)` (или `D_{n-1}`) при известном месте n-1 в `p2`.

## 3. Трудность (то, что явно указано в PLAN и AGENTS)

Дальше нужно превратить путь `p2 -> id_n` в комбинацию (а) кратчайшего
слова `q -> id_{n-1}` в малых образующих `L_{n-1}, R_{n-1}, X_{n-1}` и
(б) поправки на то, что `L_n`/`R_n` двигают ВСЕ n позиций, включая ту, где
сейчас сидит значение n-1 (AGENTS.md: «фиксированный элемент нельзя молча
исключать»). Если применять буквы малого слова напрямую как буквы
большого алфавита (тот же символ `L`/`R`/`X`, только на массиве длины n),
значение n-1 «едет» по окружности вместе со всеми: при каждом `L`/`R`
большого слова оно сдвигается на одну позицию, ничего не «замораживается».
Это не мешает малым `X`, пока n-1 не оказывается под головой (позиции 0,1)
в момент, когда малое слово требует там обмена — но за слово длины
`D_{n-1} ~ floor((n-1)^2/4)` n-1 успевает пройти вокруг окружности несколько
раз и почти наверняка попадает под голову хотя бы раз.

## 4. Проверенная (и отвергнутая) конструкция: «буквальный подъём»

`experiments/h3_induction_probe.py` (h3_induction_probe-1.0): применяет
малое кратчайшее слово `q -> id_{n-1}` буквально (те же буквы) к `p2`,
без какой-либо коррекции при столкновениях, и добавляет точное расстояние
от получившегося состояния до `id_n` (свежий BFS по всему `S_n`, эталонные
ходы `oracle/moves.py`). Итоговая длина = `rot_cost + len(малое слово) +
extra_after_lift`. Результат на sigma_n (BFS 5 <= n <= 9, `data/runs/h3_induction_probe/report.md`):

```text
n        5    6    7    8    9
B_n     10   15   21   28   36
итог    10   15   24   30   39
избыток  0    0   +3   +2   +3
```

Совпадение при n = 5, 6 — случайность (малый размер, столкновений мало);
начиная с n = 7 конструкция систематически выходит за бюджет `B_n`. На
случайных `pi` (20 на каждое n, `--samples 20 --seed 1`) избыток над `B_n`
доходит до +13 при n = 9 (у части входов, наоборот, сильно меньше `B_n`,
потому что `d(pi)` само меньше — сравнение с `B_n` там неинформативно;
показательно именно поведение на sigma_n, самом длинном входе). Вывод:
буквальный подъём малого слова REFUTED как конструкция для H3 — она не
достигает нужного бюджета `n - 1` уже при n = 7. Строка реестра C38.

## 5. Что не удалось и что могло бы сработать

Не является контрпримером к H3 как ГИПОТЕЗЕ (H3 утверждает существование
КАКОГО-ТО пути с нужной стоимостью, а не то, что произвольный подъём малого
слова его достигает) — это отрицательный результат именно про buквальный
подъём. Кандидаты для следующей сессии:

1. **Не любое кратчайшее малое слово, а специально подобранное.** У `q`
   обычно много геодезических (см. C13/C13v: почти всегда не единственных);
   нужно слово, которое почти не задерживается у позиций 0/1 там, где
   n-1 «проезжает». Порядок посещения окружности малым словом (позиции
   обменов `h_1..h_k`, PROBLEM §2) можно в принципе выбирать так, чтобы
   момент, когда n-1 проходит под головой, не совпадал с обменом — но нужно
   доказать, что такой выбор всегда существует БЕЗ дополнительной платы.
2. **Выбор места вставки (какую из n позиций окружности резервировать под
   n-1) как второй степени свободы.** В п. 2 цель вставки жёстко — позиция
   n-1; на самом деле подходит любая из n позиций (стоимость `rot_cost`
   меняется). Нужно расчёт, использующий это n-параметрическое семейство
   совместно с выбором малого слова (аналог «совместных сдвигов» H13-I —
   вероятно, та же принципиальная трудность).
3. **Другая индукция**: не «убрать наибольшее значение», а «убрать одну
   позицию окружности» (двойственная редукция); или индукция на пару
   (n-1, n) сразу; не проверялось в этой сессии.
4. Прямая формула стоимости «буквального подъёма» через число столкновений
   n-1 с головой малого слова, чтобы количественно понять, откуда берётся
   избыток `+3` при n = 7 (не сделано — не хватило бюджета сессии).

## 6. Вердикт сессии 9

H3 не доказана и не опровергнута; израсходована половина заявленного
бюджета (1 из 2 сессий, PLAN §4.3). Зарегистрирован точный отрицательный
результат об одной конкретной конструкции (C38) и точная (не приближённая)
лемма о вложении (§2) как отправная точка. Следующая сессия — пункты 1–2
§5 (подбор малого слова / совместный выбор позиции вставки), либо явный
отказ от буквального подъёма в пользу редукции через формулу
`d(pi) = min [k + sum delta(h_i, h_{i+1})]` (PROBLEM §2) напрямую на большом
n, обходя малую подзадачу.
