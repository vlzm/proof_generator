# H3 — индукция sigma_(n-1) -> sigma_n: попытка, честный останов

Дата: 15.09.2026 (сессия 9, запасное направление после незавершённого H13-I,
см. `docs/notes/h13_line_model.md` §7). Бюджет по PLAN §4.3 п. 3 — 2 сессии
до вердикта; в этой сессии сделан только первый, ограниченный по времени
заход (остаток бюджета текущей сессии после H13-I), без письменного
доказательства и без явного опровержения — честная остановка с указанием,
что именно мешает и куда двигаться дальше.

## 0. Что утверждает H3

PLAN §0: переход от sigma_(n-1) к sigma_n стоит `floor((n-1)/2)` обменов и
`floor(n/2)` шагов головы; рекуррента `T_n <= T_(n-1) + (n-1)` при `T_4 <= 6`
даёт ровно `B_n` (`B_n = n(n-1)/2`, PROBLEM §1), запас — ноль. Смысл шире, чем
формула для sigma_n: PLAN §4.3 п. 3 ставит вопрос о доказательстве общей
верхней оценки `D_n <= B_n` (C15, для ВСЕХ pi, не только sigma_n) индукцией
по n — вложить (n-1)-задачу в n-задачу и оценить стоимость имитации её ходов.

Тождество нулевого запаса (элементарно, не требует вычислений):
`B_n - B_(n-1) = (n-1)(n)/2 - (n-1)(n-2)/2 = n-1` и
`floor(n/2) + floor((n-1)/2) = n-1` для любого n — то есть ЕСЛИ индукция
работает, она работает без единого лишнего хода на переход; любая потеря хотя
бы в одном ходе ломает рекуррента (это предупреждение уже стоит в PLAN §4.3:
«запас рекурренты нулевой»).

## 1. Естественное вложение для sigma_n (проверено конкретно)

`sigma_n[i] = (1-i) mod n = (1, 0, n-1, n-2, ..., 2)`. Удаление ПОСЛЕДНЕЙ
позиции (индекс n-1, значение 2) и релейбл оставшихся значений (сдвиг всех
значений > 2 на −1) даёт в точности `sigma_(n-1)`:

```
sigma_5 = (1,0,4,3,2)  ->  удалить позицию 4 (значение 2), сжать  ->  (1,0,3,2) = sigma_4
sigma_6 = (1,0,5,4,3,2) -> удалить позицию 5 (значение 2), сжать -> (1,0,4,3,2) = sigma_5
```

Проверено вручную для n = 4..8 (подстановкой формулы). Значит для sigma_n
конкретно редукция «удалить элемент со значением 2» естественна и точна.
Но для sigma_n частная задача уже решена БЕЗ индукции: явное слово C32
(«две линейные инверсии дуг», `docs/proofs/C32_two_arc_reversal.md`) даёт
`d(pi_h) <= B_n - delta_n(h,1)` при всех n >= 4 и всех h напрямую, без
опоры на sigma_(n-1). Индукция для одного только sigma_n не добавляет
ничего к C9 (уже PROVED через C32). Ценность H3 — только если она
работает для ПРОИЗВОЛЬНОЙ pi (путь к C15 целиком), а не только для sigma_n.

## 2. Общая схема вложения и где она упирается

Для произвольной pi из S_n: удалить один элемент (по значению или по
позиции — конвенция требует выбора) на окружности из n элементов, сжать до
окружности из n-1 элементов с некоторой pi' из S_(n-1), взять кратчайшее
слово для pi' (индукционное предположение: длина `<= B_(n-1)`), и попытаться
«поднять» это слово на n-элементную окружность, добавив стоимость размещения
удалённого элемента.

Проблема (указана уже в PLAN §4.3 п. 3: «Фиксированный элемент нельзя молча
исключать: L и R вращают весь массив»): L и R на n-элементной окружности
двигают ВСЕ n элементов, включая удалённый/добавленный. Если удалённый
элемент просто «паркуется» в одной позиции и словом (n-1)-задачи имитируются
её ходы буквально (L/R сдвигают голову на 1 позицию из n вместо 1 из n-1;
X делает обмен под головой), то симуляция ТОЧНА без дополнительной платы
ТОЛЬКО пока голова (n-1)-слова ни разу не должна «пересечь» позицию, где
запаркован лишний элемент — иначе на пересечении нужен дополнительный ход
(обойти лишний элемент), и по тождеству §0 такого хода уже не остаётся
(запас — ноль).

Значит корректная (без потерь) имитация возможна ровно тогда, когда
ВЫБРАННОЕ кратчайшее слово для pi' является «линейным» относительно
какого-то одного ребра окружности — то есть никогда не переходит через это
ребро (там паркуем удалённый элемент). Это ТОЧНО определение `d_line` из
линейной модели H13 (`docs/notes/h13_line_model.md` §0, `d_line(pi') = min
по рёбрам разреза длины слова, не переходящего разрез`). Условие для
индукционного шага без потерь — существование геодезической (n-1)-задачи с
`d_line(pi') = d(pi')` (геодезическая, не пересекающая хотя бы одно ребро).

## 3. Эта H3-редукция наследует уже известное препятствие H13/линейной модели

Данные сессии 8 (`data/runs/line_model/report.md`, `docs/notes/h13_line_model.md`
п. 1.6): `d_walk = d` (голова обходит разрез, но не обменивает через него) при
n <= 7 для всех pi, НО при n = 8, 9 есть входы (аффинные), где `d_walk - d`
доходит до 4, 5 — то есть КАЖДАЯ геодезическая таких pi обязана обменивать
через любое ребро окружности, какое ни выбери. Для таких pi' простое
«запарковать лишний элемент на одном ребре» не даёт точной симуляции без
потерь ни при каком выборе ребра — а запас на потери, по тождеству §0,
нулевой. Значит для этих pi' (существующих уже при n' = 8, 9, то есть при
переходе 8->9 и 9->10 в рекурренте) прямая («запарковать и просимулировать»)
версия схемы H3 не проходит.

Это не опровергает H3 в целом (возможна другая редукция — не «удалить один
элемент и запарковать», а нечто более тонкое, например перераспределение
экономии между шагом индукции и последующей коррекцией, или вложение с
переменным, а не фиксированным разрезом), но показывает, что H3 в наивной
форме СВОДИТСЯ к тому же открытому вопросу, что и H13-R (бюджет вращений
линейной модели, `docs/notes/h13_line_model.md` C36: `Rbest(pi) <=
floor(n^2/4)` — доказано только для СУЩЕСТВОВАНИЯ хорошего разреза, не для
геодезических без разреза вовсе), а не является независимым более лёгким
путём к C15, как можно было ожидать из формулировки в PLAN.

## 4. Вердикт

Не доказано и не опровергнуто за отведённое время. Найдено:

1. Естественная редукция «удалить один элемент» подтверждена явно для
   sigma_n (§1), но для sigma_n самой задача уже закрыта явным словом C32 —
   индукция здесь избыточна.
2. Для общей pi корректная безубыточная имитация (n-1)-геодезической на
   n-элементной окружности требует, чтобы эта геодезическая не пересекала
   хотя бы одно ребро (§2) — это буквально `d_line(pi') = d(pi')`.
3. Это условие НЕ выполняется для всех pi' уже при n' = 8, 9 (§3, данные
   line_model сессии 8) — прямая схема H3 наследует то же препятствие, что и
   недоказанная часть H13 (H13-R существование геодезической в линейной
   модели), а не обходит его.

Рекомендация для следующей сессии (бюджет по PLAN — ещё 1 сессия из
заявленных 2 до вердикта по H3): либо (а) искать НЕ «запарковать один
элемент», а редукцию с переменным разрезом (удалённый элемент может
менять позицию по ходу слова, с ограниченным числом пересечений, а не
нулевым) — тогда допустимый бюджет пересечений нужно явно вывести из
тождества §0 (скорее всего он тоже ноль, что возвращает к тому же тупику,
но это стоит проверить формально, а не предполагать); либо (б) признать, что
H3 в этой форме требует того же результата, что и H13-R в общем виде
(геодезическая почти всегда укладывается в линейную модель без потерь), и
объединить бюджеты — атаковать H13-R (не H13-I) как общую задачу вместо
отдельного H3. Второе представляется более экономным: H13-R уже частично
VERIFIED (C36, существование хорошего разреза с ограниченным бюджетом
вращений, а не отсутствие обхода) и явно связано с той же структурой.
