# H13 — линейная модель: профиль, бюджет вращений, вердикт

Дата: 13.09.2026 (сессия 8). Ядро oracle-1.0, таблицы C2v (4 <= n <= 10).
Код: `experiments/line_profile.c`, `experiments/line_rotation_budget.py`,
`experiments/line_model.py` (1.1), `constructions/line_cocktail.py`,
`checks/check_C34.py`. Отчёты: `data/runs/line_profile/`,

`data/runs/check_C34/`.

## 0. Определения

Двойной разрез `(q, c)`: ребро позиций {q, q+1} и сдвиг c. Линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1; цель — тождественная линия;
голова стартует в индексе `j0 = (−q−1) mod n`, заканчивает в `j1 = (c−q−1)
mod n`. Слово *линейное*, если голова не переходит и не обменивает через
разрез; *сокращённое*, если каждый обмен снимает инверсию (`N_X = inv(w)`).

- `I(pi) = min_{q,c} inv(w)` — по всем n^2 разрезам (эквивалентно: минимум
  инверсий по торическому классу pi — повороты позиций и значений).
- `d_line(pi)`, `d_walk(pi)`, `d_red(pi)`, `Rbest(pi)`, `Rfree(w)` — см.
  отчёты `line_model`, `line_rotation_budget`. Всегда
  `d <= d_walk <= d_line <= d_red`.

## 1. Что показали данные (исчерпывающе)

1. `I(pi) <= floor((n−1)^2/4)` при 4 <= n <= 10 (равенство — ровно n отражений).
2. `d(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 10; более того,
   `d_red(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 9: для каждой pi есть
   разрез с `inv = I(pi)` и сокращённое линейное слово с
   `N_rot <= floor(n^2/4)`. Максимум `Rbest = floor(n^2/4)` достигается на
   2, 4, 11, 11, 50, 111 входах (n = 4..9) — не только на отражениях.
3. Профиль `max_{I(pi) = I} d(pi)` (профиль `line_profile`): при I >= max − 1
   равен `I + floor(n^2/4)`, при n <~ I <= max − 2 — `I + floor(n^2/4) − 1`,
   при малых I — около `2I + n`. Бюджет вращений `floor(n^2/4)` требуется
   уже при I ≈ n.
4. `max_pi (d − 2I)` = 3, 3, 5, 6, 8, 10, 13 при n = 4..10: растёт не медленнее
   n − 1 (лемма B) и быстрее n (обмен блоков у антипода).
5. `max_w Rfree(w) = B_n − 1` при 4 <= n <= 9 — без выбора разреза бюджет
   вращений равен `B_n − 1` (лемма A, точно).
6. `d_walk = d` при n <= 7; при n = 8, 9 есть входы с `d_walk − d` до 4, 5
   (аффинные), но при `I >= max − 1` всегда `d_line = d`.
7. Индукция по одному элементу для п. 1 не проходит: при n = 8 аффинный вход
   `(0,5,2,7,4,1,6,3)` имеет I = 11, а все восемь его редукций (удаление
   элемента с контракцией позиций и значений) — I = 6, тогда как
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2) = 3`. Семейство
   разрезов «первый элемент линии имеет значение t» (n разрезов вместо n^2)
   тоже недостаточно ни при каком t (n = 5: `(0,2,4,1,3)`; n = 7:
   `(0,2,4,6,1,3,5)`).

## 2. Лемма A (универсальный маршрут линии; PROVED)

Для любой линии w из n позиций существует сокращённое линейное слово с
`N_X = inv(w)` и `N_rot = B_n − 1` (конец головы свободен; старт — ребро 0).
Оценка точна: полностью обращённая линия имеет `inv = B_n`, а в кратчайшем
слове `N_rot >= N_X − 1`.

Маршрут (`constructions/line_cocktail.py`): проход 1 по рёбрам 0, 1, ..., n−2;
проход 2 по n−3, ..., 0; проход 3 по 1, ..., n−4; проход 4 по n−5, ..., 1; …
(k-й проход содержит n − k рёбер, направления чередуются, каждый проход
начинается рядом с концом предыдущего). На каждом ребре обмен делается
тогда и только тогда, когда пара инвертирована. Всего `1 + 2 + … + (n−1) =
B_n` сравнений, длина пути `B_n − 1`.

Корректность: проход 1 переносит максимум на позицию n−1; проход 2 —
минимум позиций 0..n−2 на позицию 0; проход 3 — максимум позиций 1..n−2 на
n−2; и т. д. (шейкер-сортировка с сужающимися границами). После k проходов
`ceil(k/2)` наибольших и `floor(k/2)` наименьших элементов стоят на своих
местах, после n − 1 проходов — все. Каждый обмен снимает ровно одну инверсию,
поэтому обменов ровно `inv(w)`. ∎ Проверено эталонными ходами на всех линиях
при 4 <= n <= 8 (`checks/check_C34.py`, часть A).

Следствие. Для любой pi и любого разреза `d(pi) <= inv(w) + B_n − 1 + подход +
финал`. Это бесполезно для C15: вся экономия до `floor(n^2/4)` — в выборе
разреза (п. 1.5), а не в маршруте по данной линии.

## 3. Лемма B (антиподальная транспозиция; PROVED при чётных n >= 6, таблицы 4..10)

Пусть n = 2m чётно и `tau_n` — тождественная перестановка с обменянными
позициями m, m+1. Тогда `I(tau_n) = 1` и `d(tau_n) = n + 1`.

`I = 1`: разрез q = n−1, c = 0 даёт линию с одной инверсией; `I = 0` только у
поворотов тождественной. Верхняя оценка — слово `L^m X R^m` длины n + 1.

Нижняя оценка. Пусть слово сортирует tau_n и голова заканчивает в c; тогда
элемент e должен оказаться на позиции e + c. Для элемента e обозначим `t_e`
его суммарное знаковое смещение по обменам (каждый X даёт +1 одному и −1
другому участнику); `sum_e t_e = 0`, `N_X >= (1/2) sum_e |t_e|`, и
`t_e ≡ c (mod n)` при e ∉ {m, m+1}, `t_m ≡ c − 1`, `t_{m+1} ≡ c + 1`.

Случай c = 0. Если есть обмен на ребре m (антипод старта), голова проходит
0 → m → 0: `N_rot >= 2m = n`, `N_X >= 1`, итого >= n + 1. Если обменов на ребре
m нет, все обмены — соседние транспозиции пути `m+1, m+2, …, n−1, 0, …, m`
(окружность без ребра m), и их произведение как перестановка позиций равно
транспозиции концов этого пути, длина которой в порождающих пути равна
`2n − 3 >= n + 1`.

Случай c ≠ 0. Автоморфизм `p -> sigma_n o p o sigma_n` (PROBLEM §4.3) меняет
L и R местами, сохраняет tau_n (проверка: 1 − tau(1 − i) = i при i ∉ {m, m+1}
и меняет m, m+1 местами) и переводит c в −c; поэтому достаточно 1 <= c <= m.
Запишем `t_e = r_e + n·k_e`, `r_e` — остаток в [0, n): `sum r_e = (n−2)c +
(c−1) + (c+1) = nc`, значит `sum k_e = −c`. Стоимость `|t_e|` при k = 0 равна
r, при k = −1 — n − r, каждый следующий шаг |k| добавляет n; k > 0 стоит
n + r и требует лишнего уменьшения у другого элемента. Минимум `sum |t_e|`
достигается, когда ровно c элементов имеют k = −1 — те, у кого остатки
наибольшие: один с остатком c + 1 и c − 1 с остатком c:
`sum |t_e| >= nc + (n − 2c − 2) + (c − 1)(n − 2c) = 2cn − 2c^2 − 2`,
`N_X >= cn − c^2 − 1`. При 1 <= c <= m правая часть вогнута по c, на концах
`n − 2` (c = 1) и `m^2 − 1 >= n − 2` (c = m), так что `N_X >= n − 2`. В
кратчайшем слове нет XX, поэтому `N_rot >= N_X − 1` и длина `>= 2n − 5 >= n + 1`
при n >= 6. ∎ При n = 4 равенство `d = 5` — по таблице; `d = n + 1` при
n = 4, 6, 8, 10 сверено с таблицами (`check_C34.py`, часть B).

Следствие. Всякая оценка вида `d(pi) <= 2·I(pi) + g(n)`, верная при всех pi,
требует `g(n) >= n − 1` (чётные n). Критерий PLAN §8 (`g(n) <= floor(n/2) +
O(1)`) недостижим. Обмен блоков длины k у антипода даёт ещё больше:
`d − 2I` = 8 (n = 8, k = 2), 13 (n = 10, k = 3).

## 4. Лемма C (локальная оптимальность разреза)

Если (q, c) минимизирует inv, то линия w удовлетворяет
`sum_{j<k} w_j <= k(n−1)/2` для всех k (и симметрично для суффиксов), и то же
для обратной перестановки (`sum_{x<k} pos(x) <= k(n−1)/2`): сдвиг разреза
позиций на k переносит первые k элементов в конец, меняя inv на
`sum_{j<k} (n − 1 − 2 w_j)`; сдвиг разреза значений на k делает элементы
0..k−1 наибольшими, меняя inv на `sum_{x<k} (n − 1 − 2 pos(x))`. ∎

Этих условий недостаточно для `inv <= floor((n−1)^2/4)`: линия
`(0,5,4,3,2,1,6)` при n = 7 удовлетворяет всем им (суммы 0, 5, 9, 12, 14, 15
при порогах 0, 6, 9, 12, 15, 18; обратная — те же), но `inv = 10 > 9`; её
торический класс имеет I = 8 при несоседнем разрезе. Доказательство п. 1.1
должно использовать совместные сдвиги обоих разрезов.

## 5. Вердикт по H13

1. Исходная форма H13 («один неиспользуемый разрез достаточен для диаметра»)
   подтверждена конечно и уточнена: на слоях `B_n`, `B_n − 1` `d_line = d`
   при 4 <= n <= 9, но в общем случае обмены через все рёбра бывают нужны
   (n = 8, 9).
2. Критерий PLAN §8 — оценка `d <= 2I + g(n)` с `g(n) <= floor(n/2) + O(1)` —
   ложен (лемма B). Правильная форма — с наклоном 1:
   **H13′: `d(pi) <= I(pi) + floor(n^2/4)`**, распадающаяся на
   **H13-I: `I(pi) <= floor((n−1)^2/4)`** (чистая комбинаторика торических
   классов) и **H13-R: существует разрез с `inv = I(pi)` и сокращённое линейное
   слово с `N_rot <= floor(n^2/4)`** (бюджет вращений, не зависящий от I).
   `H13-I + H13-R => C15` по C12. Обе части VERIFIED (4 <= n <= 10 и 4 <= n <= 9),
   обе тесны.
3. «Доказуемая схема слова для линии с inv инверсиями и `N_rot <= inv + f`»
   (PLAN §8 п. (2)) не существует в нужной силе: бюджет вращений не убывает с
   inv (Rbest = floor(n^2/4) при I ≈ n), а без выбора разреза он равен
   `B_n − 1` (лемма A). Схема должна выбирать разрез; экстремальные маршруты
   разного вида (зигзаги на отражениях, холостые переходы на блочных входах).
4. Пункт (3) PLAN §8 (входы с `I > max − n/4`) не сводит задачу к конечному
   числу семейств: их 660 при n = 10 и они растут с n.

## 6. Следующий шаг

Доказать H13-I отдельно (бюджет 1 сессия): утверждение о торических классах —
у каждой pi есть поворот позиций и значений с не более `floor((n−1)^2/4)`
инверсиями. Эквивалентная форма: у каждой pi есть двойной разрез с не менее
`floor(n^2/4)` неинверсий; в терминах точек `(i, pi(i))` на торе — точка
`(q, s)` тора, лежащая в «одноимённых» квадрантах не менее `floor(n^2/4)` пар.
Известно: усреднение по всем n^2 разрезам не работает (среднее для sigma_n
равно `(n^2 − 1)/6 < n^2/4` в форме максимума и `~n^2/3` для id в форме
минимума), индукция по одному элементу не работает (п. 1.7), локальные
условия недостаточны (лемма C). Кандидаты: сдвиги обоих разрезов вместе;
экстремальность отражений через леммы C32 (баланс дуг); литература о
торических классах перестановок. Если H13-I доказана — H13-R остаётся
эквивалентом C15 при известном N_X и переходит в задачу о маршрутах; если
нет за сессию — переход к индукции H3 (PLAN §4.3).

## 7.1. Обозначения

`pi` — перестановка Z_n; точки `P_i = (i, pi(i))` на торе Z_n x Z_n.
Двойной разрез `(a, b)`, линия `w^{a,b}_j = (pi[(j + a) mod n] − b) mod n`,
`G(a, b) = inv(w^{a,b})`, `I(pi) = min_{a,b} G(a,b)`.

- `u_P = (x_P − a) mod n`, `v_P = (y_P − b) mod n` — координаты точки в
  фундаментальном квадрате с углом в разрезе. Пара `{P, Q}` *согласована*
  (неинверсия), если `(u_P − u_Q)(v_P − v_Q) > 0`.
- `N(a, b) = #{i < a : pi(i) < b}` — число точек в углу `[0,a) x [0,b)`;
  `A(a) = sum_{i<a}(n − 1 − 2·pi(i))`, `B(b) = sum_{j<b}(n − 1 − 2·pi^{-1}(j))`.
- `D(a, b) = N(a, b) − ab/n` — расхождение угла; `Dt` — его двойное
  центрирование (вычесть средние по строке и столбцу, прибавить общее среднее).
- `M_n = floor((n − 1)^2/4)`, `B_n = n(n − 1)/2`, `B_n = floor(n^2/4) + M_n` (C12).

Эквивалентная форма H13-I: `max_{a,b} conc(a,b) >= floor(n^2/4)`, где
`conc = B_n − G`. Ещё одна: применяя утверждение к `−pi` (у неё таблица
дополнительна к таблице `pi`), получаем, что H13-I для всех `pi`
равносильна `min_{a,b} conc(a,b) <= M_n` для всех `pi`.

## 7.2. Доказанные тождества

**Лемма D1 (критерий согласованности — коробки на торе).** Пусть
`d = (x_Q − x_P) mod n`, `e = (y_Q − y_P) mod n` (оба в 1..n−1). Тогда
`Q` стоит раньше `P` в порядке позиций ⟺ `a ∈ (x_P, x_Q]`, и аналогично
для значений и `b`. Поэтому пара `{P, Q}` согласована ⟺ разрез `(a, b)`
лежит в одной из двух коробок `(x_P, x_Q] x (y_P, y_Q]` или
`(x_Q, x_P] x (y_Q, y_P]`, и число согласующих разрезов равно
`d·e + (n − d)(n − e)`. ∎
*Следствие D1′.* `sum_{a,b} conc(a,b) = sum_{(P,Q) упорядоченных} d·e`;
среднее по всем n^2 разрезам равно `(1/n^2)·sum_{P≠Q} d·e`. Для `id`
это `(n−1)(2n−1)/6 ≈ n^2/3`, для отражений `(n^2 − 1)/6 ≈ n^2/6`.
(Это и есть подсчёт из §6, проверен прямым перебором.)

**Лемма D2 (шаговые рекурренты).**
`G(a+1, b) − G(a, b) = n − 1 − 2·w_0`, где `w_0 = (pi(a) − b) mod n`;
`G(a, b+1) − G(a, b) = n − 1 − 2·q`, где `q = (pi^{-1}(b) − a) mod n`.
Доказательство: сдвиг разреза позиций переносит первый элемент линии в
конец — он теряет `w_0` инверсий и приобретает `n − 1 − w_0`; сдвиг разреза
значений превращает значение 0 (стоящее в позиции `q`) в наибольшее — оно
теряет `q` инверсий и приобретает `n − 1 − q`. ∎

**Лемма D3 (смешанная вторая разность).** Для всех `a, b ∈ Z_n`
```text
G(a+1,b+1) − G(a+1,b) − G(a,b+1) + G(a,b) = 2 − 2n·[pi(a) = b].
```
Доказательство: по D2 левая часть равна
`−2·[((pi^{-1}(b) − a − 1) mod n) − ((pi^{-1}(b) − a) mod n)]`; разность
остатков равна `−1`, кроме случая `pi^{-1}(b) = a`, когда она равна `n − 1`. ∎
*Следствие D3′ (коробочное тождество).* Для любых `k, l >= 0`
`G(a+k,b+l) + G(a,b) − G(a+k,b) − G(a,b+l) = 2kl − 2n·(число точек pi в
[a, a+k) x [b, b+l))`.

**Лемма D4 (замкнутая формула).** При `0 <= a, b <= n − 1`
```text
G(a, b) = inv(pi) + A(a) + B(b) + 2ab − 2n·N(a, b).
```
Доказательство: телескопирование D2 вдоль первой строки и первого столбца
плюс суммирование D3 по прямоугольнику `[0,a) x [0,b)`. ∎

**Лемма D5 (форма расхождения).** `G(a, b) = avg_cuts G − 2n·Dt(a, b)`,
где `avg_cuts G = (1/n^2) sum_{a,b} G(a,b)`.
Доказательство. `sum_{i<a} pi(i) = sum_{b'=1}^{n-1} #{i < a : pi(i) >= b'} =
a(n−1) − sum_{b'} N(a, b')`, поэтому `A(a) = −a(n−1) + 2·sum_{b'} N(a,b')`
(слагаемое `b' = 0` нулевое); симметрично `B(b) = −b(n−1) + 2·sum_{a'} N(a',b)`.
Подставим в D4 и заменим `N = D + ab/n`: слагаемые `−(a+b)(n−1)` сокращаются с
`a(n−1) + b(n−1)` из `sum_{b'} ab'/n = a(n−1)/2` и её аналога, и остаётся
```text
G(a,b) = inv(pi) + 2·R(a) + 2·C(b) − 2n·D(a,b),
R(a) = sum_{b'} D(a,b'),  C(b) = sum_{a'} D(a',b).
```
Наконец `D(a,b) = Dt(a,b) + R(a)/n + C(b)/n − m`, где `m` — среднее `D`;
подстановка сокращает `R` и `C` и даёт `G = inv(pi) + 2n·m − 2n·Dt`.
Усреднение по всем разрезам (у `Dt` нулевое среднее) определяет константу. ∎

*Следствие D5′ (точная переформулировка H13-I).*
```text
I(pi) = avg_cuts G − 2n·max_{a,b} Dt(a,b),
H13-I  <=>  max_{a,b} Dt(a,b) >= (avg_cuts G − M_n) / (2n).
```
То есть H13-I — в точности нижняя оценка расхождения матрицы перестановки
по «угловым» коробкам, с порогом, зависящим от `pi` через D1′.
Дополнительно `D(a,b) = sum_i f_i(a)·g_i(b)` с `f_i(a) = [i < a] − a/n`,
`g_i(b) = [pi(i) < b] − b/n`, а двойное центрирование действует на
произведение помножителям, поэтому `Dt(a,b) = sum_i F_i(a)·G_i(b)`
(`F_i`, `G_i` — центрированные `f_i`, `g_i`): `Dt` — матрица ранга <= n
с явным разложением.

**Лемма D6 (аффинные входы).** Если `pi(x) = ax + b`, то
`w^{α,β}_j = a·j + (aα + b − β)`, значит `G(α, β)` зависит только от
`aα − β mod n`: таблица постоянна на n прямых наклона `a`. ∎

**Лемма D7 (условия минимальности разреза и их сумма).** Разрез `(0,0)`
глобально минимален ⟺ `A(a) + B(b) + 2ab >= 2n·N(a, b)` для всех
`0 <= a, b <= n − 1` (сразу из D4). Сумма всех n^2 неравенств равносильна
```text
sum_i i·pi(i) >= n(n − 1)^2/4,   т. е.   sum_i (i − pi(i))^2 <= n(n^2 − 1)/6.
```
Доказательство суммы: `sum_a A(a) = sum_i (n−1−i)(n−1−2pi(i))`,
`sum_b B(b) = sum_i (n−1−pi(i))(n−1−2i)`, `sum_{a,b} 2ab = 2B_n^2`,
`sum_{a,b} N(a,b) = sum_i (n−1−i)(n−1−pi(i))`. Подстановка `X_i = n−1−i`,
`Y_i = n−1−pi(i)` даёт `2n·sum X_iY_i − 2n(n−1)B_n + 2B_n^2 >= 0`, а
`sum X_iY_i = sum_i i·pi(i)` после раскрытия. ∎

*Следствие D7′ (точная переформулировка H13-I, вторая).* Так как в каждом
торическом классе есть представитель с минимальным разрезом `(0,0)`,
H13-I равносильна: **всякая `pi`, удовлетворяющая n^2 неравенствам D7,
имеет `inv(pi) <= M_n`.** Это конечная система линейных условий на `pi`
без упоминания разрезов.

## 7.3. Что опровергнуто в этой сессии

Все свидетели — из исчерпывающего перебора (`data/runs/h13i_cut_torus/`).

1. **Усреднение по антидиагональному семейству разрезов.** Идея §6
   «сдвигать оба разреза вместе»: взять `n` разрезов `(a, s − a)` и
   усреднить. Величина `max_pi min_s (1/n)·sum_a G(a, s−a)` равна
   2, **5**, **22/3**, **11**, **14**, **58/3** при n = 4..9 против
   `M_n` = 2, 4, 6, 9, 12, 16. Опровергнуто с n = 5, свидетель
   `(0,2,4,1,3)`; далее `(0,3,6,2,5,1,4)`, `(0,4,8,3,7,2,6,1,5)`.
   Причина структурная, а не случайная: по D6 у аффинной `pi(x) = ax + b`
   хорошие разрезы лежат на прямых наклона `a`, поэтому **никакое семейство
   разрезов фиксированного наклона не работает** — семейство обязано
   зависеть от `pi`. (Семейство «первый элемент = t» из §1.7 — это случай
   наклона, задаваемого самой `pi`, и оно тоже недостаточно.)
2. **Сумма всех условий минимальности (D7).** Релаксация
   `sum_i i·pi(i) >= n(n−1)^2/4` допускает `inv` = 3, 6, 8, 12, 16, 22 при
   n = 4..9 — примерно `(n−1)^2/3` вместо `(n−1)^2/4`. Опровергнуто уже
   при n = 4 (`(0,3,2,1)`: `inv = 3 > 2`). То есть одного «скалярного»
   следствия n^2 неравенств мало; нужна их совместная структура.
3. **Одномерное усиление: «разрез позиций не важен».** Утверждение
   «для каждого `a` найдётся `b` с `G(a,b) <= M_n`» ложно:
   `max_pi min_b G(0,b)` = 2, 4, 6, **10**, **13**, **17** при n = 4..9.
   Свидетели: n = 7 — `(0,5,4,3,2,1,6)` (та же линия, что в лемме C),
   n = 8 — `(0,6,5,3,4,2,1,7)`, n = 9 — `(0,2,7,6,5,4,3,8,1)`.
   Превышение ровно 1 при n = 7, 8, 9 — разрез позиций обязателен, но
   «стоит» немного; это уточняет лемму C количественно.
4. **Моментная оценка в форме D5′.** Из `sum Dt = 0` следует
   `max Dt >= sum Dt^3 / sum Dt^2`. Полученная граница даёт
   29/6, 8, ≈11.86, ≈16.43, ≈21.73, ≈27.77 при n = 4..9 — примерно
   `(n−1)^2/2`. Опровергнуто при n = 4.

## 7.4. Почему мягкие аргументы не проходят (граница метода)

**Лемма D8 (моменты равномерной меры на разрезах бессильны).** Пусть
`pi_h` — отражение. По D6 (случай `a = −1`) `G` зависит только от
`T = h − a − b`, и линия при данном `T` — две убывающие серии длин
`k = T + 1` и `n − k`, откуда `conc = k(n − k)`. Значит по n^2 разрезам
величина `conc` принимает каждое из значений `k(n − k)`, `k = 1..n`,
ровно на `n` разрезах. Любая оценка вида `max conc >= sum λ·conc` с
вероятностной мерой `λ`, полученной из равномерной перевзвешиванием
степенью `conc` (моментное отношение `E[X^{j+1}]/E[X^j]`), даёт строго
меньше `max_k k(n−k) = floor(n^2/4)`, так как усредняются значения,
среди которых есть строго меньшие максимума. Предел при `j → ∞` равен
`floor(n^2/4)`, но не достигается ни при каком конечном `j`. ∎
Пункты 2 и 4 из 7.3 — частные случаи.

**Замечание D9 (зазор мал уже на случайных входах).** По D1′ среднее
`conc` по разрезам для случайной `pi` равно `B_n/2 = floor(n^2/4) − Θ(n)`.
Значит требуемый выигрыш над средним по разрезам — `Θ(n)` на типичной `pi`
и `Θ(n^2)` на отражениях. Доказательство обязано одновременно быть
«сильным» на отражениях и «точным» на типичных входах; это объясняет,
почему все проверенные усредняющие схемы ломаются.

## 7.5. Итог и переход

Сделано: H13-I сведена к двум точным и самодостаточным формулировкам —
D5′ (нижняя оценка расхождения `max Dt` для матрицы перестановки) и

Ни одна из них не доказана. Отвергнуты (с свидетелями): антидиагональные

условий минимальности (D7), одномерное усиление, моментные оценки (D8).

Что осталось непроверенным и может быть началом новой попытки (не в этой
сессии): индукция с удалением **двух** точек (бюджет
`M_n − floor((n−3)^2/4) = n − 2` вместо `floor((n−1)/2)`); экстремальная
устойчивость (доказать, что при `I(pi) = M_n` перестановка — отражение,
и вести индукцию по «расстоянию до отражения»); литература о расхождении
перестановочных матриц по угловым коробкам на торе (источник, если
найдётся, оформлять по правилу 11 — версия, точная формулировка, аудит).

По документированному плану (PLAN §8, repo_state «Следующая задача»)
следующая задача — **H3** (PLAN §4.3, п. 3), а не продолжение H13-I.
Что обязана проверить первая сессия по H3:

1. **База — уже проверена в этой сессии.** `data/tables/dist_n4.json`:
   `"max_distance": 6`, `"complete": true`, ядро oracle-1.0 (C2v), а
   `B_4 = 6`. Значит `T_4 <= 6` выполнено, причём с равенством. Рекуррента
   `T_n <= T_{n−1} + (n − 1)` с `T_4 = 6` даёт ровно `B_n`, так как
   `B_n − B_{n−1} = n − 1`: запас ноль, ни одного лишнего хода на шаг.
2. **Шаг как конкретное утверждение о словах.** Нужно определить вложение
   `ι: S_{n−1} -> S_n` и редукцию `ρ: S_n -> S_{n−1}` (молча выбросить
   элемент нельзя: L и R вращают весь массив, и положение головы —
   часть состояния) и доказать: для всякой `pi ∈ S_n` есть слово `u`,
   `|u| <= n − 1`, с `apply_word(pi, u) = ι(ρ(pi))`, причём сортировка
   `ι(ρ(pi))` не обязана трогать выделенный элемент. Первая проверка —
   по сертифицированным таблицам при 5 <= n <= 10:
   `max_pi [d_n(pi) − d_{n−1}(ρ(pi))] <= n − 1` для предложенного `ρ`.
3. **Нулевой запас на sigma_n.** Из `d(sigma_n) = B_n` следует, что на
   `sigma_n` шаг обязан быть точным: `ρ(sigma_n)` должно быть `sigma_{n−1}`
   (с точностью до положения головы), а `u` — суффиксом геодезической.
   Проверяется прямо по таблицам (n = 5..10).
4. **Согласие с C32 — самый дешёвый положительный тест.** Для явного слова
   «две линейные инверсии дуг» (C32) на `sigma_n` выполнено
   `N_X = floor((n−1)^2/4)`, `N_rot = floor(n^2/4)` (у C32
   `N_rot = floor(n^2/4) − delta_n(h, 1)`, а `sigma_n = pi_1`), сумма — `B_n`.
   Приращения
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2)` и
   `floor(n^2/4) − floor((n−1)^2/4) = floor(n/2)` в сумме дают ровно
   `n − 1` — то есть в точности заявленная в H3 цена шага
   (`floor((n−1)/2)` обменов и `floor(n/2)` ходов головы). Первый
   содержательный вопрос сессии по H3: **является ли слово C32 для
   `sigma_n` продолжением слова C32 для `sigma_{n−1}`** на эти
   `floor((n−1)/2)` обменов и `floor(n/2)` вращений? Проверяется
   `constructions/reflection_word.py` без нового кода.
