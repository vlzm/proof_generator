## 0. Определения

Двойной разрез `(q, c)`: ребро позиций {q, q+1} и сдвиг c. Линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1; цель — тождественная линия;
голова стартует в индексе `j0 = (−q−1) mod n`, заканчивает в `j1 = (c−q−1)
mod n`. Слово *линейное*, если голова не переходит и не обменивает через
разрез; *сокращённое*, если каждый обмен снимает инверсию (`N_X = inv(w)`).

- `I(pi) = min_{q,c} inv(w)` — по всем n^2 разрезам (эквивалентно: минимум
  инверсий по торическому классу pi — повороты позиций и значений).
- `d_line(pi)`, `d_walk(pi)`, `d_red(pi)`, `Rbest(pi)`, `Rfree(w)` — см.
  отчёты `line_model`, `line_rotation_budget`. Всегда
  `d <= d_walk <= d_line <= d_red`.

## 1. Что показали данные (исчерпывающе)

1. `I(pi) <= floor((n−1)^2/4)` при 4 <= n <= 10 (равенство — ровно n отражений).
2. `d(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 10; более того,
   `d_red(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 9: для каждой pi есть
   разрез с `inv = I(pi)` и сокращённое линейное слово с
   `N_rot <= floor(n^2/4)`. Максимум `Rbest = floor(n^2/4)` достигается на
   2, 4, 11, 11, 50, 111 входах (n = 4..9) — не только на отражениях.
3. Профиль `max_{I(pi) = I} d(pi)` (профиль `line_profile`): при I >= max − 1
   равен `I + floor(n^2/4)`, при n <~ I <= max − 2 — `I + floor(n^2/4) − 1`,
   при малых I — около `2I + n`. Бюджет вращений `floor(n^2/4)` требуется
   уже при I ≈ n.
4. `max_pi (d − 2I)` = 3, 3, 5, 6, 8, 10, 13 при n = 4..10: растёт не медленнее
   n − 1 (лемма B) и быстрее n (обмен блоков у антипода).
5. `max_w Rfree(w) = B_n − 1` при 4 <= n <= 9 — без выбора разреза бюджет
   вращений равен `B_n − 1` (лемма A, точно).
6. `d_walk = d` при n <= 7; при n = 8, 9 есть входы с `d_walk − d` до 4, 5
   (аффинные), но при `I >= max − 1` всегда `d_line = d`.
7. Индукция по одному элементу для п. 1 не проходит: при n = 8 аффинный вход
   `(0,5,2,7,4,1,6,3)` имеет I = 11, а все восемь его редукций (удаление
   элемента с контракцией позиций и значений) — I = 6, тогда как
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2) = 3`. Семейство
   разрезов «первый элемент линии имеет значение t» (n разрезов вместо n^2)
   тоже недостаточно ни при каком t (n = 5: `(0,2,4,1,3)`; n = 7:
   `(0,2,4,6,1,3,5)`).

## 2. Лемма A (универсальный маршрут линии; PROVED)

Для любой линии w из n позиций существует сокращённое линейное слово с
`N_X = inv(w)` и `N_rot = B_n − 1` (конец головы свободен; старт — ребро 0).
Оценка точна: полностью обращённая линия имеет `inv = B_n`, а в кратчайшем
слове `N_rot >= N_X − 1`.

Маршрут (`constructions/line_cocktail.py`): проход 1 по рёбрам 0, 1, ..., n−2;
проход 2 по n−3, ..., 0; проход 3 по 1, ..., n−4; проход 4 по n−5, ..., 1; …
(k-й проход содержит n − k рёбер, направления чередуются, каждый проход
начинается рядом с концом предыдущего). На каждом ребре обмен делается
тогда и только тогда, когда пара инвертирована. Всего `1 + 2 + … + (n−1) =
B_n` сравнений, длина пути `B_n − 1`.

Корректность: проход 1 переносит максимум на позицию n−1; проход 2 —
минимум позиций 0..n−2 на позицию 0; проход 3 — максимум позиций 1..n−2 на
n−2; и т. д. (шейкер-сортировка с сужающимися границами). После k проходов
`ceil(k/2)` наибольших и `floor(k/2)` наименьших элементов стоят на своих
местах, после n − 1 проходов — все. Каждый обмен снимает ровно одну инверсию,
поэтому обменов ровно `inv(w)`. ∎ Проверено эталонными ходами на всех линиях
при 4 <= n <= 8 (`checks/check_C34.py`, часть A).

Следствие. Для любой pi и любого разреза `d(pi) <= inv(w) + B_n − 1 + подход +
финал`. Это бесполезно для C15: вся экономия до `floor(n^2/4)` — в выборе
разреза (п. 1.5), а не в маршруте по данной линии.

## 3. Лемма B (антиподальная транспозиция; PROVED при чётных n >= 6, таблицы 4..10)

Пусть n = 2m чётно и `tau_n` — тождественная перестановка с обменянными
позициями m, m+1. Тогда `I(tau_n) = 1` и `d(tau_n) = n + 1`.

`I = 1`: разрез q = n−1, c = 0 даёт линию с одной инверсией; `I = 0` только у
поворотов тождественной. Верхняя оценка — слово `L^m X R^m` длины n + 1.

Нижняя оценка. Пусть слово сортирует tau_n и голова заканчивает в c; тогда
элемент e должен оказаться на позиции e + c. Для элемента e обозначим `t_e`
его суммарное знаковое смещение по обменам (каждый X даёт +1 одному и −1
другому участнику); `sum_e t_e = 0`, `N_X >= (1/2) sum_e |t_e|`, и
`t_e ≡ c (mod n)` при e ∉ {m, m+1}, `t_m ≡ c − 1`, `t_{m+1} ≡ c + 1`.

Случай c = 0. Если есть обмен на ребре m (антипод старта), голова проходит
0 → m → 0: `N_rot >= 2m = n`, `N_X >= 1`, итого >= n + 1. Если обменов на ребре
m нет, все обмены — соседние транспозиции пути `m+1, m+2, …, n−1, 0, …, m`
(окружность без ребра m), и их произведение как перестановка позиций равно
транспозиции концов этого пути, длина которой в порождающих пути равна
`2n − 3 >= n + 1`.

Случай c ≠ 0. Автоморфизм `p -> sigma_n o p o sigma_n` (PROBLEM §4.3) меняет
L и R местами, сохраняет tau_n (проверка: 1 − tau(1 − i) = i при i ∉ {m, m+1}
и меняет m, m+1 местами) и переводит c в −c; поэтому достаточно 1 <= c <= m.
Запишем `t_e = r_e + n·k_e`, `r_e` — остаток в [0, n): `sum r_e = (n−2)c +
(c−1) + (c+1) = nc`, значит `sum k_e = −c`. Стоимость `|t_e|` при k = 0 равна
r, при k = −1 — n − r, каждый следующий шаг |k| добавляет n; k > 0 стоит
n + r и требует лишнего уменьшения у другого элемента. Минимум `sum |t_e|`
достигается, когда ровно c элементов имеют k = −1 — те, у кого остатки
наибольшие: один с остатком c + 1 и c − 1 с остатком c:
`sum |t_e| >= nc + (n − 2c − 2) + (c − 1)(n − 2c) = 2cn − 2c^2 − 2`,
`N_X >= cn − c^2 − 1`. При 1 <= c <= m правая часть вогнута по c, на концах
`n − 2` (c = 1) и `m^2 − 1 >= n − 2` (c = m), так что `N_X >= n − 2`. В
кратчайшем слове нет XX, поэтому `N_rot >= N_X − 1` и длина `>= 2n − 5 >= n + 1`
при n >= 6. ∎ При n = 4 равенство `d = 5` — по таблице; `d = n + 1` при
n = 4, 6, 8, 10 сверено с таблицами (`check_C34.py`, часть B).

Следствие. Всякая оценка вида `d(pi) <= 2·I(pi) + g(n)`, верная при всех pi,
требует `g(n) >= n − 1` (чётные n). Критерий PLAN §8 (`g(n) <= floor(n/2) +
O(1)`) недостижим. Обмен блоков длины k у антипода даёт ещё больше:
`d − 2I` = 8 (n = 8, k = 2), 13 (n = 10, k = 3).

## 4. Лемма C (локальная оптимальность разреза)

Если (q, c) минимизирует inv, то линия w удовлетворяет
`sum_{j<k} w_j <= k(n−1)/2` для всех k (и симметрично для суффиксов), и то же
для обратной перестановки (`sum_{x<k} pos(x) <= k(n−1)/2`): сдвиг разреза
позиций на k переносит первые k элементов в конец, меняя inv на
`sum_{j<k} (n − 1 − 2 w_j)`; сдвиг разреза значений на k делает элементы
0..k−1 наибольшими, меняя inv на `sum_{x<k} (n − 1 − 2 pos(x))`. ∎

Этих условий недостаточно для `inv <= floor((n−1)^2/4)`: линия
`(0,5,4,3,2,1,6)` при n = 7 удовлетворяет всем им (суммы 0, 5, 9, 12, 14, 15
при порогах 0, 6, 9, 12, 15, 18; обратная — те же), но `inv = 10 > 9`; её
торический класс имеет I = 8 при несоседнем разрезе. Доказательство п. 1.1
должно использовать совместные сдвиги обоих разрезов.

## 5. Вердикт по H13

1. Исходная форма H13 («один неиспользуемый разрез достаточен для диаметра»)
   подтверждена конечно и уточнена: на слоях `B_n`, `B_n − 1` `d_line = d`
   при 4 <= n <= 9, но в общем случае обмены через все рёбра бывают нужны
   (n = 8, 9).
2. Критерий PLAN §8 — оценка `d <= 2I + g(n)` с `g(n) <= floor(n/2) + O(1)` —
   ложен (лемма B). Правильная форма — с наклоном 1:
   **H13′: `d(pi) <= I(pi) + floor(n^2/4)`**, распадающаяся на
   **H13-I: `I(pi) <= floor((n−1)^2/4)`** (чистая комбинаторика торических
   классов) и **H13-R: существует разрез с `inv = I(pi)` и сокращённое линейное
   слово с `N_rot <= floor(n^2/4)`** (бюджет вращений, не зависящий от I).
   `H13-I + H13-R => C15` по C12. Обе части VERIFIED (4 <= n <= 10 и 4 <= n <= 9),
   обе тесны.
3. «Доказуемая схема слова для линии с inv инверсиями и `N_rot <= inv + f`»
   (PLAN §8 п. (2)) не существует в нужной силе: бюджет вращений не убывает с
   inv (Rbest = floor(n^2/4) при I ≈ n), а без выбора разреза он равен
   `B_n − 1` (лемма A). Схема должна выбирать разрез; экстремальные маршруты
   разного вида (зигзаги на отражениях, холостые переходы на блочных входах).
4. Пункт (3) PLAN §8 (входы с `I > max − n/4`) не сводит задачу к конечному
   числу семейств: их 660 при n = 10 и они растут с n.

### 7.0 Тождество C(n,2) − floor((n−1)^2/4) = floor(n^2/4)

Передоказано (обе чётности): n = 2m — `C(n,2) = 2m^2 − m`,
`floor((n−1)^2/4) = floor((2m−1)^2/4) = m^2 − m`, разность `m^2 = floor(n^2/4)`.
n = 2m+1 — `C(n,2) = 2m^2 + m`, `floor((n−1)^2/4) = m^2`, разность
`m^2 + m = floor(n^2/4)`. Так что «инверсионная» (H13-I) и «неинверсионная»
(`max NonInv >= floor(n^2/4)`) формы H13-I действительно эквивалентны точно,
без округления — используется свободно ниже.

### 7.1 Лемма D (рекуррентность вращения) — PROVED

Идея сессии (см. постановку задачи) верна и доказывается элементарно, без
компьютера — компьютерная проверка (побайтовая, п. 7 выше) только подтверждает
алгебру.

**Лемма D.** Пусть s = (s_0, ..., s_{n−1}) — перестановка {0, ..., n−1} и
`R_k = (s_k, s_{k+1 mod n}, ..., s_{k−1 mod n})` — её циклический сдвиг на k.
Тогда `inv(R_{k+1}) − inv(R_k) = (n − 1) − 2 s_k`.

*Доказательство.* `R_{k+1}` получается из `R_k` переносом переднего элемента
`s_k` в конец (остальные n − 1 элементов сохраняют взаимный порядок — их
пары не меняют статус). В `R_k` элемент `s_k` стоит первым и даёт инверсию
с каждым из `s_k` элементов, которые меньше него (ровно `s_k` штук, так как
остальные значения — это `{0, ..., n−1} \ {s_k}`); в `R_{k+1}` он стоит
последним и даёт инверсию с каждым из `n − 1 − s_k` элементов, которые больше
него. Итого `inv(R_{k+1}) = inv(R_k) − s_k + (n − 1 − s_k)`. ∎

**Следствие (a-рекуррентность).** Для фиксированного b положим
`s = pi_b := ((pi(0)−b) mod n, ..., (pi(n−1)−b) mod n)` (перестановка
{0,...,n−1}, так как pi — биекция и сдвиг по модулю n — биекция значений).
Тогда `w^{a,b} = R_a(s)`, и лемма D с `NonInv = C(n,2) − inv` даёт

```
NonInv(a+1,b) − NonInv(a,b) = 2 r_a − (n − 1),   r_a = (pi(a) − b) mod n.
```

**Следствие (b-рекуррентность, двойственная форма).** Для фиксированного a
положим `t = (pi(a), pi(a+1 mod n), ..., pi(a+n−1 mod n))` (тоже
перестановка). Переход b -> b+1 заменяет каждое значение `t_j` на
`(t_j − 1) mod n` — это НЕ сдвиг позиций, а сдвиг значений: единственный
элемент, который «оборачивается» (был 0, стал n − 1), — это тот, что стоит на
позиции `j_0 = t^{-1}(0)` (относительно текущего b; в терминах исходного pi —
позиция значения b, т.е. `j_0 = (pi^{-1}(b) − a) mod n`). Ровно тот же
подсчёт, что в лемме D, но с ролями «позиция <-> значение» поменянными
местами (`t^{-1}` играет роль `s` из леммы D, а «сдвиг значений» играет роль
«сдвига позиций»), даёт симметричную формулу:

```
NonInv(a,b+1) − NonInv(a,b) = 2 r'_b − (n − 1),   r'_b = (pi^{-1}(b) − a) mod n.
```

(Строго: применить лемму D к перестановке `u = t^{-1}` — где стоит каждое
значение — рассуждая по инверсиям `u`, которые с точностью до дополнения
равны инверсиям `t`; выкладка идентична, поэтому не повторяется отдельно.)
Обе формулы проверены побайтово (`experiments/h13i_walk_attempt.py`,
функция `check_recurrence`) на всех pi при 4 <= n <= 8 и на выборках при
n = 9, 10, 12, 15 — расхождений нет. Значит для фиксированного b шаги
`NonInv(a+1,b) − NonInv(a,b)` при a = 0..n−1 — это в точности числа
`{2k − (n−1) : k = 0..n−1}` (набор D из постановки задачи) в порядке,
заданном последовательностью `r_0, ..., r_{n−1}` (перестановка {0,...,n−1});
аналогично по столбцам с `pi^{-1}`. Это подтверждает структурную идею
сессии полностью, но остаётся ТОЛЬКО тождеством: сама по себе она не
ограничивает диапазон блуждания снизу.

### 7.2 Пять кандидатных семейств размера O(n) — все НЕДОСТАТОЧНЫ

Испытаны как продолжение вычислительной идеи (найти явную формулу для
удачного (a, b) через семейство линейного размера вместо полного n^2):

| n | bound `floor((n−1)^2/4)` | diag: (a, pi(a)) | a=0, b любое | b=0, a любое | union | (t,t) |
|---|---|---|---|---|---|---|
| 4 | 2 | 3 | 2 | 2 | 2 | 4 |
| 5 | 4 | 6 | 4 | 4 | 4 | 6 |
| 6 | 6 | 10 | 6 | 6 | 6 | 10 |
| 7 | 9 | 15 | **10** | **10** | **10** | 12 |
| 8 | 12 | 21 | **13** | **13** | **13** | 17 |

Значение в ячейке — максимум по всем pi при данном n минимума `inv(w^{a,b})`
по разрезам семейства; жирным — где семейство впервые не покрывает границу.
`diag` (b = pi(a), n разрезов, «разрез в точке графика pi») — переоткрытие
уже отвергнутого случая «первый элемент = t» при t = 0 (§1.7), включено для
полноты; худший вход — отражение `pi_0 = (0, n−1, ..., 1)`. Два НОВЫХ (не
проверявшихся раньше) семейства — «a = 0 фиксировано, b любое» и
«b = 0 фиксировано, a любое» (по n разрезов; раньше проверяли только связку
«b = pi(0)», где a и b менялись вместе, а не эти два независимых семейства) —
ломаются уже при n = 7 на входе `(0,5,4,3,2,1,6)` (10 > 9) и при n = 8 на
`(0,6,5,3,4,2,1,7)` (13 > 12); их объединение (до 2n − 1 разрезов) не
помогает — оба семейства достигают одного и того же (недостаточного)
минимума на одних и тех же худших входах. `(t, t)` (диагональный сдвиг,
a = b) — хуже всех, ломается уже при n = 4. Вывод: обе координаты разреза
существенно нужно выбирать совместно; ни один естественный линейный срез
n^2 разрезов (теперь их проверено 7 разных, вместе с §1.7 и лемма C) не
достаточен.

### 7.3 Второй момент (RMS) тоже недостаточен

Проверено (Коши—Буняковский: `max_{a,b} NonInv >= sqrt(mean NonInv^2)`),
достаточен ли сам по себе второй момент распределения `NonInv(a,b)` по всем
n^2 разрезам:

| n | `floor(n^2/4)` | худший запас RMS − bound | худшая pi |
|---|---|---|---|
| 4 | 4 | −1.08 | (0,3,2,1) |
| 5 | 6 | −1.44 | (0,4,3,2,1) |
| 6 | 9 | −2.43 | (0,5,4,3,2,1) |
| 7 | 12 | −3.06 | (0,6,5,4,3,2,1) |
| 8 | 16 | −4.32 | (0,7,6,5,4,3,2,1) |

Худшие pi здесь — снова ровно отражения pi_0; запас отрицателен и растёт по
модулю с n (не эффект малых n). Значит и среднее (сессия 8), и
среднеквадратичное значение `NonInv` по всем n^2 разрезам для отражений лежат
ниже `floor(n^2/4)` — искомый максимум сосредоточен на «тяжёлом хвосте»
распределения (немногих пиках), не обнаруживаемом ни первым, ни вторым
моментом. Это исключает не только «наивное усреднение», но и любой чисто
моментный (без учёта порядка/структуры) аргумент через два первых момента.

### 7.4 Геометрическая переформулировка (для следующей сессии, не завершена)

Каждая пара точек `{(i, pi(i)), (j, pi(j))}` (i != j) даёт на торе `Z_n x Z_n`
одну из двух «диагональных» пар прямоугольников: обозначив `d_pos = (j−i)
mod n`, `d_val = (pi(j)−pi(i)) mod n` (взяв i, j в порядке, где эта разница
берётся; выбор i или j как «первого» не меняет результат — см. ниже), при
разрезе (a,b) пара НЕ инвертирована тогда и только тогда, когда (a,b) лежит
в объединении прямоугольников `(j,i] x (j,i]`-подобного вида площади
`d_pos*d_val + (n−d_pos)(n−d_val)` (точная форма выведена вручную, не
внесена в код). `NonInv(a,b)` — это в точности число пар, чьё прямоугольное
объединение покрывает точку (a,b); задача H13-I эквивалентна: у объединения
`C(n,2)` таких пар прямоугольников (полученных из точек перестановочной
матрицы) есть точка кратности >= `floor(n^2/4)`. Важное наблюдение: площадь
одной пары НЕ ограничена снизу величиной `~n^2/2` (она линейна по n на
«крайних» (d_pos, d_val), например `d_pos=1, d_val=n−1` даёт площадь
`2(n−1)`) — это объясняет, почему усреднение (сумма площадей / n^2) может
быть маленьким. Для отражений `d_val = n − d_pos` для КАЖДОЙ пары (одна и та
же диагональная связь), поэтому все C(n,2) прямоугольных объединений имеют
одинаковую «форму» относительно оси отражения — вероятно, отсюда и
концентрация максимума в одной точке (антипод/центр), которую не видно ни
среднему, ни RMS. Направление для следующей сессии: превратить это
наблюдение в доказательство (например, показать, что для отражений все
C(n,2) объединений содержат общую точку, и что отражения экстремальны по
некоторому обменному/перестановочному аргументу — см. §6). Не реализовано
и не проверено кодом — это записанное наблюдение, а не результат.

### 7.5 Итог сессии 9

H13-I **не доказана и не опровергнута** за отведённый бюджет (1 сессия).
Позитивный результат — лемма D (п. 7.1): рекуррентность блуждания из
постановки задачи доказана строго (не только проверена) в обе стороны
(по a и по b, с одинаковым мультимножеством шагов D для любого b и любого a
соответственно) — это уточняет и подтверждает структурную идею, с которой
начиналась сессия. Отрицательный результат — семь испытанных путей (пять

существенно использующий совместный выбор обеих координат разреза и, судя
по геометрической переформулировке (п. 7.4), структуру перекрытия C(n,2)
прямоугольников на торе. Задача остаётся открытой при общем n (VERIFIED
