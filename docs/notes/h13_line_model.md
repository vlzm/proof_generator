## 0. Определения

Двойной разрез `(q, c)`: ребро позиций {q, q+1} и сдвиг c. Линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1; цель — тождественная линия;
голова стартует в индексе `j0 = (−q−1) mod n`, заканчивает в `j1 = (c−q−1)
mod n`. Слово *линейное*, если голова не переходит и не обменивает через
разрез; *сокращённое*, если каждый обмен снимает инверсию (`N_X = inv(w)`).

- `I(pi) = min_{q,c} inv(w)` — по всем n^2 разрезам (эквивалентно: минимум
  инверсий по торическому классу pi — повороты позиций и значений).
- `d_line(pi)`, `d_walk(pi)`, `d_red(pi)`, `Rbest(pi)`, `Rfree(w)` — см.
  отчёты `line_model`, `line_rotation_budget`. Всегда
  `d <= d_walk <= d_line <= d_red`.

## 1. Что показали данные (исчерпывающе)

1. `I(pi) <= floor((n−1)^2/4)` при 4 <= n <= 10 (равенство — ровно n отражений).
2. `d(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 10; более того,
   `d_red(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 9: для каждой pi есть
   разрез с `inv = I(pi)` и сокращённое линейное слово с
   `N_rot <= floor(n^2/4)`. Максимум `Rbest = floor(n^2/4)` достигается на
   2, 4, 11, 11, 50, 111 входах (n = 4..9) — не только на отражениях.
3. Профиль `max_{I(pi) = I} d(pi)` (профиль `line_profile`): при I >= max − 1
   равен `I + floor(n^2/4)`, при n <~ I <= max − 2 — `I + floor(n^2/4) − 1`,
   при малых I — около `2I + n`. Бюджет вращений `floor(n^2/4)` требуется
   уже при I ≈ n.
4. `max_pi (d − 2I)` = 3, 3, 5, 6, 8, 10, 13 при n = 4..10: растёт не медленнее
   n − 1 (лемма B) и быстрее n (обмен блоков у антипода).
5. `max_w Rfree(w) = B_n − 1` при 4 <= n <= 9 — без выбора разреза бюджет
   вращений равен `B_n − 1` (лемма A, точно).
6. `d_walk = d` при n <= 7; при n = 8, 9 есть входы с `d_walk − d` до 4, 5
   (аффинные), но при `I >= max − 1` всегда `d_line = d`.
7. Индукция по одному элементу для п. 1 не проходит: при n = 8 аффинный вход
   `(0,5,2,7,4,1,6,3)` имеет I = 11, а все восемь его редукций (удаление
   элемента с контракцией позиций и значений) — I = 6, тогда как
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2) = 3`. Семейство
   разрезов «первый элемент линии имеет значение t» (n разрезов вместо n^2)
   тоже недостаточно ни при каком t (n = 5: `(0,2,4,1,3)`; n = 7:
   `(0,2,4,6,1,3,5)`).

## 2. Лемма A (универсальный маршрут линии; PROVED)

Для любой линии w из n позиций существует сокращённое линейное слово с
`N_X = inv(w)` и `N_rot = B_n − 1` (конец головы свободен; старт — ребро 0).
Оценка точна: полностью обращённая линия имеет `inv = B_n`, а в кратчайшем
слове `N_rot >= N_X − 1`.

Маршрут (`constructions/line_cocktail.py`): проход 1 по рёбрам 0, 1, ..., n−2;
проход 2 по n−3, ..., 0; проход 3 по 1, ..., n−4; проход 4 по n−5, ..., 1; …
(k-й проход содержит n − k рёбер, направления чередуются, каждый проход
начинается рядом с концом предыдущего). На каждом ребре обмен делается
тогда и только тогда, когда пара инвертирована. Всего `1 + 2 + … + (n−1) =
B_n` сравнений, длина пути `B_n − 1`.

Корректность: проход 1 переносит максимум на позицию n−1; проход 2 —
минимум позиций 0..n−2 на позицию 0; проход 3 — максимум позиций 1..n−2 на
n−2; и т. д. (шейкер-сортировка с сужающимися границами). После k проходов
`ceil(k/2)` наибольших и `floor(k/2)` наименьших элементов стоят на своих
местах, после n − 1 проходов — все. Каждый обмен снимает ровно одну инверсию,
поэтому обменов ровно `inv(w)`. ∎ Проверено эталонными ходами на всех линиях
при 4 <= n <= 8 (`checks/check_C34.py`, часть A).

Следствие. Для любой pi и любого разреза `d(pi) <= inv(w) + B_n − 1 + подход +
финал`. Это бесполезно для C15: вся экономия до `floor(n^2/4)` — в выборе
разреза (п. 1.5), а не в маршруте по данной линии.

## 3. Лемма B (антиподальная транспозиция; PROVED при чётных n >= 6, таблицы 4..10)

Пусть n = 2m чётно и `tau_n` — тождественная перестановка с обменянными
позициями m, m+1. Тогда `I(tau_n) = 1` и `d(tau_n) = n + 1`.

`I = 1`: разрез q = n−1, c = 0 даёт линию с одной инверсией; `I = 0` только у
поворотов тождественной. Верхняя оценка — слово `L^m X R^m` длины n + 1.

Нижняя оценка. Пусть слово сортирует tau_n и голова заканчивает в c; тогда
элемент e должен оказаться на позиции e + c. Для элемента e обозначим `t_e`
его суммарное знаковое смещение по обменам (каждый X даёт +1 одному и −1
другому участнику); `sum_e t_e = 0`, `N_X >= (1/2) sum_e |t_e|`, и
`t_e ≡ c (mod n)` при e ∉ {m, m+1}, `t_m ≡ c − 1`, `t_{m+1} ≡ c + 1`.

Случай c = 0. Если есть обмен на ребре m (антипод старта), голова проходит
0 → m → 0: `N_rot >= 2m = n`, `N_X >= 1`, итого >= n + 1. Если обменов на ребре
m нет, все обмены — соседние транспозиции пути `m+1, m+2, …, n−1, 0, …, m`
(окружность без ребра m), и их произведение как перестановка позиций равно
транспозиции концов этого пути, длина которой в порождающих пути равна
`2n − 3 >= n + 1`.

Случай c ≠ 0. Автоморфизм `p -> sigma_n o p o sigma_n` (PROBLEM §4.3) меняет
L и R местами, сохраняет tau_n (проверка: 1 − tau(1 − i) = i при i ∉ {m, m+1}
и меняет m, m+1 местами) и переводит c в −c; поэтому достаточно 1 <= c <= m.
Запишем `t_e = r_e + n·k_e`, `r_e` — остаток в [0, n): `sum r_e = (n−2)c +
(c−1) + (c+1) = nc`, значит `sum k_e = −c`. Стоимость `|t_e|` при k = 0 равна
r, при k = −1 — n − r, каждый следующий шаг |k| добавляет n; k > 0 стоит
n + r и требует лишнего уменьшения у другого элемента. Минимум `sum |t_e|`
достигается, когда ровно c элементов имеют k = −1 — те, у кого остатки
наибольшие: один с остатком c + 1 и c − 1 с остатком c:
`sum |t_e| >= nc + (n − 2c − 2) + (c − 1)(n − 2c) = 2cn − 2c^2 − 2`,
`N_X >= cn − c^2 − 1`. При 1 <= c <= m правая часть вогнута по c, на концах
`n − 2` (c = 1) и `m^2 − 1 >= n − 2` (c = m), так что `N_X >= n − 2`. В
кратчайшем слове нет XX, поэтому `N_rot >= N_X − 1` и длина `>= 2n − 5 >= n + 1`
при n >= 6. ∎ При n = 4 равенство `d = 5` — по таблице; `d = n + 1` при
n = 4, 6, 8, 10 сверено с таблицами (`check_C34.py`, часть B).

Следствие. Всякая оценка вида `d(pi) <= 2·I(pi) + g(n)`, верная при всех pi,
требует `g(n) >= n − 1` (чётные n). Критерий PLAN §8 (`g(n) <= floor(n/2) +
O(1)`) недостижим. Обмен блоков длины k у антипода даёт ещё больше:
`d − 2I` = 8 (n = 8, k = 2), 13 (n = 10, k = 3).

## 4. Лемма C (локальная оптимальность разреза)

Если (q, c) минимизирует inv, то линия w удовлетворяет
`sum_{j<k} w_j <= k(n−1)/2` для всех k (и симметрично для суффиксов), и то же
для обратной перестановки (`sum_{x<k} pos(x) <= k(n−1)/2`): сдвиг разреза
позиций на k переносит первые k элементов в конец, меняя inv на
`sum_{j<k} (n − 1 − 2 w_j)`; сдвиг разреза значений на k делает элементы
0..k−1 наибольшими, меняя inv на `sum_{x<k} (n − 1 − 2 pos(x))`. ∎

Этих условий недостаточно для `inv <= floor((n−1)^2/4)`: линия
`(0,5,4,3,2,1,6)` при n = 7 удовлетворяет всем им (суммы 0, 5, 9, 12, 14, 15
при порогах 0, 6, 9, 12, 15, 18; обратная — те же), но `inv = 10 > 9`; её
торический класс имеет I = 8 при несоседнем разрезе. Доказательство п. 1.1
должно использовать совместные сдвиги обоих разрезов.

## 5. Вердикт по H13

1. Исходная форма H13 («один неиспользуемый разрез достаточен для диаметра»)
   подтверждена конечно и уточнена: на слоях `B_n`, `B_n − 1` `d_line = d`
   при 4 <= n <= 9, но в общем случае обмены через все рёбра бывают нужны
   (n = 8, 9).
2. Критерий PLAN §8 — оценка `d <= 2I + g(n)` с `g(n) <= floor(n/2) + O(1)` —
   ложен (лемма B). Правильная форма — с наклоном 1:
   **H13′: `d(pi) <= I(pi) + floor(n^2/4)`**, распадающаяся на
   **H13-I: `I(pi) <= floor((n−1)^2/4)`** (чистая комбинаторика торических
   классов) и **H13-R: существует разрез с `inv = I(pi)` и сокращённое линейное
   слово с `N_rot <= floor(n^2/4)`** (бюджет вращений, не зависящий от I).
   `H13-I + H13-R => C15` по C12. Обе части VERIFIED (4 <= n <= 10 и 4 <= n <= 9),
   обе тесны.
3. «Доказуемая схема слова для линии с inv инверсиями и `N_rot <= inv + f`»
   (PLAN §8 п. (2)) не существует в нужной силе: бюджет вращений не убывает с
   inv (Rbest = floor(n^2/4) при I ≈ n), а без выбора разреза он равен
   `B_n − 1` (лемма A). Схема должна выбирать разрез; экстремальные маршруты
   разного вида (зигзаги на отражениях, холостые переходы на блочных входах).
4. Пункт (3) PLAN §8 (входы с `I > max − n/4`) не сводит задачу к конечному
   числу семейств: их 660 при n = 10 и они растут с n.

## 6. Следующий шаг (запись сессии 8)

Доказать H13-I отдельно (бюджет 1 сессия): утверждение о торических классах —
у каждой pi есть поворот позиций и значений с не более `floor((n−1)^2/4)`
инверсиями. Эквивалентная форма: у каждой pi есть двойной разрез с не менее
`floor(n^2/4)` неинверсий; в терминах точек `(i, pi(i))` на торе — точка
`(q, s)` тора, лежащая в «одноимённых» квадрантах не менее `floor(n^2/4)` пар.
Известно: усреднение по всем n^2 разрезам не работает (среднее для sigma_n
равно `(n^2 − 1)/6 < n^2/4` в форме максимума и `~n^2/3` для id в форме
минимума), индукция по одному элементу не работает (п. 1.7), локальные
условия недостаточны (лемма C). Кандидаты: сдвиги обоих разрезов вместе;
экстремальность отражений через леммы C32 (баланс дуг); литература о
торических классах перестановок. Если H13-I доказана — H13-R остаётся
эквивалентом C15 при известном N_X и переходит в задачу о маршрутах; если
нет за сессию — переход к индукции H3 (PLAN §4.3).

### 7.1. Формула площади «квадрантов» (вывод, не новый факт)

Для пары позиций `i != j`, `d = (j − i) mod n`, `e = (pi(j) − pi(i)) mod n`
(оба в `{1, ..., n−1}`), число разрезов `(a, b)` из `n^2`, на которых пара
`{i, j}` — неинверсия, равно `(n − d)(n − e) + d*e`, инверсия —
`n(d + e) − 2de`. Проверено прямым подсчётом (согласуется с `inv(a, b)` по
всем малым n). Формализует «одноимённые квадранты» из §6: неинверсия — это
объединение двух прямоугольников `[0, n−d) x [0, n−e)` и `[n−d, n) x [n−e, n)`
в координатах (позиция a внутри своих n значений, значение b внутри своих n
значений), контрпример к прямому усреднению остаётся в силе (сумма по парам
`n(d+e) − 2de`, деление на n^2 даёt слишком большое среднее).

### 7.2. Проверена и отвергнута новая редукция: «один свободный параметр»

Гипотеза (не проверявшаяся в сессии 8): не нужен полный перебор `n^2`
разрезов — достаточно зафиксировать разрез позиций `a = 0` и перебирать
только сдвиг значений `b` (n вариантов), либо взять `b` как явную функцию
`f(pi, a)` от разреза позиций (тоже n вариантов). Это дало бы прямую
индукцию/экстремальный аргумент по одному параметру.

Результат (`experiments/h13i_coupling.py`, `experiments/h13i_search.py`,
отчёт `data/runs/h13i_coupling/report.md`):

1. **Фиксированный `a = 0`, перебор только `b`**: исчерпывающе
   4 <= n <= 9 — превышает `floor((n−1)^2/4)` уже при n = 7, 8, 9 (10 против
   9, 13 против 12, 17 против 16 — разрыв `+1`, худшие входы не отражения,
   например `(0, 5, 4, 3, 2, 1, 6)` при n = 7). Направленный локальный поиск
   (2-opt от развёрнутой перестановки, `experiments/h13i_search.py`,
   seed = 2, 4000 шагов) находит входы с растущим разрывом: `+1` (n = 9),
   `+3` (n = 12), `+6` (n = 15), `+14` (n = 20), `+22` (n = 25), `+32`
   (n = 30) — разрыв растёт **не медленнее линейно по n** (не O(1)).
   Вывод: фиксация одного разреза и перебор только второго недостаточны ни
   при каком фиксированном первом разрезе в общем случае — нужна совместная
   (2-параметрическая) оптимизация. На самих отражениях (экстремали I(pi))
   разрыв, напротив, всегда 0 (проверено 10 <= n <= 100, все h) — так что
   контрпримеры к редукции лежат вне известного экстремального семейства.
2. **Явные правила `b = f(pi, a)`** (`b = pi(a)`, `b = pi(a) − 1`,
   `b = pi(a−1) + 1`, т. е. разрез значений выбирается так, чтобы линия
   начиналась с фиксированного значения относительно разреза позиций):
   существенно хуже — на развороте (`rev_n`) не сокращают почти ничего
   (например n = 9: разрыв до `+12`, худший случай достигает `C(n, 2)` —
   рассматриваемые n кандидатов не бьют ни одной инверсии на некоторых
   входах). Отвергнуто без дальнейшего рассмотрения.

### 7.3. Вердикт сессии 9

H13-I не доказана и не опровергнута за сессию (бюджет 1 сессия исчерпан).
Новое: семейство «один свободный параметр» (в любой из проверенных форм)
формально исключено как путь к доказательству — разрыв растёт минимум
линейно по n, не O(1). Это сужает пространство: нужна конструкция или
аргумент, где оба параметра `(a, b)` выбираются совместно и зависимо от pi
(не через явную функцию одного от другого при переборе только оставшегося
диапазона значений второго). Кандидаты не проверены за сессию:
одновременный сдвиг обоих разрезов малыми шагами с обоснованием
монотонности (не локальный, а глобальный аргумент — простая локальная
оптимальность уже отвергнута леммой C); анализ через Фурье/дискретный
дисбаланс на торе `Z_n x Z_n`, используя формулу §7.1 (сумма по парам —
билинейная по индикаторам дуг, что открывает путь к оценке через
характеры, не опробовано). Следующая сессия — на выбор: (а) попытка
Фурье/дисбаланс-аргумента для H13-I ещё раз, бюджет 1 сессия; (б) переход к
индукции H3 (PLAN §4.3, независимый путь к C15 без линейной модели).
