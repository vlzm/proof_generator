# H13 — линейная модель: профиль, бюджет вращений, вердикт

Дата: 13.09.2026 (сессия 8). Ядро oracle-1.0, таблицы C2v (4 <= n <= 10).
Код: `experiments/line_profile.c`, `experiments/line_rotation_budget.py`,
`experiments/line_model.py` (1.1), `constructions/line_cocktail.py`,
`checks/check_C34.py`. Отчёты: `data/runs/line_profile/`,
`data/runs/line_rotation_budget/`, `data/runs/line_model/`,
`data/runs/check_C34/`.

## 0. Определения

Двойной разрез `(q, c)`: ребро позиций {q, q+1} и сдвиг c. Линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1; цель — тождественная линия;
голова стартует в индексе `j0 = (−q−1) mod n`, заканчивает в `j1 = (c−q−1)
mod n`. Слово *линейное*, если голова не переходит и не обменивает через
разрез; *сокращённое*, если каждый обмен снимает инверсию (`N_X = inv(w)`).

- `I(pi) = min_{q,c} inv(w)` — по всем n^2 разрезам (эквивалентно: минимум
  инверсий по торическому классу pi — повороты позиций и значений).
- `d_line(pi)`, `d_walk(pi)`, `d_red(pi)`, `Rbest(pi)`, `Rfree(w)` — см.
  отчёты `line_model`, `line_rotation_budget`. Всегда
  `d <= d_walk <= d_line <= d_red`.

## 1. Что показали данные (исчерпывающе)

1. `I(pi) <= floor((n−1)^2/4)` при 4 <= n <= 10 (равенство — ровно n отражений).
2. `d(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 10; более того,
   `d_red(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 9: для каждой pi есть
   разрез с `inv = I(pi)` и сокращённое линейное слово с
   `N_rot <= floor(n^2/4)`. Максимум `Rbest = floor(n^2/4)` достигается на
   2, 4, 11, 11, 50, 111 входах (n = 4..9) — не только на отражениях.
3. Профиль `max_{I(pi) = I} d(pi)` (профиль `line_profile`): при I >= max − 1
   равен `I + floor(n^2/4)`, при n <~ I <= max − 2 — `I + floor(n^2/4) − 1`,
   при малых I — около `2I + n`. Бюджет вращений `floor(n^2/4)` требуется
   уже при I ≈ n.
4. `max_pi (d − 2I)` = 3, 3, 5, 6, 8, 10, 13 при n = 4..10: растёт не медленнее
   n − 1 (лемма B) и быстрее n (обмен блоков у антипода).
5. `max_w Rfree(w) = B_n − 1` при 4 <= n <= 9 — без выбора разреза бюджет
   вращений равен `B_n − 1` (лемма A, точно).
6. `d_walk = d` при n <= 7; при n = 8, 9 есть входы с `d_walk − d` до 4, 5
   (аффинные), но при `I >= max − 1` всегда `d_line = d`.
7. Индукция по одному элементу для п. 1 не проходит: при n = 8 аффинный вход
   `(0,5,2,7,4,1,6,3)` имеет I = 11, а все восемь его редукций (удаление
   элемента с контракцией позиций и значений) — I = 6, тогда как
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2) = 3`. Семейство
   разрезов «первый элемент линии имеет значение t» (n разрезов вместо n^2)
   тоже недостаточно ни при каком t (n = 5: `(0,2,4,1,3)`; n = 7:
   `(0,2,4,6,1,3,5)`).

## 2. Лемма A (универсальный маршрут линии; PROVED)

Для любой линии w из n позиций существует сокращённое линейное слово с
`N_X = inv(w)` и `N_rot = B_n − 1` (конец головы свободен; старт — ребро 0).
Оценка точна: полностью обращённая линия имеет `inv = B_n`, а в кратчайшем
слове `N_rot >= N_X − 1`.

Маршрут (`constructions/line_cocktail.py`): проход 1 по рёбрам 0, 1, ..., n−2;
проход 2 по n−3, ..., 0; проход 3 по 1, ..., n−4; проход 4 по n−5, ..., 1; …
(k-й проход содержит n − k рёбер, направления чередуются, каждый проход
начинается рядом с концом предыдущего). На каждом ребре обмен делается
тогда и только тогда, когда пара инвертирована. Всего `1 + 2 + … + (n−1) =
B_n` сравнений, длина пути `B_n − 1`.

Корректность: проход 1 переносит максимум на позицию n−1; проход 2 —
минимум позиций 0..n−2 на позицию 0; проход 3 — максимум позиций 1..n−2 на
n−2; и т. д. (шейкер-сортировка с сужающимися границами). После k проходов
`ceil(k/2)` наибольших и `floor(k/2)` наименьших элементов стоят на своих
местах, после n − 1 проходов — все. Каждый обмен снимает ровно одну инверсию,
поэтому обменов ровно `inv(w)`. ∎ Проверено эталонными ходами на всех линиях
при 4 <= n <= 8 (`checks/check_C34.py`, часть A).

Следствие. Для любой pi и любого разреза `d(pi) <= inv(w) + B_n − 1 + подход +
финал`. Это бесполезно для C15: вся экономия до `floor(n^2/4)` — в выборе
разреза (п. 1.5), а не в маршруте по данной линии.

## 3. Лемма B (антиподальная транспозиция; PROVED при чётных n >= 6, таблицы 4..10)

Пусть n = 2m чётно и `tau_n` — тождественная перестановка с обменянными
позициями m, m+1. Тогда `I(tau_n) = 1` и `d(tau_n) = n + 1`.

`I = 1`: разрез q = n−1, c = 0 даёт линию с одной инверсией; `I = 0` только у
поворотов тождественной. Верхняя оценка — слово `L^m X R^m` длины n + 1.

Нижняя оценка. Пусть слово сортирует tau_n и голова заканчивает в c; тогда
элемент e должен оказаться на позиции e + c. Для элемента e обозначим `t_e`
его суммарное знаковое смещение по обменам (каждый X даёт +1 одному и −1
другому участнику); `sum_e t_e = 0`, `N_X >= (1/2) sum_e |t_e|`, и
`t_e ≡ c (mod n)` при e ∉ {m, m+1}, `t_m ≡ c − 1`, `t_{m+1} ≡ c + 1`.

Случай c = 0. Если есть обмен на ребре m (антипод старта), голова проходит
0 → m → 0: `N_rot >= 2m = n`, `N_X >= 1`, итого >= n + 1. Если обменов на ребре
m нет, все обмены — соседние транспозиции пути `m+1, m+2, …, n−1, 0, …, m`
(окружность без ребра m), и их произведение как перестановка позиций равно
транспозиции концов этого пути, длина которой в порождающих пути равна
`2n − 3 >= n + 1`.

Случай c ≠ 0. Автоморфизм `p -> sigma_n o p o sigma_n` (PROBLEM §4.3) меняет
L и R местами, сохраняет tau_n (проверка: 1 − tau(1 − i) = i при i ∉ {m, m+1}
и меняет m, m+1 местами) и переводит c в −c; поэтому достаточно 1 <= c <= m.
Запишем `t_e = r_e + n·k_e`, `r_e` — остаток в [0, n): `sum r_e = (n−2)c +
(c−1) + (c+1) = nc`, значит `sum k_e = −c`. Стоимость `|t_e|` при k = 0 равна
r, при k = −1 — n − r, каждый следующий шаг |k| добавляет n; k > 0 стоит
n + r и требует лишнего уменьшения у другого элемента. Минимум `sum |t_e|`
достигается, когда ровно c элементов имеют k = −1 — те, у кого остатки
наибольшие: один с остатком c + 1 и c − 1 с остатком c:
`sum |t_e| >= nc + (n − 2c − 2) + (c − 1)(n − 2c) = 2cn − 2c^2 − 2`,
`N_X >= cn − c^2 − 1`. При 1 <= c <= m правая часть вогнута по c, на концах
`n − 2` (c = 1) и `m^2 − 1 >= n − 2` (c = m), так что `N_X >= n − 2`. В
кратчайшем слове нет XX, поэтому `N_rot >= N_X − 1` и длина `>= 2n − 5 >= n + 1`
при n >= 6. ∎ При n = 4 равенство `d = 5` — по таблице; `d = n + 1` при
n = 4, 6, 8, 10 сверено с таблицами (`check_C34.py`, часть B).

Следствие. Всякая оценка вида `d(pi) <= 2·I(pi) + g(n)`, верная при всех pi,
требует `g(n) >= n − 1` (чётные n). Критерий PLAN §8 (`g(n) <= floor(n/2) +
O(1)`) недостижим. Обмен блоков длины k у антипода даёт ещё больше:
`d − 2I` = 8 (n = 8, k = 2), 13 (n = 10, k = 3).

## 4. Лемма C (локальная оптимальность разреза)

Если (q, c) минимизирует inv, то линия w удовлетворяет
`sum_{j<k} w_j <= k(n−1)/2` для всех k (и симметрично для суффиксов), и то же
для обратной перестановки (`sum_{x<k} pos(x) <= k(n−1)/2`): сдвиг разреза
позиций на k переносит первые k элементов в конец, меняя inv на
`sum_{j<k} (n − 1 − 2 w_j)`; сдвиг разреза значений на k делает элементы
0..k−1 наибольшими, меняя inv на `sum_{x<k} (n − 1 − 2 pos(x))`. ∎

Этих условий недостаточно для `inv <= floor((n−1)^2/4)`: линия
`(0,5,4,3,2,1,6)` при n = 7 удовлетворяет всем им (суммы 0, 5, 9, 12, 14, 15
при порогах 0, 6, 9, 12, 15, 18; обратная — те же), но `inv = 10 > 9`; её
торический класс имеет I = 8 при несоседнем разрезе. Доказательство п. 1.1
должно использовать совместные сдвиги обоих разрезов.

## 5. Вердикт по H13

1. Исходная форма H13 («один неиспользуемый разрез достаточен для диаметра»)
   подтверждена конечно и уточнена: на слоях `B_n`, `B_n − 1` `d_line = d`
   при 4 <= n <= 9, но в общем случае обмены через все рёбра бывают нужны
   (n = 8, 9).
2. Критерий PLAN §8 — оценка `d <= 2I + g(n)` с `g(n) <= floor(n/2) + O(1)` —
   ложен (лемма B). Правильная форма — с наклоном 1:
   **H13′: `d(pi) <= I(pi) + floor(n^2/4)`**, распадающаяся на
   **H13-I: `I(pi) <= floor((n−1)^2/4)`** (чистая комбинаторика торических
   классов) и **H13-R: существует разрез с `inv = I(pi)` и сокращённое линейное
   слово с `N_rot <= floor(n^2/4)`** (бюджет вращений, не зависящий от I).
   `H13-I + H13-R => C15` по C12. Обе части VERIFIED (4 <= n <= 10 и 4 <= n <= 9),
   обе тесны.
3. «Доказуемая схема слова для линии с inv инверсиями и `N_rot <= inv + f`»
   (PLAN §8 п. (2)) не существует в нужной силе: бюджет вращений не убывает с
   inv (Rbest = floor(n^2/4) при I ≈ n), а без выбора разреза он равен
   `B_n − 1` (лемма A). Схема должна выбирать разрез; экстремальные маршруты
   разного вида (зигзаги на отражениях, холостые переходы на блочных входах).
4. Пункт (3) PLAN §8 (входы с `I > max − n/4`) не сводит задачу к конечному
   числу семейств: их 660 при n = 10 и они растут с n.

### 7.1. Лемма D (тождество суммы по всем n^2 разрезам; PROVED)

Для любых двух различных позиций `i, j` положим `dx = (j − i) mod n`,
`dy = (pi(j) − pi(i)) mod n` (оба в `{1, ..., n − 1}`; неупорядоченная пара
{i, j} даёт одно и то же `f` при любом выборе, кто из них `i`, а кто `j`,
см. ниже). Тогда

```text
sum_{(q,c) in Z_n x Z_n} inv(w_{q,c}) = sum_{{i,j}} f(dx, dy),
f(dx, dy) = n(dx + dy) − 2 dx dy.
```

Доказательство. Зафиксируем неупорядоченную пару позиций {i, j}. При
изменении q позиция i предшествует j в чтении от разреза ровно для `n − dx`
из n значений q (стандартный факт про циклическое чтение: `x` предшествует
`x'` тогда и только тогда, когда `(x − q − 1) mod n < (x' − q − 1) mod n`,
что выполняется для `n − dx` значений q, где `dx = (x' − x) mod n`); для
оставшихся `dx` значений q — j предшествует i. Аналогично при изменении c:
значение `pi(i)` после сдвига c меньше значения `pi(j)` для `n − dy` из n
значений c, больше — для `dy`. Пара {i, j} инвертирована в `w_{q,c}` тогда
и только тогда, когда порядок по позиции не совпадает с порядком по
значению; по независимости выбора q и c число таких (q, c) равно

```text
(n − dx)*dy + dx*(n − dy) = n(dx + dy) − 2 dx dy = f(dx, dy).
```

Замена `i <-> j` меняет `dx -> n − dx`, `dy -> n − dy`; подстановка в f даёт
то же значение (раскрыть скобки), значит f от пары определено однозначно.
Суммируя по всем C(n,2) парам и меняя порядок суммирования (сумма по (q,c)
пар инверсий = сумма по парам числа (q,c), на которых они инвертированы),
получаем тождество. ∎ Проверено на случайных pi при 3 <= n <= 8 (по 5 pi на
n, точное совпадение сравнением брутфорса по всем n^2 разрезам и закрытой
формы), `checks/check_H13I_session9.py`, часть 2.

Значение для задачи: даёт точную (не приближённую) формулу среднего
`avg_{q,c} inv = (1/n^2) sum_{i<j} f(dx_{ij}, dy_{ij})`, объясняя, почему
усреднение проваливается (см. п. 6) — f растёт квадратично по обоим
аргументам с отрицательным членом `−2 dx dy`, максимизируется при
`dx, dy` близких к `n/2` одновременно для многих пар сразу (что и
происходит у sigma_n: `dy ≈ n − dx` для большинства пар), но минимум по
(q,c) — не средняя, а существенно меньшая величина; тождество само по себе
не даёт оценки минимума, только точную сумму. Не использовано дальше в этой
сессии за нехваткой времени; кандидат для session 10 — anti-concentration
или выпуклый анализ f по многомерному распределению (dx, dy) пар данной pi.

### 7.2. Лемма E (симметрия `I(pi) = I(pi^{-1})`; PROVED, набросок)

Для всех pi: `I(pi) = I(pi^{-1})`. Набросок: определение I(pi) через
инвертированные пары {i, j} по позиции и значению симметрично относительно
замены ролей «позиция» <-> «значение» (замена pi на pi^{-1} переставляет
координаты точек `(i, pi(i)) -> (pi(i), i)` на торе, что то же самое
множество точек с переставленными осями; разрез (q, c) заменяется на разрез
(c − 1, q + 1) той же формы, и число инвертированных пар не меняется —
проверяется прямой подстановкой в определение w). Проверено исчерпывающе
при 3 <= n <= 7 (все pi; `checks/check_H13I_session9.py`, часть 3). Полезно
для сокращения будущего перебора вдвое и как структурная подсказка
(отражения — единственный класс, инвариантный относительно этой симметрии
одновременно с автоморфизмом sigma_n из PROBLEM §4.3, что согласуется с
их экстремальностью).

### 7.3. Два новых опровергнутых упрощения: семейства с одной степенью свободы

Кандидат: не искать по всем n^2 разрезам, а зафиксировать одну из двух
свобод и искать минимум только по другой (n разрезов вместо n^2), что дало
бы H13-I как элементарное следствие (одна степень свободы явно достижима
перебором/явной формулой). Проверены оба варианта:

- `G(pi) = min_q inv(pi, прочитанная от q, без сдвига значений)` — поворот
  только позиций (значения — буквальные метки 0..n−1, без переразметки).
  Совпадает с расстоянием «отсортировать n точек на окружности с
  фиксированными метками соседними обменами» (см. п. 7.5).
- `J(pi) = min_c inv((pi − c) mod n)` — поворот только значений, позиции
  читаются в исходном порядке (q = n − 1 фиксирован).

Оба **не ограничены `floor((n−1)^2/4)`**: `max_pi G = 2, 4, 6, 10, 13, 17`
и `max_pi J` — те же числа при n = 4..9 (совпадение G и J по максимуму — не
случайность, следствие леммы E: J для pi равно G для pi^{-1} с точностью до
переиндексации, проверено численно). Оба впервые превышают
`floor((n−1)^2/4)` (= 9) ровно при **n = 7**, и оба достигают максимума на
**той же перестановке `(0,5,4,3,2,1,6)`**, что и контрпример леммы C (§4) —
не совпадение: это тот самый вход, у которого локально-оптимальный разрез
не соседний, то есть ни одно из двух «одномерных» приближений (только q,
только c) не видит его настоящий минимизирующий разрез. Вывод: обе степени
свободы (q и c) существенны совместно начиная с n = 7; никакое сведение к n
попыткам вместо n^2 из уже проверенных не работает. Проверено исчерпывающе
4 <= n <= 9, `checks/check_H13I_session9.py`, часть 4.

### 7.4. Рекурсивный аргумент «деление пополам по значению» — куда упирается

Естественный кандидат в духе намёка «литература о торических классах» (см.
7.5): зафиксировать сдвиг c, разбить n точек на «нижнюю» половину L (m =
floor(n/2) точек с наименьшими n−c-сдвинутыми значениями) и «верхнюю» H;
подобрать q так, чтобы L (или H) стала непрерывной дугой позиций, и
рекурсивно оценить `I` внутри каждой половины по индукции. Препятствие,
найденное при разборе (не преодолено): множество L для фиксированного c —
произвольное m-подмножество позиций, как правило не дуга; выбор q даёт
n возможных «точек разреза» дуги L (по одной на каждую граничную позицию
L/H), но это **позиционная** свобода без сопутствующей свободы по
значениям внутри L (значения L при фиксированном c уже зафиксированы как
блок `{c, ..., c+m−1}` без дальнейшего вращения) — то есть рекурсия
получила бы только «G-тип» свободы для суб-блока L, а этого недостаточно
(п. 7.3, семейство G нарушается уже при m = 7). Одновременный перебор c
(дающий n разных блоков L, не просто n поворотов одного и того же L)
может давать больше свободы, чем кажется на первый взгляд, но формализовать
это за бюджет сессии не удалось; это первое, что стоит пробовать в
session 10 (см. п. 7.7).

### 7.5. Внешний источник: вероятно, задача уже решена (arXiv:2502.14398)

Веб-поиск (WebSearch, доступ к полному тексту заблокирован сетевым прокси
среды — `arxiv.org`, `sciencedirect.com`, `princeton.edu` и другие домены
не проходят через `$HTTPS_PROXY`, см. `curl -sS $HTTPS_PROXY/__agentproxy/status`)
нашёл прямое совпадение по формулировке и константе:

> R. M. Adin, N. Alon, Y. Roichman, **«Circular sorting»**, arXiv:2502.14398
> (версия v1, доступна также правка `arXiv:2608.06338` «Circular sorting in
> the alternating group» и слайды доклада, июль 2026). По выдержкам из
> поисковика: «We determine the maximal number of steps required to sort n
> labeled points on a circle by adjacent swaps... For adjacent swaps, the
> worst-case distance is exactly `floor((n−1)^2/4)`... A different type of
> cyclic order, called toric order, was introduced by Develin, Macauley and
> Reiner [Toric partial orders, Trans. AMS 368 (2016), 2263–2287]... the
> toric class of pi comprises `(n+1)^2` permutations in general... proof
> uses a divide-and-conquer argument, splitting the circle into arcs and
> using the discrete intermediate value theorem to show that one can always
> find a partition where "small" and "large" labels are balanced».

Статус источника: **CLAIMED, аудит не выполнен** (текст статьи не получен —
все попытки WebFetch и `curl` на `arxiv.org`, `ar5iv.labs.arxiv.org`,
`web.math.princeton.edu`, `export.arxiv.org`, `www.semanticscholar.org` и
другие домены отклонены прокси среды с `CONNECT tunnel failed, 403`; поиск
через WebSearch дал только фрагменты выдачи, не полный текст). Формулировка
«sort n labeled points on a circle by adjacent swaps», взятая буквально
(фиксированные метки, поворот только чтения = только q), — это ровно
семейство G из п. 7.3, которое **не** удовлетворяет `floor((n−1)^2/4)` уже
при n = 7 (наш прямой расчёт); значит либо (а) их «distance» — не G, а
настоящее циклическое кэли-расстояние по образующим транспозициям окружности
(которое сортирует до ЛЮБОГО поворота меток и может быть строго меньше
`min_q inv`, потому что последовательность обменов не обязана избегать ни
одного фиксированного ребра — это открытый для нас вопрос, не решённый
в этой сессии), либо (б) их модель включает и поворот меток (что ближе к
I(pi)). Название «toric order» (Develin–Macauley–Reiner) и упоминание
«(n+1)^2» скорее говорит в пользу (б)/полного тождества с торическим
классом, что делает эту статью весьма вероятным источником доказательства
H13-I (возможно, дословного). До получения полного текста нельзя ни
объявить H13-I доказанной, ни использовать их метод — только
зарегистрировать источник (PROBLEM §6.1, S3) и указать это как первый шаг
session 10.

### 7.6. Расширенная проверка: 4 <= n <= 13 исчерпывающе (было 4 <= n <= 10)

Новая реализация `experiments/line_profile_fast.c` (`line_profile_fast-1.0`)
считает I(pi) за `O(n^2)` на перестановку вместо `O(n^4)` у эталонного
`experiments/line_profile.c` (амортизированный пересчёт `inv` при сдвиге q
или c на 1 вместо полного пересчёта; обе формулы для Δinv стандартные и
выведены в комментариях кода). Сверена с эталоном побайтово по гистограмме
`I` при 4 <= n <= 9 (`checks/check_H13I_session9.py`, часть 1; правило 3).
Результат (`data/runs/line_profile_fast/`, отчёт `report.md`):
`max_pi I(pi) = floor((n − 1)^2/4)` ровно при **4 <= n <= 13** (n = 11: 25 за
10 с; n = 12: 30 за 135 с; n = 13: 36 за ~33 мин фоном), без единого
исключения; argmax всегда `rev_n` (отражение h = n − 1).
