## 0. Определения

Двойной разрез `(q, c)`: ребро позиций {q, q+1} и сдвиг c. Линия
`w_j = pi(q+1+j) − (q+1−c) mod n`, j = 0..n−1; цель — тождественная линия;
голова стартует в индексе `j0 = (−q−1) mod n`, заканчивает в `j1 = (c−q−1)
mod n`. Слово *линейное*, если голова не переходит и не обменивает через
разрез; *сокращённое*, если каждый обмен снимает инверсию (`N_X = inv(w)`).

- `I(pi) = min_{q,c} inv(w)` — по всем n^2 разрезам (эквивалентно: минимум
  инверсий по торическому классу pi — повороты позиций и значений).
- `d_line(pi)`, `d_walk(pi)`, `d_red(pi)`, `Rbest(pi)`, `Rfree(w)` — см.
  отчёты `line_model`, `line_rotation_budget`. Всегда
  `d <= d_walk <= d_line <= d_red`.

## 1. Что показали данные (исчерпывающе)

1. `I(pi) <= floor((n−1)^2/4)` при 4 <= n <= 10 (равенство — ровно n отражений).
2. `d(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 10; более того,
   `d_red(pi) <= I(pi) + floor(n^2/4)` при 4 <= n <= 9: для каждой pi есть
   разрез с `inv = I(pi)` и сокращённое линейное слово с
   `N_rot <= floor(n^2/4)`. Максимум `Rbest = floor(n^2/4)` достигается на
   2, 4, 11, 11, 50, 111 входах (n = 4..9) — не только на отражениях.
3. Профиль `max_{I(pi) = I} d(pi)` (профиль `line_profile`): при I >= max − 1
   равен `I + floor(n^2/4)`, при n <~ I <= max − 2 — `I + floor(n^2/4) − 1`,
   при малых I — около `2I + n`. Бюджет вращений `floor(n^2/4)` требуется
   уже при I ≈ n.
4. `max_pi (d − 2I)` = 3, 3, 5, 6, 8, 10, 13 при n = 4..10: растёт не медленнее
   n − 1 (лемма B) и быстрее n (обмен блоков у антипода).
5. `max_w Rfree(w) = B_n − 1` при 4 <= n <= 9 — без выбора разреза бюджет
   вращений равен `B_n − 1` (лемма A, точно).
6. `d_walk = d` при n <= 7; при n = 8, 9 есть входы с `d_walk − d` до 4, 5
   (аффинные), но при `I >= max − 1` всегда `d_line = d`.
7. Индукция по одному элементу для п. 1 не проходит: при n = 8 аффинный вход
   `(0,5,2,7,4,1,6,3)` имеет I = 11, а все восемь его редукций (удаление
   элемента с контракцией позиций и значений) — I = 6, тогда как
   `floor((n−1)^2/4) − floor((n−2)^2/4) = floor((n−1)/2) = 3`. Семейство
   разрезов «первый элемент линии имеет значение t» (n разрезов вместо n^2)
   тоже недостаточно ни при каком t (n = 5: `(0,2,4,1,3)`; n = 7:
   `(0,2,4,6,1,3,5)`).

## 2. Лемма A (универсальный маршрут линии; PROVED)

Для любой линии w из n позиций существует сокращённое линейное слово с
`N_X = inv(w)` и `N_rot = B_n − 1` (конец головы свободен; старт — ребро 0).
Оценка точна: полностью обращённая линия имеет `inv = B_n`, а в кратчайшем
слове `N_rot >= N_X − 1`.

Маршрут (`constructions/line_cocktail.py`): проход 1 по рёбрам 0, 1, ..., n−2;
проход 2 по n−3, ..., 0; проход 3 по 1, ..., n−4; проход 4 по n−5, ..., 1; …
(k-й проход содержит n − k рёбер, направления чередуются, каждый проход
начинается рядом с концом предыдущего). На каждом ребре обмен делается
тогда и только тогда, когда пара инвертирована. Всего `1 + 2 + … + (n−1) =
B_n` сравнений, длина пути `B_n − 1`.

Корректность: проход 1 переносит максимум на позицию n−1; проход 2 —
минимум позиций 0..n−2 на позицию 0; проход 3 — максимум позиций 1..n−2 на
n−2; и т. д. (шейкер-сортировка с сужающимися границами). После k проходов
`ceil(k/2)` наибольших и `floor(k/2)` наименьших элементов стоят на своих
местах, после n − 1 проходов — все. Каждый обмен снимает ровно одну инверсию,
поэтому обменов ровно `inv(w)`. ∎ Проверено эталонными ходами на всех линиях
при 4 <= n <= 8 (`checks/check_C34.py`, часть A).

Следствие. Для любой pi и любого разреза `d(pi) <= inv(w) + B_n − 1 + подход +
финал`. Это бесполезно для C15: вся экономия до `floor(n^2/4)` — в выборе
разреза (п. 1.5), а не в маршруте по данной линии.

## 3. Лемма B (антиподальная транспозиция; PROVED при чётных n >= 6, таблицы 4..10)

Пусть n = 2m чётно и `tau_n` — тождественная перестановка с обменянными
позициями m, m+1. Тогда `I(tau_n) = 1` и `d(tau_n) = n + 1`.

`I = 1`: разрез q = n−1, c = 0 даёт линию с одной инверсией; `I = 0` только у
поворотов тождественной. Верхняя оценка — слово `L^m X R^m` длины n + 1.

Нижняя оценка. Пусть слово сортирует tau_n и голова заканчивает в c; тогда
элемент e должен оказаться на позиции e + c. Для элемента e обозначим `t_e`
его суммарное знаковое смещение по обменам (каждый X даёт +1 одному и −1
другому участнику); `sum_e t_e = 0`, `N_X >= (1/2) sum_e |t_e|`, и
`t_e ≡ c (mod n)` при e ∉ {m, m+1}, `t_m ≡ c − 1`, `t_{m+1} ≡ c + 1`.

Случай c = 0. Если есть обмен на ребре m (антипод старта), голова проходит
0 → m → 0: `N_rot >= 2m = n`, `N_X >= 1`, итого >= n + 1. Если обменов на ребре
m нет, все обмены — соседние транспозиции пути `m+1, m+2, …, n−1, 0, …, m`
(окружность без ребра m), и их произведение как перестановка позиций равно
транспозиции концов этого пути, длина которой в порождающих пути равна
`2n − 3 >= n + 1`.

Случай c ≠ 0. Автоморфизм `p -> sigma_n o p o sigma_n` (PROBLEM §4.3) меняет
L и R местами, сохраняет tau_n (проверка: 1 − tau(1 − i) = i при i ∉ {m, m+1}
и меняет m, m+1 местами) и переводит c в −c; поэтому достаточно 1 <= c <= m.
Запишем `t_e = r_e + n·k_e`, `r_e` — остаток в [0, n): `sum r_e = (n−2)c +
(c−1) + (c+1) = nc`, значит `sum k_e = −c`. Стоимость `|t_e|` при k = 0 равна
r, при k = −1 — n − r, каждый следующий шаг |k| добавляет n; k > 0 стоит
n + r и требует лишнего уменьшения у другого элемента. Минимум `sum |t_e|`
достигается, когда ровно c элементов имеют k = −1 — те, у кого остатки
наибольшие: один с остатком c + 1 и c − 1 с остатком c:
`sum |t_e| >= nc + (n − 2c − 2) + (c − 1)(n − 2c) = 2cn − 2c^2 − 2`,
`N_X >= cn − c^2 − 1`. При 1 <= c <= m правая часть вогнута по c, на концах
`n − 2` (c = 1) и `m^2 − 1 >= n − 2` (c = m), так что `N_X >= n − 2`. В
кратчайшем слове нет XX, поэтому `N_rot >= N_X − 1` и длина `>= 2n − 5 >= n + 1`
при n >= 6. ∎ При n = 4 равенство `d = 5` — по таблице; `d = n + 1` при
n = 4, 6, 8, 10 сверено с таблицами (`check_C34.py`, часть B).

Следствие. Всякая оценка вида `d(pi) <= 2·I(pi) + g(n)`, верная при всех pi,
требует `g(n) >= n − 1` (чётные n). Критерий PLAN §8 (`g(n) <= floor(n/2) +
O(1)`) недостижим. Обмен блоков длины k у антипода даёт ещё больше:
`d − 2I` = 8 (n = 8, k = 2), 13 (n = 10, k = 3).

## 4. Лемма C (локальная оптимальность разреза)

Если (q, c) минимизирует inv, то линия w удовлетворяет
`sum_{j<k} w_j <= k(n−1)/2` для всех k (и симметрично для суффиксов), и то же
для обратной перестановки (`sum_{x<k} pos(x) <= k(n−1)/2`): сдвиг разреза
позиций на k переносит первые k элементов в конец, меняя inv на
`sum_{j<k} (n − 1 − 2 w_j)`; сдвиг разреза значений на k делает элементы
0..k−1 наибольшими, меняя inv на `sum_{x<k} (n − 1 − 2 pos(x))`. ∎

Этих условий недостаточно для `inv <= floor((n−1)^2/4)`: линия
`(0,5,4,3,2,1,6)` при n = 7 удовлетворяет всем им (суммы 0, 5, 9, 12, 14, 15
при порогах 0, 6, 9, 12, 15, 18; обратная — те же), но `inv = 10 > 9`; её
торический класс имеет I = 8 при несоседнем разрезе. Доказательство п. 1.1
должно использовать совместные сдвиги обоих разрезов.

## 5. Вердикт по H13

1. Исходная форма H13 («один неиспользуемый разрез достаточен для диаметра»)
   подтверждена конечно и уточнена: на слоях `B_n`, `B_n − 1` `d_line = d`
   при 4 <= n <= 9, но в общем случае обмены через все рёбра бывают нужны
   (n = 8, 9).
2. Критерий PLAN §8 — оценка `d <= 2I + g(n)` с `g(n) <= floor(n/2) + O(1)` —
   ложен (лемма B). Правильная форма — с наклоном 1:
   **H13′: `d(pi) <= I(pi) + floor(n^2/4)`**, распадающаяся на
   **H13-I: `I(pi) <= floor((n−1)^2/4)`** (чистая комбинаторика торических
   классов) и **H13-R: существует разрез с `inv = I(pi)` и сокращённое линейное
   слово с `N_rot <= floor(n^2/4)`** (бюджет вращений, не зависящий от I).
   `H13-I + H13-R => C15` по C12. Обе части VERIFIED (4 <= n <= 10 и 4 <= n <= 9),
   обе тесны.
3. «Доказуемая схема слова для линии с inv инверсиями и `N_rot <= inv + f`»
   (PLAN §8 п. (2)) не существует в нужной силе: бюджет вращений не убывает с
   inv (Rbest = floor(n^2/4) при I ≈ n), а без выбора разреза он равен
   `B_n − 1` (лемма A). Схема должна выбирать разрез; экстремальные маршруты
   разного вида (зигзаги на отражениях, холостые переходы на блочных входах).
4. Пункт (3) PLAN §8 (входы с `I > max − n/4`) не сводит задачу к конечному
   числу семейств: их 660 при n = 10 и они растут с n.

Доказать H13-I отдельно (бюджет 1 сессия): утверждение о торических классах —

торических классах перестановок. Если H13-I доказана — H13-R остаётся

нет за сессию — переход к индукции H3 (PLAN §4.3).

### 7.1. Редукция: совместный сдвиг разрезов = чистое вращение

Запишем двойной разрез через `k = (c − q) mod n` вместо `c`. Линия из §0:

```text
w_j(q, c) = pi(q + 1 + j) − (q + 1 − c) mod n.
```

Слагаемое `q + 1 − c = 1 − k` не зависит от q. Значит на «диагонали» с
фиксированным k (n разрезов `(q, q + k)`, q = 0..n − 1) линия — это ровно
n циклических вращений ОДНОГО фиксированного массива

```text
u^(k)_i = (pi(i) + k − 1) mod n,   i = 0..n − 1        (значения ФИКСИРОВАНЫ,
                                                          вращаются только позиции)
```

(проверка: при переходе q -> q+1 внутри диагонали (c тоже растёт на 1, k
неизменно) слагаемое `q+1−c` не меняется, а формула для w — это u^(k),
прочитанный начиная с позиции q+1, т. е. u^(k), повёрнутый на q+1 шагов).
Отсюда точное тождество (проверено на переборе, `--exhaustive` в
`experiments/h13i_diagonal_bound.py`, ассерт против прямого определения при
4 <= n <= 7):

```text
I(pi) = min_{k=0}^{n-1} R(u^(k)),   R(u) := min по n вращениям u массива inv(вращение).
```

R(u) — классическая величина «минимум инверсий циклической последовательности
по выбору точки разреза» (позиции циклические, значения — фиксированные метки
0..n−1, не циклические). В отличие от исходных n^2 разрезов, здесь всего n
«столбцов» k, и в каждом задача уже одномерна.

### 7.2. Гипотеза H13-I-diag (VERIFIED 4 <= n <= 10 и выборочно; НЕ доказана)

Поскольку `I(pi) <= (1/n) * sum_k R(u^(k))` тривиально (минимум не больше
среднего), из следующего утверждения следует H13-I:

```text
H13-I-diag:  sum_{k=0}^{n-1} R(u^(k)) <= n * floor((n-1)^2/4)   для всех pi, n >= 4,
             с равенством тогда и только тогда, когда pi — отражение (поворот
             pi_h(i) = h − i mod n при каком-то h).
```

Это НЕ переформулировка H13-I и не то же самое «усреднение по n^2 разрезам»,
которое уже отвергнуто (§1, §6): здесь усредняются n УЖЕ ВЗЯТЫХ ПОМИНИМУМОВ
(по одному минимуму на диагональ), а не n^2 сырых значений inv. Это строго
более сильное (и более специфичное, проверяемое) утверждение, чем H13-I.

Проверено:

- Исчерпывающе, все pi, 4 <= n <= 10 (`experiments/h13i_diagonal_bound.py
  --exhaustive`): 0 контрпримеров на 24 + 120 + 720 + 5040 + 40320 + 362880 +
  3628800 перестановках; для 4 <= n <= 7 каждое значение `min_k R(u^(k))`
  дополнительно сверено ассертом с прямым перебором всех n^2 разрезов
  (совпадает всегда). Равенство `sum_k R(u^(k)) = n * floor((n−1)^2/4)`
  достигается РОВНО на n входах при каждом n — это в точности n поворотов
  (сдвигов L) одного отражения, т. е. вся орбита отражения под вращением
  окружности позиций.
- Структурно/случайно при n = 20, 50, 100, 101, 200
  (`experiments/h13i_diagonal_bound.py --sample`): sigma_n, отражение h = 0,
  rev_n — точное равенство `sum = n * floor((n−1)^2/4)`; id_n — 0; аффинные
  `pi(i) = 7i + 11 mod n` и три случайные перестановки на каждое n — везде
  строго меньше границы, без исключений.
- n = 10 занял 207.2 с (Python, все 3 628 800 перестановок), n = 9 — 16.6 с;
  отчёт и JSON — `data/runs/h13i_diagonal_bound/`.

Статус H13-I-diag в реестре — CONJECTURED (VERIFIED при указанном покрытии),
не PROVED: доказательства нет, только перебор и выборка (AGENTS.md правило 5).

### 7.3. Доказанный вспомогательный факт (лемма D)

Одна часть цепочки рассуждений доказана честно (не переборным путём).
Пусть `S_t^(k) = sum_{s=0}^{t-1} [(n-1) - 2 u^(k)_s]` — накопленное изменение
inv при вращении u^(k) на t шагов (шаг вывода: перенос переднего элемента со
значением m в конец даёт `Delta(inv) = (n-1) - 2m` — прямая проверка на паре
позиций: элемент со значением m уходит с позиции 0, где он образовывал m
инверсий с меньшими себя элементами позади, и появляется в конце, где
образует n-1-m инверсий с большими себя элементами впереди).

**Лемма D.** Для любого фиксированного t (0 <= t <= n) и любой pi:
`sum_{k=0}^{n-1} S_t^(k) = 0`.

Доказательство. Для фиксированной позиции s значение `u^(k)_s = (pi(s)+k-1)
mod n` пробегает все n значений 0, ..., n-1 по одному разу, пока k пробегает
Z_n (это биекция по k при фиксированном s). Значит
`sum_k [(n-1) - 2 u^(k)_s] = n(n-1) - 2*sum_{v=0}^{n-1} v = n(n-1) - n(n-1) = 0`
для каждого s, а `S_t^(k)` — сумма таких слагаемых по s < t, поэтому сумма по
k тоже 0. ∎ (проверено также вычислением на переборе, 4 <= n <= 7,
`--identity`, 0 нарушений на 5904 перестановках).

Лемма D — единственный элемент рассуждения, доведённый до настоящего
доказательства в этой сессии. Сама по себе она НЕ доказывает H13-I-diag: см.
§7.4.2.

### 7.4. Что опробовано для замыкания H13-I-diag и не сработало

1. **`min_t <= avg_t` через лемму D.** Раз `sum_k S_t^(k) = 0` при каждом
   фиксированном t, а `R(u^(k)) = inv(u^(k)) + min_t S_t^(k) <= inv(u^(k)) +
   avg_t S_t^(k)`, то суммируя по k: `sum_k R(u^(k)) <= sum_k inv(u^(k)) +
   (1/n) sum_t sum_k S_t^(k) = sum_k inv(u^(k)) + 0`. Но `sum_k inv(u^(k))`
   (без вращения, t = 0 в каждой диагонали) сам по себе УЖЕ превышает
   `n * floor((n-1)^2/4)` на отражениях: для sigma_7 сумма равна 91 против
   `n*bound = 63` (разница 28), для sigma_8 — 140 против 96, для sigma_20 —
   2470 против 1800 (`--raw` в скрипте). Значит замена настоящего минимума
   по t на среднее по t теряет слишком много — нужен именно минимум, не
   среднее, и лемма D одна эту разницу не закрывает.
2. **Явное правило вместо минимума.** Кандидат «разрез сразу после позиции
   максимального значения» (естественная эвристика: убрать наибольший вклад)
   протестирован явно (`--heuristic`, 4 <= n <= 8, все pi): уже при n = 4
   даёт 4 контрпримера из 24 (на отражениях сумма 12 > n*bound = 8), при
   n = 8 — 7656 из 40320. Значит никакое простое явное правило «разреза при
   фиксированном k» не подходит — нужен именно `min_t`, что делает прямое
   явное построение (без обращения к оптимизации) более сложным, чем казалось
   в §6.
3. **Парная (по двум точкам) формула для полной суммы по всем n^2 разрезам**
   (не по диагоналям) выведена и проверена (`B(A,d) = n^2 - n(A+d) + 2Ad` —
   суммарное число «плохих» (q,c) для одной пары точек с направленными
   разрывами A по позициям и d по значениям), но поскольку H13-I-diag
   работает через МИНИМУМ по t внутри каждой диагонали, а min — нелинейная
   операция, эта парная формула не раскладывается на независимый вклад по
   парам и не даёт после суммирования по k замкнутой формулы для
   `sum_k R(u^(k))`.
4. **Литературный поиск** (WebSearch, два запроса на «минимум инверсий при
   совместном вращении домена и области значений перестановки» и «cyclic
   inversions minimum over rotations circular sequence extremal reflection»)
   не нашёл прямого источника на эту величину; выдача — общая теория
   инверсий и циклических перестановок, без совпадения с формулировкой.
   Дальнейший поиск не пробовался (может быть продуктивен под другими
   терминами — «necklace alignment», «toroidal permutation discrepancy»,
   «linear extension of cyclic order» — не проверялось).

### 7.5. Итог и рекомендация

H13-I остаётся VERIFIED 4 <= n <= 10 (C33), CONJECTURED в общем случае.
Новый, более узкий и по-прежнему открытый ориентир для следующей сессии —
доказать H13-I-diag (§7.2); это достаточное условие для H13-I (по
тривиальному неравенству среднее >= минимум) и куда более конкретная цель:
чистое числовое утверждение об одной сумме n «диагональных минимумов» с
известной точкой равенства (ровно отражения). Направление, которое
представляется наиболее многообещающим и не опробованным до конца: прямое
комбинаторное описание `R(u)` как функции перестановки `u` (не через блуждание
`S_t`, которое, по п. 7.4.1, теряет слишком много при переходе к среднему) —
например, через ранговую структуру `u` и точную характеризацию, при какой
структуре разреза достигается минимум (потенциально — рассуждение о выпуклости
или обмене соседних элементов перестановки pi, показывающее, что отражения
экстремальны). Если и это не даст результата за следующую сессию —
переходить к индукции H3 (PLAN §4.3, уменьшение исходной задачи о диаметре на
один элемент, а не индукция по I(pi), которая уже отвергнута в §1.7).
