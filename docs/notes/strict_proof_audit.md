## 2. Переходы, проверенные вручную

### §1. Нагрузки

- (1.1): дуга, проходящая вершину насквозь, даёт по 1 в оба соседних ребра;
  входящая/исходящая дуга — только в одно. Разобраны все 4 комбинации знаков.
  Дуги длины <= n/2 не проходят вершину дважды. Верно.
- Число переходов +→− равно числу −→+ (циклическая последовательность знаков),
  отсюда E = k − 2t >= 0. Верно.
- Связность положительного носителя: объединение рёбер замкнутого обхода
  связно; на цикле Z_n это либо всё кольцо, либо одна дуга. Верно.

### §2. Локальное слово (C18, локальная часть)

- §2.1. При одном знаке нагрузки постоянны и равны M = F/n — любой b годится.
  В смешанном случае начало максимального участка нагрузки M имеет входной
  скачок ровно +2, значит b ∈ C и тип −→+. Верно; (2.1) следует.
- §2.2. (2.2): ровно M дуг проходят ребро {0,1}. (2.3): проекция обхода
  замкнута. Обнулиться может только e_0 (при d_0 = 1) или e_{k−1}
  (при d_{k−1} = −1): внутренние дуги не могут состоять из одного ребра {0,1}.
  Верно.
- §2.3. Проверено прямым вычислением: u^{z_j}(1) = v_j (склеенная вершина
  представлена 1); Π u^{z_j}(0 1)u^{−z_j} · u^{z_k} с u^{z_k} = 1 по (2.3);
  (0 v_1)(0 v_2)…(0 v_{k−1}) = (0 v_{k−1} … v_1) = (0 v_1 … v_{k−1})^{−1}.
  Ориентация цикла согласована с f_c (a_{j+1} = f_c(a_j)), поэтому
  получается именно C^{−1}, что и требуется в (3.2). Верно.
- §2.4. Правила сокращений используют только первую X положительного блока
  и последнюю X отрицательного; нужные блоки непусты (случаи e_0 = 0,
  e_{k−1} = 0 не затрагиваются). Несокращённых вставленных X ровно t:
  вершина a_0 в смешанном случае имеет тип −→+, все t переходов +→− —
  внутренние. Итог 2F − S. Верно. Чекер выполняет ровно эти сокращения и
  проверяет действие слова до и после них.

### §3. Сшивка и позиционирование

- (3.1): позиционная перестановка W_C в системе переносчика равна
  ρ_{−b} C^{−1} ρ_b; проверено на определении ρ_b(i) = i + b и v_j = a_j − b.
- (3.2): произведение C^{−1} по циклам f_c = f_c^{−1} (циклы коммутируют);
  π f_c^{−1} ρ_c = 1, так как f_c = ρ_c π. Верно.
- Маршрут H(c): при c ≠ 0 маршрут d−1 вперёд, назад, n−d в другую сторону
  посещает все вершины и заканчивается в c; длина n + d − 2. При c = 0 — n.
  Верно; H — достаточная стоимость, фактический маршрут может быть короче.
- Средние: Σ_c F_c = nP (сумма расстояний от точки до всех вершин = P
  при обеих чётностях); Σ_c H(c) = n + (n−1)(n−2) + P. Верно, (3.4) следует.

### §4. Тождество ℰ = V + 2B (антиподальная поправка)

- (4.3): при j = f_c(i) входящий в j шаг равен j − i, исходящий
  π(j) − π(i); каждая упорядоченная пара (i, j), i ≠ j, отвечает ровно
  одному c. Верно.
- j ∈ I_i ⇔ sgn_n(j − i) = + (антипод положителен); τ(j) ∈ I_{τ(i)} ⇔
  sgn_n(π(i) − π(j)) = +. При нечётном n отрицание меняет знак: V = ℰ.
  При чётном n разобраны оба случая антиподальности образа и прообраза:
  неантиподальная исходная пара даёт по 1 в ℰ и V, антиподальная — 2 и 0.
  Верно. B = Σ θ_c: пара {i, j} — антиподальная транспозиция ровно одного
  f_c (c = j − π(i)) и обратно. Верно.

### §5. Лемма опорной точки (C19)

- |I_a △ I_b| = 2δ_n(a, b): для обеих чётностей окна не «схлёстываются»
  (a + m + d <= a + n − 1). Верно. (5.2) — два неравенства треугольника.
- (5.3): при одинаковых знаках u_b − u_a = s_2 − s_1 с |s_2 − s_1| <= n/2;
  при одном антиподальном шаге разность ≡ n/2 − r. Верно; исключительные
  пары определены корректно (антиподы не исключительны).
- Взаимность исключительности и b ∈ B_a, a ∈ B_b — верно (оба шага
  неантиподальны, оба знака меняются при перестановке концов).
- §5.3: k ∉ B_a означает совпадение знаков в соглашении «антипод = +»,
  что исключает исключительность пары (a, k). |G| > 2m при n > 4m + ρ_j.
  Оценка (5.6) — сумма (5.3) по двум парам через k с ρ_k <= Q/|G|. Верно.
- §5.4: b <= |B_a| = m; арифметика (5.8) сведена: m(n−1+m) + Q = V + m(m−1).
  Верно. §5.5: m >= 1 ⇒ m(m−1) <= x(x−1); случай m = 0 отдельно через (5.5).
  Верно.

### §6. Два разреза (C20)

- (6.2): пара, разделённая границей полукруга, пересекает одно из двух
  граничных рёбер. Верно при любом направлении дуги.
- Нечётный n: a = (h+c)/2 корректно, u = i − a пробегает Z_n при переборе c;
  число разделений = |I △ (ε − I)|; при ε = 0 равно n − 1; сдвиг на d меняет
  <= 2d принадлежностей. Верно.
- Чётный n: h + c ≡ 2a + t (mod n) для любых целых представителей; при
  фиксированном t величина u пробегает q подряд идущих классов, то есть
  каждый класс mod q один раз; инвариантность индикатора при u → u + q —
  оба конца сдвигаются на q и меняют принадлежность полукругу. При ε = 0
  слагаемые равны n − 2 и n. Верно.
- (6.4): Σ_C M(C) >= M_c^all; F(C) <= nM(C). Верно.

### §7. Цикловая оценка (C21)

- M = 1 ⇒ нет скачков ±2 ⇒ t = 0, E = k; k = 2 при одном знаке — только
  антиподальная транспозиция. Верно.
- M <= 2 с поворотом ⇒ все нагрузки одной чётности, есть скачок 2 ⇒ M = 2,
  нагрузки ∈ {0, 2}; связность носителя ⇒ ровно один скачок +2 и один −2 ⇒
  t = 1, k = E + 2. Верно — здесь связность действительно необходима.
- Треугольник с обоими знаками: сумма трёх шагов лежит в (−n, n) и кратна n,
  значит 0; единственный шаг одного знака равен по модулю сумме двух других,
  F = 2|он| <= n. Верно.
- Перебор случаев в §7.2: M >= 3; M = 1, E >= 3; M = 2, E >= 2 (включает
  однонаправленный случай M = 2, k >= 3, не названный в тексте явно);
  M = 2, E ∈ {0, 1} — по (7.2); антиподальная транспозиция — равенство.
  Арифметика 8/3 + 1/3 = 3 и 34/9 < 4 верна. Все нетривиальные циклы покрыты.
- (7.3): (7/9)(x + 2θ̄) − (2/9)θ̄ = (7/9)x + (4/3)θ̄. Верно.

### §8. Исключение параметров
