## 2. C18: локальное слово и сшивка (N1 §§1–3)

Проверенные переходы:

1. **Правило скачков (1.1).** Входящая дуга в a_j использует ребро {a_j-1,a_j}
   при d_{j-1}>0 и {a_j,a_j+1} при d_{j-1}<0; исходящая — {a_j,a_j+1} при
   d_j>0 и {a_j-1,a_j} при d_j<0. Разность нагрузок = (вклад исходящей) +
   (вклад входящей) = ±2 или 0 ровно по таблице (1.1). Дуга, проходящая
   сквозь вершину, даёт по 1 в оба ребра. Дуга не длиннее n/2, поэтому не
   проходит через собственные концы дважды. ✓
2. **t(-+) = t(+-), E >= 0, F <= nM, связность носителя.** Знаки по циклу
   меняются чётное число раз; носитель — образ замкнутого обхода. ✓
3. **Переносчик (§2.1).** Начало максимального участка нагрузки M имеет
   входной скачок > 0, значит +2, значит вершина цикла с переходом -→+;
   после перенумерации d_0>0, d_{k-1}<0. В однонаправленном случае нагрузка
   постоянна. ✓
4. **Стягивание (§2.2).** Каждая дуга проходит ребро {b,b+1} не более раза
   (|d|<=n/2<n), поэтому sum|e_j| = F - M и sum e_j ≡ 0 (mod n-1)
   (проекция замкнутого обхода). При 1<=j<=k-2 концы шага отличны от b, а
   проекция отождествляет только b с b+1, поэтому e_j ≠ 0 и |e_j|<=n/2<n-1;
   знак сохранён. Нулевыми могут быть только e_0 (d_0 = +1, a_1 = b+1)
   и e_{k-1} (d_{k-1} = -1). ✓
5. **Действие (2.5).** U = XL даёт [x_0, x_2, ..., x_{n-1}, x_1]: позиционная
   перестановка u с u(1)=2, ..., u(n-1)=1 (новый массив = старый ∘ u).
   После U^{z} в позиции 1 стоит старое содержимое позиции u^{z}(1) = 1+z
   по кольцу {1..n-1}. Индукция по j: u^{z_j}(1) = v_j, так как кольцевое
   смещение проекции дуги равно e_j. Полная степень u^{z_k} = id по (2.3).
   Сопряжение u^{z}(0 1)u^{-z} = (0 v_j); произведение
   (0 v_1)...(0 v_{k-1}) при композиции «применять справа налево» равно
   (0 v_{k-1} ... v_1) = (0 v_1 ... v_{k-1})^{-1}. Хронологическая
   композиция g, затем h даёт p∘g∘h — согласовано с записью произведения
   в (2.5). Машинно: (2.5) проверено для всех 144 606 циклов. ✓
6. **Сокращения (§2.4).** Для X_j (1<=j<=k-1): при d_j>0 блок j начинается
   с X и ненулевой (для j<=k-2 — п. 4; для j=k-1 знак d_{k-1}>0 бывает
   только в однонаправленном случае, где дуга в 0 идёт через {n-1,0}, не
   через стянутое ребро); при d_{j-1}<0 и d_j<0 блок j-1 кончается на X и
   ненулевой (аналогично при j=1). Положительный блок отдаёт только первую
   X, отрицательный — только последнюю; пары не пересекаются. Без
   сокращения остаются ровно переходы +→- среди a_1..a_{k-1}; их t
   (переносчик — переход -→+ или t=0). Итог 2F - S. ✓
   *Замечание.* Длина после этих сокращений равна 2F - S точно, не только
   <=; в реализации это assert. Свободное сокращение слова может быть
   короче — это уже «потери», не часть леммы.
7. **Сшивка (3.1)–(3.2).** Голова в позиции b означает массив p∘rho_b;
   локальное слово в этой системе имеет позиционную перестановку
   rho_{-b}∘C^{-1}∘rho_b, откуда p∘C^{-1}∘rho_b. Циклы f_c дизъюнктны,
   коммутируют; после всех циклов и маршрута 0→c: pi∘f_c^{-1}∘rho_c =
   pi∘pi^{-1}∘rho_{-c}∘rho_c = id. ✓ Переносчики разных циклов различны
   (переносчик — вершина своего цикла). Локальное слово применяется при
   первом посещении переносчика (маршрут при c ≠ 0 посещает вершины
   короткой дуги дважды — см. §9).
8. **H(c).** Маршрут d-1 вперёд, d-1 назад, n-d по длинной дуге: длина
   n+d-2, посещает все вершины; при c=0 полный круг n. Средние F_bar = P
   (для фиксированного i значения f_c(i) пробегают все вершины) и
   H_bar = n - 2 + (P+2)/n. ✓ (3.3), (3.4). ✓

Вердикт: C18 — PROVED. Область n >= 4 (нигде не требуется большее;
при n = 3 кольцо после стягивания имеет 2 вершины, что текст не рассматривает
и не заявляет).

## 3. C19: тождества §4 и лемма опорной точки §5

1. **(4.3).** E(C) считает вершины с одинаковыми знаками входящего и
   исходящего шагов = дуги (i → j=f_c(i)), у которых следующая дуга
   (j → f_c(j)) того же знака. c = j - pi(i) и f_c(j) - j = pi(j) - pi(i):
   получаем (4.3). ✓
2. **(4.4).** j ∈ B_i ⟺ sgn(j-i) ≠ sgn(pi(i)-pi(j)) (окно I_i — ровно
   положительная полуокружность с антиподом внутри). При нечётном n
   sgn(pi(i)-pi(j)) = -sgn(pi(j)-pi(i)) всегда: V = 𝓔. При чётном n пары
   с антиподальными образами: если {i,j} не антиподальна — по одному вкладу
   в 𝓔 и в V; если антиподальна — 2 в 𝓔 и 0 в V. ✓ (4.5): каждая такая
   пара — антиподальная транспозиция f_c ровно при c = j - pi(i). ✓
3. **(5.2).** |I_a △ I_b| = 2delta(a,b) при окнах длины floor(n/2):
   при delta = d <= floor(n/2) сдвиг окна меняет ровно 2d принадлежностей.
   Неравенство треугольника для △ через tau(I_a), tau(I_b). ✓
4. **(5.3).** Неисключительная пара: шаги s (a→b) и s' (tau a→tau b) одного
   знака или один антиподален; u_b - u_a ≡ s' - s; при одном знаке
   |s'-s| = ||s'|-|s|| <= n/2; при s = n/2 расстояние от s' - n/2 до 0 равно
   n/2 - |s'|. ✓ Исключительная пара взаимна и b ∈ B_a, a ∈ B_b. ✓
5. **(5.4).** h = a + pi(a): delta(pi(i)+i, a+pi(a)) = delta(u_i, u_a)
   (обе величины отличаются знаком одинаково). ✓ m=0: B_a = ∅, нет
   исключительных партнёров, T_h <= V/2. ✓
6. **(5.6).** При n <= 4m + rho_j: n/2 <= 2m + rho_j/2. Иначе |G| >= n - 2m -
   rho_j > 2m, min_{k∈G} rho_k <= Q/|G| <= Q/(2m); k ∉ B_a ∪ B_j означает
   совпадение знаков в обеих парах — они неисключительны; треугольник даёт
   2m + rho_j/2 + rho_k. ✓ (a, j ∉ G автоматически.)
7. **(5.8).** b <= |B_a| = m; сумма rho_i/2 по всем i <= Q/2; при b <= m
   получаем m(n-1+m) + Q = V + m(m-1). ✓
8. **§5.5.** m>0 ⟹ x >= m >= 1 и z(z-1) возрастает при z >= 1;
   m=0 отдельно: nx/2 <= (n-1)x при n >= 2. ✓

Вердикт: C19 — PROVED.
