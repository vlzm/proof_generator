# Точная формула F_c, S_c на семействе отражений (PLAN §4.2, H10, шаг 1)

Сессия 4 (13.09.2026). Обозначения — N1 и PROBLEM §5.2. Ядро oracle-1.0,
конструкция `constructions/strict_upper.py` (strict_upper-1.0). Цель — первый
шаг направления H10: явные F_c, S_c по чётности c (точнее, по чётности
m = h+c mod n) для всей серии отражений pi(i) = h-i mod n при любом n >= 4
и любом h, без ограничения диапазона n (в отличие от C24, где h = 1 и разбор
был числовым при 4<=n<=12).

## 0. Постановка

pi(i) = h - i mod n, h из Z_n. f_c(i) = pi(i) + c mod n = m - i mod n, где
`m = (h+c) mod n`. Обозначим rho_m(i) = m - i mod n.

**Лемма 0.** rho_m — инволюция: rho_m(rho_m(i)) = m - (m-i) = i.

Значит f_c состоит только из неподвижных точек и транспозиций (нетривиальных
2-циклов), как уже отмечено в C24 для случая h = 1.

## 1. Неподвижные точки и число транспозиций K(m)

Неподвижная точка: 2i ≡ m (mod n).

- n нечётно: 2 обратимо mod n, ровно одна неподвижная точка при любом m;
  K(m) = (n-1)/2 — константа, не зависит от m.
- n чётно, m чётно: два решения (i0 и i0+n/2); K(m) = (n-2)/2 = n/2 - 1.
- n чётно, m нечётно: решений нет; K(m) = n/2.

(Стандартный факт о квадратичном сравнении 2i ≡ m mod n; проверяется прямой
подстановкой i0 = m * inv(2) mod n для нечётного n, i0 = m/2 для чётного m.)

## 2. S(C) = 3 для каждой транспозиции

Пусть {i,j} — транспозиция rho_m (j = m-i mod n, i != j), d = signed_step(i,j,n)
— подписанный кратчайший шаг (правило 16: антиподальный шаг положителен).
Цикл длины k=2, шаги (d1,d2) с d2 = signed_step(j,i,n).

- d != n/2 (не антипод): d2 = -d1 (шаг в обратную сторону не антипод, поэтому
  берёт естественный знак). Ровно один переход "отрицательный -> положительный"
  среди двух циклических соседей пары (d1,d2), значит t = 1, E = k - 2t = 0.
  Дуги проходят одно и то же множество рёбер в противоположных направлениях,
  поэтому M = 2 (нагрузка каждого общего ребра — обе дуги). S = 2M+E-1 = 4+0-1 = 3.
- d = n/2 (антипод, n чётно): по правилу 16 оба шага положительны, d1=d2=n/2.
  Нет отрицательного шага, t = 0, E = k-2t = 2. Дуги — два непересекающихся
  полукруга (различные множества рёбер), M = 1. S = 2*1+2-1 = 3.

**Лемма 1.** S(C) = 3 для каждой нетривиальной транспозиции rho_m, независимо
от того, антиподальна она или нет. Следствие: S_c = 3*K(m).

## 3. F(C) = 2*dist(i,j)

Для транспозиции {i,j}, F(C) = |d1| + |d2|. Не-антипод: |d2|=|-d1|=|d1|;
антипод: |d1|=|d2|=n/2. В обоих случаях F(C) = 2*|d1| = 2*dist(i,j), где
dist(i,j) — круговое расстояние в (0, n/2] (значение |signed_step(i,j,n)|).

**Лемма 2.** F(C) = 2*dist(i,j) для каждой транспозиции rho_m.

Заметим dist(i,j) = dist(i, m-i) = |m-2i|_circ, где |x|_circ = min(x mod n,
n - x mod n) — представитель в (0, n/2] (или 0 для x ≡ 0).

## 4. Сумма F_c по чётности m

Пусть Fix(m) — множество неподвижных точек. Для i не из Fix(m), партнёр
j = m-i mod n; каждая пара {i,j} даёт значение |m-2i|_circ дважды в сумме по
i (один раз для i, один для j, поскольку |m-2j|_circ = |m-2(m-i)|_circ =
|2i-m|_circ = |m-2i|_circ). Значит

```text
F_c = sum_{транспозиции} F(C) = sum_{i not in Fix(m)} |m-2i|_circ.
```

(Каждая транспозиция вносит 2*dist один раз в сумму по транспозициям —
и это совпадает с суммой по i из двух представителей, дающих одно и то же
значение dist каждый — итого коэффициент 2 сохраняется.)

Известное тождество: `sum_{k=1}^{n-1} min(k, n-k) = floor(n^2/4) = P` для
любого n >= 2 (пары (k, n-k) при 2k != n дают min = k один раз и n-k один раз
на симметричные k; при n чётном k=n/2 даёт единственный вклад n/2, и сумма
равна (n/2)^2 = P; при n нечётном сумма = 2*sum_{k=1}^{(n-1)/2} k = P — обе
формулы дают floor(n^2/4)).

### 4.1. n нечётно

i -> m - 2i mod n — биекция Z_n -> Z_n (2 обратим). Единственная неподвижная
точка i0 отображается в 0. Значит {m-2i mod n : i != i0} = {1, ..., n-1}
(каждое значение по одному разу). Сумма = P (см. выше). F_c = P для ЛЮБОГО m.

### 4.2. n четно, m чётно (K = n/2 - 1)

i -> m-2i mod n — 2-к-1 отображение на чётные вычеты (ядро {0, n/2}).
Неподвижные точки i0, i0+n/2 — единственные два прообраза 0. После их
исключения оставшиеся n-2 значения i дают каждое ненулевое чётное значение
m-2i mod n ровно дважды. Пусть n = 4t (n ≡ 0 mod 4) или n = 4t+2 (n ≡ 2 mod 4).

Через прямое суммирование (арифметика по блокам, см. §4.4 ниже) сумма
чётных k в {2,...,n-2} от min(k,n-k):
- n ≡ 0 (mod 4), n=4t: сумма = 2t^2 = n^2/8.
- n ≡ 2 (mod 4), n=4t+2: сумма = 2t(t+1) = (n^2-4)/8.

F_c = 2 * (сумма чётных k) в обоих случаях (коэффициент 2 — из 2-к-1
кратности после исключения неподвижных точек):
- n ≡ 0 (mod 4): F_c = 2 * n^2/8 = n^2/4 = P.
- n ≡ 2 (mod 4): F_c = 2 * (n^2-4)/8 = (n^2-4)/4 = P - 1 (P = n^2/4 для
  чётного n точно, без floor).

### 4.3. n чётно, m нечётно (K = n/2)

Неподвижных точек нет; i -> m-2i mod n — тоже 2-к-1 на нечётные вычеты, но
без исключений (все n значений i участвуют). Сумма нечётных k в {1,...,n-1}
от min(k,n-k) = P - (сумма чётных k, §4.2, включая k=0, вклад 0) = P минус
результат §4.2 для соответствующего n mod 4:
- n ≡ 0 (mod 4): нечётная сумма = P - n^2/8 = n^2/8.
- n ≡ 2 (mod 4): нечётная сумма = P - (n^2-4)/8 = (n^2+4)/8.

F_c = 2 * (нечётная сумма):
- n ≡ 0 (mod 4): F_c = n^2/4 = P.
- n ≡ 2 (mod 4): F_c = (n^2+4)/4 = P + 1.

### 4.4. Явная сумма по блокам (доказательство формул §4.2)

Для n = 4t, чётные k = 2j, j = 1..2t-1: min(2j,4t-2j) = 2j при j<t, = 2t при
j=t, = 4t-2j при j>t. Сумма = 2*sum_{j=1}^{t-1} 2j... (см. вычисление ниже,
итог 2t^2). Для n = 4t+2 аналогично с половинным сдвигом (итог 2t(t+1)).
Оба вычисления — конечные арифметические суммы, проверены символьно и
численно (см. §5) для 4<=n<=200; общая формула для суммы арифметической
прогрессии стандартна и не требует отдельного файла.

## 5. Итоговая теорема (Лемма 3)

**Лемма 3.** Для отражения pi(i) = h-i mod n (n >= 4, любое h) и c из Z_n,
пусть m = (h+c) mod n. Тогда:

```text
n нечётно:        F_c = P,       S_c = 3(n-1)/2                (для всех m)
n ≡ 0 (mod 4):     F_c = P,       S_c = 3(n/2 - 1)   если m чётно
                                   S_c = 3n/2         если m нечётно
n ≡ 2 (mod 4):     F_c = P - 1,   S_c = 3(n/2 - 1)   если m чётно
                    F_c = P + 1,   S_c = 3n/2         если m нечётно
```

F_c, S_c зависят только от чётности m (не от h и c по отдельности) и не
зависят от диапазона n — доказательство общее для всех n >= 4.

**Следствие (Лемма 4).** min по m (эквивалентно: по подходящему c при
фиксированном h) от 2F_c - S_c равен, с учётом B_n = n(n-1)/2 (C12, для
любой чётности n):

```text
n нечётно:        2F_c - S_c = (n-1)(n-2)/2 = B_n - (n-1)     (для всех m)
n ≡ 0 (mod 4):     min (при m нечётном) = n^2/2 - 3n/2 = B_n - n
n ≡ 2 (mod 4):     min (при m чётном) = n^2/2 - 3n/2 + 1 = B_n - (n-1)
```

Доказательство следствия — прямая подстановка P = floor(n^2/4) (нечётн.:
(n^2-1)/4; чётн.: n^2/4) и B_n = n(n-1)/2 (C12) в формулы Леммы 3 и
арифметика; см. также проверку в §6.

по формулам Леммы 3 и сравнивает с фактическими значениями `strict_upper.py`

в выводе на конечном диапазоне.

## 7. Что не доказано (маршрут R_c)

Лемма 4 даёт точную формулу минимума 2F_c - S_c по подходящей чётности m,
но НЕ даёт длину слова: нужно ещё min по подходящим c от R_c (маршрут по
переносчикам, вариант, правило 16). Эмпирически минимум R_c на подходящей
чётности c почти в точности компенсирует выигрыш Леммы 4 (n-1 или n), так
что итоговая сумма садится ровно на B_n или B_n+1 — это НЕ следует из
Леммы 3 напрямую и остаётся открытой комбинаторной леммой о структуре
переносчиков (расположение "разрывов" между занятыми вершинами на
окружности).

`experiments/reflections_h10_check.py` расширяет исчерпывающую проверку C27v
(H10 на отражениях) с 4<=n<=12 (C27v, сессия 3) до 4<=n<=70 (все h, все c,
186.6 с; `data/runs/reflections_fs/h10_report.md`): `Q_R - B_n` равно ровно 1
при n ≡ 2 (mod 4) (максимум по h достигается на h = 2, т.е. m = h+c чётно даёт
F_c = P-1, но не спасает от +1 в маршруте) и ровно 0 при остальных n, на
всём диапазоне без единого исключения; `Q_RJ - B_n` (после свободного
сокращения) равно 0 на КАЖДОМ n и КАЖДОМ h в этом диапазоне — вторая часть
H10 (`<= B_n` после сокращения) для отражений подтверждена без единого
превышения на 4<=n<=70. Это самое чистое и полное численное свидетельство
H10 на структурированном семействе на сегодня, но не общее доказательство:
общий n (произвольная антиподальная структура при n ≡ 2 mod 4) и почему
именно свободное сокращение убирает единицу — не объяснены алгебраически.

Направление — предмет следующей сессии по бюджету §4.2 H10 (2 сессии,
из них использована часть первой на явные F_c, S_c и расширенную проверку).
Следующий шаг: доказать алгебраически (не только по данным), что при n ≡ 2
(mod 4) минимальный по подходящему c маршрут R_c равно n даёт после
свободного сокращения ровно n-1 (то есть сокращение снимает ровно один
XX-стык на границе маршрута и локального слова), а при остальных n минимум
R_c уже без сокращения не превышает n-1 либо n-2 — используя явную структуру
переносчиков §4 (какие вершины являются переносчиками для каждой чётности m).
