# C37/C38 — общая оценка `I(pi) <= floor((n−1)(2n−1)/6)` и предел усреднения

Дата: 16.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py`. Ничего, кроме определения двойного
разреза (PROBLEM §2–3, `docs/notes/h13_line_model.md` §0), не используется:
таблицы расстояний, N1 и C16–C36 не нужны.

Предмет — чисто комбинаторная величина

```text
I(pi) = min_{q, c} inv(w),    w_j = (pi(q + 1 + j) − (q + 1 − c)) mod n,
```

минимум по всем n^2 двойным разрезам. Гипотеза H13-I (`I(pi) <=
floor((n−1)^2/4)`) остаётся открытой; здесь доказана более слабая общая оценка
с той же структурой доказательства и показано, что усреднением по разрезам
лучшей оценки получить нельзя.

## Утверждения

**C37.** Для всех n >= 2 и всех перестановок pi: `I(pi) <= floor((n−1)(2n−1)/6)`.
Это в точности `floor` от максимума среднего числа инверсий по n^2 разрезам,
и максимум достигается ровно на отражениях.

**C38 (пределы усреднения).**
(a) Если λ — фиксированное (не зависящее от pi) распределение вероятностей на
Z_n × Z_n и оценка `sum_{k,l} λ(k,l) · inv(a+k, b+l) <= M(n)` верна для всех pi
и всех разрезов (a, b), то `M(n) >= (n−1)(2n−1)/6`. Так как
`floor((n−1)^2/4) < (n−1)(2n−1)/6` при n >= 5, H13-I этим способом недоказуема.
(b) На отражении `pi_h` ровно n разрезов (чётное n) или 2n (нечётное n) из n^2
дают `inv = floor((n−1)^2/4)`, а все остальные строго больше. Поэтому любое
усреднение (в том числе с выбором опорной точки по pi) обязано быть
сосредоточено на множестве разрезов плотности 1/n: доказательство H13-I должно
указывать разрез почти точно.

**Следствие (точность H13-I).** `max_pi I(pi) >= floor((n−1)^2/4)` при всех
n >= 2 — отражения дают равенство. Ранее это было известно как конечные данные
(C33, 4 <= n <= 10); теперь доказано при всех n.

## 1. Обозначения

Разрез `(q, c)` удобнее записывать парой `(a, b)`, где `a = q + 1` — начало
линии по позициям, `b = q + 1 − c` — сдвиг значений; отображение
`(q, c) -> (a, b)` — биекция Z_n^2 -> Z_n^2. Линия:

```text
w_j = (pi(a + j) − b) mod n,   j = 0, ..., n − 1.
```

Ранг позиции i равен `p_i = (i − a) mod n`, ранг значения — `q_i = (pi(i) − b)
mod n`; `inv(a, b)` — число пар `{i, i'}` с противоположным порядком рангов.
Пару, у которой порядок рангов совпадает, называем *согласованной*
(неинверсия). Обозначим `N = C(n, 2)` и `D(a, b) = (число согласованных пар) −
inv(a, b) = N − 2·inv(a, b)` (числитель тау Кендалла).

Для `x` из Z_n, `x` ≠ 0, положим `h(x) = n − 2·(x mod n)`; значения h —
это `n − 2, n − 4, ..., 2 − n`, поэтому h инъективна на Z_n \ {0} и
`h(−x) = −h(x)`. Для пары позиций `i ≠ i'` с выбранным направлением `i -> i'`
пишем `r = (i' − i) mod n`, `s = (pi(i') − pi(i)) mod n`,
`h_r = h(i' − i) = n − 2r`, `h_s = n − 2s`. При смене направления r, s
заменяются на n − r, n − s, а `h_r, h_s` меняют знак оба сразу.

## 2. Лемма 1 (сколько разрезов согласуют пару)

Для любой пары позиций `i ≠ i'`: среди n^2 разрезов пара согласована ровно
для `(n − r)(n − s) + r·s` из них и инвертирована ровно для
`n(r + s) − 2rs`.

Доказательство. Пусть `m = (i − a) mod n`. Тогда `(i' − a) mod n = (m + r) mod
n`, и это равно `m + r` тогда и только тогда, когда `m <= n − 1 − r`. Значит
`p_i < p_{i'}` ⟺ `m ∈ {0, ..., n − 1 − r}` ⟺ a принадлежит множеству из
`n − r` значений `{i, i − 1, ..., i − (n − 1 − r)}`; в остальных r случаях
`p_{i'} < p_i`. Так же по b: `q_i < q_{i'}` ровно при `n − s` значениях b.
Параметры a и b независимы, поэтому число согласующих разрезов равно
`(n − r)(n − s) + r·s`, а остальные `n^2 − (n − r)(n − s) − rs = n(r + s) −
2rs` инвертируют пару. Выражения не зависят от выбора направления пары. ∎

## 3. Лемма 2 (тождество порогов) и переформулировка H13-I

Для всех n >= 1: `floor((n−1)^2/4) + floor(n^2/4) = C(n, 2)`.

Доказательство. При чётном n: `(n^2 − 2n)/4 + n^2/4 = (2n^2 − 2n)/4 =
n(n−1)/2`. При нечётном n: `(n−1)^2/4 + (n^2 − 1)/4 = (2n^2 − 2n)/4`. ∎

Следствие (переформулировка). Для фиксированного pi равносильны:

1. `I(pi) <= floor((n−1)^2/4)` (H13-I для этой pi);
2. существует разрез с не менее чем `floor(n^2/4)` согласованными парами;
3. `max_{a,b} D(a, b) >= floor(n/2)`.

Действительно, (1) ⟺ (2) — это лемма 2, а `D = N − 2·inv` даёт
`D >= N − 2·floor((n−1)^2/4) = 2·floor(n^2/4) − N = floor(n/2)`
(последнее равенство — прямая проверка по чётности n). Заметим, что
`D(a, b) ≡ N (mod 2)` и `floor(n/2) ≡ N (mod 2)`, так что порог в (3) —
наименьшее допустимое значение нужной чётности, большее `floor(n/2) − 2`.

## 4. Лемма 3 (точное среднее по разрезам)

Положим `A(pi) = sum_{i ≠ i'} h(i' − i) · h(pi(i') − pi(i))` (сумма по
упорядоченным парам). Тогда

```text
sum_{a,b} inv(a, b) = N · n^2 / 2 − A(pi)/4,
mean(pi) := (1/n^2) sum_{a,b} inv(a, b) = N/2 − A(pi)/(4n^2).
```

Доказательство. Для одной пары с параметрами (r, s):
`n(r + s) − 2rs = (n^2 − h_r·h_s)/2`, потому что `r = (n − h_r)/2`,
`s = (n − h_s)/2` и

```text
n(r + s) − 2rs = n^2 − n(h_r + h_s)/2 − (n^2 − n(h_r + h_s) + h_r h_s)/2
               = (n^2 − h_r h_s)/2.
```

Суммируя по всем N неупорядоченным парам (лемма 1) и учитывая, что сумма
`h_r h_s` по неупорядоченным парам равна `A(pi)/2`, получаем требуемое. ∎

Замечание. `D(a, b)` в среднем равно `A(pi)/(2n^2)`; на отражениях это число
отрицательно, тогда как нужен разрез с `D >= floor(n/2) > 0`.

## 5. Лемма 4 (норма) и лемма 5 (Коши — Буняковский)

**Лемма 4.** `sum_{x=1}^{n−1} (n − 2x)^2 = n(n−1)(n−2)/3`.

Доказательство. `sum (n^2 − 4nx + 4x^2) = (n−1)n^2 − 4n·n(n−1)/2 +
4·(n−1)n(2n−1)/6 = n(n−1)[n − 2n + (4n − 2)/3] = n(n−1)(n−2)/3`. ∎

**Лемма 5.** `|A(pi)| <= n^2(n−1)(n−2)/3`. Равенство достигается тогда и
только тогда, когда pi — поворот `pi(i) = i + const` (тогда A положительно
и максимально) или отражение `pi(i) = const − i` (тогда A отрицательно
и минимально).

Доказательство. Рассмотрим векторы `u`, `v`, занумерованные упорядоченными
парами `(i, i')`, `i ≠ i'`: `u_{i,i'} = h(i' − i)`, `v_{i,i'} =
h(pi(i') − pi(i))`; тогда `A(pi) = <u, v>`. Далее
`||u||^2 = sum_{i} sum_{x ≠ 0} h(x)^2 = n·n(n−1)(n−2)/3` (лемма 4).
Для v: pi — биекция, поэтому мультимножество разностей
`{(pi(i') − pi(i)) mod n}` по упорядоченным парам — это мультимножество всех
упорядоченных разностей элементов Z_n, то есть каждое ненулевое значение
встречается ровно n раз; значит `||v||^2 = ||u||^2`. Неравенство
Коши — Буняковского даёт `|A| <= ||u||·||v|| = n^2(n−1)(n−2)/3`.

Равенство означает `v = λu` при некотором вещественном λ, а равенство норм
даёт `λ = ±1`. При λ = 1 имеем `h(pi(i') − pi(i)) = h(i' − i)` для всех пар;
h инъективна на Z_n \ {0}, поэтому `pi(i') − pi(i) = i' − i`, то есть
`pi(i) = i + pi(0)`. При λ = −1, используя `−h(x) = h(−x)`, получаем
`pi(i') − pi(i) = −(i' − i)`, то есть `pi(i) = pi(0) − i`. Обратно, для этих
двух семейств равенство очевидно. ∎

## 6. Теорема C37

Для всех n >= 2 и всех pi:

```text
I(pi) <= mean(pi) = N/2 − A(pi)/(4n^2) <= n(n−1)/4 + (n−1)(n−2)/12
       = (n−1)(2n−1)/6,
```

и, поскольку I — целое, `I(pi) <= floor((n−1)(2n−1)/6)`.

Доказательство. Минимум не больше среднего (лемма 3), затем `−A <= |A| <=
n^2(n−1)(n−2)/3` (лемма 5) и
`n(n−1)/4 + (n−1)(n−2)/12 = (n−1)(3n + n − 2)/12 = (n−1)(2n−1)/6`. ∎

Второе неравенство обращается в равенство ровно на отражениях (лемма 5), то
есть `max_pi mean(pi) = (n−1)(2n−1)/6`. Для поворотов, наоборот,
`mean = N/2 − (n−1)(n−2)/12 = (n^2 − 1)/6`.

Сравнение с целью: `(n−1)(2n−1)/6 ≈ n^2/3`, а `floor((n−1)^2/4) ≈ n^2/4`;
отношение стремится к 4/3. Значения: n = 4, ..., 10 дают оценку C37
3, 6, 9, 13, 17, 22, 28 против фактического `max_pi I` = 2, 4, 6, 9, 12, 16, 20.

## 7. Лемма 6 (класс отражения) и точность H13-I

Пусть `pi_h(i) = h − i mod n`. Для разреза (a, b) линия равна
`w_j = (h − a − b − j) mod n = (C − j) mod n`, где `C = (h − a − b) mod n`;
каждое значение C получается ровно при n разрезах. При k = C + 1 линия — это
две убывающие серии: `(C, C−1, ..., 0)` (k наименьших значений) и
`(n−1, n−2, ..., C+1)`; все `k(n−k)` пар между сериями согласованы, все пары
внутри серий инвертированы. Поэтому

```text
inv = C(k, 2) + C(n − k, 2) = (k^2 + (n − k)^2 − n)/2,   k = 1, ..., n.
```

Минимум по k достигается при `k = n/2` (чётное n) и `k = (n ± 1)/2`
(нечётное n) и равен `floor((n−1)^2/4)`; следующее значение больше на 1
(чётное n) или на 2 (нечётное n). Итого:

- `I(pi_h) = floor((n−1)^2/4)` при всех n >= 2 и всех h, откуда
  `max_pi I(pi) >= floor((n−1)^2/4)` — граница H13-I точна при всех n;
- число разрезов с `inv = I` равно n при чётном n и 2n при нечётном.

## 8. Теорема C38 (пределы усреднения)

**(a)** Пусть λ — распределение вероятностей на Z_n × Z_n, не зависящее от pi,
и пусть число M(n) таково, что для всех pi и всех (a, b)

```text
sum_{k,l} λ(k, l) · inv(a + k, b + l) <= M(n).
```

Тогда `M(n) >= (n−1)(2n−1)/6`.

Доказательство. Усредним это неравенство по всем n^2 опорным точкам (a, b).
Слева получится `sum_{k,l} λ(k,l) · mean(pi) = mean(pi)`, так как при каждом
сдвиге (k, l) среднее по (a, b) равно среднему по всем разрезам. Значит
`mean(pi) <= M(n)` для всех pi; возьмём отражение (лемма 5). ∎

Поскольку `floor((n−1)^2/4) < (n−1)(2n−1)/6` при n >= 5 (n = 5: 4 < 6;
асимптотически 1/4 < 1/3), никакая такая схема H13-I не доказывает. Вместе
с C37 это означает: **оценка C37 — ровно предел метода усреднения**, и она
достигается уже равномерным средним.

**(b)** Пусть pi — отражение и λ — любое (возможно, зависящее от pi)
распределение на разрезах с `sum λ(a,b) · inv(a,b) <= floor((n−1)^2/4)`.
Так как `inv(a, b) >= I(pi_h) = floor((n−1)^2/4)` при всех (a, b), носитель λ
обязан лежать в множестве разрезов с `inv = I`, а в нём по лемме 6 ровно n
(или 2n) элементов из n^2. ∎

Смысл: выбор разреза в доказательстве H13-I должен быть точным с точностью до
множества плотности 1/n. В частности, на отражении усреднение по любому
семейству, содержащему хотя бы один неоптимальный разрез (а значит, по любому
семейству более чем из 2n разрезов), даёт строго больше `floor((n−1)^2/4)`.

## 9. Лемма 7 (блочный критерий) — достаточное условие H13-I

Пусть для некоторого разреза линия w распадается в прямую сумму блоков:
существуют `0 = j_0 < j_1 < ... < j_m = n` такие, что
`w({j_{t−1}, ..., j_t − 1}) = {j_{t−1}, ..., j_t − 1}` для всех t. Тогда
инверсии есть только внутри блоков, и при `b_t = j_t − j_{t−1}`

```text
I(pi) <= inv(w) <= sum_t C(b_t, 2).
```

В частности, если какая-то дуга из `floor(n/2)` подряд идущих позиций
переходит в дугу подряд идущих значений, то `I(pi) <= C(floor(n/2), 2) +
C(ceil(n/2), 2) = floor((n−1)^2/4)` — H13-I верна для такой pi. Отражения
попадают в этот случай (лемма 6), повороты тоже (все блоки единичные).

Критерий не универсален: при n = 5 у `pi(i) = 2i` все линии имеют вид
`(2j + t) mod 5`, и блочные разложения бывают только вида (1, 4) и (4, 1)
(например, `(0,2,4,1,3)` и `(1,3,0,2,4)`); лучшая блочная оценка равна
`C(4,2) = 6 > 4`, тогда как `I = 3`. Доля перестановок, для
которых критерий даёт H13-I, убывает: 24/24, 110/120, 612/720, 3346/5040,
21616/40320 при n = 4, ..., 8 (`checks/check_C37.py`, часть 6).

## 10. Что не доказано

H13-I (`I(pi) <= floor((n−1)^2/4)`) остаётся открытой: разрыв между C37
(`≈ n^2/3`) и целью (`≈ n^2/4`) — величина порядка `n^2/12`, и по теореме C38
он не закрывается никаким усреднением. Конечные данные (исчерпывающе при
4 <= n <= 14) и разобранные препятствия — в `docs/notes/h13i_verdict.md`.

Главный кандидат к доказательству, согласованный с C38 (разрез нужно
*выбирать*, а не усреднять), — гипотеза H13-S (CLAIMS C39): разрез,
минимизирующий расстояние Спирмена линии `sum_j (w_j − j)^2`, даёт
`inv <= floor((n−1)^2/4)` и даже ровно `I(pi)`
(`experiments/line_cut_rules.py`, `experiments/line_toric_scan.c`;
`docs/notes/h13i_verdict.md` §4.1).
