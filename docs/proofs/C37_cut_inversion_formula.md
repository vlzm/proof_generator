# C37 — замкнутая форма и рекуррентные леммы для f(a, b) (двойной разрез)

Сессия 9 (14.09.2026). Контекст: H13-I (`docs/notes/h13_line_model.md` §0, §6),
`experiments/line_model.py`, `experiments/line_profile.c` (C33, C35).
Код: `experiments/torus_cut.c` (torus_cut-1.0), чекер `checks/check_C37.py`
(независимая реализация на Python, PASS).

## 0. Определения

pi — перестановка Z_n. Для (a, b) в Z_n x Z_n (a — начало окна чтения
позиций, b — сдвиг значений) пусть

```
w_j(a, b) = (pi[(a + j) mod n] - b) mod n,   j = 0, ..., n-1,
f(a, b)   = inv(w(a, b))  (число инверсий).
```

Это переформулировка двойного разреза `(q, c)` из `docs/notes/h13_line_model.md`
§0 с `a = q + 1 mod n`, `b = q + 1 - c mod n` (эквивалентно `c = a - b mod n`);
`I(pi) = min_{a,b} f(a,b) = min_{q,c} inv(w)`.

Прямое вычисление `f(a,b)` для всех n^2 разрезов стоит `O(n^2)` на одну пару
`(a,b)` (подсчёт инверсий) `= O(n^4)` на pi — так устроен `line_profile.c`.
Ниже — точные приращения `f` при сдвиге `a` или `b` на 1, дающие алгоритм
`O(n^2)` на pi (лемма 1) и явную формулу `f(a,b)` через классические
статистики перестановки (лемма 2).

## 1. Лемма 1 (приращения). PROVED

Для любых pi, a, b в Z_n:

```
(i)  f(a+1 mod n, b) - f(a, b) = n - 1 - 2 * ((pi(a) - b) mod n)
(ii) f(a, b+1 mod n) - f(a, b) = n - 1 - 2 * ((pi^{-1}(b) - a) mod n)
```

**Доказательство (i).** Переход от окна, начинающегося с a, к окну,
начинающемуся с a+1, убирает элемент pi(a) с начала последовательности и
добавляет его в конец; взаимный порядок всех остальных n-1 элементов не
меняется (они лишь сдвигаются на одну позицию раньше, не переставляясь
между собой). Пусть `w0 = (pi(a) - b) mod n` — сдвинутое значение этого
элемента. До сдвига он стоит первым, поэтому образует инверсию с элементом
j > 0 тогда и только тогда, когда `w_j < w0`; таких j ровно `w0` (среди n
различных сдвинутых значений 0..n-1 ровно `w0` меньше `w0`, и все они — среди
остальных n-1, так как `w0` встречается только у самого этого элемента).
После сдвига тот же элемент стоит последним, поэтому образует инверсию с
более ранним элементом k тогда и только тогда, когда `w_k > w0`; таких k
ровно `n - 1 - w0`. Изменение: `(n - 1 - w0) - w0 = n - 1 - 2 w0`. Все прочие
пары не задействованы, так как их взаимный порядок сохранён. ∎

**Доказательство (ii).** Симметрично для значений: увеличение b на 1
уменьшает все сдвинутые значения на 1 по модулю n; единственный элемент,
чьё значение оборачивается через 0, — тот, что имел сдвинутое значение
ровно 0 до сдвига, то есть элемент на позиции `i0 = pi^{-1}(b)` (после сдвига
на b его исходное значение b становится нулём). У всех прочих элементов
сдвинутое значение просто уменьшается на 1 без оборота, поэтому их взаимный
порядок сохраняется. Пусть `pos = (i0 - a) mod n` — положение этого элемента
в окне чтения, начинающемся с a. До сдвига у него глобальный минимум (0),
поэтому он образует инверсию с каждым из `pos` элементов, стоящих раньше
(раньше + больше = инверсия, а все прочие значения больше 0), и ни с одним
из позже стоящих. После сдвига у него глобальный максимум (n-1), поэтому
он образует инверсию с каждым из `n - 1 - pos` элементов, стоящих позже
(он сам раньше и больше), и ни с одним из более ранних. Изменение:
`(n - 1 - pos) - pos = n - 1 - 2 pos`. ∎

Тождество проверено `checks/check_C37.py` (часть A) прямым перебором
`f(a,b)`, `f(a+1,b)`, `f(a,b+1)` против леммы на случайных pi при 2 <= n <= 9
(200 pi x n^2 троек `(a,b)`, PASS).

## 2. Лемма 2 (замкнутая форма). PROVED

Пусть `P(a) = sum_{i<a} pi(i)`, `R(b) = sum_{t<b} pi^{-1}(t)` (суммы по
представителям 0..n-1, не по модулю), `K(a,b) = #{i < a : pi(i) < b}`
(стандартная ранговая функция перестановочной матрицы — число точек
`(i, pi(i))` в прямоугольнике `[0,a) x [0,b)`). Тогда для всех
`0 <= a, b <= n`:

```
f(a, b) = inv(pi) + (n-1)(a+b) + 2ab - 2 P(a) - 2 R(b) - 2 n K(a, b).
```

**Доказательство.** Телескопируем лемму 1(i) от 0 до a при b = 0:

```
f(a, 0) = f(0,0) + sum_{s=0}^{a-1} (n - 1 - 2 pi(s)) = inv(pi) + (n-1) a - 2 P(a),
```

используя `(pi(s) - 0) mod n = pi(s)`. Затем телескопируем лемму 1(ii) от 0
до b при уже сдвинутом a:

```
f(a, b) = f(a, 0) + sum_{t=0}^{b-1} (n - 1 - 2 ((pi^{-1}(t) - a) mod n))
        = f(a, 0) + (n-1) b - 2 sum_{t=0}^{b-1} ((pi^{-1}(t) - a) mod n).
```

Для каждого t в [0, b) положим `x = pi^{-1}(t)`; тогда
`(x - a) mod n = x - a`, если `x >= a`, и `x - a + n` иначе. Значит

```
sum_{t=0}^{b-1} ((pi^{-1}(t) - a) mod n)
  = sum_{t<b} (pi^{-1}(t) - a) + n * #{t < b : pi^{-1}(t) < a}
  = R(b) - a b + n K(a, b),
```

так как `{t < b : pi^{-1}(t) < a}` и `{i < a : pi(i) < b}` — одно и то же
множество пар `(i, t) = (pi^{-1}(t), t)`, откуда `#{...} = K(a,b)`. Подставляя,

```
f(a,b) = inv(pi) + (n-1)a - 2P(a) + (n-1)b - 2(R(b) - ab + n K(a,b))
       = inv(pi) + (n-1)(a+b) + 2ab - 2P(a) - 2R(b) - 2n K(a,b). ∎
```

Проверено на границах: `a=0,b=0` даёт `inv(pi)` (P=R=K=0); `a=n,b=0` и
`a=0,b=n` дают `inv(pi)` снова (`P(n) = R(n) = n(n-1)/2`, `K(0,·) = K(·,0) = 0`,
согласуется с периодичностью f по обеим осям). Тождество проверено
`checks/check_C37.py` (часть B) прямым перебором на случайных pi при
2 <= n <= 9.

## 3. Следствие: алгоритм O(n^2)

Лемма 1 даёт `f(a, 0)` для всех a за O(n) (одно накопление), затем для
каждого a — `f(a, b)` для всех b за ещё O(n) (второе накопление по
`pi^{-1}`); итого `I(pi) = min_{a,b} f(a,b)` за O(n^2) вместо O(n^4)
(`experiments/torus_cut.c`, режим `exhaustive`/`family`/`search`). Это
понижение степени — практический инструмент, а не часть доказательства
H13-I: см. `docs/notes/h13_line_model.md` §7 о том, что даёт (и чего не даёт)
эта замкнутая форма для самой гипотезы.

`checks/check_C37.py` (часть C) сверяет O(n^2)-минимум по всем n! pi при
4 <= n <= 9 с ранее сертифицированными `max_pi I(pi)` из
`data/runs/line_profile/profile_n{n}.json` (построены отдельным O(n^4)
кодом `line_profile.c`) — совпадение точное, что служит независимой
перекрёстной проверкой обоих инструментов.
