# C37 — отражения: `I(pi_h) <= floor((n − 1)^2 / 4)` явным разрезом (часть H13-I)

Дата: 14.09.2026 (сессия 9, автоматическая). Статус: PROVED (локальный аудит
одной сессии, один автор). Чекер: `checks/check_C37.py`. Конвенции для `I(pi)`
и двойного разреза `(q, c)` — `experiments/line_model.py`,
`docs/notes/h13_line_model.md` §0, строка C33.

## Утверждение

Пусть n >= 2 и `pi_h(i) = h − i mod n` — отражение. Тогда

```text
I(pi_h) <= floor((n − 1)^2 / 4)
```

явным разрезом `(q, c)` с `q` не зависящим от h (после приведения к h = 0
инвариантностью ниже) и `c` таким, что переразмеченная линия распадается на
два блока длин `ceil(n/2)` и `floor(n/2)`, каждый — по отдельности строго
убывающая последовательность (внутри блока обращены все пары), причём первый
блок несёт все значения `0, ..., ceil(n/2) − 1`, второй — все значения
`ceil(n/2), ..., n − 1`, поэтому между блоками нет инверсий и

```text
I(pi_h) <= C(floor(n/2), 2) + C(ceil(n/2), 2) = floor((n − 1)^2 / 4)     (*)
```

точно (тождество (*) — лемма 0 ниже). Численно (`line_profile.c`, C33,
4 <= n <= 10) это неравенство — равенство; нижняя оценка `I(pi_h) >=
floor((n − 1)^2 / 4)` в общем n не доказывается здесь и не нужна для H13-I.

Это доказывает часть H13-I на всей бесконечной подсемье отражений (всех
n >= 2, всех h), а не только в проверенном диапазоне 4 <= n <= 10.

## Лемма 0 (тождество блоков)

Для всех n >= 1: `floor((n − 1)^2 / 4) = C(floor(n/2), 2) + C(ceil(n/2), 2)`.

Доказательство. Пусть n = 2m: правая часть = `2 * C(m, 2) = m(m − 1)`.
`(n − 1)^2 = (2m − 1)^2 = 4m^2 − 4m + 1`, значит
`floor((n − 1)^2/4) = m^2 − m = m(m − 1)`. Совпадает.
Пусть n = 2m + 1: правая часть = `C(m, 2) + C(m + 1, 2)
= [m(m − 1) + m(m + 1)] / 2 = m^2`. `(n − 1)^2 = 4m^2`, `floor(.../4) = m^2`.
Совпадает. ∎

## Лемма 1 (инвариантность I под value-поворотом)

Для любой pi и любого t: `I(pi + t) = I(pi)`, где `(pi + t)(i) := pi(i) + t mod n`.

Доказательство. По определению (`line_model.py`, `line_profile.c`)
`I(pi) = min_{q,c} inv(w)`, где `w_j = pi(q + 1 + j) − (q + 1 − c) mod n`.
Заменяя pi на `pi + t` и c на `c + t` (тоже пробегает Z_n при c ∈ Z_n) даёт
ту же линию w для каждого q: `(pi(q+1+j) + t) − (q + 1 − (c + t)) = pi(q+1+j)
− (q + 1 − c) mod n`. Множества `{(q,c)}` и `{(q, c+t)}` совпадают как
множества Z_n × Z_n, поэтому минимумы равны. ∎

Следствие. `pi_h = pi_0 + h` (поточечно: `pi_h(i) = pi_0(i) + h mod n`),
значит `I(pi_h) = I(pi_0)` для всех h. Достаточно доказать утверждение при
h = 0.

## Лемма 2 (разрез q = 0 для pi_0)

Пусть `pi_0(i) = (n − i) mod n` (`pi_0(0) = 0`, `pi_0(i) = n − i` при
i = 1, ..., n − 1). Разрез q = 0 даёт линию (до сдвига c) `v = (pi_0(1), ...,
pi_0(n − 1), pi_0(0)) = (n − 1, n − 2, ..., 1, 0)` — строго убывающая
последовательность всех значений 0, ..., n − 1.

Для сдвига `c` со значением `shift = (0 + 1 − c) mod n = s`, значения линии —
`w_j = (v_j − s) mod n`. Покажем: для `s ∈ {0, ..., n − 1}`,

```text
inv(w) = C(n − s, 2) + C(s, 2).
```

Доказательство. `v_j = n − 1 − j` для j = 0, ..., n − 1 (перечисление всех
значений по убыванию), поэтому `w_j = (n − 1 − j − s) mod n`. Для j таких, что
`n − 1 − j − s >= 0`, т.е. `j <= n − 1 − s`, имеем `w_j = n − 1 − j − s` без
обёртывания; таких j — `n − s` штук (j = 0, ..., n − 1 − s), и на них w строго
убывает от `n − 1 − s` до 0 — значения `{0, ..., n − 1 − s}`. Для остальных
`s` индексов j = n − s, ..., n − 1 (обёртывание) `w_j = n − 1 − j − s + n =
2n − 1 − j − s`, тоже строго убывает по j — значения `{n − s, ..., n − 1}`.
Итак линия w — конкатенация двух строго убывающих блоков длин `n − s` и `s`;
первый несёт все значения `< n − s`, второй — все значения `>= n − s`, и
первый блок идёт раньше по позиции. Значит между блоками нет инверсий (все
пары "элемент первого блока — элемент второго" уже в верном порядке: меньшее
значение раньше), а внутри строго убывающего блока длины k инверсии — все
`C(k, 2)` пар. Итого `inv(w) = C(n − s, 2) + C(s, 2)`. ∎

## Доказательство утверждения

По лемме 1 достаточно h = 0. По лемме 2, для q = 0 и любого s ∈ {0, ..., n−1}
(эквивалентно c = 1 − s mod n) `I(pi_0) <= inv(w) = C(n − s, 2) + C(s, 2)`.
Берём `s = floor(n/2)` (тогда `n − s = ceil(n/2)`): по лемме 0

```text
I(pi_0) <= C(ceil(n/2), 2) + C(floor(n/2), 2) = floor((n − 1)^2 / 4).
```

Вместе с леммой 1 — `I(pi_h) <= floor((n − 1)^2 / 4)` для всех n >= 2,
всех h. ∎

## Замечание: связь с C32

C32 доказывает верхнюю оценку на **длину слова** для отражений через явную
конструкцию «две дуги», не через линейную модель; блочная структура здесь
(два строго убывающих блока без взаимных инверсий) — независимое наблюдение
о комбинаторике I(pi), не переиспользует C32. Формула `N_X = floor((n−1)^2/4)`
в C32 численно совпадает с I(pi_h) здесь (обе — минимальное число обменов на
кратчайшем/сокращённом слове); это согласуется с C33 (`I = N_X` на слоях,
близких к максимуму), но не выведено одно из другого в этом файле.

## Область действия и ограничения

Доказана только подсемья отражений (n значений h из n^2 возможных разрезов на
каждый h; всего n перестановок из n! при данном n). Общий случай H13-I (для
произвольной pi) остаётся CONJECTURED — см. `docs/notes/h13_line_model.md`
§6a (сессия 9): блочная конструкция существенно использует аффинность pi_h
(контигуальный блок позиций отображается в контигуальный блок значений), что
для произвольной pi неверно.
