# C37 — двойной разрез: точные тождества и переформулировки H13-I

Дата: 16.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py` (PASS: леммы 1–7 — все pi при
4 <= n <= 6 исчерпывающе и выборка 300 pi — отражения, аффинные, случайные,
seed 12345 — при 7 <= n <= 9; отражения при 4 <= n <= 20). Эксперимент:
`experiments/torus_cut_scan.c` (torus_cut_scan-1.0), отчёт
`data/runs/torus_cut_scan/report.md`.

Доказательство элементарно и не использует N1, C16–C21, C28, C32 и таблицы
расстояний. Оно ничего не утверждает о самой H13-I: это инструменты
(тождества и равносильные формы), на которых строятся попытки её доказать.

## 0. Обозначения

`pi` — перестановка Z_n, `n >= 2`. Двойной разрез — пара `(a, b)` из Z_n × Z_n;
линия разреза

```text
w_j(a, b) = (pi(a + j) − b) mod n,   j = 0, ..., n − 1.
```

Связь с обозначениями `docs/notes/h13_line_model.md` §0: `a = q + 1`,
`b = q + 1 − c`; соответствие (q, c) <-> (a, b) биективно, поэтому «минимум
по n^2 разрезам» в обеих записях — одно и то же.

```text
inv(a, b) = число инверсий линии w(a, b),
I(pi)     = min_{a,b} inv(a, b),
B_n       = n(n − 1)/2 = C(n, 2) = floor(n^2/4) + floor((n − 1)^2/4)   (C12),
S(a, b)   = B_n − 2 inv(a, b).
```

`Gamma = {(i, pi(i)) : i из Z_n}` — множество точек тора Z_n × Z_n.

**H13-I**: `I(pi) <= floor((n − 1)^2/4)` для всех pi и всех n >= 2.

## 1. Лемма 1 (согласие пар и порог floor(n/2))

`S(a, b)` = (число согласованных пар) − (число инверсий), и

```text
I(pi) <= floor((n − 1)^2/4)   <=>   max_{a,b} S(a, b) >= floor(n/2).
```

Доказательство. Пар всего `C(n, 2) = B_n`, каждая либо инверсия, либо
согласована, поэтому согласованных `B_n − inv` и разность равна
`B_n − 2 inv = S`. Далее `inv <= floor((n − 1)^2/4)` равносильно
`S >= B_n − 2 floor((n − 1)^2/4) = floor(n^2/4) − floor((n − 1)^2/4)` (по C12),
а `floor(n^2/4) − floor((n − 1)^2/4) = floor(n/2)` разбором чётности:
при чётном n это `n^2/4 − (n^2 − 2n)/4 = n/2`, при нечётном —
`(n^2 − 1)/4 − (n − 1)^2/4 = (n − 1)/2`. ∎

Замечание. Отсюда `S(a, b) ≡ B_n ≡ floor(n/2) (mod 2)` — все три величины
имеют одну чётность, так что оценка `max S >= floor(n/2) − 1` автоматически
усиливается до `>= floor(n/2)`.

## 2. Лемма 2 (две циклические порядки; равносильная формулировка H13-I)

Для `a` из Z_n определим линейный порядок позиций
`i <_a i'  <=>  (i − a) mod n < (i' − a) mod n`
(это линеаризация циклического порядка позиций разрезом в `a`), и аналогично
для значений `<'_b`. Тогда пара `{i, i'}` согласована при разрезе `(a, b)`
тогда и только тогда, когда `i <_a i'` равносильно `pi(i) <'_b pi(i')`.

Следовательно `B_n − inv(a, b)` — число совпадений (агрементов) двух линейных
порядков на одном n-элементном множестве, из которых первый — линеаризация
циклического порядка «позиции», второй — линеаризация циклического порядка
«значения». Поэтому **H13-I равносильна**:

> Для любых двух циклических порядков на n-элементном множестве найдутся
> их линеаризации, совпадающие не менее чем на `floor(n^2/4)` из `C(n, 2)` пар.

Доказательство. Первое утверждение — определение инверсии линии: `w_j < w_k`
при `j < k` означает ровно, что позиции упорядочены по `<_a`, а значения — по
`<'_b`. Второе — переформулировка первого плюс лемма 1. ∎

Точность. Пусть второй циклический порядок — обращение первого (в терминах
перестановок: отражения `pi_h(i) = h − i`). Тогда при любом разрезе линия —
две убывающие серии длин `k` и `n − k`, число инверсий равно
`C(k, 2) + C(n − k, 2)`, минимум по `k` достигается при `k = floor(n/2)` и
равен `floor((n − 1)^2/4)`: при `n = 2m` это `2 C(m, 2) = m(m − 1)`, при
`n = 2m + 1` — `C(m, 2) + C(m + 1, 2) = m^2`. Итак на отражениях
`I(pi_h) = floor((n − 1)^2/4)` и в лемме 1 равенство. ∎

## 3. Лемма 3 (приращения по каждому разрезу)

Для всех `(a, b)`:

```text
inv(a + 1, b) − inv(a, b) = (n − 1) − 2 * w_0(a, b),    w_0(a, b) = (pi(a) − b) mod n;
inv(a, b + 1) − inv(a, b) = (n − 1) − 2 * p(a, b),      p(a, b) = (pi^{-1}(b) − a) mod n.
```

Здесь `w_0` — первый элемент линии, `p` — индекс наименьшего элемента линии.
Эквивалентно `S(a + 1, b) − S(a, b) = 4 w_0 − 2(n − 1)` и
`S(a, b + 1) − S(a, b) = 4 p − 2(n − 1)`.

Доказательство. Линия `w(a + 1, b)` получается из `w(a, b)` переносом первого
элемента в конец. Пары, не содержащие его, не меняются. Значения линии — все
элементы Z_n, поэтому элементов меньше `w_0` ровно `w_0`, больше — `n − 1 − w_0`.
В начале он давал `w_0` инверсий (с меньшими, стоящими после него), в конце —
`n − 1 − w_0` (с большими, стоящими до него). Разность `(n − 1) − 2 w_0`.

Линия `w(a, b + 1)` получается из `w(a, b)` так: элемент со значением 0
(он стоит на индексе `p`) становится равным `n − 1`, остальные уменьшаются
на 1. Взаимный порядок остальных сохраняется. Этот элемент давал `p` инверсий
(со всеми, стоящими до него), станет давать `n − 1 − p`. ∎

Следствие (лемма C заметки `h13_line_model.md` §4). Если `(a, b)` минимизирует
`inv`, то `w_0(a, b) <= (n − 1)/2 <= w_0(a − 1, b)` и
`p(a, b) <= (n − 1)/2 <= p(a, b − 1)`; суммирование приращений по цепочке
сдвигов даёт префиксные условия леммы C. ∎

Следствие (сумма приращений). При фиксированном `b` величины `w_0(a, b)`,
`a` из Z_n, пробегают Z_n ровно по разу; поэтому `a -> S(a, b)` — замкнутая
ломаная с фиксированным мультимножеством шагов
`{4g − 2(n − 1) : g из Z_n}`, порядок шагов задаётся `pi`. То же по `b`
с `pi^{-1}`. ∎

## 4. Лемма 4 (смешанная вторая разность = расхождение)

```text
S(a + 1, b + 1) − S(a + 1, b) − S(a, b + 1) + S(a, b) = 4n * [pi(a) = b] − 4.
```

Доказательство. По лемме 3 `S(a, b + 1) − S(a, b) = 4 p(a, b) − 2(n − 1)`,
поэтому левая часть равна `4 (p(a + 1, b) − p(a, b))`. Так как
`p(a, b) = (pi^{-1}(b) − a) mod n`, то `p(a + 1, b) = p(a, b) − 1` при
`p(a, b) >= 1` и `p(a + 1, b) = n − 1` при `p(a, b) = 0`; последнее
равносильно `pi(a) = b`. Значит левая часть равна `−4` вне `Gamma` и
`4(n − 1)` на `Gamma`, что и записано. ∎

Следствие (прямоугольники). Для `0 <= a_1 <= a_2 <= n`, `0 <= b_1 <= b_2 <= n`
(прямоугольник не оборачивается вокруг тора) и `R = [a_1, a_2) × [b_1, b_2)`:

```text
S(a_2, b_2) + S(a_1, b_1) − S(a_1, b_2) − S(a_2, b_1)
        = 4n * ( |R ∩ Gamma| − |R| / n ),
```

то есть ровно `4n` умножить на расхождение прямоугольника (число точек
перестановки минус «ожидаемое» `площадь/n`). В частности, на любом
прямоугольнике, не содержащем точек `Gamma`, функция `S` субмодулярна
(вторая смешанная разность отрицательна). ∎

## 5. Лемма 5 (замкнутая форма)

Для `0 <= a, b <= n` (в фундаментальной области):

```text
S(a, b) = S(0, 0)
        + 4 * sum_{i < a} ( pi(i) − (n − 1)/2 )
        + 4 * sum_{v < b} ( pi^{-1}(v) − (n − 1)/2 )
        + 4n * ( K(a, b) − a b / n ),
```

где `K(a, b) = #{ i < a : pi(i) < b }` — число точек `Gamma` в коробке
`[0, a) × [0, b)`. Функция продолжается на Z × Z периодически (проверка:
подстановка `a = n` и `b = n` возвращает то же значение).

Доказательство. `S(a, 0)` и `S(0, b)` получаются суммированием леммы 3
(при `b = 0` имеем `w_0(a, 0) = pi(a)`; при `a = 0` имеем `p(0, b) = pi^{-1}(b)`),
а смешанный член — суммированием леммы 4 по коробке `[0, a) × [0, b)`.
Периодичность: при `a = n` первая сумма равна `4 * (n(n−1)/2) − 2n(n−1) = 0`,
а `K(n, b) = b` даёт `4n(b − b) = 0`. ∎

## 6. Лемма 6 (двойственность обращения значений)

Пусть `pi*(i) = (−1 − pi(i)) mod n` (обращение циклического порядка значений).
Тогда

```text
S_{pi*}(a, b) = − S_{pi}(a, (−b) mod n)   для всех (a, b).
```

Следовательно `max_{a,b} S_{pi*} = − min_{a,b} S_{pi}`, и H13-I равносильна
утверждению «для всех pi верно `min_{a,b} S_pi(a, b) <= − floor(n/2)`».
В частности, если H13-I верна, то для всех pi
`max_{a,b} S_pi − min_{a,b} S_pi >= 2 floor(n/2)`.

Доказательство. Пусть `t_j = (pi(a + j) + b) mod n` — линия `pi` при разрезе
`(a, −b)`. Линия `pi*` при разрезе `(a, b)` равна
`(−1 − pi(a + j) − b) mod n = n − 1 − t_j`, то есть дополнению линии `t`.
Дополнение обращает каждую пару, поэтому `inv = C(n, 2) − inv(t)` и
`S = B_n − 2(B_n − inv(t)) = −(B_n − 2 inv(t))`. ∎

## 7. Лемма 7 (тройки: инвариант чётности)

Для тройки точек `T` из `Gamma` пусть `inv_3(T; a, b)` — число инверсий среди
её трёх пар при разрезе `(a, b)`. Тогда:

1. чётность `inv_3(T; a, b)` не зависит от `(a, b)` (инвариант торического
   класса тройки);
2. `(n − 2) * S(a, b) = sum_T ( 3 − 2 inv_3(T; a, b) )`, сумма по всем
   `C(n, 3)` тройкам;
3. если чётность чётна, то `3 − 2 inv_3` равно 3 ровно на 3 из 9 «клеток»
   (позиция `a` среди трёх дуг позиций × позиция `b` среди трёх дуг значений)
   и `−1` на остальных шести; если нечётна — `−3` на 3 клетках и `1` на шести;
   в обоих случаях три особые клетки образуют матрицу перестановки 3 × 3.

Доказательство. (1) Сдвиг `a -> a + 1` либо не меняет линейный порядок трёх
позиций, либо циклически сдвигает его; циклический сдвиг трёх элементов —
чётная перестановка, значит знак `(−1)^{inv_3}` сохраняется. То же для `b`.
(2) Каждая пара лежит ровно в `n − 2` тройках, поэтому
`sum_T inv_3 = (n − 2) inv`, и `sum_T (3 − 2 inv_3) = 3 C(n, 3) − 2(n − 2) inv
= (n − 2)(B_n − 2 inv)`. (3) Зафиксируем циклический порядок позиций
`(P_1, P_2, P_3)`. Если циклический порядок значений тот же, то линейный
образец — тождество (при совпадении номеров дуг, `inv_3 = 0`) или один из двух
циклов длины 3 (`inv_3 = 2`); если обратный — образец есть транспозиция
(`inv_3 = 1`) либо полное обращение (`inv_3 = 3`), и последнее происходит
ровно при трёх согласованных парах дуг. ∎

Замечание. Отсюда `(n − 2) S(a, b) = (O − E) + 4 ( G_+(a, b) − G_-(a, b) )`,
где `E`, `O` — числа чётных и нечётных троек (инварианты pi), а `G_±` — числа
троек в своих трёх особых клетках. Среднее по всем `n^2` разрезам даёт
`(n − 2) * mean S = (E − O)/3`.

## 8. Что из этого следует и чего не следует

Леммы 1–2 дают чистую комбинаторную формулировку H13-I (две циклические
порядки, максимум согласия линеаризаций) с точным экстремумом на обращённых
парах. Леммы 3–5 полностью описывают «ландшафт» `S` на торе: он задаётся
расхождениями прямоугольников относительно `Gamma` и одной аддитивной
константой. Лемма 6 показывает, что задача самодвойственна.

Ни одна из них не доказывает H13-I: все они — тождества. Отрицательные
результаты сессии 9 (какие способы вывести H13-I из этих тождеств не
работают) собраны в `docs/notes/h13_line_model.md` §7.
