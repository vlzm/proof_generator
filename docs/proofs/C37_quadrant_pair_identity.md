# C37 — тождество о числе инвертирующих разрезов для пары точек на торе

Дата: 14.09.2026 (сессия 9). Статус: PROVED (для всех n >= 2; элементарное
доказательство, локальный аудит одной сессии). Чекер: `checks/check_C37.py`
(PASS: пары — все `a, b` при 4 <= n <= 12 с несколькими базовыми точками;
суммы по всем разрезам — все pi при 4 <= n <= 8; случайные точки и
перестановки при 11 <= n <= 60). Часть работы над H13-I
(`docs/notes/h13_line_model.md` §6, вердикт сессии 9 —
`docs/notes/h13i_session9.md`). Доказательство не использует таблицы и не
зависит от чекера.

Эта лемма была явно сформулирована как рабочая гипотеза (без доказательства)
в задании сессии 9 и в `h13_line_model.md` §6 («в терминах точек (i, pi(i))
на торе — точка (q, s) тора, лежащая в „одноимённых” квадрантах»); здесь она
доказана и проверена. Сама по себе она **не доказывает H13-I** — см. вердикт
сессии 9, где показано, что прямое усреднение по всем n^2 разрезам (следствие
этой леммы) не даёт нужной оценки почти ни для одной pi.

## Определения

Двойной разрез `(q, c)` и линия `w` — `docs/notes/h13_line_model.md` §0:
`w_j = pi(q+1+j) − (q+1−c) mod n`, `j = 0, ..., n−1`. Позиция элемента i на
линии: `j(i) = (i − q − 1) mod n`. Значение элемента i на линии, после сдвига:
`val(v) = (v − shift) mod n`, где `shift = (q+1−c) mod n` и `v = pi(i)`.

Пара позиций `i1 != i2` — **инверсия** разреза `(q, c)`, если та из них, что
раньше на линии, получает большее значение: `(j(i1) < j(i2)` и `val(pi(i1)) >
val(pi(i2)))` или `(j(i2) < j(i1)` и `val(pi(i2)) > val(pi(i1)))`.

## Утверждение

Пусть n >= 2, `i1 != i2` — позиции, `v1 = pi(i1)`, `v2 = pi(i2)` — их значения
(различны, так как pi — перестановка). Положим

```text
a = (i2 − i1) mod n,   b = (v2 − v1) mod n     (оба в {1, ..., n−1}).
```

Тогда среди n^2 двойных разрезов `(q, c) из Z_n x Z_n` ровно

```text
a(n − b) + (n − a)b
```

делают пару `{i1, i2}` инверсией; оставшиеся `ab + (n−a)(n−b)` — нет.

Следствие (свёртка по всем парам). Для любой pi

```text
sum_{(q,c)} inv(w_{q,c}) = sum_{i1<i2} [a(n−b) + (n−a)b],
```

где сумма справа — по всем `C(n,2)` неупорядоченным парам позиций (значение
`a(n−b)+(n−a)b` не зависит от того, какая из двух позиций пары названа `i1`:
обмен `i1 <-> i2` переводит `(a,b)` в `(n−a, n−b)`, и выражение симметрично).
В частности среднее `inv` по всем n^2 разрезам равно `(1/n^2)` этой суммы —
величина, вычисленная в `h13_line_model.md` §6 для `id_n` и `sigma_n`
((n^2−1)/6 и в среднем ~n^2/3 в зависимости от перестановки, см. §3 ниже) —
теперь получается из явной формулы, а не только численно.

## Доказательство

**Шаг 1 (репараметризация).** Отображение `(q, c) -> (q, shift)`, где
`shift = (q+1−c) mod n`, — биекция `Z_n x Z_n -> Z_n x Z_n`: при
фиксированном q оно линейно по c с коэффициентом −1, значит биективно на
Z_n; значит для каждого q ровно одно значение c даёт каждый shift. Поэтому
подсчёт по всем n^2 парам `(q,c)` эквивалентен подсчёту по всем n^2 парам
`(q, shift)`, где q и shift пробегают Z_n **независимо**.

**Шаг 2 (позиционная сторона зависит только от q).** `j(i) = (i−q−1) mod n`
не зависит от c (только от q). Зафиксируем `j1 = j(i1)`; тогда
`j(i2) = (j1 + a) mod n` (так как `i2 − i1 = a`, а j — сдвиг на константу
`−q−1` от i, применённый к обеим позициям одинаково). При q, пробегающем Z_n,
`j1` пробегает Z_n биективно (это тот же сдвиг, `j1 = (i1−q−1) mod n`,
линеен по q с коэффициентом −1). Сравним `j1` и `j(i2) = (j1+a) mod n`:

- если `j1 + a < n` (т.е. `j1 <= n−1−a`, это n−a значений j1), то
  `j(i2) = j1+a > j1`: `i1` раньше на линии;
- если `j1 + a >= n` (т.е. `j1 >= n−a`, это a значений j1), то
  `j(i2) = j1+a−n < j1`: `i2` раньше.

Итого: ровно `n − a` значений q дают «`i1` раньше», ровно `a` значений q дают
«`i2` раньше».

**Шаг 3 (значенная сторона зависит только от shift, дословно тот же довод).**
`val(v) = (v − shift) mod n`. Положим `w1 = val(v1)`; тогда `w2 = val(v2) =
(w1 + b) mod n` (так как `v2 − v1 = b`). При shift, пробегающем Z_n
независимо от q (шаг 1), `w1` пробегает Z_n биективно. Тем же сравнением,
что в шаге 2 (роли `a` и `j1` играют `b` и `w1`):

- `n − b` значений shift дают `w1 < w2` (т.е. `val(v2) > val(v1)`);
- `b` значений shift дают `w1 > w2`.

**Шаг 4 (объединение).** Пара — инверсия, если (`i1` раньше **и** `val(v1) >
val(v2)`) или (`i2` раньше **и** `val(v2) > val(v1)`). Так как q и shift
независимы (шаг 1), число разрезов в первом случае — `(n−a) * b` (n−a
значений q из шага 2, b значений shift из шага 3), во втором —
`a * (n−b)`. События не пересекаются (позиционный порядок при данном q
фиксирован), поэтому общее число инвертирующих разрезов —

```text
(n − a) b + a (n − b) = a(n − b) + (n − a) b.  ∎
```

## Лемма 2 (инвариантность строчной суммы; PROVED)

Для любой pi и любого q сумма `sum_{c=0}^{n-1} inv(w_{q,c})` — обозначим её
`R(q)` — **не зависит от q**; следовательно, `R(q) = (1/n) * sum_{i1<i2}
[a(n−b)+(n−a)b]` (правая часть следствия выше, свёртка по всем n^2 разрезам,
делённая на n) при любом q.

Это доказывает (а не просто иллюстрирует численно), что кандидат-доказательство
H13-I «выбрать q, минимизирующий строчное среднее `avg_c inv(w_{q,c})`, затем
взять по пигeонхолу лучшее c» **не сильнее** плоского усреднения по всем n^2
разрезам: у него нет свободы выбора q — все n строк дают одно и то же среднее.
Это объясняет численное совпадение результатов кандидатов (A) и (B) в
`docs/notes/h13i_session9.md` §2 (`experiments/h13i_averaging_scan.py`) — не
как случайность на выборке, а как точное тождество.

**Доказательство.** Пусть `u^{(q)} = (pi(q+1), pi(q+2), ..., pi(q+n))`
(индексы mod n) — массив значений в порядке линии при разрезе q. Стандартное
тождество (та же биекция шага 1–3 выше, применённая при фиксированном q и
варьируемом shift): для любого массива u, являющегося перестановкой Z_n,

```text
sum_{shift=0}^{n-1} inv((u_i − shift) mod n)_i = sum_{p<r} [(u_r − u_p) mod n].
```

(Каждая пара `p<r` вносит `(u_r−u_p) mod n` по тому же счёту «n−b против b»
шага 3, примененному к одной паре с фиксированным позиционным порядком —
это в точности R(q) при данном q, так как варьирование c при фиксированном q
и есть варьирование shift по всем Z_n.)

Переход `q -> q+1`: `u^{(q+1)}` получается из `u^{(q)}` циклическим сдвигом
влево на 1 (первый элемент `x = u^{(q)}_0` переходит в конец, остальные
сдвигаются на одну позицию). Пары, не содержащие x, сохраняют и значения, и
относительный порядок (переиндексация `i -> i−1` для `i = 1, ..., n−1`
сохраняет порядок), поэтому их суммарный вклад в `R(q)` и `R(q+1)` одинаков.
Остаётся сравнить вклад пар, содержащих x:

- в `u^{(q)}`: x на позиции 0 (первая), для каждого `y = u^{(q)}_i, i > 0`
  вклад — `(y − x) mod n` (x раньше); сумма по всем n−1 значениям y — сумма
  `(y−x) mod n` по всем y != x, а `(y−x) mod n` пробегает `{1, ..., n−1}`
  ровно по разу (pi — биекция), так что сумма равна `n(n−1)/2`;
- в `u^{(q+1)}`: x на позиции n−1 (последняя), вклад каждой пары —
  `(x − y) mod n` (x позже); по тому же доводу сумма также `n(n−1)/2`.

Значит `R(q+1) − R(q) = n(n−1)/2 − n(n−1)/2 = 0`. По индукции `R(q)`
одинаково для всех q. ∎

## Замечания

1. Формула симметрична по перестановке `(a,b) -> (n−a, n−b)` (переобозначение
   `i1 <-> i2`), как и должно быть: это тождество о неупорядоченной паре
   точек. Она также инвариантна относительно одновременного поворота позиций
   и значений (замены `i1, i2 -> i1+t, i2+t`, `v1, v2 -> v1+u, v2+u` для любых
   `t, u из Z_n`) — сдвиг `t` переводит множество n^2 разрезов в себя
   биективно (замена `q -> q − t`), аналогично `u` — заменой `c` или, что то
   же, `shift`; в шаге 1–3 это уже заложено, так как результат зависит только
   от `a, b`, не от `i1, v1`. Часть 1 чекера отдельно проверяет это прямым
   перебором нескольких базовых точек.
2. Правая часть `a(n−b) + (n−a)b` — это в точности «неодноимённые квадранты»
   из формулировки задания сессии 9 и `h13_line_model.md` §6: если считать,
   что разрез `(q, shift)` попадает в один из четырёх «квадрантов» размеров
   `ab` (`i1` раньше, `val(v1) < val(v2)`, т.е. и позиционный, и значенный
   порядок совпадают с исходным «i1 -> i2, v1 -> v2»), `a(n−b)`, `(n−a)b`,
   `(n−a)(n−b)` (симметричный случай), то инверсия — это ровно два
   «неодноимённых» квадранта `a(n−b)` и `(n−a)b`, что и требовалось
   проверить в задании.
3. Следствие о сумме по всем парам объясняет численные наблюдения
   `h13_line_model.md` §6 (среднее `inv` по n^2 разрезам для `id_n` и
   `sigma_n`) явной формулой; численная проверка — `crosscheck.py` в отчёте
   сессии (воспроизведена в части 2, 3 чекера).
4. Лемма — точный комбинаторный факт о паре точек на торе; она не использует
   структуру перестановки pi за пределами значений `(a, b)` конкретной пары.
   Само по себе тождество не даёт оценки `I(pi) <= floor((n−1)^2/4)`
   (H13-I): свёртка по всем n^2 разрезам даёт **среднее** значение inv,
   а не оценку минимума — среднее оказывается заметно выше цели уже для
   почти всех pi при малых n (часть «негативный результат» вердикта сессии
   9, `docs/notes/h13i_session9.md` §2). Лемма используется там как точный
   инструмент диагностики (а не как доказательство), в согласии с
   отвергнутым в предыдущих сессиях подходом «усреднение по всем n^2
   разрезам» (`h13_line_model.md` §6).
