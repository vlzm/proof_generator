# C37 — тождество «инверсии двойного разреза = среднее минус ковариация»

Дата: 14.09.2026 (сессия 9). Ядро oracle-1.0 не используется: утверждение
чисто комбинаторное, о числе инверсий линии, а не о ходах LRX.

Чекер: `checks/check_C37.py` (PASS), отчёт `data/runs/check_C37/`.
Контекст: H13-I (`docs/notes/h13_line_model.md` §6, PLAN §8).

## 0. Обозначения

`pi` — биекция Z_n -> Z_n (торическая перестановка: точки `(i, pi(i))` на торе
Z_n x Z_n). Двойной разрез — пара `(a, b) ∈ Z_n^2`. Для точки i положим

```text
s_i = (i - a) mod n        индекс i в линии (позиция после разреза)
t_i = (pi(i) - b) mod n    ранг значения pi(i) после сдвига
```

Оба набора `(s_i)` и `(t_i)` — перестановки множества {0, ..., n-1}. Линия —
слово `w` с `w_{s_i} = t_i`; число инверсий

```text
inv(a, b) = #{ (i, j) : s_i < s_j, t_i > t_j }.
```

Соответствие с конвенцией `experiments/line_model.py` (`w_j = pi(q+1+j) -
(q+1-c) mod n`): `a = q+1`, `b = q+1-c`; когда `(q, c)` пробегает Z_n^2,
`(a, b)` пробегает Z_n^2. Поэтому

```text
I(pi) = min_{q,c} inv = min_{a,b} inv(a, b).
```

Далее `B_n = n(n-1)/2`, а

```text
psi(t) = (t mod n) - (n-1)/2      (центрированная «пила»; sum_{t∈Z_n} psi(t) = 0)
V(a, b) = sum_{i∈Z_n} psi(i - a) * psi(pi(i) - b)
        = sum_i (s_i - (n-1)/2) (t_i - (n-1)/2)          — ковариация Спирмена
inv_avg(pi) = n^{-2} * sum_{a,b} inv(a, b)
```

Значения `psi` полуцелые при чётном n; все утверждения — тождества в Q.

## 1. Лемма 1 (знак как аффинная функция разности)

Для i != j положим `u_ij = (j - i) mod n ∈ {1..n-1}`, `E_ij = 1 - 2 u_ij / n`.
Тогда

```text
sgn(s_j - s_i) = E_ij + (2/n) (s_j - s_i).
```

Доказательство. `s_j - s_i ≡ u_ij (mod n)` и `s_j - s_i ∈ (-n, n)`, значит
`s_j - s_i ∈ {u_ij, u_ij - n}`. В первом случае `s_j > s_i` (так как
`u_ij >= 1`) и правая часть равна `1 - 2u/n + 2u/n = 1`. Во втором случае
`s_j - s_i = u_ij - n < 0`, то есть `s_j < s_i`, и правая часть равна
`1 - 2u/n + 2(u - n)/n = -1`. ∎

Аналогично для значений: `v_ij = (pi(j) - pi(i)) mod n`, `F_ij = 1 - 2 v_ij/n`,
`sgn(t_j - t_i) = F_ij + (2/n)(t_j - t_i)`.

Заметим `E_ji = -E_ij` (ибо `u_ji = n - u_ij`) и `F_ji = -F_ij`.

## 2. Лемма 2 (строчные суммы равны нулю)

Для каждого i: `sum_{j != i} E_ij = 0` и `sum_{j != i} F_ij = 0`.

Доказательство. Отображение `j -> (j - i) mod n` — биекция `Z_n \ {i}` на
{1, ..., n-1}, поэтому `sum_{j != i} u_ij = n(n-1)/2` и
`sum_{j != i} E_ij = (n-1) - (2/n) n(n-1)/2 = 0`. Для F то же самое: `pi` —
биекция, поэтому `j -> (pi(j) - pi(i)) mod n` тоже биекция `Z_n \ {i}` на
{1, ..., n-1}. ∎

Именно здесь используется, что перестановка торическая: позиции и значения
пробегают **все** вычеты.

## 3. Лемма 3 (корреляция Кендалла)

Пусть `K(a, b) = sum_{i<j} sgn(s_j - s_i) sgn(t_j - t_i)`. Тогда
`K = B_n - 2 inv(a, b)` и

```text
K(a, b) = sum_{i<j} E_ij F_ij + (4/n^2) * sum_{i<j} (s_j - s_i)(t_j - t_i).
```

Доказательство. Первое равенство: каждая пара даёт +1, если согласована, и -1,
если инвертирована; согласованных `B_n - inv`. Второе: перемножаем два
представления леммы 1 и суммируем. Перекрёстные слагаемые равны

```text
(2/n) sum_{i<j} E_ij (t_j - t_i)   и   (2/n) sum_{i<j} F_ij (s_j - s_i).
```

Произведение `E_ij (t_j - t_i)` симметрично по (i, j) (оба множителя
антисимметричны), поэтому

```text
sum_{i<j} E_ij (t_j - t_i) = (1/2) sum_{i != j} E_ij (t_j - t_i)
 = (1/2) [ sum_j t_j sum_{i != j} E_ij - sum_i t_i sum_{j != i} E_ij ] = 0
```

по лемме 2 (и `E_ij = -E_ji`). Аналогично второе перекрёстное слагаемое. ∎

## 4. Лемма 4 (переход к ковариации)

```text
sum_{i<j} (s_j - s_i)(t_j - t_i) = n * V(a, b).
```

Доказательство. `2 sum_{i<j} (s_j-s_i)(t_j-t_i) = sum_{i,j} (s_j-s_i)(t_j-t_i)
= 2n sum_i s_i t_i - 2 (sum_i s_i)(sum_i t_i)`. Так как `(s_i)` и `(t_i)` —
перестановки {0..n-1}, обе суммы равны `n(n-1)/2`, и
`V = sum_i s_i t_i - n(n-1)^2/4`, откуда
`n V = n sum_i s_i t_i - n^2 (n-1)^2/4 = n sum s_i t_i - (sum s)(sum t)`. ∎

## 5. Теорема C37

Для любой биекции `pi: Z_n -> Z_n` и любого разреза `(a, b)`

```text
inv(a, b) = inv_avg(pi) - (2/n) * V(a, b).                       (C37.1)
```

Доказательство. По леммам 3 и 4 `K = S + (4/n) V`, где
`S = sum_{i<j} E_ij F_ij` не зависит от `(a, b)`. Значит

```text
inv(a, b) = (B_n - K)/2 = (B_n - S)/2 - (2/n) V(a, b).
```

Остаётся проверить `(B_n - S)/2 = inv_avg`, то есть `sum_{a,b} V(a,b) = 0`:

```text
sum_{a,b} V(a,b) = sum_i ( sum_a psi(i-a) ) ( sum_b psi(pi(i)-b) ) = 0,
```

так как `sum_{t∈Z_n} psi(t) = 0`. Усреднение (C37.1) по всем n^2 разрезам даёт
`inv_avg = (B_n - S)/2`. ∎

Следствие: **минимизация числа инверсий по двойному разрезу эквивалентна
максимизации ковариации Спирмена** `V(a, b)` линеаризованной перестановки:

```text
I(pi) = inv_avg(pi) - (2/n) * max_{a,b} V(a, b).                 (C37.2)
```

Замечание. Для одной фиксированной перестановки Кендалл и Спирмен не связаны
аффинно; аффинность возникает именно на семействе n^2 разрезов одной торической
перестановки и опирается на лемму 2.

## 6. Следствие 1 (квадратичная форма)

Пусть `D(a, b) = sum_i (s_i - t_i)^2`. Тогда

```text
D(a, b) = n(n^2 - 1)/6 - 2 V(a, b),                              (C37.3)
inv(a, b) = const(pi) + D(a, b)/n,    const(pi) = inv_avg - (n^2-1)/6. (C37.4)
```

Доказательство. `sum_i s_i^2 = sum_i t_i^2 = (n-1)n(2n-1)/6`, поэтому
`D = n(n-1)(2n-1)/3 - 2 sum_i s_i t_i = n(n-1)(2n-1)/3 - 2V - n(n-1)^2/2`
и `n(n-1)(2n-1)/3 - n(n-1)^2/2 = n(n-1)(n+1)/6`. ∎

Геометрически: линейный порядок тем ближе к тождественному (в смысле суммы
квадратов смещений), чем меньше инверсий, и связь **точная**.

Полезная переформулировка «лагов». Положим `c = a - b` и `l_i = s_i - t_i`.
Тогда `sum_i l_i = 0` всегда (обе последовательности — перестановки
{0..n-1}), `l_i ≡ (i - pi(i)) - c (mod n)` и `l_i ∈ {delta_i, delta_i - n}`, где
`delta_i = ((i - pi(i)) - c) mod n` зависит только от c. Число индексов
с «обёрнутым» выбором `l_i = delta_i - n` равно `m = (sum_i delta_i)/n`
при **любом** a, а само множество таких индексов есть
`S(a) = { i : a ∈ J_i }`, `J_i = (pi(i) + c, i]` — дуга длины `delta_i`
(дуги `J_i` покрывают каждую точку Z_n ровно m раз). Поэтому

```text
D(a,b) = sum_i delta_i^2 + n * sum_{i ∈ S(a)} (n - 2 delta_i),
```

и минимизация по a при фиксированном c — задача о выборе точки, покрытой
«длинными» дугами.

## 6a. Следствие 1b (форма через расхождение)

Пусть `N(a, b) = #{x < a : pi(x) < b}` — число точек в «нижнем левом» боксе
`[0,a) x [0,b)`, а `D(a, b) = N(a, b) - a b / n` — его расхождение
(на границе `D(a,0) = D(0,b) = D(a,n) = D(n,b) = 0`). Тогда

```text
V(a, b) = n * Phi(a, b) + gamma(pi),                             (C37.3b)
Phi(a, b) = n D(a, b) - sum_{b'=1}^{n-1} D(a, b') - sum_{a'=1}^{n-1} D(a', b),
gamma(pi) = T - S(n-1) + n(n-1)^2/4,
T = sum_i i * pi(i),  S = n(n-1)/2.
```

Доказательство. При `i, a ∈ {0..n-1}` имеем
`psi(i-a) = (i - a) + n*[i < a] - (n-1)/2`, аналогично для значений. Раскрывая
произведение в определении V и собирая слагаемые (`sum_i i = sum_i pi(i) = S`,
`R(a) = sum_{x<a} pi(x)`, `P(b) = sum_{y<b} pi^{-1}(y)`):

```text
V(a,b) = T - S(a+b+n-1) + n(n-1)^2/4 - n a b + n P(b) + n R(a) + n^2 N(a,b).
```

Далее `sum_{x<a} psi(pi(x)) = R(a) - a(n-1)/2 = -sum_{b'=1}^{n-1} D(a, b')`
(потому что `R(a) = na - a - sum_{b'=1}^{n-1} N(a,b')` и
`sum_{b'=1}^{n-1} a b'/n = a(n-1)/2`), и симметрично
`P(b) - b(n-1)/2 = -sum_{a'=1}^{n-1} D(a', b)`. Подстановка даёт (C37.3b). ∎

Смысл: `I(pi)` определяется максимумом «локального минус маргинальные»
расхождения точечного множества `{(i, pi(i))}` по всем боксам с углом в начале
координат. Это ещё одна форма для атаки на (C37.7): нужна нижняя оценка
`max_{a,b} Phi`.

## 7. Следствие 2 (константа)

Пусть `Q(pi) = sum_{i,j ∈ Z_n} psi(j - i) * psi(pi(j) - pi(i)) = sum_i V(i, pi(i))`.
Тогда

```text
inv_avg(pi) = (n^2 - 1)/4 - Q(pi)/n^2,                           (C37.5)
const(pi)   = (n^2 - 1)/12 - Q(pi)/n^2.                          (C37.6)
```

Доказательство. Из `psi(j-i) = u_ij - (n-1)/2` следует `E_ij = (1 - 2 psi(j-i))/n`
и `F_ij = (1 - 2 psi(pi(j)-pi(i)))/n`, поэтому

```text
S = sum_{i<j} E_ij F_ij = (1/(2n^2)) sum_{i != j} (1-2psi(j-i))(1-2psi(pi(j)-pi(i))).
```

Здесь `sum_{i != j} 1 = n(n-1)`; `sum_{i != j} psi(j-i) = n * sum_{t != 0} psi(t)
= -n psi(0) = n(n-1)/2` и столько же для второго множителя;
`sum_{i != j} psi(j-i) psi(pi(j)-pi(i)) = Q - n psi(0)^2 = Q - n(n-1)^2/4`.
Подстановка даёт `S = 2Q/n^2 - (n-1)/2`, откуда
`inv_avg = (B_n - S)/2 = (n^2-1)/4 - Q/n^2` и (C37.6) по (C37.4). Равенство
`Q = sum_i V(i, pi(i))` — прямая подстановка `a = i`, `b = pi(i)` в определение V. ∎

Проверка: для `pi = id` имеем `Q = n sum_t psi(t)^2 = n^2(n^2-1)/12`, значит
`const = 0` и `inv(a,b) = D(a,b)/n`; при a = b это даёт 0. Для отражения
`sigma_n(i) = -i` и n = 7: `Q = -49`, `const = 5`, `I = 5 + 28/7 = 9 =
floor(36/4)`.

## 8. Следствие 3 (эквивалентная форма H13-I)

Положим `V* = max_{a,b} V(a,b)` и

```text
c_n = (n^2-1)/4 - floor((n-1)^2/4) = (2n-1)/4 при чётном n, (n-1)/2 при нечётном.
```

Тогда

```text
H13-I для pi   <=>   2 V*(pi) + Q(pi)/n >= n * c_n.              (C37.7)
```

Доказательство. `I(pi) <= floor((n-1)^2/4)` <=>
`inv_avg - (2/n) V* <= floor((n-1)^2/4)` <=> (по (C37.5))
`(2/n) V* + Q/n^2 >= c_n`; умножение на n даёт (C37.7). ∎

Так как `V(i, pi(i)) <= V*` для каждого i, то `Q <= n V*`, и потому

```text
V*(pi) >= n * c_n / 3   =>   H13-I для pi.                       (C37.8)
```

(C37.8) — достаточное, но не необходимое условие: на отражениях (C37.7)
выполнено с равенством, а `V*` там примерно `n^3/24`, то есть запас (C37.8)
велик.

## 9. Точная проверка экстремальности отражений

Для `pi(i) = -i` величина `V(a,b)` зависит только от `m = (a + b) mod n`:
`V = -C(m) - n psi(-m)`, где `C(m) = sum_t psi(t) psi(t+m) = n(n^2-1)/12 -
(n/2) m (n-m)` — автокорреляция пилы. При чётном n максимум по m достигается
при `m = (n+2)/2` и

```text
V(0) = Q/n = n(n-1)(5-n)/12,     V* - V(0) = (n/2)(n-2)^2/4 = n(n-2)^2/8,
2 V* + Q/n = 3 V(0) + n(n-2)^2/4 = n[(n-1)(5-n) + (n-2)^2]/4 = n(2n-1)/4 = n c_n,
```

то есть (C37.7) обращается в равенство. Полное вычисление и проверка при
4 <= n <= 60 — в `checks/check_C37.py`, часть E.

## 10. Область и статус

(C37.1)–(C37.8) — тождества и эквивалентности, доказанные для всех n >= 2 и всех
биекций `pi` (локальный аудит одной сессии). Они **не** доказывают H13-I:
(C37.7) переносит задачу на нижнюю оценку максимума ковариации `V*`, которая
остаётся открытой. Конечные проверки самой H13-I: `4 <= n <= 14`
(`experiments/line_imax.c`, все торические классы).
