# C37 — H13-I как задача о переключениях: точная релаксация `S >= floor(n/2)`

Дата: 17.09.2026 (сессия 9). Статус: теорема 4 и леммы 1–3, 7 — PROVED
(локальный аудит одной сессии, один автор); сама H13-I — OPEN (см. §6).
Чекер: `checks/check_C37.py`. Эксперимент: `experiments/h13i_balanced_cut.c`,
отчёт `data/runs/h13i_switching/`. Доказательство не использует N1, таблицы
расстояний и ходы окружности: всё утверждение — о перестановках и инверсиях.

## Утверждение

H13-I (`docs/notes/h13_line_model.md` §5–6): для каждой перестановки pi из Z_n
в Z_n найдётся двойной разрез (поворот позиций и поворот значений) с

```text
inv <= floor((n − 1)^2 / 4).
```

Здесь доказано:

1. (лемма 1) H13-I равносильна: у каждой pi есть разрез с `S >= floor(n/2)`,
   где `S = (#согласованных пар) − (#несогласованных пар)` линии.
2. (лемма 2) n^2 разрезов дают n^2 (не обязательно различных) переключений
   (switching) одной и той же ±1-разметки рёбер K_n; переход к соседнему разрезу — переключение одной
   вершины. Класс переключений (two-graph) — инвариант торического класса pi.
3. (**теорема 4**) для **любой** ±1-разметки рёбер K_n найдётся переключение
   с `S >= floor(n/2)`; оценка точна (полностью отрицательная разметка).
   Эквивалентно: всякий two-graph на n вершинах содержит граф с не менее чем
   `floor(n^2/4)` рёбрами.
4. (следствие 5) релаксация H13-I — «разрешено любое переключение вместо n^2
   разрезов» — верна при всех n >= 2 с той же константой и с тем же
   экстремальным классом (отражения). Константа `floor((n−1)^2/4)` в H13-I —
   в точности граница переключений.
5. (предложение 6, отрицательное) доказательство H13-I «найти разрез,
   устойчивый к переключению каждой одной вершины» невозможно: при n = 8 таких
   разрезов нет ровно у двух представителей (`pi(i) = 3i` и `pi(i) = 5i mod 8`),
   при n = 9 — у 77 из 40320 (строка C38).
6. (лемма 7) явная формула `S(q, s)` через корреляцию пилы; из неё — точное
   среднее S по всем n^2 разрезам (почему усреднение не работает).

## 0. Обозначения

`pi` — перестановка Z_n. Двойной разрез — пара `(q, s)` из Z_n^2; линия

```text
w^{q,s}_j = (pi(q + j) − s) mod n,   j = 0, ..., n − 1.
```

Когда (q, s) пробегает Z_n^2, линия пробегает все повороты позиций и значений,
то есть весь торический класс pi (совпадает с семейством §0 заметки
`h13_line_model.md` с точностью до переобозначения параметров).
`inv(q, s) = inv(w^{q,s})`, `I(pi) = min_{q,s} inv(q, s)`.

Вершины — элементы `u` из Z_n (номер позиции на окружности; элемент u несёт
значение pi(u)). Для u != v положим

```text
chi_{uv}(q, s) = +1, если пара {u, v} согласована в линии w^{q,s}
                     (порядок по позициям и порядок по значениям совпадают),
                 −1 иначе (пара — инверсия),
S(q, s) = sum_{u < v} chi_{uv}(q, s) = N − 2 inv(q, s),   N = n(n − 1)/2.
```

Явно: `chi_{uv} = +1` тогда и только тогда, когда `(q ∈ (u, v]) = (s ∈ (pi(u), pi(v)])`,
где `(a, b]` — дуга Z_n от a вперёд до b (это утверждение доказано в лемме 7.1).

## 1. Лемма 1 (переформулировка)

Для всех n >= 2 и всех целых inv: `inv <= floor((n−1)^2/4)` равносильно
`N − 2 inv >= floor(n/2)`.

Доказательство. `N − 2inv >= floor(n/2)` равносильно
`inv <= (N − floor(n/2))/2`. При чётном n: `(n(n−1)/2 − n/2)/2 = n(n−2)/4 =
floor((n−1)^2/4)`. При нечётном n: `(n(n−1)/2 − (n−1)/2)/2 = (n−1)^2/4 =
floor((n−1)^2/4)`. ∎

Итак, H13-I ⟺ `max_{q,s} S(q, s) >= floor(n/2)` для каждой pi. Заметим
`S ≡ N (mod 2)` и `N ≡ floor(n/2) (mod 2)`: оценка тесна по чётности, то есть
доказать `S > floor(n/2) − 2` — то же самое, что доказать H13-I.

## 2. Лемма 2 (разрезы — это переключения)

Переключением (Seidel switching) разметки chi по множеству W ⊆ Z_n называем
разметку `chi^W`, где знак ребра {u, v} меняется тогда и только тогда, когда
ровно один из концов лежит в W.

Тогда для всех (q, s):

```text
chi(q + 1, s) = chi(q, s)^{{q}},           (переключение вершины q)
chi(q, s + 1) = chi(q, s)^{{pi^{-1}(s)}},  (переключение вершины pi^{-1}(s))
chi(q, s)     = chi(0, 0)^{U(q,s)},  U(q, s) = A_q Δ B_s,
A_q = {0, 1, ..., q − 1},   B_s = {i : pi(i) < s}.
```

Доказательство. Линия w^{q+1,s} получается из w^{q,s} переносом первого элемента
(это элемент с номером позиции q) в конец. Для пары, не содержащей его, порядок
по позициям и по значениям не изменился. Для пары {q, u}: порядок значений тот
же, порядок позиций противоположный, значит chi_{qu} меняет знак. Это и есть
переключение вершины q. Аналогично w^{q,s+1} получается вычитанием 1 из всех
значений по модулю n: значение 0 (у элемента `pi^{-1}(s)` в исходной нумерации)
становится наибольшим, порядок значений в парах с этим элементом меняется на
противоположный, остальные пары не затронуты. Наконец, `A_q` — множество
элементов, «перенесённых в конец» при переходе от 0 к q, `B_s` — множество
элементов, значения которых «подняты наверх» при переходе от 0 к s; композиция
переключений — переключение по симметрической разности. ∎

Следствия. (а) Все n^2 разметок chi(q, s) лежат в одном классе переключений;
класс (two-graph) — инвариант торического класса pi. (б) Инвариант класса —
произведение по треугольнику: `chi_{uv} chi_{vw} chi_{uw}` не зависит от
разреза (это циклическая согласованность тройки: статистика Фишера–Ли).
(в) Семейство разрезов — не более n^2 из 2^{n−1} переключений (у отражений
разметка зависит только от q + s, различных всего n); множества `U(q, s)` —
в точности множества «северо-запад ∪ юго-восток» для n^2 разбиений решётки
позиций×значений.

## 3. Лемма 3 (степени и переключения)

Положим `d_v(q, s) = sum_{u != v} chi_{vu}(q, s) = (n − 1) − 2 inv_v`, где
`inv_v` — число инверсий линии, в которых участвует элемент v. Тогда

```text
2 S = sum_v d_v,
S(chi^W) = S(chi) − 2 ( sum_{v in W} d_v − 2 sum_{e ⊆ W} chi_e ).
```

Доказательство. Первое — подсчёт каждого ребра дважды. Второе: переключение по
W меняет знак ровно у рёбер разреза (W, V∖W); сумма chi по этим рёбрам равна
`sum_{v in W} d_v − 2 sum_{e ⊆ W} chi_e` (сумма степеней внутри W учитывает
внутренние рёбра дважды), и S уменьшается на удвоенную эту величину. ∎

В частности: `S(chi^{{v}}) = S(chi) − 2 d_v` и
`S(chi^{{u,v}}) = S(chi) − 2 (d_u + d_v − 2 chi_{uv})`.

## 4. Теорема 4 (граница переключений)

**Пусть n >= 2 и chi — произвольная ±1-разметка рёбер K_n. Тогда существует
W ⊆ V с `S(chi^W) >= floor(n/2)`.** Оценка точна: у класса переключений
полностью отрицательной разметки максимум равен ровно `floor(n/2)`.

Доказательство. Возьмём W, на котором `S = S(chi^W)` максимально (множеств
конечное число), и обозначим через d_v степени этой разметки.

(а) Переключение одной вершины не увеличивает S, значит `d_v >= 0` для всех v
(лемма 3).

(б) Чётность: `d_v = (n − 1) − 2 inv_v ≡ n − 1 (mod 2)`.

Случай n чётно. Тогда каждое d_v нечётно и неотрицательно, то есть `d_v >= 1`,
поэтому `2S = sum_v d_v >= n` и `S >= n/2 = floor(n/2)`.

Случай n нечётно. Тогда каждое d_v чётно и неотрицательно. Пусть
`Z = {v : d_v = 0}`, `z = |Z|`. Для u, v из Z переключение пары {u, v} не
увеличивает S, значит `d_u + d_v − 2 chi_{uv} >= 0`, то есть `chi_{uv} <= 0`,
то есть `chi_{uv} = −1`: Z — клика из отрицательных рёбер. Но каждая вершина v
из Z имеет ровно `(n − 1)/2` отрицательных рёбер (`d_v = 0`), а внутри Z их уже
`z − 1`, поэтому `z − 1 <= (n − 1)/2`, то есть `z <= (n + 1)/2`. Все остальные
вершины имеют `d_v >= 2`, значит

```text
2 S = sum_v d_v >= 2 (n − z) >= 2 (n − (n + 1)/2) = n − 1,
S >= (n − 1)/2 = floor(n/2).
```

Точность. Для полностью отрицательной разметки переключение по множеству из u
вершин делает положительными ровно рёбра разреза, поэтому

```text
S = u(n − u) − C(u, 2) − C(n − u, 2) = 2u(n − u) − N,
```

что максимально при сбалансированном u и равно `2 floor(n^2/4) − n(n−1)/2 =
floor(n/2)`. Значит, для этого класса переключений максимум равен ровно
`floor(n/2)`, и константа теоремы неулучшаема при каждом n. ∎

Замечание (эквивалент). В терминах графов: положительный граф разметки
пробегает класс переключений (two-graph); `S = 2e − N`, поэтому теорема 4
означает: **всякий two-graph на n вершинах содержит граф с не менее чем
`floor(n^2/4)` рёбрами**, и экстремален класс пустого графа (его максимальный
представитель — `K_{floor(n/2), ceil(n/2)}`, граница Мантеля).

## 5. Следствие 5 (релаксация H13-I)

Для каждой pi класс переключений её разметки содержит разметку с
`S >= floor(n/2)`, то есть «линию» с `inv <= floor((n−1)^2/4)`, если разрешить
произвольное переключение вместо n^2 разрезов. Экстремальный случай
релаксации — класс полностью отрицательной разметки; он же реализуется
отражениями: при `pi(i) = h − i` линия разреза (q, s) имеет вид
`(c, c−1, ..., 0, n−1, ..., c+1)` с `c = c(q + s)`, при c = n − 1 все пары
инвертированы (разметка полностью отрицательна), а
`inv = C(c+1, 2) + C(n−1−c, 2)`, что при сбалансированном c равно ровно
`floor((n−1)^2/4)`. Значит, для отражений семейство разрезов достигает границы
релаксации, и

```text
min_pi max_W S = floor(n/2)   (теорема 4 и отражения),
min_pi max_{q,s} S <= floor(n/2)   (отражения),
```

а H13-I — это в точности обратное неравенство
`min_pi max_{q,s} S >= floor(n/2)` (проверено исчерпывающе при 4 <= n <= 10,
C33; здесь не доказано). Иначе говоря: константа H13-I доказана как константа
релаксации, а открытым остаётся вопрос реализуемости — достигает ли
**семейство разрезов** границы своего класса переключений там, где это нужно.

## 6. Предложение 6 (чего не хватает; отрицательный результат)

Доказательство теоремы 4 использует переключения одной вершины (и пар при
нечётном n). Назовём разрез (q, s) **устойчивым**, если `d_v(q, s) >= 0` для
всех v, то есть каждый элемент линии участвует не более чем в
`floor((n−1)/2)` инверсиях. Если бы у каждой pi был устойчивый разрез, то при
чётном n доказательство теоремы 4 (случай n чётно) дословно давало бы H13-I.

Это неверно: устойчивого разреза нет уже при n = 8 у двух представителей
торических классов — `pi(i) = 3i` и `pi(i) = 5i (mod 8)`, то есть
`(0,3,6,1,4,7,2,5)` и `(0,5,2,7,4,1,6,3)`; у них минимум по разрезам
`max_v inv_v` равен 4 при пороге 3. При n = 9 таких представителей 77 из 40320
(минимум `max_v inv_v` равен 5 при пороге 4). Подробности и минимальность —
строка C38, `data/counterexamples/C38_no_balanced_cut_n8.json`.

Более того, семейство разрезов вообще не всегда достигает максимума своего
класса переключений: при n = 8 это так для 26 из 5040 представителей
(максимальный разрыв 6: `pi(i) = 5i` даёт `max_cut S = 6`, `max_switch S = 12`),
при n = 9 — для 248 из 40320 (максимальный разрыв 4). При 4 <= n <= 7 разрыв
всегда нулевой.

Вывод: доказательство H13-I обязано использовать переключения по множествам
вида `U(q, s) = A_q Δ B_s` (лемма 2в) нелокально; локальных условий
(одна вершина, пара вершин) недостаточно, и «глобальная» релаксация, хотя и
даёт верную константу, не даёт самого утверждения.

## 7. Лемма 7 (явная формула S и среднее по разрезам)

Положим `⟨t⟩ = t mod n ∈ {0, ..., n−1}` и `σ(t) = ⟨t⟩ − n/2` (нечётная пила:
`σ(−t) = −σ(t)` при t ≢ 0, `σ(0) = −n/2`). Тогда для всех (q, s)

```text
S(q, s) = (4/n) K(q, s) + (2/n^2) T − 1 − n/2,
K(q, s) = sum_{i in Z_n} σ(i − q) σ(pi(i) − s),
T       = sum_{i, j in Z_n} σ(j − i) σ(pi(j) − pi(i)) = sum_i K(i, pi(i)).
```

Доказательство. 7.1. Для u != v и любого q: элемент u стоит в линии w^{q,s}
раньше v тогда и только тогда, когда `q ∉ (u, v]`. Действительно, позиции в
линии равны `⟨u − q⟩` и `⟨v − q⟩`, и
`⟨v − q⟩ = ⟨u − q⟩ + ⟨v − u⟩ − n·[⟨u − q⟩ + ⟨v − u⟩ >= n]`; так как
`⟨v − u⟩ >= 1`, неравенство `⟨v − q⟩ > ⟨u − q⟩` равносильно
`⟨u − q⟩ + ⟨v − u⟩ < n`, то есть (при q != u) `⟨q − u⟩ > ⟨v − u⟩`, то есть
`q ∉ (u, v]`; при q = u обе части верны. Отсюда

```text
⟨v − q⟩ − ⟨u − q⟩ = ⟨v − u⟩ − n · 1_{(u,v]}(q),
```

и, подставляя `⟨t⟩ = σ(t) + n/2`, получаем для знака порядка позиций

```text
phi_{uv}(q) = 1 − 2·1_{(u,v]}(q) = −(2/n) A_{uv}(q),
A_{uv}(q) = σ(v − u) + σ(u − q) − σ(v − q).
```

Аналогично для знака порядка значений `psi_{uv}(s) = −(2/n) A'_{uv}(s)` с
`A'_{uv}(s) = σ(pi(v) − pi(u)) + σ(pi(u) − s) − σ(pi(v) − s)`. По определению
согласованности `chi_{uv} = phi_{uv} psi_{uv} = (4/n^2) A_{uv} A'_{uv}`.

7.2. Суммируем по всем упорядоченным парам (включая u = v, где
`A = A' = σ(0) = −n/2`, вклад `n · n^2/4`):

```text
sum_{u, v} A_{uv} A'_{uv}
  = T + sum_{u,v} σ(v − u)(σ(pi(u) − s) − σ(pi(v) − s))
      + sum_{u,v} (σ(u − q) − σ(v − q)) σ(pi(v) − pi(u))
      + sum_{u,v} (σ(u − q) − σ(v − q))(σ(pi(u) − s) − σ(pi(v) − s)).
```

Так как `sum_{v} σ(v − c) = sum_{t} σ(t) = −n/2` для любого c (и то же для
значений, ибо pi — биекция), вторая и третья суммы равны нулю, а четвёртая
равна

```text
2n sum_u σ(u − q) σ(pi(u) − s) − 2 (sum_u σ(u − q))(sum_v σ(pi(v) − s))
  = 2n K(q, s) − n^2/2.
```

Диагональ (u = v) даёт `n · σ(0)^2 = n^3/4`; вычитая её и деля на 2 (переход к
неупорядоченным парам), получаем

```text
S(q, s) = (2/n^2) [ T + 2n K(q, s) − n^2/2 − n^3/4 ]
        = (4/n) K(q, s) + (2/n^2) T − 1 − n/2.   ∎
```

Следствия. (а) `sum_{q,s} K(q, s) = n^3/4`, поэтому среднее S по всем n^2
разрезам равно `(2/n^2) T − n/2`; это единственная «бесплатная» оценка снизу
для максимума, и её недостаточно. (б) Для отражения `pi(i) = h − i`
`T = n^2 (6n − n^2 − 2)/12`, среднее `inv` по разрезам равно
`n^2/3 − n/2 + 1/6`, среднее числа неинверсий — `(n^2 − 1)/6 < floor(n^2/4)`
(совпадает с §6 заметки `h13_line_model.md`: усреднение по всем n^2 разрезам
не даёт H13-I). (в) `T = sum_i K(i, pi(i))` — сумма K по n «разрезам на самой
кривой»; отсюда же видно, что замена максимума средним по любому семейству
разрезов, задаваемому самой pi (свёртка `mu ⋆ mu^-`), тоже не проходит:
проверено, что при n = 5 и n = 7 максимум таких средних меньше `floor(n/2)`
(`data/runs/h13i_switching/report.md`).
