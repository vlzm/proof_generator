## 1. Обозначения и статус варианта

Обозначения N1 — PROBLEM §5.2. Для перестановки pi из S_n и сдвига c из Z_n:

```text
f_c(i) = pi(i) + c mod n
F_c, S_c   — суммы F(C), S(C) = 2M(C) + E(C) − 1 по нетривиальным циклам f_c
b(C)       — переносчик цикла C (N1 §2.1)
H(c)       — маршрут N1 §3: H(0) = n, H(c) = n + delta_n(0,c) − 2 при c != 0
R_c        — длина кратчайшей прогулки по Z_n из 0 в c, проходящей через все
             переносчики (вариант, правило 16 AGENTS.md)
B_n        = n(n−1)/2 = 2P − floor(n/2),   P = floor(n^2/4)
```

**Лемма 1 (перенос C18 на вариант).** Пусть W — произвольная прогулка по Z_n
из 0 в c, посещающая каждый переносчик b(C). Соберём слово: идём по W, при
первом посещении переносчика b(C) вставляем локальное слово W_C из N1 §2.
Тогда полученное слово сортирует pi и имеет длину не более `2F_c − S_c + |W|`
(в самой конструкции — ровно столько: подсчёт сокращений N1 §2.4 даёт
|W_C| = 2F(C) − S(C) с равенством, что и проверяет `strict_upper.py`).

*Доказательство.* Дословно N1 §3. Тождество (3.1) показывает, что локальное
слово, применённое в системе координат своего переносчика, меняет только свой
цикл и не меняет внешнее позиционирование `rho_b`; поэтому порядок обработки
циклов и вид прогулки между переносчиками не важны. После обработки всех циклов
и прихода в c равенство (3.2) даёт тождественную перестановку. Длина: сумма
|W_C| = 2F(C) − S(C) по (2.6) плюс |W|. Единственное требование к прогулке —
посетить каждый переносчик и закончить в c; маршрут N1 длины H(c) — частный
случай. □

Следствие: `R_c <= H(c)` для всех c (маршрут N1 — допустимая прогулка), и
`d(pi, 1) <= 2F_c − S_c + R_c` для каждого c, значит и для минимума по c.
Локальные слова, выбор переносчика и соглашение о подписанном кратчайшем шаге
(правило 16) — как в N1, без изменений; изменён только внешний маршрут.

Полезная переформулировка цели H10. Так как `B_n = 2P − floor(n/2)`,

```text
2F_c − S_c + R_c <= B_n + 1   <=>   S_c − R_c >= 2(F_c − P) + floor(n/2) − 1.  (1.1)
```

При этом `mean_c F_c = P` (N1 §3), поэтому при «медианном» сдвиге
(`F_c = sum_i delta_n(i − pi(i), c)`, минимум — 1-медиана мультимножества
разностей) слагаемое `2(F_c − P)` не положительно, и всё сводится к тому,
насколько S_c больше R_c.

## 2. Теорема A: отражения

**Теорема A.** Пусть n >= 4, h из Z_n и `pi(i) = h − i mod n`. Тогда

```text
min_c [2F_c − S_c + R_c] <= B_n      при нечётном n и при n = 0 (mod 4),
min_c [2F_c − S_c + R_c] <= B_n + 1  при n = 2 (mod 4),
```

причём при n = 2 (mod 4) и нечётном h верна и более сильная оценка `<= B_n`.
Все три оценки достигаются уже минимумом по двум сдвигам c из {0, 1}.

### 2.1. Структура f_c

**Лемма A1.** При `pi(i) = h − i` и `g = h + c` имеем `f_c(i) = g − i`, то есть
f_c — инволюция. Её неподвижные точки — решения `2i = g (mod n)`:
при нечётном n ровно одна; при чётном n две (i = g/2 и g/2 + n/2), если g чётно,
и ни одной, если g нечётно. Остальные точки разбиты на транспозиции
{i, g − i}; их число T равно (n − 1)/2, n/2 − 1 или n/2 соответственно.

**Лемма A2 (S = 3 для любой транспозиции).** Для транспозиции {a, b} с
подписанными кратчайшими шагами: если она не антиподальна, оба шага — одна и та
же дуга в противоположных направлениях, значит M = 2, число переходов −→+ равно
t = 1, E = 2 − 2 = 0 и S = 2·2 + 0 − 1 = 3. Если она антиподальна (n чётно,
b − a = n/2), оба шага положительны по правилу 16, нагрузки всех рёбер равны 1,
M = 1, t = 0, E = 2 и S = 2·1 + 2 − 1 = 3. Итак `S_c = 3T`.
(Это разбор PROBLEM §5.3 / C24.)

**Лемма A3 (F_c).** `F_c = sum_{i in Z_n} delta_n(2i − g, 0)`, и

```text
n нечётно:      F_c = P;
n = 0 (mod 4):  F_c = P                (при обеих чётностях g);
n = 2 (mod 4):  F_c = P − 1 при чётном g,  F_c = P + 1 при нечётном g.
```

*Доказательство.* Каждая точка i из носителя даёт шаг длины
delta_n(i, g − i) = delta_n(2i − g, 0); неподвижные точки дают 0. Отсюда первая
формула (суммирование по всем i, включая неподвижные).

Для суммы по кольцу: `sum_{x in Z_n} delta_n(x,0) = P` (при чётном n это
2(1+…+(n/2−1)) + n/2 = n^2/4, при нечётном 2(1+…+(n−1)/2) = (n^2−1)/4).

Нечётное n: 2 обратимо, значит `2i − g` пробегает все вычеты по одному разу,
F_c = P.

Чётное n = 2m: `2i − g` пробегает вычеты чётности g, каждый дважды. Пусть
A_чёт = sum_{x чётно} delta_n(x,0) и A_нечёт = sum_{x нечётно} delta_n(x,0),
A_чёт + A_нечёт = P = m^2. Для x = 2j (j = 0..m−1) имеем
delta_n(2j,0) = 2·min(j, m−j), поэтому A_чёт = 2q, где
q = sum_{j=0}^{m−1} min(j, m−j) равно m^2/4 при чётном m и (m^2−1)/4 при
нечётном m (прямой подсчёт двух арифметических прогрессий). Отсюда:
при чётном m (то есть n = 0 mod 4) A_чёт = A_нечёт = m^2/2 и в обоих случаях
F_c = 2·m^2/2 = m^2 = P; при нечётном m (n = 2 mod 4) A_чёт = (m^2−1)/2,
A_нечёт = (m^2+1)/2, откуда F_c = m^2 − 1 = P − 1 при чётном g и
F_c = m^2 + 1 = P + 1 при нечётном g. □

### 2.2. Доказательство Теоремы A

По Лемме 1 достаточно оценить `2F_c − S_c + H(c)` при c из {0, 1}; напомним
`H(0) = n`, `H(1) = n − 1` (при n >= 4), и `R_c <= H(c)`.

*n нечётно.* По A1–A3 при любом c: F_c = P, T = (n−1)/2, S_c = 3(n−1)/2.
Берём c = 1:

```text
2F_1 − S_1 + H(1) = 2P − 3(n−1)/2 + (n−1) = 2P − (n−1)/2 = B_n.
```

*n = 0 (mod 4).* Выберем c из {0, 1} так, чтобы g = h + c было нечётным; тогда
F_c = P, T = n/2, S_c = 3n/2 и

```text
2F_c − S_c + H(c) <= 2P − 3n/2 + n = 2P − n/2 = B_n
```

(при c = 1 даже B_n − 1).

*n = 2 (mod 4).* Выберем c из {0, 1} так, чтобы g = h + c было чётным; тогда
F_c = P − 1, T = n/2 − 1, S_c = 3n/2 − 3 и

```text
2F_c − S_c + H(c) <= 2(P−1) − (3n/2 − 3) + H(c) = 2P + 1 − 3n/2 + H(c).
```

При c = 0 это `2P + 1 − n/2 = B_n + 1`, при c = 1 — `2P − n/2 = B_n`. Нужное c
равно 0 при чётном h и 1 при нечётном h. □

Замечание. Выбор «g нечётно» при n = 0 (mod 4) и «g чётно» при n = 2 (mod 4)
существенен: в первом случае нечётное g убирает обе неподвижные точки и даёт
лишнюю транспозицию (S больше на 3 при том же F), во втором чётное g даёт
одновременно меньшее F (на 2) и меньшее S (на 3), и выигрыш в F перевешивает.

### 2.3. Точность

Машинная проверка (`checks/check_C27.py`, раздел D) для всех отражений при
4 <= n <= 30: фактический `min_c [2F_c − S_c + R_c] − B_n` равен

* нечётное n: 0 при 1 <= h <= (n−1)/2, отрицательно при остальных h;
* n = 0 (mod 4): −1 при чётном h <= n/2, 0 при нечётном h <= n/2,
  отрицательно при h > n/2 (минимум по h равен −(n/4 + 1));
* n = 2 (mod 4): **+1 при чётном h из 2..n/2**, 0 при нечётном h <= n/2,
  −1 при h = 0 и отрицательно при h > n/2.

То есть оценка Теоремы A достигается, и «+1» в формулировке H10 на отражениях
не является артефактом оценки: при n = 2 (mod 4) минимум по всем c
действительно равен B_n + 1 (проверено при 6 <= n <= 30; это конечная
проверка, не доказательство для всех n). После свободного сокращения слова на
всех отражениях при 4 <= n <= 30 длина не превосходит B_n.

### 3.3. Почему не работают естественные общие оценки

Переформулировка (1.1) требует при медианном c неравенства
`S_c − R_c >= floor(n/2) − 1`. Естественная попытка — оценить S_c снизу через
размер носителя: `S(C) >= |C| + 1` (верно для транспозиций и для треугольников
с M = 2, и равносильно `M(C) >= t(C) + 1`). Это **неверно**: для чётного n >= 8
«зигзаг» — цикл

```text
C = (0, 1, n−2, n−1, n−4, n−3, …, 4, 5, 2, 3)
```

имеет k = n, M = 3, t = n/2, E = 0, F = 2n и S = 5, то есть
`S(C) − |C| = 5 − n → −бесконечность`.

*Доказательство (Лемма 2).* Вершины идут в порядке 0, 1, n−2, n−1, n−4, n−3, …,
2, 3; подписанные кратчайшие шаги чередуются: `+1` (из чётной вершины в
следующую нечётную) и `−3` (из нечётной вершины 2j+1 в 2j−2), последний шаг
3 → 0 тоже равен −3. При n >= 8 шаг из 2j+1 в 2j−2 действительно кратчайший:
(2j−2) − (2j+1) = −3 и |−3| < n/2. Итого n/2 шагов `+1` и n/2 шагов `−3`,
их сумма равна −n (обмотка −1), F = n/2 + 3n/2 = 2n, число переходов −→+ равно
t = n/2 (каждому `+1` предшествует `−3`), E = n − 2·(n/2) = 0. Нагрузки: дуга
`+1` из чётной вершины 2j покрывает ребро 2j; дуга `−3` из нечётной 2j+1
покрывает рёбра 2j, 2j−1, 2j−2, то есть два чётных ребра и одно нечётное.
Значит каждое чётное ребро 2j покрыто тремя дугами (шагом `+1` из 2j и шагами
`−3` из 2j+1 и из 2j+3), каждое нечётное — одной; суммарная нагрузка
3·(n/2) + 1·(n/2) = 2n = F. Отсюда M = 3 и S = 2·3 + 0 − 1 = 5. □

(проверено также машинно при чётных 8 <= n <= 20, `check_C27.py`, раздел E;
полный перебор всех ориентированных нетривиальных циклов даёт минимум
S(C) − |C| = 1, 1, −1, −1, −3, −3 при n = 4..9 — раздел F, — причём при n = 8
он достигается именно на зигзаге). Тем самым неверна любая цикловая
оценка вида `S(C) >= alpha·|C| + beta` с alpha > 0, а значит и оценка
`S_c >= alpha·(n − fix_c) + beta·K_c`, на которой держалась бы проверка (1.1)
через размер носителя.

Кроме того, усреднение по c для варианта тоже не даёт B_n: максимум по pi
величины `mean_c [2F_c − S_c + R_c] − B_n` равен 1/2, 0, 1, 5/7, 3/2, 14/9,
12/5, 25/11, 7/2 при n = 4..12 (исчерпывающие прогоны), то есть растёт.
Ни минимум, ни среднее по c для этого варианта не удерживают B_n.

## 5. Что дальше

1. Вариант с маршрутом по переносчикам **не** даёт C15 и не даёт `B_n + O(1)`:
   направление §4.2 PLAN, выбранное в сессии 3, закрыто. Сохраняется факт:
   при 4 <= n <= 11 конструкция с этим маршрутом даёт слово длины <= B_n + 1
   (и <= B_n после сокращения при n <= 9 и при n = 11).
2. Узкое место видно из (1.1) и из §3.3: не существует нижней оценки S_c через
   носитель, а R_c у «рассеянных» переносчиков близко к n. Следующий разумный
   шаг — не маршрут, а сами локальные слова и порядок циклов: у контрпримеров
   §3.1–3.2 при **каждом** c выполняется F_c = P (или почти), несколько циклов
   средней длины и малое S_c; аффинные pi — их бесконечное продолжение.
3. Свободно доступные альтернативные направления (PLAN §4.2–4.3): H6/C22
   (`D_n <= B_n + n`), доказательство H8/C25 (формула длины на sigma_n даёт
   локальное C9), аудит S1 (C8).
