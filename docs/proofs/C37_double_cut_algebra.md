# C37 — алгебра двойного разреза и граница свободного разреза

Дата: 16.09.2026 (сессия 9). Область: все n >= 1 (содержательно n >= 4).
Зависимости: только PROBLEM §§2–3 (модель) и определения линейной модели из
`docs/notes/h13_line_model.md` §0. Не зависит от N1, C8, C16, таблиц.
Код: `experiments/toric_cut_algebra.py` (toric_cut-1.0), чекер
`checks/check_C37.py`, отчёт `data/runs/h13i_verdict/`.

Цель раздела — не доказать H13-I, а перевести её в точную алгебраическую форму
и доказать ту её часть, которая не зависит от вида семейства разрезов.

## 0. Обозначения и конвенции

`pi` — перестановка множества Z_n; точки `(i, pi(i))`, i = 0..n−1. Пара — это
неупорядоченная пара различных точек. Записи `i < j`, `pi(i) < pi(j)` —
сравнения целых в диапазоне 0..n−1.

- `Inv(pi)` — множество инверсий: пар `{i, j}` с `i < j` и `pi(i) > pi(j)`;
  `inv(pi) = |Inv(pi)|`.
- `A_m = {i : i < m}` — префикс позиций, m = 0..n−1 (`A_0` пусто).
- `B_k = {i : pi(i) < k}` — префикс значений, k = 0..n−1.
- `S(m, k) = A_m xor B_k` (симметрическая разность подмножеств точек).
- Для `S ⊆ Z_n`: `delta(S)` — множество пар, разделённых S (ровно один конец
  в S); `|delta(S)| = s(n − s)`, `s = |S|`.
- `e_inv(S) = |Inv(pi) ∩ delta(S)|` — число разделённых инверсий.
- `B_n = n(n−1)/2` — число пар.

Двойной разрез в форме `(q, c)` из `docs/notes/h13_line_model.md`:
`w_j = (pi(q + 1 + j) − (q + 1 − c)) mod n`, j = 0..n−1.

## Лемма 1 (параметризация)

Отображение `(q, c) -> (m, k) = ((q + 1) mod n, (q + 1 − c) mod n)` — биекция
`Z_n x Z_n -> Z_n x Z_n`, и линия разреза `(q, c)` совпадает с линией

```text
w_j = (pi((m + j) mod n) − k) mod n,   j = 0..n−1.
```

Доказательство. Подстановка `m = q + 1`, `k = q + 1 − c`; при фиксированном q
сдвиг c пробегает Z_n тогда и только тогда, когда k пробегает Z_n. ∎

Далее разрез задаётся парой `(m, k)`: линия начинается с позиции m, значение k
становится нулём. `I(pi) = min_{m,k} inv(w(m, k))` — то же, что в C33/C35.

## Лемма 2 (тождество разреза)

Для всех pi, m, k, при `S = S(m, k)` и `s = |S|`:

```text
inv(w(m, k)) = |Inv(pi) xor delta(S)| = inv(pi) + s(n − s) − 2 e_inv(S).
```

Доказательство. Обозначим `rho(i) = (i − m) mod n` (индекс точки i в линии) и
`nu(i) = (pi(i) − k) mod n` (её значение в линии). Пусть `i < j`.

(а) `rho(i) < rho(j)` тогда и только тогда, когда пара `{i, j}` не лежит
в `delta(A_m)`. Действительно, если i и j по одну сторону от m (оба `< m` или
оба `>= m`), то `rho` сохраняет их порядок; если `i < m <= j`, то
`rho(i) = i − m + n >= n − m > j − m = rho(j)`, порядок меняется. Случай
`j < m <= i` при `i < j` невозможен. А `{i, j} ∈ delta(A_m)` равносильно
`i < m <= j`.

(б) Так же `nu(i) < nu(j)` равносильно `pi(i) < pi(j)`, если пара не в
`delta(B_k)`, и `pi(i) > pi(j)`, если в ней.

Пара — инверсия линии, когда порядки `rho` и `nu` различны, то есть когда
`[{i,j} ∈ Inv(pi)] xor [{i,j} ∈ delta(A_m)] xor [{i,j} ∈ delta(B_k)] = 1`.
Индикатор `delta(S)` на паре равен `1_S(i) xor 1_S(j)` и потому линеен по `1_S`
над GF(2): `delta(A_m) xor delta(B_k) = delta(A_m xor B_k) = delta(S)`. Отсюда
первое равенство. Второе — обычная формула симметрической разности:
`|X xor Y| = |X| + |Y| − 2|X ∩ Y|`. ∎

Геометрически `S(m, k)` — объединение двух «разноимённых» квадрантов сетки
n x n, рассечённой вертикалью m и горизонталью k: точки с `i < m, pi(i) >= k`
и точки с `i >= m, pi(i) < k`.

## Лемма 3 (знаковая форма)

Пусть `x ∈ {±1}^n`, `x_i = −1` при `i ∈ S`, и
`eps_{ij} = +1`, если пара `{i, j}` не инверсия pi, и `−1`, если инверсия.
Положим `Q(x) = sum_{i<j} eps_{ij} x_i x_j`. Тогда

```text
inv(w) = B_n/2 − Q(x)/2,   число неинверсий линии = B_n/2 + Q(x)/2,
inv(w) <= floor((n−1)^2/4)  <=>  Q(x) >= floor(n/2).
```

Доказательство. Пара — инверсия линии тогда и только тогда, когда
`eps_{ij} x_i x_j = −1` (лемма 2 в знаках: `x_i x_j = −1` равносильно
`{i,j} ∈ delta(S)`). Значит `inv(w) = sum_{i<j} (1 − eps_{ij}x_i x_j)/2`.
Далее `B_n − 2 floor((n−1)^2/4)` равно `n/2` при чётном n и `(n−1)/2` при
нечётном, то есть `floor(n/2)`. ∎

Следствие (точная форма H13-I). H13-I равносильна утверждению: для каждой pi
среди n^2 знаковых векторов `x(m, k)`, порождённых префиксами позиций и
значений, есть вектор с `Q(x) >= floor(n/2)`.

## Лемма 4 (сколько разрезов делают пару согласованной)

Для пары точек `p = (i, u)`, `r = (j, v)` положим `d_p = (j − i) mod n`,
`d_v = (v − u) mod n` (оба в 1..n−1). Пара не является инверсией линии ровно
для

```text
F(d_p, d_v) = (n − d_p)(n − d_v) + d_p d_v
```

разрезов `(m, k)` из n^2. Величина F не зависит от выбора порядка точек
(замена меняет `(d_p, d_v)` на `(n − d_p, n − d_v)`).

Доказательство. `rho(i) < rho(j)` равносильно `t + d_p < n`, где
`t = (i − m) mod n`; при пробеге m по Z_n величина t пробегает Z_n, поэтому
таких m ровно `n − d_p`, а противоположных — `d_p`. Так же для k и `d_v`.
Параметры m и k независимы, и согласованность — совпадение двух порядков. ∎

Следствие 4.1. `Sigma(pi) = sum_{пары} F(d_p, d_v)` — суммарное число
согласованных пар по всем n^2 разрезам, и среднее их число равно
`Sigma(pi)/n^2`. Если `Sigma(pi)/n^2 >= floor(n^2/4)`, H13-I верна для pi.

Следствие 4.2 (усреднения недостаточно). Для `id_n`: `d_p = d_v = d`,
`Sigma(id_n) = sum_{d=1}^{n−1} (n − d)[(n − d)^2 + d^2] = n^2 (n−1)(2n−1)/6`,
среднее `(n−1)(2n−1)/6`. Для `sigma_n` (и `rev_n`): `d_v = n − d_p`,
`Sigma = n^2 (n^2 − 1)/6`, среднее `(n^2 − 1)/6 < floor(n^2/4)` при всех n >= 2.
То есть усреднение проваливается ровно на экстремальном входе `sigma_n`,
а для `id_n` работает при n >= 5 (при n = 4 среднее 3.5 < 4). Поскольку
`F >= 1/2 n^2` равносильно `(n − 2 d_p)(n − 2 d_v) >= 0`, пары с
«разноимёнными» дугами (`d_p < n/2 < d_v` или наоборот) всегда хуже среднего,
и у отражений такова каждая пара.

## Теорема 5 (граница свободного разреза)

Пусть n >= 1 и `eps: пары -> {±1}` произвольна. Тогда

```text
max_{x ∈ {±1}^n} Q(x) >= floor(n/2),   Q(x) = sum_{i<j} eps_{ij} x_i x_j,
```

и это точно: при `eps ≡ −1` максимум равен `floor(n/2)`.

Доказательство. Возьмём x, максимизирующий Q, и положим
`N_{ij} = eps_{ij} x_i x_j` (симметрично, значения ±1, диагональ не
используется). Для `T ⊆ [n]` пусть `x^T` — x со сменой знака на T. Тогда

```text
Q(x^T) = Q(x) − 2 W(T),   W(T) = sum_{i ∈ T, j ∉ T} N_{ij},
```

потому что при переходе к `x^T` меняют знак ровно слагаемые пар, разделённых T.
Из максимальности `W(T) >= 0` для всех T. В частности
`r_p := W({p}) = sum_{j != p} N_{pj} >= 0`, и `sum_p r_p = 2 Q(x)`.

Случай чётного n. `r_p` — сумма `n − 1` слагаемых ±1, число слагаемых нечётно,
поэтому `r_p` нечётно; вместе с `r_p >= 0` это даёт `r_p >= 1`. Значит
`2Q >= n`, `Q >= n/2 = floor(n/2)`.

Случай нечётного n. Теперь все `r_p` чётны и неотрицательны. Пусть
`Z = {p : r_p = 0}`. Для `p != q` из Z
`0 <= W({p, q}) = r_p + r_q − 2 N_{pq} = −2 N_{pq}`, значит `N_{pq} = −1`.
Тогда для `p ∈ Z`: `sum_{j ∈ Z, j != p} N_{pj} = −(|Z| − 1)`, а так как
`r_p = 0`, то `sum_{j ∉ Z} N_{pj} = |Z| − 1`. Слева не более `n − |Z|`
слагаемых модуля 1, поэтому `|Z| − 1 <= n − |Z|`, то есть `|Z| <= (n+1)/2`.
Каждое `r_p` вне Z чётно и положительно, значит `>= 2`, и
`2Q = sum_p r_p >= 2(n − |Z|) >= n − 1`, `Q >= (n−1)/2 = floor(n/2)`.

Точность. При `eps ≡ −1` имеем `Q(x) = −sum_{i<j} x_i x_j =
(n − (sum_i x_i)^2)/2`; сумма `sum x_i` имеет ту же чётность, что n, поэтому
`Q <= n/2` при чётном n и `<= (n−1)/2` при нечётном. ∎

Замечание. Доказательство конструктивно: локальный спуск по одиночным и
парным сменам знака уменьшает `inv` хотя бы на 1 за шаг, поэтому
заканчивается не более чем за `B_n` шагов и выдаёт требуемый x. При чётном n
достаточно одиночных смен.

### Следствие 5.1 (H13-I со свободным разрезом — доказано)

Для каждой pi и каждого n >= 1 существует подмножество точек `S ⊆ Z_n` с

```text
|Inv(pi) xor delta(S)| <= floor((n−1)^2/4),
```

причём равенство достигается на `rev_n` и `sigma_n` (там `Inv = все пары`,
и величина равна `B_n − s(n − s) >= B_n − floor(n^2/4) = floor((n−1)^2/4)`).

То есть **константа `floor((n−1)^2/4)` в H13-I — это в точности порог
Эдвардса для полного графа K_n**, и она не улучшаема даже при свободном
выборе S. Всё содержание H13-I — в том, что нужный S можно взять в
торическом семействе `S(m, k)` (n^2 множеств из 2^{n−1}).

### Следствие 5.2 (достаточный критерий; H14)

Пусть для некоторого разреза `(m, k)` линия `w` такова, что

1. каждый элемент линии инвертирован не более чем с `floor((n−1)/2)` другими;
2. при нечётном n любые два элемента, у которых это число равно `(n−1)/2`,
   инвертированы друг с другом.

Тогда `inv(w) <= floor((n−1)^2/4)`.

Доказательство. Пусть `inv_p` — число элементов, инвертированных с p; тогда
`r_p = n − 1 − 2 inv_p`, а условие 1 равносильно `r_p >= 0`. Условие 2 — это
`W({p, q}) >= 0` для `p, q ∈ Z`. Повторяем оба случая теоремы 5, где эти
неравенства — единственное, что использовалось. ∎

Критерий H14 достаточен, но не необходим: он **опровергнут при n = 8**
(16 перестановок, все аффинные: `pi(i) = 3i + b` и `pi(i) = 5i + b mod 8`,
например `(0,3,6,1,4,7,2,5)` и `(0,5,2,7,4,1,6,3)`); ни один из 64 разрезов
не даёт `max_p inv_p <= 3`, хотя `I(pi)` равно 9 и 11 при пороге 12
(`experiments/toric_cut_algebra.py`, часть 6).

## 6. Что осталось (H13-I)

Открытая часть: торическое семейство `{S(m, k)}` содержит подходящее S.
Конечные данные (часть 5 отчёта): при 4 <= n <= 7 торический минимум совпадает
со свободным для **всех** pi; при n = 8 расхождение есть у 208 из 40320 pi
(на 200 — ровно 1, на 8 — ровно 3). Восемь входов с расхождением 3 — это
в точности аффинное семейство `pi(i) = 5i + b mod 8` (`I = 11`, свободный
минимум 8); семейство `pi(i) = 3i + b` даёт расхождение 1 (`I = 9`,
свободный минимум 8). И там, и там `I(pi) <= 12 = floor((n−1)^2/4)` с запасом.
Направления — `docs/notes/h13i_verdict.md`.
