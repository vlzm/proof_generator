## 0. Определения

Для `pi` из S_n, разреза `q` из Z_n и сдвига `c` из Z_n линия

```text
w_j = (pi((q + 1 + j) mod n) - (q + 1 - c)) mod n,   j = 0, ..., n - 1.
```

`w` — перестановка множества `{0, ..., n-1}` (позиции 0..n-1 линии).
`inv(w) = #{(j, k) : j < k, w_j > w_k}`. `I(pi) = min_{q,c} inv(w)`.

Всюду ниже `q` фиксирован, кроме леммы 2, где меняется явно; операции
над индексами и значениями — по модулю n.

## 1. Лемма 1 (сдвиг значения: `c -> c + 1`)

При фиксированном `q` для всех `c`:

```text
inv(w(c + 1)) - inv(w(c)) = 2 * posmax(c) - (n - 1),
```

где `posmax(c)` — позиция (индекс `j` в текущей линии `w(c)`) элемента с
текущим максимальным значением `n - 1`.

**Доказательство.** Из определения `w_j(c) = (t_j - q - 1 + c) mod n`, где
`t_j = pi(q + 1 + j)` не зависит от `c`, получаем `w_j(c + 1) = (w_j(c) + 1)
mod n` для каждого `j` (прибавление константы 1 коммутирует с `mod n`).
Значит все значения растут на 1 по модулю n; единственный элемент, чьё
значение не могло бы расти обычным образом — тот, что имеет текущее
максимальное значение `n - 1`: он переходит в 0, все остальные — в `w_j(c)+1`.

Пусть `j* = posmax(c)`. Инверсии, не затрагивающие `j*`, не меняются (порядок
остальных n-1 значений между собой сохраняется: если `w_j(c) < w_k(c)` для
`j, k != j*`, то и `w_j(c)+1 < w_k(c)+1`, так как обе величины лежат в
`{0, ..., n-2}` и сложение с 1 не создаёт переполнения по модулю n для
не-максимальных значений).

Инверсии с `j*` при `c`: так как `w_{j*}(c) = n - 1` — максимум, пара
`(j*, k)` при `k > j*` не инверсия (`w_{j*} > w_k` всегда, но `k` идёт после,
условие инверсии `j* < k` с `w_{j*} > w_k` — это ЕСТЬ инверсия для каждого
`k > j*`); пара `(j, j*)` при `j < j*` не инверсия (`w_j < w_{j*} = n - 1`
всегда, значит `w_j > w_{j*}` ложно). Итого при `c`: инверсий с `j*` ровно
`n - 1 - j*` (пары `(j*, k)`, `k > j*`; это они, не "не инверсия" — проверим
знак ниже) — уточним аккуратно:

при `c`: `w_{j*}(c) = n-1`; для `k > j*`: `j* < k`, `w_{j*} = n-1 > w_k`
(т.к. `w_k != n-1`), значит `(j*, k)` — инверсия; таких `k` ровно `n-1-j*`.
Для `j < j*`: `j < j*`, `w_j < n-1 = w_{j*}`, не инверсия. Итого `n-1-j*`.

при `c+1`: `w_{j*}(c+1) = 0` — минимум; для `k > j*`: `w_{j*}=0 < w_k`, не
инверсия. Для `j < j*`: `w_j(c+1) > 0 = w_{j*}(c+1)` всегда (все прочие
значения лежат в `{1,...,n-1}`), значит `(j, j*)` — инверсия; таких `j` ровно
`j*`. Итого `j*`.

`delta = j* - (n - 1 - j*) = 2 j* - (n - 1)`. ∎

Проверено эталонно (перебором `inv`) для всех pi, q, c при 4 <= n <= 7;
выборочно (300 случайных pi + sigma_n + rev_n) для 8 <= n <= 40
(`checks/check_H13I_identities.py`, часть A).

## 2. Лемма 2 (сдвиг позиции: `q -> q + 1`)

При фиксированном `c` для всех `q`:

```text
inv(w(q + 1)) - inv(w(q)) = (n - 1 - 2 w_0(q)) + (n - 1 - 2 j0),
```

где `w_0(q)` — значение первого элемента текущей линии, и `j0` — позиция
элемента со значением 0 в сдвинутой линии `v = (w_1(q), ..., w_{n-1}(q), w_0(q))`
(та же линия с передвинутым в конец первым элементом).

**Доказательство.** Прямо из определения: `p_j = q + 1 + j mod n` — позиция
окружности на месте `j`; при `q -> q + 1` позиции сдвигаются: новая
последовательность позиций — `p_1, ..., p_{n-1}, p_0` (старая с передвинутым
в конец первым элементом), а база `q + 1 - c` увеличивается на 1. Разложим
переход в два шага.

*Шаг A (перестановка порядка, значения не меняются).* Пусть
`v_j = w_j(q)` для `j = 1, ..., n-1` в новом порядке и `v_{n-1} = w_0(q)`
(то есть `v` — старая линия `w(q)` с элементом `w_0(q)`, перенесённым в
конец). Меняется только порядок чтения, не значения. Инверсии между парами,
не включающими старый первый элемент, не меняются. Пусть `w_0 = w_0(q)`.

При старом порядке инверсии с элементом `w_0` (он на первом месте, индекс 0):
пара `(0, k)` — инверсия ровно когда `w_0 > w_k`; таких `k` ровно `w_0`
(значений, меньших `w_0`, среди `{0,...,n-1}\{w_0}` ровно `w_0`). Итого
`w_0` инверсий (пар вида `(0, k)`, `k > 0`; пар `(j, 0)` с `j < 0` нет).

При новом порядке (элемент на последнем месте, индекс n-1): пара `(j, n-1)`
— инверсия ровно когда `w_j > w_0`; таких `j` ровно `(n - 1) - w_0` (значений,
больших `w_0`, среди прочих n-1 элементов). Итого `n - 1 - w_0` инверсий.

`delta_A = (n - 1 - w_0) - w_0 = n - 1 - 2 w_0`.

*Шаг B (значения падают на 1 по модулю n, порядок фиксирован).* Новая база
больше старой на 1, поэтому `w_j(q+1) = (v_j - 1) mod n` для всех `j`
(та же выкладка, что и в лемме 1, но с шагом -1 вместо +1). Это — операция,
обратная к лемме 1 с ролями "макс" и "мин" поменянными местами: элемент со
значением 0 в `v` (позиция `j0`) переходит в `n - 1`, все прочие падают на 1
без переполнения. Тем же счётом инверсий, что в лемме 1 (роли максимума и
минимума и разница `c -> c+1` и `c -> c-1` зеркальны): при `v` инверсий с
`j0` ровно `j0` (все `j < j0` дают инверсию `v_j > 0 = v_{j0}`); при `v - 1`
— ровно `n - 1 - j0` (все `k > j0` дают инверсию `v'_{j0} = n-1 > v'_k`).
`delta_B = (n - 1 - j0) - j0 = n - 1 - 2 j0`.

`delta = delta_A + delta_B`. ∎

Проверено так же, как лемма 1 (`checks/check_H13I_identities.py`, часть A).

## 3. Лемма 3 (двойственность обращения)

Для всех `pi` из S_n, `q, c` из Z_n:

```text
inv(line(pi, q, c)) = inv(line(pi^{-1}, q - c, -c)).
```

**Доказательство.** Пусть `base = q + 1 - c`, `w_j = (pi(p_j) - base) mod n`
с `p_j = q + 1 + j mod n` как в определении. Для значения `v` из Z_n индекс
`j` с `w_j = v` существует единственный (`w` — перестановка), и

```text
j = (p_j - q - 1) mod n = (pi^{-1}((v + base) mod n) - q - 1) mod n.
```

Значит обратная последовательность `w^{-1}` (как функция от `v`) равна

```text
w^{-1}(v) = (pi^{-1}((v + base) mod n) - (q + 1)) mod n.
```

Сравним с определением `line(pi^{-1}, q*, c*)_j = (pi^{-1}(q* + 1 + j) -
(q* + 1 - c*)) mod n`. Подставляя `j = v`, требуем `q* + 1 = base = q+1-c`
(значит `q* = q - c`) и `q* + 1 - c* = q + 1` (значит `c* = q* + 1 - (q+1) =
-c`). При этих `q*, c*` получаем `w^{-1} = line(pi^{-1}, q-c, -c)` как
последовательность (индексированную `v`). Так как `inv(sigma) = inv(sigma^{-1})`
для любой перестановки `sigma` множества `{0,...,n-1}` (стандартный факт:
пара `(j,k)`, `j<k`, `w_j>w_k` инверсии `w` соответствует ровно паре
значений `(w_k, w_j)`, являющейся инверсией `w^{-1}` в обратном порядке
позиций), `inv(w) = inv(w^{-1}) = inv(line(pi^{-1}, q-c, -c))`. ∎

Следствие: `I(pi) = I(pi^{-1})` для всех `pi` (минимум берётся по одному и
тому же множеству значений `inv`, так как `(q,c) -> (q-c,-c)` — биекция
Z_n x Z_n на себя). В частности крайние (экстремальные для C33) `pi`
замкнуты относительно обращения; `sigma_n` — инволюция, согласуется.

Проверено так же, как леммы 1–2 (`checks/check_H13I_identities.py`, часть A).

## 4. Лемма 4 (точная формула двойного счёта по всем n^2 разрезам)

Для `pi` из S_n и точки данных `i` из Z_n определим на торе `Z_n x Z_n`
точку `(i, pi(i))`. Для точки отсчёта `(a, b)` из Z_n x Z_n и пары различных
`i, i'` скажем, что пара «согласована» относительно `(a, b)`, если
`(i - a) mod n` и `(i' - a) mod n` находятся в том же относительном порядке,
что и `(pi(i) - b) mod n` и `(pi(i') - b) mod n` (обе меньше/обе больше).
Число согласованных пар при `(a, b)` равно `C(n,2) - inv(line(pi, a-1, a-b))`
(развёрнутая перезапись определения через `q = a - 1`, `c = a - b`; можно
проверить прямой подстановкой). Тогда для любой фиксированной пары `{i, i'}`,
`i != i'`, положим `D = (i' - i) mod n`, `D' = (pi(i') - pi(i)) mod n` (оба
из `{1, ..., n-1}`, выбор, какую из точек называть `i`, а какую `i'`, не
меняет следующую формулу — см. ниже). Тогда

```text
#{(a, b) из Z_n x Z_n : пара {i, i'} согласована при (a, b)}
    = (n - D)(n - D') + D * D'.
```

**Доказательство.** Зафиксируем `i, i'`. Пусть `x(a) = (i - a) mod n`,
`x'(a) = (i' - a) mod n`. Так как `x'(a) = (x(a) + D) mod n` для всех `a`
(прямая подстановка), а отображение `a -> x(a)` — биекция Z_n на себя,
достаточно посчитать, для скольких значений `v = x(a)` из `{0,...,n-1}`
выполнено `v < (v + D) mod n`. Если `v <= n - 1 - D` (нет переполнения),
`(v+D) mod n = v + D > v` — верно; таких `v` ровно `n - D`. Если
`v >= n - D` (переполнение), `(v+D) mod n = v + D - n < v` — неверно.
Итого `#{a : x(a) < x'(a)} = n - D`, и `#{a : x(a) > x'(a)} = D` (равенства
нет, `D != 0`). Симметрично для `b`: `#{b : y(b) < y'(b)} = n - D'`,
`#{b : y(b) > y'(b)} = D'`, где `D' = (pi(i')-pi(i)) mod n`.

Так как `x, x'` зависят только от `a`, а `y, y'` только от `b`, и `a, b`
пробегают Z_n независимо (`n^2` пар всего), событие «пара согласована»
раскладывается на два непересекающихся случая: `(x < x'` и `y < y')` или
`(x > x'` и `y > y')`. Число `(a, b)` в первом случае — произведение
`(n - D)(n - D')` (независимость по построению — каждое из двух условий
зависит только от своей координаты и является точным подсчётом, а не
вероятностью), во втором — `D * D'`. Сумма — заявленная формула.

Замена выбора «какую точку назвать `i`»: если поменять местами `i, i'`, то
`D -> n - D`, `D' -> n - D'`, и `(n-D)(n-D')+DD'` инвариантно относительно
одновременной замены `D -> n-D`, `D' -> n-D'` (раскрытие скобок: обе формы
равны `n^2 - n(D+D') + 2DD'`). ∎

Суммируя по всем `C(n,2)` парам, получаем точную формулу для суммы числа
согласованных пар по всем `n^2` точкам отсчёта:

```text
S(pi) = sum_{i<i'} [n^2 - n(D_{i,i'} + D'_{i,i'}) + 2 D_{i,i'} D'_{i,i'}].
```

Проверено эталонно (прямой перебор `(a,b)` и подсчёт согласованных пар,
сверка с формулой) для всех pi при 4 <= n <= 7; выборочно для 8 <= n <= 14
(`checks/check_H13I_identities.py`, часть B; при n > 14 проверка double
counting в чекере отключена по стоимости `O(n^4)` за перестановку — не по
существу проверки, а по бюджету).

## 5. Что из этого НЕ следует (см. вердикт)

Леммы 1–4 — точные, доказанные тождества локального изменения `inv` при
единичном сдвиге `q` или `c`, тождество двойственности и точная формула
двойного счёта. Они не доказывают H13-I: попытки использовать лемму 4 через
усреднение (среднее число согласованных пар по всем `n^2` точкам меньше
`floor(n^2/4)` уже на `rev_n`, эквивалентно `sigma_n` по C12/§0) и через
однопараметрические семейства (`c = 0` при переборе `q`) дают контрпримеры
уже при малых n — см. `docs/notes/h13i_verdict.md` §1 для точных чисел и
вывода о том, почему нужен принципиально более тонкий (не усредняющий,
не однопараметрический) аргумент.
