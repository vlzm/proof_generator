# C37 — точная рекуррента для инверсий при сдвиге значений

Дата: 14.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор; элементарное тождество, полный аргумент ниже). Чекер:
`checks/check_C37.py` (PASS: тождество — все перестановки при 4 <= n <= 8,
выборочно n в {20, 50, 100}; см. также раздел 3 — контрпримеры к простым
стратегиям, исчерпывающе при 4 <= n <= 9). Обозначения и модель торических
классов — `docs/notes/h13_line_model.md` §0 (гипотеза H13-I).

Это вспомогательная лемма для H13-I, не само доказательство: она даёт точную
(не асимптотическую) формулу для одного из двух свободных сдвигов, но раздел 3
показывает предъявленным контрпримером, что её одной (или её применения по
схеме «сначала одна координата, потом другая») недостаточно — нужен
совместный выбор обоих сдвигов сразу, как и предполагала лемма C сессии 8.

## Утверждение

Пусть n >= 1 и `tau` — перестановка (линейная последовательность) множества
`{0, ..., n-1}`, `tau_j`, `j = 0, ..., n-1`. Для `c` из `Z_n` определим сдвиг
значений `sigma_c(tau)_j = (tau_j - c) mod n`. Пусть `inv(w)` — число инверсий
линейной последовательности `w` (пар `j < k` с `w_j > w_k`), `pos(v)` —
позиция значения `v` в `tau` (`tau_{pos(v)} = v`). Тогда для любого
`c из {0, ..., n-1}`:

```text
inv(sigma_c(tau)) = inv(tau) + c(n - c) - 2 * X_c(tau),

X_c(tau) := #{ (x, y) : 0 <= x < c <= y <= n-1, pos(y) < pos(x) }.
```

`X_c(tau)` — число «перекрёстных» инверсий между нижними `c` значениями
`{0,...,c-1}` и верхними `n-c` значениями `{c,...,n-1}`: пара `(x, y)`
считается, когда большее (или равное порогу) значение `y` стоит в `tau`
раньше меньшего `x`. Всегда `0 <= X_c(tau) <= c(n-c)`, поэтому
`c(n-c) - 2 X_c(tau)` из `[-c(n-c), c(n-c)]`.

### Следствие (симметричная форма по позициям)

Так как `inv(pi) = inv(pi^{-1})` и `pos_{pi^{-1}}(v) = pi(v)` (позиция
значения `v` в последовательности `pi^{-1}` равна `pi(v)`), применение
утверждения к `tau = pi^{-1}` даёт формулу для вращения **позиций** `pi`
(при неизменных значениях): для `q` из `Z_n`,

```text
inv(rotate_q(pi)) = inv(pi) + q(n - q) - 2 * Y_q(pi),
Y_q(pi) := #{ (i, j) : 0 <= i < q <= j <= n-1, pi(i) > pi(j) },
```

где `rotate_q(pi)_k = pi((q + k) mod n)` — циклический сдвиг начала отсчёта
позиций, а `Y_q(pi)` — число обычных инверсий `pi`, «пересекающих» разрез
позиций `{i < q <= j}`.

## Доказательство

При `c = 0` обе части равны `inv(tau)` (`X_0 = 0`) — база.

**Шаг рекурренты.** Пусть `w = sigma_c(tau)`, `w' = sigma_{c+1}(tau)`.
Тогда `w'_j = w_j - 1` для всех `j`, кроме единственной позиции `p`, где
`w_p = 0` (`p = pos_tau(c)`, так как `tau_p - c ≡ 0`); там `w'_p = n - 1`.

Уменьшение на 1 всех остальных значений не меняет их взаимный порядок,
поэтому статус инверсии для любой пары, не содержащей `p`, не меняется.
Меняется вклад пар, содержащих `p`:

- в `w`: `w_p = 0` — минимум; пара `(j, p)` при `j < p` — инверсия (так как
  `w_j > 0`), пара `(p, j)` при `j > p` — не инверсия. Итого `p` даёт ровно
  `p` инверсий.
- в `w'`: `w'_p = n - 1` — максимум; пара `(j, p)` при `j < p` — не инверсия
  (`w'_j <= n - 2 < n - 1`), пара `(p, j)` при `j > p` — инверсия. Итого `p`
  даёт ровно `n - 1 - p` инверсий.

Значит `inv(w') = inv(w) - p + (n - 1 - p) = inv(w) + (n - 1 - 2p)`,
`p = pos_tau(c)`.

**Телескопирование.** По индукции от `c = 0`:

```text
inv(sigma_C(tau)) = inv(tau) + sum_{c=0}^{C-1} (n - 1 - 2 pos_tau(c))
                   = inv(tau) + C(n-1) - 2 * sum_{c=0}^{C-1} pos_tau(c).
```

**Сумма позиций нижних значений.** Стандартное тождество: для множества
значений `{0, ..., C-1}` с позициями `pos(0), ..., pos(C-1)` в произвольной
перестановке,

```text
sum_{c=0}^{C-1} pos(c) = C(C-1)/2 + X_C(tau).
```

Действительно, отсортируем позиции нижних `C` значений по возрастанию:
`p_(1) < ... < p_(C)`. «Идеальная» сумма (если бы нижние значения занимали
первые `C` позиций `0, ..., C-1`) равна `C(C-1)/2`. Превышение
`sum p_(i) - C(C-1)/2` равно, для каждого `i`, числу «верхних» значений
(`>= C`), стоящих на позициях `< p_(i)` сверх уже учтённых меньших нижних
значений — это ровно число пар (верхнее значение перед нижним), то есть
`X_C(tau)` (стандартный факт о сумме позиций подмножества через число
пересекающих инверсий; проверяется индукцией по `C` или прямым счётом:
`sum_i p_(i) = sum_i [(i - 1) + (число элементов не из подмножества перед
p_(i))]`, а сумма вторых слагаемых по всем `i` пересчитывает каждую пару
(верхнее до нижнего) ровно один раз).

Подставляя:

```text
inv(sigma_C(tau)) = inv(tau) + C(n-1) - 2[C(C-1)/2 + X_C(tau)]
                   = inv(tau) + C(n-1) - C(C-1) - 2 X_C(tau)
                   = inv(tau) + C(n - C) - 2 X_C(tau).
```

∎ (переобозначив `C` обратно в `c`).

## 2. Точность на отражениях

Для `tau = rev_n` (`tau_j = n - 1 - j`) при любом пороге `c` **все** `c(n-c)`
перекрёстных пар инвертированы (нижние значения `0..c-1` стоят на последних
`c` позициях, верхние `c..n-1` — на первых `n-c`, так что каждая верхняя
позиция меньше каждой нижней): `X_c(rev_n) = c(n-c)`, и формула даёт

```text
inv(sigma_c(rev_n)) = C(n,2) - c(n-c).
```

Минимум по `c` достигается при `c = floor(n/2)` (или `ceil(n/2)`), где
`c(n-c) = floor(n^2/4)`, что по тождеству C12
(`B_n = floor(n^2/4) + floor((n-1)^2/4) = C(n,2)`) даёт

```text
min_c inv(sigma_c(rev_n)) = floor((n-1)^2 / 4)
```

— точное значение `I(rev_n)` (и, после циклического сопряжения, любого
отражения `pi_h`), совпадающее с максимумом `I(pi)` из C33/C35. Это первое
**аналитическое** (не только табличное) подтверждение верхней половины C33
для семейства отражений: одного сдвига значений `c` достаточно, `q = 0`.

## 3. Почему одной координаты (или их независимого применения) недостаточно

Формула раздела 1 точно решает задачу с одной степенью свободы (`c` при
фиксированном `q`, или наоборот `q` при фиксированном `c`). Естественная
попытка доказать H13-I — показать, что для каждой pi достаточно **одной** из
двух координат (`q = 0`, подбираем `c`; либо `c = 0`, подбираем `q`, что по
следствию §1 эквивалентно применению утверждения к `pi^{-1}`), или их простой
комбинации («взять лучшее из двух»). Все три стратегии проверены исчерпывающе
`checks/check_C37.py` (перебор всех перестановок):

| n | floor((n-1)^2/4) | max, только `q=0` (подбор `c`) | max, min(`q=0`, `c=0`) |
|---|---|---|---|
| 4 | 2 | 2 | 2 |
| 5 | 4 | 4 | 4 |
| 6 | 6 | 6 | 6 |
| 7 | 9 | **10** | **10** |
| 8 | 12 | **13** | **13** |
| 9 | 16 | **17** | **17** |

Начиная с `n = 7` обе стратегии превышают границу `floor((n-1)^2/4)` ровно на
1. Минимальный (первый в порядке `itertools.permutations`) свидетель при
`n = 7`: `pi = (0, 5, 4, 3, 2, 1, 6)` — как для `q = 0` (перебор по `c`), так
и для `min(best_c(pi), best_c(pi^{-1}))` дают `10`, тогда как полный перебор
по обеим координатам даёт истинный минимум `I(pi) = 8 <= 9`, достигаемый на
десяти парах `(q, c)`: `(1,2), (1,3), (2,1), (2,2), (3,1), (4,6), (5,5),
(5,6), (6,4), (6,5)` (перебор всех `n^2 = 49` пар, вручную в сессии,
воспроизводимо). Ни одна из них не имеет `q = 0` или `c = 0` — у этого `pi`
**ни** фиксация `q = 0`, **ни** фиксация `c = 0` не достигают оптимума,
нужен совместный (небазовый по обеим координатам) сдвиг.

Это независимое (иным методом) подтверждение вывода леммы C сессии 8
(`docs/notes/h13_line_model.md` §4): локальная информация по одной координате
не определяет глобальный минимум `I(pi)`; доказательство H13-I должно
анализировать оба сдвига одновременно, а не сводиться к последовательному
применению утверждения §1 по одной координате за раз.
