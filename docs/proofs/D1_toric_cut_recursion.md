# D1 — рекурсия по разрезу для `I(pi)` за O(n^2)

Дата: 16.09.2026 (сессия 9). Контекст: H13-I (PLAN §0, `docs/notes/h13_line_model.md`
§6) — гипотеза `I(pi) <= floor((n − 1)^2/4)` для всех pi. Существующий код
(`experiments/line_profile.c`, line_profile-1.0) считает `I(pi)` перебором всех
`n^2` разрезов, на каждом — подсчёт инверсий за O(n^2): итого O(n^4) на одну pi.
Здесь — рекурсия, дающая тот же `I(pi)` за O(n^2) на pi, без предположений и
приближений (точная целочисленная арифметика).

## 0. Определения

pi: Z_n -> Z_n — перестановка. Для `a, b in Z_n` пусть

```
w^{(a,b)}_i = (pi[(a+i) mod n] - b) mod n,   i = 0..n-1
Inv(a,b)     = число инверсий линейной последовательности w^{(a,b)}
I(pi)        = min_{a,b in Z_n} Inv(a,b)
```

Это переобозначение двойного разреза `docs/notes/h13_line_model.md` §0
(`w_j = pi(q+1+j) − (q+1−c) mod n`) с `a = q + 1 mod n`, `b = q + 1 − c mod n`:
при фиксированном `a` переменная `b` пробегает Z_n взаимно однозначно с `c`,
так что `min_{a,b} Inv(a,b) = min_{q,c} inv(w)` — то же самое `I(pi)`.

## 1. Лемма (две рекурсии по соседнему разрезу)

Для любых `a, b`:

```
Inv(a+1, b) = Inv(a, b) + (n - 1 - 2*val),      val  = (pi[a mod n] - b) mod n
Inv(a, b+1) = Inv(a, b) + (n - 1 - 2*istar),    istar = (pi^{-1}(b) - a) mod n
```

(индексы `a+1`, `b+1` — по модулю n).

**Доказательство первой формулы.** Зафиксируем b. Сравним последовательности
`w^{(a)}_i := w^{(a,b)}_i` и `w^{(a+1)}_i`. По определению `w^{(a+1)}_i =
(pi[(a+1+i) mod n]-b) mod n = w^{(a)}_{i+1}` для `i = 0..n-2`, и `w^{(a+1)}_{n-1}
= (pi[(a+n) mod n]-b) mod n = (pi[a mod n]-b) mod n = w^{(a)}_0`. Иначе говоря,
переход `a -> a+1` переносит первый элемент последовательности в конец, не
меняя относительный порядок остальных n−1 элементов между собой.

Пусть `val = w^{(a)}_0 = (pi[a mod n]-b) mod n in {0,...,n-1}`. Число
инверсий, в которых участвует этот элемент:
- как первый элемент (в `w^{(a)}`): пара (0, j) — инверсия, если `w_0 > w_j`;
  таких j ровно `val` (столько элементов последовательности строго меньше
  val, поскольку значения — это в точности {0,...,n-1});
- как последний элемент (в `w^{(a+1)}`): пара (j, n-1) — инверсия, если
  `w_j > w_{n-1} = val`; таких j ровно `n-1-val` (столько элементов строго
  больше val).

Вклады всех остальных пар не меняются (относительный порядок остальных n−1
элементов сохранён). Значит `Inv(a+1,b) - Inv(a,b) = (n-1-val) - val =
n-1-2*val`. ∎

**Доказательство второй формулы.** Зафиксируем a. При `b -> b+1` каждое
значение `w^{(a,b)}_i` уменьшается на 1 по модулю n; единственный индекс
`i*` с `w^{(a,b)}_{i*} = 0` переходит в `n-1` (перенос через 0), у всех
остальных индексов значение уменьшается на 1 без переноса (поскольку их
старое значение лежало в {1,...,n-1}), так что относительный порядок между
ними сохраняется. Тот же счёт, что выше, применённый к элементу `i*
(меняющему роль «наименьший» -> «наибольший» вместо «первый» -> «последний»)
даёт `Inv(a,b+1) - Inv(a,b) = (n-1-i*) - i*= n-1-2*i*`, где `i*` — позиция
(индекс в последовательности при разрезе a) элемента текущего значения b, то
есть `i* = (pi^{-1}(b) - a) mod n` (из `w^{(a,b)}_{i*} = (pi[(a+i*) mod n]-b)
mod n = 0` следует `pi[(a+i*) mod n] = b`, т.е. `a+i* = pi^{-1}(b) mod n`). ∎

## 2. Алгоритм O(n^2)

1. `Inv(0,0)` — прямым подсчётом инверсий последовательности `pi[0..n-1]`,
   O(n^2) (или O(n log n) деревом Фенвика — не требуется, доминирующий член
   и так O(n^2) из шага 3).
2. Ряд `Inv(a,0)` для `a = 0..n-1` — n−1 шагов первой рекурсии, O(n).
3. Для каждого `a` (n значений): ряд `Inv(a,b)` для `b = 0..n-1` — n−1 шагов
   второй рекурсии от `Inv(a,0)`, O(n) на каждое a, итого O(n^2).
4. `I(pi) = min` по всем вычисленным `Inv(a,b)`.

Итого O(n^2) на одну pi (шаг 1 — O(n^2) один раз, шаг 3 — O(n^2) суммарно).
Против O(n^4) прямого перебора (`line_profile.c`) — ускорение порядка `n^2`.

## 3. Проверка реализации

`experiments/toric_cut_fast.c` (toric_cut_fast-1.0), режим `check`: для
каждой pi считает `Inv(a,b)` прямым подсчётом инверсий по определению §0
(перебор всех `n^2` разрезов) и по рекурсии §2, сравнивает минимумы. PASS
(0 расхождений) исчерпывающе при 4 <= n <= 9 (24, 120, 720, 5040, 40320,
362880 перестановок). Совпадение исчерпывающее по построению доказательства
(не численное приближение) — тестируется реализация, а не формула.

## 4. Применение — расширение диапазона C33/H13-I

Режим `profile` того же файла даёт `I(pi)` и максимум по всем pi. Времена
(1 ядро, `gcc -O2`): n = 10 — 1.245 с (было 93 с у line_profile.c), n = 11 —
14.5 с, n = 12 — 3 мин 23 с. Результат (см. `docs/notes/h13_line_model.md`
§7 и обновлённую C33): `max_pi I(pi) = floor((n-1)^2/4)` подтверждено
исчерпывающе при 4 <= n <= 12 (было 4 <= n <= 10), максимум — ровно на n
отражениях в каждом случае (`argmax` — последняя перестановка в порядке
Лемера, известный отражённый вход). n = 13 (6.2 млрд перестановок,
оценка по времени n = 12 — около 50 минут) не запускался: не было отдельного
вопроса, для которого он нужен (правило 10 AGENTS.md); строку C33
расширять дальше — по требованию следующей сессии.
