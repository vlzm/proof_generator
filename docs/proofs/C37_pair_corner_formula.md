# C37 — формула числа несогласных углов двойного разреза для пары точек

Дата: 17.09.2026 (сессия 9). Ядро не требуется (чистая комбинаторика).
Контекст: гипотеза H13-I (PLAN §8, `docs/notes/h13_line_model.md` §6),
попытка доказать `I(pi) <= floor((n-1)^2/4)` для всех pi.

## 0. Определения

Точки перестановки pi на торе `Z_n x Z_n`: `P = {(i, pi(i)) : i in Z_n}`.
Угол — пара `(a, b) in Z_n x Z_n`. Угол `(a,b)` соответствует двойному
разрезу `(q,c)` из `docs/notes/h13_line_model.md` §0 при `a = q+1`,
`b = (a - c) mod n`; переход `(q,c) <-> (a,b)` — биекция `Z_n x Z_n ->
Z_n x Z_n`, так что "минимум по всем `(q,c)`" и "минимум по всем `(a,b)`"
совпадают.

Для угла `(a,b)` линия — `w_j = (pi((a+j) mod n) - b) mod n`, `j = 0..n-1`;
`inv(a,b)` — число инверсий `w` (пар `j<k` c `w_j > w_k`).

Для двух различных позиций `i1 < i2` (обычное целочисленное сравнение,
`i1, i2 in {0,...,n-1}`) пара точек `P1=(i1,pi(i1))`, `P2=(i2,pi(i2))`
*несогласна в угле `(a,b)`*, если относительный порядок `i1,i2` в линии
`w` (т. е. по `(i1-a) mod n` против `(i2-a) mod n`) не совпадает
с относительным порядком `pi(i1), pi(i2)` в линии (по `(pi(i1)-b) mod n`
против `(pi(i2)-b) mod n`). Тогда `inv(a,b) = sum_{i1<i2} [несогласны в (a,b)]`.

## 1. Утверждение

Пусть `d = i2 - i1 in {1,...,n-1}` и `e = (pi(i2) - pi(i1)) mod n in
{1,...,n-1}` (ненулевые, так как `i1 != i2` и `pi(i1) != pi(i2)`). Тогда
число углов `(a,b) in Z_n x Z_n` (из `n^2`), в которых пара `(P1,P2)`
несогласна, равно

```
f(d,e) = n(d+e) - 2de.
```

## 2. Доказательство

**Шаг 1 (одна координата).** Зафиксируем `d in {1,...,n-1}`. Для `a in
Z_n` рассмотрим `j1 = (i1-a) mod n`, `j2 = (i2-a) mod n`; оба в `[0,n)`,
и `j2 - j1 ≡ d (mod n)`. Так как `d in [1,n-1]`, либо `j2-j1 = d` (без
переноса; тогда `j1<j2`, т. е. `i1` идёт раньше `i2`), либо `j2-j1 = d-n`
(с переносом; тогда `j1>j2`, `i2` идёт раньше `i1`). Перенос происходит
ровно тогда, когда `a in {i1+1,...,i1+d} (mod n)` — это `d` значений
из `n`; в остальных `n-d` случаях переноса нет. Значит: `i1` идёт раньше
`i2` для `n-d` значений `a`, и `i2` идёт раньше `i1` для `d` значений `a`.
(Проверено перебором в `experiments/h13_pair_corner.py`, часть 1.)

**Шаг 2 (вторая координата).** Дословно то же рассуждение с `b` вместо
`a`, `pi(i1),pi(i2)` вместо `i1,i2`, `e` вместо `d`: `pi(i1)` идёт раньше
`pi(i2)` для `n-e` значений `b`, обратный порядок — для `e` значений.

**Шаг 3 (произведение).** `a` и `b` независимы, всего `n^2` углов. Пара
несогласна ровно когда один из двух порядков (по `i` или по `pi(i)`)
"нормальный", а другой "обращён" (иначе порядки совпадают — согласны).
Число таких углов:

```
(n-d)*e + d*(n-e) = ne - de + dn - de = n(d+e) - 2de = f(d,e). ∎
```

## 3. Проверка

`experiments/h13_pair_corner.py`, часть 1: для случайных pi при
`n = 5, 6, 7` формула `f(d,e)` сверена с прямым перебором всех `n^2`
углов для каждой пары `(i1,i2)` — совпадение без исключений (все
`C(n,2)` пар при каждом n). `checks/check_C37.py`: то же исчерпывающе
для всех pi при `4 <= n <= 7` (все пары всех перестановок).

## 4. Следствие и статус по H13-I

`f(d,e)` линейна по `d` при фиксированном `e` и наоборот (билинейна),
поэтому для одной пары точек угол, плохой для неё, легко избежать —
но `inv(a,b) = sum` по `C(n,2)` парам одновременно, и разные пары
требуют разных "хороших" углов. Среднее `f` по углам не даёт H13-I
(см. `docs/notes/h13_line_model.md` §5–6: среднее работает только для
sigma_n, не в общем случае). Формула C37 — точный инструмент учёта
одной пары, не завершённое доказательство H13-I; попытка построить
из неё покрывающий аргумент (двойственность/локальный поиск угла,
хороший одновременно для большинства пар) не завершена в сессии 9 —
см. `docs/notes/h13_line_model.md` §7.
