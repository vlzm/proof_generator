## Постановка и конвенции

`n >= 2`, pi — перестановка Z_n. Двойной разрез — пара `(a, s)` из Z_n
(в обозначениях `docs/notes/h13_line_model.md` §0: `a = q + 1`, `s = q + 1 − c`).
Линия разреза:

```text
w_j = (pi(a + j) − s) mod n,   j = 0, ..., n − 1,
inv(a, s) = #{ j < k : w_j > w_k },   I(pi) = min_{a, s} inv(a, s).
```

`I` постоянна на торическом классе `{ i -> pi(i + a') − s' }` и каждый класс
содержит представителя с `pi(0) = 0`.

Цикличный интервал `(x, y] = {x + 1, ..., y}` (в Z_n) имеет `(y − x) mod n`
элементов. Для неупорядоченной пары различных точек `P = (i, pi(i))`,
`Q = (j, pi(j))` фиксируем порядок и полагаем

```text
A = (i − j) mod n,   B = (pi(i) − pi(j)) mod n   (оба из {1, ..., n − 1}).
```

Смена порядка пары заменяет `(A, B)` на `(n − A, n − B)`; все используемые
ниже величины при этом не меняются.

`con(a, s) = C(n,2) − inv(a, s)` — число неинвертированных («согласованных»)
пар. `T_n := floor((n − 1)^2/4)` — цель H13-I.

## 1. Лемма 1 (критерий для одной пары)

Пара `{P, Q}` не инвертирована при разрезе `(a, s)` тогда и только тогда,
когда `[a ∈ (j, i]] = [s ∈ (pi(j), pi(i)]]`. Следовательно, число разрезов,
при которых пара не инвертирована, равно `AB + (n − A)(n − B)`, а число
разрезов, при которых она инвертирована, равно `n(A + B) − 2AB`.

Доказательство. Индекс точки P в линии равен `u = (i − a) mod n`, точки Q —
`v = (j − a) mod n`; P предшествует Q в линии ⟺ `u < v`. Положим
`d = (a − j) mod n`. Если `d = 0`, то `v = 0 < u`. Если `1 <= d <= A`, то
`v = n − d` и `u = (A − d) mod n = A − d <= A − 1 < n − d = v`, то есть `u < v`.
Если `A < d <= n − 1`, то `u = A − d + n` и `v = n − d`, откуда `u − v = A > 0`.
Итак, `u < v` ⟺ `1 <= d <= A` ⟺ `a ∈ (j, i]`. Тот же счёт для значений даёт
`w`-значение P меньше `w`-значения Q ⟺ `s ∈ (pi(j), pi(i)]`. Пара
инвертирована ⟺ ровно одно из двух включений выполнено; число таких `(a, s)`
равно `A(n − B) + (n − A)B = n(A + B) − 2AB`. ∎

## 2. Лемма 2 (точное среднее по всем n^2 разрезам)

Положим `Delta(pi) = sum_{пары} (A + B − n)^2 >= 0`. Тогда

```text
12 * sum_{(a,s) in Z_n^2} inv(a, s) = 3 n^3 (n − 1) + n^2 (n − 1)(n − 2) − 12 Delta(pi),
```

то есть среднее по всем разрезам равно
`n(n − 1)/4 + (n − 1)(n − 2)/12 − Delta(pi)/n^2`.

Доказательство. По лемме 1 сумма равна `sum_{пары} [n(A + B) − 2AB]`.
Тождество (проверяется раскрытием квадрата
`(A + B − n)^2 = (A − n/2)^2 + (B − n/2)^2 + 2(A − n/2)(B − n/2)`):

```text
n(A + B) − 2AB = n^2/2 + (A − n/2)^2 + (B − n/2)^2 − (A + B − n)^2.
```

Далее, суммы квадратов не зависят от pi:

```text
sum_{пары} (A − n/2)^2 = (1/2) sum_{i != j} ((i − j) mod n − n/2)^2
                       = (n/2) * sum_{d=1}^{n−1} (d − n/2)^2
                       = n^2 (n − 1)(n − 2) / 24 =: G_n,
```

где `sum_{d=1}^{n−1} (d − n/2)^2 = n(n − 1)(n − 2)/12` (прямой подсчёт:
`sum d^2 − n sum d + (n − 1)n^2/4`). Первое равенство — потому что
`(A − n/2)^2` не меняется при смене порядка пары `A -> n − A`, поэтому сумму
по неупорядоченным парам можно записать как половину суммы по упорядоченным.
Для значений `B` то же самое: когда `{i, j}` пробегает все пары позиций,
`{pi(i), pi(j)}` пробегает все пары значений, так что
`sum_{пары} (B − n/2)^2 = G_n` при любой pi. Итого

```text
sum_{a,s} inv = C(n,2) * n^2/2 + 2 G_n − Delta(pi)
              = n^3 (n − 1)/4 + n^2 (n − 1)(n − 2)/12 − Delta(pi). ∎
```

## 3. Теорема 3 (общая верхняя оценка I(pi))

Для всех `n >= 2` и всех pi

```text
I(pi) <= n(n − 1)/4 + (n − 1)(n − 2)/12 − Delta(pi)/n^2 <= (n − 1)(2n − 1)/6,
```

и, так как `I` — целое, `I(pi) <= floor((n − 1)(2n − 1)/6)`.

Доказательство. Минимум не превосходит среднего (лемма 2); `Delta >= 0`;
`n(n − 1)/4 + (n − 1)(n − 2)/12 = (n − 1)(4n − 2)/12 = (n − 1)(2n − 1)/6`. ∎

Это первая безусловная общая оценка `I(pi)`; она примерно в 4/3 раза больше
цели H13-I (`(n − 1)(2n − 1)/6 ≈ n^2/3` против `T_n ≈ n^2/4`). Значения:
`floor((n−1)(2n−1)/6)` = 3, 6, 9, 13, 18, 23, 30 при n = 4..10 против
`T_n` = 2, 4, 6, 9, 12, 16, 20.

## 4. Следствие 4 (достаточное условие для H13-I)

Если

```text
Delta(pi) >= n^2 (n^2 + 2)/12   (n чётно),      Delta(pi) >= n^2 (n^2 − 1)/12   (n нечётно),
```

то `I(pi) <= T_n`, то есть H13-I верна для pi.

Доказательство. По теореме 3 достаточно
`Delta/n^2 >= (n − 1)(2n − 1)/6 − T_n`; разность равна `(n^2 + 2)/12` при
чётном n и `(n^2 − 1)/12` при нечётном. ∎

Условие слабое: усреднение по всем `n^2` разрезам покрывает лишь малую часть
входов (6/6, 23/24, 119/120, 712/720, 4979/5040 представителей классов при
n = 4..8 его **не** проходят, см. `data/runs/toric_inversions/`). Причина
видна из леммы 2: у «случайной» pi `Delta` порядка `2 G_n ≈ n^4/12`, а нужно
`≈ n^4/12 + n^3/4`.

## 5. Лемма 5 (нулевой дефект — ровно отражения)

`Delta(pi) = 0` тогда и только тогда, когда pi — отражение `pi_h(i) = h − i`.

Доказательство. `A + B = n` для всех пар ⟺ `pi(i) − pi(j) ≡ −(i − j)` для всех
`i != j` ⟺ `pi(i) + i` постоянно. ∎

## 6. Лемма 6 (отражения: точное значение I, все n)

Для любого `n >= 2` и любого h: `I(pi_h) = T_n = floor((n − 1)^2/4)`.

Доказательство. При разрезе `(a, s)` линия отражения есть
`w_j = (h − a − s − j) mod n = (K − j) mod n`, где `K = (h − a − s) mod n`.
Значит `w = (K, K − 1, ..., 0, n − 1, n − 2, ..., K + 1)`: первые `K + 1`
членов строго убывают и принимают значения `0..K`, остальные `n − K − 1`
строго убывают и принимают значения `K + 1..n − 1`. Любая пара «из первого
блока, из второго» не инвертирована, внутри блоков инвертированы все пары:

```text
inv(a, s) = C(K + 1, 2) + C(n − K − 1, 2) =: f(K).
```

При фиксированном h отображение `(a, s) -> K` сюръективно на Z_n, поэтому
`I(pi_h) = min_{0 <= K <= n − 1} f(K)`. Функция `f` строго выпукла по K
(`f(K+1) − f(K) = K + 1 − (n − K − 1) = 2K + 2 − n`), минимум — при
`K + 1 = floor(n/2)` или `ceil(n/2)`:
`f = C(m,2) + C(m,2) = m(m − 1) = n(n − 2)/4 = T_n` при `n = 2m`;
`f = C(m+1,2) + C(m,2) = m^2 = T_n` при `n = 2m + 1`. ∎

Следствие. Оценка H13-I, если верна, точна при каждом `n >= 2`: равенство
достигается на классе отражений (раньше это было известно лишь как конечная
проверка при `4 <= n <= 10`). Число разрезов с `inv = T_n` равно n при чётном n
и 2n при нечётном.

## 7. Лемма 7 (пошаговое правило; обоснование сканера)

```text
inv(a + 1, s) − inv(a, s) = n − 1 − 2 w_0,   w_0 = (pi(a) − s) mod n,
inv(a, s + 1) − inv(a, s) = n − 1 − 2 p_0,   p_0 = (pi^{-1}(s) − a) mod n.
```

Доказательство. Линия разреза `(a + 1, s)` получается из линии разреза
`(a, s)` переносом первого члена `w_0` в конец. Пары, не содержащие индекса 0,
статус не меняют; пара `(0, k)` была инверсией ⟺ `w_0 > w_k` (таких `k` ровно
`w_0`), а станет инверсией ⟺ `w_k > w_0` (таких `n − 1 − w_0`).
Для второй формулы: при `s -> s + 1` все значения линии уменьшаются на 1 по
модулю n, то есть член со значением 0 (он стоит на индексе
`p_0 = (pi^{-1}(s) − a) mod n`) становится наибольшим, остальные сохраняют
взаимный порядок. Он был инвертирован ровно с `p_0` предшествующими членами,
станет — ровно с `n − 1 − p_0` последующими. ∎

Эта лемма — то же, что «лемма C» из `docs/notes/h13_line_model.md` §4, и она
обосновывает вычисление всей таблицы `inv(a, s)` за `O(n^2)` на перестановку
(`experiments/toric_min_inversions.c`), что и позволило довести исчерпывающую
проверку H13-I до n = 13.

## 8. Эквивалентные формы H13-I (для справки)

`inv + con = C(n,2)`, поэтому для фиксированной pi равносильны:

```text
(i)   существует разрез с inv <= floor((n − 1)^2/4);
(ii)  существует разрез с con >= floor(n^2/4);
(iii) существует разрез с con − inv >= floor(n/2).
```

(Равенства `C(n,2) − floor((n−1)^2/4) = floor(n^2/4)` и
`2 floor(n^2/4) − C(n,2) = floor(n/2)` проверяются отдельно для чётных и
нечётных n.) Форма (iii) — «корреляция Кендалла двух циклических порядков
с выбранными началами неотрицательна с запасом `floor(n/2)`»; по лемме 1
`con − inv = sum_{пары} eps_a(i, j) * eta_s(pi(i), pi(j))`, где
`eps_a(i, j) = ±1` — знак циклической ориентации тройки `(a, i, j)`,
`eta_s` — то же для значений.
