# C37 — торические классы: тождество «инверсии = среднее − корреляция» и оценка `I(pi) <= (n−1)(2n−1)/6`

Дата: 14.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py` (PASS). Эксперимент:
`experiments/toric_inv.c`, отчёт `data/runs/toric_inv/report.md`.
Доказательство не использует N1, C16–C21, C28, C32 и таблицы расстояний:
это чистая комбинаторика перестановок Z_n.

## 0. Обозначения

`pi` — перестановка Z_n (0-индексация), `sigma = pi^{-1}`. Двойной разрез —
пара `(u, v)` из Z_n × Z_n; линия разреза

```text
w_j = (pi(u + j) − v) mod n,   j = 0..n−1,
```

`inv(u, v)` — число обычных линейных инверсий w. Связь с обозначением
`(q, c)` из `docs/notes/h13_line_model.md`: `u = q + 1`, `v = q + 1 − c`;
при пробеге всех `(q, c)` пара `(u, v)` пробегает весь тор, так что

```text
I(pi) = min_{u,v} inv(u, v)
```

— то же число, что и в C33/C35. Ещё две величины:

```text
Ibar(pi) = (1/n^2) * sum_{u,v} inv(u, v)          (среднее по всем разрезам)
k_a      = (1/n) * sum_i ((pi(i + a) − pi(i)) mod n),  a = 1..n−1
```

`k_a` — целое число из `[1, n−1]` (лемма 3 ниже); это «средний сдвиг значения
на дуге длины a». Пилообразная функция

```text
phi(x) = (x mod n) − (n − 1)/2,    sum_{x in Z_n} phi(x) = 0,
```

и «спирменова» корреляция разреза

```text
T(u, v) = sum_{i in Z_n} phi(i − u) * phi(pi(i) − v).
```

## 1. Лемма 1 (шаги разреза)

```text
inv(u + 1, v) − inv(u, v) = −2 * phi(pi(u) − v),
inv(u, v + 1) − inv(u, v) = −2 * phi(sigma(v) − u).
```

Доказательство. Сдвиг разреза позиций на 1 переносит первый элемент линии
в конец. Его значение `a = (pi(u) − v) mod n`; до переноса он инвертирован
ровно с `a` меньшими элементами, стоящими после него, после переноса — ровно
с `n − 1 − a` большими, стоящими до него. Изменение равно
`(n − 1 − a) − a = −2*phi(a)`. Вторая формула — та же выкладка для значений:
сдвиг разреза значений на 1 делает значение `v` наибольшим; оно стоит на
позиции `b = (sigma(v) − u) mod n`, было инвертировано с `b` элементами слева,
стало — с `n − 1 − b` справа. ∎

## 2. Лемма 2 (тождество)

Для всех `(u, v)`

```text
inv(u, v) + (2/n) * T(u, v) = Ibar(pi).
```

Доказательство. `phi(x − 1) − phi(x) = −1 + n * [x ≡ 0 mod n]`, поэтому

```text
T(u + 1, v) − T(u, v) = sum_i (−1 + n*[i = u]) * phi(pi(i) − v)
                      = −sum_i phi(pi(i) − v) + n * phi(pi(u) − v)
                      = n * phi(pi(u) − v),
```

так как `sum_i phi(pi(i) − v) = sum_y phi(y − v) = 0`. Вместе с леммой 1
это даёт `inv(u+1,v) + (2/n)T(u+1,v) = inv(u,v) + (2/n)T(u,v)`. Точно так же
для сдвига v: `T(u, v+1) − T(u, v) = n * phi(sigma(v) − u)`. Значит сумма
постоянна на торе разрезов. Её значение: `sum_v phi(pi(i) − v) = 0` для
каждого i, поэтому сумма T по любой строке (и по любому столбцу) равна нулю,
и среднее `inv` по тору равно константе. ∎

Следствия.

1. `I(pi) = Ibar(pi) − (2/n) * max_{u,v} T(u, v)`: минимум инверсий по
   торическому классу и максимум корреляции T достигаются на одних и тех же
   разрезах (внутри класса «кендалл» и «спирмен» — аффинно связаны).
2. Среднее `inv` по любой полной строке `{(u, v) : v in Z_n}` и по любому
   полному столбцу равно `Ibar`. Поэтому усреднение по строке или столбцу
   никогда не даёт ничего сильнее усреднения по всему тору.
3. `T(u, v) = n^2 * D~(u, v)`, где `D~` — дважды центрированная (вычтены
   средние по строке и по столбцу) угловая дискрепанция
   `D(u, v) = #{i < u : pi(i) < v} − u*v/n`. Прямая выкладка: раскрывая
   `phi(i − u) = (i − u + n*[i < u]) − (n−1)/2` и то же для значений,
   получаем `T(u,v) = Theta + n*(A(u) − u*(n−1)/2) + n*(B(v) − v*(n−1)/2)
   − n*u*v + n^2*N(u,v)`, где `A(u) = sum_{i<u} pi(i)`,
   `B(v) = sum_{y<v} pi^{-1}(y)`, `N(u,v) = #{i < u : pi(i) < v}`,
   `Theta = sum_i (i − (n−1)/2)(pi(i) − (n−1)/2)`; а `A(u) − u(n−1)/2 =
   −sum_v D(u,v)`, `B(v) − v(n−1)/2 = −sum_u D(u,v)`, `Theta = sum_{u,v} D(u,v)`.
   Итак, H13-I — утверждение о максимуме дискрепанции точечного множества
   `{(i, pi(i))}` на торе.
4. Смешанная разность: `inv(u+1,v+1) + inv(u,v) − inv(u+1,v) − inv(u,v+1) =
   2 − 2n*[pi(u) = v]` (прямое следствие леммы 1): `inv` супермодулярна всюду,
   кроме n точек самой pi.

## 3. Лемма 3 (статистики k_a)

Положим `e_i(a) = (pi(i + a) − pi(i)) mod n` для `a != 0`; тогда
`e_i(a) in [1, n−1]` и `k_a = (1/n) sum_i e_i(a)`.

1. `k_a` — целое: `sum_i e_i(a) ≡ sum_i (pi(i+a) − pi(i)) = 0 (mod n)`,
   и `1 <= k_a <= n − 1`.
2. `k_a + k_{n−a} = n`: при всех i `e_i(a) + e_{i+a}(n−a) = n` (сумма делится
   на n и лежит в `[2, 2n−2]`).
3. При `a + b + c ≡ 0 (mod n)`, `a, b, c in [1, n−1]`: `k_a + k_b + k_c <= 2n`.
   Действительно, `e_i(a) + e_{i+a}(b) + e_{i+a+b}(c)` делится на n и лежит
   в `[3, 3n−3]`, значит равно n или 2n; суммируем по i и делим на n. ∎

## 4. Лемма 4 (формула среднего)

```text
Ibar(pi) = n(n−1)/2 − (1/n) * sum_{a=1}^{n−1} a * k_a.
```

Доказательство. Пара позиций `i != j` с `a = (j − i) mod n`,
`b = (pi(j) − pi(i)) mod n` инвертирована в разрезе `(u, v)` тогда и только
тогда, когда ровно одно из событий «i раньше j», «pi(i) раньше pi(j)»
выполнено. Первое верно ровно для `n − a` значений u, второе — для `n − b`
значений v, и события независимы по u и v; значит пара инвертирована ровно
в `a(n − b) + (n − a)b` разрезах. Суммируя по неупорядоченным парам
(то есть половину суммы по упорядоченным) и деля на `n^2`:

```text
Ibar = (1/(2n^2)) * sum_{i != j} [ n(a + b) − 2ab ].
```

Здесь `sum_{i != j} a = sum_{i != j} b = n * n(n−1)/2` (для каждого значения
разности ровно n упорядоченных пар; для b — потому что pi биекция), а
`sum_{i != j} ab = sum_a a * sum_i e_i(a) = n * sum_a a*k_a`. Подстановка
даёт формулу. ∎

Проверка на краях: тождественная `pi` даёт `k_a = a` и
`Ibar = (n^2 − 1)/6`; отражение `pi_h(i) = h − i` даёт `k_a = n − a` и
`Ibar = (n−1)(2n−1)/6`.

## 5. Лемма 5 (весовое неравенство)

```text
sum_{a=1}^{n−1} a * k_a >= sum_{a=1}^{n−1} a(n − a) = n(n^2 − 1)/6   (n >= 3).
```

Доказательство. Положим `g_a = k_a − (n − a)`. По лемме 3.2
`g_a + g_{n−a} = 0`, поэтому `sum_{a=1}^{n−1} g_a = 0`. По лемме 3.3 для любых
целых `a, b, c >= 1` с `a + b + c = n`

```text
g_a + g_b + g_c = (k_a + k_b + k_c) − 3n + (a + b + c) = (k_a + k_b + k_c) − 2n <= 0.
```

Просуммируем это по всем упорядоченным тройкам `(a, b, c)` натуральных чисел
с суммой n. Каждый индекс a входит в `3 * #{(b, c) : b + c = n − a} = 3(n − 1 − a)`
слагаемых, поэтому

```text
sum_{a=1}^{n−1} (n − 1 − a) * g_a <= 0.
```

Так как `sum_a g_a = 0`, левая часть равна `−sum_a a*g_a`. Значит
`sum_a a*g_a >= 0`, то есть `sum_a a*k_a >= sum_a a(n − a)`. ∎

Равенство достигается, когда все тройные неравенства точны; в частности при
`k_a = n − a`, то есть на всех отражениях (и, как показывает перебор
`experiments/toric_inv.c`, только на них при 4 <= n <= 13).

## 6. Теорема

Для всех `n >= 3` и всех перестановок pi

```text
I(pi) <= Ibar(pi) <= (n − 1)(2n − 1)/6,   то есть  I(pi) <= floor((n−1)(2n−1)/6).
```

Доказательство. Первое неравенство — «минимум не больше среднего». Второе:
по леммам 4 и 5 `Ibar <= n(n−1)/2 − n(n^2−1)/(6n) = (n−1)(2n−1)/6`. ∎

Это первая доказанная общая верхняя оценка для `I(pi)`; гипотеза H13-I требует
`floor((n−1)^2/4)`, то есть асимптотически в `4/3` раза меньше:
`(n−1)(2n−1)/6 ≈ n^2/3`, `floor((n−1)^2/4) ≈ n^2/4`.

Побочно: `max_pi Ibar(pi) = (n−1)(2n−1)/6` — максимум среднего по разрезам
достигается ровно на отражениях (верхняя оценка доказана, достижимость —
прямой подсчёт).

## 7. Что осталось до H13-I

По следствию 1 леммы 2 гипотеза H13-I равносильна

```text
max_{u,v} T(u, v) >= (n/2) * (Ibar(pi) − floor((n−1)^2/4)),
```

а правая часть по теореме не превосходит `(n/2)((n−1)(2n−1)/6 −
floor((n−1)^2/4)) ≈ n^3/24`. На отражениях обе части равны `n^3/24 + O(n)`,
то есть неравенство точно и «тонкое»: T принимает значения порядка `n^3`,
а запас — порядка `n^2`. Отвергнутые подходы и проверенные диапазоны —
`docs/notes/h13_I_toric.md`.
