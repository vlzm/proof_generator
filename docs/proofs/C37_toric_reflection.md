# C37 — торические разрезы: точность константы `floor((n−1)^2/4)` и запреты усреднений

один автор). Чекер: `checks/check_C37.py`. Эксперимент-первоисточник:
`experiments/toric_cuts.py`, отчёт `data/runs/toric_cuts/report.md`.
Конвенции — PROBLEM §3; линейная модель и `I(pi)` — `docs/notes/h13_line_model.md` §0.
Доказательство не использует N1, C16–C21, таблицы расстояний и ядро ходов:
это чистая комбинаторика перестановок.

## 0. Обозначения

Для перестановки pi множества Z_n (n >= 4) и двойного разреза `(p, s)` из Z_n × Z_n
линия — это последовательность

```text
w_j = (pi[(p + j) mod n] − s) mod n,   j = 0, ..., n − 1,
```

перестановка множества {0, ..., n − 1}; `inv(w)` — число её инверсий,

```text
I(pi) = min по всем n^2 разрезам (p, s) от inv(w).
```

(Связь с обозначениями заметки: `p = q + 1`, `s = q + 1 − c`; при пробеге (q, c)
по Z_n × Z_n пара (p, s) пробегает Z_n × Z_n, так что оба определения `I` совпадают.)

Разрез задаёт два линейных порядка на n точках `A_i = (i, pi(i))`: порядок
позиций и порядок значений. Пару точек называем **согласной**, если оба порядка
её упорядочивают одинаково, и **несогласной** иначе; число несогласных пар и
есть `inv(w)`. Для пары точек A, B положим
`dx = (x_B − x_A) mod n`, `dy = (y_B − y_A) mod n` (обе величины в {1, ..., n−1}).

Отражение: `pi_h(i) = (h − i) mod n`; `sigma_n = pi_1`.

H13-I — утверждение `I(pi) <= floor((n − 1)^2/4)` для всех pi и всех n >= 4;
здесь оно **не доказывается** (вердикт сессии — `docs/notes/h13_line_model.md` §7).
Ниже доказано, что константа в нём точна при каждом n, и перечислены
доказанные препятствия для усреднений.

## Утверждение C37

Для всех n >= 4:

1. **(Нижняя оценка и точность.)** Для каждого отражения `pi_h` и каждого
   двойного разреза `inv(w) >= floor((n − 1)^2/4)`, причём равенство достигается;
   значит `I(pi_h) = floor((n − 1)^2/4)` при всех n >= 4 и всех h. Следовательно
   константу в H13-I нельзя уменьшить ни при каком n >= 4.
2. **(Общая нижняя оценка через тройки.)** Пусть `T(pi)` — число троек точек, на
   которых циклический порядок позиций и циклический порядок значений
   противоположны. `T` — инвариант торического класса, и
   `(n − 2) · I(pi) >= T(pi)`; кроме того `T(pi) = C(n,3)` тогда и только тогда,
   когда pi — отражение.
3. **(Среднее по всем разрезам.)** Число разрезов, делающих данную пару
   несогласной, равно `n·dx + n·dy − 2·dx·dy`; отсюда среднее `inv` по всем n^2
   разрезам равно `C(n,2) − (1/n^2)·сумма dx·dy по упорядоченным парам`, а на
   отражениях оно равно `C(n,2) − (n^2 − 1)/6` и превосходит `floor((n−1)^2/4)`
   не менее чем на `(n^2 − 1)/12`.
4. **(Запрет для аффинных входов.)** Если `gcd(a, n) = 1` и `pi(i) = a·i + b`, то
   `inv(p, s)` зависит только от `r = (a·p + b − s) mod n`, и каждое значение r
   даёт ровно n разрезов. Поэтому любое семейство разрезов, задевающее каждый
   класс r одинаковое число раз, даёт на отражении среднее
   `C(n,2) − (n^2 − 1)/6` и для H13-I непригодно; таковы равномерное
   усреднение и все семейства фиксированного наклона
   `{(p, a'·p + tau)}` с `gcd(1 + a', n) = 1` (остальные наклоны отсеиваются
   конечными контрпримерами, см. §7 и `data/runs/toric_cuts/report.md`).
5. **(Семейство, привязанное к точкам.)** Семейство `F(alpha, beta) = {(x_A + alpha,
   y_A + beta) : A — точка pi}` из n разрезов на аффинных входах лежит целиком
   в одном классе r, поэтому `min по (alpha, beta)` даёт там в точности `I(pi)`;
   но в общем случае оно недостаточно (наименьший контрпример n = 5).

Пункты 1–4 доказаны ниже. Пункт 5: первая часть доказана (лемма 6), вторая —
конечная (контрпримеры, п. «Машинная сверка»).

## 1. Лемма 1 (`B_n = C(n,2)` и двойственная форма H13-I)

`floor(n^2/4) + floor((n−1)^2/4) = n(n−1)/2 = C(n,2)` (C12 и прямой разбор
чётности: при чётном n это `n^2/4 + (n^2−2n)/4`, при нечётном
`(n^2−1)/4 + (n−1)^2/4`). Значит для любого разреза

```text
inv(w) <= floor((n−1)^2/4)  <=>  (число согласных пар) >= floor(n^2/4),
```

и H13-I равносильно утверждению «у каждой pi есть разрез, у которого согласных
пар не меньше `floor(n^2/4) = max_k k(n − k)`». ∎

## 2. Лемма 2 (линия отражения — две убывающие дуги)

Для `pi_h` и разреза (p, s) линия равна `w_j = (t − j) mod n`, где
`t = (h − p − s) mod n`; при пробеге (p, s) параметр t пробегает Z_n, каждое
значение ровно n раз.

Доказательство: `w_j = (h − (p + j) − s) mod n = (t − j) mod n`. ∎

Такая линия — это блок `t, t−1, ..., 0` длины `t + 1`, за которым идёт блок
`n−1, n−2, ..., t+1` длины `n − 1 − t`. Внутри каждого блока все пары —
инверсии; любая пара «первый блок / второй блок» инверсией не является
(значение слева не больше t, справа больше t). Значит

```text
число согласных пар = (t + 1)·(n − 1 − t),
inv(w) = C(n,2) − (t + 1)(n − 1 − t).
```

## 3. Теорема 1 (пункт 1 утверждения)

`max_{t in Z_n} (t + 1)(n − 1 − t) = max_{k=1..n-1} k(n − k) = floor(n^2/4)`
(подстановка `k = t + 1`, `t = 0, ..., n−1` даёт `k = 1, ..., n`, а `k = n`
даёт 0). Поэтому по лемме 2 и лемме 1

```text
inv(w) >= C(n,2) − floor(n^2/4) = floor((n−1)^2/4)
```

для каждого разреза, с равенством при `t + 1 = floor(n/2)` (или `ceil(n/2)`).
Итак `I(pi_h) = floor((n−1)^2/4)` при всех n >= 4 и всех h. ∎

Замечание. Раньше равенство `max_pi I(pi) = floor((n−1)^2/4)` было только
конечным (C33, VERIFIED 4 <= n <= 10). Теорема 1 доказывает нижнюю половину
(«не меньше») при всех n >= 4: верхняя половина — это и есть открытая H13-I.
Единственность максимизатора (равенство только на отражениях) остаётся конечной
(VERIFIED 4 <= n <= 10, здесь — 4 <= n <= 8 независимой проверкой).

## 4. Лемма 3 (инвариант троек)

Тройка точек несёт два циклических порядка: по позициям и по значениям. Назовём
тройку **нечётной**, если они противоположны. Для тройки, линеаризованной
разрезом, циклические порядки совпадают тогда и только тогда, когда число
несогласных пар среди трёх её пар чётно (0 или 2): шесть линейных порядков
тройки распадаются на два циклических класса по три, переход внутри класса —
чётная перестановка. Значит нечётность тройки не зависит от разреза, и
`T(pi)` — инвариант торического класса. ∎

## 5. Лемма 4 (`(n − 2)·inv >= T`)

Зафиксируем разрез и построим граф D несогласных пар на n вершинах, `|D| = inv`.
По лемме 3 нечётные тройки — это тройки с нечётным числом рёбер D (1 или 3).
Обозначим `t_i` число троек ровно с i рёбрами. Считая пары (тройка, ребро),
`inv·(n − 2) = t_1 + 2 t_2 + 3 t_3`, а `T = t_1 + t_3`, откуда

```text
inv·(n − 2) = T + 2 (t_2 + t_3) >= T.
```

Это верно для каждого разреза, значит `(n − 2)·I(pi) >= T(pi)`. ∎

## 6. Лемма 5 (характеризация `T = C(n,3)`)

Циклический порядок на n >= 3 элементах однозначно определяется своими тройками.
`T(pi) = C(n,3)` значит, что на каждой тройке циклический порядок значений
противоположен циклическому порядку позиций, то есть циклический порядок
значений — обращённый; это равносильно `pi(i + 1) = pi(i) − 1` для всех i,
то есть `pi = pi_h` с `h = pi(0)`. ∎

Дополнение (структурная форма). Если все тройки нечётны, то при любом разрезе
граф **согласных** пар G не содержит троек с нечётным числом рёбер, поэтому
отношение «uv не ребро G» рефлексивно, симметрично и транзитивно (если uv и vw
не рёбра, то тройка имеет не более одного ребра, значит ноль), классы —
независимые множества, между разными классами все пары — рёбра; при трёх и
более классах нашлась бы тройка с тремя рёбрами. Итак G — полный двудольный
граф `K_{k, n−k}`, число согласных пар `k(n − k) <= floor(n^2/4)` — второе
доказательство теоремы 1, уже без явного вида линии.

## 7. Лемма 6 (счёт разрезов по паре; пункты 3–5 утверждения)

Для пары точек A, B точка A стоит раньше B в порядке позиций тогда и только
тогда, когда `p` лежит в дуге `(x_B, x_A]` длины `n − dx`; аналогично для
значений и дуги `(y_B, y_A]` длины `n − dy`. Позиции p и s пробегают Z_n
независимо, поэтому число разрезов с несогласной парой равно

```text
(n − dx)·dy + dx·(n − dy) = n·dx + n·dy − 2·dx·dy,
```

выражение симметрично относительно замены (dx, dy) -> (n − dx, n − dy), то есть
не зависит от выбора направления пары. Суммируя по неупорядоченным парам и
пользуясь `сумма по упорядоченным парам dx = n^2 (n−1)/2` (для каждой точки
сумма dx по остальным равна `0 + 1 + ... + (n−1)`), получаем

```text
среднее inv по n^2 разрезам = C(n,2) − (1/n^2)·сумма по упорядоченным парам dx·dy.
```

Для отражения `dy = n − dx`, поэтому
`сумма dx·dy = n·сумма_{d=1}^{n-1} d(n−d) = n^2 (n^2 − 1)/6`, и среднее равно
`C(n,2) − (n^2 − 1)/6`. Разность с границей:

```text
C(n,2) − (n^2 − 1)/6 − (n − 1)^2/4 = (n^2 − 1)/12 > 0   (n >= 2),
```

значит среднее строго больше `floor((n−1)^2/4)` — равномерное усреднение
доказать H13-I не может (пункт 3). ∎

Аффинные входы. Если `pi(i) = a·i + b` и `gcd(a, n) = 1`, то
`w_j = a·(p + j) + b − s = a·j + r`, где `r = (a·p + b − s) mod n`: линия зависит
только от r, и уравнение `a·p + b − s = r` имеет ровно n решений (p, s). Значит
всякое семейство разрезов, задевающее каждый класс r одинаковое число раз, даёт
среднее `mean_r inv`, а на отражении (`a = n − 1`, `mean_r inv` — среднее по всем
разрезам) это `C(n,2) − (n^2 − 1)/6` (пункт 4). ∎

Семейства фиксированного наклона. Для семейства
`F_{a', tau} = {(p, a'·p + tau) : p in Z_n}` и отражения `pi_h` имеем
`r = (h − p − s) mod n = h − tau − (1 + a')·p`: образ — подгруппа, порождённая
`1 + a'`, каждое её значение достигается `gcd(1 + a', n)` раз. Если
`gcd(1 + a', n) = 1`, семейство задевает каждый класс r ровно один раз, и по
предыдущему абзацу оно на отражении бесполезно. Исключение — наклоны с
`gcd(1 + a', n) > 1` (в частности «антидиагональ» `a' = n − 1`, целиком лежащая
в одном классе и потому точная на отражениях): они отсеиваются другими входами,
см. конечные контрпримеры ниже (минимум по всем n^2 семействам
`{(p, a'p + tau)}` уже при n = 5 превышает границу на `(0,2,1,4,3)`).

Семейство, привязанное к точкам (пункт 5): для `F(alpha, beta)` и аффинной pi
имеем `p = i + alpha`, `s = a i + b + beta`, поэтому
`r = a(i + alpha) + b − (a i + b + beta) = a·alpha − beta` — одно и то же для всех
n разрезов семейства; при пробеге (alpha, beta) величина `a·alpha − beta`
пробегает Z_n, поэтому `min по (alpha, beta)` от среднего по семейству равен
`min_r inv = I(pi)`. То есть на всех аффинных входах это семейство точно. ∎

- часть D: аффинные входы при `4 <= n <= 12` — `inv` зависит только от r,
  каждое r даёт ровно n разрезов, семейство `F(alpha, beta)` даёт `I(pi)`;
  контрпримеры к нему вне аффинных входов: n = 5 `(0,1,4,3,2)` (среднее 21/5),
  n = 7 `(0,2,1,6,5,4,3)` (67/7), n = 8 `(5,7,6,4,3,0,2,1)` (25/2) — всюду
  строго больше `floor((n−1)^2/4)`.
