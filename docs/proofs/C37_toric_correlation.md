# C37 — торическая корреляционная тождественность для inv(q, c) и оценка среднего

Дата: 13.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py`. Эксперимент:
`experiments/toric_correlation.py` (toric_corr-1.0), отчёт
`data/runs/toric_correlation/report.md`. Доказательство не использует N1,
таблицы расстояний и предыдущие утверждения; это чистая комбинаторика
перестановок.

## 0. Обозначения

`pi` — перестановка Z_n, n >= 2. Разрез `(q, c)` из Z_n x Z_n задаёт линию

```text
w_j = (pi(q + 1 + j) - (q + 1 - c)) mod n,   j = 0, ..., n - 1,
inv(q, c) = #{ (j, k) : j < k, w_j > w_k }.
```

`I(pi) = min_{q,c} inv(q, c)` (H13-I утверждает `I(pi) <= floor((n-1)^2/4)`).

Пилообразная функция и две корреляции (всюду `t mod n` — представитель
в {0, ..., n-1}):

```text
sig(t)  = n - 1 - 2 (t mod n),          sum_{t in Z_n} sig(t) = 0,
S(q, s) = sum_{i in Z_n} sig(q - i) sig(s - pi(i)),
E(pi)   = sum_{i, j in Z_n} sig(j - i) sig(pi(j) - pi(i)).
```

Значения `sig` — это n-1, n-3, ..., -(n-1), все различные; `sig(0) = n - 1`.
Разрезу `(q, c)` сопоставляется точка `(q, s)` с `s = (q - c) mod n`;
при пробеге `(q, c)` по Z_n x Z_n точка `(q, s)` пробегает Z_n x Z_n биективно.

Отражения: `pi_h(i) = (h - i) mod n` (sigma_n — это h = 1, PROBLEM §1).

## 1. Теорема A (тождество)

**Теорема A.** Для любых pi, n >= 2 и любого разреза (q, c) с `s = (q - c) mod n`

```text
4 n^2 inv(q, c) = n^2 (n^2 - 1) - E(pi) - 2 n S(q, s),
```

то есть `inv(q, c) = (n^2 - 1)/4 - E(pi)/(4 n^2) - S(q, s)/(2 n)`.

В частности `inv` зависит от разреза только через `S`, а `min_{q,c} inv`
отвечает `max_{q,s} S`.

### 1.1. Лемма 1 (sig — это индекс в линии)

Зафиксируем разрез. Для элемента i положим

```text
x_i = (i - q - 1) mod n   — позиция i в линии,
y_i = (pi(i) - (q + 1 - c)) mod n   — значение i в линии,
```

так что `w_{x_i} = y_i`, и оба набора `{x_i}`, `{y_i}` пробегают
{0, ..., n-1}. Тогда

```text
sig(q - i) = 2 x_i - (n - 1),      sig(s - pi(i)) = 2 y_i - (n - 1).
```

Доказательство. Пусть `p = x_i`. Если `p <= n - 2`, то `(i - q) mod n = p + 1`,
это не 0, поэтому `(q - i) mod n = n - p - 1` и
`sig(q - i) = n - 1 - 2(n - p - 1) = 2p + 1 - n`. Если `p = n - 1`, то `i = q`,
`(q - i) mod n = 0` и `sig(q - i) = n - 1 = 2p + 1 - n`. Оба случая дают
`sig(q - i) = 2p + 1 - n = 2 x_i - (n - 1)`. Вторая формула — та же выкладка с заменой `i -> pi(i)`, `q -> s`: по
определению `s = q - c`, поэтому `(s - pi(i)) mod n` относится к
`y_i = (pi(i) - s - 1) mod n = (pi(i) - (q + 1 - c)) mod n`. ∎

### 1.2. Лемма 2 (S — это линейный момент линии)

```text
S(q, s) = 4 sum_{j=0}^{n-1} j * w_j - n (n - 1)^2.
```

Доказательство. По лемме 1

```text
S = sum_i (2 x_i - (n-1)) (2 y_i - (n-1))
  = 4 sum_i x_i y_i - 2(n-1) (sum_i x_i + sum_i y_i) + n (n-1)^2.
```

`sum_i x_i = sum_i y_i = n(n-1)/2`, поэтому средний член равен `-2n(n-1)^2`,
и `S = 4 sum_i x_i y_i - n(n-1)^2`. Наконец `sum_i x_i y_i = sum_j j w_j`,
так как пары `(x_i, y_i)` — это в точности пары `(j, w_j)`. ∎

### 1.3. Лемма 3 (инвариант)

Величина `Phi(q, c) = inv(q, c) + (2/n) sum_j j w_j` одна и та же для всех
n^2 разрезов данной pi.

Доказательство. Достаточно проверить два элементарных сдвига.

(а) Сдвиг разреза значений, `c -> c + 1` при том же q. Тогда
`w_j' = (w_j + 1) mod n`: элемент со значением n-1 (пусть он стоит на позиции
x) получает значение 0, у всех остальных значение увеличивается на 1, и их
взаимный порядок не меняется. Инверсии: раньше этот элемент был максимальным
и давал инверсию с каждым элементом правее себя — их n-1-x штук; теперь он
минимален и даёт инверсию с каждым элементом левее — их x штук. Значит

```text
delta inv = x - (n - 1 - x) = 2x - (n - 1).
```

Линейный момент: элемент на позиции x меняет вклад на `-x(n-1)`, каждый из
остальных даёт `+j`, то есть
`delta sum_j j w_j = -x(n-1) + sum_{j != x} j = -x(n-1) + (n(n-1)/2 - x)
= -x n + n(n-1)/2`, поэтому
`(2/n) delta sum_j j w_j = (n-1) - 2x = -delta inv`. Итого `delta Phi = 0`.

(б) Сдвиг разреза позиций, `q -> q + 1` (одновременно `c -> c + 1`, чтобы
сдвинулась только позиция; в координатах `(q, s)` это сдвиг `q -> q + 1`
при том же s). Первый элемент линии (значение y) переходит в конец, остальные
сдвигаются на одну позицию влево. Раньше он давал инверсию с каждым меньшим
значением — их y штук; теперь — с каждым большим, их n-1-y штук:

```text
delta inv = (n - 1 - y) - y = n - 1 - 2y.
```

Момент: `delta sum_j j w_j = y (n-1) - sum_{others} w = y(n-1) - (n(n-1)/2 - y)
= y n - n(n-1)/2`, значит `(2/n) delta = 2y - (n-1) = -delta inv`. ∎

Оба сдвига порождают всю группу Z_n x Z_n разрезов, поэтому Phi постоянна.

### 1.4. Лемма 4 (значение константы)

```text
avg_{q,c} inv(q, c) = (n^2 - 1)/4 - E(pi)/(4 n^2).
```

Доказательство. Считаем среднее по парам. Для i != j положим
`u = (j - i) mod n`, `v = (pi(j) - pi(i)) mod n` (оба не равны 0). Пара {i, j}
образует инверсию линии разреза (q, c) тогда и только тогда, когда порядок по
позиции и порядок по значению расходятся; по лемме 1 порядок по позиции
совпадает с порядком `x`, и `x_i < x_j` в точности для n - u значений q
(и `x_i > x_j` для u значений), аналогично для значений. Позиционный и
значенный разрезы независимы, поэтому доля разрезов, где пара инвертирована,
равна

```text
P(u, v) = [ u (n - v) + (n - u) v ] / n^2 = [ n(u + v) - 2uv ] / n^2.
```

Из `sig(u) sig(v) = (n-1)^2 - 2(n-1)(u+v) + 4uv` получаем
`2uv = [sig(u) sig(v) - (n-1)^2]/2 + (n-1)(u+v)`, значит

```text
n^2 P(u, v) = (u + v) - [ sig(u) sig(v) - (n-1)^2 ] / 2.
```

Суммируем по всем упорядоченным парам i != j и делим на 2 (каждая
неупорядоченная пара учтена дважды; величина `P` не зависит от выбора
ориентации, что видно из первой формулы для P):

```text
sum_{i != j} (u + v) = 2 * n * (1 + 2 + ... + (n-1)) = n^2 (n - 1),
sum_{i != j} sig(u) sig(v) = E(pi) - n (n-1)^2
```

(в E добавлены n диагональных членов `sig(0)^2 = (n-1)^2`). Итого

```text
n^2 avg inv = (1/2) [ n^2 (n-1) ] - (1/4) [ E - n(n-1)^2 ]
              + (1/4) n(n-1) (n-1)^2
            = n^2 (n-1)/2 - E/4 + n^2 (n-1)^2 / 4,
```

откуда `avg inv = (n-1)/2 + (n-1)^2/4 - E/(4n^2) = (n^2-1)/4 - E/(4n^2)`. ∎

### 1.5. Доказательство теоремы A

По лемме 2 `(2/n) sum_j j w_j = S/(2n) + (n-1)^2/2`, поэтому лемма 3 означает,
что `inv(q, c) + S(q, s)/(2n)` постоянна на всех n^2 разрезах. Так как
`sum_{t in Z_n} sig(t) = 0`, при суммировании S по всем (q, s) получается 0,
то есть `avg S = 0`; значит константа равна `avg inv`, и по лемме 4 она равна
`(n^2-1)/4 - E/(4n^2)`. ∎

## 2. Теорема B (оценка энергии) и её случай равенства

**Теорема B.** Для любой pi и любого n >= 2

```text
E(pi) >= 2 n^2 (n - 1) - n^2 (n^2 - 1) / 3,
```

причём равенство достигается тогда и только тогда, когда pi — отражение
`pi(i) = h - i`.

Доказательство. Разобьём E по i. Диагональные члены (j = i) дают
`n * sig(0)^2 = n (n-1)^2`. При фиксированном i отображение
`j -> u = (j - i) mod n` — биекция Z_n \ {i} -> Z_n \ {0}, а
`tau_i(u) = (pi(i + u) - pi(i)) mod n` — биекция Z_n \ {0} -> Z_n \ {0}
(из инъективности pi). Поэтому

```text
E = n (n-1)^2 + sum_i sum_{u != 0} sig(u) sig(tau_i(u)).
```

Числа `sig(u)`, u = 1, ..., n-1, попарно различны и строго убывают по u.
По неравенству о перестановках при фиксированном i сумма
`sum_{u != 0} sig(u) sig(tau_i(u))` минимальна, когда `tau_i` расставляет
множители в обратном порядке, то есть `tau_i(u) = n - u`, и минимум строгий
для любой другой биекции (все `sig(u)` различны). Значит

```text
sum_{u != 0} sig(u) sig(tau_i(u)) >= sum_{u=1}^{n-1} sig(u) sig(n - u).
```

Правая часть считается явно: при `A = sig(u) = n - 1 - 2u` имеем
`sig(n - u) = 2u - n - 1 = -A - 2`, поэтому `sig(u) sig(n-u) = -A^2 - 2A`, и

```text
sum_{u=1}^{n-1} A   = (n-1)^2 - n(n-1) = -(n-1),
sum_{u=1}^{n-1} A^2 = n(n^2-1)/3 - (n-1)^2,
sum_{u=1}^{n-1} sig(u) sig(n-u) = -n(n^2-1)/3 + (n-1)^2 + 2(n-1).
```

Складывая n таких сумм и диагональ, получаем

```text
E >= n(n-1)^2 + n[ (n-1)^2 + 2(n-1) - n(n^2-1)/3 ]
   = 2 n (n-1) * n - n^2 (n^2-1)/3 = 2 n^2 (n-1) - n^2 (n^2-1)/3.
```

Равенство требует `tau_i(u) = n - u` при всех i и всех u != 0, то есть
`pi(i + u) - pi(i) = -u` для всех i, u, что равносильно
`pi(i) + i = const`, то есть pi — отражение; обратно, для отражения
`tau_i(u) = n - u` тождественно и равенство достигается. ∎

## 3. Следствие C (доказанная при всех n оценка для I(pi))

**Следствие C.** Для любой pi и любого n >= 2

```text
avg_{q,c} inv(q, c) = (n^2-1)/4 - E(pi)/(4n^2) <= (n-1)(2n-1)/6,
```

с равенством тогда и только тогда, когда pi — отражение. В частности

```text
I(pi) <= floor( (n-1)(2n-1)/6 )   для всех pi и всех n >= 2.
```

Доказательство. Первое равенство — лемма 4; подстановка оценки теоремы B даёт

```text
avg inv <= (n^2-1)/4 - (n-1)/2 + (n^2-1)/12 = (n-1)(2n-1)/6,
```

случай равенства наследуется из теоремы B. Минимум не превосходит среднего,
а `I(pi)` — целое. ∎

Замечания.

1. Это первая доказанная при всех n нетривиальная верхняя оценка для `I(pi)`
   (тривиальная — `inv <= n(n-1)/2`). Она слабее
   цели H13-I: `(n-1)(2n-1)/6 ~ n^2/3` против `floor((n-1)^2/4) ~ n^2/4`
   (отношение стремится к 4/3). Уже при n = 4 она даёт 3 против цели 2.
2. Следствие C строго объясняет известный факт (`docs/notes/h13_line_model.md`
   §6), что усреднение по всем n^2 разрезам не доказывает H13-I: максимум
   среднего равен `(n-1)(2n-1)/6` и достигается ровно на отражениях —
   тех же входах, на которых H13-I тесна. Разрыв между средним и целью равен
   `(n-1)(2n-1)/6 - (n-1)^2/4 = (n-1)(n+1)/12` — ровно `(n^2-1)/12`.
3. Теорема A даёт эквивалентную форму H13-I: при
   `thr(n) = n floor(n/2) + n(n-1)/2`

   ```text
   H13-I  <=>  2 n max_{q,s} S(q, s) + E(pi) >= 2 n thr(n).
   ```

   Обе части тесны на отражениях: для отражения
   `max S = -n(n^2-1)/3 + 2n floor(n^2/4)` и `E` равно границе теоремы B.
4. Теорема A даёт и алгоритм: `I(pi)` вычисляется как `max S` — циклическая
   двумерная корреляция, O(n^2) операций после O(n^2) подготовки (или
   O(n^2 log n) через БПФ) вместо перебора n^2 линий по O(n log n).
5. Для отражения `pi_h` имеем `S(q, s) = C((q + s - h) mod n)`, где
   `C(m) = sum_u sig(u) sig(m - u) = -n(n^2-1)/3 + 2n(m+1)(n-1-m)` —
   вогнутая парабола; отсюда `max S` и `I(pi_h) = floor((n-1)^2/4)` заново
   и без перебора.
