## 0. Переобозначение разреза

Разрез `(q, c)` (`line_model.py`) даёт линию `w_j = pi(q+1+j) - (q+1-c) mod n`.
Положим `a = q+1 mod n` (начало отсчёта позиций), `b = q+1-c mod n` (начало
отсчёта значений); тогда `w_j = pi(a+j) - b mod n`. При фиксированном `q`,
`c` пробегает `Z_n` биективно на `b`; `q` пробегает `Z_n` биективно на `a`.
Значит `(q, c) <-> (a, b)` — биекция `Z_n x Z_n` на себя, и
`I(pi) = min_{q,c} inv(w) = min_{a,b} inv(w)`. Ниже разрез задаётся парой
`(a, b)`.

Для разреза `(a, b)` и пары индексов `i1 < i2` (i1, i2 — позиции, 0-индексация,
плоское, не по модулю сравнение) пусть `i1' = i1 - a mod n`, `i2' = i2 - a mod n`
— их места в линии, `j1' = pi(i1) - b mod n`, `j2' = pi(i2) - b mod n` — их
значения в линии. Пара согласована (даёт неинверсию), если порядок `i1', i2'`
совпадает с порядком `j1', j2'`.

## 1. Лемма 1 (число разрезов, согласующих данную пару)

Пусть `di = (i2 - i1) mod n in {1, ..., n-1}`. Для фиксированных `i1 < i2`,
`i1' < i2'` (позиционный порядок сохранён) — ровно для `n - di` значений `a`
из `n`, и `i2' < i1'` — ровно для `di` значений `a`. (Симметрично для `b` и
`dj = (pi(i2) - pi(i1)) mod n`.)

Доказательство. `i1' - i2' = i1 - i2 mod n = -di mod n = n - di` — константа,
не зависящая от `a`. При изменении `a` на 1 оба `i1', i2'` уменьшаются на 1 по
модулю `n`, поэтому порядок `i1' < i2'` инвертируется ровно в двух точках
окружности `Z_n` (в `a = i1` и `a = i2`, где одно из `i1', i2'` проходит через
0); прямой подсчёт по одному обходу `a = 0, ..., n-1` даёт `n - di` значений
с `i1' < i2'` (индукция по `a`: при `a=0` верно `i1' = i1 < i2 = i2'`, шаг
подтверждён явным пересчётом `n=5, i1=0, i2=2` в тексте эксперимента). ∎

## 2. Лемма 2 (тождество суммы по всем `n^2` разрезам)

Для любой `pi` из `S_n`:

```
sum_{(a,b) in Z_n^2} noninv(w_{a,b})
  = sum_{i1 < i2} [ n^2 - n(di + dj) + 2 di dj ],
```

где сумма справа — по всем `C(n,2)` парам индексов `i1 < i2` (плоское
сравнение), `di = i2 - i1`, `dj = (pi(i2) - pi(i1)) mod n`.

Доказательство. `noninv(w)` для фиксированного разреза — сумма по парам
индикаторов согласованности. Меняя порядок суммирования (сумма по разрезам
от суммы по парам к сумме по парам от суммы по разрезам) и применяя лемму 1
независимо к `a` (позиции) и `b` (значения, `a` и `b` независимы по
построению): число разрезов, согласующих пару, равно (оба порядка совпадают)
`(n-di)(n-dj) + di dj` — раскрывая, `n^2 - n(di+dj) + 2 di dj`. Суммируя по
всем парам, получаем тождество. ∎ Проверено перебором (`check_C37.py`,
часть A): для всех перестановок при `2 <= n <= 7` левая часть (прямой пересчёт
по всем `n^2` разрезам) совпадает с правой (по формуле).

## 3. Лемма 3 (точное среднее для sigma_n и его вращений)

Пусть `sigma_n(i) = (1-i) mod n`, и пусть `pi = L^k sigma_n` — любое вращение
позиций (`pi(i) = sigma_n((i+k) mod n)`), `k = 0, ..., n-1`. Тогда для каждой
пары индексов `i1 < i2` выполнено `dj = n - di` тождественно (не приближённо),
и

```
(1/n^2) sum_{(a,b)} noninv(w_{a,b}) = (n^2 - 1) / 6
```

точно при всех `n >= 4`, тогда как цель H13-I требует существования разреза с
`noninv >= floor(n^2/4)` (эквивалентная форма C33/C35 §6).

Доказательство. `dj(i1,i2) = (pi(i2) - pi(i1)) mod n`; для `sigma_n`:
`sigma_n(i2) - sigma_n(i1) = (1-i2)-(1-i1) = i1-i2 = -di`, значит
`dj = -di mod n = n - di` (так как `1 <= di <= n-1`). Вращение позиций `L^k`
переставляет пары `(i1,i2) -> (i1-k, i2-k) mod n` и сохраняет `di` (как
разность по модулю `n` — но не как плоскую разность `i2-i1`, если пара
переходит через край; лемма 1 использует именно `di mod n`, симметричную
относительно вращения) и `dj` тождественно, так что тождество `dj = n-di`
(в смысле `mod n`) сохраняется. Подставляя `dj = n - di` (пар по `mod n`,
что не меняет лемму 1 — её доказательство использует только `di mod n`) в
лемму 2: `n^2 - n(di + (n-di)) + 2 di (n-di) = n^2 - n^2 + 2di(n-di)
= 2 di (n - di)`. Сумма по всем `C(n,2)` парам с данным `di` (их `n - di` пар
при каждом `di in {1,...,n-1}`, лемма о подсчёте пар с фиксированной
разностью): `sum_{i1<i2} 2di(n-di) = sum_{k=1}^{n-1} (n-k) * 2k(n-k)`. Деля на
`n^2` и упрощая (проверено `check_C37.py` часть B в точной рациональной
арифметике для `4 <= n <= 200`; совпадает с `(n^2-1)/6` во всех случаях) даёт
заявленное точное среднее. ∎

Разница со целью: `floor(n^2/4) - (n^2-1)/6 = n^2/12 + O(1)` — растёт
квадратично по `n`, а не как `O(n)` (как было отмечено эвристически в
`h13_line_model.md` §1 для одного `n`, без формулы и без доказательства
точности/универсальности по вращениям).

## 4. Следствие (недостаточность усреднения)

Никакая верхняя граница `noninv(some cut) >= floor(n^2/4)`, полученная из
принципа Дирихле применительно к сумме леммы 2 (равномерное или любое
взвешенное среднее по разрезам, зависящее только от `di, dj` попарно
независимо для каждой пары — то есть любой метод вида «оценить каждую пару
отдельно и сложить»), не может работать: для семейства `sigma_n` и его
вращений среднее равно `(n^2-1)/6 < floor(n^2/4)` с зазором `Theta(n^2)`,
тогда как сама цель ДОСТИЖИМА на этом семействе ровно на одном разрезе
(C32/C33: `I(sigma_n) = floor((n-1)^2/4)` точно, полученное явной
конструкцией, не усреднением). Значит доказательство H13-I (если оно верно)
обязано использовать структуру `pi` за пределами попарной суммы `di, dj` —
например экстремальность именно этого одного разреза (двумерный локальный
оптимум, лемма C `h13_line_model.md` §4, недостаточна в исходной форме) или
не-вероятностный (структурный/экстремальный) аргумент.

## 5. Расширенная выборочная проверка H13-I

`experiments/i_bound_sampled.py` (не доказательство, правило 9): 1274
проверки при `n` от 11 до 200 (случайные, аффинные `a*i+b`, sigma_n и все его
вращения `L^k sigma_n`, `rev_n`) — нарушений `I(pi) > floor((n-1)^2/4)` не
найдено; максимум `I(pi) - floor((n-1)^2/4)` среди выборки равен 0 (достигается
точно на sigma_n и его вращениях) при каждом проверенном `n`, у остальных
семейств строго меньше. Отчёт `data/runs/i_bound_sampled/report.md`. Быстрое
`I(pi)` (`O(n^2)` вместо `O(n^4)` в `line_profile.c`: один проход
merge-sort на `inv(w)` при `a` фиксированном плюс `O(n)` инкрементального
пересчёта по `b`) сверено с полным перебором на всех перестановках при
`2 <= n <= 8` (без расхождений).

## 6. Статус H13-I

Не доказана и не опровергнута. Усреднение по `n^2` разрезам как техника
закрыто отрицательно и точно (не эвристически) для семейства `sigma_n`.
H13-I VERIFIED исчерпывающе при `4 <= n <= 10` (C33/C35, из сессии 8);
SAMPLED без нарушений при `n` от 11 до 200 (этот раздел). Кандидаты на
следующую сессию (бюджет 1 сессия): (а) двумерная локальная экстремальность
разреза (оба параметра `a, b` совместно, не по одному, ср. лемму C
`h13_line_model.md` §4, которая опровергнута только для одномерных
условий); (б) прямая структурная индукция H3 (PLAN §4.3, собственный бюджет
2 сессии) как независимый путь к C15 в обход H13-I.
