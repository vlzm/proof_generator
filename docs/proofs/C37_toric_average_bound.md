# C37 — общая оценка `I(pi) <= floor((2n − 1)(n − 1)/6)` усреднением по разрезам

Дата: 16.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py` (PASS: исчерпывающе 4 <= n <= 7,
выборки 8 <= n <= 12, семейства n = 20, 30, 40, 50, 60). Эксперимент:
`experiments/toric_degree.c`, отчёт `data/runs/toric_degree/report.md`.
Доказательство элементарно и не зависит ни от N1, ни от таблиц, ни от ядра
ходов: это утверждение о перестановках, а не о словах.

## Утверждение

Пусть n >= 2 и pi — перестановка Z_n. Для разреза `(q, c)` из Z_n × Z_n линия —
`w_j = (pi(q + 1 + j) − (q + 1 − c)) mod n`, j = 0..n−1, и
`I(pi) = min_{q, c} inv(w)` (`docs/notes/h13_line_model.md` §0). Положим

```text
S(pi) = sum_{x != y} ((y − x) mod n) * ((pi(y) − pi(x)) mod n)
```

(сумма по всем n(n−1) упорядоченным парам различных x, y из Z_n). Тогда

1. **(тождество)** сумма `inv(w)` по всем n^2 разрезам равна
   `n^2 * C(n, 2) − S(pi)`;
2. **(перестановочное неравенство)** `S(pi) >= n^2 (n^2 − 1)/6`, причём
   равенство достигается ровно на отражениях `pi(i) = h − i mod n`;
3. **(оценка)** `I(pi) <= floor(C(n, 2) − S(pi)/n^2) <= floor((2n − 1)(n − 1)/6)`.

Следствие (отрицательное, но точное): усреднение по всем n^2 разрезам не
доказывает H13-I ни при каком n >= 4 и проваливается ровно на отражениях —
то есть ровно на экстремальных входах H13-I. Действительно, для отражений
среднее равно `C(n, 2) − (n^2 − 1)/6`, а `floor((2n − 1)(n − 1)/6) >
floor((n − 1)^2/4)` при всех n >= 4 (разность ~ n^2/12).

## 0. Переобозначение разреза

Положим `a = q + 1`, `b = q + 1 − c` (всё в Z_n). Отображение
`(q, c) -> (a, b)` — биекция Z_n^2 на Z_n^2, и линия записывается как

```text
w_j = (pi(a + j) − b) mod n,   j = 0..n−1.
```

Для элемента x из Z_n обозначим его *индекс позиции* и *значение* в этой линии:

```text
alpha_x = (x − a) mod n,   beta_x = (pi(x) − b) mod n.
```

`x -> alpha_x` и `x -> beta_x` — биекции Z_n на {0, ..., n−1}, и линия — это
перестановка `alpha_x -> beta_x`. Пара {x, y} называется *согласованной*
(неинверсией), если `(alpha_x − alpha_y)` и `(beta_x − beta_y)` одного знака,
и *инверсией* иначе; `inv(w)` — число инверсий, `C(n, 2) − inv(w)` — число
согласованных пар.

Для x != y из Z_n пишем `(x, y]` для дуги `{x + 1, x + 2, ..., y}` из Z_n;
её длина — `(y − x) mod n`.

## 1. Лемма 1 (какой разрез переставляет пару)

Для любых x != y из Z_n: `alpha_x > alpha_y` тогда и только тогда, когда
`a ∈ (x, y]`.

**Доказательство.** Пусть `d = (y − x) mod n`, 1 <= d <= n−1. По определению
`alpha_y ≡ alpha_x + d (mod n)`, а `alpha_x, alpha_y ∈ {0, ..., n−1}`, поэтому
`alpha_y = alpha_x + d`, если `alpha_x + d <= n − 1`, и `alpha_y = alpha_x + d − n`
иначе. Значит `alpha_x > alpha_y` равносильно `alpha_x >= n − d`, то есть
`(x − a) mod n >= n − d`, то есть `(a − x) mod n <= d` и `a != x`, то есть
`a ∈ {x + 1, ..., x + d} = (x, y]`. ∎

Точно так же (применяя лемму 1 к перестановке pi(x), pi(y) и сдвигу b):
`beta_x > beta_y` равносильно `b ∈ (pi(x), pi(y)]`.

## 2. Лемма 2 (тождество для суммы по всем разрезам)

`sum_{(a, b) ∈ Z_n^2} inv(w^{(a,b)}) = n^2 * C(n, 2) − S(pi)`.

**Доказательство.** Обозначим через `NI(a, b) = C(n, 2) − inv(w^{(a,b)})` число
согласованных пар. Пара {x, y} согласована тогда и только тогда, когда либо
(`alpha_x > alpha_y` и `beta_x > beta_y`), либо (`alpha_y > alpha_x` и
`beta_y > beta_x`); эти два случая исключают друг друга. Поэтому

```text
NI(a, b) = #{упорядоченные пары (x, y), x != y :
             alpha_x > alpha_y и beta_x > beta_y},
```

так как каждая согласованная пара учитывается ровно в одном порядке. По лемме 1
условие в правой части равносильно `a ∈ (x, y]` и `b ∈ (pi(x), pi(y)]`. Число
разрезов (a, b), удовлетворяющих ему при фиксированной упорядоченной паре,
равно произведению длин дуг:

```text
|(x, y]| * |(pi(x), pi(y)]| = ((y − x) mod n) * ((pi(y) − pi(x)) mod n).
```

Суммируя по всем (a, b) и меняя порядок суммирования,
`sum_{a, b} NI(a, b) = S(pi)`, откуда
`sum_{a, b} inv = n^2 C(n, 2) − S(pi)`. ∎

Замечание. Здесь `(x, y]` — дуга *от x к y*, и её длина — та самая d, а вторая
дуга — от pi(x) к pi(y); обмен x и y заменяет обе длины на дополнительные,
поэтому упорядоченная сумма — это в точности сумма по парам
`d e + (n − d)(n − e)` «одноимённых квадрантов» из `h13_line_model.md` §6.

## 3. Лемма 3 (перестановочное неравенство для S)

Для всякой перестановки pi: `S(pi) >= n^2 (n^2 − 1)/6`, и равенство выполнено
тогда и только тогда, когда pi — отражение `pi(i) = h − i mod n`.

**Доказательство.** Зафиксируем x. Когда y пробегает Z_n \ {x}, величина
`d(y) = (y − x) mod n` пробегает {1, ..., n−1} биективно; так же и
`e(y) = (pi(y) − pi(x)) mod n` (потому что pi — биекция и `pi(y) != pi(x)`).
Значит внутренняя сумма `T_x = sum_{y != x} d(y) e(y)` — это сумма произведений
двух перестановок одного и того же множества {1, ..., n−1}.

По перестановочному неравенству такая сумма минимальна при противоположном
порядке. Для полноты — обменный аргумент: если для некоторых y, z верно
`d(y) < d(z)` и `e(y) < e(z)`, то перестановка значений e у y и z меняет сумму
на `d(y) e(z) + d(z) e(y) − d(y) e(y) − d(z) e(z) = −(d(z) − d(y))(e(z) − e(y)) < 0`,
то есть строго уменьшает её. Поэтому в точке минимума пары упорядочены
противоположно: большему d отвечает меньшее e. Так как оба набора — это
{1, ..., n−1}, единственное противоположное упорядочение — `e = n − d`, и

```text
T_x >= sum_{k=1}^{n-1} k (n − k) = n * n(n−1)/2 − (n−1)n(2n−1)/6
     = n(n−1)(n+1)/6 = n(n^2 − 1)/6,
```

причём равенство равносильно тому, что `e(y) = n − d(y)` для всех y != x.
Суммируя по всем n значениям x, получаем `S(pi) >= n^2 (n^2 − 1)/6`.

Равенство в сумме требует равенства для каждого x, то есть
`(pi(y) − pi(x)) ≡ −(y − x) (mod n)` для всех x != y, то есть
`pi(y) + y ≡ pi(x) + x (mod n)`; обозначив это общее значение через h, получаем
`pi(i) = h − i mod n`. Обратно, для отражения `e = n − d` при всех парах, и
равенство выполнено. ∎

## 4. Теорема (C37)

Для всякой перестановки pi множества Z_n, n >= 2:

```text
I(pi) <= floor(C(n, 2) − S(pi)/n^2) <= floor((2n − 1)(n − 1)/6).
```

**Доказательство.** Минимум конечного набора не превосходит его среднего,
поэтому по лемме 2

```text
I(pi) = min_{a, b} inv(w^{(a,b)}) <= (1/n^2) sum_{a, b} inv(w^{(a,b)})
      = C(n, 2) − S(pi)/n^2.
```

Левая часть — целое число, поэтому её можно ограничить целой частью правой.
По лемме 3 `S(pi)/n^2 >= (n^2 − 1)/6`, и

```text
C(n, 2) − (n^2 − 1)/6 = (3n(n−1) − (n^2 − 1))/6 = (2n^2 − 3n + 1)/6
                      = (2n − 1)(n − 1)/6.  ∎
```

## 5. Точность и область применимости

1. Оценка леммы 3 точна: на отражениях `S = n^2(n^2 − 1)/6` и среднее по
   разрезам равно ровно `C(n, 2) − (n^2 − 1)/6 ~ n^2/3`. Гипотеза H13-I требует
   `~ n^2/4`. Поэтому **никакое усреднение с равными весами по всем n^2
   разрезам не может дать H13-I**: разрыв — множитель 4/3, и он реализуется
   именно на экстремальных входах H13-I (отражениях). Это уточняет наблюдение
   `h13_line_model.md` §6, где то же считалось только для sigma_n.
2. Оценка C37 слабее H13-I при всех n >= 4:
   `floor((2n − 1)(n − 1)/6)` против `floor((n − 1)^2/4)` — 3 против 2 (n = 4),
   28 против 20 (n = 10), 1170 против 870 (n = 60).
3. Тем не менее это первая *доказанная при всех n* верхняя оценка для `I(pi)`;
   вместе с H13-R (`N_rot <= floor(n^2/4)`, пока CONJECTURED) она дала бы
   `d(pi) <= (2n − 1)(n − 1)/6 + floor(n^2/4) ~ 0.583 n^2`, что хуже `B_n ~ n^2/2`
   и потому для C15 недостаточно. Для C15 нужна именно H13-I.
4. Промежуточная форма (пункт 3 теоремы, с `S(pi)` вместо минимума по pi)
   сильнее и зависит от входа: например, для тождественной перестановки
   `S = n^2 (n−1)(2n−1)/6` и оценка даёт `I <= (n^2 − 1)/6` (истинное значение 0).
   Исчерпывающий подсчёт (`data/runs/toric_degree/report.md`) показывает, что
   пункт 3 доказывает H13-I лишь для 1.2 %, 1.8 %, 0.9 %, 1.7 %, 1.2 %
   перестановок при n = 8, 9, 10, 11, 12: «усреднение + разбор оставшихся случаев» не сводит
   H13-I к малому структурированному семейству.
