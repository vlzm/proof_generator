# C9: d(sigma_n) <= B_n при всех n >= 4 — явное слово конструкции N1

Статус: PROVED при условии C18 (локальный аудит C18 — 12.09.2026,
`docs/notes/strict_proof_audit.md` §2). Машинная сверка: `checks/check_C9.py`,
слова построены и исполнены для 4 <= n <= 80 (`data/runs/strict_audit/check_C9.json`).

Конвенции — PROBLEM.md §3; обозначения N1 — PROBLEM.md §5.2. Ядро oracle-1.0,
конструкция `constructions/strict_upper.py` (strict_upper-1.0).

## Утверждение

Пусть `sigma_n(i) = (1 - i) mod n`, `B_n = n(n-1)/2`, `P = floor(n^2/4)`,
`m = floor(n/2)`. Положим

```text
c* = 0, если n = 0 (mod 4);   c* = 1 иначе.
```

Тогда слово конструкции N1 (§§2–3) для перестановки sigma_n и сдвига c*
имеет длину ровно `2F_{c*} - S_{c*} + H(c*) = B_n`. Следовательно
`d(sigma_n) <= B_n` при всех n >= 4.

Слово не зависит от S2 (C9 ранее опиралось только на источник S2).

## Лемма 1 (строение f_{c*})

`f_c(i) = sigma_n(i) + c = 1 + c - i (mod n)` — отражение окружности позиций.
Все его нетривиальные циклы — транспозиции `{i, 1+c-i}`.

1. n нечётно, c* = 1: `f(i) = 2 - i`. Неподвижная точка одна: `i = 1`
   (уравнение `2i = 2` при нечётном n имеет одно решение). Остальные n - 1
   точек образуют `m = (n-1)/2` транспозиций. Антиподов при нечётном n нет.
2. n = 2m, m чётно, c* = 0: `f(i) = 1 - i`. Неподвижных точек нет
   (`2i = 1` неразрешимо). m транспозиций `{i, 1-i}`; расстояние в паре
   `delta(i, 1-i) = delta(0, 2i-1)` — нечётный вычет, а антипод m чётен,
   значит антиподальных транспозиций нет.
3. n = 2m, m нечётно, c* = 1: `f(i) = 2 - i`. Неподвижные точки `i = 1`
   и `i = 1 + m`. Остальные n - 2 точки — `m - 1` транспозиций `{i, 2-i}`;
   расстояние `delta(0, 2(i-1))` — чётный ненулевой вычет, а антипод m
   нечётен, значит антиподальных транспозиций нет.

Для неантиподальной транспозиции с расстоянием d обе дуги — один и тот же
путь в противоположных направлениях: `F(C) = 2d`, `M(C) = 2`, `t = 1`,
`E(C) = 0`, `S(C) = 3` (N1 §7.1, случай M = 2, E = 0; в PROBLEM §5.3 то же).

## Лемма 2 (закрытые формы)

Обозначим `Odd = sum_{r нечётный, 1<=r<=n-1} delta(0,r)`,
`Even = sum_{r чётный, 2<=r<=n-2} delta(0,r)`; всегда `Odd + Even = P`.

1. n нечётно.
   `F_1 = sum_{i != 1} delta(i, 2-i) = sum_{i != 1} delta(0, 2(i-1))`;
   при i - 1, пробегающем Z_n \ {0}, вычет 2(i-1) пробегает Z_n \ {0}
   (2 обратимо), значит `F_1 = P`. Далее `S_1 = 3m = 3(n-1)/2`,
   `H(1) = n + 1 - 2 = n - 1`.
2. n = 2m, m чётно. `F_0 = sum_i delta(i, 1-i) = sum_i delta(0, 2i-1)`;
   при i, пробегающем Z_n, вычет 2i - 1 пробегает каждый нечётный вычет
   дважды, поэтому `F_0 = 2 Odd`. Нечётные r < m: 1, 3, ..., m-1, сумма
   `(m/2)^2`; по симметрии `Odd = 2 (m/2)^2 = m^2/2`, `F_0 = m^2 = P`.
   `S_0 = 3m`, `H(0) = n = 2m`.
3. n = 2m, m нечётно. `F_1 = sum_{i != 1, 1+m} delta(0, 2(i-1))`; вычет
   2(i-1) пробегает каждый чётный вычет дважды, нулевой — ровно при
   исключённых i, поэтому `F_1 = 2 Even`. Чётные r < m: 2, 4, ..., m-1,
   сумма `((m-1)/2)((m+1)/2) = (m^2-1)/4`; `Even = (m^2-1)/2`,
   `F_1 = m^2 - 1 = P - 1`. `S_1 = 3(m-1)`, `H(1) = n - 1 = 2m - 1`.

## Лемма 3 (длина)

По C18 (N1 (2.6) и §3) слово для сдвига c имеет длину ровно
`2F_c - S_c + H(c)` до свободного сокращения (в реализации длина сырого
слова равна этой величине, `checks/check_C16.py`, режим `--perms`).

1. n нечётно: `2P - 3(n-1)/2 + (n-1) = (n^2-1)/2 - (n-1)/2 = n(n-1)/2`.
2. n = 2m, m чётно: `2m^2 - 3m + 2m = m(2m-1) = n(n-1)/2`.
3. n = 2m, m нечётно: `2(m^2-1) - 3(m-1) + (2m-1) = 2m^2 - m = n(n-1)/2`.

Во всех случаях длина равна B_n, что и требовалось. ∎

## Замечания

- Зависимости: C18 (локальные слова и сшивка N1). Общий аргумент C16/C17
  не нужен: используется только конструкция и прямой подсчёт для sigma_n.
- Расщепление построенных слов: при 4 <= n <= 80 `N_X = floor((n-1)^2/4)`,
  `N_rot = floor(n^2/4)` — совпадает с расщеплением всех геодезических
  до sigma_n (C13v при n <= 12). Общее равенство расщепления не доказано
  и здесь не заявляется; для C9 нужна только длина.
- Для остальных отражений `pi(i) = h - i` минимум по c той же
  конструкции равен B_n при нечётном n и при нечётном h; при n = 0 (mod 4)
  и чётном h — B_n - 1; при n = 2 (mod 4) и чётном h — B_n + 1
  (проверено 4 <= n <= 20, `data/runs/strict_audit/report.md`). Это
  данные о конструкции, а не утверждения о d.
- C9 не даёт C15: для произвольной pi минимум по c превышает B_n уже
  при n = 5 (`check_C16.py --perms`: max_pi min_c len = 11 при n = 5).
