# C37 — тождество двойного разреза: `inv = Fbar − (2/n)·ранговая ковариация`

Дата: 16.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py`. Эксперименты:
`experiments/toric_inv.c`, `experiments/toric_spearman.py`.
Доказательство элементарно и самодостаточно: оно не использует N1, C16–C21,
таблицы расстояний и модель ходов LRX вообще — речь только о числе инверсий
переразмеченной линии (H13-I, `docs/notes/h13_line_model.md`).

Литературная сверка не проводилась: тождество может быть известно (связь
Кендалла и Спирмена на окружности), но доказательство ниже независимо.

## 0. Обозначения

`pi: Z_n -> Z_n` — биекция, n >= 3. Двойной разрез `(q, c)` из
`docs/notes/h13_line_model.md` §0 задаёт линию

```text
w_j = (pi(q + 1 + j) − (q + 1 − c)) mod n,   j = 0 .. n − 1.
```

Положим `a = (q + 1) mod n`, `b = (q + 1 − c) mod n`. Соответствие
`(q, c) <-> (a, b)` — биекция Z_n^2 -> Z_n^2, и

```text
F(a, b) := inv(w) = #{ j1 < j2 : w_{j1} > w_{j2} }.
```

Для позиции k положим

```text
X_k = (k − a) mod n        (индекс k в линии),
Y_k = (pi(k) − b) mod n    (метка элемента, стоящего в позиции k),
```

так что `w_{X_k} = Y_k`. Обе величины при фиксированном разрезе пробегают
`{0, ..., n − 1}` ровно по одному разу. Далее `m = (n − 1)/2` (полуцелое при
чётном n) и

```text
S(a, b) := sum_k (X_k − m)(Y_k − m)        — ранговая ковариация разреза,
I(pi)   := min_{a, b} F(a, b),
Fbar    := (1/n^2) sum_{a, b} F(a, b),
M       := floor((n − 1)^2 / 4).
```

`S` — это `n(n^2 − 1)/12` умноженное на коэффициент Спирмена линии, поэтому
`|S| <= n(n^2 − 1)/12`. Целочисленная форма: `S2(a, b) = 4 S(a, b) =
sum_k s(k − a) s(pi(k) − b)`, где `s(u) = 2 (u mod n) − (n − 1)`.

Для упорядоченной пары `(i, j)`, i != j, пишем `d_{ij} = (j − i) mod n`,
`e_{ij} = (pi(j) − pi(i)) mod n` (оба в `{1, ..., n − 1}`).

H13-I — утверждение `I(pi) <= M` при всех n >= 4 и всех pi.

## 1. Лемма 1 (разности F)

Для всех (a, b):

```text
(а)  F(a + 1, b) − F(a, b) = n − 1 − 2 Y_a,
(б)  F(a, b + 1) − F(a, b) = n − 1 − 2 X_{pi^{-1}(b)}.
```

Доказательство. (а) Линия разреза `(a + 1, b)` получается из линии разреза
`(a, b)` переносом первого элемента `w_0 = Y_a` в конец: действительно,
`w'_j = (pi(a + 1 + j) − b) mod n = w_{j + 1}` при `j < n − 1` и
`w'_{n − 1} = (pi(a + n) − b) mod n = w_0`. Пары, не содержащие перенесённого
элемента, сохраняют порядок. Перенесённый элемент имел метку `Y_a` и стоял
первым, поэтому был в инверсии ровно с элементами меньшей метки, которых
`Y_a`; встав последним, он в инверсии ровно с элементами большей метки,
которых `n − 1 − Y_a`. Разность равна `n − 1 − 2 Y_a`.

(б) При `b -> b + 1` метки меняются как `v -> (v − 1) mod n`: все элементы
с `Y >= 1` уменьшают метку на 1 (их взаимный порядок сохраняется), а
единственный элемент с `Y = 0` — это элемент в позиции `pi^{-1}(b)` — получает
метку `n − 1`. Меняются только пары, содержащие его. Он был наименьшим, то есть
был в инверсии ровно с элементами, стоящими в линии левее, которых `X`, где
`X = X_{pi^{-1}(b)}`; став наибольшим, он в инверсии ровно с элементами правее,
которых `n − 1 − X`. ∎

## 2. Лемма 2 (разности S)

```text
(а)  S(a + 1, b) − S(a, b) = n (Y_a − m),
(б)  S(a, b + 1) − S(a, b) = n (X_{pi^{-1}(b)} − m).
```

Доказательство. (а) При `a -> a + 1` индексы меняются так: `X_k -> X_k − 1`
для всех k с `X_k >= 1`, а элемент с `X_a = 0` получает индекс `n − 1`.
Метки `Y_k` не меняются. Значит

```text
S(a + 1, b) − S(a, b) = sum_{k != a} (−1)(Y_k − m) + (n − 1 − 0)(Y_a − m)
                      = −sum_k (Y_k − m) + (Y_a − m) + (n − 1)(Y_a − m)
                      = n (Y_a − m),
```

так как `sum_k (Y_k − m) = sum_{v = 0}^{n − 1} v − n m = 0`.
(б) симметрично: при `b -> b + 1` метки уменьшаются на 1, кроме элемента
с `Y = 0`, получающего `n − 1`; индексы не меняются. ∎

## 3. Теорема 3 (тождество двойного разреза)

Величина `F(a, b) + (2/n) S(a, b)` не зависит от разреза и равна `Fbar`:

```text
F(a, b) = Fbar − (2/n) sum_k (X_k − m)(Y_k − m)      для всех (a, b).
```

Доказательство. По леммам 1(а) и 2(а)

```text
[F + (2/n) S](a + 1, b) − [F + (2/n) S](a, b)
   = (n − 1 − 2 Y_a) + (2/n) · n (Y_a − m) = n − 1 − 2 Y_a + 2 Y_a − (n − 1) = 0,
```

и точно так же по леммам 1(б), 2(б) разность по b равна нулю. Сдвиги
`a -> a + 1` и `b -> b + 1` связывают все n^2 разрезов, значит функция
постоянна. Её значение равно среднему `Fbar + (2/n)·(1/n^2) sum_{a,b} S(a, b)`,
а

```text
sum_{a, b} S(a, b) = sum_k [ sum_a (X_k(a) − m) ] [ sum_b (Y_k(b) − m) ] = 0,
```

поскольку при фиксированном k величина `X_k(a) = (k − a) mod n` пробегает
все значения `0 .. n − 1` по одному разу (и так же `Y_k(b)`). ∎

Замечание. В целых числах: `2 n^2 F(a, b) + n S2(a, b) = 2 n^2 Fbar` —
см. лемму 4 для правой части.

## 4. Лемма 4 (значение константы)

```text
Fbar = n(n − 1)/2 − (1/n^2) sum_{i != j} d_{ij} e_{ij},
```

то есть `2 n^2 Fbar = n^3 (n − 1) − 2 sum_{i != j} d_{ij} e_{ij}` — целое число.

Доказательство. Для неупорядоченной пары `{i, j}` и разреза (a, b) пара
не инвертирована тогда и только тогда, когда порядки по позиции и по метке
совпадают. Условие `X_i < X_j` равносильно `a ∈ {j + 1, ..., i}` (дуга длины
`n − d_{ij}`), условие `Y_i < Y_j` — `b ∈ {pi(j) + 1, ..., pi(i)}` (дуга длины
`n − e_{ij}`). Поэтому число разрезов, при которых пара не инвертирована,
равно `(n − d)(n − e) + d e`, а число разрезов с инверсией —

```text
n^2 − (n − d)(n − e) − d e = n(d + e) − 2 d e.
```

Это выражение не меняется при замене `(d, e) -> (n − d, n − e)`, то есть
не зависит от выбранного порядка пары. Суммируя по неупорядоченным парам
(каждая учитывается дважды в сумме по упорядоченным парам):

```text
sum_{a, b} F(a, b) = (1/2) sum_{i != j} [ n(d + e) − 2 d e ].
```

При фиксированном i величина `d_{ij}` пробегает `1 .. n − 1`, поэтому
`sum_{i != j} d_{ij} = n·n(n − 1)/2`, и то же для `e`. Значит

```text
sum_{a, b} F(a, b) = n^3 (n − 1)/2 − sum_{i != j} d_{ij} e_{ij}. ∎
```

## 5. Следствие 5 (равносильная форма H13-I)

```text
I(pi) = Fbar − (2/n) max_{a, b} S(a, b),
```

и, значит, H13-I равносильно неравенству

```text
max_{a, b} S(a, b) >= (n/2) (Fbar − M).
```

То есть: у каждой pi есть разрез, ранговая ковариация (коэффициент Спирмена)
которого не меньше явного порога. Минимизация инверсий по торическому классу
и максимизация ранговой корреляции по классу — одна и та же задача. ∎

## 6. Лемма 6 (сумма по разрезам в точках)

Пусть `R := sum_k S(k, pi(k))` — сумма ранговых ковариаций по n «точечным»
разрезам (разрез в точке графика pi). Тогда

```text
R = n^2 [ (n^2 − 1)/4 − Fbar ].
```

Доказательство. При `(a, b) = (k, pi(k))` имеем `X_l = (l − k) mod n = d_{kl}`
и `Y_l = (pi(l) − pi(k)) mod n = e_{kl}` (при `l = k` обе величины равны 0).
Поэтому

```text
R = sum_{k, l} (d_{kl} − m)(e_{kl} − m) = sum_{k != l} (d − m)(e − m) + n m^2.
```

Раскрывая и пользуясь `sum_{k != l} d = sum_{k != l} e = n^2 (n − 1)/2`
и леммой 4 (`sum_{k != l} d e = n^2 [ n(n − 1)/2 − Fbar ]`):

```text
R = n^2 [n(n − 1)/2 − Fbar] − m·n^2 (n − 1) + m^2 n(n − 1) + n m^2
  = n^2 [n(n − 1)/2 − Fbar] − n^2 (n − 1)^2/2 + n^2 m^2          (m^2 n(n−1) + n m^2 = n^2 m^2)
  = n^2 [ n(n − 1)/2 − (n − 1)^2/2 + (n − 1)^2/4 − Fbar ]
  = n^2 [ n(n − 1)/2 − (n − 1)^2/4 − Fbar ]
  = n^2 [ (n^2 − 1)/4 − Fbar ]. ∎
```

## 7. Следствие 7 (критерий по среднему в точках)

```text
I(pi) <= (1/n) sum_k F(k, pi(k)) = 3 Fbar − (n^2 − 1)/2.
```

В частности, **H13-I верна для всякой pi с `Fbar <= (M + (n^2 − 1)/2)/3`**.

Доказательство. Минимум по всем разрезам не больше среднего по n точечным
разрезам; по теореме 3 и лемме 6

```text
(1/n) sum_k F(k, pi(k)) = Fbar − (2/n^2) R = Fbar − 2[(n^2 − 1)/4 − Fbar]
                        = 3 Fbar − (n^2 − 1)/2. ∎
```

## 8. Следствие 8 (комбинаторный смысл Fbar: тройки)

Для трёх различных `x, y, z` из Z_n положим `o(x, y, z) = +1`, если, двигаясь
от x в сторону возрастания, мы встречаем y раньше z, и `−1` иначе; полагаем
также `o(x, x, z) = +1`, `o(x, y, x) = −1`. Функция `o` инвариантна при
циклической перестановке аргументов и меняет знак при транспозиции. Для
тройки различных позиций `T = {i, j, k}` положим

```text
eps(T) = o(i, j, k) · o(pi(i), pi(j), pi(k))
```

(корректно определено: транспозиция меняет знак обоих множителей), и пусть
`E(pi) = sum_T eps(T)` — разность числа «циклически согласованных» и
«циклически несогласованных» троек, `|E| <= C(n, 3)`. Тогда

```text
Fbar = n(n − 1)/4 − E(pi) / (2n),
```

и критерий следствия 7 принимает вид

```text
I(pi) <= (n − 1)(n − 2)/4 − 3 E(pi) / (2n),
```

так что H13-I верна для всякой pi с `E(pi) >= −n(n − 2)/6` (чётное n) и
с `E(pi) >= −n(n − 1)/6` (нечётное n).

Доказательство. Пара `{i, j}` не инвертирована при разрезе (a, b) тогда и
только тогда, когда `o(a, i, j) · o(b, pi(i), pi(j)) = +1` (при `a = i` первый
множитель равен +1, что согласовано с `X_i = 0 < X_j`; аналогично при `a = j`).
Положим `T(a, b) = #неинверсий − #инверсий = n(n − 1)/2 − 2 F(a, b)`. Тогда

```text
T(k, pi(k)) = sum_{пары {i, j}} o(k, i, j) o(pi(k), pi(i), pi(j)).
```

Пары, содержащие k, дают `+1` каждая (их `n − 1`); пара `{i, j}` с `i, j != k`
даёт `eps({i, j, k})`. Суммируя по k, каждая тройка учитывается трижды:

```text
sum_k T(k, pi(k)) = n(n − 1) + 3 E(pi).
```

С другой стороны, по следствию 7

```text
sum_k T(k, pi(k)) = n·n(n − 1)/2 − 2 sum_k F(k, pi(k))
                  = n^2 (n − 1)/2 − 2n[3 Fbar − (n^2 − 1)/2].
```

Приравнивая и решая относительно Fbar, получаем
`Fbar = n(n − 1)/4 − E/(2n)`. Подстановка в следствие 7 даёт
`I(pi) <= 3n(n − 1)/4 − 3E/(2n) − (n^2 − 1)/2 = (n − 1)(n − 2)/4 − 3E/(2n)`.
Сравнение с `M` даёт указанные пороги (при чётном n
`(n − 1)(n − 2)/4 − M = (2 − n)/4`, при нечётном `−(n − 1)/4`). ∎

Проверка на краях: у тождественной перестановки все тройки согласованы,
`E = C(n, 3)`, критерий даёт `I <= 0` — точное значение. У отражения
`pi(i) = h − i` все тройки несогласованы, `E = −C(n, 3)`, критерий даёт
`I <= (n − 1)(n − 2)/2`, что при n >= 5 слабее M: **на отражениях критерий
не работает**, и именно они — экстремальные входы H13-I.

## 9. Следствие 9 (критерий по сдвинутым точечным разрезам)

Пусть `Delta` — мультимножество из n^2 векторов разностей
`(u, v) = (k − l, pi(k) − pi(l))`, `k, l ∈ Z_n` (автокорреляция графика pi),
и `sig(u) = (u mod n) − m`. Тогда для любых (s, t)

```text
I(pi) <= (1/n) sum_k F(k + s, pi(k) + t)
       = Fbar − (2/n^2) sum_{(u, v) ∈ Delta} sig(u − s) sig(v − t).
```

При `(s, t) = (0, 0)` это следствие 7. Критерий зависит только от `Delta`.

Доказательство. Минимум не больше среднего по n разрезам
`(k + s, pi(k) + t)`; по теореме 3 это среднее равно
`Fbar − (2/n^2) sum_k S(k + s, pi(k) + t)`, а

```text
sum_k S(k + s, pi(k) + t) = sum_{k, l} sig(l − k − s) sig(pi(l) − pi(k) − t)
                          = sum_{(u, v) ∈ Delta} sig(u − s) sig(v − t). ∎
```

## 10. Что тождество даёт и чего не даёт

Даёт:

1. Точную формулу `I(pi) = Fbar − (2/n) max S` и равносильность H13-I
   максимизации ранговой корреляции (следствие 5). Все величины —
   торические инварианты; `Fbar` имеет замкнутый вид (лемма 4) и
   комбинаторный смысл через тройки (следствие 8).
2. Доказанные достаточные критерии (следствия 7 и 9), покрывающие
   большинство классов (см. C38): при 4 <= n <= 10 критерий следствия 7
   закрывает 75–84 % представителей торических классов, критерий
   следствия 9 — 79–100 % (при n >= 8 — не менее 97 %).
3. Объяснение, почему усреднение по всем n^2 разрезам не работает:
   среднее равно `Fbar`, а `Fbar − M` растёт как `~n^2/12` на отражениях
   (`Fbar = (n^2 − n)/4 + (n − 1)(n − 2)/12`).

Не даёт: оставшиеся классы — с сильно отрицательным `E` (много циклически
несогласованных троек). На отражениях неравенство следствия 5 точное:
`max S = n^3/24 + O(n)`, порог `(n/2)(Fbar − M) = n^3/24 + O(n)`, — поэтому
никакой оценки «с запасом» тут быть не может, и второй момент не спасает:
среднеквадратичное `S` по разрезам на отражениях равно
`n^3/sqrt(180) ≈ 0.0745 n^3`, а требуется максимум `>= n^3/12 ≈ 0.0833 n^3`.
Любое доказательство H13-I должно быть точным в экстремальной точке.
