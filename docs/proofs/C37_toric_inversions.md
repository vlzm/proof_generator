# C37–C40 — торические инверсии: словарь, релаксация, безусловная оценка

Дата: 14.09.2026 (сессия 9). Предмет — чисто комбинаторная часть H13:

> **H13-I.** Для всех n >= 4 и всех pi из S_n: `I(pi) <= floor((n − 1)^2/4)`,
> где `I(pi)` — минимум числа инверсий переразмеченной линии по всем n^2
> двойным разрезам (эквивалентно — по торическому классу pi).

Ниже доказаны четыре утверждения (C37 — словарь, C38 — релаксация,
C39 — безусловная оценка, C40 — тождество двух разрезов). Сама H13-I
**не доказана**; что именно осталось — §7 и `docs/notes/h13i_verdict.md`.
Проверка всех формул и примеров — `checks/check_C37.py`.

## 0. Обозначения

`pi` — перестановка Z_n. Двойной разрез `(q, c)`: ребро позиций {q, q+1}
и сдвиг c; линия `w_j = pi(q + 1 + j) − (q + 1 − c) mod n`, j = 0..n−1
(`experiments/line_model.py`, `experiments/line_profile.c`). Положим

    alpha = q + 1        (начало позиций),
    beta  = q + 1 − c    (начало значений),

тогда `w_j = pi(alpha + j) − beta mod n`, и при пробеге (q, c) по Z_n × Z_n
пара (alpha, beta) пробегает Z_n × Z_n биективно. Пишем `inv(alpha, beta)`
для числа инверсий этой линии и

    I(pi) = min_{alpha, beta} inv(alpha, beta).

Точки: `a = (x_a, y_a)`, где `y_a = pi(x_a)`; их n штук, все x и все y различны.
Пару {a, b} зовём **согласованной** (concordant) при разрезе o = (alpha, beta),
если в линии её элементы идут в одном порядке по позиции и по значению, и
**рассогласованной** (discordant) иначе; `inv(o)` — число рассогласованных пар,
`conc(o) = C(n,2) − inv(o)`.

Дуги на окружности Z_n пишем полуинтервалами: `(u, v] = {u+1, ..., v}` (по
возрастанию с переносом), `[u, v) = {u, ..., v−1}`; `|(u, v]| = (v − u) mod n`.

Всюду `M_n := floor((n − 1)^2/4)`, `B_n = floor(n^2/4) + floor((n−1)^2/4)`.

## 1. C37. Словарь: разрез = квадрантная раскраска

**Лемма 1.1 (области пары).** Для различных точек a, b и разреза
o = (alpha, beta):

- a стоит в линии позже b тогда и только тогда, когда `alpha ∈ (x_a, x_b]`;
- значение a больше значения b тогда и только тогда, когда `beta ∈ (y_a, y_b]`.

*Доказательство.* Позиция a в линии равна `j_a = (x_a − alpha) mod n`, позиция
b — `j_b = (x_b − alpha) mod n`. Пусть `p = (x_b − x_a) mod n ∈ {1, ..., n−1}`.
Тогда `j_b − j_a ≡ p (mod n)` и `|j_b − j_a| < n`, значит либо `j_b − j_a = p`
(тогда a раньше b), либо `j_b − j_a = p − n` (тогда a позже b). Второй случай
равносилен `j_a >= n − p`, т. е. `(x_a − alpha) mod n >= n − p`, т. е.
`alpha ∈ {x_a + p, x_a + p − 1, ..., x_a + 1} = (x_a, x_b]`. Для значений — то
же рассуждение с `w`. ∎

**Следствие 1.2 (два «одноимённых» ящика).** Пара {a, b} согласована при o
тогда и только тогда, когда

    o ∈ ((x_a, x_b] × (y_a, y_b])  ∪  ((x_b, x_a] × (y_b, y_a]),

и рассогласована тогда и только тогда, когда o лежит в одном из двух
«разноимённых» ящиков `(x_a, x_b] × (y_b, y_a]`, `(x_b, x_a] × (y_a, y_b]`.
Площади четырёх ящиков равны `p v`, `(n−p)(n−v)`, `p(n−v)`, `(n−p)v`, где
`p = (x_b − x_a) mod n`, `v = (y_b − y_a) mod n`; их сумма равна n^2.

*Доказательство.* Пара согласована, если оба порядка совпадают: либо a позже b
и значение a больше (первый ящик по лемме 1.1), либо оба условия ложны (второй
ящик). ∎

Это — точная форма «одноимённых квадрантов» из `h13_line_model.md` §6
(в заметке она была сформулирована неточно: квадранты определяются парой
точек, а не одной выделенной диагональю).

**Теорема 1.3 (разрез = квадрантная раскраска).** Зафиксируем базовый разрез
(0, 0). Пусть `E` — множество пар, инвертированных при нём (граф инверсий pi
на n вершинах-точках), `S_alpha = {a : x_a < alpha}`, `T_beta = {a : y_a < beta}`,
`U(alpha, beta) = S_alpha Δ T_beta` и `cut(U)` — множество пар, разделённых
разбиением (U, U^c). Тогда для всех alpha, beta из {0, ..., n−1}

    inv(alpha, beta) = | E Δ cut(U(alpha, beta)) |.                       (1.3)

Эквивалентно, в знаковой записи: положим `eps_ab = +1`, если пара {a, b}
инвертирована при базовом разрезе, и `−1` иначе;
`chi_a(alpha, beta) = sgn(x_a − alpha) · sgn(y_a − beta) ∈ {±1}`. Тогда

    R(o) := inv(o) − conc(o) = sum_{a<b} eps_ab · chi_a(o) · chi_b(o),      (1.4)
    inv(o) = ( C(n,2) + R(o) ) / 2.

*Доказательство.* По лемме 1.1 при сдвиге начала позиций с 0 на alpha порядок
пары {a, b} по позиции меняется на противоположный ровно тогда, когда
`alpha ∈ (x_a, x_b]` при `x_a < x_b`, т. е. ровно когда `x_a < alpha <= x_b`,
т. е. когда пара разделена разбиением `(S_alpha, S_alpha^c)`. Аналогично
порядок по значению меняется ровно для пар, разделённых `(T_beta, T_beta^c)`.
Инвертированность пары меняется при смене ровно одного из двух порядков,
поэтому множество инвертированных пар при разрезе (alpha, beta) равно
`E Δ cut(S_alpha) Δ cut(T_beta)`. Далее `cut(S) Δ cut(T) = cut(S Δ T)`:
пара {a, b} разделена разбиением по `S Δ T` ровно когда
`[a ∈ S] ⊕ [a ∈ T] ⊕ [b ∈ S] ⊕ [b ∈ T] = 1`, а это то же самое, что
`([a ∈ S] ⊕ [b ∈ S]) ⊕ ([a ∈ T] ⊕ [b ∈ T]) = 1`, т. е. пара разделена ровно
одним из двух разбиений. Отсюда (1.3).

Для (1.4): `chi_a = +1` ровно когда a лежит либо в `S_alpha ∩ T_beta`, либо вне
обоих, т. е. `chi_a = −1` ровно когда `a ∈ U`. Пара {a, b} даёт вклад
`eps_ab chi_a chi_b = +1` ровно когда она инвертирована при (alpha, beta):
если `eps_ab = +1` (инверсия при базе), она остаётся инверсией, когда a и b
по одну сторону от U (`chi_a chi_b = +1`), и перестаёт быть ею иначе. ∎

**Следствие 1.4 (эквивалентная форма H13-I).** H13-I равносильна утверждению

    для каждой pi найдётся разрез o с  conc(o) − inv(o) >= floor(n/2).    (1.5)

*Доказательство.* `inv <= M_n` ⟺ `R = 2 inv − C(n,2) <= 2 M_n − C(n,2)`.
При чётном n `2M_n − C(n,2) = n(n−2)/2 − n(n−1)/2 = −n/2`; при нечётном
`(n−1)^2/2 − n(n−1)/2 = −(n−1)/2`. Оба равны `−floor(n/2)`. ∎

**Следствие 1.5.** Доступные раскраски — ровно квадрантные: цвет точки a при
разрезе (alpha, beta) равен `sgn(x_a − alpha)·sgn(y_a − beta)`, т. е. точки
делятся на лежащие в «одноимённых» (нижний левый и верхний правый) и
«разноимённых» квадрантах базового квадрата с углом (alpha, beta). Всего
n^2 раскрасок из 2^(n−1) разбиений.

**Лемма 1.6 (замкнутая формула).** Пусть `F(alpha) = sum_{x < alpha} pi(x)`,
`G(beta) = sum_{y < beta} pi^{-1}(y)`, `N(alpha, beta) = #{x < alpha : pi(x) < beta}`.
Тогда для всех целых `0 <= alpha, beta <= n − 1`

    inv(alpha, beta) = inv(0,0) + (n−1)(alpha + beta) + 2 alpha beta
                       − 2 F(alpha) − 2 G(beta) − 2n N(alpha, beta).      (1.6)

*Доказательство.* Одношаговые приращения: при `alpha -> alpha + 1` первый
элемент линии (со значением `u = (pi(alpha) − beta) mod n`) уходит в конец,
теряя u инверсий с меньшими значениями и приобретая `n − 1 − u` с большими,
так что `inv(alpha+1, beta) − inv(alpha, beta) = n − 1 − 2u`. Симметрично
при `beta -> beta + 1` наименьшее значение становится наибольшим и
`inv(alpha, beta+1) − inv(alpha, beta) = n − 1 − 2t`, где t — позиция в линии
элемента со значением beta. Складывая приращения сначала по beta при alpha = 0
(там `t = pi^{-1}(y)`), затем по alpha при фиксированном beta (там
`u = (pi(x) − beta) mod n = pi(x) − beta + n[pi(x) < beta]`), получаем (1.6). ∎

**Следствие 1.7 (смешанная вторая разность и тождество прямоугольника).**
Для `0 <= alpha, beta <= n − 2`

    inv(a+1,b+1) − inv(a+1,b) − inv(a,b+1) + inv(a,b) = 2 − 2n·[pi(a) = b],

и для любого прямоугольника `[a1, a2) × [b1, b2)` внутри базового квадрата

    inv(a1,b1) + inv(a2,b2) − inv(a1,b2) − inv(a2,b1)
        = 2 (a2 − a1)(b2 − b1) − 2n · K,                                  (1.7)

где K — число точек pi в этом прямоугольнике. В частности, при смещении
разреза на (k, l) (базу всегда можно перенести в текущий разрез)

    inv(o + (k,l)) − inv(o) = Δ_alpha(k) + Δ_beta(l) + 2kl − 2n K(k,l),   (1.8)

где `Δ_alpha(k) = sum_{j<k}(n − 1 − 2 w_j)`, `Δ_beta(l) = sum_{y<l}(n − 1 − 2 t_y)`
по линии w текущего разреза, `K(k, l) = #{j < k : w_j < l}`. Условия
`Δ >= 0` при всех (k, l) — это в точности условие глобальной оптимальности
разреза (усиление леммы C заметки `h13_line_model.md`, где рассматривались
только `l = 0` и `k = 0`).

## 2. C38. Релаксация: произвольные раскраски (PROVED)

**Теорема 2.1.** Пусть `eps` — произвольная симметричная функция на парах
{1..n} со значениями ±1. Тогда

    min_{x ∈ {±1}^n} sum_{a<b} eps_ab x_a x_b  <=  −floor(n/2).

*Доказательство.* Занумеруем вершины 1..n в произвольном порядке. Положим
`x_1 = +1`; при k >= 2, зная `x_1, ..., x_{k−1}`, положим
`s_k = sum_{b<k} eps_{bk} x_b` и выберем `x_k = −sgn(s_k)` (при `s_k = 0` —
любой знак). Тогда

    sum_{a<b} eps_ab x_a x_b = sum_{k=2}^n x_k s_k = − sum_{k=2}^n |s_k|.

Величина `s_k` — сумма k − 1 слагаемых ±1, поэтому `s_k ≡ k − 1 (mod 2)`; при
чётном k число `s_k` нечётно и `|s_k| >= 1`. Чётных k в {2, ..., n} ровно
floor(n/2). ∎

**Следствие 2.2 (графовая форма).** Всякий граф G на n вершинах превращается
в полный двудольный граф (одна доля может быть пуста) не более чем
`M_n = floor((n−1)^2/4)` заменами рёбер: `min_{U ⊆ V} |E(G) Δ cut(U)| <= M_n`.
Оценка точна: для `G = K_n` минимум равен `C(n,2) − max_k k(n−k) = M_n`.

*Доказательство.* По (1.4)-подобной записи `|E Δ cut(U)| = (C(n,2) + sum eps x x)/2`
с `eps_ab = +1` для рёбер и `−1` для не-рёбер; подставляем теорему 2.1 и
считаем, как в следствии 1.4. Для K_n: `|E Δ cut(U)| = C(n,2) − |cut(U)|`. ∎

**Следствие 2.3 (релаксация H13-I).** Если в H13-I разрешить произвольные
раскраски точек (все 2^(n−1) разбиений вместо n^2 квадрантных), утверждение
верно при всех n с той же константой, и константа точна: она достигается на
`pi(i) = n − 1 − i` (граф инверсий = K_n). Кроме того

    M_n = floor((n−1)^2/4) = sum_{m=0}^{n−1} floor(m/2),

т. е. константа H13-I — это в точности цена жадного добавления вершин по одной
с чётностным выигрышем 1 на каждом шаге чётной длины.

*Замечание 2.4 (что это даёт и чего не даёт).* Вся трудность H13-I — в
ограничении на квадрантные раскраски, а не в величине константы: никакой
аргумент, не использующий это ограничение, не даст оценки лучше M_n.
Разрыв между задачей и релаксацией реален: при n = 8 у аффинного входа
`(0,5,2,7,4,1,6,3)` `I = 11`, а минимум по всем разбиениям равен 8 (разрыв 3);
при n = 9 разрыв до 2 (`(0,1,6,3,8,5,2,7,4)`); тем не менее максимум по pi
у обеих величин совпадает и равен M_n при 4 <= n <= 9 (`toric_inversions.c`,
режим `free`).

## 3. C39. Безусловная оценка I(pi) через усреднение (PROVED)

**Лемма 3.1.** `sum_{alpha, beta} conc(alpha, beta) = T(pi)`, где

    T(pi) = sum_{a ≠ b, упорядоченные} p_ab · v_ab,
    p_ab = (x_b − x_a) mod n,  v_ab = (y_b − y_a) mod n.

*Доказательство.* По следствию 1.2 множество разрезов, при которых пара {a, b}
согласована, — объединение двух непересекающихся ящиков площадей `p_ab v_ab` и
`p_ba v_ba`. Суммируя по неупорядоченным парам, получаем сумму по
упорядоченным. ∎

**Лемма 3.2.** `T(pi) >= n^2 (n^2 − 1)/6`, причём равенство достигается тогда и
только тогда, когда pi — отражение `pi(i) = h − i mod n`.

*Доказательство.* Зафиксируем точку a. Отображение `b -> p_ab` — биекция
множества остальных точек на {1, ..., n−1}; отображение `b -> v_ab` — тоже
биекция на {1, ..., n−1} (обе — из-за биективности pi). Значит существует
перестановка `rho_a` множества {1, ..., n−1} с `v_ab = rho_a(p_ab)`, а именно
`rho_a(p) = (pi(x_a + p) − pi(x_a)) mod n`, и

    T(pi) = sum_a sum_{p=1}^{n−1} p · rho_a(p).

По неравенству о перестановках (rearrangement inequality) для любой
перестановки rho множества {1, ..., n−1}

    sum_p p·rho(p) >= sum_p p (n − p) = n(n^2 − 1)/6,

с равенством тогда и только тогда, когда `rho(p) = n − p` при всех p (обратный
порядок — единственный минимизатор, так как последовательность p строго
возрастает). Суммируя по n точкам, получаем `T >= n^2(n^2−1)/6`. Равенство
означает `v_ab = n − p_ab` для всех a, b, т. е. `y_b − y_a ≡ −(x_b − x_a)`, т. е.
`x + y ≡ const` — отражение. ∎

**Теорема 3.3 (первая безусловная оценка I).** Для всех n >= 2 и всех pi

    I(pi) <= floor( C(n,2) − T(pi)/n^2 ) <= floor( (n−1)(2n−1)/6 ).

*Доказательство.* Минимум не больше среднего:
`I(pi) <= (1/n^2) sum_{o} inv(o) = C(n,2) − T(pi)/n^2` по лемме 3.1; левая часть
целая. Подстановка леммы 3.2 и тождество
`C(n,2) − (n^2 − 1)/6 = (2n^2 − 3n + 1)/6 = (2n−1)(n−1)/6` дают вторую оценку. ∎

Значения `floor((n−1)(2n−1)/6)`: 3, 6, 9, 13, 17, 22, 28 при n = 4..10 против
истинного максимума M_n = 2, 4, 6, 9, 12, 16, 20. Асимптотика оценки — `n^2/3`
против гипотетических `n^2/4`.

**Замечание 3.4 (почему усреднение не доводит до M_n — и не только на
отражениях).** Усреднение даёт M_n лишь при `T >= n^2 floor(n^2/4)`. Для
отражений `T = n^2(n^2−1)/6` — минимум, что даёт `n^2/3`. Но и для типичной
перестановки усреднения не хватает: при равномерно случайной pi
`E[v_ab] = n/2` независимо от `p_ab`, поэтому

    E[T] = (n/2) · sum_{a≠b} p_ab = (n/2) · n·C(n,2) = n^3 (n−1)/4,

и средняя по разрезам оценка равна `C(n,2) − E[T]/n^2 = n(n−1)/4`, что ровно на
`n/4` больше цели `floor((n−1)^2/4) = (n^2−2n)/4` (n чётно). То есть разрыв
усреднения имеет порядок n для *всех* типов входов, а не только для
экстремальных: любое доказательство H13-I обязано использовать разброс
inv по разрезам (или отбор разреза), а не только среднее.

**Замечание 3.5 (количественная форма).** Из доказательства леммы 3.2:
`T(pi) = n^2(n^2−1)/6 + sum_a D_a`, где
`D_a = sum_p p (rho_a(p) − (n − p)) >= 0` — мера удалённости pi от отражения,
видимая из точки a. Отсюда `I(pi) <= C(n,2) − (n^2−1)/6 − (sum_a D_a)/n^2`:
чем дальше pi от отражения, тем сильнее оценка. Чтобы достичь `n^2/4`, нужно
`sum_a D_a >= n^4/12 + Θ(n^3)`, а у случайной pi `sum_a D_a ≈ n^4/12` — то же
пограничное положение, что в замечании 3.4.

## 4. C40. Тождество двух разрезов (PROVED)

Пусть даны два разреза `o = (alpha, beta)` и `o' = (alpha', beta')` с
`alpha ≠ alpha'`, `beta ≠ beta'`. Дуги позиций `P_1 = [alpha, alpha')`,
`P_2 = [alpha', alpha)`; дуги значений `V_1 = [beta, beta')`,
`V_2 = [beta', beta)`. Четыре ящика `X_ij = P_i × V_j` с числами точек
`A = |X_11|`, `B = |X_22|`, `C = |X_12|`, `D = |X_21|`, `A+B+C+D = n`.

**Теорема 4.1.** Для любых таких o, o'

    inv(o) + inv(o') = 2 · sum_{i,j} inv(X_ij) + 2 C D + (A + B)(C + D),   (4.1)

где `inv(X)` — число рассогласованных пар с обеими точками в ящике X (оно
одинаково при o и при o').

*Доказательство.* Разберём пары.

(i) Обе точки в одном ящике. Внутри дуги `P_1` линейный порядок по позиции
один и тот же при o (это начальный отрезок линии) и при o' (конечный отрезок);
то же для `P_2`, `V_1`, `V_2`. Значит согласованность такой пары одинакова при
o и o': вклад `2 inv(X_ij)`.

(ii) `a ∈ X_11`, `b ∈ X_22`. При o: a в первой полосе позиций, b во второй,
значит a раньше b; a в первой полосе значений, b во второй, значит значение a
меньше — пара согласована. При o' обе полосы меняются местами одновременно,
поэтому пара снова согласована. Вклад 0.

(iii) `a ∈ X_12`, `b ∈ X_21`. При o: a раньше b по позиции, но значение a
больше — рассогласована; при o' оба порядка меняются — снова рассогласована.
Вклад `2CD`.

(iv) Пары из разных ящиков, делящих одну полосу: `(X_11, X_12)` и
`(X_21, X_22)` делят полосу позиций, `(X_11, X_21)` и `(X_12, X_22)` — полосу
значений. У такой пары один из двух порядков одинаков при o и o' (по п. (i)
внутри общей полосы), а другой при переходе от o к o' меняется на
противоположный (точка «нижней» полосы становится точкой «верхней»). Значит
пара рассогласована ровно при одном из двух разрезов: вклад 1 с каждой пары,
всего `AC + BD + AD + BC = (A+B)(C+D)`.

Сложение даёт (4.1). ∎

**Следствие 4.2.** `min(inv(o), inv(o')) <= sum inv(X_ij) + CD + (A+B)(C+D)/2`.
В частности, если найдутся два разреза с пустыми «разноимёнными» ящиками
(`C = D = 0`) и `| A − B | <= 1`, то

    I(pi) <= inv(o) = inv(X_11) + inv(X_22) <= C(A,2) + C(B,2) = M_n,

т. е. H13-I верна для такой pi.

**Следствие 4.3 (отражения и не только).** Для отражения `pi_h(i) = h − i`
возьмём `P_1` — любую дугу позиций длины `k = floor(n/2)` и `V_1 = h − P_1`;
тогда `C = D = 0`, `A = k`, `B = n − k`, и следствие 4.2 даёт
`I(pi_h) <= C(k,2) + C(n−k,2) = M_n` при всех n >= 4 — независимое (и гораздо
более короткое, чем через слова) доказательство верхней оценки для
экстремального семейства. Тот же аргумент покрывает тождественную
перестановку и вообще любую pi, чьё множество точек лежит в объединении двух
«противоположных» ящиков со сбалансированными размерами.

*Ограничение.* Условие `C = D = 0` — сильное: уже у аффинных
`pi(i) = a i + b` с `a ≠ ±1` любые два разреза оставляют `C + D = Θ(n)` точек,
а «потеря» в следствии 4.2 относительно M_n равна `(C+D)^2/4` при
худшем (тривиальном) способе оценить `inv(X_ij) <= C(|X_ij|, 2)`.

## 5. Что опровергнуто (кандидаты на доказательство H13-I)

Все примеры проверены в `checks/check_C37.py`; первые три — новые (сессия 9),
последние два — из `h13_line_model.md` §1.7, §4.

1. **«Для всякого alpha найдётся beta»** (усиление, которое позволило бы
   индукцию по одному элементу с выбором стороны): ложно.
   `max_alpha min_beta inv` равен 10 при n = 7 (например
   `pi = (0,1,6,5,4,3,2)`) и 13 при n = 8 при M_7 = 9, M_8 = 12.
   Двойственная форма (`max_beta min_alpha`) — те же числа.
2. **Семейства из n разрезов вида `(t + h, pi(t) + k)`** (сдвиг разреза
   относительно точки данных на фиксированный вектор (h, k)): ни при каком
   (h, k) не годится. Даже у наилучшего (h, k) величина `max_pi min_t inv`
   равна 5, 7, 11, 16 при n = 5..8 против M_n = 4, 6, 9, 12 (перебор всех
   n^2 векторов (h, k) и всех pi).
3. **Локальные условия глубины 1.** Пусть линия w удовлетворяет (1.8) с
   `Δ(k, l) >= 0` при всех (k, l) с `min(k, l) <= 1` (это условия леммы C
   заметки плюс совместные сдвиги на 1). При 5 <= n <= 9 отсюда следует
   `inv(w) <= M_n`, но при n = 10 — нет: линия `(0,1,8,7,6,5,4,3,2,9)`
   удовлетворяет всем им и имеет `inv = 21 > 20 = M_10`. Условия глубины 2
   достаточны при 5 <= n <= 10, но нет оснований считать, что нужная глубина
   ограничена.
4. **Усреднение по всем n^2 разрезам** — замечания 3.4, 3.5 (разрыв Θ(n) даже
   для случайной pi).
5. **Индукция по одному элементу** (удаление точки с контракцией): при n = 8
   у `(0,5,2,7,4,1,6,3)` `I = 11`, у всех восьми редукций `I = 6`, а шаг
   индукции требует не более `M_8 − M_7 = 3`. Причина в терминах §1: после
   удаления точки сторона этой точки в квадрантной раскраске *вынуждена*
   (свобода есть только когда разрез стоит ровно в позиции или ровно в
   значении удалённой точки).

## 6. Конечные данные (сессия 9)

`experiments/toric_inversions.c` (toric_inv-1.0), отчёт
`data/runs/h13i_toric/report.md`:

- исчерпывающе `max_pi I = M_n` при 4 <= n <= 9 (аргмаксимумы — ровно n
  отражений); при n = 10 — из `data/runs/line_profile/` (сессия 8);
- подъём по транспозициям (400 рестартов) при 11 <= n <= 26: максимум найден
  равным `M_n` при n <= 16 (на отражениях), превышений нет ни разу;
- все аффинные `pi(i) = a i + b` при n <= 36: максимум ровно `M_n` (на a = n−1);
- окрестность экстремума: все отражения с одной и с двумя транспозициями

  одна транспозиция всегда даёт ровно `M_n − 1`.

## 7. Статус

PROVED (локальный аудит одной сессии, один автор): теоремы 1.3, 1.6, 2.1,
3.3, 4.1 и их следствия. CONJECTURED: сама H13-I (VERIFIED исчерпывающе при
4 <= n <= 10, SAMPLED при 11 <= n <= 36).

Чего не хватает для H13-I: аргумента, который использует ограничение на
квадрантные раскраски (следствие 1.5). Все «слепые» к этому ограничению
методы упираются либо в константу M_n (она точна уже для релаксации,
теорема 2.1), либо в разрыв Θ(n) усреднения (замечание 3.4). Наиболее
близкая к цели известная схема — жадная из теоремы 2.1: ей нужно n свободных
знаков, а разрез даёт только 2 параметра; в терминах §1.7 заметки это и есть
причина провала индукции по одному элементу.
