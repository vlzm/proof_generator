## 0. Постановка и замена переменных

Двойной разрез `(q, c)` даёт линию `w_j = pi(q+1+j) − (q+1−c) mod n`.
Положим

```text
a = q + 1,   b = q + 1 − c    (mod n),      w_j = (pi(a + j) − b) mod n.
```

Отображение `(q, c) -> (a, b)` — биекция `Z_n^2 -> Z_n^2`, поэтому
`I(pi) = min_{a,b} inv(w)` — тот же минимум по всем n^2 разрезам. Ниже
`inv(a, b)` — число инверсий линии при разрезе `(a, b)`, `NI(a, b) = C(n,2) −
inv(a, b)` — число возрастающих (неинвертированных) пар,
`S(a, b) = NI(a, b) − inv(a, b)`.

Для пары различных `x, y` из Z_n обозначим

```text
u = (x − y) mod n,        A_{xy} = (y, x]        — дуга позиций, |A| = u,
t = (pi(x) − pi(y)) mod n, B_{xy} = (pi(y), pi(x)] — дуга значений, |B| = t.
```

Замена ориентации пары (`x <-> y`) заменяет обе дуги на дополнения.

Обозначения линии: `j_x = (x − a) mod n` — позиция элемента x в линии,
`v_x = (pi(x) − b) mod n = w_{j_x}` — его значение.

**H13-I.** При всех n >= 4 и всех pi существует разрез с
`inv(a, b) <= floor((n−1)^2/4)`.

## 1. Лемма 1 (дуговая форма инверсии)

При любом разрезе `(a, b)` и любой паре `{x, y}`:

```text
j_x < j_y   <=>   a in A_{xy};        v_x < v_y   <=>   b in B_{xy}.
```

Следовательно пара возрастает тогда и только тогда, когда `a in A_{xy}`
и `b in B_{xy}` одновременно верны или одновременно ложны, и инвертирована
тогда и только тогда, когда верно ровно одно из двух. Условие не зависит
от выбранной ориентации пары.

*Доказательство.* Пусть `u = (x − y) mod n in [1, n−1]`. Тогда
`j_y = (j_x + n − u) mod n`, а `j_x, j_y in [0, n)`, поэтому `j_x < j_y`
равносильно `j_x + n − u < n`, то есть `j_x < u`, то есть
`(x − a) mod n < u`, то есть `a in {x − u + 1, ..., x} = (y, x] = A_{xy}`.
Для значений дословно то же с `pi(x), pi(y), b`. Пара инвертирована, когда
порядки позиций и значений противоположны, — это ровно случай «ровно одно
из двух». При замене ориентации обе дуги переходят в дополнения, и оба
вхождения меняются одновременно: «ровно одно» сохраняется. ∎

**Следствие 1.1.** `inv(a, b) = sum_p [1_{a in A_p} XOR 1_{b in B_p}]`.

**Следствие 1.2.** Пара с параметрами `(u, t)` инвертирована ровно при
`u(n − t) + (n − u)t` разрезах и возрастает при `ut + (n − u)(n − t)`.

**Следствие 1.3 (форма «одноимённых квадрантов»).**

```text
NI(a, b) = #{ упорядоченных (y, x), y != x : (a, b) in (y, x] x (pi(y), pi(x)] }.
```

То есть каждая упорядоченная пара задаёт торический прямоугольник, и
`NI(a, b)` — кратность покрытия точки `(a, b)` этими n(n−1) прямоугольниками.
(Две точки тора разбивают тор на четыре прямоугольника; два «одноимённых»
дают возрастание пары, два других — инверсию.)

**Следствие 1.4 (знаковая форма).** Пусть `eps_p(a) = 1 − 2·1_{a in A_p}`
и `eta_p(b) = 1 − 2·1_{b in B_p}` — знаки в {±1}. Тогда

```text
S(a, b) = sum_p eps_p(a) eta_p(b),     inv(a, b) = (C(n,2) − S(a, b))/2.
```

Так как по C12 `C(n,2) = floor(n^2/4) + floor((n−1)^2/4)` и
`floor(n^2/4) − floor((n−1)^2/4) = floor(n/2)`, получаем эквивалентную форму:

```text
H13-I  <=>  max_{a,b} S(a, b) >= floor(n/2)
       <=>  max_{a,b} NI(a, b) >= floor(n^2/4).
```

**Следствие 1.5 (почему равномерное усреднение обречено).** Среднее S по всем
n^2 разрезам равно `(1/n^2) sum_p (n − 2u_p)(n − 2t_p)`. Для отражения
`pi(x) = h − x` каждая пара имеет `t = n − u`, то есть слагаемое равно
`−(n − 2u)^2 <= 0`, и среднее строго отрицательно при n >= 4, тогда как
требуется максимум `>= floor(n/2) > 0`. Это точная причина провала
усреднения (`h13_line_model.md` §1.7) и заодно граница применимости любого
аргумента вида «минимум не больше среднего по фиксированному семейству»:
семейство обязано зависеть от pi.

## 2. Лемма 2 (градиент разреза)

```text
inv(a + 1, b) − inv(a, b) = (n − 1) − 2·w_0,
inv(a, b + 1) − inv(a, b) = (n − 1) − 2·p_0,
```

где `w_0 = w_0(a, b)` — первое значение линии, `p_0` — позиция значения 0
в линии (`w_{p_0} = 0`).

*Доказательство.* По лемме 1 статус пары `{x, y}` меняется при `a -> a + 1`
тогда и только тогда, когда ровно одна из точек `a, a+1` лежит в `A_{xy} =
(y, x]`, то есть когда `a = y` (левый конец) или `a = x` (правый конец), —
иначе говоря, для пар, содержащих элемент, стоящий в линии на позиции 0.
При сдвиге `a -> a + 1` этот элемент переходит с позиции 0 на позицию n−1,
поэтому порядок позиций во всех n−1 таких парах меняется на противоположный,
а значения не трогаются: возрастающие пары становятся инверсиями и наоборот.
Элемент с значением `w_0` стоит первым, поэтому он инвертирован ровно
с `w_0` элементами (меньшими) и возрастает с `n − 1 − w_0`. Итого
`Δ = (n − 1 − w_0) − w_0`. Второе равенство — то же рассуждение для дуг
значений: значение 0 становится наибольшим. ∎

**Следствие 2.1 (лемма C заметки).** В точке минимума все частные приращения
неотрицательны, что после суммирования по k шагам даёт
`sum_{j<k} w_j <= k(n−1)/2` и симметрично для обратной перестановки.

## 3. Лемма 3 (совместный сдвиг обоих разрезов)

Зафиксируем разрез `(a, b)` и линию w. Для `k, l in [0, n)` положим
`P = {j : j < k}` (позиции), `V = {j : w_j < l}` (носители малых значений),
`m = |P ∩ V|`, `D = P Δ V`, `g = |D| = k + l − 2m`, `E` — дополнение D.
Тогда

```text
inv(a + k, b + l) − inv(a, b) = asc(D, E) − desc(D, E),
```

где `asc(D, E)` и `desc(D, E)` — числа возрастающих и инвертированных пар
между D и E при исходном разрезе; всего таких пар `g(n − g)`.

*Доказательство.* Сдвиг `a -> a + k` переносит первые k элементов линии
в конец, сохраняя порядок внутри обеих частей: порядок позиций меняется
ровно у пар, ровно один элемент которых лежит в P. Сдвиг `b -> b + l`
делает l наименьших значений наибольшими, сохраняя порядок внутри обеих
групп: порядок значений меняется ровно у пар, ровно один элемент которых
лежит в V. Статус пары (инверсия или нет) меняется, когда изменился ровно
один из двух порядков. Для элементов i, i′ с индикаторами
`alpha = 1_{i in P}`, `beta = 1_{i in V}` это означает
`(alpha_i != alpha_{i'}) XOR (beta_i != beta_{i'})`, то есть
`alpha_i XOR beta_i != alpha_{i'} XOR beta_{i'}`, то есть ровно один
из i, i′ лежит в `D = P Δ V`. Меняющиеся пары — в точности пары между D и E,
их `g(n − g)`; каждая возрастающая становится инверсией и наоборот, откуда
приращение равно `asc(D, E) − desc(D, E)`. ∎

**Следствие 3.1.** Если разрез `(a, b)` минимизирует inv, то для всех `(k, l)`
между `D(k, l)` и дополнением не меньше половины из `g(n − g)` пар
возрастают. Случай `l = 0` — это следствие 2.1 (лемма C).

**Замечание (условия леммы C недостаточны — точный механизм).** Для линии
`(0, 5, 4, 3, 2, 1, 6)` при n = 7 (`h13_line_model.md` §4) все приращения по
одному разрезу неотрицательны: по позициям и по значениям они равны
`0, 6, 2, 0, 0, 2, 6`. Но `inv = 10 > 9`, и совместный сдвиг `(k, l) = (1, 2)`
даёт приращение −2 (как и `(1,3), (2,1), (2,2), (3,1)`), приводя к `I = 8`.
Так что доказательство H13-I обязано пользоваться леммой 3, а не 2.

## 4. Лемма 4 (порог Мантеля)

`floor((n−1)^2/4) = C(n,2) − floor(n^2/4)`, а `floor(n^2/4)` — максимум числа
рёбер графа без треугольников на n вершинах (теорема Мантеля). Поэтому:
если линия w не содержит возрастающей подпоследовательности длины 3
(избегает шаблона 123), то

```text
inv(w) >= floor((n−1)^2/4),
```

причём равенство достигается только на линиях
`w = (alpha−1, alpha−2, ..., 0, n−1, n−2, ..., alpha)` с
`alpha in {floor(n/2), ceil(n/2)}` — это в точности сбалансированные линии
отражений.

*Доказательство.* Граф возрастаний G (вершины — позиции линии, рёбра —
возрастающие пары) имеет треугольник тогда и только тогда, когда в w есть
возрастающая тройка. Пусть G без треугольников и m = |E(G)|.
Возьмём вершину u максимальной степени Δ. Её окрестность `N(u)`
независима (иначе треугольник), поэтому каждое ребро имеет конец в
`B = V ∖ N(u)`, откуда `m <= sum_{v in B} d(v) <= |B|·Δ = (n − Δ)Δ <=
floor(n^2/4)` (последнее — целочисленный максимум произведения при сумме n).
Значит `inv(w) = C(n,2) − m >= C(n,2) − floor(n^2/4) = floor((n−1)^2/4)`.

Равенство. Тогда `(n − Δ)Δ = floor(n^2/4)`, то есть
`Δ in {floor(n/2), ceil(n/2)}`; в неравенстве `m <= sum_{v in B} d(v)`
равенство означает, что внутри B рёбер нет (иначе ребро сосчитано дважды),
а в `sum_{v in B} d(v) <= |B|Δ` — что все вершины B имеют степень Δ. Так
как `A = N(u)` тоже независимо и `|A| = Δ`, `|B| = n − Δ`, граф двудольный
с долями A, B, и каждая вершина B соединена со всеми Δ вершинами A: значит
`G = K_{A,B}` — полный двудольный со сбалансированными долями.
Обе доли — независимые множества в G, то есть убывающие подпоследовательности
линии. Если бы позиция `q in B` лежала строго между позициями `p_1 < p_2`
из A, то из «все пары A×B возрастают» следовало бы `w_{p_1} < w_q < w_{p_2}`,
что противоречит убыванию A. Значит A и B занимают по непрерывному блоку
позиций; пусть A — первый блок. Все пары между блоками возрастают, поэтому
`max A < min B`, и A состоит из значений `0..|A|−1`, убывающих, B — из
остальных, убывающих. Это и есть указанный вид линии. ∎

**Следствие 4.1.** Порог `floor((n−1)^2/4)` в H13-I — это в точности порог
Мантеля, а равенство в H13-I требует, чтобы граф возрастаний оптимального
разреза был полным двудольным сбалансированным. Экстремальность отражений
(C33: максимум `I` достигается ровно на n отражениях) не случайна.

## 5. Лемма 5 (ориентация троек — инвариант торического класса)

Для различных `x, y, z in Z_n` положим `or(x, y, z) = +1`, если
`(y − x) mod n < (z − x) mod n`, и `−1` иначе (обход окружности от x
встречает сначала y или сначала z). Это циклический инвариант: `or` не
меняется при циклической перестановке аргументов и меняет знак при
транспозиции. Положим

```text
T_+(pi) = #{ троек {x,y,z} : or(pi(x), pi(y), pi(z)) = or(x, y, z) }.
```

Тогда:

1. всякая возрастающая тройка любой линии pi — положительно ориентированная
   тройка pi; в частности число треугольников графа возрастаний при любом
   разрезе не превосходит `T_+(pi)`;
2. обратно, у каждой положительно ориентированной тройки есть разрез, при
   котором она возрастает;
3. `T_+(pi) = 0` тогда и только тогда, когда pi — отражение `pi(x) = h − x`,
   тогда и только тогда, когда все n^2 линий pi избегают 123.

*Доказательство.* (1) Пусть `i < j < k` — позиции линии при разрезе `(a, b)`
и `w_i < w_j < w_k`. Для элементов `x = a+i, y = a+j, z = a+k` имеем
`(y − x) mod n = j − i < k − i = (z − x) mod n`, то есть `or(x, y, z) = +1`;
для значений `pi(x) = b + w_i` и т. д.:
`(pi(y) − pi(x)) mod n = w_j − w_i < w_k − w_i = (pi(z) − pi(x)) mod n`,
то есть `or(pi(x), pi(y), pi(z)) = +1`. (Обе разности лежат в `[1, n)`,
поэтому взятие остатка их не меняет.)

(2) Пусть `or(x, y, z) = or(pi(x), pi(y), pi(z)) = +1` (после циклической
перенумерации). Выберем `a in (z, x]` и `b in (pi(z), pi(x)]`; тогда по лемме 1
`j_x < j_y`, `j_y < j_z` (обе пары имеют a вне соответствующей «встречной»
дуги) и аналогично `v_x < v_y < v_z`, то есть тройка возрастает.

(3) `T_+(pi) = 0` означает, что pi обращает ориентацию каждой тройки. Положим
`psi(x) = −pi(x)`. Отрицание обращает ориентацию каждой тройки
(`(−q + p) mod n` — это `n − ((q − p) mod n)`, и неравенство между двумя
такими величинами переворачивается), поэтому psi сохраняет ориентацию всех
троек. Биекция Z_n, сохраняющая ориентацию всех троек, — поворот. В самом
деле, для целых `0 <= i < j < k < n` имеем `(j − i) mod n = j − i <
k − i = (k − i) mod n`, то есть `or(i, j, k) = +1`; положим
`rho(i) = (psi(i) − psi(0)) mod n` (сдвиг ориентацию не меняет), тогда
`rho(0) = 0`, и для всех `0 < j < k` из `or(0, rho(j), rho(k)) = +1`
следует `rho(j) < rho(k)`. Значит rho строго возрастает на `1..n−1`
и принимает там все значения `{1, ..., n−1}`, откуда `rho(j) = j`
и `psi(i) = psi(0) + i`. Отсюда
`pi(x) = −psi(0) − x`, то есть отражение. Обратно, у отражения
`t = n − u` для каждой пары и ориентация каждой тройки обращается, так что
`T_+ = 0`; по пункту (1) ни одна линия не имеет возрастающей тройки. ∎

**Следствие 5.1 (точность порога H13-I).** Для отражения любая линия
избегает 123, поэтому по лемме 4 `inv >= floor((n−1)^2/4)` при всех n^2
разрезах; равенство достигается (лемма 4, сбалансированная линия; явно —
C32). Значит константу в H13-I уменьшить нельзя, а отражения — точный
экстремум.

## 6. Что этими леммами не получается

H13-I равносильна утверждению: у графа возрастаний хотя бы одного разреза
не меньше `ex(n; K_3) = floor(n^2/4)` рёбер. Теорема Мантеля даёт оценку
сверху для графов без треугольников и не даёт оценки снизу; леммы 4–5 лишь
объясняют константу и экстремум. Проверены и отвергнуты (сессия 9,
`experiments/h13i_cut_families.py`, вместе с §1.7 заметки):

- равномерное усреднение по всем n^2 разрезам (следствие 1.5);
- **любое якорное семейство из n разрезов**: для фиксированных `(p0, v0)`
  берём n разрезов «элемент x стоит в линии на позиции p0 со значением v0»,
  то есть `(a, b) = (x − p0, pi(x) − v0)`. Такое семейство привязано к
  элементу и потому согласовано с действием тора (поворот pi поворачивает
  семейство); прежнее семейство §1.7 — это `p0 = 0`. Ни одно из n^2 таких семейств не
  достигает порога при 4 <= n <= 8 (исчерпывающе); лучшее — `(0, 1)`, его
  худшее значение 3, 5, 7, 11, 16 при n = 4..8 против порога 2, 4, 6, 9, 12.
  Случай `p0 = 0` — прежний результат §1.7;
- индукция удалением k элементов (сжатие обеих окружностей): при k = 1 и
  k = 2 шаг ложен уже на аффинном входе `(0,5,2,7,4,1,6,3)` (n = 8, I = 11):
  лучшая однократная редукция даёт `I = 6` при допустимом разрыве 3,
  лучшая двукратная — `I = 4` при допустимом разрыве 6. При k = 3 этот вход
  разрыв не нарушает (8 при допустимых 8) — случай k >= 3 не проверен
  исчерпывающе;
- локальные условия одного разреза (лемма C = следствие 2.1) — недостаточны,
  точный контрпример и работающий совместный сдвиг — в замечании к лемме 3.

Количественно: в худшем случае доля «хороших» разрезов равна 1/n. Минимум по
pi числа разрезов с `inv <= floor((n−1)^2/4)` равен 4, 7, 6, 10, 8 при
n = 4..8 (из 16, 25, 36, 49, 64), и при чётных n минимум достигается на
отражениях. Поэтому доказательство обязано указывать разрез по pi, а не
выбирать его из короткого заранее заданного списка.

  рекуррентной таблицы `inv_table` с прямым подсчётом инверсий;
- часть C (лемма 3): все pi, все разрезы, все сдвиги `(k, l)`, 4 <= n <= 5
  (проверяются и `|D| = k + l − 2m`, и `g(n − g)`);
- часть D (лемма 4): все линии, избегающие 123, 4 <= n <= 8 (14, 42, 132,
  429, 1430 линий — числа Каталана), граница и описание равенства;
- часть E (лемма 5): все pi, все разрезы, 4 <= n <= 6;
- часть F (сверка с C33): `max_pi I(pi) = floor((n−1)^2/4)` и достигается
  ровно на n отражениях, 4 <= n <= 8.

Конечная проверка не доказывает общий случай; доказательства лемм 1–5 выше
не опираются на перебор.
