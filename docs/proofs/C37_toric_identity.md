# C37, C38 — торический класс: тождество Кендалл–Спирмен и максимум среднего

Дата: 13.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор), общий случай — все n >= 2 и все pi. Чекер: `checks/check_C37.py`
(PASS; отчёт `data/runs/check_C37/`). Эксперимент: `experiments/toric_identity.py`,
отчёт `data/runs/toric_identity/`. Доказательство не использует ни таблицы,
ни N1, ни ядро ходов: это чистая комбинаторика перестановок.

## Обозначения

`pi: Z_n -> Z_n` — перестановка. Двойной разрез — пара `(a, b)` из `Z_n^2`;
**линия** разреза — слово

```text
w^{a,b}_j = (pi(j + a) - b) mod n,   j = 0, ..., n - 1.
```

Точке `i` из Z_n сопоставим её координаты в линии:
`X_i = (i - a) mod n` (номер позиции), `Y_i = (pi(i) - b) mod n` (ранг значения);
`j -> X`, `w_j -> Y` — одно и то же с точностью до имени индекса.
Пара `{i, j}` **инвертирована** при разрезе `(a, b)`, если порядки её элементов
по X и по Y противоположны.

```text
inv(a, b) = число инверсий линии w^{a,b};
D2(a, b)  = sum_j (j - w^{a,b}_j)^2 = sum_i (X_i - Y_i)^2   (квадрат Спирмена);
I(pi)     = min по всем n^2 разрезам от inv(a, b)           (H13-I: I <= floor((n-1)^2/4));
A(pi)     = среднее по всем n^2 разрезам от inv(a, b).
```

Отражение — `pi_h(i) = h - i mod n`, то есть `pi(i) + i = const`.

## Утверждения

**Теорема A (C37).** Для любой pi величина `inv(a, b) - D2(a, b)/n` одна и та же
для всех n^2 разрезов; она равна `(n^2 - 1)/12 - W/n^2`, где
`W = sum_{i, j in Z_n} f(j - i) f(pi(j) - pi(i))`, `f(t) = (t mod n) - (n - 1)/2`.

Следствие A1. Разрез минимизирует число инверсий тогда и только тогда, когда он
минимизирует сумму квадратов смещений: на торическом классе расстояния Кендалла
и Спирмена — аффинные функции друг друга.

Следствие A2. `I(pi) = (n^2 - 1)/12 - W/n^2 + (1/n) min_{a,b} D2(a, b)`.

**Теорема B (C38).** Для любой pi и любого n >= 2

```text
A(pi) <= (n - 1)(2n - 1)/6,
```

причём равенство достигается тогда и только тогда, когда pi — отражение.

Следствие B1. `I(pi) <= floor((n - 1)(2n - 1)/6)` для всех n >= 2 и всех pi.

Это первая общая (при всех n) верхняя оценка величины H13-I; целевая оценка
H13-I — `floor((n - 1)^2/4)`, то есть требуется улучшение ровно в 4/3 раза
асимптотически (`(2/6)n^2` против `(1/4)n^2`).

## 1. Лемма 1 (шаг разреза позиций)

Пусть `w = w^{a,b}` и `w_0` — её первая буква. Тогда

```text
inv(a + 1, b) - inv(a, b) = n - 1 - 2 w_0,
D2 (a + 1, b) - D2 (a, b) = n (n - 1 - 2 w_0).
```

Доказательство. `w^{a+1,b} = (w_1, ..., w_{n-1}, w_0)`: циклический сдвиг влево.

Инверсии. Взаимный порядок букв `w_1, ..., w_{n-1}` не изменился. Буква `w_0`
в начале образует инверсию ровно с теми буквами, которые меньше её; так как
буквы — все элементы {0, ..., n − 1}, таких ровно `w_0`. В конце она образует
инверсию ровно с теми, которые больше её, то есть с `n - 1 - w_0` буквами.
Значит изменение равно `(n - 1 - w_0) - w_0`.

Квадраты. Обозначим `w' = w^{a+1,b}`. Тогда

```text
D2(w) - w_0^2 = sum_{j=0}^{n-2} ((j + 1) - w_{j+1})^2,
D2(w') - (n - 1 - w_0)^2 = sum_{j=0}^{n-2} (j - w_{j+1})^2,
```

поэтому

```text
D2(w') - D2(w) = sum_{j=0}^{n-2} [ (j - w_{j+1})^2 - (j + 1 - w_{j+1})^2 ]
                 + (n - 1 - w_0)^2 - w_0^2
               = sum_{j=0}^{n-2} [ 2 w_{j+1} - (2j + 1) ] + (n - 1)^2 - 2(n - 1) w_0.
```

Здесь `sum_{j=0}^{n-2}(2j + 1) = (n - 1)^2` и `sum_{j=1}^{n-1} w_j = n(n-1)/2 - w_0`
(сумма всех букв равна `n(n-1)/2`). Итого

```text
D2(w') - D2(w) = n(n - 1) - 2 w_0 - 2(n - 1) w_0 = n(n - 1) - 2 n w_0. ∎
```

## 2. Лемма 2 (шаг разреза значений)

Пусть `p` — номер позиции с `w_p = 0`. Тогда

```text
inv(a, b + 1) - inv(a, b) = n - 1 - 2 p,
D2 (a, b + 1) - D2 (a, b) = n (n - 1 - 2 p).
```

Доказательство. `w^{a,b+1}_j = (w_j - 1) mod n`: все буквы уменьшаются на 1,
кроме буквы 0, которая становится `n - 1`.

Инверсии. Взаимный порядок всех букв, кроме бывшей нулевой, сохраняется.
Буква в позиции p была минимумом и давала инверсии ровно с p буквами слева;
стала максимумом и даёт инверсии ровно с `n - 1 - p` буквами справа.

Квадраты.

```text
D2(w') - D2(w) = sum_{j != p} [ (j - w_j + 1)^2 - (j - w_j)^2 ]
                 + (p - (n - 1))^2 - p^2
               = sum_{j != p} [ 2(j - w_j) + 1 ] + (n - 1)^2 - 2 p (n - 1).
```

Так как `sum_j (j - w_j) = 0`, имеем `sum_{j != p}(j - w_j) = -(p - 0) = -p`,
и сумма даёт `-2p + (n - 1)`. Итого

```text
D2(w') - D2(w) = -2p + (n - 1) + (n - 1)^2 - 2p(n - 1) = n(n - 1) - 2 n p. ∎
```

## 3. Теорема A

Из лемм 1 и 2: приращения функции `inv` и функции `D2/n` совпадают на обоих
типах элементарных шагов, а шаги `(a, b) -> (a + 1, b)` и `(a, b) -> (a, b + 1)`
связывают весь тор `Z_n^2`. Значит `const(pi) := inv(a, b) - D2(a, b)/n`
не зависит от разреза. ∎

Значение константы. Усредним тождество по всем n^2 разрезам. Для фиксированного i
пара `(X_i, Y_i)` пробегает `Z_n^2` ровно по разу, поэтому

```text
avg D2 = n * (1/n^2) sum_{x, y in Z_n} (x - y)^2 = n (n^2 - 1)/6
```

(так как `(1/n^2) sum_{x,y} (x-y)^2 = 2 Var(U) = (n^2 - 1)/6` для равномерного U).
Значит `const(pi) = A(pi) - (n^2 - 1)/6`. Ниже (лемма 4 и её переписывание)
`A(pi) = (n^2 - 1)/4 - W/n^2`, откуда `const(pi) = (n^2 - 1)/12 - W/n^2`. ∎

Следствие A1 очевидно: `inv` и `D2/n` отличаются на константу разреза.
Следствие A2 — подстановка. Проверка: для тождественной pi имеем `W = n^2(n^2-1)/12`,
`const = 0` и `inv(a, b) = D2(a, b)/n = k(n - k)`, где `k = (b - a) mod n`.

## 4. Лемма 3 (сколько разрезов инвертируют данную пару)

Пусть `i != j`, `d = (j - i) mod n` и `e = (pi(j) - pi(i)) mod n`
(оба в {1, ..., n − 1}). Число разрезов `(a, b)`, при которых пара `{i, j}`
инвертирована, равно

```text
(n - d) e + d (n - e) = n(d + e) - 2 d e = n^2/2 - 2 u v,
где u = d - n/2,  v = e - n/2.
```

Доказательство. `X_j = (X_i + d) mod n`, поэтому `X_i < X_j` равносильно
`X_i <= n - 1 - d`, то есть `a` лежит в циклическом отрезке `(j, i]` длины `n - d`;
дополнение — отрезок `(i, j]` длины d. Аналогично `Y_i < Y_j` равносильно
`b in (pi(j), pi(i)]` (длина `n - e`). Условия на a и на b независимы, а пара
инвертирована ровно тогда, когда выполнено ровно одно из них; отсюда первое
выражение. Второе — раскрытие скобок, третье — проверка:
`-2(d - n/2)(e - n/2) = -2de + nd + ne - n^2/2`. Замена ориентации пары
(`d -> n - d`, `e -> n - e`) меняет знаки u и v одновременно, так что величина
корректно определена на неупорядоченной паре. ∎

## 5. Лемма 4 (среднее число инверсий)

```text
A(pi) = (1/2) C(n, 2) - (2/n^2) Q,   Q = sum_{пары {i,j}} u_{ij} v_{ij}.
```

Доказательство: суммируем лемму 3 по всем `C(n, 2)` парам и делим на n^2. ∎

Эквивалентная форма через W. Для `k != 0` положим `g(k) = (k mod n) - n/2 = f(k) - 1/2`.
Тогда `2Q = sum_{i != j} g(j - i) g(pi(j) - pi(i))`, и, раскрывая произведение,

```text
2Q = sum_{i != j} f(j-i) f(pi(j)-pi(i)) - (1/2) sum_{i != j} f(j-i)
     - (1/2) sum_{i != j} f(pi(j)-pi(i)) + n(n-1)/4.
```

Здесь `sum_{i != j} f(j - i) = n sum_{k != 0} f(k) = n (0 - f(0)) = n(n-1)/2`,
и столько же для второй суммы (pi — биекция), а
`sum_{i != j} f(j-i) f(pi(j)-pi(i)) = W - n f(0)^2 = W - n(n-1)^2/4`.
Итого `2Q = W - n^2 (n - 1)/4` и

```text
A(pi) = n(n-1)/4 - (1/n^2) (W - n^2(n-1)/4) = (n^2 - 1)/4 - W/n^2.
```

## 6. Теорема B

Из леммы 4 достаточно оценить снизу Q. По неравенству о среднем
`u v >= -(u^2 + v^2)/2` для каждой пары, поэтому

```text
Q >= -(1/2) [ sum_пары u^2 + sum_пары v^2 ].
```

Обе суммы равны: `u_{ij} = g(j - i)` и при пробеге неупорядоченных пар `{i, j}`
пары значений `{pi(i), pi(j)}` пробегают все неупорядоченные пары ровно по разу,
так что `sum_пары v^2 = sum_пары u^2`. Далее

```text
sum_пары u^2 = (1/2) sum_{i != j} g(j - i)^2 = (n/2) sum_{k=1}^{n-1} (k - n/2)^2
             = (n/2) * n(n-1)(n-2)/12 = n^2 (n-1)(n-2)/24,
```

где использовано

```text
sum_{k=1}^{n-1} (k - n/2)^2 = sum_{k=0}^{n-1} (k - n/2)^2 - n^2/4
   = (n-1)n(2n-1)/6 - n^2(n-1)/2 + n^3/4 - n^2/4 = n(n-1)(n-2)/12.
```

Значит `Q >= -n^2 (n-1)(n-2)/24` и

```text
A(pi) <= n(n-1)/4 + (2/n^2) * n^2(n-1)(n-2)/24 = n(n-1)/4 + (n-1)(n-2)/12
       = (n-1)(2n-1)/6.
```

Случай равенства. Равенство в `uv >= -(u^2+v^2)/2` равносильно `u = -v`, то есть
`e = n - d`: `(pi(j) - pi(i)) mod n = n - ((j - i) mod n)`, то есть
`pi(j) - pi(i) = -(j - i)` в Z_n. Требование по всем парам равносильно
`pi(i) + i = const`, то есть pi — отражение; обратно, для отражения равенство
выполнено для каждой пары. ∎

Следствие B1: `I(pi) <= A(pi) <= (n-1)(2n-1)/6`, а `I(pi)` — целое. ∎

## 7. Точность и замечания

1. Оценка B1 не достигается: на отражениях `A = (n-1)(2n-1)/6`, но
   `I = floor((n-1)^2/4)` (это в 4/3 раза меньше). Тем не менее B точна как
   оценка именно среднего, и максимум среднего достигается ровно на том же
   семействе, на котором тесна H13-I. Поэтому усреднение по всем n^2 разрезам
   принципиально не может дать `floor((n-1)^2/4)`: единственные pi с большим
   средним — отражения, а у них минимум лежит на 25 % ниже среднего.
2. Второй момент. Так как `sum_{a,b} (inv - A) = 0`, верно
   `max inv * (A - min inv) >= Var(inv)`, откуда
   `I(pi) <= A(pi) - Var(inv)/(max inv - A)`; с грубой оценкой
   `max inv - A <= n(n^2-1)/12` получается `I <= A - 6 Var/(n^2 - 1)`.
   На отражениях это даёт ~`0.30 n^2` вместо `n^2/3` — строгое улучшение,
   но всё ещё не `n^2/4` (`data/runs/toric_identity/report.md`, последняя таблица).
   Общей нижней оценки для Var нет: вклад «диагонали» спектра даёт лишь `O(n^4)`.
3. Тождество A даёт O(n^2) алгоритм вычисления `I(pi)` (обе леммы — шаги за O(1))
   и, что важнее для H13-R, описывает оптимальный разрез как разрез с минимальной
   суммой квадратов смещений `sum_i (X_i - Y_i)^2`; смещения — та же величина,
   через которую оценивается пробег головы.
4. Переформулировка H13-I после теоремы A: положив
   `S(a, b) = sum_i (X_i - (n-1)/2)(Y_i - (n-1)/2)`, имеем `inv(a,b) = A - (2/n) S(a,b)`,
   и H13-I равносильно
   `max_{a,b} S(a, b) >= n * floor(n/2)/4 - Q/n`
   (см. `docs/notes/h13_line_model.md` §7). Усреднение (теорема B) — это в точности
   оценка `max S >= 0`; недостаёт ровно колебания S.

пар, без рекуррент лемм 1–2):

  и на выборке при n = 8, 9;

  разрезов при 4 <= n <= 7;

  при 2 <= n <= 200;
- следствие B1 против точного `I(pi)` при 4 <= n <= 8.

Конечные проверки не входят в доказательство: леммы 1–4 и теоремы A, B доказаны
для всех n.
