# C37 — торическое тождество для числа инверсий и следствия для H13-I

Дата: 17.09.2026 (сессия 9). Статус: PROVED (локальный аудит одной сессии,
один автор). Чекер: `checks/check_C37.py`. Эксперименты:
`experiments/toric_inversions.c` (toric_inversions-1.0),
`experiments/toric_sampling.py` (toric_sampling-1.0). Отчёт:
`data/runs/h13_i/report.md`.

Доказательство не использует N1, C16–C21, C28, C32 и таблицы расстояний:
это чистая комбинаторика перестановок, независимая от модели LRX. Связь
с проектом — через H13-I (`docs/notes/h13_line_model.md` §6, PLAN §8).

## 0. Обозначения

`n >= 2`; `pi` — биекция Z_n -> Z_n; `T(u) = u mod n` со значениями
в `{0, ..., n − 1}`; `D(u) = min(T(u), n − T(u))` — циклическое расстояние
до нуля.

Двойной разрез — пара `(a, s)` из Z_n x Z_n. Он задаёт линию

```text
w_j = T(pi(a + j) − s),   j = 0, ..., n − 1,
```

то есть перестановку `{0, ..., n − 1}`. Для точки `i` из Z_n положим

```text
alpha_i = T(i − a)        (ранг позиции i при разрезе a),
beta_i  = T(pi(i) − s)    (ранг значения pi(i) при разрезе s);
```

обе — биекции Z_n -> {0, ..., n − 1}, и `w_{alpha_i} = beta_i`.

```text
inv(a, s) = #{ j < k : w_j > w_k },
Q(a, s)   = sum_j (j − w_j)^2 = sum_i (alpha_i − beta_i)^2.
```

`I(pi) = min_{a, s} inv(a, s)` — величина H13-I; утверждение H13-I:
`I(pi) <= floor((n − 1)^2 / 4)`.

Соглашение о разрезе `(q, c)` из `docs/notes/h13_line_model.md` §0
переходит в это подстановкой `a = q + 1`, `s = q + 1 − c`; множество всех
`n^2` разрезов то же, поэтому `I(pi)` совпадает.

## 1. Лемма 1 (торическое тождество)

**Величина `inv(a, s) − Q(a, s) / n` не зависит от `(a, s)`.**

Доказательство. Группа Z_n x Z_n действует на разрезах сдвигами `a -> a + 1`
и `s -> s + 1`; достаточно проверить инвариантность на этих двух ходах.

*(1) `a -> a + 1`.* Новая линия `w' = (w_1, ..., w_{n−1}, w_0)`. Пары
с индексами `>= 1` сохраняют порядок. Пары с `w_0`: до сдвига `w_0` стоит
первым и даёт инверсию с каждым меньшим значением — их ровно `w_0`; после
сдвига `w_0` стоит последним и даёт инверсию с каждым большим — их
`n − 1 − w_0`. Значит

```text
inv(w') − inv(w) = (n − 1 − w_0) − w_0 = n − 1 − 2 w_0.
```

Далее, `Q(w') = sum_{j=0}^{n−2} (j − w_{j+1})^2 + (n − 1 − w_0)^2`, поэтому

```text
Q(w') − Q(w) = sum_{k=1}^{n−1} [ (k − 1 − w_k)^2 − (k − w_k)^2 ]
               + (n − 1 − w_0)^2 − w_0^2
             = sum_{k=1}^{n−1} [ 1 − 2 (k − w_k) ] + (n − 1)^2 − 2 (n − 1) w_0.
```

Так как `sum_{k=0}^{n−1} (k − w_k) = 0`, имеем `sum_{k=1}^{n−1}(k − w_k) = w_0`,
и

```text
Q(w') − Q(w) = (n − 1) − 2 w_0 + (n − 1)^2 − 2 (n − 1) w_0
             = n (n − 1) − 2 n w_0 = n (n − 1 − 2 w_0).
```

Итак `Q(w') − Q(w) = n · (inv(w') − inv(w))`.

*(2) `s -> s + 1`.* Теперь `w'_j = T(w_j − 1)`: все значения уменьшаются на 1,
кроме значения 0, которое становится `n − 1`. Пусть `j_0` — индекс с `w_{j_0} = 0`.
Порядок пар без `j_0` не меняется. До сдвига `w_{j_0} = 0` — минимум, инверсии
с каждым предшествующим индексом: их `j_0`. После сдвига `w'_{j_0} = n − 1` —
максимум, инверсии с каждым последующим: их `n − 1 − j_0`. Значит
`inv(w') − inv(w) = n − 1 − 2 j_0`. Далее

```text
Q(w') − Q(w) = sum_{j != j_0} [ (j − w_j + 1)^2 − (j − w_j)^2 ]
               + (j_0 − (n − 1))^2 − j_0^2
             = sum_{j != j_0} [ 2 (j − w_j) + 1 ] + (n − 1)^2 − 2 j_0 (n − 1)
             = −2 j_0 + (n − 1) + (n − 1)^2 − 2 j_0 (n − 1)
             = n (n − 1 − 2 j_0),
```

где снова использовано `sum_j (j − w_j) = 0` (вклад `j_0` равен `j_0 − 0`).
Опять `Q(w') − Q(w) = n · (inv(w') − inv(w))`. ∎

Обозначим `c(pi) = inv(a, s) − Q(a, s)/n` (общее значение).

**Следствие 1.1.** `inv(a, s) = c(pi) + Q(a, s)/n`; в частности разрез,
минимизирующий число инверсий, — это в точности разрез, минимизирующий
квадратичное смещение `Q(a, s) = sum_j (j − w_j)^2`, и

```text
I(pi) = c(pi) + (1/n) min_{a, s} Q(a, s).
```

## 2. Лемма 2 (замкнутая формула для c)

```text
c(pi) = (1/n^2) * sum_{i < k} ( T(k − i) − T(pi(k) − pi(i)) )^2
      = (1/(2 n^2)) * sum_{k in Z_n} Q(k, pi(k)).
```

В частности `c(pi) >= 0`, `c` — инвариант торического класса (разности
`T(k − i)` и `T(pi(k) − pi(i))` не меняются при поворотах позиций и значений),
и `c(pi) = 0` тогда и только тогда, когда `pi` — поворот `pi(i) = i + b`.

Доказательство. Для пары `i != k` положим `p = T(k − i)`, `q = T(pi(k) − pi(i))`.

*(а) Когда пара даёт инверсию.* `alpha_i > alpha_k` равносильно
`a` из полуинтервала `(i, k]` (дуга длины `p`): действительно,
`alpha_i = T(i − a)`, `alpha_k = T(k − a) = T(alpha_i + p)`, и `alpha_i > alpha_k`
равносильно `alpha_i + p >= n`, то есть `T(i − a) >= n − p`, то есть
`a` лежит в `{i + 1, ..., i + p} = (i, k]`. Аналогично `beta_i > beta_k`
равносильно `s` из `(pi(i), pi(k)]` (дуга длины `q`). Пара `{i, k}` —
инверсия тогда и только тогда, когда выполнено ровно одно из этих двух
условий, то есть ровно для `p (n − q) + (n − p) q` разрезов.

*(б) Сумма Q по всем разрезам.* Для фиксированного `i` отображения
`a -> alpha_i` и `s -> beta_i` — биекции на `{0, ..., n − 1}`, причём
независимые. Значит

```text
sum_{a, s} (alpha_i − beta_i)^2 = sum_{u, v = 0}^{n−1} (u − v)^2
                                = 2 n sum u^2 − 2 (sum u)^2
                                = n^2 (n^2 − 1)/6,
```

и `sum_{a,s} Q(a, s) = n^3 (n^2 − 1)/6`.

*(в)* Усредняя тождество леммы 1 по всем `n^2` разрезам:

```text
c(pi) = (1/n^2) sum_{i<k} [ p (n − q) + (n − p) q ] − (n^2 − 1)/6.
```

*(г) Тождество для константы.* Посчитаем `sum_{i<k} [ n (p + q) − p^2 − q^2 ]`.
Выражение инвариантно относительно смены ориентации пары
(`p -> n − p`, `q -> n − q`), поэтому равно половине суммы по упорядоченным
парам. По упорядоченным парам `sum p = sum q = n · n(n−1)/2` и
`sum p^2 = sum q^2 = n · n(n−1)(2n−1)/6`, откуда

```text
sum_{ordered} [ n (p + q) − p^2 − q^2 ] = n^3 (n − 1) − n^2 (n−1)(2n−1)/3
                                        = n^2 (n^2 − 1)/3,
```

и по неупорядоченным парам — `n^2 (n^2 − 1)/6`. Значит
`(n^2 − 1)/6 = (1/n^2) sum_{i<k} [ n(p + q) − p^2 − q^2 ]`, и

```text
c(pi) = (1/n^2) sum_{i<k} [ p(n − q) + (n − p) q − n p − n q + p^2 + q^2 ]
      = (1/n^2) sum_{i<k} (p − q)^2.
```

*(д)* Наконец `Q(k, pi(k)) = sum_i (T(i − k) − T(pi(i) − pi(k)))^2`, то есть
сумма `(p − q)^2` по упорядоченным парам с первым элементом `k`; суммируя
по `k`, получаем удвоенную сумму по неупорядоченным парам. Обращение
`c(pi) = 0` равносильно `T(k − i) = T(pi(k) − pi(i))` для всех пар, то есть
`pi(i) − i` постоянно. ∎

## 3. Лемма 3 (максимум c — ровно на отражениях)

**Для всех `n >= 2` и всех `pi`**

```text
c(pi) <= (n − 1)(n − 2)/6,
```

**причём равенство достигается тогда и только тогда, когда `pi` — отражение
`pi(i) = h − i mod n`.**

Доказательство. Зафиксируем `k` и рассмотрим `Q(k, pi(k)) = sum_i (p_i − q_i)^2`,
где `p_i = T(i − k)`, `q_i = T(pi(i) − pi(k))`. Оба отображения `i -> p_i`
и `i -> q_i` — биекции на `{0, ..., n − 1}`, и `p_i = 0` равносильно `i = k`
равносильно `q_i = 0`. Так как `sum_i p_i^2 = sum_i q_i^2` фиксированы,

```text
Q(k, pi(k)) = 2 sum_{u=0}^{n−1} u^2 − 2 sum_i p_i q_i
```

максимально тогда и только тогда, когда `sum_i p_i q_i` минимальна. Пара
`(0, 0)` вынуждена; на остальных индексах это спаривание множества
`{1, ..., n − 1}` с самим собой, и по неравенству о перестановках минимум
`sum p q` достигается только при обратном спаривании `q_i = n − p_i`:

```text
min sum_i p_i q_i = sum_{u=1}^{n−1} u (n − u),
max Q(k, pi(k))   = sum_{u=1}^{n−1} (u − (n − u))^2 = sum_{u=1}^{n−1} (2u − n)^2
                  = n (n − 1)(n − 2)/3.
```

(Последнее равенство: `sum_{u=1}^{n−1}(2u−n)^2 = 4 sum u^2 − 4 n sum u + (n−1)n^2
= n(n−1)(n−2)/3`.)

По лемме 2 `c(pi) = (1/(2 n^2)) sum_k Q(k, pi(k)) <= (1/(2 n^2)) · n · n(n−1)(n−2)/3
= (n − 1)(n − 2)/6`.

Равенство требует равенства при каждом `k`, а равенство при одном `k` уже
означает `T(pi(i) − pi(k)) = n − T(i − k)` для всех `i != k`, то есть
`pi(i) = pi(k) − (i − k)` — отражение с `h = pi(k) + k`. Обратно, для
отражения `q = n − p` при всех парах, и `c = (n − 1)(n − 2)/6`. ∎

## 4. Лемма 4 (выровненная релаксация)

Положим `d_i = T(i − pi(i))`, `r = T(a − s)` и
`delta_i = T(alpha_i − beta_i) = T(d_i − r)` (последнее равенство:
`alpha_i − beta_i = (i − a) − (pi(i) − s) ≡ d_i − r`). Определим

```text
J(r) = c(pi) + (1/n) * sum_i D(d_i − r)^2.
```

**(а)** Для каждого разреза `(a, s)` с `T(a − s) = r` верно `inv(a, s) >= J(r)`,
причём равенство равносильно «выровненности» всех точек:
`|alpha_i − beta_i| = D(delta_i)` при всех `i`.

**(б)** `J(r)` — целое число при каждом `r`.

Доказательство. (а) `alpha_i − beta_i` — целое, сравнимое с `delta_i` по модулю
`n` и по модулю не превосходящее `n − 1`, поэтому
`alpha_i − beta_i` равно `delta_i` или `delta_i − n`, значит
`(alpha_i − beta_i)^2 >= D(delta_i)^2`, с равенством ровно в выровненном случае.
Суммируя и применяя следствие 1.1, получаем `inv(a,s) = c + Q/n >= J(r)`.

(б) Для точки `i` разность `(alpha_i − beta_i)^2 − D(delta_i)^2` равна `0`
(выровнена) либо `(n − D)^2 − D^2 = n (n − 2 D)` (не выровнена), то есть
делится на `n`. Значит `sum_i D(delta_i)^2 ≡ Q(a, s) (mod n)`, и
`J(r) = inv(a, s) − sum_{невыровненные i} (n − 2 D(delta_i))` — целое. ∎

## 5. Теорема 5 (H13-I для выровненной релаксации)

**Для всех `n >= 2` и всех `pi`:**

```text
min_r J(r) <= floor((n − 1)^2 / 4).
```

Доказательство. Обозначим `Delta_n = (1/n) sum_{v in Z_n} D(v)^2`. Прямой
подсчёт:

```text
n нечётно: sum_v D(v)^2 = 2 sum_{k=1}^{(n−1)/2} k^2 = n (n^2 − 1)/12,
           Delta_n = (n^2 − 1)/12;
n чётно (m = n/2): sum_v D(v)^2 = 2 sum_{k=1}^{m−1} k^2 + m^2 = m (2 m^2 + 1)/3,
           Delta_n = (2 m^2 + 1)/6 = (n^2 + 2)/12.
```

Усредняя `J` по `r` и пользуясь тем, что при каждом `i` величина `d_i − r`
пробегает все вычеты:

```text
(1/n) sum_r J(r) = c(pi) + (1/n^2) sum_i sum_r D(d_i − r)^2
                 = c(pi) + (1/n) sum_v D(v)^2 = c(pi) + Delta_n.
```

Значит `min_r J(r) <= c(pi) + Delta_n`, и по лемме 3

```text
min_r J(r) <= (n − 1)(n − 2)/6 + Delta_n
            = (n − 1)^2/4,                       n нечётно,
            = (n^2 − 2n + 2)/4 = (n^2 − 2n)/4 + 1/2,  n чётно.
```

При нечётном `n` правая часть равна `floor((n − 1)^2/4)`. При чётном `n`
она равна `floor((n − 1)^2/4) + 1/2`, а `min_r J(r)` — целое (лемма 4(б)),
поэтому `min_r J(r) <= floor((n − 1)^2/4)` и здесь. ∎

**Следствие 5.1 (достаточный признак H13-I).** Если для какого-нибудь `r*`,
на котором достигается `min_r J(r)`, существует разрез `(a, s)` с
`T(a − s) = r*`, у которого все точки выровнены, то

```text
I(pi) <= inv(a, s) = J(r*) = min_r J(r) <= floor((n − 1)^2 / 4),
```

то есть H13-I верна для этой `pi`.

**Следствие 5.2 (нижняя оценка).** Всегда `I(pi) >= min_r J(r)`.

## 6. Предложение 6 (отражения: точное значение I)

**Для отражения `pi_h(i) = h − i mod n` и любого `n >= 2`**

```text
I(pi_h) = floor((n − 1)^2 / 4),
```

то есть отражения достигают границы H13-I при всех `n` (а не только
при проверенных `4 <= n <= 10`).

Доказательство. Для разреза `(a, s)` линия равна
`w_j = T(h − a − j − s) = T(v − j)`, где `v = T(h − a − s)`; при пробеге
`(a, s)` величина `v` пробегает все вычеты. Линия — это
`v, v − 1, ..., 0, n − 1, n − 2, ..., v + 1`: два убывающих блока длин
`v + 1` и `n − 1 − v`. Внутри каждого блока инвертированы все пары; между
блоками инверсий нет (каждый элемент первого блока не превосходит `v`,
каждый элемент второго строго больше `v`). Значит

```text
inv = C(v + 1, 2) + C(n − 1 − v, 2),   (v + 1) + (n − 1 − v) = n.
```

Функция `x -> C(x, 2) + C(n − x, 2)` строго выпукла по `x`, поэтому минимум
по целым `x` достигается при `x = floor(n/2)` или `ceil(n/2)` и равен

```text
C(ceil(n/2), 2) + C(floor(n/2), 2) = floor((n − 1)^2/4)
```

(проверка по чётности: при `n = 2m` это `m(m−1) = (n^2 − 2n)/4`; при
`n = 2m + 1` это `m(m−1)/2 + m(m+1)/2 = m^2 = (n − 1)^2/4`). ∎

## 7. Что именно доказано и что нет

Доказано: леммы 1–4, теорема 5 и предложение 6 — общие утверждения при всех
`n >= 2` без конечного перебора.

**Не доказано:** сама H13-I. Теорема 5 — утверждение о нижней оценке
`J(r) <= inv` и не даёт верхней оценки для `I(pi)`: между `min_r J(r)`
и `I(pi)` стоит «плата за невыровненность»

```text
I(pi) = min_r [ J(r) + min_a M(a, r) ],
M(a, r) = sum over non-aligned i of ( n − 2 D(delta_i) ) >= 0.
```

Исчерпывающе (`experiments/toric_inversions.c`) максимум `I(pi) − min_r J(r)`
равен `0, 0, 0, 0, 3, 2, 5` при `n = 4, ..., 10`; на выборках он растёт
(8, 10, 24, 56 при `n = 12, 15, 20, 30`). Разбор попыток закрыть этот разрыв —
`docs/notes/h13_i_verdict.md`.

## 8. Замечания

1. Геометрическая форма невыровненности: точка `i` не выровнена тогда
   и только тогда, когда `a` лежит в полуинтервале между `pi(i) + r` и `i`,
   пройденном в короткую сторону (длина `D(d_i − r)`), а её вес равен
   `n − 2 D(d_i − r)`. Так H13-I превращается в задачу «найти точку
   окружности, покрытую хордами малого суммарного веса».
2. Эквивалентная запись H13-I через леммы 1–2:
   `min_{a,s} Q(a,s) + (1/(2n)) sum_k Q(k, pi(k)) <= n · floor((n − 1)^2/4)`.
   Опускание второго слагаемого даёт ложное утверждение
   `min Q <= sum_v D(v)^2 − n·[n чётно]/2` (контрпример: `n = 8`,
   `pi(i) = 5 i mod 8`, `min Q = 56 > 44`).
3. Тождество леммы 1 — не общее свойство пары (inv, Q): вне торического
   класса они не связаны аффинно (например при `n = 3` слова `(2,0,1)`
   и `(2,1,0)` имеют `Q = 6` и `Q = 8` при `inv = 2` и `3`, но
   `(1,0,2)` имеет `Q = 2`, `inv = 1`). Лемма 1 существенно использует,
   что сдвиг разреза меняет `inv` и `Q/n` на одну и ту же величину.
