# C37 — точная формула суммы инверсий по всем n^2 разрезам тора

Дата: 17.09.2026 (сессия 9). Статус: PROVED (общий n >= 2, элементарный
аргумент, не зависящий от таблиц). Чекер: `checks/check_C37.py` (PASS:
исчерпывающе по всем pi при 4 <= n <= 8, случайные pi при 9 <= n <= 60).
Контекст: попытка доказать H13-I (PLAN §8, `docs/notes/h13_line_model.md`
§6); формула сама H13-I не доказывает (см. §4 ниже — отчёт о том, что было
испробовано и почему не хватило), но даёт точный алгебраический инструмент
для дальнейших попыток и объясняет, почему усреднение (уже отвергнутое
в §1.7 заметки) даёт для отражений завышенное среднее.

## Утверждение

Пусть n >= 2, pi — перестановка {0,...,n-1}. Для разреза `(q, c)` в
`Z_n x Z_n` пусть `w = w_{q,c}` — линия из PROBLEM §5.6 / `h13_line_model.md`
§0: `w_j = pi(q+1+j) - (q+1-c) mod n`. Для пары позиций `0 <= i < j <= n-1`
положим

```text
d = j - i               (в {1, ..., n-1}),
e = (pi(j) - pi(i)) mod n   (в {1, ..., n-1}, ненулевой, т.к. pi(i) != pi(j)).
```

Тогда число разрезов `(q, c)` из всех n^2, при которых пара `{i, j}`
образует инверсию в `w_{q,c}`, равно ровно

```text
F(d, e) = n(d + e) - 2 d e.
```

Следовательно

```text
S(pi) := sum_{(q,c) in Z_n^2} inv(w_{q,c}) = sum_{0<=i<j<=n-1} F(j - i, (pi(j)-pi(i)) mod n).
```

`F` симметрична: `F(d,e) = F(e,d) = F(n-d, n-e)`; на границах диапазона
`F(1,1) = F(n-1,n-1) = 2n-2` (минимум по целым d,e в [1,n-1], пара почти
всегда согласована), `F(1,n-1) = F(n-1,1) = n^2-2n+2` (максимум, пара почти
всегда инвертирована).

## Доказательство

Зафиксируем пару `i < j`, `d = j - i`. Разрез `(q,c)` определяет два
независимых бита:

- `P(t) = 1`, если позиция `i` стоит в линии раньше позиции `j`, где
  `t = q + 1 mod n` (t пробегает Z_n биективно вместе с q);
- `Q(c) = 1`, если `pi(i)` стоит раньше `pi(j)` в порядке рангов
  `rank_c(v) = (v - c) mod n`.

Пара `{i,j}` образует инверсию в `w_{q,c}` тогда и только тогда, когда
`P(t) != Q(c)` (более ранняя по чтению позиция получает большее значение).
Это два независимых события (t и c пробегают Z_n независимо), поэтому
достаточно посчитать `#{t : P(t)=1}` и `#{c : Q(c)=1}` по отдельности и
перемножить дополнения.

**Число t с P(t) = 1.** По определению линии позиция `p` встречается в
линии на индексе `(p - t) mod n`. Тогда `i` раньше `j` (`P(t)=1`) в точности
когда `(i - t) mod n < (j - t) mod n`. При `t <= i` обе разности неотрицательны
и равенство совпадает с `i < j` — верно. При `t > j` обе разности после
приведения по модулю получают одно и то же `+n`, порядок сохраняется —
верно. При `i < t <= j` (**ровно `d = j - i` значений t**) `i - t` становится
отрицательным и получает `+n`, а `j - t` — нет, так что `(i-t) mod n >= n - d
> j - t = (j-t) mod n` — неверно. Итого `P(t)=1` для `n - d` значений `t`
из `n`, `P(t)=0` — для `d` значений.

**Число c с Q(c) = 1.** Тот же аргумент с ролями `(i,j,t)` -> `(lo,hi,c)`,
где `lo = min(pi(i),pi(j))`, `hi = max(pi(i),pi(j))`: `rank_c(lo) < rank_c(hi)`
для `n - (hi-lo)` значений c и не выполняется для `hi - lo` значений. Если
`pi(i) < pi(j)`, то `e = hi - lo` и `Q(c) = [rank_c(pi(i)) < rank_c(pi(j))]`
верно ровно при `rank_c(lo)<rank_c(hi)`, т.е. для `n-e` значений c. Если
`pi(i) > pi(j)`, то `e = (pi(j)-pi(i)) mod n = n - (hi-lo)`, а
`Q(c) = [rank_c(hi) < rank_c(lo)] = NOT[rank_c(lo)<rank_c(hi)]`, что верно
для `hi-lo = n-e` значений c из `n`, т.е. снова `n-e` (число c с Q=1).
В обоих случаях: `Q(c)=1` для `n-e` значений c, `Q(c)=0` — для `e` значений.

**Подсчёт инверсий.** `P != Q` для `(n-d)*e + d*(n-e) = n(d+e) - 2de = F(d,e)`
пар `(t,c)`, что и требовалось (t и q — биекция Z_n <-> Z_n, значит то же
верно для q). Суммируя по всем `C(n,2)` парам `i<j`, получаем формулу для
`S(pi)`. QED.

## Следствия и ограничения

1. **Среднее не подходит: количественное объяснение.** `mean inv = S(pi)/n^2`.
   На отражении `pi_h` каждая пара соседних позиций (`d=1`) имеет `e = n-1`
   (или `e=1`, в зависимости от ориентации) — экстремальное значение F,
   близкое к максимуму `n^2-2n+2`; в целом отражения максимизируют вклад
   почти всех пар, отсюда среднее у них систематически выше
   `floor((n-1)^2/4)`, хотя сам минимум по разрезам у них в точности равен
   этому порогу (H13-I тесна). Это делает явным факт из §1.7 заметки
   (усреднение не работает именно на экстремалях), а не просто
   переформулирует его.
2. **Формула не доказывает H13-I.** Она даёт только сумму по всем n^2
   разрезам; связи с минимумом нужна доп. информация о распределении
   `inv(q,c)` (не только среднее). В сессии 9 проверены и отвергнуты две
   попытки использовать сумму `S(pi)` (и связанную с ней дисперсию) для
   прямой оценки минимума — см. `docs/notes/h13_line_model.md` §7.
3. Формула симметрична относительно одновременной замены `d -> n-d`,
   `e -> n-e` (переобозначение "какая точка пары первая"), но не по
   отдельности — что и объясняет (алгебраически), почему семейства с
   зафиксированным `c` или зафиксированным `q` (см. §7.2 заметки) не дают
   нужного контроля: фиксация одной координаты замораживает соответствующий
   бит `P` или `Q` вместо усреднения по нему.
