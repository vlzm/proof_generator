# C28 — гипотеза H10 на отражениях

Дата: 13.09.2026 (сессия 4); дополнено 13.09.2026 (сессия 5, сверка с PR #5).
Статус: PROVED (часть 1 — сессия 4, один автор; часть 2 — сессия 5, второй
независимый вывод и численная сверка тем же ядром и той же конструкцией,

все отражения, все сдвиги; §2 ниже — до n <= 60 включительно). Конвенции —
PROBLEM §3; обозначения N1 — PROBLEM §5.2; подписанный шаг `-n/2 < d <= n/2`
(правило 16 AGENTS.md).

Часть 2 ниже реконструирует независимо (по мотивам механизма, найденного
параллельной сессией в PR #5, `docs/proofs/C28_reflections.md` той ветки:
лемма о слове антиподальной транспозиции, оканчивающемся на L) результат
«после свободного сокращения `<= B_n` на всех отражениях при всех n >= 4»
и выводит из него C9 (`d(sigma_n) <= B_n`) как частный случай h = 1.
Формулы лемм 1-4 (часть 1) не менялись.

## Утверждение

Пусть n >= 4, `pi(i) = h - i mod n` — отражение (h из Z_n; sigma_n — это
h = 1, rev_n — это h = n - 1). Для c из Z_n обозначим `f_c(i) = pi(i) + c`,
F_c, S_c — суммы по нетривиальным циклам f_c (N1 §1), H(c) — стоимость
маршрута N1 §3, R_c — длина кратчайшей прогулки по Z_n из 0 в c, посещающей
все переносчики нетривиальных циклов f_c (вариант конструкции, C27).
Тогда

```text
min_c [2F_c - S_c + R_c] <= min_c [2F_c - S_c + H(c)] <= B_n + 1,
```

точнее, для выражения с H(c):

```text
n нечётно:                                 min_c = B_n      (любое h)
n = 0 (mod 4):                             min_c = B_n      (h нечётно),   B_n - 1 (h чётно)
n = 2 (mod 4):                             min_c = B_n      (h нечётно),   B_n + 1 (h чётно)
```

Достаточные сдвиги: c = 1 при нечётном n; c = 0 при n чётном и h нечётном,
кроме n = 2 (mod 4), где при нечётном h берётся c = 1; c = 1 при n = 0 (mod 4)
и чётном h; c = 0 при n = 2 (mod 4) и чётном h. Это первая часть H10 (C27)
на семействе отражений. Вторая часть H10 (свободное сокращение, `<= B_n`)
здесь не рассматривается.

Зависимости: только определения N1 §§1–3 и `B_n = 2P - floor(n/2)` (C12).
Не используется ни C16, ни C18 (для неравенства не нужна корректность
слова — только значения F_c, S_c и стоимость маршрута); для утверждения
`d(pi) <= B_n + 1` на отражениях нужны дополнительно C18 (слово длины
`2F_c - S_c + H(c)` сортирует pi) — оно PROVED.

## Лемма 1 (циклы f_c)

`f_c(i) = h' - i`, где `h' = h + c mod n`. Это инволюция; её нетривиальные
циклы — транспозиции {i, h' - i}, неподвижные точки — решения `2i = h'`.
Число неподвижных точек: 1 при нечётном n (i = h'/2 в Z_n); при чётном n —
2, если h' чётно (i = h'/2 и i = h'/2 + n/2), и 0, если h' нечётно.
Число транспозиций K_c:

```text
n нечётно: (n-1)/2;    n чётно, h' чётно: (n-2)/2;    n чётно, h' нечётно: n/2.
```

Доказательство: `f_c(f_c(i)) = h' - (h' - i) = i`; уравнение `2i = h'` в Z_n
имеет одно решение при нечётном n (2 обратимо) и при чётном n — два решения,
если h' чётно, и ни одного, если нечётно.

## Лемма 2 (F_c)

Для транспозиции {a, b} оба шага — кратчайшие, `F = 2 delta_n(a, b)`
(антиподальная: оба шага +n/2, F = n = 2 delta_n). Поэтому
`F_c = sum_i delta_n(i, h' - i) = sum_i delta_n(2i, h')` (неподвижные точки
дают 0). Значения:

```text
n нечётно:                    F_c = P
n = 0 (mod 4):                F_c = P                 (обе чётности h')
n = 2 (mod 4):                F_c = P - 1 (h' чётно),  P + 1 (h' нечётно)
```

Доказательство. При нечётном n отображение `i -> 2i` — биекция Z_n, и
`F_c = sum_x delta_n(x, h') = sum_x delta_n(x, 0) = P`. При чётном n,
m = n/2, значения 2i пробегают чётные вычеты, каждый дважды:
`F_c = 2 sum_{j=0}^{m-1} delta_n(2j, h')`.

- h' = 2a чётно: `delta_n(2j, 2a) = 2 delta_m(j, a)`, сумма равна
  `2 * 2 floor(m^2/4)`, то есть `F_c = 4 floor(m^2/4)`: `m^2 = P` при чётном m
  (n = 0 mod 4) и `m^2 - 1 = P - 1` при нечётном m (n = 2 mod 4).
- h' нечётно: расстояния от h' до чётных вершин — нечётные числа
  1, 1, 3, 3, ..., по два каждое, не превосходящие m; при чётном m это
  1, 1, ..., m-1, m-1 с суммой `2 (m/2)^2 = m^2/2`, `F_c = m^2 = P`; при
  нечётном m — 1, 1, ..., m-2, m-2 и одно расстояние m (антипод h' + m чётен),
  сумма `2 ((m-1)/2)^2 + m = (m^2 + 1)/2`, `F_c = m^2 + 1 = P + 1`.

## Лемма 3 (S_c)

Для любой транспозиции S = 3 (C24, PROBLEM §5.3): неантиподальная — шаги d и
-d по одной дуге, нагрузка 2 на её рёбрах, M = 2, один переход `- -> +`,
t = 1, E = 0, S = 2·2 + 0 - 1 = 3; антиподальная — оба шага +n/2, все
нагрузки 1, M = 1, t = 0, E = 2, S = 2 + 2 - 1 = 3. Поэтому `S_c = 3 K_c`.

## Лемма 4 (выбор сдвига)

`H(0) = n`, `H(1) = n - 1` (N1 §3), `R_c <= H(c)` (маршрут N1 посещает все
вершины, в том числе переносчики, и заканчивается в c; R_c — минимум по
таким прогулкам). Используем `B_n = 2P - floor(n/2)` (C12: при чётном n
`2P - n/2 = n(n-1)/2`, при нечётном `2P - (n-1)/2 = (n^2 - 1 - n + 1)/2`).

- n нечётно, c = 1: `2P - 3(n-1)/2 + (n - 1) = 2P - (n-1)/2 = B_n`.
- n = 0 (mod 4), h нечётно, c = 0 (h' нечётно, K = n/2):
  `2P - 3n/2 + n = B_n`. h чётно, c = 1 (h' нечётно): `2P - 3n/2 + n - 1 = B_n - 1`.
- n = 2 (mod 4), h нечётно, c = 1 (h' чётно, F = P - 1, K = (n-2)/2):
  `2(P-1) - 3(n-2)/2 + (n-1) = 2P - n/2 = B_n`.
  h чётно, c = 0 (h' чётно): `2(P-1) - 3(n-2)/2 + n = B_n + 1`.

Это доказывает `<= B_n + 1` во всех случаях и точные значения из
утверждения как верхние оценки. Точность для выражения с H(c): при
нечётном n все c дают `2P - 3(n-1)/2 + H(c) >= B_n`, так как `H(c) >= n - 1`;
при n = 0 (mod 4) значение равно `2P - 3n/2 + H(c)` (h' нечётно) или
`2P - 3n/2 + 3 + H(c)` (h' чётно), и `H(c) >= n - 1` с равенством только при
c = ±1, что при чётном h даёт нечётное h' и B_n - 1, а при нечётном h
требует чётного c, то есть `H(c) >= n`, итого B_n; при n = 2 (mod 4) и чётном
h: нечётное c даёт h' нечётно, `2P + 2 - 3n/2 + H(c) >= B_n + 1`; чётное c
даёт h' чётно и `H(c) >= n`, `2P - 3n/2 + 1 + H(c) >= B_n + 1`. Все равенства
достигаются при указанных c. ∎

## Замечания к части 1

1. Для варианта с маршрутом R_c значение может быть меньше, чем с H(c),
   но не всегда: при n = 2 (mod 4) и чётном h с `2 <= h <= n/2 - 1` минимум
   `min_c [2F_c - S_c + R_c]` равен ровно B_n + 1 при всех 6 <= n <= 58
   (`data/runs/check_C28/report.json`, поле `R_route_plus_one_cases`),
   а при h = 0 и `h >= n/2` — не выше B_n. Значит, «+1» в первой части H10
   не улучшается до «<= B_n» для несокращённого слова варианта: оценка
   точна на бесконечном (по данным) семействе. Улучшение до B_n даёт только
   свободное сокращение — часть 2 ниже.
2. Аргумент использует лишь то, что F_c и S_c зависят от c только через
   чётность h', а H(c) минимально при c из {0, ±1}. Для произвольной pi
   ни одно из этих свойств не выполняется (см. `docs/notes/h10_verdict.md`).

## Часть 2 (после свободного сокращения): `<= B_n` на всех отражениях

**Утверждение.** Для всех n >= 4 и всех h из Z_n свободное сокращение слова
варианта (маршрут по переносчикам, сдвиг c из части 1 или c ниже в
исключительном случае) даёт слово длины `<= B_n`, сортирующее pi_h.
Следствие: `d(pi_h) <= B_n` для всех отражений; в частности `d(sigma_n) <= B_n`
(C9, h = 1) и `d(rev_n) <= B_n` (h = n - 1).

Случаи 1-4 части 1 (n нечётно; n = 0 mod 4) уже дают `<= B_n` без сокращения
(значение леммы 4 равно 0 или -1) — часть 2 в них тривиальна. Остаётся
случай n = 2 (mod 4), h чётно, где часть 1 даёт ровно B_n + 1 при c = 1.

**Лемма 5 (слово антиподальной транспозиции оканчивается на L).** Пусть
n = 2m и {a, a+m} — антиподальная транспозиция (единственный тип
транспозиции с обоими шагами +m, лемма 3 части 1: возможна только при h'
чётном и m нечётном, т.е. здесь при n = 2 mod 4). В координатах переносчика
a оба шага равны +m; по построению `local_word` (стягивание e_0 = m-1,
e_1 = m, оба положительны, вставленная между блоками X сокращается с первой
буквой второго блока, поскольку исходящий шаг из a_1 положителен) слово
имеет вид `(XL)^{m-1} L (XL)^{m-1}`, длины `4m - 3 = 2F - S` (F = 2m, S = 3),
и его последняя буква — L. (Проверено вычислением `local_word` для
n = 6, m = 3: слово `XLXLLXLXL`, действительно `(XL)^2 L (XL)^2`.)

**Случай 5 (n = 2 mod 4, h чётно, h' = h+1 нечётно при c = 1).** Здесь
неподвижных точек нет и K = m — все m/… транспозиции; так как m нечётно
и h' нечётно, `h' - 2i ≡ m` имеет решение (лемма 3 части 1: антипод
существует при h' ≡ m mod 2, что здесь верно), то есть ровно одна
антиподальная пара {a, a+m} с переносчиком a = наименьшим представителем
в [0, m). Маршрут `carrier_route` для c = 1 идёт в длинную сторону
(`R^{n-1}`, все буквы R, лемма 2 части 1) и посещает a при некотором шаге.
Если a = 1, слово начинается с W_a и обходит все остальные переносчики
идя дальше по R — a = 1 равносильно h' ≡ m + 2 (mod n), то есть h ≡ m + 1;
этот подслучай выделен как случай 6. Иначе (`a != 1`, включая a = 0) слово
`W_a` вставлено в маршрут и непосредственно за ним следует буква R (маршрут
не заканчивается в a). По лемме 5 `W_a` оканчивается на L, так что в полном
слове есть смежная пара `LR`; свободное сокращение снимает эту пару (и,
возможно, дальнейшие внутренние пары), уменьшая длину минимум на 2:
`B_n + 1 - 2 = B_n - 1 <= B_n`. (Вычисление подтверждает точное значение
B_n - 1: `data/runs/check_C28` §2.)

**Случай 6 (n = 2 mod 4, h ≡ m + 1 mod n).** Тогда h чётно (m нечётно), и
при c = 1 переносчик антиподальной пары — это a = 1: маршрут `R^{n-1}`
начинается с W_1, за которым сразу идёт первая буква маршрута — тоже R,
и никакой соседней пары LR/RL нет по этой причине. Вместо этого берём
c = 2, h' = h + 2 = m + 3 (чётно): по лемме 5 части 1 `2F - S = B_n - n + 1`;
антиподальных пар нет вовсе (h' чётно и m нечётно нарушает условие леммы 3
части 1 для существования антипода), и вершина 1 не является переносчиком
никакой транспозиции (переносчик неантиподальной транспозиции — начало
положительного шага, лемма о выборе переносчика; шаг из 1 при отображении
h' - i равен `(h' - 2) mod n = m + 1 > m`, то есть отрицательный шаг).
Маршрут в длинную сторону из 0 в c = 2 имеет длину `R_2 <= n - 2` (лемма 2
части 1), и уже без сокращения `2F - S + R_2 <= B_n - n + 1 + n - 2 = B_n - 1`.

Случаи 5 и 6 покрывают весь оставшийся случай части 1; в обоих итоговая
длина после сокращения (когда оно нужно) не превосходит B_n. ∎

**Замечание.** Формулировка выше и механизм (антиподальное слово оканчивается
на L, смежная буква маршрута — R) воспроизводят независимо найденный
результат параллельной сессии (PR #5, ветка `claude/busy-turing-s5bvjj`,
тот же файл под тем же именем с иным содержанием — расхождение отмечено
в LOGS.md сессии 4). Здесь лемма 5 и разбор случаев 5-6 получены заново
из уже существующего в этой ветке `local_word`/`carrier_route`
(`constructions/strict_upper.py`), не скопированы из PR #5, и проверены
экспериментально по всему диапазону §2 независимым запуском.

## Машинная сверка

`checks/check_C28.py --nmax 60`: для всех n из [4, 60], всех h и всех c
формулы лемм 1–3 совпали с величинами K_c, F_c, S_c, вычисленными
конструкцией `strict_upper-1.0` по определениям N1 (нагрузки перечислением

леммы 4 и минимум по c выражения с H(c) совпали с утверждением точно;
минимум с R_c не превосходит B_n + 1. Итого 73 796 троек (n, h, c), 16 с.
