# C28 — конструкция N1 с маршрутом по переносчикам на отражениях: `d(pi) <= B_n`

Сессия 4, 12.09.2026. Формат — PLAN §9.11. Чекер: `checks/check_C28.py`
(отчёт `data/runs/check_C28/`). Ядро oracle-1.0, конструкция
`constructions/strict_upper.py` (strict_upper-1.0). Зависимости: N1 §§1–3
(C18, PROVED локально — локальные слова и сшивка циклов); ниже используется
только та часть N1, которая не зависит от маршрута H(c).

## 0. Утверждение

Отражение с параметром h: `pi_h(i) = h − i (mod n)`, `h` из Z_n. В частности
`sigma_n = pi_1`, `rev_n = pi_{n−1}`. Обозначения N1 (PROBLEM §5.2):
`f_c(i) = pi(i) + c`, F_c, S_c — суммы по нетривиальным циклам f_c,
`P = floor(n^2/4)`, `B_n = n(n−1)/2`, `m = floor(n/2)`.

**Вариант конструкции** (правило 16 AGENTS.md; реализация `shift_word(pi, c,
route="carrier")`): локальные слова N1 §2 применяются при первом посещении
переносчика; внешний маршрут — произвольная прогулка по Z_n из 0 через все
переносчики в c; R_c — длина кратчайшей такой прогулки. Длина слова равна
`2F_c − S_c + R_c`.

**Теорема C28.** Для всех n >= 4 и всех h из Z_n:

1. существует c с `2F_c − S_c + R_c <= B_n + 1`; при этом `<= B_n`, кроме
   случая `n ≡ 2 (mod 4)`, `h` чётно;
2. в этом исключительном случае найдётся c, при котором слово варианта имеет
   длину `B_n + 1` или меньше и содержит пару соседних букв `LR`; его свободное
   сокращение сортирует pi_h и имеет длину `<= B_n`.

**Следствие.** `d(pi_h) <= B_n` для всех n >= 4 и всех h; в частности
`d(sigma_n) <= B_n` (C9) и `d(rev_n) <= B_n`. Это верхние оценки; равенство
`d(sigma_n) = B_n` требует нижней оценки C8.

Точнее, для sigma_n выбранный сдвиг даёт слово с `N_X = floor((n−1)^2/4)`
(лемма 8), то есть с расщеплением геодезических C13v.

Замечание о конвенциях. Подписанный кратчайший шаг `−n/2 < d <= n/2`,
антиподальный шаг положителен (правило 16). Переносчик однонаправленного
цикла — любая его вершина (N1 §2.1); в реализации `cycles_of` начинает
цикл с наименьшего номера, поэтому переносчик антиподальной транспозиции
`{a, a+m}` — её меньший представитель `a` из `[0, m)`. Доказательство
ниже привязано к этому выбору там, где это существенно (случай 5).

## 1. Леммы

**Лемма 1 (сшивка с произвольным маршрутом; N1 §3, (3.1)–(3.2)).**
Пусть pi из S_n, c из Z_n, и для каждого нетривиального цикла C
отображения f_c построено локальное слово W_C N1 §2 в координатах его
переносчика b_C. Пусть маршрут — любая прогулка головы по Z_n из 0 в c,
посещающая все b_C. Тогда слово, полученное вставкой W_C при первом
посещении b_C, сортирует pi и имеет длину `2F_c − S_c + (длина маршрута)`.

*Доказательство.* Дословно N1 §3: если текущий массив имеет вид
`p ∘ rho_b` (голова в позиции b), то применение W_C даёт `p ∘ C^{−1} ∘ rho_b`
(3.1) — локальное слово меняет только цикл C в исходных координатах и не
меняет положения головы. Циклы f_c непересекающиеся, поэтому произведение
`C^{−1}` по всем циклам в любом порядке равно `f_c^{−1}`; после конечного
позиционирования в c массив равен `pi ∘ f_c^{−1} ∘ rho_c = 1` (3.2).
Ни (3.1), ни (3.2) не используют форму маршрута; N1 лишь предъявляет
конкретную прогулку длины H(c). Длина: `sum |W_C| = 2F_c − S_c` по (2.6)
(в реализации равенство проверяется assert'ом на каждом цикле). ∎

**Лемма 2 (обход в длинную сторону).** Пусть `delta = delta_n(0, c)`.
Прогулка из 0 в c по длинной дуге имеет длину `n − delta` и посещает все
вершины, кроме лежащих строго внутри короткой дуги между 0 и c (при c = 0 —
полный оборот длины n, посещающий все вершины). Следовательно,
`R_0 <= n`, `R_{±1} <= n − 1`, и `R_{±2} <= n − 2`, если ±1 не переносчик.

*Доказательство.* Прямая проверка: при c = 1 прогулка `R^{n−1}` проходит
0, n−1, n−2, …, 1 — все n вершин; при c = 2 прогулка `R^{n−2}` проходит
все вершины, кроме 1. ∎

**Лемма 3 (циклы отражения).** `f_c = pi_{h'}` с `h' = h + c`. Неподвижные
точки — решения `2i ≡ h' (mod n)`: одна при нечётном n; при чётном n —
ни одной, если h' нечётно, и две (`h'/2`, `h'/2 + m`), если h' чётно.
Остальные элементы разбиты на транспозиции `{i, h' − i}`; их число
`K = (n − fix)/2`. Транспозиция антиподальна тогда и только тогда, когда
`h' − 2i ≡ m (mod n)`; при чётном n это возможно только при `h' ≡ m (mod 2)`.

**Лемма 4 (транспозиция; C24).** Для транспозиции {a, b} c
`d = delta_n(a, b)`: `F = 2d`, `S = 3`. Неантиподальная: шаги +d и −d
проходят одни и те же d рёбер, `M = 2`, один переход `−→+` (в начале
положительного шага), `t = 1`, `E = 0`, `S = 4 + 0 − 1 = 3`; переносчик —
начало положительного шага (N1 §2.1: начало участка нагрузки M).
Антиподальная (n = 2m, d = m): оба шага +m, `M = 1`, `t = 0`, `E = 2`,
`S = 2 + 2 − 1 = 3`.

**Лемма 5 (F_c и S_c отражения).** `F_c = sum_i delta_n(2i, h')`,
`S_c = 3K`. Явно:

| n | h' | fix | K | F_c | 2F_c − S_c |
|---|---|---|---|---|---|
| нечётное | любое | 1 | (n−1)/2 | P | B_n − (n − 1) |
| ≡ 0 (mod 4) | нечётное | 0 | m | P | B_n − n |
| ≡ 0 (mod 4) | чётное | 2 | m − 1 | P | B_n − n + 3 |
| ≡ 2 (mod 4) | нечётное | 0 | m | P + 1 | B_n − n + 2 |
| ≡ 2 (mod 4) | чётное | 2 | m − 1 | P − 1 | B_n − n + 1 |

*Доказательство.* Элемент i транспозиции {i, h'−i} вносит в F ровно
`delta_n(i, h' − i) = delta_n(2i, h')` (лемма 4: F = 2d, по d на каждый из
двух элементов); неподвижная точка вносит 0, и для неё `delta_n(2i, h') = 0`.
Отсюда первая формула. Суммы:

- n нечётно: `i -> 2i` — биекция Z_n, сумма расстояний от h' до всех
  вершин равна `P = (n^2 − 1)/4`.
- n = 2m: 2i пробегает чётные вычеты, каждый дважды; `F_c = 2 sum_{j чётн.}
  delta_n(j, h')`. При нечётном h' расстояния от h' до чётных вершин —
  нечётные числа 1, 3, …, каждое дважды, кроме m при нечётном m (антипод h'
  чётен, одна вершина): m чётно — `2(1 + 3 + … + (m−1)) = m^2/2`;
  m нечётно — `2(1 + … + (m−2)) + m = (m^2 + 1)/2`. При чётном h'
  расстояния 0, 2, 4, …, причём 0 один раз и m один раз при чётном m:
  m чётно — `2(2 + … + (m−2)) + m = m^2/2`; m нечётно —
  `2(2 + … + (m−1)) = (m^2 − 1)/2`. Умножение на 2 даёт столбец F_c
  (`P = m^2` при чётном n).
- `S_c = 3K` по лемме 4; K — по лемме 3. Последний столбец — подстановка
  `B_n = 2P − m` (n чётно), `B_n = 2P − (n−1)/2` (n нечётно). ∎

**Лемма 6 (слово антиподальной транспозиции).** n = 2m, транспозиция
`{a, a+m}` с переносчиком a. В координатах переносчика шаги +m, +m;
после стягивания `e_0 = m − 1` (дуга 0 → m проходит ребро {0,1}),
`e_1 = m` (дуга m → 0 его не проходит). Слово (2.4):
`(XL)^{m−1} X (XL)^m`; исходящий шаг вершины a_1 положителен, поэтому
вставленная X сокращается с первой X следующего блока:

```text
W = (XL)^{m−1} L (XL)^{m−1},   |W| = 4m − 3 = 2F − S,   последняя буква L.
```

**Лемма 7 (слово неантиподальной транспозиции).** Переносчик a, шаг +d,
`1 <= d < n/2`: `e_0 = d − 1`, `e_1 = −(d − 1)`; в вершине a_1 переход
`+→−`, сокращения нет: `W = (XL)^{d−1} X (RX)^{d−1}`, `|W| = 4d − 3`,
`N_X(W) = 2d − 1`; при d = 1 слово — одна буква X. Первая и последняя
буквы — X.

**Лемма 8 (число обменов).** `N_X` полного слова равно сумме `N_X(W_C)`:
`2d − 1` на неантиподальную транспозицию с шагом d и `2m − 2` на
антиподальную. Для sigma_n при выбранном ниже сдвиге (нечётное n: c = 1,
`h' = 2`; n ≡ 0 (mod 4): c = 0, `h' = 1`; n ≡ 2 (mod 4): c = 1, `h' = 2`)
все транспозиции неантиподальны (n нечётно; n ≡ 0 (mod 4), h' нечётно и
m чётно — лемма 3; n ≡ 2 (mod 4), h' чётно и m нечётно — лемма 3), поэтому
`N_X = F_c − K = P − (n−1)/2 = ((n−1)/2)^2` (n нечётно),
`P − m = m^2 − m = ((n−1)^2 − 1)/4` (n ≡ 0 mod 4),
`P − 1 − (m − 1) = m^2 − m` (n ≡ 2 mod 4), то есть `floor((n−1)^2/4)`.
Свободное сокращение снимает только пары LR/RL на стыках (лемма 6) и не
меняет N_X.

## 2. Доказательство теоремы

Во всех случаях длина слова оценивается леммой 1 как
`2F_c − S_c + R_c`, `2F_c − S_c` берётся из леммы 5, R_c — из леммы 2.

**Случай 1: n нечётно.** c = 1, `h' = h + 1`: `2F − S = B_n − (n−1)`,
`R_1 <= n − 1`. Итого `<= B_n`.

**Случай 2: n ≡ 0 (mod 4), h чётно.** c = 1, h' нечётно: `B_n − n + (n − 1)
= B_n − 1`.

**Случай 3: n ≡ 0 (mod 4), h нечётно.** c = 0, `h' = h` нечётно:
`B_n − n + n = B_n`.

**Случай 4: n ≡ 2 (mod 4), h нечётно.** c = 1, h' чётно: `B_n − n + 1 +
(n − 1) = B_n`.

**Случай 5: n ≡ 2 (mod 4), h чётно, `h ≢ m + 1 (mod n)`.** c = 1, h'
нечётно: `B_n − n + 2 + (n − 1) = B_n + 1` — часть 1 с +1. Часть 2:
маршрут леммы 2 — `R^{n−1}`, все буквы R. Так как h' нечётно и m нечётно,
`h' − m` чётно, и антиподальная пара `{a, a+m}` с `2a ≡ h' − m` существует
(лемма 3); её переносчик — представитель `a` из `[0, m)`; `a = 1` равносильно
`h' ≡ m + 2`, то есть `h ≡ m + 1`, что исключено. Если a = 0, слово
начинается с `W_a`, за которым идёт первая буква маршрута R; если
`2 <= a <= m − 1`, слово `W_a` вставлено при посещении a и за ним следует
очередная буква R (a ≠ 1 — не конец маршрута). По лемме 6 `W_a`
оканчивается на L, поэтому слово содержит пару LR; свободное сокращение
даёт слово длины `<= B_n − 1`, которое сортирует pi_h (сокращение не
меняет действия).

**Случай 6: n ≡ 2 (mod 4), `h ≡ m + 1 (mod n)`** (h чётно, так как m нечётно;
здесь n >= 6, m >= 3). c = 2, `h' = m + 3` чётно: `2F − S = B_n − n + 1`.
Антиподальных пар нет (лемма 3: h' чётно, m нечётно). Вершина 1 — не
переносчик: переносчик неантиподальной транспозиции — начало её
положительного шага (лемма 4), а шаг из 1 равен `(h' − 2) mod n = m + 1 > m`,
то есть не положителен. По лемме 2 `R_2 <= n − 2`, итого `<= B_n − 1`.

Случаи 1–6 покрывают все n >= 4 и все h. Часть 1 доказана с `<= B_n` во всех
случаях, кроме 5, где `<= B_n + 1`; часть 2 — случай 5. Следствие: слово
(в случае 5 — сокращённое) — допустимое слово в алфавите {L, R, X},
сортирующее pi_h, длины `<= B_n`, поэтому `d(pi_h) <= B_n`. ∎

## 3. Что доказано и что нет

- Доказана верхняя оценка `d(pi_h) <= B_n` для всех отражений при всех n >= 4
  — в частности C9 (`d(sigma_n) <= B_n`), ранее CLAIMED по S2. Это локальное
  доказательство, зависящее от N1 §§1–3 (C18, PROVED локально) и лемм выше.
- Не доказано равенство: `d(sigma_n) = B_n` требует C8.
- Теорема — про отражения; на других входах вариант с маршрутом по
  переносчикам оценки `B_n + O(1)` не даёт (H10 REFUTED, см.
  `data/runs/h10_verdict/report.md`): аффинные входы `pi(i) = a·i + b`
  дают `min_c [2F_c − S_c + R_c] = B_n + 3` при n = 18 и растущий избыток.
- Данные карты потерь (`data/runs/strict_loss_audit/report.md`, §Семейства)
  согласуются с разбором: при нечётном n `Q_R − B_n = 0` для всех h; при
  n ≡ 0 (mod 4) значения −1 (h чётно) и 0 (h нечётно) в диапазоне малых h;
  единственные отражения с `Q_R = B_n + 1` — n ≡ 2 (mod 4), h чётно.
  Исправление к тому отчёту: при n = 6, h = 2 после сокращения получается
  14 (c = 1), а не 15 — сокращение снимает пары букв.

## 4. Машинная сверка (`checks/check_C28.py`)

Для всех h при 4 <= n <= 64 (и sigma_n при n <= 200): выбранный по случаям
сдвиг c, слово `shift_word(pi_h, c, "carrier")` (сортировка проверяется
эталонными ходами), равенства F_c, S_c, fix, K из лемм 3 и 5, тождество
`F_c = sum_i delta_n(2i, h')`, `R_c <= n − delta_n(0, c)` (лемма 2),
в случае 5 — положение антиподального переносчика, форма его слова (лемма 6)
и наличие пары LR на стыке; в случае 6 — `1` не переносчик; длина слова и
длина после сокращения против правой части; `N_X` для sigma_n (лемма 8).
Отдельно (только отчёт): минимум по всем c против выбранного c при n <= 40.
Конечная проверка удостоверяет реализацию и формулы на диапазоне; общий
аргумент — §2.
