# H10 (C27) на отражениях: точные формулы F_c, S_c и статус R_c

Сессия 4 (13.09.2026), продолжение направления §4.2 (PLAN §8), 1-я из
2 бюджетных сессий на H10. Ядро oracle-1.0, конструкция strict_upper-1.0.

Цель: доказать `min_c [2F_c - S_c + R_c] <= B_n + 1` для отражений
`pi_h(i) = (h - i) mod n` явно, алгебраически (не только численно).
F_c и S_c доказаны ниже в замкнутом виде. R_c (маршрут по переносчикам,
`carrier_route`) явной формулы пока не имеет — раздел 3 объясняет
почему и что доказано вместо неё.

## 1. Структура циклов отражения

Для сдвига c пусть `m = (h + c) mod n`. Тогда `f_c(i) = pi_h(i) + c = m - i
(mod n)` — инволюция (`f_c(f_c(i)) = i`). Неподвижные точки: `2i = m (mod n)`.

- `n` нечётно: 2 обратимо mod n, ровно одна неподвижная точка
  `i0 = m * inv(2) mod n`; остальные `n-1` элементов образуют `(n-1)/2`
  двухэлементных циклов (транспозиций).
- `n` чётно, `m` чётно: две неподвижные точки `i0, i0 + n/2`; `(n-2)/2`
  транспозиций.
- `n` чётно, `m` нечётно: неподвижных точек нет (2i mod n принимает только
  чётные значения); `n/2` транспозиций.

## 2. F(C) и S(C) для транспозиции — точно 2*delta и 3

Пусть `{i, j}` — транспозиция, `j = (m - i) mod n`, `d = signed_step(i,j,n)`
(соглашение правила 16: антиподальный шаг положителен). Прямой шаг
`i -> j` равен `d`, обратный `j -> i` равен `-d` при `|d| < n/2` и снова
`+n/2` в антиподальном случае `d = n/2` (оба шага получают знак `+` по
правилу 16, поскольку раскрутка в обе стороны имеет длину ровно `n/2`).

Отсюда для любой транспозиции:

- `F(C) = |d| + |d| = 2*delta_n(i,j)` (delta_n — беззнаковое расстояние
  по окружности, `1 <= delta_n <= n/2`).
- Нагрузка рёбер: при `|d| < n/2` обе дуги (`i->j` и `j->i`) проходят по
  ОДНОМУ и тому же набору из `|d|` рёбер (в противоположных направлениях),
  так что каждое из них нагружено дважды, остальные — нулём: `M(C) = 2`.
  При `d = n/2` дуги `i->j` и `j->i` идут в ОДНОМ направлении и вместе
  покрывают весь цикл по одному разу каждое ребро: `M(C) = 1`.
- `t(C)`: при `|d| < n/2` шаги `(d, -d)` разного знака дают ровно один
  переход `-->+` на цикле длины 2, значит `t(C) = 1`, `E(C) = 2 - 2 = 0`.
  При `d = n/2` оба шага положительны, переходов `-->+` нет: `t(C) = 0`,
  `E(C) = 2`.
- `S(C) = 2M(C) + E(C) - 1`: неантиподальный случай `2*2+0-1 = 3`;
  антиподальный `2*1+2-1 = 3`. **Одно и то же значение в обоих случаях.**

Итог: `F(C) = 2*delta_n(i,j)`, `S(C) = 3`, для любой нетривиальной
транспозиции отражения, без исключений. Локальная длина слова этой
транспозиции равна `2F(C) - S(C) = 4*delta_n(i,j) - 3`.

## 3. F_c и S_c в замкнутом виде

`F_c(p) = sum_i delta_n(i, (p[i]+c) mod n)` (тождество PROBLEM §7, не
зависит от структуры циклов) даёт для отражения:

```text
F_c = sum_{i=0}^{n-1} delta_n(0, m - 2i mod n).
```

**n нечётно.** `2` обратимо mod n, поэтому `m - 2i mod n` пробегает ВСЕ
вычеты `0..n-1` по одному разу при `i = 0..n-1`. Значит

```text
F_c = sum_{r=0}^{n-1} delta_n(0,r) = floor(n^2/4) = P,
```

**не зависит ни от m (то есть ни от h, ни от c), ни от чего ещё.**
Число транспозиций `(n-1)/2` даёт `S_c = 3(n-1)/2` — точно совпадает
с C24 (`s = 3(n-1)/2` на отражениях при нечётном n; здесь показано, что
это именно значение при каждом c, а не только среднее `overline(S_c)`).

**n чётно.** `2i mod n` пробегает только чётные вычеты, каждый по два
раза. Пусть `N = n/2`. Раскладка по чётности вычета `r`:

```text
sum_{r even, 0<=r<n} delta_n(0,r) = 2 * sum_{k=0}^{N-1} min(k, N-k) = 2*floor(N^2/4)
sum_{r odd,  0<=r<n} delta_n(0,r) = P - 2*floor(N^2/4)      (P = N^2)
```

При `m` чётном `F_c = 2 * 2*floor(N^2/4) = 4*floor(N^2/4)`; при `m`
нечётном `F_c = 2*(N^2 - 2*floor(N^2/4))`.

- `N` чётно (`n = 0 mod 4`): `floor(N^2/4) = N^2/4` точно, обе формулы
  дают `F_c = N^2 = P` — **F_c не зависит от чётности m** при `n = 0
  mod 4`, то есть совпадает со случаем нечётного n (F_c = P всегда).
- `N` нечётно (`n = 2 mod 4`): `floor(N^2/4) = (N^2-1)/4`, значит
  `F_c(m чёт) = N^2 - 1 = P - 1`, `F_c(m нечёт) = N^2 + 1 = P + 1`.
  Разница ровно 2, зависит только от чётности m, то есть от чётности
  `h + c`.

**Уточнение к LOGS.md (сессия 3).** Запись сессии 3 гласит «на отражениях
усредняется именно H(c): F_c постоянна по c» — это верно только при `n`
нечётном или `n = 0 mod 4`; при `n = 2 mod 4` F_c принимает ровно два
значения `P-1`/`P+1` по чётности `h+c` (проверено на sigma_n, `n=6,10`:
`F_c = 10,8,10,8,...` и `26,24,26,24,...`; при `n=9` действительно
константа `20 = P`). Формулировка сессии 3 требует этой поправки; вывода
о зазоре `n/4` в среднем по c (C24) поправка не меняет — там речь о
среднем `overline(S_c)`, а не о поведении `F_c`.

Число транспозиций: `(n-2)/2 = N-1` при m чётном (2 неподвижные точки),
`N` при m нечётном (0 неподвижных точек). `S_c = 3(N-1)` или `3N`
соответственно.

Проверено численно (см. §4) против `strict_upper.shift_word`, полное
совпадение при 4<=n<=24 без исключений — формулы выше не гипотеза,
а прямое следствие §§1-2 (PROVED).

## 4. R_c: что доказано, а что осталось

Маршрут по переносчикам — вариант (правило 16), лемм N1 к нему нет.
Явную формулу R_c(m,c,n) для отражений получить не удалось за бюджет
этой сессии: множество переносчиков (по одному на транспозицию, выбор
§2.1 — начало дуги с максимальной нагрузкой) образует на окружности два
кластера длины около `n/4` каждый (см. численные данные ниже), их
взаимное расположение зависит от `m` и `n mod 4` негладко.

Вместо замкнутой формулы установлено (`experiments/`, ядро oracle-1.0,
конструкция strict_upper-1.0, скрипт ниже):

```text
max_h min_c [2F_c - S_c + R_c] - B_n =
  1   если n = 2 (mod 4)
  0   иначе (n = 0, 1, 3 mod 4)
```

**VERIFIED явным перебором всех h, всех c при 4 <= n <= 71**
(`experiments/h10_reflections_check.py`, версия
h10_reflections_check-1.0; отчёт
`data/runs/strict_loss_audit/h10_reflections_check.json`; ранее было
подтверждено лишь при 4<=n<=9 (все pi) и семьями до n=12). Расширение
покрытия — прямой вклад к C27v: диапазон подтверждения увеличен более
чем на порядок, ни одного контрпримера к `<= B_n+1` не найдено, граница
`+1` достигается ровно на `n = 2 mod 4` (не только n=6, как было
отмечено в C27v по меньшему диапазону).

Итог для H10 на отражениях: `min_c [2F_c-S_c+R_c] <= B_n+1` для всех
проверенных `4 <= n <= 71`, с равенством `B_n+1` в точности при
`n = 2 mod 4`. Общее доказательство (для всех n) требует формулы R_c
или оценки `R_c <= n - 2*floor(n/4) + O(1)`-типа, что не получено;
шаг (1) плана §8 закрыт VERIFIED (не PROVED) на этом диапазоне.

## 5. Общий pi (шаг 2 плана §8): статус

Требуется связать `argmin_c F_c` (медианный сдвиг, тождество
`F_c = sum_i delta_n(i-pi(i), c)`) с `S_c` и `R_c` для произвольной pi.
Собственный маршрут `H(c)` для этого не годится (H9 REFUTED, C26).
За бюджет этой сессии продвижения не получено: препятствие то же, что
и на отражениях — нет замкнутой оценки `R_c` даже для одной конкретной
структуры циклов (транспозиции), поэтому для произвольного набора
циклов задача как минимум не проще. Худшие входы из
`data/runs/strict_loss_audit/perms_n9.json` не пересчитывались повторно
в этой сессии (без изменений с сессии 3).

Бюджет: использована 1 из 2 сессий H10. Следующий шаг — либо (a)
явная оценка R_c через положение кластеров переносчиков (продолжение
§4 здесь), либо (b) при неудаче в оставшуюся сессию — письменный
вердикт с найденным препятствием (отсутствие формулы/оценки R_c даже
на отражениях).
