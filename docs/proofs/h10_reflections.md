# H10 на отражениях: точная формула минимума по сдвигу (C28)

Редакция 13.09.2026 (сессия 4). Утверждения реестра: C28 (эта теорема),
C29 (лемма `S(C) >= 3`), C30 (достаточное условие общего случая).
Конвенции — PROBLEM §3, обозначения конструкции N1 — PROBLEM §5.2,
знаковое соглашение `-n/2 < d <= n/2` — AGENTS.md правило 16.
Машинная сверка — §6, чекер `checks/check_C28.py`, прогон
`data/runs/h10_reflections/`.

## 1. Обозначения

Для перестановки pi из S_n и сдвига c из Z_n положим `f_c(i) = pi(i) + c mod n`.
Для каждого нетривиального цикла C отображения f_c определены (N1 §1)
подписанные кратчайшие шаги d_j, величины F(C), M(C), t(C), `E(C) = |C| - 2t(C)`
и `S(C) = 2M(C) + E(C) - 1`. Далее

```text
F_c = sum_C F(C),   S_c = sum_C S(C),   K_c = число нетривиальных циклов f_c,
P   = floor(n^2/4), B_n = n(n-1)/2,
H(0) = n,  H(c) = n + delta_n(0,c) - 2  (c != 0)      — маршрут N1 §3,
R_c = длина кратчайшей прогулки по Z_n из 0 в c, проходящей через все
      переносчики нетривиальных циклов f_c                — вариант, правило 16.
```

По C18 (N1 §§2–3) слово конструкции при сдвиге c существует, сортирует pi
и имеет длину ровно `2F_c - S_c + H(c)`; вариант с маршрутом по переносчикам
даёт слово длины `2F_c - S_c + R_c` (порядок посещения переносчиков не важен
по (3.1), а `R_c <= H(c)`, см. лемму 6).

Отражение — перестановка `pi(i) = h - i mod n` при фиксированном h из Z_n;
при h = 1 это sigma_n.

## 2. Теорема

**Теорема 1.** Пусть n >= 4 и `pi(i) = h - i mod n`. Тогда

```text
min_c [2F_c - S_c + H(c)] - B_n =
    0    при нечётном n (при любом h),
   -1    при n = 0 (mod 4) и чётном h,
    0    при n = 0 (mod 4) и нечётном h,
   +1    при n = 2 (mod 4) и чётном h,
    0    при n = 2 (mod 4) и нечётном h.
```

**Следствие 1 (H10 на отражениях).** Для всех n >= 4 и всех отражений

```text
min_c [2F_c - S_c + R_c] <= min_c [2F_c - S_c + H(c)] <= B_n + 1,
```

то есть гипотеза H10 (C27) верна на семействе отражений при всех n >= 4.
Более того, на отражениях верна и та же оценка с собственным маршрутом N1
(форма H9, опровергнутая в общем случае контрпримером при n = 9, C26).

**Следствие 2 (C9).** `d(sigma_n) <= B_n` при всех n >= 4: при h = 1 значение
минимума равно B_n (n нечётно и n = 2 mod 4) или B_n (n = 0 mod 4, h = 1
нечётно), и это длина явно построенного сортирующего слова.

**Следствие 3.** `d(pi) <= B_n + 1` для любого отражения при всех n >= 4,
и `d(pi) <= B_n` для всех отражений, кроме случая `n = 2 (mod 4)`, h чётное.

Оговорка к следствиям 2–3: они опираются на C18 (локальный аудит N1, PROVED),
то есть на утверждение о длине и действии слова, а не на конечные прогоны.

## 3. Леммы

**Лемма 1 (F_c как сумма расстояний до c).** Для любых n >= 2, pi из S_n, c
из Z_n

```text
F_c = sum_{i in Z_n} delta_n(c, i - pi(i)).
```

*Доказательство.* Каждый i, не являющийся неподвижной точкой f_c, лежит ровно
в одном нетривиальном цикле, и выходящий из него подписанный шаг d
удовлетворяет `|d| = delta_n(i, f_c(i))`, поскольку шаг выбран кратчайшим.
Поэтому `F_c = sum_{i: f_c(i) != i} delta_n(i, pi(i) + c)`. Для неподвижной
точки `delta_n(i, pi(i) + c) = 0`, так что слагаемые можно добавить.
Остаётся `delta_n(i, pi(i)+c) = delta_n(0, pi(i)+c-i) = delta_n(c, i - pi(i))`
(сдвиг и симметрия delta_n). ∎

**Лемма 2 (мультимножество разностей отражения).** Для `pi(i) = h - i`
мультимножество `{i - pi(i) : i in Z_n}` равно `{2i - h : i in Z_n}` и

- при нечётном n это все элементы Z_n, каждый один раз;
- при чётном n это все вычеты одной чётности с h, каждый два раза.

*Доказательство.* При нечётном n отображение `i -> 2i` — биекция Z_n.
При чётном n `2i` пробегает чётные вычеты, каждый ровно дважды
(`i` и `i + n/2`); `2i - h` имеет чётность h, так как `-h = h (mod 2)`. ∎

**Лемма 3 (F_c на отражении).** Пусть `pi(i) = h - i`, n >= 4. Тогда

```text
n нечётное:      F_c = P при всех c;
n = 0 (mod 4):   F_c = P при всех c;
n = 2 (mod 4):   F_c = P - 1 при c = h (mod 2),  F_c = P + 1 иначе.
```

*Доказательство.* По леммам 1 и 2.

Нечётное n: `F_c = sum_{a in Z_n} delta_n(c,a) = 2(1 + 2 + ... + (n-1)/2)
= (n^2-1)/4 = P`.

Чётное `n = 2m` (тогда `P = m^2`). Если `c = h (mod 2)`, разности — это в точности вычеты
`c + 2j`, `j = 0..m-1`, каждый дважды, и
`delta_n(c, c+2j) = min(2j, n-2j) = 2 min(j, m-j)`, поэтому

```text
F_c = 4 * sum_{j=0}^{m-1} min(j, m-j) = 4 * floor(m^2/4)
    = m^2 = P            (m чётное, то есть n = 0 mod 4),
    = m^2 - 1 = P - 1    (m нечётное, то есть n = 2 mod 4).
```

Если `c != h (mod 2)`, разности — вычеты `c + 1 + 2j`, `j = 0..m-1`, каждый
дважды, и `delta_n(c, c+1+2j) = min(2j+1, 2m-2j-1)`. Набор этих значений при
`j = 0..m-1` равен `1,3,...,m-1,m-1,...,3,1` при чётном m и
`1,3,...,m-2,m,m-2,...,3,1` при нечётном m, откуда сумма равна `m^2/2`
и `(m^2+1)/2` соответственно, а `F_c = m^2 = P` и `F_c = m^2 + 1 = P + 1`. ∎

**Лемма 4 (строение f_c и K_c).** Для отражения `f_c(i) = g - i`, где
`g = h + c`. Это инволюция; её нетривиальные циклы — транспозиции
`{i, g-i}`, неподвижные точки — решения `2i = g (mod n)`. Поэтому

```text
n нечётное:            одна неподвижная точка,  K_c = (n-1)/2;
n = 2m, g чётное:      две неподвижные точки,   K_c = m - 1;
n = 2m, g нечётное:    неподвижных точек нет,   K_c = m.
```

*Доказательство.* `f_c(f_c(i)) = g - (g - i) = i`. Уравнение `2i = g` имеет
одно решение при нечётном n (2 обратимо), при чётном n — два решения, если
g чётно, и ни одного, если g нечётно. ∎

**Лемма 5 (S = 3 у любой транспозиции).** Пусть C = {a,b} — транспозиция
(нетривиальный цикл длины 2) при n >= 3. Тогда `S(C) = 3`; при этом
`M = 2, E = 0` в неантиподальном случае и `M = 1, E = 2` в антиподальном
(n чётно, `b = a + n/2`). Следовательно, для отражения `S_c = 3 K_c`.

*Доказательство.* Неантиподальный случай: подписанные шаги равны d и -d
с `0 < |d| < n/2`, обе дуги проходят один и тот же кратчайший путь между a и b
в противоположных направлениях, поэтому нагрузка равна 2 на его |d| рёбрах
и 0 на остальных: `M = 2`. Ровно в одной из двух вершин входящий шаг
отрицателен, а исходящий положителен, поэтому `t = 1`, `E = 2 - 2 = 0`
и `S = 2*2 + 0 - 1 = 3`.

Антиподальный случай (правило 16): оба шага равны `+n/2`. Тогда `t = 0`,
`E = 2`; первая дуга проходит рёбра `a, ..., a + n/2 - 1`, вторая —
`a + n/2, ..., a + n - 1`, вместе каждое ребро кольца ровно один раз, поэтому
`M = 1` и `S = 2*1 + 2 - 1 = 3`. ∎

**Лемма 6 (маршрут).** `R_c <= H(c)` при всех c, причём `H(0) = n`,
`H(1) = n - 1`, `H(2) = n` при n >= 4.

*Доказательство.* Маршрут N1 §3 (C18) — это прогулка из 0 в c, посещающая
все вершины кольца, значит и все переносчики; её длина равна H(c). R_c —
минимум по всем таким прогулкам, поэтому `R_c <= H(c)`. Значения H:
по определению `H(1) = n + delta_n(0,1) - 2 = n - 1`,
`H(2) = n + delta_n(0,2) - 2 = n` (при n >= 4 имеем `delta_n(0,2) = 2`). ∎

**Лемма 7 (тождество для B_n).** `2P - B_n = floor(n/2)`.

*Доказательство.* `n = 2m`: `2m^2 - m(2m-1) = m`. `n = 2m+1`:
`2(m^2+m) - m(2m+1) = m`. ∎

## 4. Доказательство теоремы 1

По леммам 5 и 7 для любого c

```text
V(c) := 2F_c - S_c + H(c) - B_n = 2(F_c - P) + floor(n/2) - 3K_c + H(c).   (*)
```

Все входящие величины известны точно: `F_c` — лемма 3, `K_c` — лемма 4,
`H(c)` — определение. Разберём случаи; всюду `m = floor(n/2)`.

**Нечётное n.** `F_c = P`, `K_c = (n-1)/2` при всех c, значит

```text
V(c) = (n-1)/2 - 3(n-1)/2 + H(c) = H(c) - (n-1).
```

Минимум H по c равен `n-1` (достигается при `c = 1` и `c = n-1`;
`H(0) = n`, а при `c != 0` H растёт с `delta_n(0,c)`). Поэтому
`min_c V = 0`, и минимум достигается при `c = 1`.

**n = 0 (mod 4).** Здесь `m = n/2` чётно и `F_c = P` при всех c, поэтому

```text
V(c) = m - 3K_c + H(c) = H(c) - n        при нечётном g = h + c   (K_c = m),
       H(c) - n + 3                      при чётном  g = h + c   (K_c = m - 1).
```

Если h чётно, то c нечётно даёт нечётное g; наименьшее H на нечётных c равно
`H(1) = H(n-1) = n - 1`, что даёт `V = -1`. На чётных c имеем
`V(c) = H(c) - n + 3 >= n - n + 3 = 3` (при чётном c либо `c = 0` и `H(0) = n`,
либо `delta_n(0,c) >= 2` и `H(c) >= n`). Итог: `min_c V = -1`.

Если h нечётно, то нечётное g получается при чётном c; наименьшее H на чётных
c равно `H(0) = H(2) = n`, что даёт `V = 0`. На нечётных c
`V(c) = H(c) - n + 3 >= (n-1) - n + 3 = 2`. Итог: `min_c V = 0`.

**n = 2 (mod 4).** Здесь `m = n/2` нечётно. Заметим, что `c = h (mod 2)`
равносильно чётности `g = h + c`, поэтому по леммам 3 и 4 два случая
согласованы:

```text
c = h (mod 2):  F_c = P - 1, K_c = m - 1,  V(c) = -2 + m - 3(m-1) + H(c) = H(c) - n + 1;
c != h (mod 2): F_c = P + 1, K_c = m,      V(c) =  2 + m - 3m     + H(c) = H(c) - n + 2.
```

Если h нечётно, то на нечётных c (первая строка) минимум H равен `n-1`,
что даёт `V = 0`; на чётных c (вторая строка) `H(c) >= n` и `V >= 2`.
Итог: `min_c V = 0`, минимум при `c = 1`.

Если h чётно, то первая строка — это чётные c, где `H(c) >= n`, значит
`V >= 1` (равенство при `c = 0` и `c = 2`); вторая строка — нечётные c,
где минимум `H = n - 1` даёт `V = 1` (при `c = 1`). Итог: `min_c V = 1`. ∎

Следствие 1 получается из `R_c <= H(c)` (лемма 6). Следствие 2 — случай
h = 1: при нечётном n и при `n = 2 (mod 4)` (h = 1 нечётно) минимум равен 0,
при `n = 0 (mod 4)` (h = 1 нечётно) минимум равен 0; во всех случаях
`min_c [2F_c - S_c + H(c)] = B_n`, а это длина явно построенного слова,
сортирующего sigma_n (C18). Следствие 3 — прямо из теоремы.

## 4a. sigma_n: точная длина и расщепление (C25 / H8)

**Лемма 11 (побуквенный подсчёт).** Слово конструкции N1 при сдвиге c имеет

```text
N_rot = F_c - sum_C M(C) + (длина внешнего маршрута),
N_X   = F_c - sum_C M(C) - E_c + K_c.
```

*Доказательство.* В локальном слове цикла C (N1 §2.4) блоки `U^{e_j}`
разворачиваются в `(XL)^{e}` или `(RX)^{-e}`; вращений в них ровно
`sum_j |e_j| = F - M` (2.2), букв X — столько же, плюс `k-1` вставленных.
Выбранные сокращения убирают только пары XX, то есть `2(k-1-t)` букв X
и ни одного вращения. Значит, у цикла `N_rot(C) = F - M` и
`N_X(C) = (F - M) + (k-1) - 2(k-1-t) = F - M - E + 1`, так как `k - 2t = E`.
Суммирование по циклам и добавление внешнего маршрута (только вращения)
дают формулы. ∎

**Предложение 1 (C25/H8).** Пусть `pi = sigma_n`, то есть h = 1, n >= 4.
Тогда `min_c [2F_c - S_c + H(c)] = B_n`, минимум достигается ровно при
`c из {0, 2, n-2}` при `n = 0 (mod 4)` и ровно при `c из {1, n-1}` иначе,
и при каждом таком c слово конструкции имеет

```text
N_X = floor((n-1)^2/4),   N_rot = floor(n^2/4).
```

*Доказательство.* Равенство `min = B_n` и множество минимумов — теорема 1
и её разбор случаев (h = 1 нечётно, поэтому во всех трёх случаях минимум
равен 0; при нечётном n и при `n = 2 (mod 4)` он достигается ровно при
`delta_n(0,c) = 1`, при `n = 0 (mod 4)` — ровно при чётных c с `H(c) = n`,
то есть `delta_n(0,c) <= 2`).

Расщепление. Во всех трёх случаях `g = h + c` таково, что антиподальных
транспозиций у f_c нет: при нечётном n их не бывает; при `n = 0 (mod 4)`
имеем g нечётным, а условие антиподальности `2i = g - n/2` неразрешимо,
поскольку `g - n/2` нечётно; при `n = 2 (mod 4)` имеем g чётным и `n/2`
нечётным, поэтому `g - n/2` нечётно и решений снова нет. Значит по лемме 5
у всех K_c транспозиций `M = 2`, `E = 0`, то есть `sum_C M = 2K_c`, `E_c = 0`.
Подставляя леммы 3, 4 в лемму 11:

```text
n нечётное, c = 1:      F = P, K = (n-1)/2:
    N_X = P - (n-1) + (n-1)/2 = (n-1)^2/4,   N_rot = P - (n-1) + (n-1) = P;
n = 0 (mod 4), m = n/2: F = P = m^2, K = m:
    N_X = m^2 - 2m + m = m^2 - m = floor((n-1)^2/4),  N_rot = m^2 - 2m + n = m^2 = P;
n = 2 (mod 4), c = 1:   F = P - 1 = m^2 - 1, K = m - 1:
    N_X = m^2 - 1 - 2(m-1) + (m-1) = m^2 - m,  N_rot = m^2 - 1 - 2(m-1) + (n-1) = m^2 = P.
```

Во всех случаях `N_X = floor((n-1)^2/4)`, `N_rot = floor(n^2/4)`, и их сумма
равна B_n (C12). ∎

Предложение 1 доказывает утверждение C25 о длине, множестве сдвигов
и расщеплении при всех n >= 4 (прежде — VERIFIED при 4 <= n <= 12) и,
вместе с C18, даёт `d(sigma_n) <= B_n`, то есть C9 без ссылки на S2.
Совпадение расщепления с расщеплением геодезических (C13v) остаётся
наблюдением: нижняя оценка `d(sigma_n) >= B_n` — это C8, не доказана здесь.

**Точность.** «+1» в H10 на этом семействе не улучшается: при `n = 2 (mod 4)`
и чётном h минимум по c выражения с собственным маршрутом равен ровно
`B_n + 1` (теорема 1), а с маршрутом по переносчикам он равен `B_n + 1`
при чётном h из промежутка `2..n/2` (проверено при n = 6 и n = 10;
`data/runs/strict_loss_audit/report.md`, `data/runs/h10_reflections/`).
Значит доказательство H10 в форме `<= B_n` до свободного сокращения
невозможно.

## 5. Общий случай: что доказано и где препятствие

**Лемма 8 (переформулировка H10).** Для данного pi неравенство
`min_c [2F_c - S_c + R_c] <= B_n + 1` равносильно существованию c с

```text
S_c - R_c + 2(P - F_c) >= floor(n/2) - 1.                                (**)
```

*Доказательство.* Подстановка `2P - B_n = floor(n/2)` (лемма 7). ∎

**Лемма 9 (C29).** Для любого нетривиального цикла C верно `S(C) >= 3`;
следовательно, `S_c >= 3 K_c`.

*Доказательство.* `S = 2M + E - 1`, `M >= 1`, `E >= 0`. Если `M >= 2`,
то `S >= 3`. Если `M = 1`, то по (1.1) скачков нагрузки на 2 нет, значит
все шаги одного знака и `E = k >= 2`, откуда `S = 2 + k - 1 >= 3`. ∎

**Лемма 10 (достаточное условие, C30).** Если существует c с

```text
3 K_c + 2(P - F_c) >= floor(n/2) - 1 + H(c),                             (SC)
```

то H10 верна для данного pi. В частности (случай `K_c = 0` в оценке), если
`min_c F_c <= P - n + 1` при чётном n или `<= P - n + 2` при нечётном n,
то H10 верна для pi.

*Доказательство.* Леммы 6, 8, 9. Частный случай: `H(c) <= n + floor(n/2) - 2`
при всех c. ∎

**Измеренное покрытие (SC).** Доля перестановок, для которых (SC) выполнено
хотя бы при одном c: 100 % (n = 4), 91.7 % (n = 5), 92.5 % (n = 6), 90.3 %
(n = 7), 83.1 % (n = 8) — `data/runs/h10_reflections/census.json`. Доля падает
с ростом n, поэтому одних лемм 9–10 для общего доказательства не хватит:
нужна нижняя оценка `S_c` сильнее, чем `3K_c`, либо верхняя оценка `R_c`
сильнее, чем `H(c)`, причём обе — при одном и том же c.

**Препятствие (жёсткость семейства равенства).** Перепись входов с
`min_c [2F_c - S_c + R_c] >= B_n` (то есть тех, где в (**) остаётся запас
не больше 1):

| n | входов с избытком >= 0 | из них отражения | максимум избытка |
|---|---|---|---|
| 4 | 1 | 1 | 0 |
| 5 | 2 | 2 | 0 |
| 6 | 7 | 3 | +1 |
| 7 | 3 | 3 | 0 |
| 8 | 11 | 2 | 0 |
| 9 | 10 | 4 | 0 |
| 10 | 96 | 4 | +1 |

Семейство равенства не сводится к отражениям (при n = 8 из 11 тесных входов
отражений только 2, например `(0,1,4,7,6,2,5,3)`, `(4,0,3,7,1,5,6,2)`), растёт
с n и не имеет видимого единого описания. Более того, при n = 10 избыток
ровно +1 дают не только отражения h = 2, 4, но и четыре не-отражения
(`(2,9,6,3,0,7,4,1,8,5)`, `(4,7,0,3,6,9,2,5,8,1)`, `(8,0,2,7,6,9,5,4,3,1)`,
`(9,2,5,0,1,8,7,6,3,4)`), то есть константу 1 в H10 нельзя убрать и вне
доказанного семейства. Любое доказательство общего случая обязано быть точным
на этом семействе: запас в (**) равен 0 или 1.

Частичная структурная зацепка: при n = 9 у каждого тесного входа среди
минимизирующих сдвигов есть c, при котором f_c — инволюция с одной
неподвижной точкой; при n = 8 это уже неверно (встречаются типы циклов
[3,3], [2,4], [8]). Для инволютивного f_c лемма 5 даёт `S_c = 3K_c` точно,
и (**) превращается в `3K_c - R_c + 2(P - F_c) >= floor(n/2) - 1` — это
естественное расширение доказанного случая отражений.
Отсюда следствие для метода: усреднение по всем c не годится — среднее
`mean_c [2F_c - S_c + R_c] - B_n` достигает 3/2 при n = 8 и 14/9 при n = 9
(`data/runs/strict_loss_audit/report.md`), то есть строго больше 1.
