# C32 — отражения: `d(pi_h) <= B_n − delta_n(h, 1)` двумя линейными инверсиями дуг

Дата: 13.09.2026 (сессия 7). Статус: PROVED (локальный аудит одной сессии,
один автор). Конструкция: `constructions/reflection_word.py` (two_arc-1.0).
Чекер: `checks/check_C32.py` (PASS: все h при 4 <= n <= 100; таблицы C2v при
4 <= n <= 10). Конвенции — PROBLEM §3; модель «окружность + голова» — PROBLEM §2.
Доказательство не использует N1, C16–C21, C28 и таблицы.

## Утверждение

Пусть n >= 4 и `pi_h(i) = h − i mod n` — отражение (sigma_n — это h = 1,
rev_n — это h = n − 1). Тогда существует слово, сортирующее pi_h, с

```text
N_X   = floor((n − 1)^2 / 4),
N_rot = floor(n^2 / 4) − delta_n(h, 1),
len   = B_n − delta_n(h, 1).
```

Следствия: `d(pi_h) <= B_n − delta_n(h, 1)` при всех n >= 4 и всех h;
в частности `d(sigma_n) <= B_n` (C9 — элементарно, без N1) и
`d(rev_n) <= B_n − 2` (верхняя половина C6). Обратное неравенство
`d(pi_h) >= B_n − delta_n(h, 1)` равносильно C8 (`d(sigma_n) >= B_n`): так как
`apply_word(pi_h, L^(h−1)) = sigma_n` (PROBLEM §3: `apply_word(p, "L")[i] = p[i+1]`,
поэтому `apply_word(pi_h, L^k) = pi_{h−k}`), верно
`d(sigma_n) <= d(pi_h) + delta_n(h, 1)`. Итого C31 (`d(pi_h) = B_n − delta_n(h, 1)`)
следует из C8, а без C8 доказана как верхняя оценка.

## 1. Модель и обозначения

Позиции окружности — Z_n; ребро `e` — пара позиций {e, e + 1}; голова видит
ребро e, когда её положение равно e; X меняет содержимое позиций e и e + 1.
Сдвиг c из Z_n: слово сортирует pi, если в конце элемент e стоит на позиции
e + c и голова стоит в c (тогда массив, прочитанный от головы, — тождественная
перестановка). В начале позиция i содержит `pi_h(i) = h − i`, голова в 0.

Положим `h' = h + c`. Элемент, стоящий на позиции i, должен попасть на позицию
`h − i + c = h' − i`. Итак, требуемое отображение позиций — отражение

```text
rho(i) = h' − i   (mod n),
```

а слово должно реализовать rho обменами соседних позиций и закончить голову в c.

Удвоенные координаты. Точку окружности с удвоенной координатой x (x из Z_{2n})
называем вершиной x/2 при чётном x и серединой ребра `(x − 1)/2` при нечётном x.
Ось отражения rho проходит через две точки: `x_1 = h'` и `x_2 = h' + n`
(в Z_{2n}); rho(x_1/2 + t) = x_1/2 − t для всех полуцелых t, то же для x_2.

## 2. Лемма 1 (две дуги)

Пусть a + b = n, дуга D_1 — a подряд идущих позиций с центром в точке x_1
(a нечётно, если x_1 — вершина, и чётно, если x_1 — середина ребра), D_2 —
остальные b позиций. Тогда D_2 — дуга с центром в x_2 (b той же чётности,
что требуется для x_2), rho переводит каждую дугу в себя, обращая порядок
позиций, и rho не переставляет ничего через два граничных ребра между D_1 и D_2.

Доказательство. Позиции D_1 — это `x_1/2 + t` при t = −(a−1)/2, ..., (a−1)/2
(полуцелые t при нечётном x_1), и rho(x_1/2 + t) = x_1/2 − t — та же дуга
в обратном порядке. Дополнение симметричной относительно оси дуги симметрично
относительно той же оси, а центр дополнения — противоположная точка оси x_2;
чётность b = n − a совпадает с требуемой для x_2 (при чётном n точки x_1, x_2
одного типа, при нечётном — разных). ∎

Следовательно rho — произведение двух линейных инверсий: обращения дуги D_1
и обращения дуги D_2, каждая — перестановка своего отрезка позиций.

## 3. Лемма 2 (зигзаг: линейная инверсия отрезка с соседними обменами)

Отрезок позиций `lo, lo + 1, ..., lo + a − 1` (a >= 1). Рёбра отрезка —
`lo, ..., lo + a − 2`. Определим последовательность рёбер `Z_out(lo, a)`:

- a = 2s чётно, центральное ребро `m = lo + s − 1`: раунд 0 — ребро m;
  раунд t = 1, ..., s − 1 — рёбра `m + t, m + t − 1, ..., m − t` (вниз),
  затем `m − t + 1, ..., m + t` (вверх); всего в раунде 4t + 1 рёбер.
- a = 2s + 1 нечётно, центральная вершина `v = lo + s`: раунд t = 0, ..., s − 1 —
  рёбра `v + t, ..., v − t − 1` (вниз, 2t + 2 рёбер), затем `v − t, ..., v + t`
  (вверх, 2t + 1 рёбер); всего 4t + 3.

Утверждение. (а) Обмены по Z_out(lo, a) обращают отрезок (позиция lo + j
получает элемент, стоявший на lo + a − 1 − j), остальные позиции не трогаются.
(б) Число обменов равно a(a − 1)/2. (в) Соседние рёбра последовательности
отличаются ровно на 1. (г) Первое ребро — m (a чётно) или v (a нечётно),
последнее — верхнее ребро отрезка `lo + a − 2` (при a >= 2).

Доказательство. Индукция по раундам. Инвариант после раунда t: блок из
позиций `m − t + 1 .. m + t` (чётный случай; `v − t .. v + t` в нечётном)
обращён, остальное на месте, последнее ребро — `m + t` (соотв. `v + t`).
База: чётный раунд 0 меняет две центральные позиции; нечётный «раунд −1» —
один центральный элемент, ничего не сделано.

Шаг (чётный случай, раунд t >= 1). Перед раундом блок B занимает
`m − t + 1 .. m + t`, x стоит на `m − t`, y — на `m + t + 1`. Обмены
`m + t, ..., m − t + 1` переносят y вниз через весь блок (порядок блока
сохраняется, блок сдвигается на 1 вверх); обмен на ребре `m − t` меняет
x и y: теперь y на `m − t`, x на `m − t + 1`. Обмены `m − t + 1, ..., m + t`
переносят x вверх через блок (блок возвращается на `m − t + 1 .. m + t` в
прежнем порядке), x встаёт на `m + t + 1`. Итог: `[y, B, x]` вместо
`[x, B, y]`; так как B уже обращён, обращён и новый блок. Нечётный случай —
дословно, с блоком `v − t .. v + t`, x на `v − t − 1`, y на `v + t + 1`:
вниз — 2t + 2 обмена (последний, на ребре `v − t − 1`, меняет x и y), вверх —
2t + 1.

(б) Чётно: `1 + sum_{t=1}^{s−1} (4t + 1) = 2s^2 − s = a(a−1)/2`; нечётно:
`sum_{t=0}^{s−1} (4t + 3) = 2s^2 + s = a(a−1)/2`.
(в) Внутри хода вниз и вверх шаг ±1; поворот `m − t → m − t + 1` (соотв.
`v − t − 1 → v − t`) — шаг 1; раунд t кончается на `m + t`, раунд t + 1
начинается на `m + t + 1` (в нечётном случае `v + t → v + t + 1`).
(г) Последний раунд кончается на `m + s − 1 = lo + a − 2` (соотв.
`v + s − 1 = lo + a − 2`). ∎

Три производные последовательности:

- `Z_out_mirror` — образ Z_out при отражении отрезка `e -> 2lo + a − 2 − e`
  (обращает отрезок по симметрии; начинается на `m` при чётном a и на
  `v − 1` при нечётном, кончается на нижнем ребре lo);
- `Z_in` — Z_out_mirror в обратном порядке: начинается на нижнем ребре lo,
  кончается на `m` (a чётно) или `v − 1` (a нечётно);
- `Z_in_mirror` — Z_out в обратном порядке: начинается на верхнем ребре,
  кончается на m или v.

Обратный порядок обменов реализует обратную перестановку позиций, а инверсия
отрезка — инволюция, поэтому Z_in и Z_in_mirror тоже обращают отрезок.
Свойство (в) сохраняется.

## 4. Лемма 3 (стоимость слова по последовательности рёбер)

Пусть E = (e_1, ..., e_k) — последовательность рёбер, голова начинает в s и
должна закончить в c. Слово: перейти от s к e_1 по короткой дуге, обменять,
перейти к e_2, ..., обменять на e_k, перейти к c. Тогда `N_X = k` и

```text
N_rot = delta_n(s, e_1) + sum_{i<k} delta_n(e_i, e_{i+1}) + delta_n(e_k, c).
```

Если E — конкатенация Z_1 (k_1 рёбер, соседние отличаются на 1) и Z_2
(k_2 рёбер, то же), то

```text
N_rot = (k_1 − 1) + (k_2 − 1) + delta_n(s, первое Z_1)
        + delta_n(последнее Z_1, первое Z_2) + delta_n(последнее Z_2, c).
```

Слово свободно несократимо: подряд идущих XX нет (соседние обмены на разных
рёбрах), а LR/RL нет, поскольку каждая прогулка идёт в одну сторону по короткой
дуге, и между двумя прогулками стоит X. ∎

## 5. Лемма 4 (баланс дуг)

При a + b = n минимум `a(a − 1)/2 + b(b − 1)/2` по допустимым (a, b) равен
`floor((n − 1)^2 / 4)` и достигается:

- n = 0 (mod 4): ось через середины рёбер (h' нечётно), a = b = n/2 (чётные);
- n = 2 (mod 4): ось через вершины (h' чётно), a = b = n/2 (нечётные);
- n нечётно: любая ось (одна точка — вершина, другая — середина ребра);
  нечётная из {m, m + 1} — длина дуги при вершине, чётная — при ребре,
  m = (n − 1)/2.

Проверка: n = 2m: `2 · m(m − 1)/2 = m^2 − m = (n^2 − 2n)/4 = floor((n − 1)^2/4)`;
n = 2m + 1: `m(m − 1)/2 + (m + 1)m/2 = m^2 = (n − 1)^2/4`. Неправильная чётность
оси при чётном n вынуждает a = n/2 − 1, b = n/2 + 1 и даёт на 1 обмен больше
(это «F_c = P + 1» леммы 2 C28 при n = 2 mod 4 и нечётном h'). Тождество
`floor(n^2/4) − floor((n − 1)^2/4) = floor(n/2)` — C12. ∎

## 6. Теорема (C32)

Во всех случаях слово = Z_out(D_1), затем Z_in(D_2), затем прогулка к c;
N_X = floor((n − 1)^2/4) по лемме 4; по лемме 3 нужно показать

```text
подход + стык + финал = floor(n/2) + 2 − delta_n(h, 1),
```

где подход = delta(0, первое ребро Z_out(D_1)), стык = delta(последнее ребро
Z_out(D_1), первое ребро Z_in(D_2)), финал = delta(последнее ребро Z_in(D_2), c).
Стык всегда равен 2: Z_out(D_1) кончается на верхнем ребре D_1 (голова на
`top − 1`, где top — последняя позиция D_1), Z_in(D_2) начинается на нижнем
ребре D_2 = {top + 1, top + 2} (голова на top + 1). Тогда

```text
N_rot = N_X − 2 + подход + 2 + финал = N_X + floor(n/2) − delta_n(h, 1)
      = floor(n^2/4) − delta_n(h, 1).
```

Используем: при чётном n `delta_n(x + n/2, y) = n/2 − delta_n(x, y)`.

**Случай E: n чётно, m = n/2.** Точка оси в голове: x_1 = 1 (n = 0 mod 4,
середина ребра {0, 1}) или x_1 = 0 (n = 2 mod 4, вершина 0); h' = x_1,
`c = h' − h`; a = b = m.

- n = 0 (mod 4): D_1 = позиции `1 − m/2 .. m/2`, центральное ребро 0: подход 0.
  D_2 = `m/2 + 1 .. m/2 + m`, центральное ребро m; Z_in(D_2) кончается на m:
  финал `delta(m, 1 − h) = m − delta(0, 1 − h) = m − delta_n(h, 1)`.
- n = 2 (mod 4): D_1 = `−(m−1)/2 .. (m−1)/2`, центральная вершина 0, первое
  ребро Z_out — ребро 0: подход 0. D_2 — нечётная дуга с центральной вершиной
  m; Z_in(D_2) кончается на ребре m − 1: финал
  `delta(m − 1, −h) = delta(m, 1 − h) = m − delta_n(h, 1)`.

Итого подход + финал = m − delta_n(h, 1) = floor(n/2) − delta_n(h, 1). ✓

**Случай O: n = 2m + 1 нечётно.** Дуга при вершине имеет нечётную длину из
{m, m + 1}, дуга при ребре — чётную; N_X = m^2. Нужно подход + финал =
m − delta_n(h, 1). Для нечётного n: `delta(0, x + m) = m + 1 − delta(0, x)` при
1 <= x <= m, `= m` при x = 0, `= m − delta(0, x)` при m + 1 <= x <= 2m.

- Подслучай A, 1 <= h <= m: h' = 0, `c = −h`. D_1 — дуга при вершине 0
  (Z_out начинается на ребре 0, подход 0), D_2 — дуга при ребре {m, m + 1}
  (удвоенная координата 0 + n = 2m + 1); Z_in(D_2) кончается на центральном
  ребре m. Финал `delta(m, −h) = delta(0, m + h) = m + 1 − h` (так как
  1 <= h <= m), а `delta_n(h, 1) = h − 1`. ✓
- Подслучай B, h = 0 или m + 2 <= h <= 2m: v = h − 1 (v из [m + 1, 2m]),
  ось через вершину v, `h' = 2v`, `c = 2v − h = v − 1`. D_1 — дуга при ребре
  {v + m, v + m + 1} (удвоенная координата 2v + n), Z_out начинается на её
  центральном ребре v + m: подход `delta(0, v + m) = v + m − n = v − m − 1`
  (v + m лежит в [2m + 1, 3m]). D_2 — дуга при вершине v, Z_in(D_2) кончается
  на ребре v − 1: голова v − 1 = c, финал 0. Итого `v − m − 1 = h − m − 2`;
  для m + 2 <= h <= 2m: `delta_n(h, 1) = 2m + 2 − h`, `m − delta = h − m − 2` ✓;
  для h = 0: v = 2m, подход m − 1, `m − delta_n(0, 1) = m − 1` ✓.
- Подслучай C, h = m + 1: `sigma_n o pi_{m+2} o sigma_n = pi_{2−(m+2)} = pi_{m+1}`
  (`(sigma o pi_h o sigma)(i) = 1 − (h − (1 − i)) = (2 − h) − i`; `2 − m − 2 =
  −m = m + 1` в Z_n). Сопряжение sigma_n — автоморфизм графа, сохраняющий id_n
  и меняющий L и R местами (PROBLEM §4.3). Слово подслучая B для pi_{m+2}
  с заменой L <-> R сортирует pi_{m+1} с теми же N_X, N_rot;
  `delta_n(m + 2, 1) = m = delta_n(m + 1, 1)`. ✓

Во всех случаях `len = N_X + N_rot = floor((n − 1)^2/4) + floor(n^2/4) −
delta_n(h, 1) = B_n − delta_n(h, 1)` (C12). ∎

## 7. Замечания

1. Два граничных ребра между дугами не обмениваются никогда: слово живёт
   в «линейной модели» с одним неиспользуемым ребром (см. `experiments/line_model.py`,
   H13 в PLAN). Обход «в длинную сторону» (переносчики N1) не нужен.
2. Порядок дуг и режимы зигзагов выбраны так, чтобы стык стоил 2 и финальная
   прогулка использовала свободу c. Политика «горизонт» (C30) на отражениях
   делает те же два зигзага, но обе дуги «из центра» и без планирования конца:
   её длина при c = 0 равна `2N_X − 1 + подход + финал + лишние шаги на стыках`
   (`checks/check_C32.py`, часть 3), поэтому около антипода h ≈ n/2 + 1 она
   теряет до `delta_n(h, 1) − 2` против настоящего слова. Это объясняет
   `g(h)` из C30 и ступени eps в `docs/notes/h12_horizon.md` §2.
3. При n = 4 и 5 формула тоже верна и совпадает с таблицами (чекер, часть 2),
   так что C31 проверена при 4 <= n <= 10.
4. Доказательство — только леммы 1–4 и C12; никакой конечной проверки оно не
   требует. Чекер — независимая сверка формул и слов (эталонные ходы).
