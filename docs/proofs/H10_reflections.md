# H10 / C27 restricted to reflections — proof

Статус: PROVED для семейства отражений `pi(i) = h - i mod n`, все `n >= 4` и все
`h` (не конечный диапазон). Общий случай (произвольная `pi`) не входит в этот
документ и остаётся CONJECTURED — см. §6 и `docs/notes/H10_general_obstruction.md`.

Зависимости: конструкция N1 §§1-3 (C18, PROVED) как реализована в
`constructions/strict_upper.py` (strict_upper-1.0); определения F(C), M(C),
E(C), S(C), F_c, S_c, H(c) — PROBLEM.md §5.2; конвенция подписанного шага —
AGENTS.md правило 16. Вариант с маршрутом по переносчикам `R_c` (carrier route,
`carrier_route` в коде) — правило 16, леммы N1 на него не переносятся, но
лемма 0 ниже верна для него по одной строке рассуждения из определения R_c.
Чекер: `checks/check_C27_reflections.py`, отчёт
`data/runs/check_C27_reflections/`.

## 0. Постановка

`pi(i) = h - i mod n` для фиксированного `h`. Показывается: при любых `n >= 4`
и любых `h`

```text
min_c [2F_c - S_c + H(c)] <= B_n + 1,
```

где `H(c)` — собственный внешний маршрут N1 §3 (не вариант!), а равенство
`= B_n + 1` достигается ровно когда `n ≡ 2 (mod 4)` и `h` чётно; во всех
остальных случаях `min_c [2F_c - S_c + H(c)] <= B_n`. Отсюда сразу следует
H10/C27 на отражениях (§5):

```text
min_c [2F_c - S_c + R_c] <= B_n + 1   для всех n >= 4, всех h.
```

Доказательство сильнее, чем требует C27: оно не использует маршрут по
переносчикам вовсе — только собственный H(c) конструкции N1. Оно также
доказывает H8/C25 (д(sigma_n) <= B_n при **всех** n >= 4, не только
4<=n<=12) как частный случай h=1 — см. §7.

## 1. Лемма 0 (общая, не только отражения): `R_c <= H(c)`

Маршрут N1 §3 длины `H(c)` — это прогулка по всем `n` вершинам `Z_n` от 0 до
`c` (обходит каждую вершину, в частности каждый переносчик). `R_c` по
определению (`carrier_route`) — минимум длины прогулки от 0 до `c`,
посещающей только множество переносчиков (подмножество всех вершин). Минимум
по более слабому требованию не больше значения на любой конкретной
допустимой прогулке, включая маршрут N1; значит `R_c <= H(c)` для любых
`pi`, `c`. (Уже отмечено в `data/runs/strict_loss_audit/report.md`; здесь
формализовано как явная лемма, используемая ниже.)

## 2. Нечётное n: F_c и S_c — точные константы по c

Пусть `n` нечётно, `pi(i) = h - i mod n`. Для сдвига `c` положим
`k = h + c mod n`, `f_c(i) = k - i mod n`.

**Факт 2.1 (неподвижные точки).** Уравнение `2i ≡ k (mod n)` имеет ровно одно
решение `i_0 = k * inv2(n) mod n` (2 обратимо по нечётному `n`). Значит
`f_c` — инволюция с единственной неподвижной точкой и `(n-1)/2`
транспозициями `{i_0+t, i_0-t}`, `t=1..(n-1)/2`, ни одна не антиподальна
(антипод требует разности `n/2`, не целой при нечётном `n`).

**Факт 2.2 (S каждой транспозиции = 3).** Для нетривиального 2-цикла (a,b)
подписанные шаги — `(d,-d)` при `d != n/2` (неантиподальный случай,
единственный при нечётном `n`, см. 2.1): обе дуги проходят один и тот же
путь длины `|d|` в противоположных направлениях, так что `M=2` на каждом
из этих рёбер и `0` вне их; переходов «minus→plus» ровно один (цикл длины
2), значит `E = 2 - 2*1 = 0`; `S = 2*2+0-1 = 3`. Это верно для **любой**
неантиподальной транспозиции, независимо от `d`. Следовательно
`S_c = 3 * (n-1)/2` — точно, для **каждого** `c`, а не только в среднем
(это уточнение C24, где утверждалось только про среднее `s`).

**Факт 2.3 (F_c = P для всех c).** `i - pi(i) = 2i - h mod n`. Отображение
`i -> 2i mod n` — биекция `Z_n -> Z_n` (2 обратимо), поэтому мультимножество
смещений `{i - pi(i) mod n : i}` — это в точности `Z_n` (каждый вычет ровно
один раз), независимо от `h`. Значит

```text
F_c = sum_i delta_n(i-pi(i), c) = sum_{d=0}^{n-1} delta_n(d,c)
    = sum_{e=0}^{n-1} delta_n(e,0)              (сдвиг e = d - c, биекция)
    = 2*(1+2+...+(n-1)/2) = (n^2-1)/4 = P(n),
```
константа, не зависящая от `c` (и от `h`).

**Теорема (нечётное n).** `2F_c - S_c = 2P - 3(n-1)/2` — константа по `c`.
Прямой подсчёт (`B_n = n(n-1)/2`):

```text
2P - 3(n-1)/2 - B_n = (n^2-1)/2 - 3(n-1)/2 - n(n-1)/2
                     = (n-1)*[(n+1)/2 - 3/2 - n/2] = (n-1)*(-1) = -(n-1),
```
то есть `2F_c - S_c = B_n - (n-1)` для каждого `c`. По лемме 0 (или прямо
`H(1) = n - 1 + delta(0,1) - 2 + 1`... по определению `H(c)=n+delta(0,c)-2`
при `c!=0`, значит `H(1) = n-1`), взяв `c=1`:

```text
2F_1 - S_1 + H(1) = [B_n - (n-1)] + (n-1) = B_n.
```

Значит `min_c[2F_c-S_c+H(c)] <= B_n` при **любом** нечётном `n >= 5` и
**любом** `h` — точно, не `B_n+1`. Проверено чекером на 5<=n<=59 (шаг 2), все
`h`, все `c` (не только c=1): 35 980 троек (n,h,c) с `F_c=P`, `S_c=3(n-1)/2`
точно; 896 случаев `h` с равенством `= B_n` при `c=1`.

## 3. Чётное n: неподвижные точки и S_c

Пусть `n` чётно. `2i ≡ k (mod n)` имеет два решения `i_0, i_0+n/2`, если `k`
чётно (`i_0 = k/2`), и ни одного, если `k` нечётно. Значит:

- `k` чётно: `f_c` — инволюция с 2 неподвижными точками и `(n-2)/2`
  транспозициями `{i_0+t,i_0-t}`, `t=1..n/2-1`; ровно одна антиподальна
  (разность `n/2`) при `t=n/4`, если `4 | n`, иначе ни одной.
- `k` нечётно: 0 неподвижных точек, `n/2` транспозиций `{m-t,m+1+t}`,
  `t=0..n/2-1`, `m=(k-1)/2`; ровно одна антиподальна (разность `1+2t=n/2`)
  если `n/2` нечётно (`n ≡ 2 mod 4`), иначе ни одной.

**Факт 3.1 (антиподальная транспозиция тоже даёт S=3).** Антиподальный шаг
по правилу 16 всегда положителен: оба подписанных шага цикла равны `+n/2`,
цикл однонаправленный, две дуги вместе проходят каждое ребро ровно один раз
(`M=1`), нет переходов «minus→plus» (`t=0`, `E=2`), `S=2*1+2-1=3`. То же
значение, что у неантиподальной транспозиции (факт 2.2). Значит для
**любой** отражения-инволюции (антиподальные транспозиции есть или нет —
неважно):

```text
S_c = 3 * (число транспозиций f_c) = 3*(n - fix_c)/2,
fix_c = 2 если k чётно, 0 если k нечётно.
```
То есть `S_c = 3(n-2)/2` при чётном `k`, `S_c = 3n/2` при нечётном `k`
(`k=h+c mod n`) — ровно два значения по чётности `k`, независимо от того,
есть ли антиподальная транспозиция.

## 4. Чётное n: F_c при c из {0,1}

Как в §2.3, `i-pi(i)=2i-h mod n`; но `i->2i mod n` не биекция (образ — только
чётные вычеты, каждый дважды). Пусть `A = sum_{e чётно, 0<=e<n} delta_n(e,0)`,
`B = sum_{e нечётно} delta_n(e,0)`; `A+B = P(n)` (полная сумма не зависит от
опорной точки). Стандартный расчёт (сведение к сумме по `Z_{n/2}`, см. §2.3
с `n/2` вместо `n`): `A = 2*P(n/2)`.

- `4 | n`: `n/2` чётно, `P(n/2) = (n/2)^2/4 = n^2/16`, значит
  `A = n^2/8 = P(n)/2 = B`. Отсюда для любой чётности `h` мультимножество
  смещений `{2i-h mod n}` — это чётные (если `h` чётно) или нечётные (если
  `h` нечётно) вычеты, каждый дважды, и в обоих случаях сумма расстояний до
  `c` равна `2A` или `2B` — но при `4|n` `A=B`, так что **`F_c = P(n)`
  постоянна по `c` и по `h`.**
- `n ≡ 2 (mod 4)`: `n/2` нечётно, `P(n/2) = ((n/2)^2-1)/4 = (n^2-4)/16`,
  `A = (n^2-4)/8 = P(n)-1`, `B = P(n)+1`. Сдвиг на `c` меняет, какая из
  сумм (по чётным или по нечётным вычетам) даёт `F_c`, в зависимости от
  чётности `k=h+c`, а не только `h` (проверяется прямой заменой
  `e -> e-c mod n`, которая меняет чётность класса, если `c` нечётно):

```text
F_c = P(n) - 1   если k = h+c mod n чётно,
F_c = P(n) + 1   если k нечётно.
```

Оба случая (F при `4|n` и при `n ≡ 2 mod 4`) проверены чекером против прямого
подсчёта конструкции для 4<=n<=60 (все h, c=0,1).

## 5. Теорема (чётное n): точный избыток по классам

`H(0)=n`, `H(1)=n-2+delta(0,1)=n-1` (определение N1 §3). Подставляя §3-4 в
`excess(c) := 2F_c - S_c + H(c) - B_n` при `c in {0,1}` (используя
`B_n=n(n-1)/2`, `P(n)=n^2/4`), получаем **точные целые числа, не зависящие
от n** внутри каждого класса (n mod 4, h mod 2):

| n mod 4 | h mod 2 | k=h+0 чётность | excess(c=0) | k=h+1 чётность | excess(c=1) | min |
|---|---|---|---|---|---|---|
| 0 | чётно | чётно | **3** | нечётно | **-1** | -1 |
| 0 | нечётно | нечётно | **0** | чётно | **2** | 0 |
| 2 | чётно | чётно | **1** | нечётно | **1** | 1 |
| 2 | нечётно | нечётно | **2** | чётно | **0** | 0 |

(Выкладка для строки `n≡0, h чётно, c=0`: `F=P(n)`, `S=3(n-2)/2` (k чётно),
`H=n`; `2P(n)-3(n-2)/2+n-B_n = n^2/2-(3n-6)/2+n-n(n-1)/2`, приводя к общему
знаменателю 2: `[n^2-3n+6+2n-n^2+n]/2 = 6/2 = 3`. Остальные три строки той же
клетки и обе строки `n≡2` считаются одинаково; все члены `n^2` и линейные по
`n` сокращаются, остаётся целая константа — это и есть причина, по которой
результат не зависит от величины `n`, только от класса. Все четыре числа
проверены чекером на 4<=n<=60, все h, обе чётности.)

Значит `min_{c in {0,1}} excess(c) = 0` при `n ≢ 2 (mod 4)` и `= 1` при
`n ≡ 2 (mod 4)` — но при `n≡2 mod4` **только для `h` чётного** (`h` нечётный
даёт `0`, беря `c=1`). Значение `1` при `n≡2mod4, h` чётном — точное:
проверено (§6) прогоном фактических слов до n=80 включительно (все h, все
c, не только {0,1}), что маршрут по переносчикам тоже не может улучшить его.

**Вывод:** `min_c[2F_c - S_c + H(c)] <= B_n + 1` для всех `n>=4`, всех `h`,
с равенством `B_n+1` ровно при `n ≡ 2 (mod 4)` и `h` чётном; иначе `<= B_n`.

## 6. Следствие: H10/C27 на отражениях

По лемме 0, `R_c <= H(c)` при том же `c`, значит теорема §5 переносится
дословно:

```text
min_c [2F_c - S_c + R_c] <= B_n + 1   для всех n >= 4 и всех h.   (H10 на отражениях)
```

Свободное сокращение (`red`) только уменьшает длину, так что
`min_c[red(...)] <= B_n + 1` тоже, и данные (`data/runs/strict_loss_audit/`,
C27v) показывают, что после сокращения превышения не остаётся ни на одном
отражении 4<=n<=9 (`Q_RJ <= B_n`), согласуясь с этим доказательством.

**Точность границы `B_n+1`.** Она не улучшается до `B_n+1` минус что-то:
семейство `n ≡ 2 (mod4)`, `h` чётное — не единственный числовой пример
(как отмечено в C27v для n=6), а **вся бесконечная подсерия** отражений;
проверено прогоном настоящих слов конструкции (обоих маршрутов) для
`4 <= n <= 80`, все `h`, все `c` (не только {0,1}): максимум
`min_c(len) - B_n` по всем отражениям равен ровно `1` при каждом
`n ≡ 2 (mod 4)` в этом диапазоне и `0` иначе, что в точности воспроизводит
теорему §5 без ограничения на `c in {0,1}` (т.е. использование c=0,1 уже
достаточно и минимум по всем c не даёт большего запаса на этой подсерии).
Прогон: `python3 -c "..."` (см. журнал воспроизведения в
`data/runs/check_C27_reflections/`; полный лог 4<=n<=80 — разовый,
не сохранён как файл, воспроизводим командой ниже, ~7 минут).

```bash
python3 -c "
import sys; sys.path[:0]=['oracle','constructions','bounds']
import strict_upper as su, known
for n in range(4,81):
    Bn = known.target_diameter(n)
    mx = max(min(su.shift_word(tuple((h-i)%n for i in range(n)), c, 'carrier')['stats']['len']
                 for c in range(n)) - Bn for h in range(n))
    print(n, mx)
"
```

## 7. Следствие: H8/C25 для sigma_n при всех n (не только 4<=n<=12)

`sigma_n = pi` с `h=1` (см. `oracle/moves.py: sigma`). Подставляя `h=1` в
таблицу §5 (`h` нечётно):

- `n` нечётно: §2 даёт `excess(c=1) = 0` для любого нечётного n — точно.
- `n ≡ 0 mod 4`: строка «h нечётно» даёт `excess(c=0)=0`.
- `n ≡ 2 mod 4`: строка «h нечётно» даёт `excess(c=1)=0`.

То есть при **всех** `n >= 4` конструкция N1 при подходящем `c` из `{0,1}`
(в точности `c` из объявленного в H8 множества: `{0,2,n-2}` при `4|n`
пересекается с `{0}`, `{1,n-1}` иначе пересекается с `{1}`) даёт слово
длины ровно `B_n`, сортирующее `sigma_n`. Значит:

```text
d(sigma_n) <= B_n   при всех n >= 4                       (H8/C25, длина, все n)
```

доказано в замкнутой форме, а не только VERIFIED для 4<=n<=12. Это не
доказывает точный подсчёт `N_X = floor((n-1)^2/4)`, `N_rot = floor(n^2/4)`
(вторая часть H8/C25) — она не выводится из этого расчёта и остаётся VERIFIED
только для 4<=n<=12 плюс наблюдение при n=20,50,100,101 (не изменяется этим
документом).

## 8. Что не доказано

Этот документ — только семейство отражений. Общий случай (произвольная
`pi`) требует другого аргумента: у отражений каждый цикл `f_c` — 2-цикл,
и **любой** 2-цикл даёт `S(C)=3` вне зависимости от длины шага (факты 2.2 и
3.1) — это и есть механизм, который делает `2F_c-S_c` не зависящим от `c`
(или зависящим только от чётности `c`), позволяя выбирать `c` всего из
2 кандидатов. Для произвольной `pi` циклы `f_c` длиннее 2, `S(C)` для
длинного цикла существенно зависит от его конкретной формы (не только от
длины `|C|`), и `2F_c-S_c` не сводится к функции одной лишь чётности `c`
(это и есть эмпирически наблюдаемое линейно растущее слагаемое «выбор
сдвига» из `data/runs/strict_loss_audit/report.md`, §4.1 п.3). Точная
формулировка препятствия и рассмотренные подходы — в
`docs/notes/H10_general_obstruction.md`.
