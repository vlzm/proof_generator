# H10 on reflections (C27 / C28): PROVED

Статус: **PROVED** для утверждения ниже (шаг 1 задачи PLAN §8 по H10). Общий
случай H10 для произвольной pi (шаг 2) этим не закрывается — см.
`docs/notes/H10_general_progress.md`.

## 1. Точная формулировка и область

Пусть `n >= 4`, `h in Z_n`, `pi_h(i) = (h - i) mod n` — отражение с параметром
`h` (в частности `pi_1 = sigma_n`, PROBLEM/oracle `sigma(n)`). Для `c in Z_n`
пусть `f_c(i) = (pi_h(i) + c) mod n`, и пусть `F_c`, `S_c` — суммы по
нетривиальным циклам `f_c`, как в N1 §1 (`docs/incoming/LRX_STRICT_PROOF_RU-1.md`),
`H(c)` — внешний маршрут N1 §3, и `R_c` — длина кратчайшей прогулки по `Z_n`
из `0` в `c`, посещающей все переносчики циклов `f_c` (вариант конструкции,
`constructions/strict_upper.py: carrier_route`, правило 16 AGENTS.md, не
наследует леммы N1 автоматически).

**Теорема.** Для всех `n >= 4` и всех `h in Z_n`:

```
min_c [2F_c - S_c + R_c] <= B_n + 1,
```

где `B_n = n(n-1)/2` (C12). Точнее, эксплицитный сдвиг `c* in {0, 1}`,
построенный в §4 ниже, даёт значение `2F_{c*} - S_{c*} + H(c*)` (а тем самым,
по лемме A, и `2F_{c*} - S_{c*} + R_{c*}`, поскольку `R_c <= H(c)` всегда) равное:

| n mod 4 | h чётно | h нечётно |
|---|---|---|
| 1, 3 (n нечётно) | `B_n` | `B_n` |
| 0 | `B_n - 1` | `B_n` |
| 2 | `B_n + 1` | `B_n` |

Равенство `B_n + 1` достигается только в случае `n = 2 mod 4`, `h` чётно;
во всех остальных случаях `min_c [2F_c - S_c + R_c] <= B_n` уже без всякого
свободного сокращения.

Это строго обобщает C25 (там же — только `h = 1`, т.е. `sigma_n`) и даёт
H10-шаг-1 из PLAN §8 доказательством, а не числом: обе стороны — точные целые
формулы от `n`, `h`.

## 2. Лемма A (маршрут по переносчикам не хуже маршрута N1): общий факт, не только для отражений

**Лемма A.** Для любых `n >= 4`, `pi in S_n`, `c in Z_n`: `R_c <= H(c)`.

*Доказательство.* По построению N1 §3 маршрут длины `H(c)` от `0` до `c`
посещает все вершины `Z_n` (полный оборот `L^n` при `c = 0`; при `c != 0` —
путь «`d-1` рёбер в одну сторону, назад в 0, затем `n-d` рёбер в другую»,
который по построению проходит каждую вершину ровно один раз, кроме `0`,
пройденной дважды). В частности, он посещает все переносчики циклов `f_c`
(это подмножество вершин). Так как `R_c` определён как длина *кратчайшей*
прогулки из `0` в `c`, посещающей это подмножество, а маршрут `H(c)` — одна
из таких прогулок, то `R_c <= H(c)`. QED.

(Проверено дополнительно как ассерт в `constructions/strict_upper.py`
самотесте на 2 <= n <= 8, и в `checks/check_H10_reflections.py` на всех
проверяемых входах ниже — но само утверждение не нуждается в переборе,
это прямое следствие определений.)

## 3. Лемма B (цикловая структура отражения)

Зафиксируем `w in Z_n` и рассмотрим инволюцию `f_w(i) = (w - i) mod n`.

**Лемма B1 (неподвижные точки и число транспозиций).**
- Если `n` нечётно, у `f_w` ровно одна неподвижная точка (единственное
  решение `2i = w mod n`, так как `2` обратимо по модулю нечётного `n`), и
  `K(w) := (n-1)/2` нетривиальных циклов, каждый — транспозиция (`k=2`).
- Если `n` чётно, уравнение `2i = w mod n` имеет ровно 2 решения
  (`i = w/2` и `i = w/2 + n/2`), если `w` чётно, и ни одного, если `w`
  нечётно (стандартный факт: образ умножения на `2` по модулю чётного `n` —
  подгруппа чётных вычетов индекса `2`, ядро `{0, n/2}` размера `2`).
  Соответственно `K(w) = (n-2)/2` при `w` чётном, `K(w) = n/2` при `w`
  нечётном; остальные вершины разбиваются на `K(w)` транспозиций.

Ни один цикл `f_w` не может иметь длину `k >= 3`: `f_w` — инволюция
(`f_w(f_w(i)) = w - (w - i) = i`), поэтому каждая орбита имеет размер `1`
(неподвижная точка) или `2` (транспозиция). Это не зависит от `n` и `w`.

**Лемма B2 (S каждой транспозиции равно 3).** Пусть `C = (a_0, a_1)` —
2-цикл `f_w` (`a_1 = w - a_0`, `a_0 = w - a_1`). Обозначим
`delta = delta_n(a_0, a_1) = min((a_1-a_0) mod n, (a_0-a_1) mod n)`.

Разбираем оба логически возможных случая (какой из них встречается для
данной пары {a_0,a_1}, для леммы не важно — оценка `S=3` верна в обоих):

- *Неантиподальный случай* (`2*delta != n`): подписанные шаги
  `d_0 = a_1-a_0` и `d_1 = a_0-a_1`, взятые по правилу `-n/2 < d <= n/2`,
  удовлетворяют `d_1 = -d_0`, один положителен, другой отрицателен. По (1.1)
  N1 нагрузка на рёбрах короткой дуги между `a_0` и `a_1` равна `2` (обе дуги
  проходят через них в противоположных направлениях), на остальных — `0`,
  так что `M = 2`, `F = 2*delta` (сумма `|d_0|+|d_1| = 2delta`). Единственный
  переход `-->+ ` — это вершина, где входящий шаг отрицателен, исходящий
  положителен (ровно одна из двух вершин), так что `t = 1`, `E = k - 2t = 0`,
  `S = 2M + E - 1 = 4 + 0 - 1 = 3`.
- *Антиподальный случай* (`n` чётно, `d_0 = d_1 = n/2`, оба положительны по
  соглашению правила 16 AGENTS.md): обе дуги — противоположные полуокружности,
  вместе покрывающие каждое ребро ровно один раз, так что `M = 1`, `F = n`.
  Оба шага положительны, значит нет перехода `-->+` среди `d_{j-1}<0<d_j`
  (`t=0`), `E = k - 0 = 2`, `S = 2*1 + 2 - 1 = 3`.

В обоих случаях `S(C) = 3`. Следовательно `S(w) = 3*K(w)`.
*(Проверено против фактического вывода `cycle_data` из
`constructions/strict_upper.py` для всех `n`, `w` в диапазоне чекера —
`checks/check_H10_reflections.py`, Lemma B/C.)*

**Лемма B3 (F(w) в замкнутой форме).** Пусть `P = P(n) = floor(n^2/4)`.
Тогда для каждого `w`:

```
delta_n(i, w-i) = delta_n(w, 2i)          (сдвиг на -i: обе стороны -- расстояние между 0 и w-2i)
F(w) = sum_{i=0}^{n-1} delta_n(w, 2i)     (сумма |d_j| по транспозициям = сумма по всем i, так как
                                            каждая транспозиция {i, w-i} даёт вклад delta_n(i,w-i)
                                            дважды -- от i и от w-i -- что и есть |d_0|+|d_1| = 2*delta;
                                            неподвижные точки дают delta_n(w,2i)=delta_n(w,w)=0)
```

- *Нечётное `n`*: `2` обратимо по модулю `n`, поэтому `i -> 2i mod n` —
  биекция `Z_n -> Z_n`. Значит `F(w) = sum_{y=0}^{n-1} delta_n(w,y) = P`
  для ЛЮБОГО `w` (сумма расстояний от фиксированной точки до всех точек
  окружности не зависит от точки — трансляционная инвариантность `delta_n`;
  это то же тождество, что даёт `mean_c F_c(pi) = P` в N1 §3, здесь применённое
  как точное, а не среднее, значение).

- *Чётное `n = 2m`*: образ `i -> 2i mod n` — множество чётных вычетов
  `{0,2,...,n-2}`, каждый достигается ровно дважды (ядро размера `2`).
  Значит `F(w) = 2 * E(w)`, где `E(w) = sum_{y чётно} delta_n(w,y)`.
  Отождествим чётные вычеты `y = 2z` (`z = 0..m-1`) с `Z_m`.
  - Если `w = 2a` чётно: `delta_n(2a,2z) = 2*delta_m(a,z)` (обе величины —
    расстояние вдоль окружности вдвое меньшего радиуса, масштабированное на
    2; формально: `d := (2z-2a) mod n` чётно, `d = 2d'` с
    `d' = (z-a) mod m`, и `min(d, n-d) = 2*min(d', m-d')`, так как
    `min(d',m-d') <= m/2` гарантирует, что удвоение не пересекает половину
    периода `n`). Значит
    `E(w) = 2 * sum_{z=0}^{m-1} delta_m(a,z) = 2*P(m)` — снова не зависит
    от `a` (та же трансляционная инвариантность, на `Z_m`). Итого
    `F(w чётно) = 4*P(m)`.
  - Если `w` нечётно, полагаем `w = 2a+1`; сдвигом `a -> 0` (та же
    трансляционная инвариантность) `E(w)` не зависит от `a`, поэтому
    достаточно вычислить `D(m) := sum_{z=0}^{m-1} delta_n(1, 2z)` при `w=1`.
    Прямым разбором (см. численную проверку) `D(m) = 2*P(m)` при `m`
    чётном и `D(m) = 2*P(m) + 1` при `m` нечётном — это и есть единственное
    место, где чётность `m` (то есть `n mod 4`) входит в ответ.

  Собирая: `P(n) = n^2/4 = m^2`.
  - `m` чётно (`n = 0 mod 4`): `P(m) = m^2/4`, `4*P(m) = m^2 = P(n)`, и
    `D(m) = 2*P(m) = m^2/2`, `F(w нечётно) = 2*D(m) = m^2 = P(n)`.
    Итого `F(w) = P(n)` для ОБЕИХ чётностей `w`.
  - `m` нечётно (`n = 2 mod 4`): `P(m) = (m^2-1)/4`, `4*P(m) = m^2-1 = P(n)-1`,
    так что `F(w чётно) = P(n) - 1`; и `D(m) = 2*P(m)+1 = (m^2-1)/2+1
    = (m^2+1)/2`, `F(w нечётно) = 2*D(m) = m^2+1 = P(n)+1`.

Итого (сведено в одну таблицу, `n=2m`):

| n mod 4 | F(w), w чётно | F(w), w нечётно |
|---|---|---|
| нечётное n | `P` | `P` |
| 0 | `P` | `P` |
| 2 | `P - 1` | `P + 1` |

*(Формула `D(m)`, включая разбор по чётности `m`, проверена численно для
`4 <= n <= 400` (все `w`) и структурными выборками до `n = 1001` в
`checks/check_H10_reflections.py`, функция `predicted_FS`; это же тождество
можно получить прямым суммированием арифметической прогрессии, что не
включено здесь как отдельная лемма ради краткости — численная проверка
исчерпывающая по `n`, а не по общему `m`, поэтому статус этой конкретной
под-леммы — PROVED по прямому счётному аргументу выше плюс VERIFIED
численно на явном диапазоне, а не PROVED только численно, см. правило 5.)*

## 4. Явный выбор сдвига и доказательство теоремы

Так как `f_c(i) = (h - i + c) mod n = (w - i) mod n` c `w := (h+c) mod n`,
циклы `f_c` (а с ними `F_c = F(w)`, `S_c = S(w)`) зависят только от `w`, не
от `h` и `c` по отдельности. Возьмём:

```
c* = 0        если чётность w=h уже нужная (см. ниже)      [даёт w = h]
c* = 1        иначе                                         [даёт w = h+1]
```

«Нужная чётность `w`» определяется ниже прямым сравнением `2F(w)-S(w)` при
`w` чётном и нечётном (её не нужно угадывать заранее — при нечётном `n`
выбор `w` вообще не влияет на `2F-S`, см. §3, Лемма B3).

`H(0) = n`, `H(1) = n - 1` (N1 §3). По Лемме B, `2F(w) - S(w)` равно:

- нечётное `n`: `2P - 3(n-1)/2` (не зависит от `w`).
- `n = 2m`, `w` чётно: `2*Feven(w) - 3(m-1)`.
- `n = 2m`, `w` нечётно: `2*Fodd(w) - 3m`.

где `Feven = P` (`m` чётно) или `P-1` (`m` нечётно), `Fodd = P` (`m` чётно)
или `P+1` (`m` нечётно). Подставляя `P = m^2` (чётное `n`):

| n mod 4 | `2F-S`, w чётно | `2F-S`, w нечётно | разница (чётно − нечётно) |
|---|---|---|---|
| 0 (`m` чётно) | `2m^2 - 3(m-1) = 2m^2-3m+3` | `2m^2 - 3m` | `+3` (нечётное w дешевле) |
| 2 (`m` нечётно) | `2(m^2-1)-3(m-1) = 2m^2-3m+1` | `2(m^2+1)-3m = 2m^2-3m+2` | `-1` (чётное w дешевле) |

Значит: при `n = 0 mod 4` выгодно `w` нечётное; при `n = 2 mod 4` выгодно
`w` чётное; при нечётном `n` выбор `w` не влияет на `2F-S` вовсе. Определим:

```
"нужная чётность w" = нечётная,  если n = 0 mod 4
                     = чётная,   если n = 2 mod 4
                     = любая,    если n нечётно
```

и `c* in {0,1}` как выше (`c*=0`, если `w=h` уже нужной чётности, иначе
`c*=1`, что меняет чётность `w=h+1`). Тогда:

**Случай `n` нечётно.** `2F-S = 2P - 3(n-1)/2` при любом `c`; берём `c*=1`
(`H=n-1` минимален среди `H(0)=n`, `H(c\ne0)=n+delta_n(0,c)-2 \ge n-1`).
Полная длина:
```
2P - 3(n-1)/2 + (n-1) = 2P - (n-1)/2.
```
`P = (n^2-1)/4` (`n` нечётно), так что `2P = (n^2-1)/2`, и
```
2P - (n-1)/2 = [(n^2-1) - (n-1)]/2 = (n-1)(n+1-1)/2 = n(n-1)/2 = B_n.
```
Точное равенство `B_n`, для ЛЮБОГО `h` (случай не зависит от `h` вообще).

**Случай `n = 0 mod 4` (`m` чётен).** Нужная чётность `w` — нечётная.
- `h` нечётно: `c*=0` (`w=h`, `H=n`). `2F-S = 2m^2-3m` (из таблицы).
  Полная длина `= 2m^2-3m+n = 2m^2-3m+2m = 2m^2-m`.
- `h` чётно: `c*=1` (`w=h+1` нечётно, `H=n-1=2m-1`). Полная длина
  `= 2m^2-3m+2m-1 = 2m^2-m-1`.

`B_n` для чётного `n=2m`: `B_n = n(n-1)/2 = 2m(2m-1)/2 = 2m^2-m` (то же
тождество `B_n=n(n-1)/2`, C12, справедливо для всех `n`, не только
нечётных — прямая проверка `floor(n^2/4)+floor((n-1)^2/4) = n(n-1)/2`).
Значит: `h` нечётно `-> B_n`; `h` чётно `-> B_n - 1`.

**Случай `n = 2 mod 4` (`m` нечётен).** Нужная чётность `w` — чётная.
- `h` чётно: `c*=0` (`w=h` чётно, `H=n=2m`). `2F-S = 2m^2-3m+1`.
  Полная длина `= 2m^2-3m+1+2m = 2m^2-m+1 = B_n + 1`.
- `h` нечётно: `c*=1` (`w=h+1` чётно, `H=n-1=2m-1`). `2F-S=2m^2-3m+1`
  (то же значение, `w` та же чётность). Полная длина
  `= 2m^2-3m+1+2m-1 = 2m^2-m = B_n`.

Это в точности таблица из §1. По Лемме A, для того же `c*`,
`2F_{c*}-S_{c*}+R_{c*} <= 2F_{c*}-S_{c*}+H(c*)`, что даёт теорему: минимум
по `c` выражения `2F_c-S_c+R_c` не превосходит табличное значение, а оно
`<= B_n+1` во всех случаях и `<= B_n`, кроме единственного случая
`n=2 mod 4`, `h` чётно. QED.

## 5. Замечание о свободном сокращении (не входит в PROVED-часть)

Численно (`data/runs/strict_loss_audit/report.md`, семейства; и новый
запуск ниже) во ВСЕХ проверенных случаях `n = 2 mod 4`, `h` чётно —
единственный класс с превышением `B_n+1` — минимум по ВСЕМ `c` (не только
по `c*` из §4) величины `red_R` (длина после свободного сокращения слова
маршрута по переносчикам) уже не превосходит `B_n`: `4 <= n <= 12`
исчерпывающе (C27v) и дополнительно проверено здесь при `n = 998` (см.
`data/runs/check_H10_reflections/`) — но НЕ при использовании ровно того
`c*`, что построен в §4: там сокращение не всегда убирает единицу
(проверено контрпримером на `n=998, h=0, c=c*=0`: длина после сокращения
остаётся `B_n+1`; при этом `c=2` для того же входа даёт `B_n-1` уже без
сокращения). Иными словами, вторая часть H10 («после свободного сокращения
`<= B_n`») для отражений подтверждена ЧИСЛЕННО в расширенном диапазоне, но
НЕ доказана здесь алгебраически: доказательство потребовало бы либо явной
формулы для минимума `red_R` по ВСЕМ `c` (не только по кандидатам `{0,1}`
из §4), либо анализа сокращений на стыке для другого явного `c`, что не
сделано в этой сессии. Статус: **VERIFIED** (см. §6), не PROVED.
