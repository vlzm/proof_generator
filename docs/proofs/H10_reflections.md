# H10 на семействе отражений — доказательство (сессия 4, 13.09.2026)

Статус: PROVED для всего семейства отражений `pi(i) = h - i mod n`, все `n >= 4`,
все `h in Z_n`. Регистрируется как C28. Общий случай (произвольная `pi`) остаётся
CONJECTURED — см. C27 и раздел «Что не доказано» ниже.

Обозначения — PROBLEM §5.2–5.3, код — `constructions/strict_upper.py`. Цель:

```text
H10:  min_c [2F_c - S_c + R_c] <= B_n + 1
```

где `R_c` — длина кратчайшей прогулки по Z_n из 0 в c, посещающей все
переносчики нетривиальных циклов `f_c(i) = (pi(i)+c) mod n` (вариант N1,
правило 16 AGENTS.md; локальные слова и их длина `2F_c-S_c` — часть N1,
не варианта).

## 1. Тривиальные оценки маршрута

`R_c <= H(c)` для любого множества переносчиков и любого c: маршрут N1 §3
длины `H(c)` посещает все n вершин, значит и любое подмножество переносчиков;
`R_c` — минимум по всем допустимым прогулкам, значит не больше. Это уже
отмечено в отчёте `data/runs/strict_loss_audit/report.md` («R_c <= H(c)
тривиально»). Нужны только два конкретных значения, оба из N1 §3
(`H(0)=n`, `H(c)=n+delta_n(0,c)-2` при c != 0, C16/C18 PROVED):

```text
R_0 <= H(0) = n            (полный оборот L^n посещает все n вершин)
R_1 <= H(1) = n - 1         (delta_n(0,1) = 1)
```

## 2. Точные формулы F_c, S_c на отражениях (усиление C24)

Пусть `pi(i) = h - i mod n`, c in Z_n, `h' = (h+c) mod n`. Тогда
`f_c(i) = (h' - i) mod n` — снова отражение с параметром h', то есть
инволюция. C24 (PROBLEM §5.3) даёт локальную структуру: у неантиподальной
транспозиции `M=2, E=0, S=3`; у антиподальной (существует только при чётном
n) `M=1, E=2, S=3`; в обоих случаях **S(C) = 3**. Значит `S_c = 3 * (число
транспозиций f_c)`, и вся работа — точно посчитать число транспозиций и
`F_c = sum 2*d(пара)` по параметру h', без усреднения по c.

### 2.1. Неподвижные точки и антиподальные пары

`i` — неподвижная точка `f_c` тогда и только тогда, когда `2i = h' mod n`.

- **n нечётно**: `gcd(2,n)=1`, решение единственно — ровно 1 неподвижная
  точка при любом h'. Антиподальных пар нет (нет точной середины).
- **n чётно**, `n=2m`: решение существует тогда и только тогда, когда h'
  чётно (в Z_n), и тогда решений ровно 2 (`i0` и `i0+m`). При h' нечётном —
  0 неподвижных точек.

Пара `{p, h'-p}` антиподальна тогда и только тогда, когда `h'-p = p+m mod n`,
то есть `2p = h'-m mod n`; это разрешимо (при чётном n) тогда и только тогда,
когда `h'-m` чётно, то есть `h' ≡ m (mod 2)`, и тогда пара ровно одна.

Отсюда четыре случая по `(n mod 4, чётность h')` (m = n/2):

| n mod 4 | h' чётно | h' нечётно |
|---|---|---|
| 0 (m чётно) | 2 неп.т., theta=1 | 0 неп.т., theta=0 |
| 2 (m нечётно) | 2 неп.т., theta=0 | 0 неп.т., theta=1 |

### 2.2. Биекция p -> d(p) и точное число транспозиций

Пусть `d(p) = (h' - 2p) mod n` — циркулярное расстояние пары `{p, h'-p}`,
взятое со знаком так, что `d(p) in (0, n/2)` ровно когда p — переносчик этой
пары (код `choose_carrier`: переносчик — исток положительного короткого шага;
проверено прямым вычислением `signed_step`, см. `/tmp` сессии, воспроизводимо
через `constructions/strict_upper.cycle_data`+`choose_carrier`).

- **n нечётно**: отображение `p -> d(p) mod n` — биекция Z_n -> Z_n (обратимо
  умножением на `inv(2) mod n`). Значит `d` пробегает `{1,...,(n-1)/2}` (полосу
  `(0,n/2)`) **ровно по одному разу** при любом h'. Отсюда:
  ```text
  F_c = 2 * sum_{d=1}^{(n-1)/2} d = (n-1)(n+1)/4 = (n^2-1)/4 = P
  S_c = 3 * (n-1)/2
  ```
  точно для КАЖДОГО c, не только в среднем (усиление C24: там `s =
  overline(S_c)`, здесь `S_c` показано постоянным). Проверено конструктивно
  (не только по формуле) для n = 4..59, 99..103, 199..202, все h in Z_n
  (или представители) — см. `checks/check_H10_reflections.py`.

- **n чётно** (`n=2m`): `2p mod n` пробегает чётные вычеты `{0,2,...,n-2}`,
  каждый по два раза; `d(p) mod n` имеет ту же чётность, что и h'. Для
  каждого допустимого значения `d in (0,m)` этой чётности ровно два p дают
  это d (пара `p` и `p+m`), то есть ровно две различные транспозиции с
  одинаковым F=2d. Прямой подсчёт по каждой из 4 комбинаций (n mod 4,
  чётность h') даёт:

  ```text
  n = 0 (mod 4):
    h' чётно:   F_c = n^2/4,        S_c = 3n/2 - 3
    h' нечётно: F_c = n^2/4,        S_c = 3n/2
  n = 2 (mod 4):
    h' чётно:   F_c = n^2/4 - 1,    S_c = 3n/2 - 3
    h' нечётно: F_c = n^2/4 + 1,    S_c = 3n/2
  ```

  Вывод (сумма по d конечной арифметической прогрессии, антиподальная пара
  добавляет ровно F=n, S=3) воспроизведён и сверен конструктивно для
  n = 4..58 (чётные), 100..102, 200..202 — `checks/check_H10_reflections.py`.
  Совпадает с наблюдением отчёта сессии 3 («F_c = P при всех c для нечётного n
  и n ≡ 0 mod 4; F_c чередует P ± 1 при n ≡ 2 mod 4») — здесь это доказано, а
  не только замечено по данным.

## 3. Доказательство H10 на отражениях

`L(h') := 2F_c - S_c` зависит (при заданном n) только от n mod 4 и чётности
h' — не от c и h по отдельности, а только от их суммы. Используя формулы §2.2:

```text
n нечётно:              L = 2P - 3(n-1)/2                          (для всех h')
n = 0 (mod 4), h' чётно: L = 2P - 3n/2 + 3
n = 0 (mod 4), h' нечёт: L = 2P - 3n/2
n = 2 (mod 4), h' чётно: L = 2P - 3n/2 + 1
n = 2 (mod 4), h' нечёт: L = 2P + 2 - 3n/2
```

Стратегия выбора c (доказывает H10 явной конструкцией, не перебором):

- **n нечётно.** Взять `c = 0` (h' = h). `R_0 <= n`. Алгебраически
  (P = (n^2-1)/4, B_n = n(n-1)/2):
  ```text
  L + n = 2P - 3(n-1)/2 + n = (n-1)(n-2)/2 + n = B_n + 1.
  ```
  Точное равенство: `min_c[2F_c-S_c+R_c] <= B_n + 1` при c = 0 всегда
  (наблюдаемый в данных факт «c*=1 часто даёт B_n» — это дополнительная
  экономия сверх доказанного здесь, доказательству не нужна).

- **n = 0 (mod 4).** Цель — c такой, что h' = h+c нечётно.
  - h нечётно: c = 0, h' = h нечётно, `R_0 <= n`:
    `L + n = 2P - 3n/2 + n = 2P - n/2 = B_n` (< B_n+1).
  - h чётно: c = 1, h' = h+1 нечётно, `R_1 <= H(1) = n-1`:
    `L + (n-1) = 2P - 3n/2 + n - 1 = 2P - n/2 - 1 = B_n - 1`.
  В обоих случаях `min_c[...] <= B_n < B_n + 1`.

- **n = 2 (mod 4).** Цель — h' чётно.
  - h чётно: c = 0, h' = h чётно, `R_0 <= n`:
    `L + n = 2P - 3n/2 + 1 + n = 2P - n/2 + 1 = B_n + 1` (точное равенство,
    единственный тесный случай — совпадает с C27v: «превышение +1 только на
    отражении n=6, h=2» и семейством «+1,0,+1,0,...» по h из отчёта сессии 3).
  - h нечётно: c = 1, h' = h+1 чётно, `R_1 <= H(1) = n-1`:
    `L + (n-1) = 2P - 3n/2 + 1 + n - 1 = 2P - n/2 = B_n`.

Во всех случаях `min_c [2F_c - S_c + R_c] <= B_n + 1`, с равенством только
при `n ≡ 2 (mod 4)` и h чётном. Это доказывает H10 для всего семейства
отражений (все n >= 4, все h) — QED.

Используемые факты о N1 без переоткрытия: `H(0)=n`, `H(1)=n-1` (N1 §3, часть
C16/C18, PROVED); `R_c <= H(c)` (тривиально по определению R_c как минимума).
Единственные новые утверждения — точные (не средние) формулы F_c, S_c §2 и
арифметика §3.

## 4. Что не доказано (за пределы этой сессии)

H10 для произвольной pi (C27) остаётся CONJECTURED. Ключевое отличие: на
отражениях `2F_c - S_c` зависит только от чётности `h'=h+c`, а не от полного
h — этим и объясняется, почему хватает c из {0,1}. Для произвольной pi
`F_c = sum_i delta_n(i - pi(i), c)` (тождество PLAN §4.1) — это 1-медиана
мультимножества `{i - pi(i)}`, и минимум по c может быть далеко от 0 и 1;
одновременно нужна верхняя оценка на `S_c` и `R_c` именно у минимизирующего
F_c сдвига, а не структурная гарантия по чётности. Собственный маршрут H(c)
для этой оценки не годится (H9 REFUTED, контрпример n=9 в
`data/runs/strict_loss_audit/perms_n9.json`); не проверено, годится ли R_c
вместо H(c) для той же схемы аргумента, который здесь сработал на
отражениях, — это следующий шаг (PLAN §8), а не завершённый результат.
